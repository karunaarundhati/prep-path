Discrete random variables & PMF

A discrete random variable turns the outcome of a random experiment into a whole number. Its probability mass function (PMF) lists how likely each number is, and from the PMF you can compute the mean and the variance.

  • Expectation (mean)
  • Variance and standard deviation

The idea in plain words

Suppose you toss three coins and count the heads. The result could be 0, 1, 2 or 3. You do not know the answer before you toss, so the count is uncertain. A quantity whose value depends on chance is called a random variable. We usually write it with a capital letter, such as X.

Think of a shop that counts customers each hour. The count changes from hour to hour, and you cannot know it in advance. But you can record how often each count happened over many hours. That record is a table of frequencies. Turn the frequencies into probabilities and you have a probability mass function, or PMF. The PMF tells you how the random variable spreads its chances over the possible values.

Once you have the PMF, two summary numbers become very useful. The first is the expectation, which is the long-run average. The second is the variance, which measures how spread out the values are around that average. GATE questions on this topic almost always give you a PMF table and ask for one of these numbers. If you can read the table and multiply carefully, you can answer them.

This topic is the bridge between basic probability and the rest of the statistics in the Data Science and AI (DA) paper, and it is also used in the probability parts of the Robotics and Automation (RA) paper. Later topics, such as the binomial and Poisson distributions, are just special PMFs with neat formulas.

Key terms

Each term is explained first in plain words, then in its precise form.

Random experiment
Plain meaning: an action whose result you cannot predict exactly, such as a coin toss. Precise definition: a process with a set of possible outcomes, where each outcome has a definite probability.
Random variable
Plain meaning: a rule that gives a number for each outcome. Precise definition: a function from the outcomes of a random experiment to the real numbers.
Discrete random variable
Plain meaning: a variable that takes values you can list one by one, such as 0, 1, 2. Precise definition: a random variable whose set of possible values is finite or countably infinite.
Support
Plain meaning: the list of values the variable can actually take. Precise definition: the set of all x with P(X = x) > 0.
PMF, p(x) or P(X = x)
Plain meaning: the chance that X equals a particular value x. Precise definition: a function that gives P(X = x) for each x, with every value at least 0 and the values adding to 1.
Expectation E[X]
Plain meaning: the long-run average value of X. Precise definition: E[X] = Σ x P(X = x), summed over the support.
Variance Var(X)
Plain meaning: the average squared distance from the mean. Precise definition: Var(X) = E[(X - E[X])²], which can also be written as E[X²] - (E[X])².
Standard deviation
Plain meaning: a spread measure in the same units as X. Precise definition: the positive square root of the variance, √Var(X).
Cumulative distribution function (CDF)
Plain meaning: the chance that X is at most x. Precise definition: F(x) = P(X ≤ x) = Σ P(X = t) over all t ≤ x.
Mean
Plain meaning: another name for the expectation of X. Precise definition: μ = E[X].
Notation Σ
Plain meaning: "add these up". Precise definition: Σx f(x) is the sum of f(x) over all values x in the support.

Concept 1: Random variables and the PMF

From outcomes to numbers

A random experiment has outcomes. For three coin tosses, one outcome is HTH (heads, tails, heads). Another is TTT. A random variable X is a rule that turns each outcome into a number. The rule "count the heads" turns HTH into 2 and TTT into 0.

Notice that the random variable is not the same as the outcome. Many different outcomes can give the same number. For example, HHT, HTH and THH all give X = 2.

The PMF

The probability mass function gives the chance of each value. We write it as P(X = x), read as "the probability that X equals x". Two rules must always hold:

P(X = x) ≥ 0 for every x, and Σ P(X = x) = 1
  • Every probability is zero or positive. A negative chance is impossible.
  • All the probabilities add to exactly 1, because X must take some value.

To find the chance of a set of values, add the PMF over that set. For example, P(X ≥ 2) = P(X = 2) + P(X = 3).

Worked example: three coin tosses

  1. There are 8 equally likely outcomes: HHH, HHT, HTH, HTT, THH, THT, TTH and TTT.
  2. Count the heads in each outcome. The counts are 3, 2, 2, 1, 2, 1, 1 and 0.
  3. Count how many outcomes give each value. Zero heads: 1 outcome. One head: 3 outcomes. Two heads: 3 outcomes. Three heads: 1 outcome.
  4. Divide by 8. P(X = 0) = 1/8, P(X = 1) = 3/8, P(X = 2) = 3/8, P(X = 3) = 1/8.
  5. Check. The four probabilities add to 1/8 + 3/8 + 3/8 + 1/8 = 8/8 = 1.

Here is a Python check that builds the same PMF by listing all 8 outcomes.

from itertools import product
from fractions import Fraction as F
from collections import Counter

outcomes = list(product("HT", repeat=3))   # all 8 equally likely sequences
counts = Counter(seq.count("H") for seq in outcomes)
pmf = {x: F(counts[x], len(outcomes)) for x in sorted(counts)}

for x, p in pmf.items():
    print(f"P(X = {x}) = {p}")
print("sum of PMF =", sum(pmf.values()))
print("P(X >= 2) =", sum(p for x, p in pmf.items() if x >= 2))
P(X = 0) = 1/8
P(X = 1) = 3/8
P(X = 2) = 3/8
P(X = 3) = 1/8
sum of PMF = 1
P(X >= 2) = 1/2

Key ideaA PMF is valid only if every entry is at least 0 and the entries add to 1. This check is the first thing to do with any table in a GATE question.

TrapStudents sometimes read P(X ≥ 2) as P(X > 2). The symbol ≥ includes the value 2 itself. Write down the values you include before you add.

Self-check: a PMF has P(X = 1) = 0.2, P(X = 2) = 0.5 and P(X = 3) = 0.4. Is it valid?

No. The values add to 1.1, not 1. Every value is non-negative, but the total must be exactly 1.

Self-check: using the three-toss PMF, what is P(1 ≤ X ≤ 2)?

P(X = 1) + P(X = 2) = 3/8 + 3/8 = 6/8 = 3/4.

Concept 2: Expectation, the long-run average

Why we need it

Suppose you play a game many times, and the amount you win is a random variable X. You would like one number that tells you what to expect per game. The expectation is that number. It is the average result you would get if you repeated the experiment a very large number of times.

Everyday picture: a shop sells apples in bags. Some bags have 0 bad apples, some have 1 and some have 2. If you buy many bags, the average number of bad apples per bag settles to a fixed value. That settled value is the expectation.

The formula

E[X] = Σ x × P(X = x)
  • x is each possible value of the variable.
  • P(X = x) is the chance of that value.
  • Σ means you add the product over all values.

Each value is weighted by its probability. Values that are more likely pull the average towards them.

Worked example: the three-toss count

  1. Write the products x × P(X = x) in a table. For x = 0: 0 × 1/8 = 0. For x = 1: 1 × 3/8 = 3/8. For x = 2: 2 × 3/8 = 6/8. For x = 3: 3 × 1/8 = 3/8.
  2. Add the products. 0 + 3/8 + 6/8 + 3/8 = 12/8 = 3/2.
  3. So E[X] = 3/2 = 1.5. On average you see 1.5 heads per three tosses. This makes sense: a fair coin gives heads half the time, and 3 × 1/2 = 3/2.

A second quantity: E[X²]

Later you will need E[X²], the expectation of the square of X. The rule is the same, but each value is squared before weighting:

E[X²] = Σ x² × P(X = x)

Do not square the answer E[X] to get E[X²]. Square each value first, then weight it.

The Python block below computes both E[X] and E[X²] for the same PMF, and it uses exact fractions.

from fractions import Fraction as F

pmf = {0: F(1, 8), 1: F(3, 8), 2: F(3, 8), 3: F(1, 8)}

ex = sum(x * p for x, p in pmf.items())
ex2 = sum(x * x * p for x, p in pmf.items())

print("E[X] =", ex)
print("E[X^2] =", ex2)
E[X] = 3/2
E[X^2] = 3

TrapE[X] is not always one of the possible values. Here the mean is 1.5, which X can never equal. The expectation is an average, not a value you must see.

GATE loves thisExpectation questions often give a PMF table with an unknown constant c. First use the fact that the PMF sums to 1 to find c. Then compute E[X]. Students who skip the first step get the wrong answer.

Self-check: X takes 1 with probability 0.5 and 3 with probability 0.5. What is E[X]?

E[X] = 1 × 0.5 + 3 × 0.5 = 0.5 + 1.5 = 2.

Self-check: what is E[X²] for the same variable?

E[X²] = 1² × 0.5 + 3² × 0.5 = 0.5 + 4.5 = 5.

Concept 3: Variance and standard deviation

Why we need it

Two variables can have the same mean but very different spreads. Imagine two cricket players who both average 40 runs. One scores about 40 every match. The other scores 0 in some matches and 80 in others. The mean is the same, but the second player is far less predictable. The variance is the number that tells these two cases apart.

The definition and the shortcut

The variance is the average squared distance of X from its mean μ = E[X]. Squaring makes all distances positive, so that values above and below the mean do not cancel out.

Var(X) = E[(X - μ)²] = E[X²] - (E[X])²

The second form is a shortcut. It is usually faster in exams: first find E[X] and E[X²], then subtract the square of the mean.

The standard deviation is the square root of the variance. It has the same units as X, so it is easier to read:

SD(X) = √Var(X)

Worked example: the three-toss count

  1. From Concept 2: E[X] = 3/2 and E[X²] = 3.
  2. Square the mean. (3/2)² = 9/4.
  3. Subtract. Var(X) = 3 - 9/4 = 12/4 - 9/4 = 3/4.
  4. Standard deviation. √(3/4) = √3 / 2, which is about 0.866.

The Python check below computes the variance and standard deviation from the same PMF.

import math
from fractions import Fraction as F

pmf = {0: F(1, 8), 1: F(3, 8), 2: F(3, 8), 3: F(1, 8)}
ex = sum(x * p for x, p in pmf.items())
ex2 = sum(x * x * p for x, p in pmf.items())
var = ex2 - ex ** 2

print("Var(X) =", var, "=", float(var))
print("SD(X) =", round(math.sqrt(var), 3))
Var(X) = 3/4 = 0.75
SD(X) = 0.866

Two rules for changing the variable

Often a question asks about Y = aX + b, where a and b are constants. Two rules help:

  • Expectation is linear: E[aX + b] = a E[X] + b.
  • Variance ignores the shift and squares the scale: Var(aX + b) = a² Var(X). The constant b disappears, because adding b shifts every value equally.

For example, if E[X] = 4 and Var(X) = 5, then Y = 2X + 3 has E[Y] = 2 × 4 + 3 = 11 and Var(Y) = 2² × 5 = 20.

TrapE[X²] is not the same as (E[X])². For the three-toss variable, E[X²] = 3, but (E[X])² = 2.25. Mixing these up is the most common mistake in variance questions.

Key ideaThe variance is always zero or positive. If you get a negative variance, you have made an arithmetic error, usually in E[X²] or in squaring the mean.

Self-check: E[X] = 2 and E[X²] = 6. What is Var(X)?

Var(X) = 6 - 2² = 6 - 4 = 2.

Self-check: if Var(X) = 9, what is the standard deviation of X?

SD(X) = √9 = 3.

Concept 4: The CDF from a PMF

Why we need it

The PMF gives the chance of exactly one value. Many questions ask about "at most" a value, such as "what is the chance of at most 1 head?" The cumulative distribution function, or CDF, answers this directly. It adds the PMF from the smallest value up to x.

The formula

F(x) = P(X ≤ x) = Σ P(X = t), summed over all t ≤ x

The CDF has three properties that help you check your work:

  • It never decreases as x grows. Adding more values can only add probability.
  • It starts at 0 for very small x and reaches 1 for large x.
  • For a discrete variable it is a staircase. It jumps at each value of the support and stays flat in between.

Using the CDF for intervals

To find the chance that X lies between two values, subtract the CDF values. For discrete variables, be careful with the endpoints:

P(a < X ≤ b) = F(b) - F(a)

The left endpoint a is excluded, and the right endpoint b is included. This is why the formula uses F(a), not F(a) minus a single PMF value.

Worked example: the three-toss count

  1. F(0) = P(X ≤ 0) = 1/8.
  2. F(1) = P(X ≤ 1) = 1/8 + 3/8 = 4/8 = 1/2.
  3. F(2) = P(X ≤ 2) = 1/2 + 3/8 = 7/8.
  4. F(3) = P(X ≤ 3) = 7/8 + 1/8 = 1. The staircase has reached its top.
  5. P(1 < X ≤ 2) = F(2) - F(1) = 7/8 - 1/2 = 3/8, which matches P(X = 2) directly.

The Python check computes the staircase and the interval probability.

from fractions import Fraction as F

pmf = {0: F(1, 8), 1: F(3, 8), 2: F(3, 8), 3: F(1, 8)}

cum = F(0)
for x in sorted(pmf):
    cum += pmf[x]
    print(f"F({x}) = {cum}")

print("P(1 < X ≤ 2) =", F(7, 8) - F(1, 2))
F(0) = 1/8
F(1) = 1/2
F(2) = 7/8
F(3) = 1
P(1 < X ≤ 2) = 3/8

TipTo build the CDF table quickly, write the PMF in one column, then add each row to the running total in the next column. The last total must be 1. If it is not, the PMF is wrong.

TrapFor discrete variables, P(X < 2) and P(X ≤ 2) are different when X can equal 2. The first is F(1), the second is F(2). Read the inequality carefully.

Self-check: what is F(x) for x below the smallest value of the support?

It is 0, because X cannot be that small.

Self-check: F(1) = 0.4 and F(3) = 0.9. What is P(1 < X ≤ 3)?

P(1 < X ≤ 3) = F(3) - F(1) = 0.9 - 0.4 = 0.5.

Solved GATE-style problems

These problems are original GATE-style questions written for practice. They are not past paper questions. Work each one on paper first, then compare with the solution.

Expectation from a small table

A random variable X takes the values 1, 2 and 3 with probabilities 0.2, 0.5 and 0.3. Find E[X].

How to think about it

  1. What is asked. The mean of X.
  2. Which idea applies. E[X] = Σ x P(X = x).
  3. Work it out. 1 × 0.2 = 0.2. 2 × 0.5 = 1.0. 3 × 0.3 = 0.9. Sum: 0.2 + 1.0 + 0.9 = 2.1.
  4. Check. The mean must lie between the smallest value 1 and the largest value 3. The answer 2.1 does, and it is closer to 2, where most of the probability sits.

Answer: E[X] = 2.1

Select all true statements about a PMF

A random variable X has P(X = 0) = 0.5, P(X = 1) = 0.3, P(X = 2) = 0.2 and P(X = 3) = 0. Select all that apply.

(A) The table is a valid PMF.
(B) P(X ≤ 1) = 0.8.
(C) E[X] = 0.7.
(D) P(X = 3) = 0.3.

How to think about it

  1. What is asked. Check each statement and tick the true ones.
  2. Which idea applies. PMF validity, adding probabilities, and the expectation formula.
  3. Work it out. Option A: all values are at least 0 and 0.5 + 0.3 + 0.2 + 0 = 1, so A is true. Option B: P(X ≤ 1) = 0.5 + 0.3 = 0.8, so B is true. Option C: E[X] = 0 × 0.5 + 1 × 0.3 + 2 × 0.2 + 3 × 0 = 0.3 + 0.4 = 0.7, so C is true. Option D: P(X = 3) is given as 0, so D is false.
  4. Check. The table in option D has the value 3 with probability 0, so D cannot be true.

Answer: (A), (B) and (C) are true. Option (D) is false.

Variance of a die

A fair six-sided die is rolled once. Let X be the number shown. Find Var(X). Give the answer as a fraction in lowest terms.

How to think about it

  1. What is asked. The variance of a uniform variable on 1 to 6.
  2. Which idea applies. Compute E[X], then E[X²], then use Var(X) = E[X²] - (E[X])².
  3. Work it out. Each value has probability 1/6. E[X] = (1 + 2 + 3 + 4 + 5 + 6)/6 = 21/6 = 7/2. E[X²] = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6. Var(X) = 91/6 - (7/2)² = 91/6 - 49/4. Common denominator 12: 182/12 - 147/12 = 35/12.
  4. Check. 35/12 is about 2.92. The standard deviation is about 1.71, which is a sensible spread for values from 1 to 6.

Answer: 35/12

Mean and spread of a gain

NAT question. A game gives a gain X with P(X = -1) = 0.2, P(X = 0) = 0.5 and P(X = 2) = 0.3. Find Var(X). Give the answer correct to two decimal places.

How to think about it

  1. What is asked. The variance of X, to two decimals.
  2. Which idea applies. The variance shortcut, which needs E[X] and E[X²].
  3. Work it out. E[X] = (-1)(0.2) + 0(0.5) + 2(0.3) = -0.2 + 0 + 0.6 = 0.4. E[X²] = (1)(0.2) + 0(0.5) + 4(0.3) = 0.2 + 1.2 = 1.4. Var(X) = 1.4 - 0.4² = 1.4 - 0.16 = 1.24.
  4. Check. A negative value is included, so E[X²] must be larger than E[X]² = 0.16, and it is (1.4 is larger). The answer 1.24 is positive, as it must be.

Answer: 1.24

Finding the constant first

A random variable X has P(X = x) = c × x for x = 1, 2, 3 and 4, and P(X = x) = 0 otherwise. Find E[X]. Give the answer as a decimal.

How to think about it

  1. What is asked. E[X], but the constant c is unknown.
  2. Which idea applies. The PMF must sum to 1, which gives c. Then use the expectation formula.
  3. Work it out. Sum: c(1 + 2 + 3 + 4) = 10c = 1, so c = 0.1. Then P(X = 1) = 0.1, P(X = 2) = 0.2, P(X = 3) = 0.3, P(X = 4) = 0.4. E[X] = 1 × 0.1 + 2 × 0.2 + 3 × 0.3 + 4 × 0.4 = 0.1 + 0.4 + 0.9 + 1.6 = 3.0.
  4. Check. The probabilities 0.1, 0.2, 0.3 and 0.4 add to 1. The mean 3.0 is weighted towards the larger values, which have larger probabilities, so it sits above the midpoint 2.5.

Answer: 3.0

Mean and variance with an unknown probability

A random variable X takes the values 0, 1 and 2. Its PMF is P(X = 0) = a, P(X = 1) = 0.4 and P(X = 2) = a, where a is a constant. Find Var(X). Give the answer as a decimal.

How to think about it

  1. What is asked. The variance, but the constant a is unknown.
  2. Which idea applies. The PMF sums to 1 to find a. Then compute E[X] and E[X²].
  3. Work it out. Sum: a + 0.4 + a = 1, so 2a = 0.6 and a = 0.3. Then E[X] = 0 × 0.3 + 1 × 0.4 + 2 × 0.3 = 0.4 + 0.6 = 1.0. E[X²] = 0 × 0.3 + 1 × 0.4 + 4 × 0.3 = 0.4 + 1.2 = 1.6. Var(X) = 1.6 - 1.0² = 0.6.
  4. Check. The distribution is symmetric about 1, since P(0) = P(2). A symmetric shape has mean 1, which matches. The variance 0.6 is less than 1, which is reasonable because most of the probability is at 1.

Answer: 0.6

Mean of a squared shift

A random variable X has E[X] = 4 and Var(X) = 5. Find E[(X - 2)²]. Give the answer as an integer.

How to think about it

  1. What is asked. The mean of the squared distance from 2, not from the mean of X.
  2. Which idea applies. Expand the square and use linearity of expectation.
  3. Work it out. (X - 2)² = X² - 4X + 4. So E[(X - 2)²] = E[X²] - 4 E[X] + 4. We know E[X²] = Var(X) + (E[X])² = 5 + 16 = 21. Then 21 - 4 × 4 + 4 = 21 - 16 + 4 = 9.
  4. Check. Another route: E[(X - 2)²] = Var(X) + (E[X] - 2)² = 5 + (4 - 2)² = 5 + 4 = 9. Both routes agree.

Answer: 9

Difference of two dice

NAT question. Two fair six-sided dice are rolled. Let X be the absolute difference of the two numbers shown. Find E[X]. Give the answer correct to three decimal places.

How to think about it

  1. What is asked. The expectation of the absolute difference, to three decimals.
  2. Which idea applies. Build the PMF of X from the 36 equally likely pairs, then use the expectation formula.
  3. Work it out. Counting the 36 pairs gives: difference 0 in 6 pairs, 1 in 10, 2 in 8, 3 in 6, 4 in 4 and 5 in 2. Total 36. So P(X = 0) = 6/36, P(X = 1) = 10/36, P(X = 2) = 8/36, P(X = 3) = 6/36, P(X = 4) = 4/36, P(X = 5) = 2/36. E[X] = (0 × 6 + 1 × 10 + 2 × 8 + 3 × 6 + 4 × 4 + 5 × 2)/36 = (0 + 10 + 16 + 18 + 16 + 10)/36 = 70/36 = 35/18, which is about 1.944.
  4. Check. The six counts add to 36, and the answer lies between 0 and 5. The mean is below 2.5, which is the midpoint of 0 and 5, as expected because small differences are more common.

Answer: 1.944

Exam-level 1: Variance after a linear change (NAT, 2 marks)

NAT question. A small shop counts the number of customer complaints X that it receives in one hour. The probability mass function is P(X = 0) = 0.1, P(X = 1) = 0.4, P(X = 2) = 0.3 and P(X = 3) = 0.2. The shop then uses the score Y = 3X - 2 in a monthly report. Find the variance of Y. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. Var(Y), to two decimal places.
  2. Which idea applies. Var(aX + b) = a² Var(X), so the shift -2 is ignored. Also Var(X) = E[X²] - (E[X])².
  3. Work it out. E[X] = 0 + 0.4 + 0.6 + 0.6 = 1.6. E[X²] = 0 + 0.4 + 0.3 × 4 + 0.2 × 9 = 0.4 + 1.2 + 1.8 = 3.4. Var(X) = 3.4 - 1.6² = 3.4 - 2.56 = 0.84. Then Var(Y) = 3² × 0.84 = 7.56.
  4. Check. The constant -2 moves the values but does not change the spread. The factor 3 changes the spread by 3² = 9, and 9 × 0.84 = 7.56.

Answer: 7.56

from fractions import Fraction as F
pmf = {0: F(1, 10), 1: F(4, 10), 2: F(3, 10), 3: F(2, 10)}
EX = sum(x * p for x, p in pmf.items())
EX2 = sum(x * x * p for x, p in pmf.items())
VX = EX2 - EX ** 2
VY = 3 ** 2 * VX
print("E[X] =", EX)
print("Var(X) =", VX)
print("Var(Y) =", VY, "=", float(VY))
E[X] = 8/5
Var(X) = 21/25
Var(Y) = 189/25 = 7.56

Exam-level 2: Scores with a linear conversion (MCQ, 2 marks)

A quality team at a bakery gives each product a taste score X from 1 to 4. The team uses the probability mass function P(X = k) = k/10 for k = 1, 2, 3 and 4, so a score of 4 is the most likely outcome. The team then converts each score into a cost C = 2X - 1 for its budget model. Which of the following is the variance of C? (A) 1 (B) 2 (C) 3 (D) 4. Select one option.

How to think about it

  1. What is asked. Var(C) = Var(2X - 1).
  2. Which idea applies. Var(aX + b) = a² Var(X), and Var(X) = E[X²] - (E[X])².
  3. Work it out. E[X] = 0.1(1) + 0.2(2) + 0.3(3) + 0.4(4) = 3. E[X²] = 0.1(1) + 0.2(4) + 0.3(9) + 0.4(16) = 10. So Var(X) = 10 - 9 = 1, and Var(2X - 1) = 2² × 1 = 4. The answer is option D.
  4. Check. The shift -1 does not change the spread. Why the other options fail: (A) is Var(X) with no factor of 2², (B) uses a factor of 2 instead of 4, and (C) is E[X], which is a mean, not a variance.

Answer: (D) 4

from fractions import Fraction as F
pmf = {k: F(k, 10) for k in range(1, 5)}
EX = sum(k * p for k, p in pmf.items())
EX2 = sum(k * k * p for k, p in pmf.items())
VX = EX2 - EX ** 2

print("E[X] =", EX)
print("E[X^2] =", EX2)
print("Var(X) =", VX)
print("Var(2X - 1) =", 2 ** 2 * VX)

Exam-level 3: Checking a PMF and its summaries (MSQ, 2 marks)

A call centre records how many times X a caller is transferred before reaching an agent. The probability mass function is P(X = 0) = 0.2, P(X = 1) = 0.5 and P(X = 2) = 0.3. Select all the statements that are true.

  • (A) E[X] = 1.1
  • (B) Var(X) = 0.49
  • (C) P(X ≥ 1) = 0.8
  • (D) The cumulative distribution function satisfies F(1) = 0.5.

How to think about it

  1. What is asked. Which of the four statements are true. Select all that apply.
  2. Which idea applies. E[X] = Σ x P(x), Var(X) = E[X²] - (E[X])², P(X ≥ 1) = 1 - P(X = 0), and F(x) = P(X ≤ x).
  3. Work it out. E[X] = 0 × 0.2 + 1 × 0.5 + 2 × 0.3 = 1.1, so (A) is true. E[X²] = 0.5 + 4 × 0.3 = 1.7, so Var(X) = 1.7 - 1.1² = 1.7 - 1.21 = 0.49, and (B) is true. P(X ≥ 1) = 1 - 0.2 = 0.8, so (C) is true. F(1) = P(X ≤ 1) = 0.2 + 0.5 = 0.7, so (D) is false.
  4. Check. The mean 1.1 lies between 0 and 2, and the variance 0.49 is below 1, which is reasonable for values that are mostly 1 or 2. Option (D) is false because it reads F(1) as P(X = 1) alone, which is 0.5, and forgets the value 0.

Answer: A, B and C

from fractions import Fraction as F
pmf = {0: F(2, 10), 1: F(5, 10), 2: F(3, 10)}
EX = sum(x * p for x, p in pmf.items())
VX = sum(x * x * p for x, p in pmf.items()) - EX ** 2
print("E[X] =", EX, "=", float(EX))
print("Var(X) =", VX, "=", float(VX))
print("P(X at least 1) =", sum(p for x, p in pmf.items() if x >= 1))
print("F(1) =", sum(p for x, p in pmf.items() if x <= 1))
E[X] = 11/10 = 1.1
Var(X) = 49/100 = 0.49
P(X at least 1) = 4/5
F(1) = 7/10

Exam-level 4: Finding a constant, then a mean (NAT, 2 marks)

NAT question. A machine produces a random number X of defective items in each batch. The values 1, 2 and 3 are possible, and P(X = x) is proportional to x squared. That is, P(X = x) = c x² for x = 1, 2 and 3, and P(X = x) = 0 otherwise, where c is a constant. Find the expected number of defective items, E[X]. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. E[X], to two decimal places, when c is not given.
  2. Which idea applies. First find c, because the probabilities must add to 1. Then use E[X] = Σ x P(X = x).
  3. Work it out. The weights are 1, 4 and 9, which add to 14, so c × 14 = 1 and c = 1/14. Then E[X] = (1 × 1 + 2 × 4 + 3 × 9) / 14 = (1 + 8 + 27) / 14 = 36/14 = 18/7, which is about 2.57.
  4. Check. The mean must lie between 1 and 3. It does, and it sits above the midpoint 2, which fits because the weight on 3 is the largest.

Answer: 2.57

from fractions import Fraction as F
w = {x: x * x for x in (1, 2, 3)}
c = F(1, sum(w.values()))
EX = sum(x * c * w[x] for x in w)
print("c =", c)
print("E[X] =", EX)
print("decimal =", round(float(EX), 2))

Summary

Random variable
A rule that turns each outcome of a random experiment into a number.
Discrete random variable
A random variable whose values can be listed one by one.
Support
The set of values x with P(X = x) greater than 0.
PMF
A function giving P(X = x), with every value at least 0 and the total equal to 1.
Expectation
The long-run average, E[X] = Σ x P(X = x).
E[X²]
The expectation of the square of X, Σ x² P(X = x).
Variance
The average squared distance from the mean, Var(X) = E[X²] - (E[X])².
Standard deviation
The square root of the variance, in the same units as X.
Linearity of expectation
E[aX + b] = a E[X] + b.
Variance of a linear change
Var(aX + b) = a² Var(X), so shifts do not change the spread.
CDF
F(x) = P(X ≤ x), the running total of the PMF.
Staircase
The shape of a discrete CDF: it jumps at each value of the support and is flat between them.
Interval probability
P(a < X ≤ b) = F(b) - F(a).
Normalisation
The step of finding an unknown constant so that the PMF sums to 1.

Remember these

  1. A PMF must have every value at least 0 and must add to exactly 1.
  2. E[X] weights each value by its probability, so it is an average, not necessarily a value X can take.
  3. Compute E[X²] by squaring each value before weighting, never by squaring E[X].
  4. Use Var(X) = E[X²] - (E[X])² as the fast route to the variance.
  5. Adding a constant to X shifts the mean but leaves the variance unchanged.
  6. The CDF is the running total of the PMF, and it always finishes at 1.
  7. For discrete variables, check whether an endpoint is included before you subtract CDF values.
