Vector space and subspaces

A vector space is a playground where you can add arrows and stretch them and still stay inside. A subspace is a smaller playground inside a bigger one. Spans, bases and dimension tell you how big a subspace is, and they link directly to rank and the null space in every GATE linear algebra question.

The idea in plain words

Imagine a sheet of paper with an origin marked in the middle. Every arrow starting at the origin is a vector. If you add any two arrows on the sheet, and stretch any arrow, the results stay on the sheet, then the sheet is a vector space. A line through the origin drawn on the sheet is also closed under these moves, so it is a smaller playground inside the bigger one. Such a smaller playground is a subspace.

Every system of equations, every projection, and every rank question in GATE is really about subspaces. The null space and the column space of a matrix are subspaces, and their dimension (the number of independent directions in them) is the rank and the nullity you already met.

Key terms

Vector space
A set of vectors closed under adding and scaling, and containing the zero vector.
Closure
A set is closed under an operation when applying it never takes you out of the set.
Subspace
A subset of a vector space that is itself a vector space.
Linear combination
A sum of scaled vectors, c1v1 + c2v2 + ... .
Span
All linear combinations of a list of vectors.
Linearly independent
Only the all-zero mix of the vectors gives the zero vector. Each vector adds a new direction.
Basis
A list of vectors that is independent and spans the space.
Dimension
The number of vectors in any basis.
Column space, C(A)
The span of the columns of A, or all vectors Ax.
Null space, N(A)
All x with Ax = 0.

Vector spaces: the playground rules, in plain words

A vector space must obey eight rules. The two that matter most are: adding two vectors gives a vector in the set, and scaling a vector gives a vector in the set. The other rules (order-free and grouping-free addition, a zero vector, partners -v, and scaling that respects addition) hold automatically for Rn, because its arithmetic is entry by entry. So Rn is a vector space.

The line y = 2x is a vector space. Take (1, 2) and (3, 6). Their sum (4, 8) has 8 = 2 x 4, so it stays on the line. Scaling (1, 2) by 5 gives (5, 10), which also stays on it.

The first quadrant (all x and y at least 0) is not a vector space. Take (1, 1), which is in it. Then (-1) times (1, 1) = (-1, -1) is not in it.

TrapA line not through the origin fails. For example, y = x + 1 does not contain (0, 0), and every vector space must contain the zero vector.

Is the set of all (x, y) with y = 3x a vector space?

Yes. It is a line through the origin, and sums and multiples of its points stay on it.

Is the set of vectors with x = 1 a vector space?

No. The zero vector has x = 0, so it is missing. Also (1, 0) + (1, 0) = (2, 0) is not in the set.

The subspace test: three checks

To test whether a set S inside Rn is a subspace, check three things:

  1. Contains zero. The zero vector is in S.
  2. Closed under addition. If u and v are in S, then u + v is in S.
  3. Closed under scaling. If v is in S and c is any number, then cv is in S.

Key ideaChecks 2 and 3 combine into one: au + bv must be in S for any u, v in S and any numbers a, b.

Example that passes. Let S = {(x, y, z) : x + y - z = 0}. The zero vector works. If u and v satisfy the equation, so does u + v, because the equation is homogeneous. Similarly, c times a solution is still a solution. So S is a subspace. Every solution set of a homogeneous system Ax = 0 is a subspace.

Example that fails. Let T = {(x, y, z) : x + y - z = 1}. The zero vector gives 0 instead of 1, so it is missing. T is a plane that does not pass through the origin.

GATE loves thisIf a set is defined by equations with zero on the right-hand side, or as a span of vectors, it is a subspace. A non-zero constant on the right, or an inequality, breaks it.

Is {(x, y) : xy = 0} a subspace of R2?

No. (1, 0) and (0, 1) are in it, but their sum (1, 1) has xy = 1, so closure under addition fails.

Is {(a, 2a, 3a) : a real} a subspace?

Yes. It is the span of (1, 2, 3), so it is a line through the origin.

Span: everything you can reach by mixing vectors

The span of a list of vectors is the set of all their linear combinations. The span is always a subspace. For example, span{(1, 0), (0, 1)} is all of R2, since (x, y) = x (1, 0) + y (0, 1). But span{(1, 2), (2, 4)} is only a line. Since (2, 4) = 2 (1, 2), every mix is a multiple of (1, 2), and the span is the line y = 2x.

Now two vectors that point in different directions. The span is the whole plane, so every target can be reached.

Key ideaThe span of vectors is the column space of the matrix that has them as columns. "Span" and "column space" are the same idea in two languages.

Is (3, 4) in span{(1, 1), (1, -1)}?

Yes. a + b = 3 and a - b = 4 give a = 7/2 and b = -1/2, which are real numbers.

What is span{(1, 2, 3), (2, 4, 6)}?

Since (2, 4, 6) = 2 (1, 2, 3), the span is the line of multiples of (1, 2, 3).

Linear independence, basis and dimension

Vectors are linearly independent when only the all-zero mix gives zero: c1v1 + ... + ckvk = 0 forces every ci = 0. For (1, 2) and (3, 1), suppose a (1, 2) + b (3, 1) = (0, 0). Then a + 3b = 0 and 2a + b = 0 give a = b = 0, so they are independent. For (1, 2) and (2, 4), the mix 2 (1, 2) - (2, 4) = 0 is non-trivial, so they are dependent.

A basis is a list that is both independent and spanning. Its size is the dimension. The standard basis (1, 0, 0), (0, 1, 0), (0, 0, 1) shows that R3 has dimension 3. A line through the origin has dimension 1, a plane through the origin has dimension 2, and the zero subspace has dimension 0.

Since the rank of a matrix whose rows are the vectors equals the number of independent vectors, the Python block tests independence with the rank.

from fractions import Fraction as F

def rank(M):
    A = [[F(x) for x in row] for row in M]
    rows, cols = len(A), len(A[0])
    r = 0
    for c in range(cols):
        p = None
        for i in range(r, rows):
            if A[i][c] != 0:
                p = i
                break
        if p is None:
            continue
        A[r], A[p] = A[p], A[r]
        for i in range(rows):
            if i != r and A[i][c] != 0:
                f = A[i][c] / A[r][c]
                A[i] = [A[i][k] - f * A[r][k] for k in range(cols)]
        r += 1
    return r

def show(name, vectors):
    r = rank(vectors)
    print(name, "rank =", r, "independent =", r == len(vectors))

show("(1,2),(2,4):", [[1, 2], [2, 4]])
show("(1,2),(3,1):", [[1, 2], [3, 1]])
show("(1,2,3),(2,4,6),(0,1,1):", [[1, 2, 3], [2, 4, 6], [0, 1, 1]])
print("dimension of the span of (1,2,3),(2,4,6),(0,1,1) =", rank([[1, 2, 3], [2, 4, 6], [0, 1, 1]]))
(1,2),(2,4): rank = 1 independent = False
(1,2),(3,1): rank = 2 independent = True
(1,2,3),(2,4,6),(0,1,1): rank = 2 independent = False
dimension of the span of (1,2,3),(2,4,6),(0,1,1) = 2

TrapDependence is about whether one vector is a mix of the others, not about how many vectors there are. Three vectors in R2 are always dependent, and two vectors can be dependent too.

Is {(1, 0, 0), (0, 1, 0), (1, 1, 0)} a basis of R3?

No. The third vector is the sum of the first two, and every vector has a zero third entry, so the set does not span R3.

What is the dimension of the plane x + y + z = 0 in R3?

Two. The basis (1, 0, -1) and (0, 1, -1) is independent and spans the plane.

The column space and the null space as subspaces

The column space C(A) is the span of the columns of A. Its dimension is the rank. For A = [[1, 0, 1], [0, 1, 1], [1, 1, 2]], the third column is the sum of the first two, so C(A) has basis (1, 0, 1), (0, 1, 1) and dimension 2.

The null space N(A) is the set of all x with Ax = 0. Solve x1 + x3 = 0 and x2 + x3 = 0. With x3 = t, every null vector is t (-1, -1, 1). So N(A) is a line with dimension 1. Check: rank 2 + nullity 1 = 3 columns.

Key ideaThe column space lives in the output space, and the null space lives in the input space. Rank-nullity says their dimensions add up to the number of columns.

Dimension of sums and intersections

For two subspaces V1 and V2, their sum V1 + V2 (all v1 + v2) and their intersection satisfy:

dim(V1 + V2) = dim V1 + dim V2 - dim(V1 and V2)

Example in R3: the planes x3 = 0 and x1 = 0 each have dimension 2. Their intersection is the line along the second axis, dimension 1. Their sum is R3, dimension 3. Check: 3 = 2 + 2 - 1.

TrapThe intersection of subspaces is always a subspace, but the union usually is not. The union of two lines in R2 fails closure under addition.

What are the rank and nullity of A = [[1, 0, 1], [0, 1, 1], [1, 1, 2]]?

Rank 2 and nullity 1, as worked out above.

Two different planes through the origin in R3 meet in what?

A line through the origin, so the intersection has dimension 1. They cannot share a whole plane, since they are different.

Solved GATE-style problems

Problems 3 and 9 are real past questions from GATE papers, rewritten in this format and marked as verified PYQs. The other problems are original GATE-style problems.

Which sets are subspaces of R2? (MSQ)

(A) All (x, y) with y = 3x
(B) All (x, y) with y = 3x + 1
(C) All (x, y) with x at least 0 and y at least 0
(D) All (x, y) with x = 0
Select all sets that are subspaces.

How to think about it

  1. What is asked. Which sets pass the subspace test.
  2. Which idea applies. The set must contain (0, 0) and be closed under sums and scaling.
  3. Work it out. (A) true, a line through the origin. (B) false, since (0, 0) is not in it. (C) false, since (-1)(1, 1) leaves the quadrant. (D) true, a line through the origin.
  4. Check. The two failures are "zero missing" (B) and "scaling leaves the set" (C).

Answer: (A) and (D).

Dimension of a span (NAT)

Find the dimension of the span of (1, 2, 3), (2, 4, 6) and (0, 1, 1). Give a single number.

How to think about it

  1. What is asked. The number of independent directions.
  2. Which idea applies. The dimension of the span is the rank.
  3. Work it out. (2, 4, 6) = 2 (1, 2, 3), so it adds nothing. The other two are not multiples of each other. The dimension is 2.
  4. Check. The Python block above prints rank 2.

Answer: 2.

GATE DA 2024 Q37 (verified PYQ): which sets are subspaces of R3? (MSQ)

Select all choices that are subspaces of R3.

(A) {x = a(1, 1, 0) + b(1, 0, 0) : a, b real}
(B) {x = a2(1, 2, 0) + b2(1, 0, 1) : a, b real}
(C) {x : 5x1 + 2x3 = 0 and 4x1 - 2x2 + 3x3 = 0}
(D) {x : 5x1 + 2x3 + 4 = 0}

How to think about it

  1. What is asked. Which sets pass the subspace test.
  2. Which idea applies. A span is a subspace. Solutions of a homogeneous system are a subspace. Squared coefficients break scaling. A non-zero constant breaks the zero vector.
  3. Work it out. (A) is a span, so true. (B) fails, since -(1, 2, 0) would need a squared number equal to -1. (C) is the null space of a 2 x 3 matrix, so true. (D) fails, since the zero vector gives 4 = 0, which is false.
  4. Check. (C) is a homogeneous solution set, which is the test given above.

Answer: (A) and (C). This is a verified PYQ from GATE DA 2024, Q37, rewritten into the format of this page.

Dimension of a column space (NAT)

Let A = [[1, 0, 1], [0, 1, 1], [1, 1, 2]]. Find the dimension of the column space of A. Give a single number.

How to think about it

  1. What is asked. The dimension of C(A).
  2. Which idea applies. The dimension of the column space is the rank.
  3. Work it out. The third column is the sum of the first two, so the rank is 2.
  4. Check. Row reduction leaves two pivots.

Answer: 2.

Which sets are bases of R2? (MSQ)

(A) {(1, 0), (0, 1)}
(B) {(1, 2), (2, 4)}
(C) {(1, 1), (1, -1)}
(D) {(1, 0), (0, 1), (1, 1)}
Select all sets that are bases of R2.

How to think about it

  1. What is asked. Which lists are both independent and spanning.
  2. Which idea applies. A basis of R2 has exactly 2 independent vectors.
  3. Work it out. (A) is the standard basis, true. (B) fails, since (2, 4) = 2 (1, 2). (C): the determinant of [[1, 1], [1, -1]] is -2, which is not 0, so the vectors are independent, true. (D) has three vectors, so they cannot be independent.
  4. Check. Two independent vectors in R2 always form a basis.

Answer: (A) and (C).

Dimension of a subspace defined by an equation (NAT)

Let W be the set of x in R3 with x1 + x2 + x3 = 0. Find the dimension of W. Give a single number.

How to think about it

  1. What is asked. The dimension of W.
  2. Which idea applies. W is the null space of (1, 1, 1), so its nullity is 3 - 1 = 2.
  3. Work it out. Choose x1 and x2 freely, and x3 = -x1 - x2. Basis: (1, 0, -1) and (0, 1, -1).
  4. Check. W is a plane through the origin, and planes through the origin have dimension 2.

Answer: 2.

Is this set a subspace? (MSQ)

Let S = {(a, b, c) in R3 : a + b = c}. Select all true statements.

(A) S is a subspace of R3
(B) The dimension of S is 2
(C) The vector (1, 1, 2) is in S
(D) S is a line through the origin

How to think about it

  1. What is asked. Test the set and count its dimension.
  2. Which idea applies. S is the solution set of a + b - c = 0, so it is a subspace with two free choices.
  3. Work it out. (A) true. (B) true. (C) true, since 1 + 1 = 2. (D) false, since it is a plane.
  4. Check. A basis is (1, 0, 1) and (0, 1, 1), and both satisfy a + b = c.

Answer: (A), (B) and (C).

Smallest intersection of two subspaces (NAT)

V1 and V2 are 3-dimensional subspaces of R5. Find the smallest possible dimension of V1 and V2 (their intersection). Give a single number.

How to think about it

  1. What is asked. The minimum of dim(V1 and V2).
  2. Which idea applies. dim(V1 + V2) = 6 - dim(intersection), and the sum sits inside R5, so it is at most 5.
  3. Work it out. 6 - dim(intersection) is at most 5, so the intersection is at least 1-dimensional. The value 1 is reached by span{e1, e2, e3} and span{e3, e4, e5}, which share only e3.
  4. Check. The sum is R5, and 3 + 3 - 1 = 5.

Answer: 1.

GATE CSE 2014 Set 3 Q5 (verified PYQ): smallest intersection of 4-dimensional subspaces (NAT)

V1 and V2 are 4-dimensional subspaces of a 6-dimensional vector space V. Find the smallest possible dimension of their intersection. Give a single number.

How to think about it

  1. What is asked. The minimum of dim(V1 and V2).
  2. Which idea applies. 4 + 4 - dim(intersection) = dim(sum), and the sum is at most 6.
  3. Work it out. 8 - dim(intersection) is at most 6, so the intersection is at least 2-dimensional. The value 2 is reached by span{e1, ..., e4} and span{e3, ..., e6}, which share span{e3, e4}.
  4. Check. The sum is R6, and 4 + 4 - 2 = 6.

Answer: 2. This is a verified PYQ from GATE CSE 2014 Set 3, Q5, rewritten into the format of this page.

Exam-level practice

Exam-level 1: Which sets are subspaces (MSQ, 2 marks)

Which are subspaces of R³? (A) {(x, y, z): x + 2y − z = 0} (B) {(x, y, z): x + y + z = 1} (C) {(x, y, z): xy = 0} (D) {(x, y, z): x = 2y and z = 3y}

How to think about it

  1. What is asked. Which sets pass the subspace test.
  2. Which idea applies. A subspace must contain 0 and be closed under addition and scalar multiples. Solution sets of homogeneous linear equations always qualify.
  3. Work it out. (A) Homogeneous plane. True. (B) Does not contain 0. False. (C) (1, 0, 0) and (0, 1, 0) are in it but their sum (1, 1, 0) is not. False. (D) The line through (2, 1, 3). True.
  4. Check. (C) is a union of two planes, and unions are rarely subspaces.

Answer: (A) and (D).

Exam-level 2: Dimension of an intersection (NAT, 2 marks)

U and W are subspaces of R⁶ with dim U = 4 and dim W = 4. If dim(U + W) = 5, find dim(U ∩ W).

How to think about it

  1. What is asked. The dimension of the intersection.
  2. Which idea applies. dim(U + W) = dim U + dim W − dim(U ∩ W).
  3. Work it out. 5 = 4 + 4 − dim(U ∩ W), so dim(U ∩ W) = 3.
  4. Check. The smallest possible intersection here is 4 + 4 − 6 = 2, and 3 is at least that.

Answer: 3.

Exam-level 3: Dimension of symmetric matrices (NAT, 1 mark)

Find the dimension of the vector space of all 4 × 4 real symmetric matrices with trace 0.

How to think about it

  1. What is asked. The dimension of a subspace of matrices.
  2. Which idea applies. Symmetric n × n matrices have n(n + 1)/2 free entries. The trace condition removes one more.
  3. Work it out. 4 · 5/2 = 10, minus 1 for the trace, gives 9.
  4. Check. The code counts free positions on and above the diagonal.
n = 4
print(len([(i, j) for i in range(n) for j in range(i, n)]) - 1)

Summary

Vector space
A set closed under addition and scalar multiplication, containing 0.
Closure
Staying inside the set after an operation.
Subspace
A vector space inside a bigger one. Test: contains 0, closed under combinations.
Span
All linear combinations of a list of vectors. Always a subspace.
Linear combination
A sum of scaled vectors.
Linearly independent
Only the all-zero mix gives 0.
Linearly dependent
Some non-trivial mix gives 0. One vector is redundant.
Basis
Independent and spanning. The minimal building blocks.
Dimension
The number of vectors in any basis.
Column space
The span of the columns of A. Dimension equals the rank.
Null space
All x with Ax = 0. Dimension equals the nullity.
Sum of subspaces
All v1 + v2, with v1 in V1 and v2 in V2.
Dimension formula
dim sum = dim V1 + dim V2 - dim intersection.
Union of subspaces
Usually not a subspace, because closure under addition fails.
Subspace test
Contains zero, and is closed under addition and scaling.
Null vector
A non-zero x with Ax = 0. Its existence means the columns are dependent.

Remember these

  1. Every subspace contains the zero vector. If zero is missing, it is not a subspace.
  2. Solution sets of homogeneous systems are subspaces. Solution sets with a non-zero right-hand side are not.
  3. The span of any list of vectors is a subspace.
  4. A basis is independent and spanning. Its size is the dimension.
  5. The dimension of the column space is the rank, and the dimension of the null space is the nullity.
  6. For two subspaces, dim sum = dim V1 + dim V2 - dim intersection. Use it to bound the intersection.
