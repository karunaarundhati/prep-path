Automated material handling & storage/retrieval systems

Once parts are made, they must be moved and stored. Automated material handling systems (AMHS) move parts between machines, and automated storage and retrieval systems (AS/RS) store and fetch them from tall racks without people walking the aisles. GATE asks about the parts of these systems and how to size them with simple calculations.

The idea in plain words

Think about a busy kitchen. Ingredients come from the fridge, go to the chopping board, then to the pan, and finally to the plate. Someone has to move each item, and someone has to find it in the fridge. If the kitchen is big, walking takes a lot of time. A kitchen with a conveyor belt and a tall shelf system, where a machine fetches each box, would save time and mistakes.

A factory has the same problem with parts. Each part must go from one machine to the next, and raw material must be stored until it is needed. Material handling is the job of moving, holding, and storing materials. When it is done by machines with control systems, it is automated material handling.

The two main groups are:

  • Automated material handling systems (AMHS), which move parts between stations. Examples are conveyors, automated guided vehicles, and robot transfer units.
  • Automated storage and retrieval systems (AS/RS), which store parts in racks and fetch them automatically. A machine called a storage and retrieval machine does the work.

Automation saves labour, reduces the time to find a part, and reduces errors, such as taking the wrong item. It also uses space well, because racks can be taller than a person can reach.

Key ideaAMHS moves parts from place to place. AS/RS stores parts in dense racks and retrieves them on demand. Both are linked to the factory computer, which decides what moves where.

Where this appears in GATE

In the RA paper, questions in this area are mostly conceptual. You may be asked which system suits a warehouse, what a rack or an AGV is for, or what benefits CIM integration brings. Some questions ask for a simple calculation, such as conveyor throughput, the number of storage locations, the time for a crane move, or the number of vehicles needed. This page covers both.

Key terms

Read these now. Each one is used again below.

Material handling
Moving, holding, and storing materials in a plant. Precise definition: the set of activities that move, store, control, and protect materials during production.
AMHS
Automated material handling system. Precise definition: a system of machines, controls, and transport devices that move materials automatically between stations.
Conveyor
A moving belt, roller, or chain that carries items. Precise definition: a fixed transport device that moves loads along a path at a set speed.
Throughput
The number of items moved per unit time. Precise definition: the rate at which items pass a point, equal to speed divided by the spacing between items.
AGV
Automated guided vehicle. Precise definition: a driverless vehicle that moves along a route using guidance such as wire, magnetic tape, or laser.
Robotic transfer
A robot that moves parts from one place to another. Precise definition: a robot arm used as a transport device between stations or between a conveyor and a machine.
AS/RS
Automated storage and retrieval system. Precise definition: a system of racks and automatic machines that store and retrieve loads without manual handling.
Rack
A tall steel frame with storage locations. Precise definition: a structure of uprights and beams that forms storage locations, each with a unique address.
Storage location (bin)
One space in a rack that holds one unit load. Precise definition: a single addressable place in a rack, usually identified by aisle, bay, and level.
Aisle
The narrow passage between two rows of racks. Precise definition: a path along which the storage and retrieval machine travels.
Storage and retrieval (S/R) machine
A crane that runs in an aisle and places or takes loads. Precise definition: a machine that moves horizontally and vertically along an aisle to store a load in, or retrieve a load from, a rack location.
Unit load
One load, such as a pallet or a tote. Precise definition: a single package or pallet of goods handled as one item.
Pick-up and deposit (P/D) station
The point where loads enter or leave the AS/RS. Precise definition: a fixed location at the end of an aisle where the S/R machine picks or deposits a unit load.
Warehouse management system (WMS)
Software that keeps track of what is stored where. Precise definition: a computer system that records stock locations and sends move orders to the automatic equipment.
Simultaneous motion
Two axes moving at the same time. Precise definition: a motion in which the horizontal and vertical axes of a crane move together, so the total time is set by the slower axis.
Utilisation
The fraction of time a machine is busy. Precise definition: busy time divided by available time, written as a number between 0 and 1.

Automated material handling systems (AMHS)

An AMHS moves parts between the stations of a plant. The choice depends on the distance, the load, how often the route changes, and how many stations must be served. The four main types are:

  • Conveyors: fixed routes with belts, rollers, or chains. They are fast and cheap per metre, but the route is hard to change.
  • Automated guided vehicles (AGVs): driverless vehicles that carry loads along routes that can be changed in software or with markers. They are flexible, but they need space and guidance.
  • Robotic transfer: a robot picks a part from one station and places it at the next. This is good when the parts are small and the handoff must be precise.
  • Overhead hoists: carriers that hang from a rail on the ceiling, which frees the floor for machines and people.

Here is a simple text diagram of a plant layout that uses a conveyor loop and an AGV.

  [ Machine 1 ]-------->[ Machine 2 ]-------->[ Machine 3 ]
       ^                                          |
       |                                          v
       |                                    [ Inspection ]
       |                                          |
       +---------- conveyor loop -----------------+

  AGV route:  Store  ---->  Machine 2 ----> Dock

Read the diagram. Parts move along the top conveyor from left to right, then return on the loop. An AGV runs a separate route between the store, Machine 2, and the dock, carrying loads that the conveyor does not serve.

TipAsk two questions to pick an AMHS: "does the route change often?" and "is the distance long?". A fixed, long, high-volume route suits a conveyor. A changing route suits AGVs.

Question: Which AMHS suits a fixed route with a high flow of parts?

A conveyor, because it is fast and cheap for a route that does not change.

Question: Name two main advantages of AGVs over conveyors.

Routes can be changed without rebuilding the floor, and the vehicles can serve many stations on one flexible network.

Conveyors and throughput

A conveyor's job is to move a steady flow of loads. The important number is the throughput: how many loads pass a point each minute or each hour. Loads on a conveyor are spaced out, and the spacing matters.

Picture a belt moving past you. Carriers are placed on it at regular gaps. If the belt moves at speed v, and the gap between carriers is s, then one carrier passes you every s / v seconds. So the number of carriers per second is:

throughput = v / s

Here v is the belt speed in metres per second, s is the spacing between carriers in metres, and the throughput is in carriers per second. Multiply by 60 to get carriers per minute.

Worked example. A conveyor moves at 0.4 m/s. The carriers are spaced 1.6 m apart. Find the throughput in carriers per minute.

  1. Per second. 0.4 / 1.6 = 0.25 carriers per second.
  2. Per minute. 0.25 × 60 = 15 carriers per minute.
  3. Check. Every 4 seconds a carrier passes, because the belt moves 1.6 m in 4 s at 0.4 m/s. In one minute there are 60 / 4 = 15 carriers, which matches.
speed = 0.4
spacing = 1.6
per_s = speed / spacing
print("Carriers per second:", round(per_s, 2))
print("Carriers per minute:", round(per_s * 60, 1))
Carriers per second: 0.25
Carriers per minute: 15.0

TrapSpacing is the gap from one carrier to the next, measured along the belt. Students sometimes use the carrier length, which gives the wrong answer.

Key ideaFaster belts or closer spacing give more throughput. Throughput is limited by the slowest station that receives the loads.

Question: A belt moves at 2 m/s with carriers 4 m apart. How many carriers pass per minute?

2 / 4 = 0.5 carriers per second, so 0.5 × 60 = 30 carriers per minute.

Question: If the spacing doubles and the speed stays the same, what happens to throughput?

It halves, because throughput = v / s.

Automated guided vehicles (AGVs)

An AGV is a driverless vehicle that carries loads along a route. It has motors, batteries, sensors, and a controller. Most AGVs run on a fixed network, and a central computer assigns the next job to each vehicle.

AGVs are guided in several ways:

  • Wire guidance: a cable buried in the floor carries a signal, and the vehicle senses it and follows it.
  • Magnetic tape or markers: the vehicle reads a magnetic strip or marker on the floor.
  • Laser guidance: the vehicle measures its position from reflectors on the walls.
  • Natural navigation: the vehicle uses a camera or laser scanner to match the surroundings, with no markers added.

AGVs are good for medium distances and changing routes. They are slower than a conveyor, and each vehicle must be charged. The number of vehicles needed depends on the number of trips and the time for each trip.

How many AGVs?

Suppose a plant must make 60 trips an hour, and each round trip takes 6 minutes. The total work is:

vehicle-hours per hour = trips per hour × round trip time (h)

Here the round trip time is in hours, so 6 minutes is 6 / 60 = 0.1 h. The number of vehicles is then the work divided by the utilisation, which is the fraction of time each vehicle is busy:

N = (trips per hour × round trip time) / utilisation
  1. Work per hour. 60 trips × 6 min = 360 vehicle-minutes = 6 vehicle-hours.
  2. Divide by utilisation. If each vehicle is busy only 80 percent of the time, then N = 6 / 0.8 = 7.5.
  3. Round up. A vehicle cannot be a fraction, so 8 AGVs are needed.
import math
trips_per_hour = 60
round_trip_min = 6
utilization = 0.8
vehicle_hours_needed = trips_per_hour * round_trip_min / 60
raw = vehicle_hours_needed / utilization
print("Vehicle-hours needed per hour:", vehicle_hours_needed)
print("Raw number of AGVs:", round(raw, 2))
print("AGVs to buy:", math.ceil(raw))
Vehicle-hours needed per hour: 6.0
Raw number of AGVs: 7.5
AGVs to buy: 8

TrapAlways round the number of vehicles up, not to the nearest whole number. Rounding 7.5 down to 7 would leave some trips unserved.

Question: What is wire guidance?

A cable buried in the floor carries a signal, and the AGV senses it and follows the route above it.

Question: Why does lower utilisation need more AGVs?

Each vehicle is free for part of the time, so more vehicles are needed to cover the same work. N = work / utilisation, and a smaller utilisation makes N larger.

Automated storage and retrieval systems (AS/RS)

An AS/RS stores unit loads in tall racks, and a machine places and retrieves them. A typical system has four parts:

  1. The rack structure. Steel uprights and beams form rows, levels, and bays. Each storage location has a unique address, such as aisle 3, bay 12, level 4.
  2. The storage and retrieval (S/R) machine. A crane runs along an aisle on rails. It moves horizontally and vertically, and it carries a fork or platform that handles the load.
  3. The pick-up and deposit (P/D) stations. These are fixed points at the end of each aisle where loads enter and leave.
  4. The control system. A warehouse management system (WMS) records where each load is and sends move orders to the S/R machine.

Here is a side view of one aisle, with two racks and an S/R machine.

      level 3 | [ ][ ][ ][ ][ ]|        |[ ][ ][ ][ ][ ]
      level 2 | [ ][ ][ ][ ][ ]|  aisle  |[ ][ ][ ][ ][ ]
      level 1 | [ ][ ][ ][ ][ ]| ==[S/R]== |[ ][ ][ ][ ][ ]
      P/D     |_______________|________|______________|
                                 ^ P/D station at aisle end

Read the picture as a cross-section of one aisle. Two racks face each other across the aisle. The S/R machine runs in the aisle and reaches any level in either rack. Each small box is one storage location, and the P/D station at the bottom is where loads enter or leave.

Benefits

  • High density: racks can be tall, so a small floor area holds many loads.
  • Speed and accuracy: the machine finds the location from the WMS record, without search.
  • Lower labour: fewer people are needed to walk the aisles.
  • Better control: stock records are kept in one system, so the stock is easy to check.

GATE loves thisAS/RS benefits are usually listed as reduced labour, higher speed, higher space use, and accurate stock records. The machine itself does not add value, it only moves loads.

Question: What is the job of the S/R machine?

To run along an aisle and place a unit load into a rack location, or take it out and bring it to the P/D station.

Question: Why is the WMS important in an AS/RS?

It knows where each load is stored, and it tells the S/R machine which location to visit. Without it, the machine could not find loads automatically.

Sizing a store and a crane

How many locations?

The number of storage locations is the product of the number of bays, the number of levels, the depth (how many loads sit one behind another), and the number of sides (how many racks face the aisle):

locations = bays × levels × depth × sides

Worked example. A rack has 25 bays, 6 levels, 2 loads deep, and there are 2 sides to each aisle. The number of locations is 25 × 6 × 2 × 2 = 600. The Python check below does the same arithmetic.

bays = 25
levels = 6
depth = 2
sides = 2
print("Storage locations:", bays * levels * depth * sides)
Storage locations: 600

How long does one crane move take?

The S/R machine moves horizontally and vertically at the same time. Because the two axes run together, the time for the motion is set by the slower axis. We use this rule:

tmove = max(dx / vx, dy / vy)

Here dx and dy are the horizontal and vertical distances, and vx and vy are the speeds on each axis. The total cycle adds the time to pick up and deposit the load, which we call tpd.

Worked example. The S/R machine must travel 36 m horizontally at 3 m/s, and 9 m vertically at 1.5 m/s. Picking and depositing takes 8 s.

  1. Horizontal time. 36 / 3 = 12 s.
  2. Vertical time. 9 / 1.5 = 6 s.
  3. Move time. Both axes run at once, so the move takes max(12, 6) = 12 s.
  4. Cycle time. 12 + 8 = 20 s.
dx, vx = 36.0, 3.0
dy, vy = 9.0, 1.5
pick_drop = 8.0
tx = dx / vx
ty = dy / vy
move = max(tx, ty)
print("Horizontal time (s):", round(tx, 1))
print("Vertical time (s):", round(ty, 1))
print("Cycle time (s):", round(move + pick_drop, 1))
Horizontal time (s): 12.0
Vertical time (s): 6.0
Cycle time (s): 20.0

TrapAdding the horizontal and vertical times gives 18 s, which is wrong when the axes move together. Use the larger time for the move, then add the pick and deposit time.

How many cranes?

One crane completes 3600 / (cycle time in seconds) moves per hour. If the plant needs a certain number of moves per hour, the number of cranes is that demand divided by one crane's capacity, rounded up.

Question: A rack has 10 bays, 4 levels, 1 deep, and 2 sides. How many locations?

10 × 4 × 1 × 2 = 80 locations.

Question: In the crane example, why is the horizontal time not added to the vertical time?

Because the two axes move at the same time. The move ends when the slower axis finishes, so the move time is the larger of the two times.

Solved GATE-style problems

These are original GATE-style practice problems, not real past exam questions. Try each one before reading the method.

Purpose of an AS/RS

What is the main purpose of an automated storage and retrieval system?

(A) To make parts on a machine   (B) To store unit loads densely and fetch them automatically   (C) To paint parts   (D) To weld two plates together

How to think about it

  1. What is asked. The main job of an AS/RS.
  2. Which idea applies. An AS/RS stores unit loads in racks, and a machine retrieves them.
  3. Work it out. Option (B) describes storage and retrieval. The other options describe processing tasks.
  4. Check. The name itself, storage and retrieval, points to option (B).

Answer: (B).

Which part moves along the aisle?

In an AS/RS, which component runs along the aisle and moves loads into and out of rack locations?

(A) The rack upright   (B) The storage and retrieval machine   (C) The warehouse management system   (D) The pick-up and deposit station

How to think about it

  1. What is asked. The moving component in the aisle.
  2. Which idea applies. The S/R machine is the crane that runs in the aisle.
  3. Work it out. Uprights are fixed. The WMS is software. The P/D station is a fixed point at the aisle end. Only the S/R machine moves along the aisle.
  4. Check. Option (B) is the only moving machine in the list.

Answer: (B).

Conveyor spacing and throughput

A conveyor runs at 0.6 m/s with carriers spaced 2.4 m apart. Find the throughput in carriers per minute.

How to think about it

  1. What is asked. Carriers per minute.
  2. Which idea applies. Throughput = v / s, then multiply by 60.
  3. Work it out. 0.6 / 2.4 = 0.25 carriers per second. 0.25 × 60 = 15 carriers per minute.
  4. Check. One carrier passes every 4 s (2.4 m at 0.6 m/s). In 60 s there are 15 passes.

Answer: 15 carriers per minute.

Statements about AMHS and AS/RS (select all that apply)

Select all the statements that are correct.

(A) A conveyor is the most flexible choice when the route changes often.   (B) An AGV can carry loads on a route that is changed in software.   (C) An AS/RS uses racks that can be taller than a person can reach.   (D) The WMS moves the loads along the aisle.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. Conveyors are fixed. AGV routes can change. AS/RS racks are tall. The WMS is software, not a moving machine.
  3. Work it out. (A) False, conveyors are the least flexible route. (B) True. (C) True. (D) False, the S/R machine moves the loads.
  4. Check. The two false statements mix up flexibility and movement, which is the trap here.

Answer: (B) and (C).

How many storage locations?

A rack has 30 bays, 5 levels, 2 loads deep, and is served from aisles with racks on both sides. Each side has 1 rack face per aisle. Find the total number of storage locations on both sides of one aisle.

How to think about it

  1. What is asked. The total number of locations on both sides of one aisle.
  2. Which idea applies. locations = bays × levels × depth × sides, with sides = 2 for both faces.
  3. Work it out. 30 × 5 × 2 × 2 = 600.
  4. Check. One side gives 30 × 5 × 2 = 300, and two sides double that to 600.

Answer: 600 locations.

Crane cycle time

An S/R machine moves 48 m horizontally at 4 m/s and 12 m vertically at 2 m/s, with both axes moving at the same time. Pick and deposit takes 10 s. Find the cycle time in seconds.

How to think about it

  1. What is asked. The total cycle time.
  2. Which idea applies. Move time = max of the two axis times. Cycle = move + pick and deposit.
  3. Work it out. Horizontal = 48 / 4 = 12 s. Vertical = 12 / 2 = 6 s. Move = max(12, 6) = 12 s. Cycle = 12 + 10 = 22 s.
  4. Check. The vertical axis finishes early, so the horizontal axis sets the move time. The answer is 22 s.
dx, vx = 48.0, 4.0
dy, vy = 12.0, 2.0
pick_drop = 10.0
move = max(dx / vx, dy / vy)
print("Move time (s):", round(move, 1))
print("Cycle time (s):", round(move + pick_drop, 1))
Move time (s): 12.0
Cycle time (s): 22.0

Answer: 22 s.

How many AGVs for a changed plan?

A plant must make 90 AGV trips an hour. Each round trip takes 4 minutes. Each vehicle is busy 75 percent of the time. Find the smallest whole number of AGVs needed.

How to think about it

  1. What is asked. The smallest whole number of vehicles.
  2. Which idea applies. N = (trips per hour × round trip time in hours) / utilisation, then round up.
  3. Work it out. 4 min = 4 / 60 h. Work = 90 × 4 / 60 = 6 vehicle-hours per hour. N = 6 / 0.75 = 8.0. The smallest whole number is 8.
  4. Check. 8 vehicles at 75 percent give 6 busy vehicle-hours per hour, which matches the work exactly.

Answer: 8 AGVs.

How many cranes? (numerical answer)

The plant needs 600 crane moves per hour. Each crane has a cycle time of 20 s. Ignore utilisation. Find the smallest whole number of cranes needed.

How to think about it

  1. What is asked. The smallest whole number of cranes.
  2. Which idea applies. One crane gives 3600 / cycle moves per hour. Cranes = demand / capacity, rounded up.
  3. Work it out. Capacity = 3600 / 20 = 180 moves per hour. Cranes = 600 / 180 = 3.33, which rounds up to 4.
  4. Check. Three cranes give 540 moves per hour, which is not enough. Four give 720, which is enough.
import math
moves_per_hour = 600
cycle_s = 20
capacity = 3600 / cycle_s
cranes = moves_per_hour / capacity
print("One crane capacity (moves/hour):", capacity)
print("Cranes needed (exact):", round(cranes, 2))
print("Cranes to install:", math.ceil(cranes))
One crane capacity (moves/hour): 180.0
Cranes needed (exact): 3.33
Cranes to install: 4

Answer: 4 cranes.

Exam-level practice

Exam-level 1: Conveyor throughput (NAT, 2 marks)

A conveyor moves at 0.5 m/s, with parts spaced 1.25 m apart. Find the delivery rate in parts per minute.

How to think about it

  1. What is asked. Flow rate.
  2. Which idea applies. Rate = speed/spacing.
  3. Work it out. 0.4 parts/s = 24 parts/min.
  4. Check. Halving the spacing doubles the rate.

Answer: 24 parts/min.

Exam-level 2: AS/RS cycle time (NAT, 2 marks)

An AS/RS crane moves horizontally at 2 m/s and vertically at 0.5 m/s at the same time. A rack bay is 40 m long and 10 m high. Find the time to reach the far top corner from the origin.

How to think about it

  1. What is asked. Travel time with simultaneous motion.
  2. Which idea applies. Time = max(x/vx, y/vy).
  3. Work it out. max(20, 20) = 20 s.
  4. Check. This rack is square in time, the ideal design.

Answer: 20 s.

Exam-level 3: AGV fleet size (NAT, 2 marks)

A plant needs 40 deliveries per hour. Each AGV delivery cycle takes 6 min, and AGVs are available 90% of the time. How many AGVs are needed?

How to think about it

  1. What is asked. The fleet size, rounded up.
  2. Which idea applies. Each AGV does 60/6 · 0.9 = 9 deliveries per hour.
  3. Work it out. 40/9 = 4.44, so 5 AGVs.
  4. Check. 4 AGVs give only 36 per hour.

Answer: 5.
