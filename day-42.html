Week 1 recap: Python, C, OOP and Java

Work through these questions aloud before reading the answers. If you cannot answer one in two sentences, go back to the matching day page and rewrite the answer in your own words.

Python

What is the mutable default argument pitfall, and how do you fix it?

A default value in a function signature is created once, when the function is defined. For example, def add(item, bucket=[]) shares one list across all calls that do not pass a bucket. The fix is bucket=None, then create a new list inside the function when the argument is None.

What does LEGB mean?

It is the order in which Python looks up a name: Local (inside the current function), Enclosing (in outer functions, which matters for closures), Global (the module), and Built-in (names such as len). The first match wins.

Why is membership testing faster in a set than in a list?

A set is a hash table, so checking membership takes O(1) on average. A list is scanned from the start, which takes O(n) in the worst case. Dictionaries use the same hashing for key lookup.

What is the difference between a shallow copy and a deep copy?

A shallow copy (copy.copy) creates a new outer container, but the nested objects are shared with the original. A deep copy (copy.deepcopy) copies nested objects too, so the two structures are fully independent.

C

What is a dangling pointer, and why is it dangerous?

A dangling pointer still holds the address of memory that has been freed. Reading or writing through it is undefined behaviour: it may appear to work, crash, or silently corrupt other data. Set pointers to NULL after freeing them.

How do malloc, calloc and realloc differ?

malloc(n) returns uninitialised memory. calloc(count, size) returns memory set to zero. realloc(p, n) resizes a block and may move it, so the old pointer becomes invalid. Assign the result to a temporary pointer and check it for NULL before replacing the original.

Why does a function that receives an array parameter see only a pointer?

In a parameter list, int a[] is adjusted to int *a. The array decays to a pointer to its first element, so sizeof(a) inside the function gives the size of a pointer, not of the array. Pass the length as a separate argument.

What is struct padding?

The compiler inserts unused bytes between or after struct members so each member starts at an address that suits its type. Ordering members from largest to smallest often reduces the total size. The exact size is compiler and platform specific, so check it with sizeof.

Java

What is the difference between == and equals for strings?

== compares references: whether two variables point to the same object. equals compares content. Strings are immutable, so any change creates a new object, and loops that concatenate with + create many objects. StringBuilder changes one buffer in place.

Why must you override hashCode when you override equals?

A HashMap finds a key by its hash code first, then by equals. If two equal objects have different hash codes, they can land in different buckets, and get will fail to find the one you stored. Equal objects must always return equal hash codes.

What is the difference between overloading and overriding?

Overloading means several methods in one class share a name but take different parameters, and the compiler chooses by the arguments (compile time). Overriding means a subclass provides its own version of a method with the same signature, and the object's actual class decides at run time. In C++, virtual functions use a vtable for this run-time choice.

Week 2 recap: architecture, OS, concurrency and containers

Computer organisation

What is the average memory access time formula, and what does it give you?

AMAT = hit time + miss rate times miss penalty. For a 1 ns hit time, 5 percent miss rate and 100 ns miss penalty, AMAT is 1 + 0.05 times 100 = 6 ns. It tells you how much the cache helps on average.

Name the three kinds of pipeline hazard and one fix for each.

A structural hazard is two instructions needing the same hardware (fix: duplicate units). A data hazard is an instruction needing a result not yet produced (fix: forwarding, or a stall). A control hazard is a branch whose target is unknown (fix: branch prediction, or flushing the wrong-path instructions).

Operating systems

What is the difference between a zombie and an orphan process?

A zombie is a child that has terminated while its parent has not yet called wait, so its exit status is still held in the process table. An orphan is a child whose parent has terminated first; the system adopts it, and the init process becomes its parent.

What do fork and exec do?

fork creates a child that is a copy of the calling process, and both continue from the same point, distinguished by the return value. exec replaces the current program image with a new program, keeping the process ID. Shells usually call fork and then exec.

Which scheduling algorithm can starve a process, and which one prevents it?

Priority scheduling and shortest job first can starve long or low-priority processes. Round robin gives each ready process a time slice, so no process waits forever, but a very large quantum behaves like FCFS and a very small one adds overhead from context switches.

What is the difference between a mutex and a semaphore?

A mutex is a lock with ownership: only the thread that locked it can unlock it, and it protects one critical section. A semaphore is a counter with wait and signal operations, and any thread can signal it. A binary semaphore can look like a mutex but has no ownership.

List the four Coffman conditions for deadlock.

Mutual exclusion (a resource is held exclusively), hold and wait (a process holds one resource while waiting for another), no preemption (resources cannot be forcibly taken), and circular wait (a cycle of processes each waiting for the next). All four must hold. Prevention breaks one of them; the Banker's algorithm avoids unsafe states.

What are the three semaphores in the classic bounded-buffer producer-consumer solution?

A mutex (or binary semaphore) protects the buffer. An empty semaphore counts free slots, initialised to the buffer size, and the producer waits on it. A full semaphore counts filled slots, initialised to zero, and the consumer waits on it.

How does page replacement with LRU differ from FIFO?

FIFO evicts the page loaded earliest, regardless of use. LRU evicts the page used least recently. FIFO can suffer Belady's anomaly, where more frames cause more faults. LRU is a stack algorithm and does not show this anomaly.

Containers and orchestration

What is the difference between a Docker image and a container?

An image is a read-only template built from layers, each created by a Dockerfile instruction. A container is a running instance of an image with a thin writable layer on top. Many containers can start from one image.

What is the difference between a Kubernetes pod, deployment and service?

A pod is the smallest deployable unit, usually one container. A deployment keeps a desired number of identical pods running and performs rolling updates. A service gives a stable name and virtual IP that load-balances across the matching pods, even as pods are replaced.

How do containers differ from virtual machines?

A virtual machine runs its own guest kernel on a hypervisor. Containers share the host kernel and use namespaces to isolate what a process can see and cgroups to limit what it can use. Containers start faster and are lighter, but share the kernel's attack surface.

Week 3 recap: networks, security, databases and NoSQL

Networks and APIs

When would you choose UDP over TCP?

When low latency matters more than guaranteed, ordered delivery, such as live video, voice calls, games and DNS queries. TCP provides reliability, ordering and congestion control, at the cost of handshakes and retransmission delay.

Describe the TCP three-way handshake.

The client sends SYN, the server replies SYN-ACK, and the client answers with ACK. After this, both sides can send data. The handshake costs one round trip before the first request can be sent over TCP.

Which HTTP methods are idempotent, and why does it matter?

GET, PUT and DELETE are idempotent: repeating the request leaves the server in the same state. POST is not. Idempotency matters because clients retry failed requests, and a retried POST can create duplicate orders unless the server uses an idempotency key.

What is the difference between 401 and 403?

401 Unauthorized means the request lacks valid authentication, so the client should log in. 403 Forbidden means the server knows who the caller is but the caller may not perform this action.

Security

How do you prevent SQL injection?

Use parameterised queries or prepared statements, so user input is sent as data and never concatenated into the SQL text. Validation helps but is not enough on its own. Limit database account privileges as a second layer.

What is the difference between JWT and OAuth 2.0?

A JWT is a signed token that carries claims; it is signed, not encrypted, so it must not hold secrets. OAuth 2.0 is a framework for delegated authorisation, letting an app act on a user's behalf with a limited token. OpenID Connect adds identity on top of OAuth 2.0.

Relational databases

Explain 1NF, 2NF, 3NF and BCNF in one line each.

1NF: every column holds atomic values. 2NF: no non-key column depends on part of a composite key. 3NF: no non-key column depends on another non-key column (no transitive dependency). BCNF: every determinant is a superkey, which is slightly stricter than 3NF.

Which anomaly does each isolation level prevent?

Read uncommitted allows dirty reads (reading uncommitted data). Read committed prevents dirty reads. Repeatable read prevents non-repeatable reads (a row changing between two reads in one transaction). Serializable prevents all of these, including phantom reads (new rows appearing in a repeated query).

What does WAL do, and why does it matter for recovery?

Write-ahead logging writes each change to a log on disk before the data page is changed. After a crash, the database replays committed changes from the log and undoes uncommitted ones, which gives durability and atomicity.

Why can NOT IN return no rows when the list contains NULL?

x NOT IN (1, NULL) means x != 1 AND x != NULL. Comparing with NULL gives unknown, not true, so the whole condition is never true. Use NOT EXISTS, or filter NULLs out of the subquery.

What is the difference between WHERE and HAVING?

WHERE filters individual rows before grouping. HAVING filters groups after aggregation, so it can use functions such as COUNT or SUM.

NoSQL

What does the CAP theorem say, and what does BASE mean?

CAP says that during a network partition, a distributed system must choose between consistency and availability. BASE stands for Basically Available, Soft state, Eventually consistent, a looser model that many NoSQL systems use in exchange for availability and scale.

Name the main NoSQL data models and a typical use for each.

Key-value (cache, sessions), document (flexible JSON-like records), column-family (wide, time-ordered data), graph (relationships), and vector (similarity search over embeddings). Choose by access pattern, not by popularity.

Week 4 recap: backend, Git, testing, AWS and system design basics

Backend

How should a backend store user passwords?

Never store plain text or reversible encryption. Store a salted hash made with a slow, purpose-built algorithm such as bcrypt or argon2. The salt is unique per user, so identical passwords produce different hashes.

What is the N+1 problem?

Loading a list of N parent rows and then running one query per row for a related value, for N+1 queries in total. Fix it by joining the tables or by batch loading the related rows in one query, such as Django's select_related or prefetch_related.

When should you use a refresh token?

When access tokens are short-lived for security, but users should not log in again every few minutes. The client exchanges a long-lived refresh token for a new access token. Refresh tokens must be stored safely and revocable.

What is the difference between a retry and an idempotency key?

A retry sends the same request again after a failure or timeout. An idempotency key is a client-generated identifier sent with the request, so the server can recognise a repeated attempt and return the original result instead of doing the work twice.

Git and testing

What is the difference between merge and rebase?

Merge joins two histories with a merge commit and keeps both branches' history as it happened. Rebase replays your commits on top of another base, producing a linear history but new commit IDs. Do not rebase commits that others have already pulled.

What is the difference between git reset and git revert?

Reset moves the branch pointer to an earlier commit, rewriting local history, and is unsafe on shared branches. Revert creates a new commit that undoes an earlier one, which is safe to push to shared branches.

Describe the test pyramid.

Many fast unit tests at the base test single functions or classes. Fewer integration tests check components working together, such as a service and its database. A few end-to-end tests drive the whole system through the user interface, which are slow and brittle.

When do you use a mock?

When the code under test depends on something slow, external or nondeterministic, such as a network call or the clock. A mock replaces that dependency with a controllable stand-in, so the test checks your logic and the calls made to the dependency.

AWS and scalability

What is the difference between a security group and a network ACL?

Security groups are stateful and attach to instances: return traffic for an allowed request is automatically allowed. Network ACLs are stateless and attach to subnets, so both directions of traffic need explicit rules.

Why should a service use an IAM role instead of access keys?

A role provides temporary credentials that AWS rotates automatically, so no long-lived secret is stored on the server. Access is also easier to audit and limit with least-privilege policies.

How much downtime per year does 99.9 percent availability allow?

0.1 percent of the 8,760 hours in a year is 8.76 hours. Each extra nine divides the allowed downtime by ten: 99.99 percent allows about 52.6 minutes per year.

What does consistent hashing achieve?

When a node is added or removed, only about 1/N of the keys move to a different node, where N is the number of nodes. Simple modulo hashing would move almost all keys. Virtual nodes spread the load more evenly.

Compare token bucket with fixed window rate limiting.

A token bucket refills tokens at a steady rate up to a capacity, so it allows short bursts while keeping the average rate. A fixed window counts requests in each time window, but a burst at the window boundary can let through about twice the limit.

Week 5 recap: distributed systems, design, web, JavaScript and React

Distributed systems

What can a vector clock tell you that a Lamport clock cannot?

A Lamport clock gives a single counter that respects causal order (if A happened before B, A's timestamp is smaller), but it cannot tell whether two events are concurrent. A vector clock keeps one counter per process, so it can show that two events are concurrent.

What does R + W > N guarantee in a quorum system?

With N replicas, a write acknowledged by W replicas and a read from R replicas must overlap in at least one replica. That replica holds the latest acknowledged write, so the read can see it. The guarantee concerns overlap, not strict linearizability in every failure case.

How does Raft elect a leader?

Followers wait for heartbeats from a leader. If one times out, it becomes a candidate for a new term and asks for votes. A candidate wins with a majority, which prevents two leaders in the same term. Logs are replicated from the leader, and an entry is committed once a majority stores it.

Compare two-phase commit with the saga pattern.

Two-phase commit coordinates a prepare and commit across services and holds locks until the decision, so it blocks if the coordinator fails. A saga runs a sequence of local transactions, each with a compensating action to undo it if a later step fails, trading strict atomicity for availability.

How do you achieve effectively exactly-once processing?

Use at-least-once delivery and make the consumer idempotent. Record each event's unique ID with its effect in one transaction, and skip events already recorded. Exactly-once delivery across arbitrary systems is not generally achievable.

What do retries with exponential backoff and jitter prevent?

They stop many clients from retrying at the same moment, which would overload a recovering service. Each retry waits longer than the last, and random jitter spreads the attempts. A circuit breaker stops calls entirely while a dependency is failing, and half-open state tests recovery.

System and low-level design

What is the first thing to do in a high-level design interview?

Clarify functional and non-functional requirements, then estimate scale (users, requests per second, storage) with stated assumptions. The estimates decide whether a single server, a cache, or sharding is needed.

How would a URL shortener generate short codes?

One approach gives each new URL a unique numeric ID from a counter or ID service, then encodes it in base 62 (digits plus upper and lower case letters). Seven base-62 characters cover more than 3.5 trillion IDs. Redirects are served from a cache, and the database stores the mapping.

What is the difference between the State pattern and the Strategy pattern?

In the State pattern, an object changes its behaviour as its internal state changes, and the states usually switch themselves (for example a vending machine). In the Strategy pattern, the client chooses an interchangeable algorithm object, and the choice does not change during the object's life.

Web and JavaScript

What is the difference between reflow and repaint?

Reflow recalculates the size and position of elements, which is expensive and affects layout of neighbours. Repaint redraws visual properties such as colour without changing layout. Changes that affect geometry cause a reflow, and a reflow always leads to a repaint.

Predict the output order: console.log(1), setTimeout(() => console.log(2)), Promise.resolve().then(() => console.log(3)), console.log(4).

The output is 1, 4, 3, 2. Synchronous code runs first. Promise callbacks are microtasks, which run before the next macrotask. The setTimeout callback is a macrotask, so it runs last.

What do the cookie flags HttpOnly, Secure and SameSite do?

HttpOnly hides the cookie from JavaScript, which limits theft through XSS. Secure sends the cookie only over HTTPS. SameSite controls whether the browser sends the cookie on cross-site requests, which reduces CSRF risk.

When is a CORS preflight request sent?

When a cross-origin request uses a method other than simple GET or POST, or custom headers, or a non-simple content type. The browser first sends an OPTIONS request to ask whether the server allows the real request. The server enables it with Access-Control response headers.

React

Why do list items need stable keys?

React uses keys to match old and new elements during reconciliation. Stable keys let React keep component state and DOM nodes with the right item when the list changes. Using array indexes as keys breaks this when items are reordered or removed.

What are the rules of hooks?

Call hooks only at the top level of a function component or a custom hook, never inside loops, conditions or nested functions. Call them in the same order on every render. React relies on this order to match each hook call with its stored state.

What does the dependency array of useEffect control?

The effect runs after render when a listed value has changed since the last run. An empty array runs it once on mount. Omitting the array runs it after every render. Missing dependencies cause stale values, so lint rules are worth following.

Week 6 recap: data stack, ML, deep learning, LLMs, agents and data engineering

Data stack and ML foundations

What is broadcasting in NumPy?

Broadcasting lets arithmetic between arrays of different shapes work by stretching the smaller array along missing or size-one dimensions, without copying data. For example, adding a vector of shape (3,) to a matrix of shape (2, 3) adds the vector to each row.

When is a NumPy result a view, and when is it a copy?

Basic slicing returns a view that shares memory with the original, so changing one changes the other. Fancy indexing with an index array, or boolean masks, returns a copy. Use .copy() when you need independence.

What is the difference between loc and iloc in pandas?

loc selects by label, and its end is inclusive. iloc selects by integer position, and its end is exclusive, like Python slices.

Write the formulas for precision, recall and F1.

Precision = TP / (TP + FP). Recall = TP / (TP + FN). F1 = 2 times precision times recall divided by (precision plus recall), the harmonic mean, which is high only when both are high.

What is the bias-variance trade-off?

High bias means the model is too simple and misses the pattern, so it underfits both training and test data. High variance means the model fits noise in the training data and does poorly on new data, which is overfitting. Regularisation, more data and simpler models move the balance.

What is the difference between L1 and L2 regularisation?

L2 adds the sum of squared weights to the loss, shrinking all weights smoothly. L1 adds the sum of absolute weights, which pushes some weights exactly to zero and so selects features.

Deep learning and transformers

Write the gradient descent update rule.

w_new = w_old minus learning_rate times the gradient of the loss with respect to w. The learning rate controls the step size: too large diverges or oscillates, too small learns slowly.

Write the scaled dot-product attention formula and say what each part does.

Attention(Q, K, V) = softmax(Q times K transposed, divided by the square root of the key dimension) times V. Q and K measure how strongly each token should attend to others, the square root scales the scores to keep softmax stable, and V carries the information that is mixed together.

What is the purpose of a KV cache during generation?

When generating token by token, the keys and values of earlier tokens do not change. The KV cache stores them so each new token computes only its own key and value, instead of recomputing the whole prefix at every step. It trades memory for speed.

Compare greedy decoding, top-k, top-p and temperature.

Greedy picks the single most probable token, which is deterministic but can be repetitive. Top-k samples from the k most probable tokens. Top-p (nucleus) samples from the smallest set whose probabilities add up to p. Temperature divides logits before softmax: below 1 sharpens the distribution, above 1 flattens it.

What does LoRA change during fine-tuning?

It freezes the pretrained weights and trains small low-rank matrices whose product is added to selected weight matrices. Far fewer parameters are trained and stored, which lowers memory and cost. QLoRA also quantises the frozen base model.

LLM applications, agents and security

List the stages of a RAG pipeline and the most common cause of a bad answer.

Chunking, embedding, retrieval, optional reranking, prompt assembly, generation, and evaluation. A bad answer is most often a retrieval failure: the right chunk was never retrieved or was poorly chunked. Measure retrieval recall before tuning the model.

What is the ReAct loop?

The model alternates a Thought, an Action (a tool call), and an Observation (the tool result) until it gives a Final Answer. The application runs the tools, so the loop needs a step limit and permission checks.

What are the three MCP server primitives?

Tools (functions the model may call), resources (read-only data identified by URI, chosen by the application), and prompts (templates the user selects). MCP uses JSON-RPC 2.0 between hosts, clients and servers.

What are the main defences against prompt injection?

Least-privilege tools, allowlists enforced in code, human approval for irreversible actions, keeping untrusted content separate from instructions, output checks, and step and spending limits. No single defence is complete.

Data engineering and ML system design

What is the difference between ETL and ELT?

ETL transforms data before loading it into the destination. ELT loads raw data first and transforms it inside the destination, usually with SQL. ELT keeps raw history for reprocessing.

Why does Kafka preserve order only within a partition?

Each partition is a single ordered log. Different partitions are written and read independently, so there is no global order. Use a consistent key so related events share a partition.

What is the first thing to say in an ML system design answer?

Clarify the problem, the users, the scale, the latency budget, and the success metrics. Then define a baseline and a rollout plan. Architecture comes after these decisions, not before.

Segment 1: introduction (0 to 3 minutes)

Question. Tell me about yourself.

Model answer. Use present, past, future. "I am currently [your role or study focus]. Segment 2: coding (3 to 18 minutes)

Question. Given a list of intervals, merge all overlapping intervals and return the result.

Model answer. Restate the problem and ask whether intervals touching at an end count as overlapping (usually yes). Brute force compares every pair, which is O(n squared). Sorting by start removes the need to look back: sort in O(n log n), then walk the list once, extending the last merged interval whenever the next start is at most its end. The total time is O(n log n) for the sort and O(n) for the scan, with O(n) space for the output. Test with one overlapping pair, one disjoint pair, and a set where one interval contains another.

Segment 3: core CS rapid fire (18 to 28 minutes)

Question. Explain deadlock and how you would prevent it.

Model answer. Deadlock needs four conditions at once: mutual exclusion, hold and wait, no preemption, and circular wait. Prevention breaks one condition, usually circular wait, by ordering locks so every thread acquires them in the same order. Avoidance, such as the Banker's algorithm, checks before each allocation that the system stays in a safe state.

Question. Why normalise a database, and when would you not?

Model answer. Normalisation removes redundancy so an update changes one place, avoiding update, insert and delete anomalies. Denormalise when read performance dominates and the duplicated data changes rarely, such as in reporting tables or caches, and accept the maintenance cost.

Question. What happens when you type a URL and press Enter?

Model answer. The browser resolves the host name with DNS, opens a TCP connection with a three-way handshake, negotiates TLS for HTTPS, sends the HTTP request, receives the response (possibly redirects and caches), and renders the HTML, loading CSS and scripts as needed.

Segment 4: system design (28 to 42 minutes)

Question. Design a URL shortener.

Model answer. Clarify: create and redirect, custom aliases optional, expiry optional, and expected traffic, which is read-heavy. Estimate with stated assumptions, such as the number of new links per day and the read-to-write ratio, and compute storage per link and requests per second. API: POST to create a short code, GET to redirect with a 301 or 302. Data model: a key-value table keyed by the short code, with the long URL, creation time and owner. Code generation: a unique ID encoded in base 62. High level: load balancer, stateless application servers, a cache in front of the key-value store for hot codes, and replication for availability. Deep dive: how the ID generator avoids collisions across servers, and how the cache is invalidated when a link is deleted. Trade-offs: 301 gets cached by browsers, which makes analytics less accurate; 302 keeps the server in the path.

Segment 5: ML and GenAI (42 to 50 minutes)

Question. How would you evaluate a RAG chatbot before releasing it?

Model answer. Build a fixed evaluation set of real questions with reference answers and the documents that should be retrieved. Measure retrieval recall, faithfulness of each answer to the retrieved text, and answer relevance. Add safety cases, such as attempts to reveal restricted documents, which must be refused. Use calibrated LLM-as-judge grading for open-ended answers, and track latency and cost. Release behind a canary or A/B test, and monitor live feedback after release.

Question. Your classifier has 99 percent accuracy on fraud data. Is it good?

Model answer. Not necessarily. If fraud is rare, a model that never flags anything reaches high accuracy. Ask for precision and recall at the chosen threshold, a confusion matrix, and the cost of each error type. Check that the split respects time and that no feature leaks the label.

Segment 6: behavioural (50 to 56 minutes)

Question. Tell me about a time you had a disagreement with a teammate.

Model answer, STAR template. Situation: "In [project or course], [teammate role] and I disagreed about [the technical point]." Task: "My job was [your responsibility], and the deadline was [date or milestone]." Action: "I [what you did to understand their view], then [how you proposed a test or a trade-off table], and we agreed to [decision]." Result: "[The measurable outcome, with your own number]. I learned to [specific lesson]." Replace every bracket with your real facts. Do not invent a story.

Segment 7: your questions (56 to 60 minutes)

Question. Do you have any questions for us?

Model answer. Ask about the work, not about perks. Good examples: "How do you measure success for this role in the first six months?", "What does a typical week look like for this team?", and "What is the biggest technical challenge the team is working on now?"

Interview questions

These cover the whole course. Answer aloud first, then check.

What is the difference between a process and a thread, and why do threads share memory?

A process has its own address space and resources. Threads inside one process share the address space, heap and open files but each has its own stack and registers. Sharing makes communication cheap and creates the need for synchronisation.

Explain vertical and horizontal scaling and the trade-off between them.

Vertical scaling adds more CPU or memory to one machine. It is simple but has a ceiling and a single point of failure. Horizontal scaling adds more machines behind a load balancer. It scales further and improves availability, but requires stateless services and data partitioning.

What is idempotency, and where does it matter in a system?

An operation is idempotent if repeating it has the same effect as doing it once. It matters for retries after timeouts, message redelivery, and payment requests. Idempotency keys and upserts are the usual tools.

What is the N+1 problem, and how do you detect it?

It is one query for a list plus one query per item for a related value. Detect it in query logs by seeing many near-identical queries for one request. Fix it with joins or batch loading.

What is the difference between a mutex and a semaphore?

A mutex has ownership and protects one critical section, so the locking thread must unlock it. A semaphore is a counter that controls access to a number of resources, and any thread can signal it.

Why is accuracy alone a poor metric for imbalanced data?

A trivial model that predicts the majority class achieves high accuracy with no value. Use precision, recall, F1 or PR-AUC, and choose a threshold from the costs of each error type.

What is the difference between the two types of prompt injection?

Direct injection comes from the user typing instructions that try to override the system. Indirect injection is hidden in content the agent reads, such as a web page, email or tool result. Indirect injection is harder to spot because the attacker is not in the conversation.

How do you explain a technical answer to a non-technical interviewer?

Start with the purpose and the result in plain words, then give one concrete example. Add detail only when they ask. Check understanding by asking whether they want more depth on any part.

What do you say when you do not know the answer?

4Sum (LeetCode 18)

Given an array of integers nums and a target, return all unique quadruplets [a, b, c, d] from the array whose sum equals the target. The quadruplets may be returned in any order, and the same value cannot be used for two different quadruplets. For [1,0,-1,0,-2,2] with target 0, the answers are [-2,-1,1,2], [-2,0,0,2] and [-1,0,0,1].

How to think about it

  1. Understand. Duplicates in the input can create duplicate quadruplets, so the output must be deduplicated. Target and values can be negative. An array with fewer than four elements has no answer.
  2. Brute force. Four nested loops over all index choices check every quadruplet, which is O(n to the fourth power). Deduplicating with a set adds more work.
  3. Find the waste. The last two numbers can be found with two pointers in a sorted array, so the innermost two loops collapse into one linear scan. That is the 2-sum pattern, applied inside two outer loops.
  4. Optimise. Sort the array. Fix the first index i and the second index j. Use two pointers lo and hi for the remaining pair. If the sum is too small, move lo right; if it is too large, move hi left. Skip repeated values at i, j, lo and hi so each unique quadruplet is produced once. The result is O(n cubed) time, and the output is already sorted.
  5. Dry run. Sorted: [-2,-1,0,0,1,2], target 0. With i at -2 and j at -1, the pointers start at lo = index 2 (value 0) and hi = index 5 (value 2). The sum is -1, too small, so lo moves to the next 0 (sum still -1), then to 1 (sum 0), which is a match. The pair then moves on. Later, with i at -2 and j at the first 0, lo and hi give -2, 0, 0, 2, another match.

Code

def four_sum(nums, target):
    nums = sorted(nums)
    n = len(nums)
    result = []
    for i in range(n - 3):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        for j in range(i + 1, n - 2):
            if j > i + 1 and nums[j] == nums[j - 1]:
                continue
            lo, hi = j + 1, n - 1
            while lo < hi:
                total = nums[i] + nums[j] + nums[lo] + nums[hi]
                if total < target:
                    lo += 1
                elif total > target:
                    hi -= 1
                else:
                    result.append([nums[i], nums[j], nums[lo], nums[hi]])
                    lo += 1
                    hi -= 1
                    while lo < hi and nums[lo] == nums[lo - 1]:
                        lo += 1
                    while lo < hi and nums[hi] == nums[hi + 1]:
                        hi -= 1
    return result

print(four_sum([1, 0, -1, 0, -2, 2], 0))
print(four_sum([2, 2, 2, 2, 2], 8))
print(four_sum([1, 2, 3, 4], 100))
[[-2, -1, 1, 2], [-2, 0, 0, 2], [-1, 0, 0, 1]]
[[2, 2, 2, 2]]
[]

The duplicate checks are the subtle part. if i > 0 and nums[i] == nums[i - 1] skips a first value already used, so the same starting value never produces the same answers twice. The check j > i + 1 makes sure the previous element is a valid second-position candidate and not the first position itself. After a match, the two inner while loops move past equal values, because equal neighbours would produce a duplicate quadruplet. The third example returns an empty list because the largest possible sum of 1, 2, 3 and 4 is 10, far below 100.

Time O(n cubed) · Space O(1) beyond the output (sorting uses O(log n) or O(n) depending on the implementation)

Pattern to rememberFor k-sum, sort, fix k minus 2 values with loops, and solve the last two with two pointers while skipping duplicates at every level.

TrapDeduplicating the output with a set after the search is correct but slow, and it hides the real mistake. Skip duplicates at each position instead.

Count Square Submatrices with All Ones (LeetCode 1277)

Given an m by n matrix of 0s and 1s, count the square submatrices whose cells are all 1. A 1 by 1 square of a single 1 counts, and so does every larger square of 1s. For [[0,1,1,1],[1,1,1,1],[0,1,1,1]] the answer is 15.

How to think about it

  1. Understand. A square is identified by its bottom-right corner and its side length. Counting squares is the same as counting, for each cell, how many squares end at that cell.
  2. Brute force. Try every top-left corner and every side length, then check all cells of that square for 1s. This is O(m times n times min(m, n) times side squared), which is too slow.
  3. Find the waste. If a cell is the bottom-right corner of a square of side k, then the cells above, left and diagonally up-left must each be the corner of a square of side k minus 1. So the answer for a cell depends on three neighbouring cells, and recomputing the whole square each time is unnecessary.
  4. Optimise. Let dp[i][j] be the number of squares whose bottom-right corner is cell (i, j). If the cell is 0, dp is 0. If it is 1, dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]), because the smallest of the three neighbouring largest squares limits how large the new square can be. Add every dp value to the total. For boundary cells the value is 1 when the cell is 1.
  5. Dry run. Take [[1,0,1],[1,1,0],[1,1,0]]. Row 0 gives dp values 1, 0, 1, total 2. Row 1: the first cell is 1 (boundary), the second is 1 + min(0, 1, 1) = 1, the third is 0, total 2. Row 2: the first is 1, the second is 1 + min(dp above = 1, dp left = 1, dp diagonal = 1) = 2, the third is 0, total 3. The overall total is 2 + 2 + 3 = 7.

Code

def count_squares(matrix):
    rows, cols = len(matrix), len(matrix[0])
    dp = [[0] * cols for _ in range(rows)]
    total = 0
    for i in range(rows):
        for j in range(cols):
            if matrix[i][j] == 0:
                continue
            if i == 0 or j == 0:
                dp[i][j] = 1
            else:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])
            total += dp[i][j]
    return total

print(count_squares([[0, 1, 1, 1], [1, 1, 1, 1], [0, 1, 1, 1]]))
print(count_squares([[1, 0, 1], [1, 1, 0], [1, 1, 0]]))
print(count_squares([[0]]))
15
7
0

The first two lines of the loop body skip zeros, since no square can end at a 0. Cells in the first row or first column can only be the corner of a 1 by 1 square, so they get 1. Every other cell uses the three neighbours, and the min captures the rule that the new square can be no larger than the smallest of the three squares it extends. The dry-run table shows the same values the code computes. The last test is a single zero, which contributes nothing.

Time O(m · n) · Space O(m · n)

Pattern to rememberWhen the answer for a cell depends only on its up, left and up-left neighbours, store a running value per cell and take the minimum of the neighbours plus one.

TrapAdding only the cell itself when it is 1 misses the larger squares. The total is the sum over all cells of the largest square ending there, which counts every smaller square too.

The Skyline Problem (LeetCode 218)

You are given buildings as triples [left, right, height]. Each building is a rectangle standing on the x-axis between left and right. Return the skyline: the list of key points [x, height] where the outline of the combined buildings changes height, sorted by x. The skyline includes the points where the height drops to 0. For [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]] the answer is [[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]].

How to think about it

  1. Understand. The output contains only points where the height changes. Two adjacent buildings of equal height produce no point between them. Buildings may overlap, and the skyline height at any x is the maximum height of the buildings covering x.
  2. Brute force. Collect all left and right coordinates, sort them, and for each coordinate compute the maximum height of the buildings covering it by scanning all buildings. That is O(n squared) with a scan at each point, and it would be fine for small inputs.
  3. Find the waste. The height only changes at building edges. A sweep line visits the edges in order and only needs the tallest building that is still active at each edge. A heap answers "tallest active building" in O(log n).
  4. Optimise. Create two events per building: a start event at left with the height (stored negative, so the heap order works for a max-heap through Python's min-heap), and an end event at right. Sort events by x. Keep a heap of (negative height, right edge) pairs with a sentinel for the ground. For each x, process every event at that x, then remove heap tops whose right edge is at or before x (lazy deletion). The top gives the current height. If it differs from the last recorded height, append [x, height]. Lazy deletion works because a building that ended but is not at the top does not change the answer until it reaches the top.
  5. Dry run. For the example, the events at 2, 3, 5, 7, 9, 12, 15, 19, 20 and 24 are processed in order. At x = 2 the tallest active building is 10, so the first point is [2, 10]. At x = 3 the 15 starts, so [3, 15]. At x = 5 the 12 starts but 15 still dominates, so no point. At x = 7 the 15 ends and the 12 becomes the top, so [7, 12]. At x = 9 the 10 ends, which is hidden behind the 12, so no point. At x = 12 the 12 ends, leaving only the ground, so [12, 0]. The remaining points follow the same pattern.

Code

import heapq

def get_skyline(buildings):
    events = []
    for left, right, h in buildings:
        events.append((left, -h, right))   # start; negative height so taller starts sort first
        events.append((right, 0, 0))       # end
    events.sort()
    result = []
    heap = [(0, float("inf"))]             # ground level, never expires
    i = 0
    while i < len(events):
        x = events[i][0]
        while i < len(events) and events[i][0] == x:
            _, neg_h, right = events[i]
            if neg_h:
                heapq.heappush(heap, (neg_h, right))
            i += 1
        while heap[0][1] <= x:
            heapq.heappop(heap)
        cur = -heap[0][0]
        if not result or result[-1][1] != cur:
            result.append([x, cur])
    return result

print(get_skyline([[2, 9, 10], [3, 7, 15], [5, 12, 12], [15, 20, 10], [19, 24, 8]]))
print(get_skyline([[0, 2, 3], [2, 5, 3]]))
print(get_skyline([[0, 5, 7], [5, 10, 7]]))
[[2, 10], [3, 15], [7, 12], [12, 0], [15, 10], [20, 8], [24, 0]]
[[0, 3], [5, 0]]
[[0, 7], [10, 0]]

Read the sort carefully. Tuples sort by x first, then by the negative height, so at the same x a start event with a taller building comes before a shorter one, and all starts come before ends (an end has height 0, which sorts after every negative height). Processing all events at one x before checking the heap means the height is recorded once per x. The inner while that pops expired buildings uses the heap top's right edge, and the ground sentinel's infinite right edge keeps the heap non-empty. The second example shows that two buildings of equal height touching at x = 2 produce no point at x = 2, because the height stays 3. The third example shows the same thing: equal heights side by side merge into one segment.

Time O(n log n) · Space O(n)

Pattern to rememberFor interval-height questions, sweep the edges in order and keep the active heights in a heap with lazy deletion, recording a point only when the maximum changes.

TrapRecording a point for every event creates duplicate points at the same x and extra points where the height does not change. Record once per x and only when the height differs from the last point.

Interviewers ask"Why negative heights in the heap?" Python's heapq is a min-heap, so storing the negative height makes the tallest building the smallest value, which is the one at the top.
