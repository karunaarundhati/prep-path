Ridge regression

Ridge regression is linear regression with a penalty on large weights. It keeps the model from trusting noise too much, and it stays stable when inputs are close copies of each other. You will learn the loss, the closed-form solution, the effect of lambda, and how ridge differs from ordinary least squares and from lasso.

The idea in plain words

Picture a tailor who makes a suit to fit one measurement very exactly. The suit fits that day, but it pulls and bunches for anyone whose body is a little different. A wiser tailor allows some slack. The suit is a bit less exact on the one measurement but fits many more people well.

Ordinary least squares, the method from the previous topic, is the exact tailor. It chooses weights that make the training error as small as possible, whatever their size. When the data is noisy or the inputs are close copies of each other, those weights can become very large and jumpy. They fit the noise in the training data, and they fail on new data. This is called overfitting.

Ridge regression is the wiser tailor. It adds a rule: large weights cost something. The model must balance two goals, fitting the data and keeping the weights small. The strength of the rule is set by a number called lambda (λ). When λ is 0, ridge is the same as ordinary least squares. As λ grows, the weights are pulled toward zero.

For GATE, ridge regression is a standard topic in the Machine Learning part of the Data Science and AI paper (DA). Typical questions ask you to write the loss, to explain why ridge handles multicollinearity, to say what happens as λ changes, and to compute a ridge solution for a small example. The ideas here build directly on multiple linear regression.

Key terms

Read these first. Each term is used again later on the page.

Overfitting
When a model fits the training data very closely, noise included, and does badly on new data. Precisely: low training error with high test error.
Weight or coefficient
A number βj that says how strongly input j moves the prediction.
Intercept β0
The prediction when all inputs are zero. By convention it is not penalised in ridge.
Loss function
A single number that measures how bad a set of weights is. Training means finding weights with the smallest loss.
Sum of squared errors SSE
Add up the squared gaps between the real and predicted outputs. Precisely: Σ(yi minus ŷi)².
Penalty term
An extra part of the loss that grows when the weights grow. In ridge it is λΣβj² over the slope weights.
Regularisation
Any method that adds a penalty to keep the model simple or the weights small.
Lambda λ
The regularisation strength, a number 0 or bigger. Large λ means a strong penalty.
L2 penalty
A penalty equal to the sum of squared weights. Ridge uses this.
L1 penalty
A penalty equal to the sum of absolute weights. Lasso uses this.
Identity matrix I
A square matrix with 1s on the main diagonal and 0s elsewhere. It acts like the number 1 in matrix products.
Bias
The systematic error of a method, how far its average answer is from the truth.
Variance
How much the answer would change if the training data were a little different.
Shrinkage
Pulling estimated weights toward zero.

The ridge loss and its penalty

Step 1: the ordinary least squares loss

Recall the least squares loss. It is the sum of squared errors, which is the squared gaps between the real outputs and the predictions.

SSE(β) = Σ (yi minus ŷi)²

Read the symbols. The sigma Σ means "add over all data points i". Each yi is a real output. Each ŷi is the predicted output from the current weights. Squaring stops positive and negative errors from cancelling.

Step 2: add the penalty

Ridge adds a second part to the loss. It is λ times the sum of the squares of the slope weights.

J(β) = Σ (yi minus ŷi)² + λ Σj=1 to n βj²

The second sum runs over the slope weights β1 to βn. It leaves out the intercept β0. The reason is simple: the intercept only sets the level of the predictions. Shrinking it would pull all predictions toward zero for no good reason, so the convention is not to penalise it.

Now the two goals are visible. The first part wants small errors. The second part wants small weights. The number λ decides which goal matters more.

A tiny numerical example of the loss

Suppose SSE = 10 for some weights, the slope weights are 2 and minus 2, and λ = 0.5. The penalty is λ times (2 squared plus minus 2 squared) = 0.5 times (4 + 4) = 4. The ridge loss is 10 + 4 = 14. A different set of weights with SSE = 12 but slopes of 0.5 and minus 0.5 would have penalty 0.5 times (0.25 + 0.25) = 0.25, giving loss 12.25. That set would be preferred, even though its raw error is larger.

Key ideaRidge does not ask only "which weights fit best?" It asks "which weights fit well and stay small?" A large λ gives small weights even at some cost in fit.

Why squares, not absolute values

The squared penalty is smooth everywhere. Its slope changes gently as a weight changes, so the minimum can be found with calculus and a neat formula. This is the main reason ridge has a closed-form solution. Lasso uses absolute values, which have a corner at zero, and that changes the story, as we see later.

Question: if λ = 0, what is the ridge loss?

The penalty term vanishes, so the ridge loss equals the ordinary sum of squared errors. Ridge with λ = 0 is ordinary least squares.

Question: why do we not penalise the intercept?

The intercept sets the overall level of the predictions. Shrinking it toward zero would move all predictions toward zero, which has nothing to do with how the inputs affect the output.

Closed-form ridge solution

Step 1: find the slope of the loss

To find the lowest point of the loss, set its slope to zero in every direction of β. This is the same idea as the bottom of a bowl. For ordinary least squares this gives the normal equations XTXβ = XTy. The penalty adds one more term, whose slope is 2λ times the weight vector (ignoring the intercept).

Put the two slopes together and set them to zero. The result is:

(XTX + λI) β = XTy

Here I is the identity matrix. In the intercept position it has a 0 instead of a 1, because the intercept is not penalised. In the simple examples on this page there is no intercept, so the full identity is used.

Step 2: solve for β

If the matrix XTX + λI has an inverse, we can solve in one line.

βridge = (XTX + λI)-1 XTy

Compare this with the ordinary least squares formula, β = (XTX)-1XTy. The only change is that λI is added inside the bracket. That tiny change is powerful, as we will see.

Key ideaAdding λI shifts every diagonal entry of XTX up by λ. A matrix with a shifted diagonal is much less likely to be singular. This is why ridge copes with multicollinearity.

Worked example: two identical inputs

Multicollinearity is easiest to see in the extreme case. Take a model with no intercept and two inputs that are exact copies: x1 = x2 = (1, 2, 3). The target is y = (1, 2, 3).

  1. Build XTX. The entries are the sums of products. x1 with itself: 1 + 4 + 9 = 14. x1 with x2: also 14. x2 with itself: 14. So XTX = [[14, 14], [14, 14]].
  2. See the problem. The determinant is 14 times 14 minus 14 times 14 = 0. So XTX has no inverse and ordinary least squares fails. The two copies cannot be separated.
  3. Build XTy. The entries are x1 dot y = 1 + 4 + 9 = 14 and x2 dot y = 14. So XTy = (14, 14).
  4. Add λI with λ = 1. The matrix becomes [[15, 14], [14, 15]]. Its determinant is 15 times 15 minus 14 times 14 = 225 minus 196 = 29, which is not zero. So it has an inverse.
  5. Solve. Because the two inputs are identical, the answer must treat them the same. Let both weights be b. Then the first equation is 15b + 14b = 14, so 29b = 14 and b = 14/29. The total effect is 2 times 14/29 = 28/29, about 0.966.

Ridge gives each copy half the credit. It does not crash and it does not invent a huge weight for one copy. The code below checks the solution and also runs the same idea on a single input, so you can see how λ shrinks a weight.

from fractions import Fraction as F

# Two identical inputs x1 = x2 = (1, 2, 3), target y = (1, 2, 3), lambda = 1
xtx = [[14, 14], [14, 14]]
xty = [14, 14]
lam = 1
a = xtx[0][0] + lam
b = xtx[0][1]
det = a * a - b * b
print("det of X^T X + lambda I =", det)
# Solve the 2 by 2 system exactly with Cramer's rule
w1 = F(xty[0] * a - b * xty[1], det)
w2 = F(a * xty[1] - b * xty[0], det)
print("weights =", w1, w2, "sum =", w1 + w2, "=", round(float(w1 + w2), 3))

# One input, shrinkage as lambda grows: beta = sum(x*y) / (sum(x*x) + lambda)
sxx, sxy = 14, 14
for lam in [0, 1, 5, 14]:
    print("lambda =", lam, " ridge weight =", F(sxy, sxx + lam))
det of X^T X + lambda I = 29
weights = 14/29 14/29 sum = 28/29 = 0.966
lambda = 0  ridge weight = 1
lambda = 1  ridge weight = 14/15
lambda = 5  ridge weight = 14/19
lambda = 14  ridge weight = 1/2
Question: why does the ridge answer give the two identical inputs equal weights?

The two inputs are identical, so the loss cannot tell them apart. The penalty is symmetric in the two weights too. The unique lowest point must therefore have equal weights.

Question: what happens to the ridge weight in the one-input example as λ becomes very large?

The denominator grows without limit, so the weight is pulled toward zero. The prediction then depends less and less on the input.

Effect of lambda on bias and variance

Two kinds of error

Imagine throwing darts at a board. Bias is how far the centre of your darts is from the bullseye. Variance is how widely the darts are scattered. You want both small. A method can be unbiased but scattered, or tightly grouped but off-centre.

In regression, imagine training the model on many different random samples from the same source. Each sample gives slightly different weights. Bias measures how far the average prediction is from the truth. Variance measures how much the predictions move from one sample to the next.

Key ideaOrdinary least squares is unbiased when its assumptions hold, but when inputs are close copies its variance can be huge. Ridge adds a little bias on purpose to cut the variance a lot. If the trade is good, the total error on new data goes down.

What λ does

  • λ = 0. The model is ordinary least squares. Bias is at its lowest, variance may be high.
  • Small λ. The weights shrink a little. Variance drops, bias rises slightly.
  • Large λ. The weights shrink a lot. Variance becomes small, but bias can become large because the model is forced toward simplicity.
  • λ very large. Every slope weight goes to zero. The model predicts only the intercept, a constant.

The one-input example from the previous section shows this clearly. Its formula is βridge = Σxy/(Σx² + λ). The table below uses the values Σxy = 14 and Σx² = 14. The true slope from the data is exactly 1.

λRidge weightShrinkage compared with the true value 1
01No shrinkage (ordinary least squares)
114/15, about 0.933Small shrinkage
514/19, about 0.737Stronger shrinkage
141/2Half the true value

TrapNever choose λ by looking at the training error. The training error is always smallest at λ = 0, so that choice always picks ordinary least squares and throws away the benefit of ridge.

Choosing λ with cross-validation

The usual way is cross-validation. Split the data into, say, five folds. Train on four folds with a chosen λ, then measure the error on the fifth fold. Repeat so that each fold is the test fold once. Average the errors. Try many values of λ, for example 0.01, 0.1, 1, 10, and keep the λ with the lowest average validation error.

Scale the inputs first

The penalty treats every weight the same way. But a weight depends on the units of its input. If one input is measured in metres and another in millimetres, the weights differ by a factor of a thousand even when the effects are equal. Before ridge, standardise each input to mean 0 and standard deviation 1, so that the penalty is fair. The intercept is handled separately, as described earlier.

Question: a model has a large variance. Should you increase or decrease λ?

Increase λ. A larger penalty shrinks the weights, which lowers variance. The price is a little more bias, so choose λ by cross-validation.

Question: why does the training error always favour λ = 0?

Ridge adds a penalty to the loss. Without it, the fit can always be at least as good on the training points. Any positive λ forces the weights smaller, which can only make the training fit worse or equal.

Ridge, OLS and lasso compared

Lasso in one paragraph

Lasso is the close cousin of ridge. It uses the sum of absolute weights, λΣ|βj|, instead of squares. The absolute value is the L1 penalty, and the square is the L2 penalty. This small change matters a great deal. The corner of the absolute value at zero pushes some weights exactly to zero, so lasso can select inputs. Ridge only makes weights small, and it almost never makes them exactly zero.

The comparison table

FeatureOrdinary least squaresRidge (L2)Lasso (L1)
PenaltyNoneλΣβj²λΣ|βj|
Closed-form solutionYes, if XTX is invertibleYes, always when λ > 0No simple formula in general
Handles multicollinearityPoorly, or not at allWell, spreads weight across copiesPartly, tends to pick one copy
Sets weights exactly to zeroNoNoYes
Main useBaseline and inferenceStable predictions with many correlated inputsChoosing a small set of inputs

GATE loves thisExpect a question asking which penalty gives exact zeros. The answer is L1, the lasso. Ridge, the L2 penalty, shrinks weights smoothly without making them zero.

Why ridge has a closed form and lasso does not

The squared penalty is smooth, so setting its slope to zero gives linear equations we can solve with a matrix inverse. The absolute value has a sharp corner at zero, which breaks the simple slope calculation. Lasso is solved with iterative methods, which run step by step until they settle near the answer.

Which one to use

  • Use OLS when there are few inputs, they are not strongly correlated, and you want plain interpretable estimates.
  • Use ridge when many inputs are correlated and you care about stable predictions.
  • Use lasso when you suspect that only a few inputs matter and you want the model to drop the rest.
Question: which method can give a weight of exactly 0?

Lasso, because its L1 penalty has a corner at zero. Ridge shrinks weights but leaves them non-zero in almost all cases.

Question: what is the main benefit of ridge over ordinary least squares when two inputs are almost identical?

The matrix XTX + λI is invertible for any λ > 0, so the solution exists and is stable. Ordinary least squares may have no unique answer or a very unstable one.

Solved GATE-style problems

These are original GATE-style practice problems written for this page. They are not real past paper questions. Try each one before you read the answer. MSQ means more than one option can be correct. NAT means you type a number.

Ridge loss value (NAT)

For some weights, the sum of squared errors is 10. The slope weights are 2 and minus 2. The intercept is not penalised. The ridge parameter is λ = 0.5. Find the ridge loss. (NAT)

How to think about it

  1. What is asked. The total ridge loss, data part plus penalty part.
  2. Which idea applies. J = SSE + λΣβj² over the slope weights only.
  3. Work it out. The slope squares are 4 and 4, adding to 8. Multiply by λ = 0.5 to get 4. Add the SSE: 10 + 4 = 14.
  4. Check. The penalty must be positive, and 14 is bigger than 10, as it should be.

Answer: 14

Facts about ridge (MSQ)

Which statements about ridge regression are true? Select all that apply.

(A) Increasing λ increases the bias of the estimate.

(B) Ridge regression can set some weights exactly to zero.

(C) For λ > 0, the matrix XTX + λI is invertible.

(D) The intercept is usually included in the penalty.

How to think about it

  1. What is asked. Which of four statements are correct.
  2. Which idea applies. More shrinkage means more bias and less variance. The L2 penalty never makes weights exactly zero. The intercept is conventionally left out.
  3. Work it out. (A) is true. (B) is false, that is the lasso property. (C) is true, because XTX has no negative eigenvalues, so adding λ > 0 makes all of them positive. (D) is false, by convention the intercept is not penalised.
  4. Check. The two true statements are the bias trade-off and the invertibility fact.

Answer: (A) and (C)

One-input shrinkage (NAT)

A model has one centred input and no intercept. The data gives Σx² = 20 and Σxy = 30. Find the ridge weight when λ = 5. (NAT)

How to think about it

  1. What is asked. The ridge slope for one input.
  2. Which idea applies. βridge = Σxy/(Σx² + λ).
  3. Work it out. The denominator is 20 + 5 = 25. The weight is 30/25 = 1.2.
  4. Check. Ordinary least squares would give 30/20 = 1.5. Ridge shrinks it to 1.2, which is smaller, as expected.

Answer: 1.2

When is the matrix singular? (MSQ)

Consider the matrix [[4, 4], [4, 4]] + λI. For which values of λ is this matrix singular, meaning it has no inverse? Select all that apply.

(A) λ = 0 (B) λ = minus 8 (C) λ = 1 (D) λ = 8

How to think about it

  1. What is asked. The λ values that make the determinant zero.
  2. Which idea applies. A 2 by 2 matrix [[p, q], [r, s]] is singular when ps minus qr = 0.
  3. Work it out. The matrix is [[4 + λ, 4], [4, 4 + λ]]. Its determinant is (4 + λ)² minus 16 = λ² + 8λ = λ(λ + 8). This is zero when λ = 0 or λ = minus 8.
  4. Check. For λ = 1 the determinant is 9. For λ = 8 it is 128. Both are non-zero, so C and D are not singular.

Answer: (A) and (B)

Ridge or lasso? (MSQ)

Which statements about the penalties are correct? Select all that apply.

(A) The lasso penalty can set a weight exactly to zero.

(B) The ridge penalty is the sum of squared weights.

(C) Ridge regression has a closed-form solution for λ > 0.

(D) The lasso penalty is the sum of squared weights.

How to think about it

  1. What is asked. Recall which penalty is which.
  2. Which idea applies. L2 means squares and closed form. L1 means absolute values and exact zeros.
  3. Work it out. (A) is true. (B) is true. (C) is true, from the formula (XTX + λI)-1XTy. (D) is false, that describes ridge.
  4. Check. Ask which penalty has the corner at zero. The absolute value does, so the L1 penalty is the one that gives exact zeros.

Answer: (A), (B) and (C)

Two identical inputs with a bigger penalty (NAT)

Use the same model as the worked example: no intercept, two identical inputs x1 = x2 = (1, 2, 3), target y = (1, 2, 3). Set λ = 3. Find the sum of the two ridge weights to three decimal places. (NAT)

How to think about it

  1. What is asked. The total effect of the pair of copies, rounded.
  2. Which idea applies. The inputs are identical, so the two weights are equal, say b each. Use the first row of (XTX + λI)β = XTy.
  3. Work it out. The first row is (14 + 3)b + 14b = 14. That gives 17b + 14b = 31b = 14, so b = 14/31. The sum is 2b = 28/31, which is about 0.9032, so 0.903.
  4. Check. With λ = 1 the sum was 28/29, about 0.966. A larger λ gives a smaller sum, which matches the shrinkage idea.

Answer: 0.903

Finding the penalty for a target weight (NAT)

A model has one centred input and no intercept. The data gives Σx² = 14 and Σxy = 21. Find the value of λ that makes the ridge weight exactly 1.0. (NAT)

How to think about it

  1. What is asked. The λ that gives a specific ridge weight.
  2. Which idea applies. βridge = Σxy/(Σx² + λ).
  3. Work it out. Set 21/(14 + λ) = 1. Multiply both sides by (14 + λ): 21 = 14 + λ. So λ = 7.
  4. Check. Put λ = 7 back: 21/(14 + 7) = 21/21 = 1. It works.

Answer: 7

Harder problems at GATE 2-mark level. Try each before reading the solution.

Exam-level 1: Ridge slope from sums (NAT, 2 marks)

A simple model has one input and no intercept, because both variables have been centred. The data give Sxx = sum of x squared = 16 and Sxy = sum of x times y = 24. A ridge regression adds a penalty lambda times beta squared to the least squares loss, with lambda = 4. The ridge slope has the closed form beta = Sxy divided by (Sxx plus lambda). Find the ridge slope. (NAT)

How to think about it

  1. What is asked. The ridge slope for one input, not the ordinary least squares slope.
  2. Which idea applies. The penalty adds lambda to the denominator of the usual slope formula, so the slope shrinks toward zero.
  3. Work it out. The ordinary slope would be 24/16 = 3/2. The ridge denominator is 16 plus 4 = 20. So beta = 24/20 = 6/5 = 1.2.
  4. Check. The ridge slope 1.2 is smaller than the ordinary slope 1.5, as shrinkage predicts. The shrink factor is 16/20 = 0.8, and 1.5 times 0.8 = 1.2.

Answer: 1.2 (6/5)

Exam-level 2: Which ridge facts hold (MSQ, 2 marks)

A student studies ridge regression with a penalty lambda times the sum of squared coefficients. Which of the following statements are correct? Select all that apply.

(A) With lambda equal to 0, ridge regression gives the ordinary least squares solution.

(B) As lambda grows, ridge coefficients shrink toward zero but usually do not become exactly zero.

(C) Ridge regression sets some coefficients exactly to zero, so it also selects inputs.

(D) For lambda greater than 0, XTX plus lambda I is invertible even when XTX is singular.

How to think about it

  1. What is asked. Which of four claims about ridge regression are true.
  2. Which idea applies. The ridge solution is (XTX plus lambda I) inverse times XTy. Adding lambda I to a singular matrix can make it invertible.
  3. Work it out. (A) is true, because lambda = 0 removes the penalty. (B) is true, because the penalty pulls coefficients toward zero smoothly. (C) is false, because exact zeros come from the lasso (L1) penalty, not the ridge (L2) penalty. (D) is true, because the determinant of XTX plus lambda I is positive for lambda greater than 0 when the matrix is positive semidefinite.
  4. Check. A small example confirms (D). The code below shows a singular matrix that becomes invertible after adding lambda I.

Answer: (A), (B) and (D). Option (C) is wrong because exact zeros are a feature of lasso, not ridge.

Exam-level 3: Two-input ridge solve (NAT, 2 marks)

A ridge regression has two centred inputs with XTX = [[5, 1], [1, 5]] and XTy = (12, 6). The penalty parameter is lambda = 1. The ridge coefficients solve (XTX plus lambda I) beta = XTy. Find the first ridge coefficient beta1 to three decimal places. (NAT)

How to think about it

  1. What is asked. The first ridge coefficient only.
  2. Which idea applies. Add lambda to each diagonal entry, then solve a two by two system with the inverse formula.
  3. Work it out. The matrix becomes [[6, 1], [1, 6]]. Its determinant is 36 minus 1 = 35. Using the inverse formula, beta1 = (6 times 12 minus 1 times 6)/35 = (72 minus 6)/35 = 66/35, which is about 1.886.
  4. Check. The second coefficient is (minus 12 plus 36)/35 = 24/35, about 0.686. Put both back into the first equation: 6 times 1.886 plus 0.686 = 12.002, which is 12 after rounding.

Answer: 1.886 (beta1 = 66/35)

Exam-level 4: Choosing lambda from a shrink factor (NAT, 2 marks)

A one-input model without an intercept has Sxx = 12 and an ordinary least squares slope of 2.1. A ridge fit with penalty lambda produces a slope equal to exactly 75 percent of the ordinary slope. Find the ridge slope for this lambda, to three decimal places. The shrink factor for one input is Sxx divided by (Sxx plus lambda), so you need to find lambda first. (NAT)

How to think about it

  1. What is asked. The ridge slope, which depends on a lambda we must find first.
  2. Which idea applies. The shrink factor equals 0.75. Solve for lambda, then multiply the ordinary slope by the factor.
  3. Work it out. 12/(12 plus lambda) = 3/4, so 12 plus lambda = 16 and lambda = 4. The ridge slope is 0.75 times 2.1 = 1.575.
  4. Check. With lambda = 4, the shrink factor is 12/16 = 0.75, so the ridge slope equals 0.75 times the ordinary slope, as required.

Answer: 1.575 (lambda = 4)

from fractions import Fraction as F

# Exam-level 1: one-input ridge slope
sxx, sxy, lam = F(16), F(24), F(4)
print("E1 OLS slope =", sxy / sxx, " ridge slope =", sxy / (sxx + lam), " shrink factor =", sxx / (sxx + lam))

# Exam-level 2: ridge facts, determinant check
M = [[2, 2], [2, 2]]
for lam2 in (0, 1):
    a = M[0][0] + lam2
    d = M[1][1] + lam2
    print("E2 lambda =", lam2, " det(X^T X + lambda I) =", a * d - M[0][1] * M[1][0])

# Exam-level 3: two-input ridge solve
A = [[F(6), F(1)], [F(1), F(6)]]
r = [F(12), F(6)]
det = A[0][0] * A[1][1] - A[0][1] * A[1][0]
c1 = (A[1][1] * r[0] - A[0][1] * r[1]) / det
c2 = (A[0][0] * r[1] - A[1][0] * r[0]) / det
print("E3 beta1 =", c1, "=", round(float(c1), 3), " beta2 =", c2, "=", round(float(c2), 3))

# Exam-level 4: lambda from a shrink factor
S = F(12)
target = F(3, 4)
lam3 = S / target - S
ridge4 = F(21, 10) * target
print("E4 lambda =", lam3, " ridge slope =", ridge4, "=", round(float(ridge4), 3))

  • The closed form (XTX + λI)-1XTy works even when XTX is singular, for any λ > 0.
  • Ridge trades a little bias for much lower variance.
  • Choose λ by cross-validation, never by training error.
  • Standardise the inputs before penalising them.
  • Lasso uses absolute values and can give exact zeros. Ridge does not.
