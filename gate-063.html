Numerical integration: Trapezoidal & Simpson's rules

Some integrals have no neat answer, and some are known only as a table of measured values. Numerical integration estimates the area under a curve by adding up simple shapes. This page explains the trapezoidal rule and Simpson's 1/3 rule, their composite versions, their error terms, and how to choose between them in GATE-style questions.

The idea in plain words

An integral is the area under a curve between two points. If the curve is a straight line, the area is easy: it is a trapezium, and its area is the average of the two heights times the width. If the curve is curved, you can still get a good estimate by cutting the area into thin pieces and treating each piece as a simple shape.

Think of measuring the area of a field with an irregular boundary. You lay a row of straight posts along the boundary, join them with straight lines, and add up the trapezium-shaped strips. The more posts you use, the closer the strips follow the boundary, and the better the estimate.

Simpson's rule uses a smarter shape. Instead of straight lines, it fits a parabola through three neighbouring points. A parabola bends, so it follows a curve more closely. For the same number of points, Simpson's rule is usually far more accurate.

Two questions always matter. How accurate is the estimate? And how does the error change when you use more points? The answers come from the error formulas in this topic.

Why this matters for GATE. In the Robotics and Automation paper, numerical integration is used to find distances, energies and average values from sensor data. Questions often give a table of function values and ask for the Trapezoidal or Simpson estimate, or ask which rule is more accurate for a given function.

Key terms

Read this list once now. Return to it when a word feels unfamiliar.

Definite integral
The area under y = f(x) between two limits a and b, written ∫ab f(x) dx.
Numerical integration
Estimating a definite integral from function values, rather than from an antiderivative.
Interval
The stretch of the x-axis from a to b. It is split into n equal parts.
Step size h
The width of each part, h = (b - a)/n.
Ordinate
A function value yi = f(xi) at one of the points. These are the heights used by the rules.
Trapezium
A four-sided shape with two parallel sides. Here, a strip under a straight line with two parallel vertical sides.
Trapezoidal rule
Estimates the integral by adding trapezium areas under straight lines joining the points.
Simpson's 1/3 rule
Estimates the integral by fitting parabolas through groups of three neighbouring points. It needs an even number of intervals.
Composite rule
The rule applied to many small pieces, and the results are added up.
Error
The difference between the exact integral I and the estimate. The error formulas show how it depends on h.
Degree of exactness
The highest power of x for which a rule gives the exact answer. Simpson's 1/3 rule has degree 3.
Factorial
n! is the product 1 × 2 × ... × n. For example, 4! = 24.

Step 1: The area under a curve and the trapezoidal rule

One trapezium

Start with the simplest case: one trapezium from x = a to x = b. Its two vertical sides have heights f(a) and f(b), and its width is b - a. The area of a trapezium is the average of the two parallel sides times the width:

∫ab f(x) dx ≈ (b - a)/2 × (f(a) + f(b))

Read this in words: "the width times the average height". The average of the two heights is (f(a) + f(b))/2, so the formula is a simple product.

Many trapezia: the composite rule

Split [a, b] into n equal parts of width h = (b - a)/n. The points are x0 = a, x1, ..., xn = b, with heights y0, y1, ..., yn. Each interior point appears in two trapezia, so it is counted twice. The end points are counted once:

Tn = (h/2) [y0 + 2y1 + 2y2 + ... + 2yn-1 + yn]

This is the composite trapezoidal rule. The rule is exact for straight lines, because a trapezium under a straight line is exactly the true area.

Worked example 1: the area under x squared

Estimate ∫02 x2 dx. The exact answer is [x3/3] from 0 to 2, which is 8/3, about 2.6667.

  1. With n = 2. h = (2 - 0)/2 = 1. The heights are y0 = 0, y1 = 1, y2 = 4.
  2. Apply the rule. T2 = (1/2)[0 + 2(1) + 4] = (1/2)(6) = 3.
  3. With n = 4. h = 0.5. The heights are 0, 0.25, 1, 2.25, 4. Then T4 = (0.5/2)[0 + 2(0.25) + 2(1) + 2(2.25) + 4] = 0.25 × 11 = 2.75.
  4. Compare. The error falls from 3 - 2.6667 = 0.3333 to 2.75 - 2.6667 = 0.0833. Doubling n cut the error by about four, which is the h2 pattern.
def trapezoid(f, a, b, n):
    h = (b - a) / n
    total = f(a) + f(b)
    for i in range(1, n):
        total += 2 * f(a + i * h)
    return h / 2 * total

f = lambda x: x * x
print("trapezoid n=2:", round(trapezoid(f, 0, 2, 2), 4))
print("trapezoid n=4:", round(trapezoid(f, 0, 2, 4), 4))
print("exact:", round(8 / 3, 4))

exact: 2.6667

The error of the trapezoidal rule

The error formula explains the pattern. For the composite rule, the exact value is related to the estimate by:

I - Tn = -(b - a)h2/12 × f''(ξ)

Here ξ (xi) is some point between a and b, and f''(ξ) is the second derivative there. For x2, f'' = 2 everywhere. With n = 2, h = 1 and b - a = 2: I - T = -(2)(1)/12 × 2 = -1/3. So I = 3 - 1/3 = 8/3, which matches.

The key point is the factor h2. Halving h divides the error by four. This is called second-order accuracy.

Key ideaThe trapezoidal error is proportional to h2 times the second derivative. It is exactly zero for straight lines, where the second derivative is zero.

TrapThe end points are counted once, and all interior points are counted twice. Students often multiply every height by 2, which doubles the end contributions and gives the wrong answer.

Question: How many trapezia are used in the composite rule with n = 5 intervals?

Five. There are n = 5 intervals, and each interval has one trapezium, so there are 5 trapezia and 6 points.

Question: If the trapezoidal error is proportional to h2, how much smaller is the error when n is doubled?

Four times smaller. Doubling n halves h, and (1/2)2 = 1/4.

Step 2: Simpson's 1/3 rule

Why parabolas are better

A straight line can only follow a curve roughly. A parabola can bend, so it follows a curve more closely. Simpson's rule takes three neighbouring points, (x0, y0), (x1, y1) and (x2, y2), with equal spacing h. It fits a parabola through them and integrates that parabola exactly. The result is:

∫x0x2 f(x) dx ≈ (h/3)[y0 + 4y1 + y2]

Here the middle point has weight 4, and the two ends have weight 1. The factor h/3 is the scaling that makes the rule exact for parabolas. Simpson's rule covers two intervals at a time, so it needs an even number of intervals in total.

Worked example 2: Simpson on x squared

Estimate ∫02 x2 dx using one Simpson panel with h = 1.

  1. Heights. y0 = 0, y1 = 1, y2 = 4.
  2. Apply the rule. S = (1/3)[0 + 4(1) + 4] = (1/3)(8) = 8/3.
  3. Compare. The estimate 8/3 is exact. This is no accident: x2 is a parabola, and Simpson's rule integrates parabolas exactly.

The error of Simpson's rule

For the composite Simpson rule, the error is:

I - Sn = -(b - a)h4/180 × f(4)(ξ)

Here f(4) is the fourth derivative, and ξ is a point between a and b. Two facts follow at once. First, the error is proportional to h4, so halving h divides the error by sixteen. Second, the error is zero for any cubic, because a cubic has zero fourth derivative. This is the degree of exactness: Simpson's 1/3 rule is exact up to cubic polynomials.

GATE loves thisSimpson's 1/3 rule is exact for cubics, even though it is built from parabolas. Questions often test this with a cubic integrand, where the answer should match the exact value.

TipRemember the pattern 1, 4, 1 for one panel. For a composite rule, the weights are 1, 4, 2, 4, 2, ..., 4, 1: the interior points alternate between 4 and 2.

Question: Which polynomial degree does Simpson's 1/3 rule integrate exactly?

Degree 3. The error formula has the fourth derivative, which is zero for every cubic.

Question: Why must the composite Simpson rule have an even number of intervals?

Because each panel covers two intervals and uses three points. The points must pair up, so n must be even.

Step 3: The composite Simpson rule and a comparison

Many panels

For a long interval, split [a, b] into n equal intervals, where n is even. Group the points into panels of two intervals each. The composite Simpson rule is:

Sn = (h/3)[y0 + 4y1 + 2y2 + 4y3 + ... + 4yn-1 + yn]

The odd-numbered interior points get weight 4, the even-numbered interior points get weight 2, and the two end points get weight 1. Notice how this matches the trapezoidal rule's structure, but with a different pattern of weights.

Worked example 3: the area under sin x

Estimate ∫0π sin x dx, whose exact value is 2. Use n = 4, so h = π/4.

  1. Heights. The points are 0, π/4, π/2, 3π/4, π. Their sine values are 0, √2/2 ≈ 0.7071, 1, √2/2 ≈ 0.7071, 0.
  2. Simpson. S4 = (π/12)[0 + 4(0.7071) + 2(1) + 4(0.7071) + 0] = (π/12)(4√2 + 2) ≈ 2.0046.
  3. Trapezoid. T4 = (π/8)[0 + 2(0.7071 + 1 + 0.7071) + 0] ≈ 1.8961.
  4. Compare. The Simpson error is about 0.005, while the trapezoidal error is about 0.104. With the same four intervals, Simpson is about twenty times more accurate.
import math

def trapezoid(f, a, b, n):
    h = (b - a) / n
    total = f(a) + f(b)
    for i in range(1, n):
        total += 2 * f(a + i * h)
    return h / 2 * total

def simpson(f, a, b, n):
    h = (b - a) / n
    total = f(a) + f(b)
    for i in range(1, n):
        total += (4 if i % 2 == 1 else 2) * f(a + i * h)
    return h / 3 * total

print("trapezoid n=4:", round(trapezoid(math.sin, 0, math.pi, 4), 4))
print("Simpson n=4:", round(simpson(math.sin, 0, math.pi, 4), 4))
print("exact:", 2.0)

Simpson n=4: 2.0046
exact: 2.0

Simpson's rule costs a little more to set up, but it is much more accurate for smooth functions. When both rules are possible, GATE answers usually favour Simpson.

TrapWhen the number of intervals is odd, Simpson's 1/3 rule cannot be applied to the whole interval. Use the trapezoidal rule, or apply Simpson to an even number of intervals and treat the leftover interval separately.

Question: With n = 6 intervals on [0, 6], what are the weights of the interior points?

The interior points x1 to x5 have weights 4, 2, 4, 2, 4. The end points have weight 1.

Question: Why is Simpson's error smaller than the trapezoidal error for the same n?

Its error is proportional to h4 instead of h2. For a small h, h4 is much smaller than h2, so the error drops faster as n grows.

Step 4: Using tabulated values

The situation

Sometimes there is no formula for f. Instead, a sensor gives values at equally spaced times, and you must estimate the total. The method is the same: read off the heights y0, ..., yn, choose the rule, and apply the weights. Work in the following order:

  1. Check that the x-values are equally spaced, and find h.
  2. Count the intervals n. If you want Simpson, check that n is even.
  3. Write the weights under the heights before you multiply.
  4. Multiply by h/2 or h/3, and add.

Worked example 4: a table of values

The table gives x = 0, 1, 2, 3, 4 and y = 1, 2, 5, 10, 17. Estimate ∫04 y dx with h = 1.

  1. Trapezoid. The weights are 1, 2, 2, 2, 1. So T = (1/2)[1 + 2(2) + 2(5) + 2(10) + 17] = (1/2)(52) = 26.
  2. Simpson. The weights are 1, 4, 2, 4, 1. So S = (1/3)[1 + 4(2) + 2(5) + 4(10) + 17] = (1/3)(76) = 76/3, which is about 25.3333.
  3. Exact check. The table comes from y = x2 + 1. Its integral from 0 to 4 is [x3/3 + x] = 64/3 + 4 = 76/3. So Simpson is exact, which is expected for a quadratic.
ys = [1, 2, 5, 10, 17]
h = 1.0

trap = h / 2 * (ys[0] + 2 * sum(ys[1:-1]) + ys[-1])
simp = h / 3 * (ys[0] + 4 * (ys[1] + ys[3]) + 2 * ys[2] + ys[4])
print("trapezoid:", round(trap, 4))
print("Simpson:", round(simp, 4))
print("exact:", round(76 / 3, 4))
trapezoid: 26.0
Simpson: 25.3333
exact: 25.3333

Key ideaIn a table, the weights do the work. Write them down first. Most wrong answers come from using the wrong weight on one height.

Question: A table has 5 equally spaced points with h = 2. What is the Simpson weight of the third point?

The points are numbered 0 to 4, so the third point is y2. It is an even-numbered interior point, so its weight is 2.

Question: Why is the trapezoidal answer 26 larger than the Simpson answer in Worked example 4?

The trapezoid draws straight lines between the points, and the curve bends upward between them. Straight lines lie above a convex curve, so the trapezoid overestimates the area.

Solved GATE-style problems

These problems are original, written in the style of GATE questions. They are not past exam questions. Try each one on paper before you read the answer.

One trapezium

Use a single trapezium to estimate ∫02 x dx. (Answer type: NAT, a whole number.)

How to think about it

  1. What is asked. The trapezoidal estimate with one strip.
  2. Which idea applies. (b - a)/2 × (f(a) + f(b)).
  3. Work it out. f(0) = 0 and f(2) = 2. So the estimate is (2 - 0)/2 × (0 + 2) = 1 × 2 = 2.
  4. Check. The exact integral is [x2/2] from 0 to 2, which is 2. A straight line is integrated exactly by the trapezoidal rule.

Answer: 2.

Properties of the two rules

Select all the statements that are true.

(A) The trapezoidal rule is exact for straight lines.
(B) Simpson's 1/3 rule needs an even number of intervals.
(C) The trapezoidal error is proportional to h4.
(D) Simpson's 1/3 rule is exact for cubic polynomials.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which facts about the two rules are correct.
  2. Which idea applies. The degree of exactness and the error orders of each rule.
  3. Work it out. (A) True. (B) True, since panels use two intervals. (C) False, the trapezoidal error is proportional to h2. (D) True, the fourth derivative of a cubic is zero.
  4. Check. Statement (C) confuses the two error orders. Remember: trapezoid h2, Simpson h4.

Answer: (A), (B) and (D).

Two trapezia for x squared

Use the composite trapezoidal rule with n = 2 to estimate ∫02 x2 dx. (Answer type: NAT, a whole number.)

How to think about it

  1. What is asked. The trapezoidal estimate with two intervals.
  2. Which idea applies. T2 = (h/2)[y0 + 2y1 + y2] with h = 1.
  3. Work it out. y0 = 0, y1 = 1, y2 = 4. So T2 = (1/2)(0 + 2 + 4) = 3.
  4. Check. The exact answer is 8/3, so the error is 1/3, which the error formula predicts.
print(0.5 * (0 + 2 * 1 + 4))

Simpson on an exponential

Use one Simpson panel (n = 2) to estimate ∫02 ex dx, rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The Simpson estimate with three points: x = 0, 1, 2.
  2. Which idea applies. S = (h/3)[y0 + 4y1 + y2] with h = 1.
  3. Work it out. The heights are 1, e, and e2. So S = (1/3)(1 + 4e + e2), which is about 6.4207.
  4. Check. The exact value is e2 - 1, about 6.3891. The estimate is close, and its error is about 0.03.
import math

print(round((1 + 4 * math.e + math.e ** 2) / 3, 4))

Answer: 6.4207.

Simpson on a square root

Use one Simpson panel (n = 2) to estimate ∫01 √x dx, rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The Simpson estimate with points x = 0, 0.5, 1.
  2. Which idea applies. S = (h/3)[y0 + 4y1 + y2] with h = 0.5.
  3. Work it out. The heights are 0, √0.5 ≈ 0.7071, and 1. So S = (0.5/3)(0 + 4 × 0.7071 + 1) ≈ 0.6381.
  4. Check. The exact value is 2/3, about 0.6667. The error is about 0.029. The square root has an infinite second derivative at 0, so the error is larger than for a smooth function.
import math

print(round((0.5 / 3) * (0 + 4 * math.sqrt(0.5) + 1), 4))
0.6381

Answer: 0.6381.

Error of a composite Simpson estimate

Use the composite Simpson rule with n = 4 to estimate ∫0π sin x dx. Give the absolute error, rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The size of the difference between the Simpson estimate and the exact value.
  2. Which idea applies. Composite Simpson with h = π/4, and the exact value 2.
  3. Work it out. S4 = (π/12)(4√2 + 2) ≈ 2.0046. The absolute error is |2.0046 - 2| = 0.0046.
  4. Check. The program computes the same error directly.
import math

def simpson(f, a, b, n):
    h = (b - a) / n
    total = f(a) + f(b)
    for i in range(1, n):
        total += (4 if i % 2 == 1 else 2) * f(a + i * h)
    return h / 3 * total

print(round(abs(simpson(math.sin, 0, math.pi, 4) - 2), 4))
0.0046

Answer: 0.0046.

Trapezoidal error for a cubic

The composite trapezoidal rule with n = 2 is used for ∫02 x3 dx. Find T2 minus the exact integral. (Answer type: NAT, a whole number.)

How to think about it

  1. What is asked. The error T2 - I, which is a signed difference.
  2. Which idea applies. Evaluate T2, then find the exact integral.
  3. Work it out. With h = 1, the heights are 0, 1, and 8. So T2 = (1/2)(0 + 2 × 1 + 8) = 5. The exact integral is [x4/4] from 0 to 2, which is 4. So T2 - I = 5 - 4 = 1.
  4. Check. The error formula gives I - T = -(b - a)h2/12 × f''(ξ) = -(2)(1)/12 × 6ξ, which equals -1 when ξ = 1. This is consistent, because f'' = 6x equals 6 at x = 1.
T2 = 0.5 * (0 + 2 * 1 + 8)
I = 2 ** 4 / 4
print(T2 - I)
1.0

Answer: 1.

Exam-level 1: Simpson's rule (NAT, 2 marks)

Estimate ∫01 1/(1 + x²) dx with Simpson's 1/3 rule using 4 subintervals, correct to 4 decimal places.

How to think about it

  1. What is asked. The Simpson estimate, which approximates π/4.
  2. Which idea applies. (h/3)[f0 + 4f1 + 2f2 + 4f3 + f4] with h = 0.25.
  3. Work it out. The values are 1, 0.941176, 0.8, 0.64, 0.5. Sum with weights: 1 + 3.764706 + 1.6 + 2.56 + 0.5 = 9.424706. Times 0.25/3: 0.7854.

Exam-level 2: Trapezoid error (NAT, 2 marks)

The trapezoidal rule with n equal subintervals on [0, 2] is used for f(x) = x³. The error bound is (b − a)h² max|f″|/12. Find the smallest n that makes the bound at most 0.01.

How to think about it

  1. What is asked. The number of subintervals for a target error.
  2. Which idea applies. f″ = 6x, so max|f″| = 12 on [0, 2]. h = 2/n.
  3. Work it out. Bound = 2 · (4/n²) · 12/12 = 8/n² ≤ 0.01, so n² ≥ 800 and n ≥ 28.3. Smallest n = 29.
  4. Check. The code finds n.
print(next(n for n in range(1, 100) if 8 / n ** 2 <= 0.01))

29

Answer: 29.

Exam-level 3: Exactness (MSQ, 2 marks)

Which are TRUE? (A) The trapezoidal rule is exact for linear functions. (B) Simpson's 1/3 rule is exact for cubics. (C) Simpson's 1/3 rule needs an even number of subintervals. (D) The trapezoidal rule is exact for quadratics.

How to think about it

  1. What is asked. The degree of precision of each rule.
  2. Which idea applies. Trapezoid has precision 1, Simpson has precision 3.
  3. Work it out. (A) True. (B) True. (C) True. (D) For x² on [0, 1] with one interval, trapezoid gives 0.5 but the integral is 1/3. False.
  4. Check. Simpson's extra degree comes from symmetry.

Answer: (A), (B) and (C).

Summary

Definite integral
The area under a curve between two limits.
Step size h
The width of each interval, h = (b - a)/n.
Ordinate
A function value at one of the points used by a rule.
Trapezoidal rule
Adds trapezia under straight lines through the points. Weights are 1, 2, 2, ..., 2, 1 times h/2.
Simpson's 1/3 rule
Fits parabolas through three points. Weights are 1, 4, 1 times h/3 for one panel.
Composite rule
The rule applied to many panels, with the results added.
Trapezoidal error
Proportional to h2 and to the second derivative.
Simpson error
Proportional to h4 and to the fourth derivative.
Degree of exactness
Simpson's 1/3 rule is exact for cubic polynomials. The trapezoidal rule is exact for straight lines.
Even number of intervals
Required for the composite Simpson rule.
Tabulated values
Data at equally spaced points, used when there is no formula for f.
Absolute error
The size of the difference between an estimate and the exact value, written without a sign.
Factorial
n! is the product of the whole numbers from 1 to n.

Remember these

  1. Trapezoid weights are 1, 2, 2, ..., 2, 1 with factor h/2. Simpson weights are 1, 4, 2, 4, ..., 4, 1 with factor h/3.
  2. Simpson's 1/3 rule needs an even number of intervals.
  3. Trapezoidal error is O(h2). Simpson error is O(h4).
  4. Simpson's 1/3 rule is exact for cubics, so check it on a cubic before you trust it.
  5. In a table, write the weights before you multiply.
