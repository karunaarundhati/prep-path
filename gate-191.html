CAD/CAM concepts and their integration tools

CAD (computer-aided design) is how a part is drawn and described on a computer, and CAM (computer-aided manufacturing) is how that description is turned into machine instructions. This page explains the main model types, parametric design, the NC code that CAM produces, and the data formats that let the two tools work together.

The idea in plain words

Welcome. Long ago, an engineer drew a part on paper, a draughtsman copied it onto a larger sheet, and a machinist read the drawing by hand to cut the metal. Every step was slow, and a small error could spoil a whole batch. Today the whole chain runs on a computer. The part is drawn in a CAD program (computer-aided design). Then the same computer model is used to plan and run the cutting machine in a CAM program (computer-aided manufacturing).

Think of a recipe book. A good recipe is written once, and it tells the cook what to buy, how to mix it and how long to bake. CAD is the recipe for the part. CAM is the set of cooking steps that a machine follows. If the recipe is changed, the steps can be regenerated automatically, rather than rewritten by hand.

Why does this matter for GATE? In the Machine Design and CIM part of the Robotics and Automation paper, CAD and CAM questions are mostly conceptual. They ask which model type holds volume, which file format carries a solid model between two software packages, what a parametric model is, or what CAM does. Some questions also ask for a simple calculation, such as the length of a toolpath around a circle. Knowing the ideas clearly makes these questions quick.

We will go slowly. We start with what a computer model can store, then build up to the whole workflow.

Key terms

Read this list once, and come back to it when a term feels unfamiliar.

CAD
Computer-aided design, the use of software to create and change a geometric model of a part. Precisely: a digital tool for creating, analysing and documenting product geometry.
CAM
Computer-aided manufacturing, the use of software to plan and control manufacturing. Precisely: software that generates machine tool paths and NC code from a model.
CAE
Computer-aided engineering, the use of software for analysis such as stress, heat or motion. Precisely: simulation tools that test a model before it is made.
Geometric model
A computer description of the shape of a part. Precisely: a set of data, such as points, curves, surfaces or volumes, that defines the geometry.
Wireframe model
A model made of edges and vertices only. Precisely: a skeleton of lines and curves with no faces or volume.
Surface model
A model made of faces with no solid interior. Precisely: a collection of surfaces that bound a shape but do not define a volume.
Solid model
A model with a defined volume, mass and inside. Precisely: a closed boundary that encloses material, so the computer can find volume, mass and interference.
Parametric model
A model whose shape is controlled by named dimensions and rules. Precisely: a model in which changing a dimension or a constraint updates the geometry automatically.
Feature
A meaningful shape element such as a hole, slot or fillet. Precisely: a building block of a feature-based model that carries its own dimensions.
Toolpath
The path followed by the cutting tool. Precisely: the sequence of tool positions and motions that the CAM system generates.
NC code (G-code)
Numerical control instructions that a machine tool reads. Precisely: a text program of commands such as G00 for rapid move and G01 for linear cutting move.
Post-processor
A small program that turns generic toolpath data into the code a specific machine understands. Precisely: the translator between CAM output and a particular controller.
IGES
Initial Graphics Exchange Specification, an older neutral format for curves and surfaces. Precisely: a text or binary format for exchanging geometry between CAD systems.
STEP
Standard for the Exchange of Product model data, ISO 10303. Precisely: a neutral format that carries solid geometry and product information between systems.
STL
Stereolithography file format, which describes a surface as a set of triangles. Precisely: a mesh of triangular facets, widely used for 3D printing.
Lead time
The time from the start of design to the first finished part. Precisely: the total elapsed time of the design and manufacturing chain for one product.

Geometric models: wireframe, surface and solid

A computer model of a part can be stored in three main ways. Each one stores more information than the one before it, and each costs more memory and effort to build.

Wireframe. The simplest model stores only the edges and corners of the part. It looks like a cage made of wire. It is quick to draw and light to store, but it is ambiguous. A wireframe cube and a wireframe box with a hole in it can look the same, because there are no faces to tell the computer what is inside. The computer cannot tell whether a point is inside or outside the part.

Surface. A surface model adds faces. The computer knows where the outside skin of the part is, so the model looks like a finished shape and can be rendered with shading. However, a surface model is like a hollow eggshell. It has an outside but no defined volume, so the computer cannot yet calculate the mass or check whether two parts overlap inside.

Solid. A solid model stores a closed boundary with a clear inside. This is the most complete type. Because the volume is known, the computer can calculate mass, centre of gravity, surface area and volume, and it can check interference between parts. Most modern CAD systems use a boundary representation, in which the solid is defined by its faces, edges and vertices, together with the rules that make them a closed shell.

  Wireframe        Surface             Solid
  edges only       faces, hollow       faces + inside
  +---+            +---+               +---+
  |\  |\           |\  |\              |###|
  | +-+-+          | +-+-+             |###|
  +-+-+ |          +-+-+ |             +-+-+
    |   |            |   |               |   |
  Ambiguous        Outside known,      Volume known,
                   volume unknown      mass computable

The sketch above shows the idea. The solid version is the one you need for mass, volume and interference questions.

Key ideaWireframe gives edges, surface gives skin, solid gives skin plus a defined volume. Only a solid model can answer questions about mass and volume.

TrapA surface model is not a solid, even when it looks complete on the screen. If a question asks for the mass or volume of a part, the model must be a solid.

Which model type lets a computer calculate the mass of a part?

A solid model, because it has a defined volume and inside. A wireframe or a surface model does not define the volume.

Why is a wireframe model ambiguous?

Because it stores only edges and corners. Without faces, the computer cannot tell which side of an edge is material and which side is empty.

Parametric design and feature-based modelling

Suppose you design a bracket with a hole of 10 mm diameter. Later the customer asks for a 12 mm hole and a plate that is 2 mm thicker. In an old drawing, you would have to edit each line by hand. In a parametric model, the hole diameter and the plate thickness are named parameters. You change the value, and the model redraws itself. Every feature that depends on those parameters updates in step.

Think of a dress pattern with a size setting. Change the size from medium to large, and every seam and panel adjusts together. The pattern is defined by rules, not by fixed numbers.

A parametric model usually has three ingredients.

  • Dimensions. Numbers such as a length of 80 mm or a radius of 5 mm.
  • Constraints. Rules such as "these two lines are parallel" or "this hole is centred on that edge".
  • Relations. Equations that link one dimension to another, such as "the slot length is twice the plate width".

Feature-based modelling builds the part from features. A feature is a meaningful element, such as a hole, a slot, a boss or a fillet. Each feature carries its own dimensions. This matches how a machinist thinks: "drill a 10 mm hole here, cut a slot there". It also makes the design easier to change, because you edit a feature rather than a list of lines.

TipWhen you read a parametric question, identify the named parameters first. Then ask which features depend on each parameter. That tells you what changes.

TrapA parametric model is not the same as a model with fixed numbers that happens to be made in a CAD program. The power comes from the links between dimensions. If the links are missing, the model cannot update correctly.

In a parametric model, what happens when one dimension is changed?

The model updates automatically. Features and constraints that depend on that dimension are recalculated, so the geometry stays consistent with the rules.

What is the difference between a dimension and a constraint?

A dimension is a number, such as a length or a diameter. A constraint is a rule about geometry, such as parallel, perpendicular or concentric.

CAM: from a model to toolpaths and NC code

A CAD model describes what the part should look like. It does not say how to make it. CAM fills that gap. The CAM software reads the solid model, chooses a cutting tool, picks the cutting strategy, and computes the path the tool must follow to remove the right material.

The output of the CAM system is a toolpath, which is a list of positions for the cutting tool. Each position is then translated into a line of NC code, which the machine tool reads. The most common NC code uses short words called G-codes and M-codes.

N10 G00 X0 Y0 Z50       (rapid move above the part)
N20 G01 Z-5 F100        (cut down 5 mm at feed 100 mm/min)
N30 G01 X50 Y0          (cut straight along X)
N40 G02 X0 Y0 I-25 J0   (arc around the centre)
N50 G00 Z50             (retract)
N60 M30                 (end of program)

The sample above is a plain text listing, not a complete real machine program. The main point is that G00 is a fast, non-cutting move, and G01 is a controlled cutting move in a straight line.

The CAM system also performs a basic calculation: the length of the path. For a circle of diameter D, the cutting path around the circle has length pi D. This is the same idea used in the Python check at the end of the page.

Length of a circular toolpath = pi D

Here D is the diameter in mm and the length is in mm. For D = 50 mm, the path is pi times 50 = 157.08 mm.

Key ideaCAD says what the part is. CAM says how to cut it. The post-processor turns the generic path into the exact code for one machine.

What is the difference between G00 and G01?

G00 is a rapid move that does not cut, used to go from one place to another. G01 is a linear cutting move at a set feed rate.

Why does the same CAM output need a post-processor?

Different machine controllers use slightly different code. The post-processor converts the toolpath into the code that one specific controller understands.

Data exchange formats: IGES, STEP and STL

Suppose a designer uses one CAD program and the manufacturing team uses another. The two programs store their data in different internal ways, so the model cannot be opened directly. A neutral format solves this. The model is saved into a standard file, and the other program reads that file. Here are the three formats most often met in GATE questions.

  • IGES. An older standard for exchanging curves and surfaces. It works well for surface models, but it is less reliable for complete solids, and it often needs repair when imported.
  • STEP (ISO 10303). A modern standard that carries solid geometry together with product information such as materials and assembly structure. It is the usual choice when a solid model must move between systems.
  • STL. A mesh of small triangles that approximates a surface. It stores only the shape of the surface, not the design intent, and it is the standard input for most 3D printers.
FormatStoresTypical use
IGESCurves and surfacesOlder exchange of surface data
STEPSolid geometry and product dataExchange of solid models between CAD and CAM systems
STLTriangular facets of a surface3D printing and rapid prototyping

GATE loves thisIf a question asks which neutral format carries a solid model between systems, the usual answer is STEP. If it asks which format is a set of triangles for 3D printing, the answer is STL.

TrapAn STL file has no design intent. It does not remember that a hole was 10 mm, or that two faces were parallel. It is a mesh of triangles, so it cannot be edited parametrically.

Which format is the best choice for exchanging a solid model with its product data?

STEP, because it is a neutral standard for solid geometry and product information.

What is a neutral format?

A standard file format that is not tied to one software package, so that different CAD and CAM systems can read and write the same data.

The integrated CAD/CAM workflow

In a modern factory, the tools are joined into one chain. The steps usually run in this order.

  1. Design. The part is drawn as a parametric solid model in CAD.
  2. Analysis. CAE checks the stress, heat or motion of the model before anything is made.
  3. Process planning. The machining method, the tools and the setup are chosen.
  4. Toolpath generation. CAM creates the toolpaths from the model.
  5. Simulation. The toolpath is run on a virtual machine to check for collisions and errors.
  6. Post-processing. The toolpath is converted to the NC code for the real machine.
  7. Machining and inspection. The part is cut, then measured, often on a coordinate measuring machine.

Notice that the model is the single source of truth. A change in the design flows through analysis, toolpaths and code. This is the main reason an integrated workflow is faster and more accurate than a paper chain.

Key ideaIn an integrated workflow, one model feeds every step. Changes flow forward automatically, and errors are caught before metal is cut.

Why is simulation placed before post-processing?

Because it is cheaper and safer to find a collision or an error on a virtual machine than on a real one. Post-processing produces the code for the real machine, so errors must be removed first.

What does CAE add to the chain?

Analysis of the design, such as stress, heat or motion, before the part is made. This catches weak designs early.

Benefits: lead time, accuracy and change

Why do companies invest in CAD and CAM? Three benefits explain most of it.

  • Shorter lead time. The time from idea to finished part shrinks, because drawings, analyses and programs are generated from one model rather than typed out by hand. The lead time reduction is found from the old and new times: (old - new)/old.
  • Better accuracy. The machine follows the computer path exactly, so the dimensions repeat from part to part. Human copying errors are removed.
  • Easy change. A parametric model can be changed in minutes. The toolpaths and code can be regenerated, instead of rewritten by hand.

Worked example. A part used to take 12 days from design to first part. With an integrated CAD/CAM chain it takes 3 days.

  1. Time saved: 12 - 3 = 9 days.
  2. Reduction in percent: 100 times 9/12 = 75 percent.

TrapDo not confuse a reduction in lead time with a reduction in the cost of material. A CAD/CAM chain changes the time and the accuracy, not the amount of material in the part.

A design takes 20 days by hand and 5 days with CAD/CAM. What is the percent reduction?

(20 - 5)/20 = 15/20 = 75 percent.

Which benefit comes most directly from a parametric model?

Easy change. Edits to one dimension update the whole model, and the toolpaths can be regenerated.

Solved GATE-style problems

These problems are original, written in the GATE style, and they are not copied from any real exam paper. Try the "How to think about it" steps yourself before you read the answer.

Which model holds mass?

Which type of computer model lets the software calculate the mass and volume of a part directly? (MCQ: choose one of wireframe, surface, solid, or sketch.)

How to think about it

  1. What is asked. The model type that defines a volume.
  2. Which idea applies. A solid model has a closed boundary with a defined inside.
  3. Work it out. Wireframe has only edges. A surface has faces but no defined volume. A sketch is a flat outline. Only a solid defines the volume and the mass.
  4. Check. This matches the earlier explanation that only a solid can answer mass questions.

Answer: solid.

Toolpath length around a circle

A CAM toolpath follows a full circle of diameter 50 mm. What is its length, in mm, to two decimal places? (NAT: enter a number.)

How to think about it

  1. What is asked. The length of the circular path.
  2. Which idea applies. Circumference = pi D.
  3. Work it out. pi times 50 = 157.08 mm.
  4. Check. A circle of diameter 50 mm has a circumference a little more than three times its diameter, as expected from pi.

Answer: 157.08 mm.

Statements about CAD and CAM

Which of the following statements about CAD, CAM and data formats are correct? Select all that apply. (MSQ)

  • (A) In a parametric model, changing a named dimension updates the dependent features.
  • (B) An STL file stores the design intent of each feature.
  • (C) STEP is a neutral standard for solid geometry and product data.
  • (D) A post-processor converts generic toolpath data into code for a specific machine.

How to think about it

  1. What is asked. Which statements are true. More than one may be correct.
  2. Which idea applies. Parametric links, the nature of an STL mesh, the role of STEP, and the role of a post-processor.
  3. Work it out. (A) True: that is the definition of a parametric update. (B) False: STL is a triangle mesh with no design intent. (C) True: STEP is ISO 10303. (D) True: that is the job of the post-processor.
  4. Check. Statement (B) claims something the mesh format does not store, so it must be false.

Answer: (A), (C) and (D) are correct.

Percent reduction in lead time

A new bracket took 40 days from design to first part by hand. With an integrated CAD/CAM chain it takes 10 days. What is the percent reduction in lead time? (NAT: enter a number.)

How to think about it

  1. What is asked. The percent reduction.
  2. Which idea applies. Reduction = (old - new)/old times 100.
  3. Work it out. (40 - 10)/40 = 30/40 = 0.75, so the reduction is 75 percent.
  4. Check. The new time is one quarter of the old, so a 75 percent reduction is consistent.

Answer: 75 percent.

Feature that updates with a parameter

In a parametric model, a slot length is defined as twice the plate width. The plate width is changed from 40 mm to 60 mm. What happens to the slot length? (MCQ: (A) stays at 80 mm, (B) becomes 120 mm, (C) becomes 60 mm, (D) becomes 30 mm.)

How to think about it

  1. What is asked. The new slot length after a parameter change.
  2. Which idea applies. The relation slot length = 2 times plate width is stored in the model, so the slot updates.
  3. Work it out. Slot length = 2 times 60 = 120 mm.
  4. Check. The old slot was 2 times 40 = 80 mm, and the new one is 120 mm, which is consistent with the rule.

Answer: (B), 120 mm.

Number of chords for a circle with a given chord error

A CAM system approximates a circle of radius 25 mm with straight chords. The chord error (the largest gap between chord and arc) must not exceed 0.01 mm. Using e = R(1 - cos(theta/2)) and a whole number of equal segments, how many segments are needed? (NAT: enter a whole number.)

How to think about it

  1. What is asked. The number of equal chords around the full circle.
  2. Which idea applies. First find the largest angle theta per segment from e = R(1 - cos(theta/2)), then divide 2 pi by theta.
  3. Work it out. cos(theta/2) = 1 - e/R = 1 - 0.0004 = 0.9996. So theta/2 = arccos(0.9996) = 0.02828 rad, and theta = 0.05657 rad (about 3.24 degrees). Then 2 pi/theta = 111.07. Rounding up to a whole number gives 112 segments.
  4. Check. 112 segments of 3.24 degrees each cover 112 times 3.24 = 363 degrees, which is just over a full turn, so the rounding up is safe.

Answer: 112 segments.

Choosing the exchange format

A designer must send a finished solid model, with its material and assembly data, from one CAD system to a CAM system in another company. Which neutral format is the best choice, and why? (Conceptual question, answer in one or two sentences.)

How to think about it

  1. What is asked. The best neutral format for a solid model with product data.
  2. Which idea applies. Compare IGES, STEP and STL by what they store.
  3. Work it out. IGES is for curves and surfaces and is less reliable for complete solids. STL keeps only triangles and no product data. STEP stores solid geometry together with product information, and it is a neutral ISO standard.
  4. Check. The model needs both the solid shape and the data, so STEP meets both needs.

Answer: STEP, because it is a neutral standard that carries solid geometry and product data between systems.

import math
D = 50.0
circ = math.pi * D
print("Circle circumference (mm):", round(circ, 2))
manual, cad = 12.0, 3.0
print("Lead time reduction (%):", round(100 * (manual - cad) / manual, 1))
R, e = 25.0, 0.01
theta = 2 * math.acos(1 - e / R)
segments = 2 * math.pi / theta
print("Angle per segment (deg):", round(math.degrees(theta), 3))
print("Segments needed (exact):", round(segments, 2))
print("Segments to use:", math.ceil(segments))

Exam-level practice

Exam-level 1: Homogeneous transform (NAT, 2 marks)

In CAD, the point (2, 1) is rotated by 90° about the origin and then translated by (3, 0). Find the result.

How to think about it

  1. What is asked. The transformed point.
  2. Which idea applies. Rotation (x, y) → (−y, x), then add the shift.
  3. Work it out. (−1, 2) + (3, 0) = (2, 2).
  4. Check. The code uses a 3 × 3 homogeneous matrix.
M = [[0, -1, 3], [1, 0, 0], [0, 0, 1]]
p = [2, 1, 1]
print([sum(M[i][j] * p[j] for j in range(3)) for i in range(2)])

[2, 2]

Answer: (2, 2).

Exam-level 2: Bezier point (NAT, 2 marks)

A cubic Bezier curve has control points (0, 0), (1, 2), (3, 2), (4, 0). Find the point at t = 0.5.

How to think about it

  1. What is asked. B(0.5).
  2. Which idea applies. B(t) = Σ C(3, i)(1 − t)3−itiPi.
  3. Work it out. Weights 1/8, 3/8, 3/8, 1/8. x = (0 + 3 + 9 + 4)/8 = 2. y = (0 + 6 + 6 + 0)/8 = 1.5.
  4. Check. The code computes it.
P = [(0, 0), (1, 2), (3, 2), (4, 0)]; w = [1/8, 3/8, 3/8, 1/8]
print(sum(a * p[0] for a, p in zip(w, P)), sum(a * p[1] for a, p in zip(w, P)))

2.0 1.5

Answer: (2, 1.5).

Exam-level 3: CAD/CAM integration (MSQ, 2 marks)

Which are TRUE? (A) STEP is a neutral data exchange format. (B) CAPP links design and manufacturing. (C) CAM can generate toolpaths from CAD geometry. (D) IGES stores only 2D drawings.

How to think about it

  1. What is asked. Integration facts.
  2. Which idea applies. Neutral formats let different systems share models.
  3. Work it out. (A) True. (B) True. (C) True. (D) IGES holds 3D curves and surfaces too. False.
  4. Check. STEP also carries product data beyond geometry.
