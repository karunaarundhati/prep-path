Informed search: A*, Greedy Best-First

Informed search uses a guess about how far each state is from the goal. That guess is called a heuristic. A* and Greedy Best-First are the two standard informed searches. A* stays optimal when the guess is well behaved, while greedy search is faster but can return a worse path. GATE Data Science and AI often asks you to trace A* on a small graph with given heuristic values.

The idea in plain words

Suppose you are driving to a friend's house in a city. The uninformed search from the last topic would try every road in turn, like a blind explorer. A sensible driver instead glances at a map and prefers roads that point towards the friend's street. That glance is a heuristic: a rough estimate of how far you still have to go.

Informed search uses this estimate to choose which node to expand next. Two standard methods are:

  • Greedy Best-First search: always expand the node that looks closest to the goal, according to the heuristic alone.
  • A* search: expand the node with the smallest total estimate, which is the cost so far plus the estimated cost still to go.

Why does this matter for GATE? The Data Science and AI paper asks you to trace A* on a small graph, to say whether a heuristic is admissible, and to compare greedy search with A*. Every term is defined below, and the traces are checked with Python.

Key terms

Heuristic h(n)
An estimate of the cheapest cost from node n to a goal. Precise: a function of the node, not a measured value.
True cost h*(n)
The actual cheapest cost from n to a goal. Precise: the minimum path cost, which the heuristic tries to estimate.
Path cost g(n)
The cost paid so far from the start to n. Precise: the sum of step costs along the path found.
Evaluation f(n)
The number used to rank the frontier. Precise: the value that decides which node is expanded next.
Admissible heuristic
Never overestimates. Precise: h(n) is at most h*(n) for every node n.
Consistent heuristic
Never drops too fast along an edge. Precise: h(u) is at most c(u, v) + h(v) for every edge, and h(goal) = 0.
Greedy Best-First search
Expands the node with the smallest h(n). Precise: uses f(n) = h(n) only.
A* search
Expands the node with the smallest g(n) + h(n). Precise: uses f(n) = g(n) + h(n).
Optimal
Returns the cheapest solution. Precise: a property of the search, not of the heuristic alone.
Complete
Finds a solution whenever one exists. Precise: a search property.
Informed search
Search that uses a heuristic. Precise: contrasted with uninformed search, which uses only the graph and costs.

Concept 1: Heuristics, admissible and consistent

A heuristic is only as good as its promises. Two promises matter for GATE.

Admissible: never too pessimistic

A heuristic is admissible if it never overestimates the true cost. For every node n:

h(n) ≤ h*(n)

If the estimate is never bigger than the truth, then an A* search that trusts it will never throw away the best path by mistake. Think of a shop assistant who says a jacket costs at least 30 when it actually costs 40. Saying "at least 30" is safe. Saying "at most 30" is not.

Consistent: no sudden drops

A heuristic is consistent if, for every edge from u to v with cost c(u, v):

h(u) ≤ c(u, v) + h(v), and h(goal) = 0

In words: the estimate at u cannot be larger than the step cost to v plus the estimate at v. A consistent heuristic is always admissible, as long as h(goal) = 0. Consistency is the stronger promise, and it lets A* avoid revisiting nodes.

A worked check

Use the graph from the earlier topics: S connects to A (cost 1) and B (cost 4); A connects to C (cost 5) and B (cost 2); B connects to D (cost 1); C connects to G (cost 2); D connects to G (cost 3). Take the heuristic h(S) = 6, h(A) = 5, h(B) = 4, h(C) = 2, h(D) = 3, h(G) = 0. The Python code computes the true costs to the goal and tests both promises.

Key ideaAdmissible means "never too pessimistic". Consistent means "never drops too fast along an edge", and it implies admissible.

TrapA heuristic that is close to the truth is not automatically admissible. One overestimate, even by 1, is enough to break the optimality guarantee.

If h(n) = 9 but the true cost from n to the goal is 7, is h admissible at n?

No. The estimate 9 is bigger than the truth, 7, so it overestimates.

Does admissible imply consistent?

No. A heuristic can be admissible but still drop too fast along an edge. Consistency is the stronger property.

Concept 2: Greedy Best-First search

Greedy Best-First search is the impatient one. At each step it expands the frontier node that looks closest to the goal, using only the heuristic. It ignores how much cost has already been paid.

  1. Put the start node in a priority queue, ordered by h(n).
  2. Remove the node with the smallest h(n). If it is the goal, stop.
  3. Add its unvisited neighbours, each ordered by their h values.
  4. Repeat.

TrapGreedy search is not optimal. Because it ignores g(n), it can walk into a costly corridor that merely looks close to the goal. Its path may be much more expensive than the best one.

What does greedy search use to rank nodes?

Only h(n), the heuristic estimate. The cost paid so far, g(n), is ignored.

Is greedy search guaranteed to find the cheapest path?

No. It can return a path whose cost is higher than the optimum, as the trace in Concept 5 shows.

Concept 3: A* search, f = g + h

A* balances the two. It ranks each node by f(n) = g(n) + h(n): the cost paid so far, plus the estimate of the cost still to go. A node that is cheap to reach and near the goal gets a low f, so it is expanded early. A node that is expensive so far gets pushed back, even if its heuristic looks good.

The steps

  1. Put the start node in a priority queue with f = 0 + h(start).
  2. Remove the node with the smallest f. If it is the goal, stop.
  3. For each neighbour, compute g = g(current) + step cost, then f = g + h. If this g is better than any earlier value for that neighbour, record it and push it.
  4. Repeat.

Why A* is optimal

If h is admissible, A* returns an optimal path, because it never delays the optimal path behind a worse one. If h is consistent, the f values along any path never decrease, so A* expands nodes in order of non-decreasing f, and it never needs to reopen a node it has already expanded.

Key ideaA* is optimal with an admissible heuristic. It is also the same as UCS when h = 0, and it is faster when h is informative.

GATE loves thisExam questions often give a graph with g values and h values and ask for the A* path. Compute f = g + h at each step, expand the smallest, and stop at the goal.

A node has g = 3 and h = 4. What is its f value?

f = g + h = 3 + 4 = 7.

Why does A* need g as well as h?

Without g, A* would ignore the cost already paid, and it could choose an expensive route that merely looks close to the goal. Adding g keeps the total cost in view.

Concept 4: Comparing A*, greedy search and UCS

All three methods are priority-queue searches. They differ only in the ranking they use.

MethodRanking f(n)Optimal?Typical behaviour
UCSg(n)YesExplores everything cheaper than the solution
Greedy Best-Firsth(n)NoFast, heads straight for the goal
A*g(n) + h(n)Yes, with an admissible heuristicBetween the two, guided and still optimal
Which method is A* when the heuristic is zero everywhere?

Uniform-cost search, since f = g + 0 = g.

Which method is A* when the cost g is ignored?

Greedy Best-First search, since f = h.

Concept 5: Tracing A* and greedy search on one graph

The code below checks the heuristic and runs both searches. It computes the true costs to the goal with Dijkstra's method, tests admissibility and consistency, then prints the expansion order and path of A* and of greedy search.

import heapq

graph = {
    "S": [("A", 1), ("B", 4)],
    "A": [("S", 1), ("C", 5), ("B", 2)],
    "B": [("S", 4), ("A", 2), ("D", 1)],
    "C": [("A", 5), ("G", 2)],
    "D": [("B", 1), ("G", 3)],
    "G": [("C", 2), ("D", 3)],
}
start, goal = "S", "G"
h = {"S": 6, "A": 5, "B": 4, "C": 2, "D": 3, "G": 0}

# true cheapest cost to goal, by Dijkstra from the goal
dist = {goal: 0}
pq = [(0, goal)]
while pq:
    d, u = heapq.heappop(pq)
    if d > dist[u]:
        continue
    for v, c in graph[u]:
        if d + c < dist.get(v, 10**9):
            dist[v] = d + c
            heapq.heappush(pq, (d + c, v))

print("true cost to goal:", " ".join(f"{n}={dist[n]}" for n in sorted(dist)))
print("heuristic:", " ".join(f"{n}={h[n]}" for n in sorted(h)))
print("admissible:", all(h[n] <= dist[n] for n in h))
consistent = all(h[u] <= c + h[v] for u in graph for v, c in graph[u]) and h[goal] == 0
print("consistent:", consistent)

def path_cost(path):
    return sum(c for u, v in zip(path, path[1:]) for nb, c in graph[u] if nb == v)

def best_first(f_of):
    frontier = [(f_of(start, 0), start)]
    best_g = {start: 0}
    parent = {start: None}
    done = set()
    order = []
    while frontier:
        _, node = heapq.heappop(frontier)
        if node in done:
            continue
        done.add(node)
        order.append(node)
        if node == goal:
            break
        for nb, c in graph[node]:
            g = best_g[node] + c
            if nb not in best_g or g < best_g[nb]:
                best_g[nb] = g
                parent[nb] = node
                heapq.heappush(frontier, (f_of(nb, g), nb))
    path = []
    node = goal
    while node is not None:
        path.append(node)
        node = parent[node]
    return order, path[::-1]

order, p = best_first(lambda n, g: g + h[n])
print("A* expansion order:", " ".join(order))
print("A* path:", " ".join(p), "cost", path_cost(p))
order, p = best_first(lambda n, g: h[n])
print("greedy expansion order:", " ".join(order))
print("greedy path:", " ".join(p), "cost", path_cost(p))
true cost to goal: A=6 B=4 C=2 D=3 G=0 S=7
heuristic: A=5 B=4 C=2 D=3 G=0 S=6
admissible: True
consistent: True
A* expansion order: S A B D G
A* path: S A B D G cost 7
greedy expansion order: S B D G
greedy path: S B D G cost 8

Read the output. A* expands 5 nodes and returns the optimal cost-7 path. Greedy search expands 4 nodes, jumping to B because its h is smaller, but it returns the costlier cost-8 path. From S, A has f = 1 + 5 = 6 and B has f = 4 + 4 = 8, so A* goes to A first.

Key ideaA* chose A first because its f value 6 was lower than B's 8, even though B looked closer to the goal by h alone.

Why did greedy search choose B first, when A* chose A?

Greedy compares only h. B has h = 4, which is smaller than A's h = 5. A* compares g + h, where A's total is 6 and B's is 8, so A wins.

Why is the A* path cost 7 and not 8?

A* reaches B through A at cost 1 + 2 = 3, which is cheaper than the direct cost 4. Then B to D to G adds 1 + 3, giving 3 + 1 + 3 = 7.

The A* ranking

In A* search, the frontier is ordered by which value? (MCQ, select one)

(A) h(n) only
(B) g(n) + h(n)
(C) g(n) − h(n)
(D) g(n) only

How to think about it

  1. What is asked. The ranking used by A*.
  2. Which idea applies. A* adds the cost so far to the estimate.
  3. Work it out. (A) is greedy search. (D) is uniform-cost search. (C) subtracts, which is not A*. (B) adds the two.
  4. Check. The formula sheet lists f = g + h for A*.

Answer: (B).

Computing f

A node has g = 3 and h = 4. What is its f value? (NAT)

How to think about it

  1. What is asked. The A* value f.
  2. Which idea applies. f = g + h.
  3. Work it out. f = 3 + 4 = 7.
  4. Check. Greedy search would rank this node by h alone, giving 4, which is a different ranking.

Facts about heuristics and search

Select all statements that are correct. (MSQ)

(A) An admissible heuristic never overestimates the true cost to the goal.
(B) With an admissible heuristic on a tree search, A* returns an optimal path.
(C) Greedy Best-First search always returns an optimal path.
(D) A consistent heuristic with h(goal) = 0 is admissible.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. The definitions of admissible and consistent, and the optimality of A*.
  3. Work it out. (A) is the definition. (B) is the standard optimality result. (C) is false, since greedy search ignores g. (D) is true: consistency implies admissibility when the goal estimate is zero.
  4. Check. The example in Concept 5 has greedy search returning cost 8 against the optimum 7, which confirms (C) is false.

Answer: (A), (B) and (D). Statement (C) is false.

Cost of the A* path

On the graph of Concept 5 with heuristic h(S) = 6, h(A) = 5, h(B) = 4, h(C) = 2, h(D) = 3 and h(G) = 0, what is the cost of the path that A* returns? (NAT)

How to think about it

  1. What is asked. The cost of the A* path.
  2. Which idea applies. Trace the smallest f at each step.
  3. Work it out. S has f = 6. Expand S: A has f = 1 + 5 = 6, B has f = 4 + 4 = 8. Expand A (f = 6): B reached through A at g = 3, so f = 7. Expand B (f = 7): D at g = 4, f = 7. Expand D: G at g = 7, f = 7. G is the goal. Path S, A, B, D, G costs 7.
  4. Check. The Python output in Concept 5 prints A* path S A B D G with cost 7.

Answer: 7

Cost of the greedy path

On the same graph and heuristic as the previous problem, what is the cost of the path returned by Greedy Best-First search? (NAT)

How to think about it

  1. What is asked. The cost of the greedy path.
  2. Which idea applies. Greedy ranks by h alone.
  3. Work it out. From S, B has h = 4 and A has h = 5, so B is chosen. From B, D has h = 3, so D is chosen. From D, G is the goal. Path S, B, D, G costs 4 + 1 + 3 = 8.
  4. Check. The Python output prints greedy path S B D G with cost 8.

Answer: 8

A* with no heuristic

If h(n) = 0 for every node, A* behaves like: (MCQ, select one)

(A) depth-first search
(B) breadth-first search
(C) uniform-cost search
(D) greedy Best-First search

How to think about it

  1. What is asked. The method A* becomes when h = 0.
  2. Which idea applies. f = g + h.
  3. Work it out. With h = 0, f = g, so nodes are expanded in order of path cost. That is uniform-cost search.
  4. Check. Greedy search would need f = h, which is 0 everywhere here, so it cannot be the answer.

Answer: (C).

How far can h(A) be raised

On the graph of Concept 5, the true cost from A to the goal is 6. What is the smallest integer value of h(A) that would make the heuristic inadmissible, keeping the other values unchanged? (NAT)

How to think about it

  1. What is asked. The smallest integer that breaks admissibility at A.
  2. Which idea applies. Admissible means h(n) ≤ h*(n).
  3. Work it out. h*(A) = 6. Values up to 6 are allowed. The next integer, 7, is an overestimate, so it is inadmissible.
  4. Check. The current h(A) = 5 is below 6, so it is admissible, which matches the Python output.

Answer: 7

Which statements about A* are true

Select all that apply. (MSQ)

(A) Greedy Best-First search may return a non-optimal path.
(B) With a consistent heuristic, A* never needs to reopen a node it has already expanded.
(C) With a consistent heuristic, A* expands nodes in non-decreasing order of f.
(D) An overestimating heuristic always makes A* faster and still optimal.

How to think about it

  1. What is asked. Which statements about A* and greedy search are true.
  2. Which idea applies. The optimality and consistency results from Concept 3.
  3. Work it out. (A) is true: the trace gives cost 8 against 7. (B) is true: consistency ensures a node is first reached at its best g. (C) is true: f never decreases along a path. (D) is false: overestimating can cause the optimal path to be missed.
  4. Check. Statement (D) contradicts the admissibility guarantee, which is the reason A* is optimal.

Answer: (A), (B) and (C). Statement (D) is false.

Exam-level 1: A* expansion order (MCQ, 2 marks)

Graph: S→A cost 1, S→B cost 4, A→B cost 2, A→G cost 6, B→G cost 2. Heuristic: h(S) = 5, h(A) = 4, h(B) = 2, h(G) = 0. Using A* graph search, what is the cost of the path found? (A) 5 (B) 6 (C) 7 (D) 8

How to think about it

  1. What is asked. The cost of the path A* returns.
  2. Which idea applies. Expand the node with the smallest f = g + h.
  3. Work it out. f(A) = 1 + 4 = 5, f(B) = 4 + 2 = 6. Expand A: B via A has g = 3, f = 5. G via A has f = 7. Expand B (f = 5): G with g = 5. Expand G: cost 5.
  4. Check. The code runs A*.
import heapq
G = {"S": [("A", 1), ("B", 4)], "A": [("B", 2), ("G", 6)], "B": [("G", 2)], "G": []}
h = {"S": 5, "A": 4, "B": 2, "G": 0}
pq = [(h["S"], 0, "S", "S")]; best = {}
while pq:
    f, g, u, path = heapq.heappop(pq)
    if u == "G": print(path, g); break
    if best.get(u, 1e9) <= g: continue
    best[u] = g
    for v, w in G[u]: heapq.heappush(pq, (g + w + h[v], g + w, v, path + v))

SABG 5

Answer: (A).

Exam-level 2: Admissibility (MSQ, 2 marks)

With the graph above, which are TRUE? (A) The heuristic is admissible. (B) The heuristic is consistent. (C) Greedy best-first search (using h only) finds the optimal path here. (D) A* with h = 0 is uniform cost search.

How to think about it

  1. What is asked. Properties of the heuristic and searches.
  2. Which idea applies. Admissible means h(n) ≤ true cost to goal. Consistent means h(u) ≤ c(u, v) + h(v) for every edge.
  3. Work it out. True costs: S 5, A 4, B 2. All h equal true cost, so admissible. Edges: S→A 5 ≤ 1 + 4, S→B 5 ≤ 4 + 2, A→B 4 ≤ 2 + 2, A→G 4 ≤ 6, B→G 2 ≤ 2. Consistent. Greedy picks B first (h = 2), then G, cost 6, not optimal. (D) True.
  4. Check. (C) fails because greedy ignores the cost already paid.
