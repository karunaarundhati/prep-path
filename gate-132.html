Sequential circuits: flip-flops & counters

Combinational circuits forget everything as soon as the inputs change. Sequential circuits remember. The flip-flop is the basic memory cell, and a counter is a set of flip-flops that steps through a sequence of numbers on each clock pulse. This topic explains the four flip-flop types, how to read and write their tables, and how ripple and synchronous counters work.

The idea in plain words

Imagine a light switch with a memory. You press it, and the light stays in the new state until you press again. A flip-flop is an electronic version of that idea. It stores one bit, a 0 or a 1, and it keeps that value until a control signal tells it to change. The control signal is usually a clock, a signal that switches between high and low in a steady rhythm. Each change of the clock is a clock pulse, and most flip-flops only look at their inputs at the instant of the change.

A sequential circuit is a circuit built from flip-flops and gates. Its output depends on the present inputs and on what it stored earlier. A counter is the simplest useful example. It is a sequential circuit that steps through a fixed list of states, such as 00, 01, 10, 11, and then starts again. Counters are used for timing, for dividing clock frequencies and for controlling the order of operations in a robot.

In GATE Robotics and Automation (RA) and Data Science and AI (DA), you will be asked to trace a flip-flop's output over several clock pulses, to fill in an excitation table, or to find the number of flip-flops needed for a counter. These are all step-by-step tasks, so we will practise each one with a clear method.

Key terms

Sequential circuit
A circuit whose output depends on present inputs and stored state. Plain meaning: a circuit with memory.
Flip-flop
A one-bit memory cell. It stores 0 or 1 and changes only at a clock edge.
Clock
A signal that alternates between 0 and 1 at a steady rate. Each change is an edge.
Edge triggering
The flip-flop reads its inputs only at a rising edge (0 to 1) or a falling edge (1 to 0).
Present state, Q
The value stored before a clock edge.
Next state, Q+
The value stored after a clock edge. Also written Q(t+1).
Characteristic equation
An equation that gives Q+ in terms of the inputs and Q.
Excitation table
A table that gives the inputs needed to move from Q to a chosen Q+.
Don't care (X)
An input value that does not matter for the result. Written X.
Counter
A sequential circuit that cycles through a fixed list of states on each clock pulse.
Ripple counter
A counter in which each flip-flop is clocked by the output of the previous one, so the changes ripple along the chain. Also called asynchronous.
Synchronous counter
A counter in which all flip-flops share the same clock, so they change together.
Mod-N counter
A counter that cycles through N states, 0 to N − 1, and then returns to 0.

Step 1: The four flip-flop types

There are four common flip-flop types. Each one has its own input rule. The easiest way to learn them is to see what each does to the stored bit when a clock edge arrives.

  • SR flip-flop: S sets the output to 1, R resets it to 0, and S = R = 1 is not allowed. When S = R = 0, it holds.
  • D flip-flop: the output copies D at the clock edge. It is the simplest, and the most used for storing data.
  • JK flip-flop: J acts like S and K acts like R, but J = K = 1 is allowed and makes the output toggle, which means flip to the opposite value.
  • T flip-flop: when T = 1 it toggles on each clock edge. When T = 0 it holds.

Each type has a characteristic equation, which gives the next state:

SR: Q+ = S + R'Q (with SR = 0)
D: Q+ = D
JK: Q+ = JQ' + K'Q
T: Q+ = T ⊕ Q = TQ' + T'Q

Symbols: Q is the present state, Q+ is the next state, and Q' is the complement of Q. The equations say that the next value depends on the present value and the inputs.

Worked example: the JK equation on a number

Take Q = 1, J = 0 and K = 1. Find Q+ step by step:

  1. JQ' = 0 × 0 = 0, because Q' = 0.
  2. K' = 0, so K'Q = 0 × 1 = 0.
  3. Q+ = 0 + 0 = 0.
  4. Meaning: K = 1 with J = 0 is a reset, so the output goes to 0. The equation agrees.

Key ideaThe JK flip-flop is the most general of the four. The others can be made from it. A D flip-flop is a JK with J = D and K = D', and a T flip-flop is a JK with J = K = T.

TrapFor an SR flip-flop, the input S = R = 1 is forbidden. Do not assume it is a toggle. That behaviour belongs to the JK flip-flop.

What is Q+ for a D flip-flop with D = 1 and Q = 0?

Q+ = D = 1. The D flip-flop ignores the present state, so the answer is 1 whatever Q was.

What does a T flip-flop do when T = 1 and Q = 1?

It toggles, so Q+ = T ⊕ Q = 1 ⊕ 1 = 0. The output goes from 1 to 0 at the clock edge.

Step 2: Excitation tables

A characteristic table tells you the next state for given inputs. An excitation table does the reverse. It says: if I want the output to go from Q to Q+, what inputs must I apply? This is the question designers ask, and it is a common GATE question.

Let us build the excitation table of the JK flip-flop with a short Python check. For each present state Q and each desired next state, the code finds which (J, K) pairs give that result. If every valid pair has the same J, that value is required. If the valid pairs disagree, the value is a don't care, X.

def jk_next(Q, J, K):
    return (J & (1 - Q)) | ((1 - K) & Q)

print("Q  Q+ | J K")
for Q in [0, 1]:
    for Qn in [0, 1]:
        needs = []
        for J in [0, 1]:
            for K in [0, 1]:
                if jk_next(Q, J, K) == Qn:
                    needs.append((J, K))
        Js = sorted({j for j, k in needs})
        Ks = sorted({k for j, k in needs})
        J_txt = str(Js[0]) if len(Js) == 1 else "X"
        K_txt = str(Ks[0]) if len(Ks) == 1 else "X"
        print(Q, " ", Qn, "|", J_txt, K_txt)
Q  Q+ | J K
0   0 | 0 X
0   1 | 1 X
1   0 | X 1
1   1 | X 0

Read the rows. To go from 0 to 0, J must be 0, and K can be anything (X). To go from 0 to 1, J must be 1, and K can be anything. To go from 1 to 0, K must be 1, and J can be anything. To stay at 1, K must be 0. This is the standard JK excitation table, and it is worth memorising because it appears in many questions.

TipRemember the pattern: to set a bit, J = 1. To reset it, K = 1. To hold a 1, K = 0. To hold a 0, J = 0. The X entries are free choices, which can make a circuit simpler.

Which JK inputs take a flip-flop from 1 to 0?

K = 1. J can be 0 or 1, so J is a don't care.

Why is J a don't care when Q = 1 and Q+ = 0?

Because when Q = 1 and K = 1, the flip-flop resets to 0 whatever J is. The J input has no effect in that case.

Step 3: Edge triggering and reading the clock

A flip-flop with a level-triggered input responds for as long as the clock is high. A flip-flop that is edge-triggered responds only at the instant the clock changes, usually from 0 to 1 (rising edge) or from 1 to 0 (falling edge). Most counters and registers use edge-triggered flip-flops, because they change only once per pulse.

Why does this matter? Suppose a level-triggered D flip-flop is high for a long pulse, and D changes during that time. The output would follow D through the whole pulse. An edge-triggered flip-flop ignores D except at the edge, so its output changes once per pulse.

TrapRead the question carefully. Some questions say "negative edge triggered", which means the flip-flop changes at the falling edge. Others say "positive edge triggered". The answer changes with the edge, so mark it on your working.

What is the difference between a level-triggered and an edge-triggered flip-flop?

A level-triggered flip-flop responds while the clock is at a certain level. An edge-triggered flip-flop responds only at the instant of a rising or falling edge.

Why do counters usually use edge-triggered flip-flops?

Because the counter must change exactly once per clock pulse. An edge-triggered flip-flop changes only at the edge, so each pulse produces one step.

Step 4: Ripple (asynchronous) counters

The simplest counter is a chain. Use T flip-flops with T = 1, so each flip-flop toggles on its clock edge. Connect the clock of the first flip-flop to the external clock. Then connect the output of each flip-flop to the clock of the next one. Because the changes travel down the chain one after another, this is called a ripple counter, or an asynchronous counter.

Picture a row of dominoes. The first domino falls, which knocks over the second, and so on. The last domino falls a little later than the first. In the same way, the last output of a ripple counter settles a little later than the first.

Consider a 2-bit ripple counter with negative-edge triggered T flip-flops. Q0 is the first flip-flop, and Q1 is the second, which is clocked by Q0. Q0 toggles on each falling clock edge. Q1 toggles only when Q0 falls from 1 to 0. Start from Q1Q0 = 00 and trace the pattern in Python:

state = [0, 0]          # [Q1, Q0]
def ripple_pulse(state):
    Q1, Q0 = state
    new_Q0 = 1 - Q0                      # Q0 toggles on every falling clock edge
    new_Q1 = Q1
    if Q0 == 1 and new_Q0 == 0:          # Q0 fell from 1 to 0, so Q1 toggles
        new_Q1 = 1 - Q1
    return [new_Q1, new_Q0]

print("pulse | Q1 Q0 | decimal")
for n in range(1, 12):
    state = ripple_pulse(state)
    print(n, "|", state[0], state[1], "|", state[0] * 2 + state[1])
pulse | Q1 Q0 | decimal
1 | 0 1 | 1
2 | 1 0 | 2
3 | 1 1 | 3
4 | 0 0 | 0
5 | 0 1 | 1
6 | 1 0 | 2
7 | 1 1 | 3
8 | 0 0 | 0
9 | 0 1 | 1
10 | 1 0 | 2
11 | 1 1 | 3

Read the trace. The count goes 1, 2, 3, 0, and then repeats. That is a mod-4 counter, because it has four states, 0 to 3. After 11 pulses from 00, the count is 3. The pattern is 11 = 2 × 4 + 3, so the remainder is 3. This is a quick check you can use in exams.

TrapIn a ripple counter, the bits do not change at exactly the same instant. The state can briefly show a wrong value while the changes ripple. This is the main disadvantage, and it limits the speed of the counter.

GATE loves thisTo find the count after n pulses in a mod-N counter, take n modulo N. Then read the state for that remainder. This works for ripple and synchronous counters alike.

A mod-4 ripple counter starts at 00. What is the count after 6 pulses?

6 mod 4 = 2, so the count is 2, which is 10 in binary.

What is the main drawback of a ripple counter?

The flip-flops change at different times, so the output can show wrong intermediate states. The total delay also grows with the number of bits.

Step 5: Synchronous counters and mod-N counters

In a synchronous counter all flip-flops share the same clock. Each flip-flop decides whether to toggle, using logic that looks at the other bits. This removes the ripple delay, so all bits change at the same time.

A 2-bit synchronous up counter is easy to design with JK flip-flops. Use J0 = K0 = 1, so Q0 toggles on every pulse. For Q1, toggle only when Q0 = 1, so J1 = K1 = Q0. The next states follow directly.

A mod-N counter stops at N − 1 and returns to 0. For a mod-5 counter, the states are 0, 1, 2, 3, 4 and then 0 again. The number of flip-flops is the smallest n with 2n ≥ N, which is:

n = ⌈log₂ N⌉

Symbols: ⌈ ⌉ means round up to the next whole number. For N = 5, log₂ 5 = 2.32, which rounds up to 3. So a mod-5 counter needs 3 flip-flops. The Python check below prints the count sequence.

import math
N = 5
bits = math.ceil(math.log2(N))
print("flip-flops for mod-5 =", bits)
seq = []
Q = 0
for _ in range(7):
    seq.append(Q)
    Q = 0 if Q == N - 1 else Q + 1       # synchronous count, reset to 0 at the end
print("sequence =", seq)
flip-flops for mod-5 = 3
sequence = [0, 1, 2, 3, 4, 0, 1]

The sequence 0, 1, 2, 3, 4 repeats every five pulses. Each step adds one, except that 4 goes back to 0. Only five of the eight possible 3-bit codes are used. The unused codes 5, 6 and 7 are never reached from 0 in normal operation, which is a point worth noting for design questions.

Key ideaA synchronous counter changes all bits on the same edge, so its output is clean. A mod-N counter needs extra logic to reset at N − 1, because a binary counter naturally counts to 2n − 1.

How many flip-flops does a mod-8 counter need?

Three, because log₂ 8 = 3 exactly, and 23 = 8.

How many flip-flops does a mod-6 counter need?

Three, because log₂ 6 = 2.58 rounds up to 3. Two flip-flops give only 4 states, which is not enough.

Solved GATE-style problems

These are original GATE-style questions for practice. They are not real past paper questions. Try each one before reading the answer.

D flip-flop after one clock edge

A positive-edge triggered D flip-flop has D = 1 just before a rising clock edge. Its output before the edge is Q = 0. What is Q just after the edge?

How to think about it

  1. What is asked. The value of Q after the edge.
  2. Which idea applies. The D flip-flop copies D at the active edge: Q+ = D.
  3. Work it out. D = 1 at the rising edge, so Q+ = 1. The old value 0 does not matter.
  4. Check. The code gives the same result.
def d_next(D):
    return D

print("Q after the clock edge =", d_next(1))
Q after the clock edge = 1

Answer: Q = 1.

Which flip-flop statements are true?

Select all that apply.
(A) For a D flip-flop, Q+ = D.
(B) A T flip-flop toggles on each clock edge when T = 1.
(C) A JK flip-flop toggles when J = K = 1.
(D) An SR flip-flop allows S = R = 1.

How to think about it

  1. What is asked. Which statements match the flip-flop rules.
  2. Which idea applies. The characteristic equations and input rules.
  3. Work it out. (A) True. (B) True. (C) True, J = K = 1 is the toggle case. (D) False, S = R = 1 is forbidden.
  4. Check. Only the SR case is the forbidden one.

Answer: (A), (B) and (C).

Counting pulses in a ripple counter

A 2-bit ripple counter with negative-edge triggered T flip-flops starts at Q1Q0 = 00. It receives 11 clock pulses. What is the final count in decimal?

How to think about it

  1. What is asked. The count after 11 pulses.
  2. Which idea applies. The counter is mod 4, so take 11 mod 4.
  3. Work it out. 11 = 2 × 4 + 3, so the remainder is 3. The count is 3, which is 11 in binary.
  4. Check. The trace in Step 4 gives 3 at pulse 11.
state = [0, 0]          # [Q1, Q0]
def ripple_pulse(state):
    Q1, Q0 = state
    new_Q0 = 1 - Q0
    new_Q1 = Q1
    if Q0 == 1 and new_Q0 == 0:
        new_Q1 = 1 - Q1
    return [new_Q1, new_Q0]

for n in range(1, 12):
    state = ripple_pulse(state)
print("after 11 pulses, decimal =", state[0] * 2 + state[1])
after 11 pulses, decimal = 3

Answer: 3.

JK input for a given change

A JK flip-flop has Q = 0 and must go to Q+ = 1 at the next clock edge. Which input values are required for J and K? Use X for a don't care.

How to think about it

  1. What is asked. J and K for the change 0 to 1.
  2. Which idea applies. The JK excitation table.
  3. Work it out. With Q = 0, Q+ = JQ' + K'Q = J. So J must be 1. The K term is 0 whatever K is, so K is X.
  4. Check. The table in Step 2 shows the row 0 to 1 as J = 1, K = X.
def jk_next(Q, J, K):
    return (J & (1 - Q)) | ((1 - K) & Q)

print("J = 1, K = 0 gives Q+ =", jk_next(0, 1, 0))
print("J = 1, K = 1 gives Q+ =", jk_next(0, 1, 1))
J = 1, K = 0 gives Q+ = 1
J = 1, K = 1 gives Q+ = 1

Answer: J = 1, K = X.

  3. Work it out. N = 5. 22 = 4 is too small. 23 = 8 is enough. So n = 3.

Tracing a JK flip-flop

A JK flip-flop starts with Q = 1. Before each of five clock edges, the inputs (J, K) are (1, 0), (0, 0), (1, 1), (0, 1) and (0, 0), in that order. Find the value of Q after the fifth edge.

How to think about it

  1. What is asked. Q after the fifth pulse.
  2. Which idea applies. Use Q+ = JQ' + K'Q at each edge, one at a time.
  3. Work it out. Edge 1: (1, 0) sets, Q = 1. Edge 2: (0, 0) holds, Q = 1. Edge 3: (1, 1) toggles, Q = 0. Edge 4: (0, 1) resets, Q = 0. Edge 5: (0, 0) holds, Q = 0.
  4. Check. The trace below reproduces each step.
def jk_next(Q, J, K):
    return (J & (1 - Q)) | ((1 - K) & Q)

Q = 1
inputs = [(1, 0), (0, 0), (1, 1), (0, 1), (0, 0)]
for n, (J, K) in enumerate(inputs, start=1):
    Q = jk_next(Q, J, K)
    print(n, "|", J, K, "|", Q)
print("final Q =", Q)
1 | 1 0 | 1
2 | 0 0 | 1
3 | 1 1 | 0
4 | 0 1 | 0
5 | 0 0 | 0
final Q = 0

Answer: Q = 0 after the fifth edge.

Statements about ripple and synchronous counters

Select all that apply.
(A) In a ripple counter, all flip-flops share the same clock.
(B) In a ripple counter, the delays of the stages add up along the chain.
(C) In a synchronous counter, all flip-flops use the same clock.
(D) A mod-6 counter needs 3 flip-flops.

How to think about it

  1. What is asked. Which claims describe these counters correctly.
  2. Which idea applies. Ripple counters chain the clocks, synchronous counters share one clock. Count bits with ⌈log₂ N⌉.
  3. Work it out. (A) False, the clocks are chained, not shared. (B) True, each stage waits for the one before. (C) True. (D) True, because ⌈log₂ 6⌉ = 3.
  4. Check. A 2-bit counter has only 4 states, so it cannot make 6 states, which confirms (D).

Answer: (B), (C) and (D). Option (A) is false.

Three-bit down counter

A 3-bit down counter starts at 000. On each clock pulse it counts down by one, and it wraps from 000 to 111. What is the state, in decimal, after 3 pulses?

How to think about it

  1. What is asked. The decimal state after three down steps.
  2. Which idea applies. Subtract one each pulse, modulo 8.
  3. Work it out. 0 goes to 7 (wrap), then 7 goes to 6, then 6 goes to 5. The state is 5.
  4. Check. The code lists the sequence, which is 0, 7, 6, 5.
state = 0
seq = [state]
for _ in range(3):
    state = (state - 1) % 8
    seq.append(state)
print("down count sequence =", seq)
print("state after 3 pulses =", state)
down count sequence = [0, 7, 6, 5]
state after 3 pulses = 5

Answer: 5.

Exam-level 1: Counter modulus (NAT, 2 marks)

A 4-bit ripple counter is reset when the count reaches 1010 (decimal 10). How many distinct states does it pass through in steady operation?

How to think about it

  1. What is asked. The modulus of the counter.
  2. Which idea applies. The reset state is transient, so the counter shows 0 to 9.
  3. Work it out. Mod 10.
  4. Check. This is a decade (BCD) counter.

Answer: 10.

Exam-level 2: JK flip-flop sequence (MCQ, 2 marks)

A JK flip-flop starts at Q = 0. The inputs at four clock edges are (J, K) = (1, 0), (1, 1), (1, 1), (0, 1). What is Q after the fourth edge? (A) 0 (B) 1 (C) toggles forever (D) undefined

How to think about it

  1. What is asked. The final state.
  2. Which idea applies. JK: 10 sets, 01 resets, 11 toggles, 00 holds.
  3. Work it out. 0 → 1 (set) → 0 (toggle) → 1 (toggle) → 0 (reset).
  4. Check. The code steps through it.
q = 0
for j, k in [(1, 0), (1, 1), (1, 1), (0, 1)]:
    q = (j & (1 - q)) | ((1 - k) & q)
    print(q, end=" ")
print()

1 0 1 0

Answer: (A).

Exam-level 3: Johnson counter (NAT, 2 marks)

How many states does a 5 flip-flop Johnson (twisted ring) counter cycle through, and how many for a 5 flip-flop ring counter?

How to think about it

  1. What is asked. The two moduli.
  2. Which idea applies. Johnson: 2n states. Ring: n states.
  3. Work it out. Johnson 10, ring 5.
  4. Check. The code simulates the Johnson counter.
s = (0,) * 5; seen = []
while s not in seen:
    seen.append(s); s = (1 - s[-1],) + s[:-1]
print(len(seen))

10

Answer: 10 and 5.
