Matrices: operations, projection matrix

Matrices can be added, multiplied, transposed and inverted, but the most useful one is the projection matrix. It gives the closest point to a vector inside a chosen line or plane, the same idea as a shadow on a wall. Projections appear in GATE DA questions on least squares and regression.

The idea in plain words

Imagine a lamp shining straight down onto a table. A pencil held above the table casts a shadow on it. The shadow is the closest point on the table to the tip of the pencil. This shadow is a projection.

In linear algebra, the table is a line or plane through the origin, and the pencil is a vector. A projection matrix is a machine that finds this shadow for every vector at once. Real data never lies exactly on a line, so the "best" line gives the closest prediction, and finding it is a projection. This is the heart of least squares, which GATE DA questions use often.

Key terms

Dot product u . v
Multiply matching entries and add. Equals uTv. Plain meaning: how much two arrows point the same way.
Length, ||u||
How long an arrow is. ||u||2 = u . u.
Orthogonal
Two vectors whose dot product is 0. They meet at a right angle.
Projection
The closest point to a vector inside a line, plane or subspace.
Residual, e
The leftover part, e = b - p, where p is the projection.
Column space, C(A)
All vectors Ax: all mixes of the columns of A.
Projection matrix, P
A square matrix with PT = P (symmetric) and P2 = P (idempotent).
Idempotent
A matrix that gives the same result when applied twice. P2 = P.
Diagonal matrix
A square matrix with zeros everywhere except possibly on the diagonal.

Matrix operations you will use in projections

Matrices of the same size add entry by entry, and a scalar multiplies every entry. Products follow the row-times-column rule. Three laws hold: (AB)C = A(BC), A(B + C) = AB + AC, and (cA)B = c(AB). The one law that fails is commutativity: AB is usually not BA. Keep the order.

Transposes and inverses reverse the order of products: (AB)T = BTAT and (AB)-1 = B-1A-1. The trace satisfies tr(AB) = tr(BA). The Python block below checks these ideas, and it also shows a fact used in GATE questions: tr(CTC) equals the sum of the squares of all entries of C.

def matmul(X, Y):
    n, k, m = len(X), len(Y), len(Y[0])
    return [[sum(X[i][t] * Y[t][j] for t in range(k)) for j in range(m)] for i in range(n)]

def transpose(M):
    return [list(col) for col in zip(*M)]

What is AB for A = [[1, 0], [0, 2]] and B = [[0, 1], [1, 0]]?

Entry (1,1) = 0, entry (1,2) = 1, entry (2,1) = 2, entry (2,2) = 0. So AB = [[0, 1], [2, 0]].

Is (A + B)(A - B) always equal to A2 - B2?

No. Expanding gives A2 - AB + BA - B2, and the middle terms cancel only when AB = BA.

Special matrices: diagonal, symmetric and skew-symmetric

A diagonal matrix has numbers only on its diagonal, such as D = [[3, 0], [0, 5]]. Multiplying by it scales rows one at a time. A symmetric matrix satisfies AT = A, such as S = [[1, 2], [2, 1]]. Every projection matrix is symmetric. A skew-symmetric matrix satisfies AT = -A, such as K = [[0, 3], [-3, 0]], and its diagonal is 0.

A skew-symmetric matrix can never be a projection except the zero matrix, because a projection must be symmetric.

Key ideaEvery square matrix is a symmetric matrix plus a skew-symmetric matrix: A = (A + AT)/2 + (A - AT)/2.

Is the zero matrix both symmetric and skew-symmetric?

Yes. It equals its transpose, and -0 is 0.

Is every diagonal matrix symmetric?

Yes. Flipping over the diagonal changes nothing, because the off-diagonal entries are all 0.

Projecting a vector onto a line

Take a line through the origin in the direction of u, and a vector v. The projection p is the point on the line closest to the tip of v. Because p lies on the line, p = c u for some number c. The leftover v - p is perpendicular to u, so (v - p) . u = 0. Solving for c gives:

p = (u . v / u . u) u

Here u . v is the dot product and u . u is the squared length of u. Take u = (2, 1) and v = (1, 2). Then u . v = 2 + 2 = 4 and u . u = 5, so c = 4/5 and p = (8/5, 4/5). The leftover is (1 - 8/5, 2 - 4/5) = (-3/5, 6/5), and its dot product with u is -6/5 + 6/5 = 0, so it is perpendicular.

Drag the tip of v in the picture. The foot of the perpendicular slides along the line, and the dashed leftover always stays at a right angle.

TrapThe projection depends only on the direction of u. Scaling u to 10u gives the same projection, because the factor u . v / u . u changes too.

Project v = (3, 0) onto the line through u = (1, 2).

u . v = 3 and u . u = 5, so p = (3/5)(1, 2) = (3/5, 6/5).

If v is already on the line through u, what is its projection?

Its own vector v. For example, v = 2u gives c = 2, so p = 2u = v.

The projection matrix onto a line and onto a column space

Since p = (uTv / uTu) u, the projection onto the line through u is the matrix P = u uT / (uTu). Here u uT is a column times a row, which gives a square matrix. For u = (2, 1), u uT = [[4, 2], [2, 1]] and uTu = 5, so P = (1/5)[[4, 2], [2, 1]]. Check: Pv = (1/5)(4 + 4, 2 + 2) = (8/5, 4/5), the same projection as before.

For a plane or any larger subspace, project onto the column space of A:

P = A (ATA)-1 AT

Here ATA is square and symmetric, and its inverse exists when the columns of A are independent. Take A = [[1, 0], [0, 1], [1, 1]]. Then ATA = [[2, 1], [1, 2]], whose inverse is (1/3)[[2, -1], [-1, 2]]. Multiplying out gives P = [[2/3, -1/3, 1/3], [-1/3, 2/3, 1/3], [1/3, 1/3, 2/3]]. The Python block does every step with exact fractions and tests the properties of the next section.

from fractions import Fraction as F

def matmul(X, Y):
    n, k, m = len(X), len(Y), len(Y[0])
    return [[sum(X[i][t] * Y[t][j] for t in range(k)) for j in range(m)] for i in range(n)]

def transpose(M):
    return [list(col) for col in zip(*M)]

def inv2(M):
    a, b = M[0]
    c, d = M[1]
    det = a * d - b * c
    return [[F(d, det), F(-b, det)], [F(-c, det), F(a, det)]]

def show(name, M):
    print(name)
    for row in M:
        print("  ", [str(x) for x in row])

A = [[1, 0], [0, 1], [1, 1]]
At = transpose(A)
G = matmul(At, A)
P = matmul(matmul(A, inv2(G)), At)
show("A^T A =", G)
show("P =", P)
print("P symmetric:", P == transpose(P))
print("P squared equals P:", matmul(P, P) == P)
print("trace of P:", sum(P[i][i] for i in range(3)))
b = [[1], [0], [0]]
print("P b =", [str(x[0]) for x in matmul(P, b)])

Key ideaIf b is already a mix of the columns of A, then Pb = b. For example, (1, 2, 3) = 1 (1, 0, 1) + 2 (0, 1, 1), so P leaves (1, 2, 3) unchanged.

What is P applied to u for the line projection P = (1/5)[[4, 2], [2, 1]] and u = (2, 1)?

(1/5)(8 + 2, 4 + 1) = (2, 1). Since u is on the line, it is unchanged.

Why is ATA always symmetric?

(ATA)T = AT(AT)T = ATA, so it equals its own transpose.

Properties of projection matrices

Every projection matrix has these properties, and they let you rule out wrong options quickly.

Symmetric and idempotent

PT = P and P2 = P

Idempotent means "same again". Projecting a point that is already on the subspace changes nothing. The Python output above showed P symmetric and P squared equal to P.

Trace equals rank

For a projection, the trace equals the dimension of the subspace, which equals the rank. In the example the trace is 2/3 + 2/3 + 2/3 = 2, and the plane is two-dimensional.

GATE loves thisTo find the rank of a projection matrix in an exam, add its diagonal entries. This is usually faster than row reduction.

The leftover matrix

Let Q = I - P. Then Q is also a projection, onto the perpendicular space. For b = (1, 0, 0) in the example, the residual is Qb = (1/3, 1/3, -1/3).

TrapIdempotent alone is not enough. A projection must also be symmetric. For example, [[1, 1], [0, 0]] satisfies P2 = P, but its transpose is different, so it is not an orthogonal projection.

What is the trace of the projection onto a line?

1, because a line is one-dimensional. For the line through (2, 1), the trace is (4 + 1)/5 = 1.

Is [[1, 1], [0, 0]] squared equal to itself?

Yes: row 1 times column 1 is 1, and row 1 times column 2 is 1. So P2 = P.

Solved GATE-style problems

Problems 1 to 7 are original GATE-style problems. Problems 8 and 9 are real past questions from GATE papers, rewritten in this format and marked as verified PYQs.

Add and scale matrices

Let A = [[1, 2], [0, 1]] and B = [[2, 0], [1, 1]]. Find 2A - B.

How to think about it

  1. What is asked. One matrix, made by scaling A and subtracting B.
  2. Which idea applies. Scale each entry of A by 2, then subtract the matching entries of B.
  3. Work it out. 2A = [[2, 4], [0, 2]], so 2A - B = [[0, 4], [-1, 1]].
  4. Check. Entry (2,1): 0 minus 1 gives -1, which matches.

Answer: [[0, 4], [-1, 1]].

Symmetric and skew-symmetric (MSQ)

(A) K = [[0, 3], [-3, 0]] is skew-symmetric. (B) S = [[1, 2], [2, 1]] is symmetric. (C) T = [[1, 2], [3, 1]] is symmetric. (D) Z = [[0, 0], [0, 0]] is both symmetric and skew-symmetric. Select all true statements.

How to think about it

  1. What is asked. Test each matrix against AT = A and AT = -A.
  2. Which idea applies. Compare mirror entries across the diagonal.
  3. Work it out. (A) true, since KT = -K. (B) true, since both mirror entries are 2. (C) false, since 2 and 3 differ. (D) true.
  4. Check. Only matrices whose mirror entries are equal or opposite pass.

Answer: (A), (B) and (D).

Sum of squares as a trace (NAT)

Let C = [[1, 2], [3, 4]]. Find the trace of CTC. Give a single number.

How to think about it

  1. What is asked. One number.
  2. Which idea applies. The diagonal of CTC holds the squared lengths of the columns of C.
  3. Work it out. Column 1 is (1, 3), with squared sum 10. Column 2 is (2, 4), with squared sum 20. Total 30.
  4. Check. CTC = [[10, 14], [14, 20]], whose trace is 30.

Answer: 30.

Projecting onto a line (NAT)

Let u = (1, 2) and v = (3, 0). Let p be the projection of v onto the line through u. Find the second entry of p.

How to think about it

  1. What is asked. One entry of p.
  2. Which idea applies. p = (u . v / u . u) u.
  3. Work it out. u . v = 3 and u . u = 5, so p = (3/5)(1, 2) = (3/5, 6/5). The second entry is 6/5.
  4. Check. The leftover (12/5, -6/5) has dot product 12/5 - 12/5 = 0 with u.

Answer: 6/5 (that is, 1.2).

Properties of a line projection (MSQ)

Let P be the projection matrix onto the line through u = (1, 2), so P = (1/5)[[1, 2], [2, 4]]. Select all true statements.

(A) P is symmetric
(B) P2 = P
(C) P = I
(D) tr(P) = 1

How to think about it

  1. What is asked. Check four properties.
  2. Which idea applies. Symmetry, idempotence, and trace equals the dimension of the line.
  3. Work it out. (A) true, since the off-diagonal entries are both 2/5. (B): P2 = (1/25)[[5, 10], [10, 20]] = (1/5)[[1, 2], [2, 4]] = P, true. (C) false, since P has entries such as 1/5 and 2/5. (D): (1 + 4)/5 = 1, true.
  4. Check. A line is one-dimensional, so the trace must be 1.

Answer: (A), (B) and (D).

Residual of a projection onto a line (MSQ)

Let a = (1, 2, 2). Project b = (3, 0, 0) onto the line through a, giving p, and let e = b - p. Select all true statements.

(A) p = (1/3, 2/3, 2/3)
(B) e is perpendicular to a
(C) the length of e is 3
(D) Pb = b, where P is the projection matrix onto the line

How to think about it

  1. What is asked. Compute the projection and residual, then test each statement.
  2. Which idea applies. p = (a . b / a . a) a, and the residual is perpendicular to a.
  3. Work it out. a . b = 3 and a . a = 9, so p = (1/3, 2/3, 2/3). (A) true. The residual is e = (8/3, -2/3, -2/3). Its dot product with a is 8/3 - 4/3 - 4/3 = 0, so (B) true. Its squared length is 64/9 + 4/9 + 4/9 = 8, so the length is about 2.83, not 3, and (C) is false. (D) is false because b is not on the line.
  4. Check. p + e = (1/3 + 8/3, 2/3 - 2/3, 2/3 - 2/3) = (3, 0, 0) = b.

Answer: (A) and (B).

Trace of a projection onto a plane (NAT)

Let A = [[1, 0], [0, 1], [1, 1]] and P = A (ATA)-1 AT. Find the sum of the three diagonal entries of P. Give a single number.

How to think about it

  1. What is asked. The trace of P.
  2. Which idea applies. The trace of a projection equals the dimension of the space it projects onto.
  3. Work it out. The column space has two independent columns, so the dimension is 2. From the worked example, the diagonal of P is 2/3, 2/3, 2/3, with sum 2.
  4. Check. The trace matches the dimension.

Answer: 2.

GATE DA 2024 Q39 (verified PYQ): projections in R3 (MSQ)

Let U be a subspace of R3, and let M be the 3 x 3 matrix that projects vectors onto U. Select all true statements.

(A) If U is 1-dimensional, the null space of M is 1-dimensional
(B) If U is 2-dimensional, the null space of M is 1-dimensional
(C) M2 = M
(D) M3 = M

How to think about it

  1. What is asked. Which statements about a projection matrix are true.
  2. Which idea applies. The output of M is U, so rank(M) = dim U, and the null space has dimension 3 minus the rank.
  3. Work it out. (C) true, because projecting twice equals projecting once. (D) true, since M3 = M2M = MM = M. (A) false: rank 1 gives nullity 2. (B) true: rank 2 gives nullity 1.
  4. Check. For a plane U, the vectors killed by M form the perpendicular line, which is 1-dimensional.

Answer: (B), (C) and (D). This is a verified PYQ from GATE DA 2024, Q39, rewritten into the format of this page.

GATE DA 2026 (verified PYQ): centering matrix (MSQ)

Let 1 be the column of n ones and let M = In - (1/n) 11T. Select all true statements.

(A) M is a projection matrix
(B) MT = M
(C) M2 = I
(D) tr(M) = n

How to think about it

  1. What is asked. Check each property of M.
  2. Which idea applies. Let J = 11T. Each entry of J2 is a sum of n ones, so J2 = nJ.
  3. Work it out. (B) true, since J is symmetric. M2 = I - (2/n)J + (1/n2)nJ = I - (1/n)J = M, so (C) is false. (A) true, because M is symmetric and idempotent. (D) false: tr(M) = n - 1.
  4. Check. For n = 2, M = [[1/2, -1/2], [-1/2, 1/2]] has trace 1 = n - 1, and M squared equals M.

Answer: (A) and (B). This is a verified PYQ from GATE DA 2026, rewritten into the format of this page.

Exam-level practice

Exam-level 1: Projection onto a column space (NAT, 2 marks)

Let A = [[1, 0], [1, 1], [0, 1]] and P = A(AᵀA)−1Aᵀ. Find tr(P) and the (1, 1) entry of P.

How to think about it

  1. What is asked. The trace of the projection matrix and its top left entry.
  2. Which idea applies. P projects onto the column space of A. For any projection, the trace equals the rank.
  3. Work it out. AᵀA = [[2, 1], [1, 2]], inverse (1/3)[[2, −1], [−1, 2]]. Row 1 of A is (1, 0), so P11 = (1, 0)(1/3)[[2, −1], [−1, 2]](1, 0)ᵀ = 2/3. The rank of A is 2, so tr(P) = 2.
  4. Check. The code forms P exactly.
from fractions import Fraction as F
A = [[1, 0], [1, 1], [0, 1]]
G = [[sum(A[k][i] * A[k][j] for k in range(3)) for j in range(2)] for i in range(2)]
d = F(G[0][0] * G[1][1] - G[0][1] * G[1][0])
Gi = [[G[1][1] / d, -G[0][1] / d], [-G[1][0] / d, G[0][0] / d]]
P = [[sum(A[i][a] * Gi[a][b] * A[j][b] for a in range(2) for b in range(2)) for j in range(3)] for i in range(3)]
print("P11 =", P[0][0], " trace =", sum(P[i][i] for i in range(3)))

P11 = 2/3  trace = 2

Answer: tr(P) = 2 and P11 = 2/3 ≈ 0.667.

Exam-level 2: Products that commute (MSQ, 2 marks)

Let P be a real n × n orthogonal projection (P = Pᵀ = P²), P ≠ 0, P ≠ I. Which are TRUE? (A) I − P is a projection. (B) P(I − P) = 0. (C) P is invertible. (D) Every eigenvalue of P is 0 or 1.

How to think about it

  1. What is asked. Properties of a non-trivial orthogonal projection.
  2. Which idea applies. Use P² = P directly, and the eigen equation Px = λx.
  3. Work it out. (A) (I − P)² = I − 2P + P² = I − P and it is symmetric. True. (B) P − P² = 0. True. (C) P ≠ I with P² = P: if P were invertible, multiplying P² = P by P−1 gives P = I. False. (D) Px = λx gives λ²x = λx, so λ is 0 or 1. True.
  4. Check. P = [[1, 0], [0, 0]] is a quick example: det 0, eigenvalues 1 and 0.

Answer: (A), (B) and (D).

Exam-level 3: Matrix power by pattern (NAT, 2 marks)

Let N = [[0, 1, 2], [0, 0, 3], [0, 0, 0]] and A = I + N. Find the (1, 3) entry of A10.

How to think about it

  1. What is asked. One entry of a high power of a unipotent matrix.
  2. Which idea applies. N is strictly upper triangular, so N³ = 0. I and N commute, so the binomial theorem gives A10 = I + 10N + 45N².
  3. Work it out. N² = [[0, 0, 3], [0, 0, 0], [0, 0, 0]]. The (1, 3) entry is 0 + 10·2 + 45·3 = 20 + 135 = 155.
  4. Check. The code multiplies A by itself ten times.
def mul(X, Y):
    return [[sum(X[i][k] * Y[k][j] for k in range(3)) for j in range(3)] for i in range(3)]
A = [[1, 1, 2], [0, 1, 3], [0, 0, 1]]
R = [[int(i == j) for j in range(3)] for i in range(3)]
for _ in range(10):
    R = mul(R, A)
print("(1,3) entry of A^10 =", R[0][2])

(1,3) entry of A^10 = 155

Answer: 155.
