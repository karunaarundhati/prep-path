Approximate inference: Sampling

When exact probability calculations in a Bayesian network become too large, we can estimate the answer by generating many random samples of the network. This topic covers prior sampling, rejection sampling, likelihood weighting and Gibbs sampling.

The idea in plain words

Suppose you want to know how likely it is that a random person in a city is left-handed, but you cannot check the whole city. You ask 1000 people at random and count. Your count is not exactly right, but it is usually close. With more people you get closer. This is the idea of approximate inference by sampling.

In a Bayesian network, exact inference means adding up many products of table entries, as in variable elimination. For large networks this can take far too long. Sampling is different. We generate complete random examples of the network, look at the examples that match what we care about, and estimate the probability from their counts.

Everyday analogy: a bag with red and blue marbles, where you want the fraction of red marbles. You do not need to count every marble in the factory. Taking a few hundred random marbles gives a good estimate.

Why it matters for GATE. In the Data Science and AI (DA) paper, you may get a conceptual question. Which sampling method throws away samples? Which one keeps every sample but gives them weights? You should know how each one works, not just the names.

Key terms

Sample
One complete random assignment of values to all variables in the network.
Prior sampling
Generating samples from the network without any evidence, one variable at a time in an order where parents come before children.
Evidence
Variables whose values we have observed, such as W = 1.
Rejection sampling
Generating prior samples and discarding those that disagree with the evidence.
Likelihood weighting
Fixing the evidence variables to their observed values and giving each sample a weight equal to how likely the evidence is.
Weight
A number attached to a sample that tells us how much to count it.
Gibbs sampling
A Markov chain Monte Carlo (MCMC) method that repeatedly resamples one variable at a time, given the values of the others.
Burn-in
The early steps of a Gibbs chain that are discarded before the samples settle down.
Estimate
A number computed from samples that approximates the true probability.

Concept 1: Prior sampling

Use the small network Rain (R) → Wet grass (W). The numbers are P(R = 1) = 1/5, P(W = 1 | R = 1) = 9/10 and P(W = 1 | R = 0) = 1/10. To produce one sample:

  1. Choose an order in which parents come before children. Here it is R, then W.
  2. For R, draw a random number u between 0 and 1. If u is less than 1/5, set R = 1. Otherwise set R = 0.
  3. For W, use the value of R. If R = 1, draw v and set W = 1 when v is less than 9/10. If R = 0, set W = 1 when v is less than 1/10.

Each sample is a full row, such as R = 1, W = 1. Over many samples, the fraction of rows with R = 1 approaches 1/5. This is the law of large numbers, a basic idea of probability: the average of many fair trials settles near the true value.

Key ideaPrior sampling is exact in the limit. With enough samples, the frequencies match the joint distribution. The error shrinks roughly like 1 over the square root of the number of samples.

Why is this useful? Exact inference might need to add up 2n rows for n binary variables. Sampling needs only a few passes through the network for each sample. The trade-off is that the answer is approximate.

Question: In prior sampling, why must parents be sampled before children?

A child's probability depends on its parents' values. The parents must be known first, so the child's table can be used.

Question: With P(R = 1) = 1/5 and 1000 samples, about how many samples have R = 1?

About 1000 × 1/5 = 200.

Concept 2: Rejection sampling

Suppose we want P(R = 1 | W = 1). Prior sampling gives samples over all variables, but we only care about samples where the evidence holds. Rejection sampling keeps a sample only if it agrees with W = 1, and throws away the rest. The estimate is:

P(R = 1 | W = 1) ≈ (number of accepted samples with R = 1) / (number of accepted samples)

The symbol ≈ means approximately equal to. The numerator counts accepted samples with R = 1. The denominator counts all accepted samples.

The exact answer is 9/13 ≈ 0.692. The reason: P(R = 1, W = 1) = 1/5 × 9/10 = 9/50, and P(W = 1) = 9/50 + 4/5 × 1/10 = 9/50 + 4/50 = 13/50. So the ratio is (9/50) / (13/50) = 9/13.

The Python program below uses an evenly spaced grid of values in place of random numbers. It is a deterministic way to show the method, and the count is exact, so the printed answers can be checked by hand.

from fractions import Fraction

N = 100                        # grid size for each "random" number
accepted = 0                   # samples that agree with the evidence W = 1
accepted_rain = 0              # accepted samples where Rain = 1
for i in range(N):
    for j in range(N):
        u = (i + 0.5) / N      # stands in for a random number used for Rain
        v = (j + 0.5) / N      # stands in for a random number used for WetGrass
        rain = 1 if u < 0.2 else 0
        p_wet = 0.9 if rain == 1 else 0.1
        wet = 1 if v < p_wet else 0
        if wet == 1:           # rejection step: keep only samples with W = 1
            accepted += 1
            if rain == 1:
                accepted_rain += 1
print("Samples generated:", N * N)
print("Samples accepted:", accepted)
print("Estimate of P(Rain=1 | Wet=1):", Fraction(accepted_rain, accepted))
print("Exact value:", Fraction(9, 13))
Samples generated: 10000
Samples accepted: 2600
Estimate of P(Rain=1 | Wet=1): 9/13
Exact value: 9/13

TrapRejection sampling wastes work when the evidence is rare. Here 7400 of the 10000 samples were rejected. If P(e) were 1/1000, almost every sample would be thrown away, and the method would be very slow.

Question: Rejection sampling keeps samples with W = 0 for a query P(R | W = 1). True or false?

False. It keeps only samples where the evidence W = 1 holds.

Question: Why does the estimate match the exact answer in the Python program?

The grid is evenly spaced, so the fraction of grid points below each threshold is exact. Random sampling only matches approximately, but the grid shows the method cleanly.

Concept 3: Likelihood weighting

Likelihood weighting avoids wasting samples. It fixes each evidence variable to its observed value, instead of sampling it. Other variables are sampled as usual. Each sample then gets a weight: the probability of the evidence values given the sampled parents. In our network, if W = 1 is fixed and R = 1 was sampled, the weight is P(W = 1 | R = 1) = 9/10. If R = 0 was sampled, the weight is P(W = 1 | R = 0) = 1/10.

Every sample is kept, but a sample that makes the evidence likely gets a bigger weight. The estimate is a weighted average:

P(R = 1 | W = 1) ≈ (sum of weights of samples with R = 1) / (sum of weights of all samples)

Worked example with two samples. Sample 1 has R = 1, so its weight is 9/10. Sample 2 has R = 0, so its weight is 1/10.

  1. Sum of weights with R = 1: 9/10.
  2. Sum of all weights: 9/10 + 1/10 = 10/10 = 1.
  3. Estimate: (9/10) / 1 = 9/10.

Two samples are far too few for a real estimate, so this is only to show the arithmetic. The exact answer is 9/13 ≈ 0.692, and more samples would bring the estimate closer to it. In a full run, each sample is drawn from the prior, and its weight is what corrects the estimate for the evidence.

TipLikelihood weighting is usually better than rejection sampling when the evidence is unlikely. Every sample counts, although some counts more than others.

A caution: if a few samples get very large weights, the estimate is dominated by them and becomes unreliable. This is a real weakness of the method, and a common GATE conceptual point.

Question: A sample has R = 0 and the evidence is W = 1. What is its weight?

1/10, which is P(W = 1 | R = 0).

Question: Does likelihood weighting throw away any samples?

No. Every sample is kept and given a weight.

Concept 4: Gibbs sampling

Gibbs sampling is a Markov chain Monte Carlo (MCMC) method. Instead of generating a whole sample from scratch, it starts with a full assignment, then updates one non-evidence variable at a time. For each variable, it draws a new value from its distribution given the current values of the others. In a Bayesian network, the distribution only needs the variable's Markov blanket, which is its parents, children and children's other parents.

Example: the network has evidence W = 1 fixed, and the variable R is free. Gibbs sampling starts with some value for R, then resamples R from P(R | W = 1, the other variables). This keeps W = 1 at every step, so evidence is never changed.

The first few values depend on the starting point, so we discard them as burn-in. After that, the chain's values behave like samples from the posterior distribution, the probability after the evidence is known. In practice, we count the values after burn-in.

GATE loves thisGibbs sampling never changes the evidence variables. It only resamples the hidden ones. It also needs burn-in, because the first samples depend on where the chain started.

Question: In Gibbs sampling, which variables are resampled when W = 1 is evidence?

Only the non-evidence variables, such as R. The evidence variable W stays fixed at 1.

Question: Why are the first Gibbs samples discarded?

They depend on the starting values, so they are not yet typical. This early phase is called burn-in.

Solved GATE-style problems

These problems are original, written in the style of GATE. They are not past exam questions.

Expected accepted samples

In rejection sampling, the evidence has probability P(e) = 0.01. How many of 1000 prior samples are expected to be accepted?

How to think about it

  1. What is asked. The expected number of accepted samples.
  2. Which idea applies. Expected accepted = N × P(e).
  3. Work it out. 1000 × 0.01 = 10.
  4. Check. One percent of 1000 is 10, which is a sensible size for a rare event.

Answer: 10.

Sampling methods (select all that apply)

Which statements are true? Select all that apply.

(A) Rejection sampling discards samples that are inconsistent with the evidence.
(B) Likelihood weighting samples the evidence variables from the prior.
(C) Gibbs sampling never changes the values of the evidence variables.
(D) Exact inference is always faster than sampling.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. What each method does with the evidence.
  3. Work it out. (A) is true, that is the definition of rejection. (B) is false, likelihood weighting fixes the evidence and does not sample it. (C) is true, evidence stays fixed. (D) is false, exact inference can be very slow on large networks.
  4. Check. Look at the Python program. Rejection removed 7400 samples, which confirms (A).

Answer: (A) and (C).

Weighted estimate from two samples

The network is Rain → Wet grass, with P(W = 1 | R = 1) = 9/10 and P(W = 1 | R = 0) = 1/10. Likelihood weighting with evidence W = 1 produces two samples. Sample 1 has R = 1. Sample 2 has R = 0. Estimate P(R = 1 | W = 1) from these two samples.

How to think about it

  1. What is asked. A weighted estimate from two samples.
  2. Which idea applies. Each weight is P(evidence | parents). The estimate divides the weight of R = 1 by the total weight.
  3. Work it out. Weight of sample 1 = 9/10. Weight of sample 2 = 1/10. Estimate = (9/10) / (9/10 + 1/10) = (9/10) / 1 = 9/10.
  4. Check. The estimate lies between 0 and 1, as a probability must.

Answer: 9/10.

Expected total samples

Rejection sampling is used for a query where the evidence has probability P(e) = 1/8. The analyst wants 400 accepted samples. How many prior samples are needed, on average? Give a whole number.

How to think about it

  1. What is asked. The expected number of total samples.
  2. Which idea applies. Accepted = total × P(e), so total = accepted / P(e).
  3. Work it out. Total = 400 / (1/8) = 400 × 8 = 3200.
  4. Check. 3200 × 1/8 = 400, which matches the target.

Answer: 3200.

Which variables does Gibbs resample?

The network has arrows A → B and C → B. The evidence is B = 1. Which variables does Gibbs sampling resample? Give the answer as a set.

How to think about it

  1. What is asked. The set of hidden variables that are updated.
  2. Which idea applies. Evidence stays fixed. Every other variable is resampled given its Markov blanket.
  3. Work it out. The variables are A, B and C. B is evidence, so it is fixed. The hidden variables are A and C.
  4. Check. A has child B and co-parent C, and C has child B and co-parent A. Both are in the blanket of each other, so both are updated.

Answer: {A, C}.

Likelihood weighting on a two-node network

The network is A → B with P(A = 1) = 1/2, P(B = 1 | A = 1) = 3/4 and P(B = 1 | A = 0) = 1/4. The evidence is B = 1 and the query is A = 1. Using one sample with A = 1 and one with A = 0, each with the same prior weight, estimate P(A = 1 | B = 1). Then compute the exact answer.

How to think about it

  1. What is asked. A weighted estimate, and the exact value to compare.
  2. Which idea applies. Weights are P(B = 1 | A). Compare with the exact formula P(A = 1 | B = 1) = P(A = 1, B = 1) / P(B = 1).
  3. Work it out. Weights: sample with A = 1 gets 3/4, sample with A = 0 gets 1/4. Estimate = (3/4) / (3/4 + 1/4) = 3/4. Exact: P(A = 1, B = 1) = 1/2 × 3/4 = 3/8. P(B = 1) = 3/8 + 1/2 × 1/4 = 3/8 + 1/8 = 1/2. So P(A = 1 | B = 1) = (3/8) / (1/2) = 3/4.
  4. Check. The estimate and the exact answer are both 3/4. This works because the two samples have equal prior weight, which matches P(A = 1) = P(A = 0) = 1/2.

Answer: The estimate is 3/4, and the exact answer is also 3/4.

Estimate from four weighted samples

Likelihood weighting is run on the Rain → Wet grass network with evidence W = 1. Four samples are drawn. Two samples have R = 1, and two have R = 0. Using P(W = 1 | R = 1) = 9/10 and P(W = 1 | R = 0) = 1/10 as weights, estimate P(R = 1 | W = 1). Give a decimal.

How to think about it

  1. What is asked. A decimal estimate from four weighted samples.
  2. Which idea applies. Estimate = sum of weights with R = 1 / sum of all weights.
  3. Work it out. Sum of weights with R = 1 = 9/10 + 9/10 = 18/10 = 1.8. Sum of weights with R = 0 = 1/10 + 1/10 = 0.2. Total = 1.8 + 0.2 = 2.0. Estimate = 1.8 / 2.0 = 0.9.
  4. Check. The estimate 0.9 is between 0 and 1. It differs from the exact value 9/13 ≈ 0.692 because four samples are far too few. This is typical of a small run, and more samples would shrink the gap.

Answer: 0.9.

Exam-level practice

Exam-level 1: Rejection sampling acceptance (NAT, 2 marks)

Using the chain above (P(C = 1) = 0.6), rejection sampling is used to estimate a query given C = 1. Out of 10000 prior samples, about how many are kept?

How to think about it

  1. What is asked. The expected number of accepted samples.
  2. Which idea applies. A sample is kept exactly when it agrees with the evidence.
  3. Work it out. 10000 · 0.6 = 6000.
  4. Check. Rare evidence makes rejection sampling waste most samples.

Answer: About 6000.

Exam-level 2: Likelihood weighting (NAT, 2 marks)

In likelihood weighting for the chain A → B → C with evidence C = 1, a sample draws A = 1, B = 0. What is its weight?

How to think about it

  1. What is asked. The sample's weight.
  2. Which idea applies. The weight is the product of P(evidence | parents) for evidence variables.
  3. Work it out. Weight = P(C = 1 | B = 0) = 0.3.
  4. Check. Non-evidence variables are sampled, so they do not contribute to the weight.

Answer: 0.3.

Exam-level 3: Monte Carlo error (NAT, 2 marks)

A probability near p = 0.2 is estimated by the fraction of N independent samples. How many samples are needed for the standard error to be 0.01?

How to think about it

  1. What is asked. N for a target standard error.
  2. Which idea applies. Standard error = √(p(1 − p)/N).
  3. Work it out. √(0.16/N) = 0.01 gives N = 0.16/0.0001 = 1600.
  4. Check. Halving the error would need four times as many samples.

Answer: 1600.

Summary

Approximate inference
Estimating a probability from samples when exact computation is too costly.
Sample
One full random assignment to all variables.
Prior sampling
Sampling a network with no evidence, parents before children.
Rejection sampling
Discarding samples that disagree with the evidence.
Likelihood weighting
Fixing evidence and weighting each sample by P(evidence | parents).
Weight
How much a sample counts in the estimate.
Gibbs sampling
MCMC: resampling each hidden variable given its Markov blanket.
MCMC
Markov chain Monte Carlo, a family of methods that build a chain of samples.
Burn-in
The early Gibbs samples that are discarded.
Evidence
Variables whose values are observed.
Posterior
The probability of the query after the evidence is known.

Remember these

  1. Prior sampling generates samples in parents-before-children order.
  2. Rejection sampling keeps only the samples that match the evidence.
  3. Likelihood weighting keeps every sample, fixes the evidence, and weights each sample.
  4. Gibbs sampling never changes the evidence, and it needs burn-in.
  5. Rejection sampling is wasteful when the evidence is rare.
  6. The estimate is always a ratio: query count over total count, or weight over total weight.
