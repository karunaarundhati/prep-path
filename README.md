# Prep Path

A static study site: 42 interview prep days and 193 GATE topics, each with worked problems, runnable Python checks and a summary.

Open `index.html` for the pathway. Day pages are `day-01.html` to `day-42.html`, GATE topics are `gate-001.html` to `gate-193.html`. Progress is saved in your browser.

Hosted with GitHub Pages (branch `main`, folder `/ (root)`).
