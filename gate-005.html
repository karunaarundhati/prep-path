Systems of linear equations and solutions

A system of linear equations is a set of straight-line rules that must all hold at once. You will learn to write it as Ax = b, to tell whether it has one solution, none or infinitely many, and to solve it by hand. Almost every GATE linear algebra question starts here.

The idea in plain words

Imagine two clues. "Two apples and one orange cost 3 pounds." "One apple and three oranges cost 4 pounds." Each clue alone allows many prices, but together they may fix the price of each fruit exactly. That is a system of linear equations: straight-line rules that must hold together.

Each equation with two unknowns is a straight line. A solution is a point where the lines meet. Three things can happen: the lines cross at one point (one solution), they are parallel (no solution), or they lie on top of each other (infinitely many solutions). Your job is to find which case you are in, and then to solve.

GATE DA and RA questions ask "how many solutions", or "for which value of a parameter is the solution unique". Solving systems is also the core computation of least squares and of finding robot joint angles.

Key terms

Linear equation
Each unknown is multiplied by a number and added, with no squares. Example: 2x + y = 3.
Coefficient matrix, A
The table of numbers that multiply the unknowns.
Right-hand side, b
The column of numbers on the right of the equals signs.
Augmented matrix, [A | b]
A with b added as an extra column. The whole system in one table.
Consistent / inconsistent
Consistent means at least one solution exists. Inconsistent means none exists.
Homogeneous system
A system Ax = 0, where every right-hand side is zero.
Trivial and non-trivial solution
The trivial solution is x = 0, which always works for Ax = 0. A non-trivial solution is any other solution.
Free variable
An unknown you may choose freely, with the others following from it.
Cramer's rule
A formula that gives each unknown as a ratio of two determinants, when the system is square with non-zero determinant.

Writing a system as Ax = b

Take the system 2x + y = 3 and x + 3y = 4. Collect the coefficients into a matrix, the unknowns into a vector x, and the right-hand sides into b:

A x = b, where A = [[2, 1], [1, 3]], x = (x, y), b = (3, 4)

There is a second reading, called the column picture. The columns of A are (2, 1) and (1, 3), and x and y are the amounts of each column. So the question becomes: what mix of the columns gives b?

x (2, 1) + y (1, 3) = (3, 4)

Try x = 1 and y = 1: (2, 1) + (1, 3) = (3, 4). That is b, so (1, 1) is the solution. Check the original equations: 2 + 1 = 3 and 1 + 3 = 4.

The picture shows the two column arrows and the target b. Drag the second arrow and see how the mix changes.

Key ideaSolving Ax = b asks: can b be made as a mix of the columns of A, and if so, in how many ways?

TrapKeep the unknowns in the same order in every equation, or the coefficient matrix will be wrong.

Write x + y = 5 and x - y = 1 as Ax = b. What is A?

A = [[1, 1], [1, -1]] and b = (5, 1).

Is (2, 0) a solution of 2x + y = 3 and x + 3y = 4?

No. 2(2) + 0 = 4, not 3. A solution must satisfy both equations.

Three outcomes: one solution, no solution, infinitely many

For any system Ax = b, exactly one of three outcomes happens.

  • One solution: 2x + y = 3 and x + 3y = 4 meet at (1, 1). The lines are not parallel.
  • No solution: x + y = 1 and x + y = 2 are parallel lines. The same left side cannot equal 1 and 2 at once.
  • Infinitely many: x + y = 1 and 2x + 2y = 2 describe the same line. Points such as (1, 0), (0, 1) and (3, -2) all work.

Trap"Infinitely many solutions" does not mean any numbers. The solutions form a line, plane or flat shape with at least one free variable.

In the column picture, the two columns of [[1, 1], [2, 2]] are parallel. Drag the second arrow and notice it can only point along the first. This is the picture behind the no-solution and infinite cases.

Does x + 2y = 3 and 2x + 4y = 7 have a solution?

No. Doubling the first gives 2x + 4y = 6, which cannot equal 7.

How many solutions does x + 2y = 3 and 2x + 4y = 6 have?

Infinitely many. The second is twice the first. Pick any y, and then x = 3 - 2y.

The rank test that decides which outcome you have

Let r = rank(A), r' = rank([A | b]), and n be the number of unknowns. Then:

  • No solution: r' is bigger than r. Adding b raised the rank, so b is not a mix of the columns.
  • Unique solution: r = r' = n. Every unknown is fixed.
  • Infinitely many: r = r' is less than n. There are n - r free variables.

Key ideaThe number of free variables is n - r. If there are none, the solution is unique, as long as the system is consistent.

The Python block runs this test on the earlier examples and on a three-unknown system.

from fractions import Fraction as F

def rank(M):
    A = [[F(x) for x in row] for row in M]
    rows, cols = len(A), len(A[0])
    r = 0
    for c in range(cols):
        p = None
        for i in range(r, rows):
            if A[i][c] != 0:
                p = i
                break
        if p is None:
            continue
        A[r], A[p] = A[p], A[r]
        for i in range(rows):
            if i != r and A[i][c] != 0:
                f = A[i][c] / A[r][c]
                A[i] = [A[i][k] - f * A[r][k] for k in range(cols)]
        r += 1
    return r

def classify(A, b):
    n = len(A[0])
    aug = [row + [bi] for row, bi in zip(A, b)]
    rA, rAb = rank(A), rank(aug)
    if rA != rAb:
        result = "no solution"
    elif rA == n:
        result = "unique solution"
    else:
        result = "infinitely many solutions"
    print("rank A =", rA, "rank [A|b] =", rAb, "unknowns =", n, "means", result)

classify([[1, 1, 1], [2, -1, 1], [1, 2, -1]], [6, 3, 2])

A system has 4 unknowns and a consistent coefficient matrix of rank 3. How many free variables are there?

4 - 3 = 1, so there are infinitely many solutions forming a line.

Does x + y = 1 and x - y = 1 have one, none or infinitely many solutions?

Rank 2 for both A and the augmented matrix, with n = 2. So one solution: x = 1, y = 0.

Homogeneous systems: trivial and non-trivial solutions

A homogeneous system Ax = 0 is always consistent, because x = 0 always works. That is the trivial solution. The real question is whether a non-trivial solution exists.

Key ideaAx = 0 has a non-trivial solution exactly when rank(A) is less than n. For a square matrix, this happens exactly when det(A) = 0.

Take x + 2y - z = 0 and 2x + 4y - 2z = 0. The second equation is twice the first, so the rank is 1, and there are 3 - 1 = 2 free variables. Let y = s and z = t. Then x = -2s + t, and every solution is (-2s + t, s, t). For example, (-2, 1, 0) and (1, 0, 1) both check out: -2 + 2 - 0 = 0 and 1 + 0 - 1 = 0.

TrapThe test is the rank, not the shape. A 2 x 3 matrix with rank 2 has non-trivial solutions, but a 3 x 3 matrix with rank 3 does not.

Does Ax = 0 have a non-trivial solution for [[1, 2, 3], [0, 1, 4], [5, 6, 0]]?

No. Its determinant is 1, which is not 0, so only x = 0 works.

What is the solution set of Ax = 0 for the 2 x 2 zero matrix?

Every vector in R2, since 0 x = 0. The rank is 0 and the nullity is 2.

Cramer's rule for square systems

For a square system Ax = b with det(A) not 0, each unknown is a ratio of determinants. To find xi, replace column i of A by b, call the result Ai, and compute:

xi = det(Ai) / det(A)

For 2x + y = 3 and x + 3y = 4: det(A) = 6 - 1 = 5. Replacing column 1 gives [[3, 1], [4, 3]] with det 9 - 4 = 5, so x = 5/5 = 1. Replacing column 2 gives [[2, 3], [1, 4]] with det 8 - 3 = 5, so y = 1. The Python block repeats this with exact fractions.

from fractions import Fraction as F

def det2(M):
    return M[0][0] * M[1][1] - M[0][1] * M[1][0]

A = [[2, 1], [1, 3]]
b = [3, 4]
d = det2(A)
x = F(det2([[b[0], A[0][1]], [b[1], A[1][1]]]), d)
y = F(det2([[A[0][0], b[0]], [A[1][0], b[1]]]), d)
print("det A =", d)
print("x =", x)
print("y =", y)
print("check:", 2 * x + y, x + 3 * y)
det A = 5
x = 1
y = 1
check: 3 4

TrapCramer's rule needs det(A) not 0. If det(A) = 0 you cannot divide, and the system is either inconsistent or has infinitely many solutions.

TipCramer's rule is quick for 2 x 2 and 3 x 3 systems. For bigger systems, use Gaussian elimination, which we meet on the next page.

Use Cramer's rule to find x for 3x + 2y = 12 and x + 4y = 14.

det(A) = 12 - 2 = 10. Replacing column 1 gives det [[12, 2], [14, 4]] = 48 - 28 = 20. So x = 2, and y = 3.

Why can you not use Cramer's rule for x + 2y = 3 and 2x + 4y = 6?

The determinant is 0, so you cannot divide. The system has infinitely many solutions.

Solved GATE-style problems

Problems 1, 2, 3, 4, 9 and 10 are original GATE-style problems. Problems 5, 6, 7 and 8 are real past questions from GATE papers, rewritten in this format and marked as verified PYQs.

Solve a small system

Solve 2x + y = 7 and x - y = 2. Give x and y.

How to think about it

  1. What is asked. Both unknowns.
  2. Which idea applies. Add the equations to remove y.
  3. Work it out. 3x = 9, so x = 3. Then 3 - y = 2, so y = 1.
  4. Check. 2(3) + 1 = 7 and 3 - 1 = 2. Both hold.

Answer: x = 3 and y = 1.

True statements about solutions (MSQ)

A is a 3 x 3 matrix. Select all true statements.

(A) If rank(A) = 3, then Ax = b has at most one solution.
(B) If Ax = b is inconsistent, it has no solution.
(C) A homogeneous system Ax = 0 is always inconsistent.
(D) If rank(A) = 2 and Ax = b is consistent, it has infinitely many solutions.

How to think about it

  1. What is asked. Test each statement.
  2. Which idea applies. Nullity = 3 - rank.
  3. Work it out. (A) true, nullity 0. (B) true, by definition. (C) false, since x = 0 always works. (D) true, since nullity is 1.
  4. Check. The trap is (C).

Answer: (A), (B) and (D).

The value that gives infinitely many solutions (NAT)

For which value of c do x + 2y = 3 and 2x + 4y = c have infinitely many solutions? Give a single number.

How to think about it

  1. What is asked. One value of c.
  2. Which idea applies. The second equation must be twice the first.
  3. Work it out. Twice the first is 2x + 4y = 6, so c = 6.
  4. Check. The rank is 1, which is less than n = 2, so there are infinitely many solutions.

Answer: 6.

Find x by Cramer's rule (NAT)

Solve 3x + 2y = 12 and x + 4y = 14 by Cramer's rule. Find x.

How to think about it

  1. What is asked. The value of x.
  2. Which idea applies. x = det(A1) / det(A).
  3. Work it out. det(A) = 12 - 2 = 10. det(A1) = det [[12, 2], [14, 4]] = 20. So x = 2.
  4. Check. y = 3, and 3(2) + 2(3) = 12, 2 + 4(3) = 14.

Answer: 2.

GATE CSE 2014 Set 1 Q4 (verified PYQ): number of solutions (NAT)

Consider four equations in three unknowns x, y and z: 3x + 2y = 1, 4x + 7z = 1, x + y + z = 3, and x - 2y + 7z = 0. Find the number of solutions. Give a single number.

How to think about it

  1. What is asked. How many solutions.
  2. Which idea applies. Solve three equations, then test the fourth.
  3. Work it out. From equation 3, y = 3 - x - z. Equation 1 gives x = 2z - 5. Equation 2 gives 15z = 21, so z = 7/5, x = -11/5, y = 19/5.
  4. Check. Equation 4: -11/5 - 38/5 + 49/5 = 0. All four hold, so the solution is unique.

Answer: 1. This is a verified PYQ from GATE CSE 2014 Set 1, rewritten into the format of this page.

GATE CSE 2008 Q3 (verified PYQ): values of a parameter for a unique solution

Consider x1 + x2 + 2x3 = 1, x1 + 2x2 + 3x3 = 2, and x1 + 4x2 + αx3 = 4. For what values of α does the system have a unique solution?

How to think about it

  1. What is asked. The α giving exactly one solution.
  2. Which idea applies. Unique needs three pivots, so det(A) is not 0.
  3. Work it out. Row 2 minus row 1: (0, 1, 1 | 1). Row 3 minus row 1: (0, 3, α - 2 | 3). Row 3 minus 3 times row 2: (0, 0, α - 5 | 0). So α is not 5.
  4. Check. If α = 5, the last row is zero and the system has infinitely many solutions, never exactly one.

Answer: every real α except α = 5. This is a verified PYQ from GATE CSE 2008 Q3, rewritten into the format of this page.

GATE CSE 2015 Set 3 Q42 (verified PYQ): when does a homogeneous system have a non-trivial solution?

Let px + qy + rz = 0, qx + ry + pz = 0, and rx + py + qz = 0, with p, q and r constants. If the system has a non-trivial solution, which condition holds?
(A) p - q + r = 0 or p = q = -r
(B) p + q - r = 0 or p = -q = r
(C) p + q + r = 0 or p = q = r
(D) p - q + r = 0 or p = -q = -r

How to think about it

  1. What is asked. The condition on p, q and r.
  2. Which idea applies. A square homogeneous system has a non-trivial solution exactly when det = 0.
  3. Work it out. The determinant is 3pqr - (p3 + q3 + r3). Using p3 + q3 + r3 - 3pqr = (p + q + r)(p2 + q2 + r2 - pq - qr - rp), and the second factor is zero only when p = q = r, the determinant is zero when p + q + r = 0 or p = q = r.
  4. Check. With p = q = r = 1, the equations are x + y + z = 0, which has non-zero solutions. Option (C) fits and (A) fails.

Answer: (C). This is a verified PYQ from GATE CSE 2015 Set 3, Q42, rewritten into the format of this page.

GATE CSE 2025 (verified PYQ): classify solutions by k

For the system x + ky = 1 and kx + y = -1, where k is a real constant, classify the solutions for each value of k.

How to think about it

  1. What is asked. The number of solutions for each k.
  2. Which idea applies. det = 1 - k2. If it is not 0, the solution is unique. If it is 0, check the right-hand sides.
  3. Work it out. The determinant is 0 when k = 1 or k = -1. For k = 1: x + y = 1 and x + y = -1 contradict each other, so no solution. For k = -1: x - y = 1 and -x + y = -1 describe the same line, so infinitely many.
  4. Check. For k = 2, det = -3, not 0, so the solution is unique, as the formula says.

Answer: unique for k not equal to 1 or -1; no solution for k = 1; infinitely many for k = -1. This is a verified PYQ from GATE CSE 2025, rewritten into the format of this page.

Non-trivial solutions with a parameter (MSQ)

Consider kx + y + z = 0, x + ky + z = 0, and x + y + kz = 0, with k real. For which values of k does the system have a non-trivial solution?
(A) k = 1
(B) k = -2
(C) k = 0
(D) k = 2

How to think about it

  1. What is asked. The k giving a non-zero solution.
  2. Which idea applies. Square and homogeneous, so the determinant must be 0.
  3. Work it out. The determinant of [[k, 1, 1], [1, k, 1], [1, 1, k]] is (k - 1)2(k + 2), which is 0 at k = 1 and k = -2. The Python block checks each option.
  4. Check. For k = -2, the vector (1, 1, 1) gives -2 + 1 + 1 = 0 in each equation.
def det3(M):
    return (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
            - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
            + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))

for k in [1, -2, 0, 2]:
    M = [[k, 1, 1], [1, k, 1], [1, 1, k]]
    print("k =", k, "det =", det3(M))
k = 1 det = 0
k = -2 det = 0
k = 0 det = 2
k = 2 det = 4

Answer: (A) and (B).

The solution set of a consistent wide system (MSQ)

A is a 4 x 5 matrix of rank 3, and Ax = b is consistent. Select all true statements.

(A) The null space of A has dimension 2
(B) The solution set of Ax = b is a shifted copy of a 2-dimensional subspace
(C) Ax = b has a unique solution
(D) Ax = b has a solution for every b in the column space of A

How to think about it

  1. What is asked. Facts that follow from rank 3 and 5 columns.
  2. Which idea applies. Rank-nullity, and the fact that solutions are one particular solution plus the null space.
  3. Work it out. (A) true, nullity 5 - 3 = 2. (B) true. (C) false, since nullity 2 gives many solutions. (D) true, which is what being in the column space means.
  4. Check. Rank 3 is less than 4 rows, so some b cannot be reached, but (D) only concerns b in the column space.

Answer: (A), (B) and (D).

Exam-level practice

Exam-level 1: Consistency with a parameter (MCQ, 2 marks)

Consider x + y + z = 3, x + 2y + 3z = 6, x + 4y + az = b. For which (a, b) does the system have infinitely many solutions? (A) a = 7, b = 12 (B) a = 7, b ≠ 12 (C) a ≠ 7 (D) a = 6, b = 12

How to think about it

  1. What is asked. The pair (a, b) that gives a rank-deficient but consistent system.
  2. Which idea applies. Row reduce the augmented matrix. Infinitely many solutions need rank(A) = rank([A|b]) less than 3.
  3. Work it out. R2 − R1: (0, 1, 2 | 3). R3 − R1: (0, 3, a − 1 | b − 3). R3 − 3R2: (0, 0, a − 7 | b − 12). So a = 7 and b = 12 makes the last row zero.
  4. Check. With a = 7 and b = 12, both (1, 1, 1) and (2, −1, 2) solve all three equations, so there is more than one solution.

Answer: (A).

Exam-level 2: Solutions of a homogeneous system (NAT, 1 mark)

A is a 4 × 6 real matrix whose rows are linearly independent. What is the dimension of the solution space of Ax = 0?

How to think about it

  1. What is asked. The nullity of A.
  2. Which idea applies. Independent rows means rank(A) = 4. Rank-nullity: nullity = 6 − rank.
  3. Work it out. nullity = 6 − 4 = 2.
  4. Check. A wide matrix always has a nontrivial null space, so the answer must be at least 6 − 4.

Answer: 2.

Exam-level 3: Least squares for an inconsistent system (NAT, 2 marks)

The system x = 1, x = 2, x = 6 has no exact solution. Using the normal equations AᵀAx = Aᵀb, find the least squares value of x. Then find the minimum value of ‖Ax − b‖².

How to think about it

  1. What is asked. The least squares x and the squared residual.
  2. Which idea applies. For a single unknown with A = (1, 1, 1)ᵀ, the normal equation gives the mean of b.
  3. Work it out. AᵀA = 3 and Aᵀb = 9, so x = 3. Residuals are −2, −1, 3, so ‖Ax − b‖² = 4 + 1 + 9 = 14.
  4. Check. The code scans x on a fine grid and confirms the minimum.
best = min((sum((x / 100 - t) ** 2 for t in (1, 2, 6)), x / 100) for x in range(0, 701))
print("min residual^2 = %.2f at x = %.2f" % best)

min residual^2 = 14.00 at x = 3.00

Answer: x = 3 and the minimum ‖Ax − b‖² = 14.

Summary

System of linear equations
Straight-line rules that must hold together.
Matrix form Ax = b
A holds coefficients, x the unknowns, b the right-hand sides.
Augmented matrix
A with b added as an extra column.
Column picture
Ax = b asks for the mix of the columns of A that gives b.
Consistent
At least one solution exists.
Inconsistent
No solution exists.
Unique solution
Consistent, with rank equal to the number of unknowns.
Infinitely many solutions
Consistent, with rank less than the number of unknowns.
Rank test
Consistent exactly when rank(A) = rank([A | b]).
Free variable
An unknown you may choose. The number of free variables is n minus the rank.
Homogeneous system
Ax = 0, always consistent.
Trivial solution
x = 0, always a solution of a homogeneous system.
Non-trivial solution
A non-zero solution of Ax = 0, which exists when rank is less than n.
Cramer's rule
xi = det(Ai) / det(A), when det(A) is not 0.
Parallel lines
Lines with the same direction that never meet, giving no solution.
Row reduction test
Reduce [A | b] and compare its pivots with the number of unknowns.

Remember these

  1. Write a system as Ax = b, and read it as "b is a mix of the columns of A".
  2. Consistent means rank(A) = rank([A | b]).
  3. Unique means rank equals the number of unknowns. Fewer means infinitely many, if consistent.
  4. Homogeneous systems always have the trivial solution x = 0.
  5. A square homogeneous system has a non-trivial solution exactly when the determinant is 0.
  6. Cramer's rule is quick for 2 x 2 and 3 x 3 systems, but needs det(A) not 0.
