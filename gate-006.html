Gaussian elimination

Gaussian elimination is the step-by-step method for solving systems by hand. You clear one unknown at a time with three simple row operations, reach a staircase shape, and then work upward. The same process gives the rank and the inverse, so it is the workhorse of GATE linear algebra.

The idea in plain words

Think of a crossword with clues that depend on each other. A good solver does not guess. One clue removes a letter from the others, the next clue removes another, and slowly the puzzle becomes simple enough to finish. Gaussian elimination does this to a system of equations. It uses one equation to remove one unknown from the equations below it, repeats for each unknown, and leaves a staircase. Then back substitution fills in the answers from the bottom row upward.

Every step is a row operation, and every row operation keeps the solutions exactly the same. For GATE, the same process gives the rank (count the pivots), the determinant (track the sign changes) and the inverse (apply the same steps to the identity matrix).

Key terms

Elementary row operation
One of three allowed moves: swap two rows, multiply a row by a non-zero number, or add a multiple of one row to another.
Augmented matrix, [A | b]
The coefficient matrix with the right-hand side added as an extra column.
Pivot
The entry used to clear the entries below it in a column. It must be non-zero.
Multiplier
The number you multiply a pivot row by before subtracting it.
Forward elimination
Clearing the entries below each pivot, from left to right.
Back substitution
Solving the staircase from the bottom row upward.
Row echelon form (REF)
A staircase with zeros below each pivot, and each pivot to the right of the one above.
Reduced row echelon form (RREF)
A row echelon form where every pivot is 1 and the entries above each pivot are also 0.
Partial pivoting
Choosing the entry with the largest absolute value in the column as the pivot, by swapping rows.
Inverse, A-1
The matrix with A-1A = I.

Why elimination works: the three row operations

Write 2x + y = 3 and x + 3y = 4 as [[2, 1 | 3], [1, 3 | 4]]. Each row is one equation. We may change rows in three ways, and none changes the solution:

  • Swap: exchange two rows, written R1 <-> R2.
  • Scale: multiply a row by a non-zero number, written R2 ← 3R2.
  • Replace: add a multiple of one row to another, written R2 ← R2 - 2R1.

The third move is the engine of elimination. Replacing row 2 by row 2 minus 2 times row 1 clears the first entry of row 2. For the example, use R2 ← R2 - (1/2)R1: row 2 becomes (1 - 1, 3 - 0.5 | 4 - 1.5) = (0, 2.5 | 2.5). Now the second row says 2.5y = 2.5, so y = 1 at once.

Key ideaRow operations keep the solution set exactly the same, because each move can be undone. Elimination never gives a wrong answer if the arithmetic is right.

Apply R2 ← R2 - 3R1 to the row (3, 5 | 7), with pivot row (1, 2 | 4).

Three times row 1 is (3, 6 | 12). Subtract: (0, -1 | -5). The first entry is cleared.

Why is multiplying a row by 0 not allowed?

It turns that equation into 0 = 0, throwing away information, so the solutions can change.

Forward elimination and back substitution, step by step

We solve x + 2y + z = 8, 2x + y + 3z = 13, and 3x + 2y + 2z = 13. The augmented matrix is [[1, 2, 1 | 8], [2, 1, 3 | 13], [3, 2, 2 | 13]].

  1. Row 2. Replace row 2 by row 2 - 2 x row 1: (0, -3, 1 | -3).
  2. Row 3. Replace row 3 by row 3 - 3 x row 1: (0, -4, -1 | -11).
  3. Column 2. The pivot is -3. The multiplier for row 3 is (-4)/(-3) = 4/3. Replace row 3 by row 3 - (4/3) x row 2: (0, 0, -7/3 | -7).

The staircase is [[1, 2, 1 | 8], [0, -3, 1 | -3], [0, 0, -7/3 | -7]]. Back substitution: -7/3 z = -7 gives z = 3. Then -3y + 3 = -3 gives y = 2. Then x + 4 + 3 = 8 gives x = 1. Check: 1 + 4 + 3 = 8, 2 + 2 + 9 = 13, and 3 + 4 + 6 = 13.

The Python block runs the same two stages with exact fractions.

from fractions import Fraction as F

def gauss_solve(A, b):
    n = len(A)
    M = [[F(x) for x in row] + [F(bi)] for row, bi in zip(A, b)]
    for c in range(n):
        p = next(i for i in range(c, n) if M[i][c] != 0)
        M[c], M[p] = M[p], M[c]
        for i in range(c + 1, n):
            m = M[i][c] / M[c][c]
            M[i] = [M[i][k] - m * M[c][k] for k in range(n + 1)]
    x = [F(0)] * n
    for i in range(n - 1, -1, -1):
        s = sum(M[i][k] * x[k] for k in range(i + 1, n))
        x[i] = (M[i][n] - s) / M[i][i]
    return M, x

A = [[1, 2, 1], [2, 1, 3], [3, 2, 2]]
b = [8, 13, 13]
M, x = gauss_solve(A, b)
print("row echelon form:")
for row in M:
    print([str(v) for v in row])
print("solution x, y, z =", [str(v) for v in x])
row echelon form:
['1', '2', '1', '8']
['0', '-3', '1', '-3']
['0', '0', '-7/3', '-7']
solution x, y, z = ['1', '2', '3']

TrapCarry the right-hand side in every row operation. Forgetting it gives a wrong answer even when the coefficients look right.

Row echelon form and reduced row echelon form

A matrix is in row echelon form (REF) when every all-zero row is at the bottom, each pivot is to the right of the pivot above, and all entries below each pivot are zero. The staircase above is in REF, with pivots 1, -3 and -7/3. Its rank is the number of pivots, which is 3.

It is in reduced row echelon form (RREF) when, in addition, every pivot is 1 and every entry above a pivot is 0. Dividing rows to make the pivots 1, and clearing above them, gives:

[ 1  0  0 | 1 ]
[ 0  1  0 | 2 ]
[ 0  0  1 | 3 ]

Read the answer directly: x = 1, y = 2, z = 3. This is Gauss-Jordan elimination.

Key ideaREF is not unique, but RREF is. Both forms have the same pivot positions, so they give the same rank.

TrapDo not call a particular REF "the" answer. Only the RREF is unique.

Is [[1, 2, 0], [0, 0, 1], [0, 0, 0]] in row echelon form?

Yes. The zero row is at the bottom, the pivots move right, and entries below pivots are 0. Its rank is 2.

Is [[2, 4], [0, 3]] in reduced row echelon form?

No. The pivots are 2 and 3, not 1, and the entry 4 above the second pivot is not 0.

Finding the inverse by row reduction

Write A next to the identity, [A | I], and row-reduce the left half to I. The same operations turn the right half into A-1, giving [I | A-1].

Take A = [[1, 1], [2, 3]]. Start with [[1, 1 | 1, 0], [2, 3 | 0, 1]].

  1. Clear below the pivot. Row 2 becomes row 2 - 2 row 1 = (0, 1 | -2, 1).
  2. Clear above the second pivot. Row 1 becomes row 1 - row 2 = (1, 0 | 3, -1).
  3. Read the inverse. A-1 = [[3, -1], [-2, 1]].
  4. Check. Row 1 of A times column 1 of the inverse is 3 - 2 = 1. Row 1 times column 2 is -1 + 1 = 0. Row 2 times column 1 is 6 - 6 = 0. Row 2 times column 2 is -2 + 3 = 1. This gives the identity.

The shear A = [[1, 1], [0, 1]] has the reverse shear as its inverse, [[1, -1], [0, 1]]. The picture shows the first move sliding the grid one way, and the inverse sliding it back.

GATE loves thisA row of zeros on the left half of [A | I] means A has no inverse, so det(A) = 0.

What is the inverse of [[1, 0], [3, 1]]?

[[1, 0], [-3, 1]]. Check: row 2 of A, (3, 1), times column 1, (1, -3), gives 3 - 3 = 0.

What does a row of zeros on the left half of [A | I] tell you?

A is singular and has no inverse.

Pivoting: swapping rows when a pivot is zero

Elimination divides by the pivot, so a zero pivot is a problem. For [[0, 1 | 2], [1, 1 | 3]], the top-left entry is 0. Swap the rows to get [[1, 1 | 3], [0, 1 | 2]]. Then y = 2 and x = 1. Check: 0 + 2 = 2 and 1 + 2 = 3.

In practice, partial pivoting swaps in the row with the largest absolute value in the column. Small pivots create large multipliers, which amplify rounding errors. Each swap changes the sign of the determinant, which matters for the LU page.

TrapWhen you swap rows, swap the whole augmented row, including the right-hand side.

Which row operation starts elimination for [[0, 2], [3, 1]]?

Swap row 1 and row 2, so the new first pivot is 3.

Why prefer partial pivoting?

Because it keeps the multipliers small, so rounding errors stay under control.

GATE ME 1996 (verified PYQ): the shape after elimination

Triangularization in the Gauss elimination method produces which kind of matrix?
(A) diagonal
(B) lower triangular
(C) upper triangular
(D) singular

How to think about it

  1. What is asked. The shape after the elimination stage.
  2. Which idea applies. Forward elimination clears every entry below each pivot.
  3. Work it out. The entries under the diagonal become zero and the rest stay, which is an upper triangular shape.
  4. Check. The staircase [[1, 2, 1], [0, -3, 1], [0, 0, -7/3]] has zeros below the diagonal.

Answer: (C) upper triangular. This is a verified PYQ from GATE ME 1996, rewritten into the format of this page.

Solve a two-by-two system by elimination

Solve x + y = 4 and 2x - y = 2 by elimination.

How to think about it

  1. What is asked. Both unknowns.
  2. Which idea applies. Use row 1 as the pivot to clear the x in row 2.
  3. Work it out. Row 2 minus 2 row 1 gives (0, -3 | -6), so y = 2. Then x + 2 = 4, so x = 2.
  4. Check. 2 + 2 = 4 and 2(2) - 2 = 2.

Answer: x = 2 and y = 2.

Count the pivots (NAT)

Let A = [[1, 2, 3], [2, 4, 7], [3, 6, 10]]. Use row reduction to find the rank of A. Give a single number.

How to think about it

  1. What is asked. The rank, which is the number of pivots.
  2. Which idea applies. Reduce to row echelon form and count non-zero rows.
  3. Work it out. Row 2 minus 2 row 1 is (0, 0, 1). Row 3 minus 3 row 1 is (0, 0, 1). Then row 3 minus row 2 is (0, 0, 0). The staircase has two non-zero rows.
  4. Check. Row 2 is twice row 1 plus (0, 0, 1), and row 3 is three times row 1 plus (0, 0, 1). One row is redundant, so the rank is 2.

Answer: 2.

Find the third unknown by elimination (NAT)

Solve x + y + z = 6, 2x + 3y + z = 10, and x + 2y + 3z = 13. Give the value of z.

How to think about it

  1. What is asked. The value of z.
  2. Which idea applies. Forward elimination, then back substitution.
  3. Work it out. Row 2 becomes (0, 1, -1 | -2) and row 3 becomes (0, 1, 2 | 7). Then row 3 minus row 2 is (0, 0, 3 | 9), so z = 3. Then y = 1 and x = 2.
  4. Check. (2, 1, 3): 6, 10 and 13 all match.

Answer: 3.

An entry of an inverse (NAT)

Let A = [[1, 2], [3, 4]]. The inverse of A is [[p, q], [r, s]]. Find q. Give a single number.

How to think about it

  1. What is asked. The entry in row 1, column 2 of A-1.
  2. Which idea applies. Row-reduce [A | I] to [I | A-1].
  3. Work it out. Row 2 minus 3 row 1 gives (0, -2 | -3, 1). Divide by -2: (0, 1 | 3/2, -1/2). Row 1 minus 2 row 2 gives (1, 0 | -2, 1). So A-1 = [[-2, 1], [3/2, -1/2]], and q = 1.
  4. Check. Row 1 of A times column 2 of the inverse is 1(1) + 2(-1/2) = 0.

Answer: 1.

True statements about echelon forms (MSQ)

Let A be a matrix. Select all true statements.

(A) The row echelon form of A is unique.
(B) The reduced row echelon form has a 1 in each pivot position and zeros above and below each pivot.
(C) The row echelon form has zeros below each pivot.
(D) The number of non-zero rows in any row echelon form of A equals the rank of A.

How to think about it

  1. What is asked. Test four facts.
  2. Which idea applies. REF is not unique, RREF is, and the pivot count is the rank.
  3. Work it out. (A) false. (B) true, by definition. (C) true, by definition. (D) true.
  4. Check. The only false statement is the uniqueness claim.

Answer: (B), (C) and (D).

A parameter that controls the solutions (NAT)

Consider x + y + z = 1, x + 2y + 3z = 2, and x + 3y + az = b. Suppose a = 5. For which value of b does the system have infinitely many solutions? Give a single number.

How to think about it

  1. What is asked. The b that makes the system consistent with a free variable.
  2. Which idea applies. Row-reduce with a = 5 and see what the last row says.
  3. Work it out. Row 2 minus row 1 is (0, 1, 2 | 1). Row 3 minus row 1 is (0, 2, 4 | b - 1). Row 3 minus 2 row 2 is (0, 0, 0 | b - 3). So b = 3, and the rank is 2 with one free variable.
  4. Check. With b = 3, z = 0 gives (0, 1, 0), and z = 1 gives (1, -1, 1). Both satisfy all three equations.

Answer: 3.

Describe the solution set (MSQ)

Use the system from the previous problem with a = 5 and b = 3: x + y + z = 1, x + 2y + 3z = 2, and x + 3y + 5z = 3. Select all true statements.

(A) The system has a unique solution.
(B) The system has infinitely many solutions.
(C) The rank of the coefficient matrix is 2.
(D) The solution set is a line in three-dimensional space.

How to think about it

  1. What is asked. The nature of the solution set.
  2. Which idea applies. Count pivots for the rank, then count free variables.
  3. Work it out. The staircase is [[1, 1, 1 | 1], [0, 1, 2 | 1], [0, 0, 0 | 0]]. Two pivots, so the rank is 2, and there is one free variable. So (B), (C) and (D) are true, and (A) is false.
  4. Check. With z = t: y = 1 - 2t and x = t, so the solutions are (t, 1 - 2t, t). At t = 0, (0, 1, 0) satisfies all three equations.

Answer: (B), (C) and (D).

Exam-level practice

Exam-level 1: Pivot count after elimination (NAT, 2 marks)

Apply Gaussian elimination to A = [[1, 2, 1, 3], [2, 4, 3, 7], [3, 6, 4, 10]]. How many pivots does the echelon form have?

How to think about it

  1. What is asked. The number of pivots, which equals the rank.
  2. Which idea applies. Eliminate below each pivot and count nonzero rows.
  3. Work it out. R2 − 2R1 = (0, 0, 1, 1). R3 − 3R1 = (0, 0, 1, 1). R3 − R2 = 0. So there are 2 pivots (columns 1 and 3).
  4. Check. The code reduces A exactly.
from fractions import Fraction as F
M = [[F(x) for x in r] for r in [[1, 2, 1, 3], [2, 4, 3, 7], [3, 6, 4, 10]]]
r, piv = 0, []
for c in range(4):
    p = next((i for i in range(r, 3) if M[i][c] != 0), None)
    if p is None:
        continue
    M[r], M[p] = M[p], M[r]
    for i in range(r + 1, 3):
        M[i] = [a - M[i][c] / M[r][c] * b for a, b in zip(M[i], M[r])]
    piv.append(c + 1); r += 1
print("pivot columns:", piv)

pivot columns: [1, 3]

Answer: 2.

Exam-level 2: Operation count (MCQ, 1 mark)

Gaussian elimination without pivoting on a dense n × n system needs about how many multiplications for large n? (A) n² (B) n³/3 (C) 2n³ (D) n log n

How to think about it

  1. What is asked. The leading order cost of forward elimination.
  2. Which idea applies. At step k, about (n − k)² entries are updated.
  3. Work it out. The sum of (n − k)² for k = 1 to n is about n³/3.
  4. Check. For n = 100, the code counts updates directly and compares with n³/3.
n = 100
print(sum((n - k) * (n - k + 1) for k in range(1, n)), round(n ** 3 / 3))

Answer: (B).

Exam-level 3: Back substitution value (NAT, 2 marks)

Solve 2x + y − z = 8, −3x − y + 2z = −11, −2x + y + 2z = −3 by Gaussian elimination. Find x + y + z.

How to think about it

  1. What is asked. The solution, then the sum of the three unknowns.
  2. Which idea applies. Eliminate x from rows 2 and 3, then y from row 3, and back substitute.
  3. Work it out. R2 + 1.5R1: (0, 0.5, 0.5 | 1). R3 + R1: (0, 2, 1 | 5). R3 − 4R2: (0, 0, −1 | 1), so z = −1. Then 0.5y − 0.5 = 1 gives y = 3. Then 2x + 3 + 1 = 8 gives x = 2. Sum = 2 + 3 − 1 = 4.
  4. Check. The code substitutes back into the original equations.
x, y, z = 2, 3, -1
print(2*x + y - z, -3*x - y + 2*z, -2*x + y + 2*z, "sum =", x + y + z)

8 -11 -3 sum = 4

Answer: 4.

Summary

Elementary row operation
Swap rows, scale a row by a non-zero number, or add a multiple of one row to another.
Augmented matrix
The coefficients with the right-hand side as an extra column.
Pivot
The entry used to clear the entries below it. Must be non-zero.
Multiplier
The number of copies of the pivot row to subtract.
Forward elimination
Clearing entries below each pivot, column by column.
Back substitution
Solving a staircase from the bottom row upward.
Row echelon form (REF)
A staircase with zeros below each pivot.
Reduced row echelon form (RREF)
Pivots equal to 1, with zeros above and below each pivot. Unique for each matrix.
Gauss-Jordan elimination
Row reduction all the way to RREF.
Inverse by row reduction
Row-reduce [A | I] to [I | A-1].
Zero pivot
Swap with a lower row that has a non-zero entry in that column.
Partial pivoting
Choose the largest absolute value in the column as the pivot.
Rank from REF
The number of pivots.
Free variable
A column with no pivot. Each one gives a direction of solutions.
Staircase
The shape of a matrix in row echelon form, with pivots moving right.
Forward and back substitution
The two stages used to solve a staircase system.

Remember these

  1. Only three row operations are allowed, and none of them changes the solutions.
  2. Forward elimination makes a staircase, and back substitution reads the answer from the bottom up.
  3. Always carry the right-hand side along with each row.
  4. If a pivot is zero, swap in a lower row with a non-zero entry in that column.
  5. To find an inverse, row-reduce [A | I] to [I | A-1].
  6. The number of pivots is the rank. Compare it with the number of unknowns to test uniqueness.
