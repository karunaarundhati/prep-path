Forward kinematics

Forward kinematics answers one question: if we know every joint value of a robot arm, where is the tool and which way is it pointing? This topic explains the idea with a simple planar arm, then introduces the Denavit-Hartenberg (DH) table, which turns any serial arm into a chain of 4 by 4 matrices. Forward kinematics is the most common GATE Robotics calculation.

The idea in plain words

Close your eyes and bend your elbow by 30 degrees and your shoulder by 60 degrees. You can roughly feel where your hand is, even without seeing it. Your brain knows the angles of the joints, and it works out the hand position from them. That calculation is called forward kinematics.

In a robot, we know the joint values because the motors report them. We want the position and orientation of the tool. Forward kinematics takes the joint values as input and gives the tool pose as output. It is always a direct calculation, with one correct answer for each set of joint values.

Everyday analogy. Think of a row of linked bicycle chain links, each one attached to the next with a hinge. If you know the angle at each hinge, you can compute where the last link ends up, by adding up the steps one after another.

Why it matters. A controller does forward kinematics many times a second, to check where the tool is. A simulator uses it to draw the arm. Designers use it to test whether a tool can reach a target before any hardware is built.

Where it appears in GATE. In the Robotics and Automation (RA) paper, you may be asked for the end-effector position of a two- or three-link arm for given joint angles, or for the DH parameters of a simple arm. These are direct calculations, and the steps must be followed in order.

Key terms

Forward kinematics
The calculation of the tool position and orientation from the joint values. Plain meaning: from the joints to the hand.
Inverse kinematics
The reverse problem: from a desired tool pose to the joint values. Plain meaning: from the hand to the joints.
Joint value
The current value of a joint, an angle for a revolute joint or a distance for a prismatic joint.
Link length (a)
The distance between two joint axes, measured along the common perpendicular.
Link twist (α)
The angle between two neighbouring joint axes, measured about the common perpendicular.
Link offset (d)
The distance along a joint axis from one common perpendicular to the next.
Joint angle (θ)
The angle about a joint axis between the two neighbouring links. For a revolute joint, it is the joint value.
Denavit-Hartenberg (DH) convention
A standard way of choosing frames on a serial arm, so that each link is described by four numbers: a, α, d and θ.
DH table
A list with one row for each link, giving its a, α, d and θ values.
Transform Ai
The 4 by 4 matrix that moves from frame i − 1 to frame i for link i.
End-effector pose
The position and orientation of the tool, found as the product of all the link transforms.

What forward kinematics asks

From joints to tool

Forward kinematics is a function. Its input is the list of joint values, and its output is the tool pose. Written in symbols, the tool pose is a function f of the joint values q = (q1, q2, ..., qn). For a given q, there is exactly one tool pose. This makes forward kinematics easier than its reverse, inverse kinematics, which can have several answers.

tool pose = f(q1, q2, ..., qn)

Two ways to do it

There are two common methods. The first is geometry: draw the arm, add up the link vectors, and use sines and cosines. This works well for a planar arm with two or three links. The second is systematic: choose a frame on each link, write one 4 by 4 transform for each link, and multiply them. This method works for any serial arm, and it is what the DH convention supports.

We start with the geometric method, then move to DH.

What are the inputs and the output of forward kinematics?

The input is the list of joint values. The output is the tool position and orientation.

Why is forward kinematics usually easier than inverse kinematics?

Each set of joint values gives exactly one tool pose. The inverse problem can have several joint solutions for one pose, so it is harder.

Forward kinematics of a planar two-link arm

The picture

A planar two-link arm has two rigid links of lengths l1 and l2. The first joint at the base has angle θ1, measured from the x-axis. The second joint has angle θ2, measured from the direction of the first link.

                  tool (x, y)
                     o
                    /
                   /  link 2, length l2
                  /    at angle θ1 + θ2 from the x-axis
        elbow    o
                / \
               /   \ link 1, length l1
              /     \   at angle θ1 from the x-axis
    -------- o ----------------------------------- x-axis
          base

    θ1 is the base joint angle, θ2 is the elbow angle.

Adding up the two link vectors

The tool position is the base point plus the vector of link 1 plus the vector of link 2. Link 1 points at angle θ1, so its vector is (l1 cos θ1, l1 sin θ1). Link 2 points at angle θ1 + θ2, because the elbow angle is measured from link 1. So its vector is (l2 cos(θ1 + θ2), l2 sin(θ1 + θ2)). Adding them gives

x = l1 cos θ1 + l2 cos(θ1 + θ2)
y = l1 sin θ1 + l2 sin(θ1 + θ2)

Symbols: x and y are the tool coordinates, l1 and l2 are the link lengths, and the angles are in radians or degrees, consistently.

Worked example

Take l1 = l2 = 1 m, θ1 = 30° and θ2 = 60°. Then θ1 + θ2 = 90°.

  1. x = 1 × cos 30° + 1 × cos 90° = 0.866 + 0 = 0.866 m.
  2. y = 1 × sin 30° + 1 × sin 90° = 0.5 + 1 = 1.5 m.
  3. The tool is at (0.87, 1.50) m, to two decimals.
import math
l1, l2 = 1.0, 1.0
t1, t2 = math.radians(30), math.radians(60)
x = l1 * math.cos(t1) + l2 * math.cos(t1 + t2)
y = l1 * math.sin(t1) + l2 * math.sin(t1 + t2)
print(f"end effector = ({x:.2f}, {y:.2f})")
end effector = (0.87, 1.50)

TrapThe second link angle is measured from the first link, not from the x-axis. So link 2 is at θ1 + θ2 in the world. Forgetting to add θ1 is the most common mistake in planar forward kinematics.

Key ideaEach link adds one vector to the chain. Its direction is the sum of all the joint angles up to that link.

For l1 = 2, l2 = 1, θ1 = θ2 = 0, where is the tool?

At (3, 0). Both links point along the x-axis, so their lengths add.

What is the tool position when θ2 = 180° and l1 = l2?

At the origin. Link 2 folds exactly back over link 1, and the two vectors cancel.

The Denavit-Hartenberg parameters

Why a standard convention

For a planar arm, the geometry is easy to draw. For a spatial arm with six joints, the links point in all directions, and drawing the vectors becomes very hard. The Denavit-Hartenberg convention solves this. It places a frame on each link in a standard way, so that only four numbers per link are needed. These four numbers fill a DH table, and the table fully describes the arm.

For each link i, the four parameters are:

  • ai (link length): the distance along xi from zi−1 to zi. It is the length of link i.
  • αi (link twist): the angle about xi from zi−1 to zi. It says how the next joint axis is turned relative to this one.
  • di (link offset): the distance along zi−1 from xi−1 to xi. It is the sliding distance for a prismatic joint.
  • θi (joint angle): the angle about zi−1 from xi−1 to xi. It is the joint value for a revolute joint.

Here zi is the axis of joint i + 1, and xi is the common perpendicular between the joint axes. For a revolute joint, θi is the variable, and di is fixed. For a prismatic joint, di is the variable, and θi is fixed.

  Two joint axes, joined by link i

       z(i-1)                 z(i)
         |                      |
         |  d(i) (slide along   |
         |  z(i-1))             |
         +-----------a(i)-------+   <- a(i): along x(i)
         |                      |
        theta(i) (turn about     alpha(i) (turn about x(i)
        z(i-1))                  from z(i-1) to z(i))

  Read the four numbers from the figure:
    a = length along x,  alpha = twist about x,
    d = slide along z,   theta = turn about z.

Reading a DH table

A DH table for a planar two-link arm with both joints revolute has two rows, one for each link. In a planar arm, all the twists and offsets are zero, and only the link lengths and joint angles are nonzero. The table below is an example for such an arm.

Linka (m)α (rad)d (m)θ
1l100θ1 (variable)
2l200θ2 (variable)
Which DH parameter is the variable for a prismatic joint?

The link offset d. The joint angle θ is fixed for a prismatic joint.

In a planar arm with all joints in the plane, what are the link twists?

Zero. All joint axes are parallel, so there is no twist between neighbouring axes.

Building the DH transform matrix

Four simple moves

Each link transform is made by four simple moves, applied in a fixed order: turn about z by θ, slide along z by d, slide along x by a, and turn about x by α. In matrix form,

Ai = Rz(θi) Tz(di) Tx(ai) Rx(αi)

Multiplying these four basic matrices gives the standard DH matrix, which is what you should use in practice.

A(i) =
[ cos θ   −sin θ cos α    sin θ sin α    a cos θ ]
[ sin θ    cos θ cos α   −cos θ sin α    a sin θ ]
[ 0        sin α          cos α          d       ]
[ 0        0              0              1       ]

The first three columns hold the rotation of frame i relative to frame i − 1. The fourth column holds its position. The last row is always (0, 0, 0, 1).

The planar case simplifies

For a planar arm, α = 0 and d = 0 for every link. Then sin α = 0 and cos α = 1, and the matrix becomes

A(i) for a planar revolute link (alpha = 0, d = 0)

[ cos θ   −sin θ   0   a cos θ ]
[ sin θ    cos θ   0   a sin θ ]
[ 0        0       1   0       ]
[ 0        0       0   1       ]

Notice that the position part is (a cos θ, a sin θ, 0). That is exactly the link vector from the geometric method. So the matrix method and the geometric method agree.

Checking the matrix against the geometry

The Python check below builds the two link matrices with the DH formula, multiplies them, and reads off the tool position. It must match the geometric formulas from the previous unit.

import math

def dh(a, alpha, d, theta):
    ct, st = math.cos(theta), math.sin(theta)
    ca, sa = math.cos(alpha), math.sin(alpha)
    return [[ct, -st * ca, st * sa, a * ct],
            [st, ct * ca, -ct * sa, a * st],
            [0.0, sa, ca, d],
            [0.0, 0.0, 0.0, 1.0]]

def matmul4(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(4)) for j in range(4)] for i in range(4)]

l1, l2 = 1.0, 1.0
t1, t2 = math.radians(30), math.radians(60)
T = matmul4(dh(l1, 0, 0, t1), dh(l2, 0, 0, t2))
print(f"DH end effector = ({T[0][3]:.2f}, {T[1][3]:.2f})")
DH end effector = (0.87, 1.50)

GATE loves thisFor a planar arm, the position of the tool is the fourth column of the product of the link matrices. Learn to read that column; it gives x and y directly.

TrapUse the same order of the four moves for every link. Some books use different DH variants, so check which convention a question uses. The standard convention above is the one this topic follows.

What is the fourth column of the DH matrix Ai?

(ai cos θi, ai sin θi, di, 1), giving the position of frame i in frame i − 1.

For a planar link with α = 0 and d = 0, what is the position part?

(a cos θ, a sin θ, 0), which is the link vector of length a at angle θ.

Chaining links to find the tool pose

Multiply in order

The tool pose is the product of all the link transforms, from the base outward. For a three-link arm,

Ttool = A1 A2 A3

The product is read from the base outward, and when you apply it to a point, the rightmost matrix acts first. The position of the tool is then the fourth column of Ttool, and the orientation is its upper-left 3 by 3 block.

Planar three-link arm

For a planar arm with three revolute links, the same method gives the tool position as a sum of three link vectors, each at the sum of the angles up to that link.

x = l1 cos θ1 + l2 cos(θ1 + θ2) + l3 cos(θ1 + θ2 + θ3)
y = l1 sin θ1 + l2 sin(θ1 + θ2) + l3 sin(θ1 + θ2 + θ3)

Each new link adds the next angle to the running total. This is the pattern to remember: the angle of link k is the sum of the first k joint angles.

Worked example

Take l1 = 1, l2 = 0.5, l3 = 0.5 (in metres), θ1 = 0°, θ2 = 90°, θ3 = −90°. The running angles are 0°, 90° and 0°.

  1. x = 1 cos 0° + 0.5 cos 90° + 0.5 cos 0° = 1 + 0 + 0.5 = 1.5 m.
  2. y = 1 sin 0° + 0.5 sin 90° + 0.5 sin 0° = 0 + 0.5 + 0 = 0.5 m.
  3. The tool is at (1.5, 0.5) m. The third link points back along the x-axis, because its running angle is 0°.

Key ideaForward kinematics is repetitive. Once you can compute one link vector, the whole arm is that same step repeated, with the angles added up as you go.

TipWrite the running angle beside each link before you compute anything. It prevents the most common mistake, which is using a relative angle as if it were an absolute one.

In the three-link example, what is the running angle of link 3?

0°, because θ1 + θ2 + θ3 = 0 + 90° − 90° = 0°.

Why do we add the joint angles as we go along the chain?

Each joint angle is measured relative to the link before it. To get the direction of a link in the base frame, we add all the joint angles up to that link.

Solved GATE-style problems

These problems are original, written in the style of GATE multiple select and numerical questions. They are not past exam questions.

Tool position with zero angles

A planar two-link arm has l1 = 2 m and l2 = 1 m. Both joint angles are zero. What is the x-coordinate of the tool, in metres? (Numerical answer.)

How to think about it

  1. What is asked. The x-coordinate of the tool when the arm is straight and along the x-axis.
  2. Which idea applies. x = l1 cos θ1 + l2 cos(θ1 + θ2).
  3. Work it out. With θ1 = θ2 = 0, cos 0 = 1. So x = 2 × 1 + 1 × 1 = 3 m.
  4. Check. The arm is straight, so the total reach is the sum of the lengths, 2 + 1 = 3 m.

Answer: 3 m.

Which statements about DH parameters are true

Select all that apply.

(A) ai is the link length.
(B) di is the link offset along z.
(C) θi is the joint angle, and it is the variable for a revolute joint.
(D) αi is the joint angle.

How to think about it

  1. What is asked. Which statements about the four DH parameters are correct.
  2. Which idea applies. The four parameters are link length a, link twist α, link offset d and joint angle θ.
  3. Work it out. (A) is true. (B) is true. (C) is true. (D) is false, since α is the link twist, and the joint angle is θ.
  4. Check. Remember the pairs: a is length, α is twist, d is offset, θ is joint angle.

Answer: (A), (B) and (C).

The x-coordinate of a bent two-link arm

A planar two-link arm has l1 = l2 = 1 m, θ1 = 90° and θ2 = −90°. What is the x-coordinate of the tool, in metres? (Numerical answer.)

How to think about it

  1. What is asked. The x-coordinate of the tool for these angles.
  2. Which idea applies. x = l1 cos θ1 + l2 cos(θ1 + θ2).
  3. Work it out. θ1 + θ2 = 0°. So x = 1 × cos 90° + 1 × cos 0° = 0 + 1 = 1 m.
  4. Check. The first link points straight up, and the second link points back to the right along x. The tool is at (1, 1), so x = 1 is consistent.

Answer: 1 m.

Tool position for an unusual pair of angles

A planar two-link arm has l1 = 2 m and l2 = 1 m. The joint angles are θ1 = 60° and θ2 = 90°. What is the x-coordinate of the tool, in metres, to two decimal places? (Numerical answer.)

How to think about it

  1. What is asked. The x-coordinate of the tool, to two decimals.
  2. Which idea applies. x = l1 cos θ1 + l2 cos(θ1 + θ2).
  3. Work it out. θ1 + θ2 = 150°. So x = 2 cos 60° + 1 cos 150° = 2 × 0.5 + (−0.866) = 1 − 0.866 = 0.134 m, which is 0.13 m to two decimals.
  4. Check. The tool is close to the base, because the second link folds back against the first. A small x is expected.
import math
l1, l2 = 2.0, 1.0
t1, t2 = math.radians(60), math.radians(90)
x = l1 * math.cos(t1) + l2 * math.cos(t1 + t2)
print(f"x = {x:.2f} m")
x = 0.13 m

Answer: 0.13 m.

Statements about serial forward kinematics

Select all that apply.

(A) The DH transform of a serial arm is the product of its link transforms, taken from the base outward.
(B) Changing the order of the link transforms can change the tool pose.
(C) For a planar RRR arm, one set of joint angles gives one tool pose.
(D) The inverse of a two-link planar arm always has exactly one joint solution for each tool point.

How to think about it

  1. What is asked. Which statements about forward and inverse kinematics are correct.
  2. Which idea applies. Forward kinematics is a function from joint values to pose. Matrices do not commute in general, so their order matters. Inverse kinematics can have several solutions.
  3. Work it out. (A) is true. (B) is true. (C) is true, since forward kinematics is a function. (D) is false, because a two-link arm usually has two solutions, the elbow up and the elbow down.
  4. Check. The elbow-up and elbow-down pair is the standard example that shows (D) is false.

Answer: (A), (B) and (C).

Y-coordinate of a three-link planar arm

A planar three-link arm has link lengths l1 = 1 m, l2 = 0.5 m and l3 = 0.5 m. The joint angles are θ1 = 0°, θ2 = 90° and θ3 = −90°. What is the y-coordinate of the tool, in metres? (Numerical answer.)

How to think about it

  1. What is asked. The y-coordinate of the tool for a three-link planar arm.
  2. Which idea applies. Each link's direction is the sum of the joint angles up to that link. So the running angles are 0°, 90° and 0°.
  3. Work it out. y = l1 sin 0° + l2 sin 90° + l3 sin 0° = 0 + 0.5 × 1 + 0 = 0.5 m.
  4. Check. The Python check below builds the same arm from DH matrices and gets the same y-coordinate.
import math

def dh(a, alpha, d, theta):
    ct, st = math.cos(theta), math.sin(theta)
    ca, sa = math.cos(alpha), math.sin(alpha)
    return [[ct, -st * ca, st * sa, a * ct],
            [st, ct * ca, -ct * sa, a * st],
            [0.0, sa, ca, d],
            [0.0, 0.0, 0.0, 1.0]]

def matmul4(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(4)) for j in range(4)] for i in range(4)]

links = [(1.0, 0.0, 0.0, math.radians(0)),
         (0.5, 0.0, 0.0, math.radians(90)),
         (0.5, 0.0, 0.0, math.radians(-90))]
T = dh(*links[0])
for L in links[1:]:
    T = matmul4(T, dh(*L))
print(f"tool = ({round(T[0][3], 6) + 0.0:.2f}, {round(T[1][3], 6) + 0.0:.2f})")
tool = (1.50, 0.50)

Answer: 0.5 m.

Which statements about a two-link arm with equal links

A planar two-link arm has l1 = l2 = L. Select all that apply.

(A) If θ2 = 180°, the tool is at the origin for every θ1.
(B) The tool is never farther than 2L from the base.
(C) If θ2 = 0°, the arm is fully folded.
(D) The closest the tool can get to the base is 0 when the links are equal.

How to think about it

  1. What is asked. Which statements about the equal-link two-link arm are true.
  2. Which idea applies. With θ2 = 180°, the link vectors are opposite, so x = L cos θ1 − L cos θ1 = 0 and y = 0 likewise.
  3. Work it out. (A) is true, as just shown. (B) is true, since the maximum reach is l1 + l2 = 2L. (C) is false: θ2 = 0° makes the arm fully straight, so the reach is 2L, not folded. (D) is true, because the minimum reach is |l1 − l2| = 0.
  4. Check. Look at (A) and (D) together: when θ2 = 180°, the tool is at the base, which is the minimum reach of 0.

Answer: (A), (B) and (D).

Exam-level practice

Exam-level 1: Two link planar arm (NAT, 2 marks)

A planar 2R arm has l1 = 1 m and l2 = 0.5 m. With θ1 = 30° and θ2 = 60°, find the x coordinate of the end effector, correct to 3 decimal places.

How to think about it

  1. What is asked. x = l1cos θ1 + l2cos(θ1 + θ2).
  2. Which idea applies. Add the link vectors.
  3. Work it out. 0.866 + 0.5 cos 90° = 0.866.
  4. Check. y = 0.5 + 0.5 = 1.
import math
t1, t2 = math.radians(30), math.radians(60)
print("x = %.3f, y = %.3f" % (math.cos(t1) + 0.5 * math.cos(t1 + t2), math.sin(t1) + 0.5 * math.sin(t1 + t2)))

x = 0.866, y = 1.000

Answer: about 0.866 m.

Exam-level 2: Workspace (NAT, 2 marks)

For the same arm with full joint ranges, find the area of its reachable workspace, correct to 3 decimal places.

How to think about it

  1. What is asked. The area of an annulus.
  2. Which idea applies. Reach is from |l1 − l2| to l1 + l2.
  3. Work it out. π(1.5² − 0.5²) = 2π = 6.283 m².
  4. Check. The code computes it.
import math
print("%.3f" % (math.pi * (1.5 ** 2 - 0.5 ** 2)))

6.283

Answer: about 6.283 m².

Exam-level 3: DH parameters (MSQ, 2 marks)

In the standard Denavit-Hartenberg convention, which are TRUE? (A) Each link is described by four parameters. (B) For a revolute joint, θ is the variable. (C) For a prismatic joint, d is the variable. (D) a is the angle between successive z axes.

How to think about it

  1. What is asked. DH convention facts.
  2. Which idea applies. Parameters a, α, d, θ. a is a length and α is a twist angle.
  3. Work it out. (A) True. (B) True. (C) True. (D) That is α. False.
  4. Check. a is the distance along x between z axes.

Answer: (A), (B) and (C).
