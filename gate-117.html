Exact inference: Variable elimination

Variable elimination answers a probability question in a Bayesian network by repeatedly multiplying small tables and adding out variables we do not care about. It is the standard exact method, and its speed depends on the order we choose.

117Unit 9 · Artificial intelligence · Paper DA · Quick Recap
  • Factors: the tables behind a network
  • Four operations: restrict, multiply, sum out, normalize
  • Elimination order and cost

The idea in plain words

Imagine a detective with a list of clues. Each clue links a few suspects. The detective does not need to think about everyone at once. She can combine two clues, write down what they say together about fewer people, and then forget a suspect she no longer needs. Step by step, the list shrinks until only the answer is left.

Variable elimination works in the same way on a Bayesian network. We want a probability, such as the chance that it was cloudy given that the grass is wet. Instead of building the full joint table of every combination, we work with small tables, called factors. We multiply the tables that share a variable, then add up (sum out) that variable. Each variable we no longer need is eliminated.

Everyday analogy: adding a long column of numbers. You do not write every partial sum on one huge sheet. You add a few at a time and keep only the running total.

Why it matters for GATE. In the Data Science and AI (DA) paper, you may be given a small network with its tables and asked for a query probability. You will need to show the factor steps, or choose a good elimination order. The arithmetic is short, but every step must be written out.

Key terms

Bayesian network
A directed acyclic graph (DAG) of variables, where each variable has a conditional probability table (CPT) given its parents.
Factor
Plain: a table of numbers over some variables. Precise: a function that gives a number for each assignment to its variables.
Query
The probability we want, such as P(C = 1 | W = 1).
Evidence
Variables whose values we know, such as W = 1.
Restrict (condition)
Keep only the rows of a factor that agree with the evidence.
Multiply factors
For each assignment, multiply the values of the factors. The result is over the union of their variables.
Sum out (marginalize)
Remove a variable by adding its values together for each assignment of the others.
Normalize
Divide each value by the total, so that the values add up to 1.
Elimination order
The order in which the hidden variables are summed out.

Concept 1: Factors: the tables behind a network

Use a small network to start. Cloudy (C) affects Rain (R), and Rain affects Wet grass (W). Each variable is yes (1) or no (0).

      Cloudy (C)  ->  Rain (R)  ->  Wet grass (W)

Here are the numbers. Read each one carefully, because the conditioning variable is always the one after the bar.

  • P(C = 1) = 1/2, so P(C = 0) = 1/2.
  • P(R = 1 | C = 1) = 4/5, and P(R = 1 | C = 0) = 1/5.
  • P(W = 1 | R = 1) = 9/10, and P(W = 1 | R = 0) = 1/10.

Each CPT is already a factor. P(C) is a factor over C alone. P(R | C) is a factor over R and C, with four entries. P(W | R) is a factor over W and R. The network's joint probability is the product of these three factors:

P(C, R, W) = P(C) × P(R | C) × P(W | R)

Here × means multiply. To get the probability of one row, multiply one entry from each factor. For example, P(C = 1, R = 1, W = 1) = 1/2 × 4/5 × 9/10 = 36/100 = 9/25.

Key ideaVariable elimination never builds the full joint table on purpose. It multiplies and sums factors in an order that keeps each table small.

The four operations

  1. Restrict. If we know W = 1, keep only the entries of P(W | R) where W = 1. This gives a factor over R alone: 9/10 when R = 1 and 1/10 when R = 0.
  2. Multiply. Multiply factors that share a variable, one entry at a time.
  3. Sum out. Remove a variable X by adding the two values for X = 0 and X = 1. For each setting of the other variables, add across X.
  4. Normalize. At the end, divide by the total so the probabilities add to 1.
Question: A factor has two binary variables. How many entries does it have?

4, because each variable has 2 values and 2 × 2 = 4.

Question: After restricting P(W | R) to W = 1, what is the value when R = 0?

1/10. The table says P(W = 1 | R = 0) = 1/10.

Concept 2: Variable elimination in a worked example

The query is P(C = c | W = 1) for each value of C. Variables C and R are not in the query, so R is hidden and we eliminate it. C is the query variable, so it stays. The steps follow the four operations.

  1. Start with the factors. P(C), P(R | C), and P(W = 1 | R).
  2. Restrict. The factor P(W = 1 | R) is already over R alone: value 9/10 at R = 1 and 1/10 at R = 0.
  3. Multiply and sum out R. Form the new factor f(C) = sum over R of P(R | C) × P(W = 1 | R).
    • For C = 1: P(R = 1 | C = 1) × 9/10 + P(R = 0 | C = 1) × 1/10 = 4/5 × 9/10 + 1/5 × 1/10 = 36/50 + 1/50 = 37/50.
    • For C = 0: P(R = 1 | C = 0) × 9/10 + P(R = 0 | C = 0) × 1/10 = 1/5 × 9/10 + 4/5 × 1/10 = 9/50 + 4/50 = 13/50.
  4. Multiply by P(C). P(C = 1) × 37/50 = 37/100. P(C = 0) × 13/50 = 13/100.
  5. Normalize. The total is 37/100 + 13/100 = 50/100 = 1/2. This total is P(W = 1), the chance of wet grass.
  6. Divide. P(C = 1 | W = 1) = (37/100) / (1/2) = 37/50. P(C = 0 | W = 1) = (13/100) / (1/2) = 13/50.

Here is the same calculation in Python. Exact fractions keep every number exact, so the printed answers can be checked by hand. The last block checks the answer by brute force, adding up every row of the full joint table.

from fractions import Fraction as F
from itertools import product

pC = {1: F(1, 2), 0: F(1, 2)}     # P(C = c)
pR = {1: F(4, 5), 0: F(1, 5)}     # pR[c] = P(R = 1 | C = c)
pW = {1: F(9, 10), 0: F(1, 10)}   # pW[r] = P(W = 1 | R = r)

def prob_r(r, c):
    return pR[c] if r == 1 else 1 - pR[c]

# Step 1: restrict the factor for W to the evidence W = 1
f_w = {r: pW[r] for r in (0, 1)}

# Step 2: multiply P(R | C) by the evidence factor, then sum out R
f_c = {}
for c in (0, 1):
    f_c[c] = sum(prob_r(r, c) * f_w[r] for r in (0, 1))
print("f(C=0) after summing out R =", f_c[0])
print("f(C=1) after summing out R =", f_c[1])

# Step 3: multiply by P(C) and normalize
unnorm = {c: pC[c] * f_c[c] for c in (0, 1)}
Z = sum(unnorm.values())
print("P(W=1) =", Z)
for c in (0, 1):
    print("P(C=%d | W=1) = %s" % (c, unnorm[c] / Z))

# Brute-force check over all rows of the joint distribution
def joint(c, r, w):
    pw = pW[r] if w == 1 else 1 - pW[r]
    return pC[c] * prob_r(r, c) * pw

num = sum(joint(1, r, 1) for r in (0, 1))
den = sum(joint(c, r, 1) for c in (0, 1) for r in (0, 1))
print("Brute force P(C=1 | W=1) =", num / den)
f(C=0) after summing out R = 13/50
f(C=1) after summing out R = 37/50
P(W=1) = 1/2
P(C=0 | W=1) = 13/50
P(C=1 | W=1) = 37/50
Brute force P(C=1 | W=1) = 37/50

TrapDo not forget to normalize. The numbers 37/100 and 13/100 do not add to 1 for the query. They add to P(W = 1) = 1/2. Dividing by that total gives the conditional probability.

Question: Why did we sum out R and not C?

R is hidden and not in the query, and not given as evidence. C is the query variable, so it must stay in the answer.

Question: What does the total 1/2 in the worked example mean?

It is P(W = 1), the probability that the grass is wet before we normalize.

Concept 3: Elimination order and cost

The answer does not depend on the order in which hidden variables are summed out. The work does. Each factor has a size, which is the number of entries. For binary variables, a factor over k variables has 2k entries. Variable elimination is fast when every factor it creates stays small.

Take the chain A → B → C and the query P(C). A and B are hidden.

  • Order A, then B. Summing out A gives a factor over B alone, with 2 entries. Then summing out B gives a factor over C, with 2 entries. Both steps are small.
  • Order B, then A. Summing out B first needs the factor P(B | A) and P(C | B) together, which gives a factor over A and C with 4 entries. This is larger, but the answer is still the same.

TipIn a GATE question, prefer the order that eliminates a variable which touches the fewest other variables. Each step's new factor contains all the variables that were attached to the eliminated one.

The worst case grows fast. If a hidden variable is linked to many others, eliminating it first creates one large factor. Choosing a good order is one reason exact inference is hard for large networks.

Question: A chain A → B → C has two hidden variables. Which order gives smaller factors?

Eliminating A first. Its factor is over B alone, which is small. The other order creates a factor over A and C.

Question: How many entries does a factor over three binary variables have?

23 = 8 entries.

Solved GATE-style problems

These problems are original, written in the style of GATE. They are not past exam questions.

Marginal probability in a chain

The network is A → B. P(A = 1) = 1/3, P(B = 1 | A = 1) = 1/2 and P(B = 1 | A = 0) = 1/4. Find P(B = 1).

How to think about it

  1. What is asked. The probability that B is 1, with A not known.
  2. Which idea applies. Sum out A from the product P(A) P(B | A).
  3. Work it out. P(B = 1) = P(A = 1) P(B = 1 | A = 1) + P(A = 0) P(B = 1 | A = 0) = 1/3 × 1/2 + 2/3 × 1/4 = 1/6 + 1/6 = 1/3.
  4. Check. The answer must lie between P(B = 1 | A = 0) = 1/4 and P(B = 1 | A = 1) = 1/2. 1/3 does.

Answer: 1/3.

Steps of variable elimination (select all that apply)

Which of the following are steps in variable elimination? Select all that apply.

(A) Multiply factors that share a variable.
(B) Sum out a hidden variable.
(C) Differentiate a factor with respect to a variable.
(D) Normalize the final factor so it sums to 1.

How to think about it

  1. What is asked. Which operations belong to the method.
  2. Which idea applies. The four operations: restrict, multiply, sum out, normalize.
  3. Work it out. (A) is a multiply step. (B) is a sum-out step. (C) is not an operation in the method, since factors are tables of probabilities, not functions to differentiate. (D) is the final normalize step.
  4. Check. Count the operations in the worked example: multiply, sum out, multiply, normalize, divide. None is differentiation.

Answer: (A), (B) and (D).

Posterior in a two-node network

The network is A → B, with the same numbers as the first problem: P(A = 1) = 1/3, P(B = 1 | A = 1) = 1/2 and P(B = 1 | A = 0) = 1/4. Find P(A = 1 | B = 1).

How to think about it

  1. What is asked. The probability that A is 1 after we see B = 1.
  2. Which idea applies. Compute the joint for B = 1, then normalize.
  3. Work it out. P(A = 1, B = 1) = 1/3 × 1/2 = 1/6. P(A = 0, B = 1) = 2/3 × 1/4 = 1/6. Their sum is P(B = 1) = 1/3. So P(A = 1 | B = 1) = (1/6) / (1/3) = 1/2.
  4. Check. The two unnormalized values are equal, so the normalized answer is 1/2 for each. The two probabilities add to 1.

Answer: 1/2.

Size of a factor after summing out

A factor f(A, B, C) has three binary variables. Summing out A gives a new factor. How many entries does the new factor have? Give a whole number.

How to think about it

  1. What is asked. The number of entries after removing A.
  2. Which idea applies. A factor over k binary variables has 2k entries.
  3. Work it out. After summing out A, the new factor is over B and C only. That is k = 2 binary variables, so 22 = 4 entries.
  4. Check. The original factor had 23 = 8 entries, and each pair of entries for A = 0 and A = 1 became one entry, so 8 / 2 = 4.

Answer: 4.

Conditional probability with a query

The network is X → Y with P(X = 1) = 3/5, P(Y = 1 | X = 1) = 1/2 and P(Y = 1 | X = 0) = 1/4. Use variable elimination to find P(X = 1 | Y = 1).

How to think about it

  1. What is asked. The chance that X = 1 after observing Y = 1.
  2. Which idea applies. Restrict to Y = 1, multiply by P(X), then normalize.
  3. Work it out. Unnormalized values: X = 1 gives 3/5 × 1/2 = 3/10. X = 0 gives 2/5 × 1/4 = 1/10. Total = 4/10 = 2/5. So P(X = 1 | Y = 1) = (3/10) / (2/5) = 3/10 × 5/2 = 15/20 = 3/4.
  4. Check. The other answer is P(X = 0 | Y = 1) = (1/10) / (2/5) = 1/4. The two add to 1.

Answer: 3/4.

Chain of three with a hidden middle variable

The network is A → B → C with P(A = 1) = 1/2, P(B = 1 | A = 1) = 1/2, P(B = 1 | A = 0) = 1/4, P(C = 1 | B = 1) = 4/5 and P(C = 1 | B = 0) = 1/5. Use variable elimination to find P(C = 1). Eliminate A first, then B.

How to think about it

  1. What is asked. P(C = 1), with A and B hidden.
  2. Which idea applies. Sum out A to get a factor over B, then sum out B to get a factor over C.
  3. Work it out. Sum out A: f(B = 1) = 1/2 × 1/2 + 1/2 × 1/4 = 1/4 + 1/8 = 3/8. f(B = 0) = 1/2 × 1/2 + 1/2 × 3/4 = 1/4 + 3/8 = 5/8. Sum out B: P(C = 1) = 3/8 × 4/5 + 5/8 × 1/5 = 12/40 + 5/40 = 17/40.
  4. Check. The factor over B adds to 3/8 + 5/8 = 1, as it should. The answer 17/40 = 0.425 lies between 1/5 and 4/5, as it should.

Answer: 17/40.

Count the multiplications

Factor f1(A, B) has four entries and factor f2(B, C) has four entries, all binary. The product f(A, B, C) is formed entry by entry, with one multiplication for each entry of the product. How many multiplications are needed? Give a whole number.

How to think about it

  1. What is asked. The number of single multiplications.
  2. Which idea applies. The product factor is over A, B and C, so it has 23 entries.
  3. Work it out. The product has 23 = 8 entries. Each entry is one multiplication of an entry from f1 and an entry from f2.
  4. Check. For each of the 2 values of B, f1 has 2 entries (one for each A) and f2 has 2 entries (one for each C). That is 2 × 2 × 2 = 8 pairs, one for each entry of the product.

Answer: 8.

Exam-level practice

Exam-level 1: Variable elimination on a chain (NAT, 2 marks)

Chain A → B → C, all binary. P(A = 1) = 0.6. P(B = 1 | A = 1) = 0.7, P(B = 1 | A = 0) = 0.2. P(C = 1 | B = 1) = 0.9, P(C = 1 | B = 0) = 0.3. Find P(C = 1).

How to think about it

  1. What is asked. A marginal by summing out A and then B.
  2. Which idea applies. First compute P(B = 1) = Σa P(a)P(B = 1 | a).
  3. Work it out. P(B = 1) = 0.6·0.7 + 0.4·0.2 = 0.5. P(C = 1) = 0.5·0.9 + 0.5·0.3 = 0.6.
  4. Check. The code enumerates the joint.
from itertools import product
pA = {1: 0.6, 0: 0.4}; pB = {1: 0.7, 0: 0.2}; pC = {1: 0.9, 0: 0.3}
tot = sum(pA[a] * (pB[a] if b else 1 - pB[a]) * (pC[b] if c else 1 - pC[b]) for a, b, c in product([0, 1], repeat=3) if c == 1)
print("%.3f" % tot)

0.600

Answer: 0.6.

Exam-level 2: Posterior by elimination (NAT, 2 marks)

Same chain. Find P(A = 1 | C = 1), correct to 3 decimal places.

How to think about it

  1. What is asked. A diagnostic query.
  2. Which idea applies. P(C = 1 | A = a) = Σb P(b | a)P(C = 1 | b), then use Bayes.
  3. Work it out. P(C = 1 | A = 1) = 0.7·0.9 + 0.3·0.3 = 0.72. P(C = 1 | A = 0) = 0.2·0.9 + 0.8·0.3 = 0.42. Posterior = 0.6·0.72/0.6 = 0.72.
  4. Check. The denominator is P(C = 1) = 0.6 from the previous problem.
print("%.3f" % (0.6 * 0.72 / (0.6 * 0.72 + 0.4 * 0.42)))

0.720

Answer: 0.72.

Exam-level 3: Elimination cost (MSQ, 2 marks)

Which are TRUE about variable elimination? (A) The order of elimination affects cost. (B) It is exact. (C) Its cost is exponential in the size of the largest intermediate factor. (D) On a polytree it can be done in time linear in the size of the network.

How to think about it

  1. What is asked. Facts about exact inference.
  2. Which idea applies. Each elimination multiplies factors that mention the variable and sums it out.
  3. Work it out. (A) True. (B) True. (C) True. (D) True for polytrees with a good order.
  4. Check. Finding the best order is NP-hard in general.

Answer: (A), (B), (C) and (D).

Summary

Variable elimination
Exact inference by multiplying and summing out factors, one variable at a time.
Factor
A table of numbers over some variables.
CPT
The table of P(node | parents), which is a factor.
Restrict
Keep the rows that agree with the evidence.
Multiply
Multiply entries of factors that share variables.
Sum out
Add over the values of a hidden variable to remove it.
Normalize
Divide by the total so the values add to 1.
Query
The probability we want to compute.
Hidden variable
A variable that is neither query nor evidence.
Elimination order
The order in which hidden variables are summed out.
Factor size
The number of entries, which is 2k for k binary variables.

Remember these

  1. The joint probability of a Bayesian network is the product of its CPT factors.
  2. Sum out hidden variables. Keep the query variable.
  3. Normalize at the end, by dividing by the total.
  4. The answer does not depend on the order, but the work does.
  5. Pick an order that creates the smallest factors.
  6. Check your answer with a brute-force sum over the joint table.
