K-means / K-medoid clustering

Clustering means grouping similar items together when nobody has given you the group labels. K-means and K-medoids are the two most common ways to do this. Both repeat a simple two-step loop until the groups settle, and GATE Data Science and AI often asks you to run a step or two of this loop by hand.

The idea in plain words

Imagine sorting a box of mixed buttons. Nobody tells you the categories. You just look for buttons that look alike and put them in piles. You might end up with three piles: small red ones, large black ones, and shiny gold ones. That is clustering: grouping similar things without being told the groups in advance.

In machine learning this is called unsupervised learning, because the data has no answer labels. The algorithm must find structure by itself. You must decide how many piles you want, and the algorithm decides which item goes in which pile.

The two methods in this topic share the same big idea. Each pile has a centre. Each item joins the pile whose centre is nearest. Then the centres move to suit their new members, and the process repeats. K-means uses the average of the members as the centre. K-medoids uses one of the actual members as the centre.

Why does this matter for GATE? The Data Science and AI paper expects you to know the steps of K-means, to recognise the effect of a bad starting point, to read an elbow plot, and to explain why K-medoids is more robust to outliers. Each term is defined below, and each step is worked with exact numbers.

Key terms

Clustering
Grouping similar items without labels. Precise: partitioning data into groups so that items in a group are more alike than items in different groups.
Unsupervised learning
Learning from data with no answer labels. Precise: the algorithm finds structure using the inputs alone.
Cluster
One group produced by the algorithm. Precise: a set of points assigned to the same centre.
Centroid
The average position of a cluster's points. Precise: for points (x, y), the centroid is (mean of x, mean of y).
Medoid
The member of a cluster that is most central. Precise: the actual data point that minimises the total distance to the other points in its cluster.
Euclidean distance
The straight-line distance between two points. Precise: for (a, b) and (c, d), the distance is the square root of (a − c)² + (b − d)².
Squared distance
The distance squared, without the square root. Precise: K-means compares squared distances, because they rank points in the same order and avoid roots.
Within-cluster sum of squares (WCSS)
The total squared distance from each point to its own centroid. Precise: the objective that K-means tries to make small.
Iteration
One full round of assign and update. Precise: one pass of the K-means loop.
Convergence
The point where the algorithm stops changing. Precise: when assignments do not change, so the centroids do not change either.
Initialisation
Choosing the starting centres. Precise: the first set of centroids or medoids, often chosen at random.
Elbow method
A way to pick k by looking at WCSS. Precise: plot WCSS against k and pick the point where the drop slows sharply.
Outlier
A point far away from the rest. Precise: a value that is unusually large or small compared with the others.
Robust
Not easily thrown off by outliers. Precise: a method whose result changes little when a few extreme points are added.

Concept 1: The K-means loop and its objective

The goal

K-means splits n points into k clusters. You choose k in advance. The algorithm tries to make each point close to its own centroid. It measures closeness by squared Euclidean distance, and its goal is to make the total WCSS as small as possible:

WCSS = Σ (over clusters) Σ (over points in the cluster) ‖point − centroid‖²
  • ‖point − centroid‖² is the squared distance from one point to its cluster's centroid.
  • The inner Σ adds these up for every point in one cluster. The outer Σ adds over all clusters.

The steps

  1. Initialise. Choose k starting centroids.
  2. Assign. Give each point to the nearest centroid.
  3. Update. Move each centroid to the average of the points assigned to it.
  4. Repeat. Go back to step 2 until the assignments stop changing.

Each assign step can only lower or keep WCSS, because each point is moved to a nearer centre. Each update step also lowers or keeps WCSS, because the average is the position that minimises squared distance. So WCSS never goes up. Since there are only finitely many ways to split the points, the algorithm must stop. It stops at a local minimum, which is not always the best possible split.

A worked trace with exact numbers

Here are six points in the plane: P1 = (1, 1), P2 = (2, 1), P3 = (1, 2), P4 = (8, 8), P5 = (9, 8) and P6 = (8, 9). The natural answer is two clusters: the left-bottom three points and the right-top three points. To show the algorithm working, we start with a poor choice of centroids, both on the left: (1, 1) and (2, 1). The code below runs the loop with exact fractions and prints each step.

from fractions import Fraction as F

points = [(1, 1), (2, 1), (1, 2), (8, 8), (9, 8), (8, 9)]
centroids = [(F(1), F(1)), (F(2), F(1))]   # a poor start: both on the left

def dist2(p, q):
    return (p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2

for it in range(1, 6):
    clusters = [[], []]
    for p in points:
        d = [dist2(p, c) for c in centroids]
        clusters[d.index(min(d))].append(p)
    new = []
    for cl in clusters:
        mx = F(sum(p[0] for p in cl), len(cl))
        my = F(sum(p[1] for p in cl), len(cl))
        new.append((mx, my))
    print("iteration", it)
    print("  cluster 1:", clusters[0])
    print("  cluster 2:", clusters[1])
    print("  new centroids:", ", ".join(f"({a}, {b})" for a, b in new))
    if new == centroids:
        print("  no change, stop")
        break
    centroids = new
iteration 1
  cluster 1: [(1, 1), (1, 2)]
  cluster 2: [(2, 1), (8, 8), (9, 8), (8, 9)]
  new centroids: (1, 3/2), (27/4, 13/2)
iteration 2
  cluster 1: [(1, 1), (2, 1), (1, 2)]
  cluster 2: [(8, 8), (9, 8), (8, 9)]
  new centroids: (4/3, 4/3), (25/3, 25/3)
iteration 3
  cluster 1: [(1, 1), (2, 1), (1, 2)]
  cluster 2: [(8, 8), (9, 8), (8, 9)]
  new centroids: (4/3, 4/3), (25/3, 25/3)
  no change, stop

Read the trace slowly. In iteration 1, the point (2, 1) is nearer to the centroid at (2, 1) than to (1, 1), so it joins cluster 2. That is a poor split, and the first update pulls the centroid of cluster 2 far to the right, to (27/4, 13/2). In iteration 2, the point (2, 1) is now nearer to the left centroid, and it joins cluster 1. The centroids settle at (4/3, 4/3) and (25/3, 25/3). Iteration 3 changes nothing, so the algorithm has converged.

Key ideaK-means always converges, because WCSS never increases. But it converges to a local answer that depends on where you started.

TrapThe centroid is an average, so it is usually not one of the data points. In the trace, the centroid (4/3, 4/3) is not a data point at all.

In iteration 1, which cluster does the point (2, 1) join, and why?

Cluster 2. Its squared distance to the centroid (2, 1) is 0, while its squared distance to (1, 1) is 1. The point goes to the nearest centroid, which is the one at (2, 1).

Does K-means need the number of clusters to be known in advance?

Yes. You choose k before running the loop. Methods such as the elbow method, described next, help you pick a good k.

Concept 2: Sensitivity to starting points and the elbow method

Why the starting points matter

Look again at the trace. With a good start, one centroid near each natural group, the loop finds the natural answer in one or two steps. With a poor start, it can still reach the right answer here, but in general it can get stuck in a worse split. Standard remedies are to run K-means several times from different random starts and keep the run with the lowest WCSS, or to use a smarter start such as k-means++, which spreads the starting centres apart.

Choosing k with the elbow method

If k is not known, we can compare WCSS across values of k. More clusters always give a lower or equal WCSS, so we cannot just pick the smallest WCSS. Instead, we look for the elbow: the point where adding one more cluster stops giving a big improvement.

Here is WCSS for our six points, with one cluster and with the natural two clusters. The code uses exact fractions.

from fractions import Fraction as F

points = [(1, 1), (2, 1), (1, 2), (8, 8), (9, 8), (8, 9)]

def wcss(clusters):
    total = F(0)
    for cl in clusters:
        mx = F(sum(p[0] for p in cl), len(cl))
        my = F(sum(p[1] for p in cl), len(cl))
        total += sum((p[0] - mx) ** 2 + (p[1] - my) ** 2 for p in cl)
    return total

print("WCSS with k = 1:", wcss([points]))
print("WCSS with k = 2:", wcss([points[:3], points[3:]]))
WCSS with k = 1: 449/3
WCSS with k = 2: 8/3

With one cluster, WCSS is 449/3, about 149.7. With the two natural clusters, it drops to 8/3, about 2.7. That huge drop is the sign that two is the right number here. If we tried k = 3, the drop would be much smaller, because the natural groups are already separated. The elbow is the bend at k = 2.

TipWhen reading an elbow plot in a GATE question, look for the k where the curve bends most sharply. The values after the bend fall only slightly, so extra clusters add little.

TrapDo not choose k with the smallest WCSS. WCSS falls every time k increases, even when the extra clusters are meaningless. That is why the elbow, not the minimum, is used.

Why does WCSS always fall, or stay the same, when k increases?

More centres means each point has more chances to sit close to its own centre. A split into more clusters can never be worse for the squared distances, so WCSS cannot rise.

What does a flat curve after k = 4 tell you on an elbow plot?

That extra clusters beyond four bring little improvement, so four is a sensible choice for k.

Concept 3: K-medoids, centres that are real data points

The idea

K-medoids works in the same spirit as K-means, with two changes. First, the centre of each cluster is always one of the actual data points, called the medoid. Second, the cost is the total ordinary distance to the medoid, not the squared distance to a mean. Because the medoid is a real point, a single extreme value cannot drag it far away from the group.

The steps

  1. Choose k actual data points as the initial medoids.
  2. Assign each point to its nearest medoid.
  3. In each cluster, test each member as a candidate medoid. Keep the member whose total distance to the others is smallest.
  4. Repeat until the medoids stop changing.

Full methods such as PAM also try swapping a medoid for a non-medoid point when that lowers the total cost. The steps above capture the main idea.

A worked example with an outlier

Take five one-dimensional values: 1, 2, 3, 4 and 100. The value 100 is an outlier. Compare the centre chosen by K-means style averaging with the centre chosen by K-medoids. The code uses the total absolute distance, which is the cost K-medoids minimises.

from fractions import Fraction as F

data = [1, 2, 3, 4, 100]
n = len(data)
mean = F(sum(data), n)
print("mean:", mean)
print("total distance from mean:", sum(abs(x - mean) for x in data))
best = min(data, key=lambda c: sum(abs(x - c) for x in data))
print("medoid:", best)
print("total distance from medoid:", sum(abs(x - best) for x in data))
mean: 22
total distance from mean: 156
medoid: 3
total distance from medoid: 101

The mean is 110/5 = 22. That is far from four of the five values, which is the outlier's doing. The total distance from 22 is 156. The medoid is 3, a real data point near the middle of the four ordinary values. The total distance from 3 is 101, which is smaller. The medoid is robust: the outlier still adds its large distance, but it does not move the centre.

Key ideaK-medoids uses an actual point as the centre, so the centre always lies among the data. K-means uses an average, which an outlier can drag far off.

GATE loves thisA classic question asks why K-medoids is more robust to outliers. The answer: the centre is a real data point and the cost is a sum of distances, not squared distances, so an outlier has less pull.

Could the medoid of a cluster be a point that is not in the data?

No. By definition the medoid is one of the cluster's own data points. This is the key difference from a K-means centroid.

Why does the mean get pulled by 100 but the medoid does not move?

The mean is an average, so a large value adds directly to the total and shifts the result. The medoid is chosen by comparing candidates, and 3 remains the best candidate, because moving to 100 would add much more total distance.

Concept 4: Comparing K-means and K-medoids

The two methods make different choices, and GATE often asks you to contrast them. The table summarises the main differences.

FeatureK-meansK-medoids
Cluster centreMean of the members (centroid)An actual data point (medoid)
Distance usedSquared Euclidean distanceAny distance, often Euclidean or Manhattan
Effect of outliersSensitive, because the mean movesMore robust
Cost per updateCheap: one average per clusterMore: compare candidates within each cluster
Fits well withLarge datasets, round clustersSmall or noisy datasets, outliers

TrapK-medoids is not always better. It costs more to run, and K-means is often preferred for large datasets with roughly round clusters. Choose the method that fits the data.

Which method is cheaper per iteration, and why?

K-means. Its update is a simple average of each cluster. K-medoids must compare many candidate points within each cluster to find the best medoid.

What a K-means centre is

In K-means, each cluster's centre is: (MCQ, select one)

(A) always one of the data points in that cluster
(B) the mean of the points assigned to that cluster
(C) the median of all the data
(D) chosen at random after every iteration

How to think about it

  1. What is asked. The definition of a K-means centre.
  2. Which idea applies. The update step: the centroid is the average of the assigned points.
  3. Work it out. (A) describes a medoid, not a centroid. (C) describes a median, which K-means does not use. (D) is wrong, since the update is deterministic. (B) is the update step.
  4. Check. The trace in Concept 1 used averages, such as (4/3, 4/3).

Answer: (B).

One assignment and one update

Points on a line are 1, 2 and 9. Two clusters are used, with starting centres 1 and 9. After one assign step and one update step, what is the new centre of the cluster that started at 1? (NAT)

How to think about it

  1. What is asked. The new centre of the first cluster.
  2. Which idea applies. Assign each point to the nearest centre, then take the mean.
  3. Work it out. The point 1 is at distance 0 from centre 1. The point 2 is at distance 1 from centre 1 and 7 from centre 9, so it joins cluster 1. The point 9 joins cluster 2. The new centre of cluster 1 is (1 + 2)/2 = 1.5.
  4. Check. The mean must lie between the two points in the cluster, and 1.5 does.

Answer: 1.5

K-means and K-medoids facts

Select all statements that are correct. (MSQ)

(A) A K-means centroid can be a point that is not in the data.
(B) A K-medoids centre must be one of the actual data points.
(C) K-medoids is usually less affected by outliers than K-means.
(D) K-means always finds the global minimum of WCSS.

How to think about it

  1. What is asked. Which facts are correct.
  2. Which idea applies. The definitions of centroid and medoid, and the local-minimum behaviour of K-means.
  3. Work it out. (A) is true: the trace produced (4/3, 4/3). (B) is true: by definition. (C) is true: the medoid example above. (D) is false: K-means stops at a local minimum that depends on the start.
  4. Check. The bad start in Concept 1 is the counterexample to (D).

Answer: (A), (B) and (C). Statement (D) is false.

Centre after a few steps

Points on a line are 1, 2, 3 and 10. K-means uses k = 2, with starting centres 1 and 10. What is the final centre of the cluster that contains the point 1? (NAT)

How to think about it

  1. What is asked. The final centre of the cluster containing 1.
  2. Which idea applies. Assign, update, repeat until nothing changes.
  3. Work it out. Assign: 1 goes to centre 1 (distance 0). 2 goes to centre 1 (distance 1, against 8). 3 goes to centre 1 (distance 2, against 7). 10 goes to centre 10. Update: cluster 1 has 1, 2, 3, with mean 2. Cluster 2 has only 10, so its centre stays 10. Next round: 1, 2 and 3 are still nearer to centre 2, and 10 is still nearer to 10, so nothing changes. Converged.
  4. Check. Distances to the final centres: 3 is at distance 1 from centre 2 and at distance 7 from centre 10, so it stays in cluster 1.

Answer: 2

WCSS of a clustering

Using the same points as the previous problem, the clustering is {1, 2, 3} and {10}. Find the WCSS of this clustering, using the mean of each cluster as its centroid. (NAT)

How to think about it

  1. What is asked. The total squared distance from points to their own centroids.
  2. Which idea applies. WCSS formula. Find each centroid, then the squared distances.
  3. Work it out. Cluster {1, 2, 3} has centroid 2. Squared distances: (1 − 2)² = 1, (2 − 2)² = 0, (3 − 2)² = 1. Sum = 2. Cluster {10} has centroid 10, and its only point is 10, so its squared distance is 0. Total WCSS = 2 + 0 = 2.
  4. Check. A single point always contributes zero, which is why the second cluster adds nothing.

Answer: 2

Reading an elbow

WCSS values for a dataset are: k = 1 gives 100, k = 2 gives 20, k = 3 gives 6, and k = 4 gives 5. Which value of k does the elbow point suggest? (NAT)

How to think about it

  1. What is asked. The k at the bend of the curve.
  2. Which idea applies. Compare the drops from one k to the next.
  3. Work it out. Drop from k = 1 to 2: 80. Drop from k = 2 to 3: 14. Drop from k = 3 to 4: 1. The drop shrinks sharply after k = 3, so the bend is at k = 3.
  4. Check. Going beyond 3 gives almost nothing, which is the signature of the elbow.

Answer: 3

Which statements about the loop are true

Select all that apply. (MSQ)

(A) K-means can converge to different final clusters depending on the initial centroids.
(B) In K-means, neither the assign step nor the update step can increase WCSS.
(C) K-medoids restricts each centre to a data point and minimises the sum of distances.
(D) The K-means loop can run forever if the data is continuous.

How to think about it

  1. What is asked. Which statements about the algorithms are true.
  2. Which idea applies. The objective decreases monotonically, and the trace in Concept 1 showed the start dependence.
  3. Work it out. (A) is true: the trace started badly and reached a different intermediate split. (B) is true: each step moves points to nearer centres or moves centres to the mean, and both lower or keep WCSS. (C) is true: that is the K-medoids definition. (D) is false: the number of possible splits of n points is finite, and WCSS never increases, so the loop stops.
  4. Check. Statement (D) is wrong because the set of possible partitions is finite, so a loop that never increases WCSS must stop.

Find the medoid of the values 2, 3, 4, 5 and 50, using total absolute distance as the cost. Then give the total absolute distance from that medoid. (NAT)
