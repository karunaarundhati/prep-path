Node and Mesh analysis

Node analysis and mesh analysis are two systematic ways to find every current and voltage in a circuit. Both turn the circuit into a set of linear equations that you can solve. They are the standard tools for network questions in GATE RA and DA.

The idea in plain words

Imagine a city map with junctions and roads. At every junction, the cars that arrive must leave again. Circuits work the same way. The junctions are nodes, and the wires between them are branches.

Now imagine a race track with laps. Each lap is a loop. A loop with no other loop inside it is a mesh. Going once round a mesh, the voltage rises and drops must add up to zero.

That gives us two rules:

  • Node analysis uses the rule for junctions. It is called Kirchhoff's Current Law (KCL). The unknowns are the node voltages.
  • Mesh analysis uses the rule for loops. It is called Kirchhoff's Voltage Law (KVL). The unknowns are the mesh currents.

Both methods give one equation per unknown, and solving those equations gives every answer. They work for any linear circuit.

Key terms

Each term has a plain meaning first, then a precise definition.

Node
A junction where two or more branches meet. Precisely: a point of the circuit connected to at least two elements.
Branch
A single element or path between two nodes. Precisely: a two-terminal element connecting two nodes.
Reference node
The node chosen as zero volts, usually ground. Precisely: all other node voltages are measured against it.
Node voltage
The voltage of a node relative to the reference node. Precisely: the unknown in node analysis.
Loop
Any closed path through the circuit that returns to its starting point.
Mesh
A loop that contains no other loop inside it. Precisely: a window in a planar circuit diagram.
Mesh current
A current assumed to flow around a mesh. Precisely: the unknown in mesh analysis.
Planar circuit
A circuit that can be drawn on a flat sheet without any wires crossing.
KCL
Kirchhoff's Current Law. The sum of currents entering a node equals the sum leaving it.
KVL
Kirchhoff's Voltage Law. Around any closed loop, the sum of voltage rises and drops is zero.
Supernode
A larger node formed by enclosing a voltage source between two non-reference nodes.
Supermesh
A larger mesh formed by combining two meshes that share a current source.
Determinant
A single number calculated from a square array of numbers. It tells you whether a set of equations has one unique solution.

Node (nodal) analysis

The method

Follow these steps every time.

  1. Pick a reference node. Choose ground, or the node with the most branches. Give it zero volts.
  2. Name the other node voltages. Call them V1, V2, and so on. Each is unknown.
  3. Write KCL at each non-reference node. Use the rule "current leaving equals current entering", with each branch current written as Ohm's law in node voltages. For a resistor between node a and node b, the current from a to b is (Va − Vb)/R.
  4. Solve the equations. You will have as many equations as there are non-reference nodes.

Think of node voltages as heights. Current flows from high to low, so every resistor current depends on a difference of two node voltages.

Worked example 1: two nodes

A 3 A ideal current source pushes current into node 1. Node 1 connects to ground through a 2 ohm resistor, and to node 2 through a 4 ohm resistor. Node 2 connects to ground through a 4 ohm resistor. Find V1 and V2.

        3 A pushes into node 1
              |
   node 1 ----+----[ 4 ohm ]---- node 2
              |                      |
           [ 2 ohm ]              [ 4 ohm ]
              |                      |
             gnd                    gnd
  1. Reference. Ground is the reference. The unknowns are V1 and V2.
  2. KCL at node 1. Current in: 3 A. Current out: V1/2 through the 2 ohm, and (V1 − V2)/4 through the 4 ohm. So 3 = V1/2 + (V1 − V2)/4.
  3. KCL at node 2. Current in: (V1 − V2)/4. Current out: V2/4. So (V1 − V2)/4 = V2/4, which gives V1 = 2V2.
  4. Substitute. 3 = (2V2)/2 + (2V2 − V2)/4 = V2 + V2/4 = (5/4) V2. So V2 = 12/5 = 2.4 V and V1 = 4.8 V.

Writing the equations as a matrix

For two equations, it helps to write them in matrix form, G V = I. Here G is a grid of conductances (one over resistance), V is the list of node voltages, and I is the list of currents injected into each node. Collecting the terms gives:

[ 3/4  -1/4 ] [ V1 ]   [ 3 ]
[ -1/4  1/2 ] [ V2 ] = [ 0 ]

The diagonal entry is the total conductance joined to that node. The off-diagonal entry is minus the conductance between the two nodes. Solving a 2 by 2 system by Cramer's rule takes one determinant and two numerators. The determinant here is (3/4)(1/2) − (−1/4)(−1/4) = 5/16.

from fractions import Fraction as F
G = [[F(3, 4), F(-1, 4)], [F(-1, 4), F(1, 2)]]
I = [F(3), F(0)]
det = G[0][0] * G[1][1] - G[0][1] * G[1][0]
V1 = (I[0] * G[1][1] - G[0][1] * I[1]) / det
V2 = (G[0][0] * I[1] - G[1][0] * I[0]) / det
print("determinant =", det)
print("V1 =", V1, "V =", float(V1), "V")
print("V2 =", V2, "V =", float(V2), "V")
determinant = 5/16
V1 = 24/5 V = 4.8 V
V2 = 12/5 V = 2.4 V

TrapBe consistent with direction. If you say a current is leaving a node, write it with a plus sign on the leaving side. Mixing the two conventions in one equation is the most common node analysis error.

Self-check

In Worked example 1, if the 4 ohm resistor between the nodes were 2 ohm, what would V2 be?

KCL at node 2 gives (V1 − V2)/2 = V2/4, so 2V1 − 2V2 = V2, which gives V1 = 3V2/2. KCL at node 1: 6 = 2V1 − V2, and V1 = 3V2/2 gives 6 = 2V2, so V2 = 3 V.

Why do we write each resistor current as a voltage difference?

Current flows from the higher voltage to the lower voltage. The current through a resistor is set by the difference in voltage across it, not by either voltage on its own.

Mesh (loop) analysis

The method

Mesh analysis works in the opposite way. The unknowns are currents, and the rule is KVL.

  1. Find the meshes. A mesh is a window in a planar drawing. It has no other loop inside it.
  2. Name a mesh current for each mesh. Use the same direction, usually clockwise, for every mesh.
  3. Write KVL around each mesh. Go round the mesh once, adding rises and subtracting drops.
  4. Solve the equations. You get one equation per mesh.

The shared resistor

A resistor on the border between two meshes carries two mesh currents at once. If the currents are i1 and i2, then the net current through the resistor is i1 − i2, taking both as clockwise. The voltage drop across the shared resistor is R(i1 − i2).

Worked example 2: two meshes

Two meshes share a 4 ohm resistor. Mesh 1 has a 12 V source and a 2 ohm resistor. Mesh 2 has a 6 V source and a 2 ohm resistor. Both sources push clockwise. Find the two mesh currents.

   +--------[ 2 ohm ]--------+
   |                          |
  12 V (mesh 1)   [4 ohm]   6 V (mesh 2)
   |                          |
   +--------[ 2 ohm ]--------+
  1. KVL around mesh 1. The source gives a rise of 12 V. The 2 ohm drops 2i1. The shared 4 ohm drops 4(i1 − i2). So 12 = 2i1 + 4(i1 − i2), which is 12 = 6i1 − 4i2.
  2. KVL around mesh 2. The source gives a rise of 6 V. The 2 ohm drops 2i2. The shared 4 ohm drops 4(i2 − i1). So 6 = 2i2 + 4(i2 − i1), which is 6 = −4i1 + 6i2.
  3. Solve. Use Cramer's rule. The determinant is 6 × 6 − (−4)(−4) = 20. Then i1 = (12 × 6 − (−4) × 6)/20 = 96/20 = 4.8 A, and i2 = (6 × 6 − (−4) × 12)/20 = 84/20 = 4.2 A.
  4. Check. Substitute into the first equation: 6(4.8) − 4(4.2) = 28.8 − 16.8 = 12. Good. The current in the shared resistor is 4.8 − 4.2 = 0.6 A.
from fractions import Fraction as F
R = [[F(6), F(-4)], [F(-4), F(6)]]
E = [F(12), F(6)]
det = R[0][0] * R[1][1] - R[0][1] * R[1][0]
i1 = (E[0] * R[1][1] - R[0][1] * E[1]) / det
i2 = (R[0][0] * E[1] - R[1][0] * E[0]) / det
print("det =", det)
print("i1 =", i1, "A =", float(i1), "A")
print("i2 =", i2, "A =", float(i2), "A")
print("shared resistor current =", i1 - i2, "A")
det = 20
i1 = 24/5 A = 4.8 A
i2 = 21/5 A = 4.2 A
shared resistor current = 3/5 A

Self-check

A single mesh has a 10 V source, a 2 ohm and a 3 ohm resistor in series. What is the mesh current?

KVL gives 10 = 2i + 3i, so 5i = 10 and i = 2 A.

Why does mesh analysis need a planar circuit?

Mesh analysis relies on drawing each loop as a window with nothing inside. Crossing wires break that idea. Node analysis has no such restriction.

Choosing between node and mesh analysis

The rule of thumb

Both methods always give the right answer. The difference is how many equations you have to write and how easy they are. Choose the method with fewer unknowns.

  • Use node analysis when the circuit has few nodes or current sources. Current sources go straight into the KCL equations.
  • Use mesh analysis when the circuit is planar and has few meshes, or has voltage sources in loops. Voltage sources go straight into the KVL equations.

Node analysis needs one equation per node, minus the reference. Mesh analysis needs one per mesh. Count both before you start.

Example: 4 nodes and 3 meshes give 3 equations either way, so choose by the sources.

TipBefore you start, count the non-reference nodes and the meshes. Pick the smaller number. Then look at where the sources are.

Self-check

A circuit has 5 nodes and 2 meshes. Which method needs fewer equations?

Node analysis needs 5 − 1 = 4 equations. Mesh analysis needs 2 equations. Mesh analysis is the better choice, provided the circuit is planar.

Which kind of source is easier in node analysis?

A current source. It is a known current entering or leaving a node, so it appears directly in the KCL equation.

Supernodes and supermeshes

The problem

A voltage source between two non-reference nodes has an unknown current, so KCL cannot be written at either node alone. A current source shared by two meshes has the same problem in mesh analysis.

The supernode

Draw a closed shape around the source and both nodes, and write KCL around the whole shape. Add one constraint: the difference of the two node voltages equals the source voltage.

Worked example 4: a supernode

A 6 V source has its plus terminal at node 1 and its minus terminal at node 2. Node 1 connects to ground through a 6 ohm resistor. Node 2 connects to ground through a 3 ohm resistor. No other sources are present. Find V1 and V2.

  1. Constraint. V1 − V2 = 6.
  2. KCL around the supernode. The currents leaving through the two resistors add up to zero, because no source feeds the supernode. So V1/6 + V2/3 = 0.
  3. Substitute. Put V1 = V2 + 6 into the second equation: (V2 + 6)/6 + V2/3 = 0. Multiply out: V2/6 + 1 + V2/3 = 0, so V2/2 = −1 and V2 = −2 V.
  4. Find V1. V1 = −2 + 6 = 4 V.
from fractions import Fraction as F
V2 = F(-1) / F(1, 2)
V1 = V2 + 6
print("V1 =", V1, "V, V2 =", V2, "V")
print("supernode KCL holds:", F(1, 6) * V1 + F(1, 3) * V2 == 0)
print("source constraint holds:", V1 - V2 == 6)
V1 = 4 V, V2 = -2 V
supernode KCL holds: True
source constraint holds: True

The supermesh

A supermesh is the mesh version. Draw one large loop around the two meshes that share the current source. Write KVL around the large loop. Then add the constraint: the difference of the two mesh currents equals the source current.

TrapDo not write KCL at each node of a supernode, and do not write KVL around each mesh of a supermesh. Those equations contain the unknown source voltage or current and cannot be solved.

Self-check

Why does a supernode need an extra equation?

The current through the voltage source is unknown, so the two nodes cannot be written as separate KCL equations. The constraint "V1 − V2 = source voltage" provides the missing equation, so the number of equations matches the number of unknowns.

Is a supermesh used for a voltage source shared by two meshes?

No. A supermesh is used for a shared current source. A shared voltage source is handled directly in the KVL equation.

Solving the equations and checking the answer

Solve the equations by substitution, Cramer's rule, or elimination.

Worked example 5: three nodes

A 6 A current source pushes into node 1 from ground. Node 1 connects to ground through 1 ohm. Node 1 connects to node 2 through 1 ohm, and to node 3 through 2 ohm. Node 2 connects to ground through 2 ohm, and to node 3 through 1 ohm. Node 3 has no other connection. Write the three KCL equations in terms of V1, V2 and V3.

  1. KCL at node 1. 6 = V1 + (V1 − V2) + (V1 − V3)/2. Multiply by 2: 12 = 5V1 − 2V2 − V3.
  2. KCL at node 2. 0 = V2/2 + (V2 − V1) + (V2 − V3). Multiply by 2: 0 = −2V1 + 5V2 − 2V3.
  3. KCL at node 3. 0 = (V3 − V1)/2 + (V3 − V2). Multiply by 2: 0 = −V1 − 2V2 + 3V3.

Solving these three equations gives V1 = 4.4 V, V2 = 3.2 V and V3 = 3.6 V. Here is a check using determinants, followed by a substitution test.

from fractions import Fraction as F
A = [[F(5), F(-2), F(-1)], [F(-2), F(5), F(-2)], [F(-1), F(-2), F(3)]]
b = [F(12), F(0), F(0)]
def det3(M):
    return (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
            - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
            + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))
D = det3(A)
sols = []
for k in range(3):
    Mk = [row[:] for row in A]
    for r in range(3):
        Mk[r][k] = b[r]
    sols.append(det3(Mk) / D)
print("determinant =", D)
print("V1 =", sols[0], "V")
print("V2 =", sols[1], "V")
print("V3 =", sols[2], "V")
determinant = 30
V1 = 22/5 V
V2 = 16/5 V
V3 = 18/5 V

Checking your answer

Put your answers back into an equation you did not use. If both sides match, the answer is very likely right.

Self-check

In Worked example 5, does V2 = 3.2 V satisfy the node 2 equation with V1 = 4.4 V and V3 = 3.6 V?

Check: −2(4.4) + 5(3.2) − 2(3.6) = −8.8 + 16 − 7.2 = 0. Yes, the equation holds.

What is the quickest way to check a 2 by 2 solution?

Substitute both values into both original equations. Each side should match exactly. This catches most arithmetic and sign errors.

Solved GATE-style problems

These are original problems in the GATE style, not past exam questions. Try each one on paper first.

Single node with two resistors

A 5 A ideal current source pushes into a single node. From the node to ground there are a 2 ohm resistor and a 3 ohm resistor in parallel. Find the node voltage.

How to think about it

  1. What is asked. The one unknown node voltage V.
  2. Which idea applies. KCL at the node: the 5 A in equals the current out through the two resistors.
  3. Work it out. 5 = V/2 + V/3 = (5/6)V, so V = 6 V.
  4. Check. Current through 2 ohm is 3 A, through 3 ohm is 2 A. Together 5 A.

Answer: 6 V.

from fractions import Fraction as F
V = F(5) / (F(1, 2) + F(1, 3))
print("V =", V, "V")
V = 6 V

Single mesh with two resistors

A 10 V source drives one loop containing a 2 ohm resistor and a 3 ohm resistor in series. Find the loop current.

How to think about it

  1. What is asked. The current i in the single mesh.
  2. Which idea applies. KVL around the loop: rises equal drops.
  3. Work it out. 10 = 2i + 3i = 5i, so i = 2 A.
  4. Check. Drops are 2 × 2 = 4 V and 3 × 2 = 6 V. Total 10 V, equal to the source.

Answer: 2 A.

Statements about node and mesh analysis (MSQ)

Select all that apply.

(A) Node analysis writes KCL at each non-reference node.
(B) Mesh analysis writes KCL around each mesh.
(C) Mesh analysis is restricted to planar circuits.
(D) A voltage source between two non-reference nodes forces a supernode.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. KCL belongs to nodes, KVL belongs to meshes, and planarity is needed for meshes.
  3. Work it out. (A) True. (B) False: mesh analysis uses KVL. (C) True. (D) True.
  4. Check. The two statements about the rules (A and B) cannot both be true. A is the correct pairing.

Answer: (A), (C) and (D).

Node voltage in a two-node circuit (NAT)

A 2 A ideal current source pushes into node 1. Node 1 connects to ground through 2 ohm and to node 2 through 2 ohm. Node 2 connects to ground through 4 ohm. Find V2 in volt.

How to think about it

  1. What is asked. The voltage of node 2.
  2. Which idea applies. Node analysis with KCL at both nodes.
  3. Work it out. At node 2: (V1 − V2)/2 = V2/4, so V1 = 3V2/2. At node 1: 2 = V1/2 + (V1 − V2)/2. Substituting gives V1 = 3 V and V2 = 2 V.
  4. Check. Node 1: 3/2 + 1/2 = 2 A. Node 2: 1/2 = 2/4. Both hold.

Answer: 2 V.

from fractions import Fraction as F
G = [[F(1), F(-1, 2)], [F(-1, 2), F(3, 4)]]
I = [F(2), F(0)]
det = G[0][0] * G[1][1] - G[0][1] * G[1][0]
V1 = (I[0] * G[1][1] - G[0][1] * I[1]) / det
V2 = (G[0][0] * I[1] - G[1][0] * I[0]) / det
print("V1 =", V1, "V, V2 =", V2, "V")
V1 = 3 V, V2 = 2 V

Shared resistor current in two meshes (NAT)

Two meshes share a 4 ohm resistor. Mesh 1 has a 12 V source and a 2 ohm resistor. Mesh 2 has one more 4 ohm resistor and no source. Both mesh currents are clockwise, and the 12 V source pushes clockwise in mesh 1. Find the current through the shared resistor in ampere.

How to think about it

  1. What is asked. The net current in the shared resistor, i1 − i2.
  2. Which idea applies. KVL in each mesh.
  3. Work it out. Mesh 2: 0 = 4i2 + 4(i2 − i1), so i2 = i1/2. Mesh 1: 12 = 2i1 + 4(i1 − i2) = 6i1 − 2i1 = 4i1. So i1 = 3 A and i2 = 1.5 A. The shared current is 3 − 1.5 = 1.5 A.
  4. Check. Mesh 1 drops: 2 × 3 = 6 V and 4 × 1.5 = 6 V. Total 12 V. Good.

Answer: 1.5 A.

from fractions import Fraction as F
i1 = F(12, 4)
i2 = i1 / 2
print("mesh 1 check:", 6 * i1 - 4 * i2 == 12)
print("mesh 2 check:", 8 * i2 - 4 * i1 == 0)
print("shared current =", i1 - i2, "A")
mesh 1 check: True
mesh 2 check: True
shared current = 3/2 A

Node voltage with a supernode (NAT)

A 6 V ideal voltage source has its plus terminal at node 1 and its minus terminal at node 2. Node 1 connects to ground through 6 ohm. Node 2 connects to ground through 3 ohm. There are no other sources. Find V1 in volt.

How to think about it

  1. What is asked. The voltage at node 1.
  2. Which idea applies. A supernode, because the source sits between two non-reference nodes.
  3. Work it out. Constraint: V1 − V2 = 6. KCL around the supernode: V1/6 + V2/3 = 0. Substituting V1 = V2 + 6 gives V2 = −2 V and V1 = 4 V.
  4. Check. 4/6 + (−2)/3 = 0. Good. The difference is 4 − (−2) = 6 V. Good.

Answer: 4 V.

Three-node network (NAT)

A 6 A ideal current source pushes into node 1 from ground. Node 1 connects to ground through 1 ohm, to node 2 through 1 ohm, and to node 3 through 2 ohm. Node 2 connects to ground through 2 ohm and to node 3 through 1 ohm. Node 3 has no other connection. Find V1 in volt.

How to think about it

  1. What is asked. The node 1 voltage in a three-node circuit.
  2. Which idea applies. Node analysis with three KCL equations, solved as a 3 by 3 linear system.
  3. Work it out. The equations, multiplied to clear halves, are: 5V1 − 2V2 − V3 = 12, −2V1 + 5V2 − 2V3 = 0, and −V1 − 2V2 + 3V3 = 0. Solving by Cramer's rule gives V1 = 4.4 V, V2 = 3.2 V and V3 = 3.6 V.
  4. Check. Substitute into each equation. The Python check below confirms all three.

Answer: V1 = 4.4 V (which is 22/5 V).

from fractions import Fraction as F
A = [[F(5), F(-2), F(-1)], [F(-2), F(5), F(-2)], [F(-1), F(-2), F(3)]]
b = [F(12), F(0), F(0)]
def det3(M):
    return (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
            - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
            + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))
D = det3(A)
sols = []
for k in range(3):
    Mk = [row[:] for row in A]
    for r in range(3):
        Mk[r][k] = b[r]
    sols.append(det3(Mk) / D)
print("V1 =", sols[0], "V")
print("V2 =", sols[1], "V")
print("V3 =", sols[2], "V")
print("all equations hold:", all(sum(A[r][c] * sols[c] for c in range(3)) == b[r] for r in range(3)))
V1 = 22/5 V
V2 = 16/5 V
V3 = 18/5 V
all equations hold: True

Exam-level practice

Exam-level 1: Nodal analysis (NAT, 2 marks)

Node 1 connects to a 12 V source through 2 Ω, to ground through 4 Ω, and to node 2 through 4 Ω. Node 2 connects to ground through 4 Ω. Find V1.

How to think about it

  1. What is asked. The node voltage.
  2. Which idea applies. Write KCL at each node.
  3. Work it out. Node 2: (V2 − V1)/4 + V2/4 = 0, so V2 = V1/2. Node 1: (V1 − 12)/2 + V1/4 + (V1/2)/4 = 0. Multiply by 8: 4V1 − 48 + 2V1 + V1 = 0, V1 = 48/7 ≈ 6.857 V.
  4. Check. The code solves the two equations.
from fractions import Fraction as F
# 4V1 - 48 + 2V1 + V1 = 0
V1 = F(48, 7)
print(V1, "%.3f" % float(V1), "V2 =", V1 / 2)

Answer: 48/7 ≈ 6.857 V.

Exam-level 2: Mesh analysis (NAT, 2 marks)

Mesh 1: 10 V source, 2 Ω, shared 3 Ω. Mesh 2: shared 3 Ω and 5 Ω, no source. Find the current in the shared 3 Ω resistor.

How to think about it

  1. What is asked. I1 − I2.
  2. Which idea applies. Mesh equations: 5I1 − 3I2 = 10 and −3I1 + 8I2 = 0.
  3. Work it out. I2 = 3I1/8. 5I1 − 9I1/8 = 10 gives I1 = 80/31. I2 = 30/31. Shared current = 50/31 ≈ 1.613 A.
  4. Check. The code solves it with Cramer's rule.
from fractions import Fraction as F
a, b, c, d, e, f = 5, -3, -3, 8, 10, 0
D = a * d - b * c
I1 = F(e * d - b * f, D); I2 = F(a * f - e * c, D)
print(I1, I2, I1 - I2, "%.3f" % float(I1 - I2))

80/31 30/31 50/31 1.613

Answer: 50/31 ≈ 1.613 A.

Exam-level 3: Number of equations (NAT, 1 mark)

A planar circuit has 6 nodes and 9 branches. How many independent mesh equations and how many nodal equations are there?

How to think about it

  1. What is asked. Counts of independent equations.
  2. Which idea applies. Meshes = b − n + 1. Nodal equations = n − 1.
  3. Work it out. Meshes: 9 − 6 + 1 = 4. Nodes: 5.
  4. Check. The total 4 + 5 = 9 matches the number of branch unknowns.

Answer: 4 mesh equations and 5 nodal equations.

Summary

Reference node
The zero-volt node, usually ground. It gets no KCL equation.
Node voltage
The voltage of a node relative to the reference. The unknown in node analysis.
Node analysis
Writing KCL at each non-reference node, with node voltages as unknowns.
Mesh
A loop with no other loop inside it, in a planar circuit.
Mesh current
The assumed current round a mesh. The unknown in mesh analysis.
Mesh analysis
Writing KVL around each mesh, with mesh currents as unknowns.
KCL
The sum of currents at a node is zero, with leaving currents positive.
KVL
The sum of voltage rises and drops around a closed loop is zero.
Supernode
A node formed around a voltage source. Needs a voltage constraint.
Supermesh
A loop formed around two meshes sharing a current source. Needs a current constraint.
Determinant
A number from a square array. Non-zero means a unique solution exists.

Remember these

  1. Node analysis uses KCL and node voltages. Mesh analysis uses KVL and mesh currents.
  2. A shared resistor carries the difference of two mesh currents.
  3. Count the equations for each method first, then choose the smaller set.
  4. A voltage source between two non-reference nodes forces a supernode.
  5. Always substitute your answer back into an equation you did not use.
