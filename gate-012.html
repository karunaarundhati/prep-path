Partition matrix and its properties

A partition matrix cuts a big matrix into smaller blocks, so that large problems can be handled one piece at a time. Block rules for products, determinants and inverses, including the Schur complement, appear in GATE questions and in real computing.

The idea in plain words

Imagine a huge spreadsheet with 1000 rows and 1000 columns. Nobody wants to read every cell at once. Instead, you draw lines across it and split it into four rectangles: top left, top right, bottom left and bottom right. Each rectangle is a block. You can then talk about the whole sheet using four smaller names. The sheet is now a small table of blocks.

This is what a partition (or block) matrix is. You draw dividing lines through a matrix, and each piece is treated as a single entry of a smaller matrix. The trick works as long as the cuts line up so that the blocks can be added and multiplied correctly.

Why does GATE care? Many large matrices in data science and robotics have a special shape: they are block diagonal, block triangular, or they have a block that is easy to invert. Recognising the shape lets you compute a determinant or an inverse in a few easy steps. The Schur complement is the tool that makes this possible, and it is a favourite in GATE DA and RA questions.

Key terms

Partition (block) matrix
A matrix cut into rectangular pieces by horizontal and vertical lines. Plain meaning: a matrix of smaller matrices. Precise: M = [[A, B], [C, D]], where each letter is a block.
Block
One of the pieces of a partition matrix. It is itself a matrix.
Conformable
Two block matrices are conformable when their blocks have sizes that allow addition or multiplication. Precise: the column blocks of the left factor must match the row blocks of the right factor.
Block diagonal matrix
A block matrix whose off-diagonal blocks are all zero. Precise: diag(A, D) = [[A, 0], [0, D]].
Block triangular matrix
A block matrix with zero blocks below (or above) the diagonal blocks. Precise: [[A, B], [0, D]] is block upper triangular.
Determinant
One number from a square matrix. Zero exactly when the matrix is singular (not invertible).
Inverse
The matrix M⁻¹ with M⁻¹M = I.
Schur complement
The matrix D − CA⁻¹B, built from the blocks of M, where A is invertible. It captures what is left of the D block after removing the influence of A.
Singular
A square matrix with determinant zero. It has no inverse.

Step 1: What a partition matrix is

Start with a plain 4 × 4 matrix. Draw a vertical line after column 2 and a horizontal line after row 2. You get four blocks, each a 2 × 2 matrix.

M = [ 1  2 | 5  6 ]       A = [ 1  2 ]    B = [ 5  6 ]
    [ 3  4 | 7  8 ]           [ 3  4 ]        [ 7  8 ]
    [-----+-----]
    [ 0  1 | 2  0 ]           C = [ 0  1 ]    D = [ 2  0 ]
    [ 1  0 | 0  2 ]               [ 1  0 ]        [ 0  2 ]

So M = [[A, B], [C, D]]. The whole matrix is written as a 2 × 2 table, but each entry of that table is a 2 × 2 block. We write the blocks in a list of rows, just as we would for ordinary entries.

The partition is only a way of looking at the same numbers. Nothing changes in the matrix itself. But the block view makes some calculations much simpler, as the next steps show.

Key ideaA block is a matrix, so a block matrix is a matrix of matrices. Treat each block as a single entry, but remember that multiplication order matters, because blocks are not numbers.

Question: in the matrix above, what is the size of block B?

2 × 2. B has the 2 rows of the top half and the 2 columns of the right half.

Question: can we cut a 3 × 3 matrix into a top block of 1 row and a bottom block of 2 rows?

Yes. The lines can go anywhere, as long as they are used consistently for rows and columns. The top blocks then have 1 row and the bottom blocks have 2 rows.

Step 2: Block addition and multiplication

Block addition is the easy part. If two matrices are cut in the same places and the blocks have the same sizes, add the blocks one by one:

[[A, B], [C, D]] + [[E, F], [G, H]] = [[A + E, B + F], [C + G, D + H]]

Block multiplication is the important part. It looks like ordinary multiplication of 2 × 2 matrices, with blocks in place of numbers:

[[A, B], [C, D]] · [[E, F], [G, H]] = [[AE + BG, AF + BH], [CE + DG, CF + DH]]

Read the rule carefully. The order of each product matters, so AE is not the same as EA. And every product must be possible: the number of columns in A must equal the number of rows in E, and so on. This is what "conformable" means.

Worked example. Let X = [[A, B], [0, D]] and Y = [[E, F], [0, G]], with A = [[1, 2], [0, 1]], B = [[3], [4]], D = [[2]], E = [[1, 0], [1, 1]], F = [[1], [0]], G = [[5]]. Find the top-left block of XY.

  1. The top-left block is AE + B·0 = AE. (The zero block removes the BG term.)
  2. Compute AE. Row 1 of A is (1, 2). Column 1 of E is (1, 1). Their product is 1·1 + 2·1 = 3. Row 1 with column 2, which is (0, 1): 1·0 + 2·1 = 2.
  3. Row 2 of A is (0, 1). With column 1 of E: 0·1 + 1·1 = 1. With column 2: 0·0 + 1·1 = 1.
  4. So AE = [[3, 2], [1, 1]].
  5. Check with the full product (the code below does this). The top-left 2 × 2 block of XY is [[3, 2], [1, 1]], which agrees.

The code below multiplies the full 3 × 3 matrices, so you can see the block result appear in the answer.

def matmul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]

X = [[1, 2, 3], [0, 1, 4], [0, 0, 2]]
Y = [[1, 0, 1], [1, 1, 0], [0, 0, 5]]
P = matmul(X, Y)
for row in P:
    print(row)
[3, 2, 16]
[1, 1, 20]
[0, 0, 10]

Look at the output. The top-left 2 × 2 block is [[3, 2], [1, 1]], which is AE. The top-right column is AF + BG = (16, 20), and the bottom-right entry is DG = 10. The block formula gave exactly these numbers.

TrapBlocks do not commute in general. AE and EA can differ, so always keep the order from the formula. Also, you can only multiply blocks when their sizes are conformable.

Question: if A is 2 × 3 and E is 2 × 2, is the product AE defined?

No. A has 3 columns but E has 2 rows, so the product is not conformable. For AE to be defined, the number of columns of A must equal the number of rows of E.

Step 3: Block triangular and block diagonal matrices

Some block matrices have a zero block, and this makes life easy. Here are the two most important shapes:

  • Block diagonal: [[A, 0], [0, D]]. The off-diagonal blocks are zero, so the two parts do not talk to each other.
  • Block upper triangular: [[A, B], [0, D]]. Only the bottom-left block is zero, so information flows one way.

Look at the picture. It shows the 2 × 2 matrix [[1, 2], [0, 1]], which is upper triangular, and it is a sideways shear. The first column is (1, 0), so the horizontal axis does not move. Points above the axis slide to the right. Try to find the one direction that stays unchanged, and notice that it is the axis itself.

Block triangular matrices have a very useful determinant rule. For [[A, B], [0, D]] with A and D square:

det [[A, B], [0, D]] = det(A) · det(D)

The same rule works for block diagonal matrices, which are a special case. The block B does not affect the determinant at all. This is one of the most useful facts in the topic.

Worked example. Let M = [[1, 2, 3], [0, 1, 4], [0, 0, 2]] with A = [[1, 2], [0, 1]], B = [[3], [4]], D = [[2]].

  1. M is block upper triangular with this partition.
  2. det A = 1·1 − 2·0 = 1.
  3. det D = 2.
  4. So det M = 1 × 2 = 2.
  5. Check: M is upper triangular with diagonal entries 1, 1, 2. Its determinant is the product of the diagonal, 1·1·2 = 2. Same answer.

The inverse also has a block formula. For [[A, B], [0, D]], with A and D invertible:

[[A, B], [0, D]]⁻¹ = [[A⁻¹, −A⁻¹BD⁻¹], [0, D⁻¹]]

Apply it to M above. A⁻¹ = [[1, −2], [0, 1]] and D⁻¹ = 1/2. The top-right block is −A⁻¹BD⁻¹ = −[[1, −2], [0, 1]] · [[3], [4]] · (1/2). First, [[1, −2], [0, 1]] · (3, 4) = (3 − 8, 4) = (−5, 4). Then multiply by −1/2: (5/2, −2). So

M⁻¹ = [ 1  -2   5/2 ]
      [ 0   1    -2 ]
      [ 0   0   1/2 ]

Check one entry: row 1 of M times column 3 of M⁻¹ is 1·(5/2) + 2·(−2) + 3·(1/2) = 5/2 − 4 + 3/2 = 0, as it should be for the off-diagonal entry of the identity.

GATE loves thisFor a block triangular matrix, you never need to expand a big determinant. Multiply the determinants of the diagonal blocks. The off-diagonal block is irrelevant.

Question: what is det [[2, 7], [0, 3]] with blocks of size 1?

det = 2 · 3 = 6. The block 7 does not matter, which is the same as the rule for ordinary upper triangular matrices.

Step 4: Determinant and inverse of general block matrices

The rules above need a zero block. What about a general block matrix M = [[A, B], [C, D]], where C is not zero? There is still a useful rule, if A is invertible. We use the Schur complement, introduced in the next step, which is the key quantity:

det [[A, B], [C, D]] = det(A) · det(D − CA⁻¹B)

The first factor is det A. The second factor is the determinant of the small matrix D − CA⁻¹B, which is smaller than M. This can be much easier to compute than det M itself.

A similar rule holds if D is invertible: det M = det(D) · det(A − BD⁻¹C).

TrapDo not write det M = det A · det D unless the matrix is triangular or block diagonal (B or C zero). In general, the formula is det A · det(D − CA⁻¹B), and the second factor is not det D.

The inverse of a general block matrix is also written with the Schur complement S = D − CA⁻¹B. If S is invertible, the top-left block of M⁻¹ is A⁻¹ + A⁻¹BS⁻¹CA⁻¹. You do not need to memorise this for GATE, but you should recognise the shape, and the Schur complement is the key ingredient.

Question: if A = I and C = 0, what does det [[I, B], [0, D]] equal?

det I · det D = 1 · det D = det D. The block B has no effect.

Question: why is the block formula useful for big matrices?

It reduces a big determinant to a product of smaller determinants. Working with a 2 × 2 or 3 × 3 block is much less work than expanding a 10 × 10 matrix.

Step 5: The Schur complement

The Schur complement is a small matrix that summarises a big block matrix. For M = [[A, B], [C, D]] with A invertible, it is:

S = D − C A⁻¹ B

Read it in words. Start with the block D. Then subtract the effect of the blocks C and B, which are connected through A. Here A⁻¹ is the "correction" that undoes A. So S is what remains of D once the interaction with A is removed.

Everyday analogy: think of a team with two groups, A and D. Group A is a manager and group D is a set of workers. The workers' true output is measured after you subtract what the manager already directs them to do. That leftover is the Schur complement.

Worked example. Let M = [[2, 1, 1], [1, 3, 0], [0, 1, 4]], with A = [[2, 1], [1, 3]], B = [[1], [0]], C = [[0, 1]] and D = [[4]].

  1. det A = 2·3 − 1·1 = 5. So A is invertible.
  2. A⁻¹ = (1/5) [[3, −1], [−1, 2]]. (For a 2 × 2 matrix [[a, b], [c, d]], the inverse is (1/det)[[d, −b], [−c, a]].)
  3. A⁻¹B = (1/5)(3·1 + (−1)·0, −1·1 + 2·0) = (3/5, −1/5) as a column.
  4. C A⁻¹B = (0, 1) · (3/5, −1/5) = 0·3/5 + 1·(−1/5) = −1/5.
  5. S = D − CA⁻¹B = 4 − (−1/5) = 21/5.
  6. Then det M = det A · S = 5 · 21/5 = 21.
  7. Check by direct expansion of the 3 × 3 matrix: 2(3·4 − 0·1) − 1(1·4 − 0·0) + 1(1·1 − 3·0) = 24 − 4 + 1 = 21. Same answer.

The code below repeats these steps with exact fractions.

from fractions import Fraction as F

def det2(m):
    return m[0][0] * m[1][1] - m[0][1] * m[1][0]

def det3(m):
    a, b, c = m[0]
    d, e, f = m[1]
    g, h, i = m[2]
    return a * (e * i - f * h) - b * (d * i - f * g) + c * (d * h - e * g)

A = [[2, 1], [1, 3]]
B = [[1], [0]]
C = [[0, 1]]
D = [[4]]
M = [[2, 1, 1], [1, 3, 0], [0, 1, 4]]

detA = det2(A)
Ainv = [[F(A[1][1], detA), F(-A[0][1], detA)], [F(-A[1][0], detA), F(A[0][0], detA)]]
CAB = sum(C[0][i] * Ainv[i][j] * B[j][0] for i in range(2) for j in range(2))
S = D[0][0] - CAB
print("det M =", det3(M))
print("det A =", detA)
print("Schur complement S =", S)
print("det A * S =", detA * S)
det M = 21
det A = 5
Schur complement S = 21/5
det A * S = 21

Key ideaWhen A is invertible, det M = det A · det S. Pick the block that is easiest to invert as A, and the Schur complement becomes a small matrix you can handle by hand.

Question: a block matrix has A = [2], B = [1], C = [1], D = [1]. What is its Schur complement, and what is det M?

S = D − CA⁻¹B = 1 − (1)(1/2)(1) = 1/2. Then det M = det A · S = 2 · (1/2) = 1. Check: the full matrix [[2, 1], [1, 1]] has det 2 − 1 = 1.

Determinant of a block diagonal matrix

Let M = [[1, 2, 0], [3, 4, 0], [0, 0, 5]]. Find det M by treating M as a block diagonal matrix.

How to think about it

  1. What is asked. The determinant of M.
  2. Which idea applies. M is block diagonal with blocks A = [[1, 2], [3, 4]] and D = [5]. The determinant is det A · det D.
  3. Work it out. det A = 1·4 − 2·3 = −2. det D = 5. So det M = −2 · 5 = −10.
  4. Check. Expand along the last column: the only non-zero entry is 5 in position (3, 3), with cofactor det [[1, 2], [3, 4]] = −2. So det M = 5 · (−2) = −10.

Answer: −10.

Block triangular determinant

Let M = [[A, B], [0, D]] with A = [[2, 0], [1, 3]], B = [[7], [4]] and D = [[1]]. Find det M.

How to think about it

  1. What is asked. The determinant of a block upper triangular matrix.
  2. Which idea applies. det [[A, B], [0, D]] = det A · det D. The block B is irrelevant.
  3. Work it out. det A = 2·3 − 0·1 = 6. det D = 1. So det M = 6 · 1 = 6.
  4. Check. Write M in full: [[2, 0, 7], [1, 3, 4], [0, 0, 1]]. Its determinant by the bottom row is 1 times det [[2, 0], [1, 3]] = 6. Same answer.

Answer: 6.

Which block rules are true? (MSQ)

Let M = [[A, B], [0, D]] with A and D square and invertible. Select all that apply.

(A) det M = det A · det D   (B) M⁻¹ = [[A⁻¹, −A⁻¹BD⁻¹], [0, D⁻¹]]   (C) det M = det A + det D   (D) M⁻¹ = [[A⁻¹, A⁻¹BD⁻¹], [0, D⁻¹]]

How to think about it

  1. What is asked. Which block formulas are correct.
  2. Which idea applies. Block triangular determinant and inverse rules.
  3. Work it out. (A) is true, the product rule for triangular blocks. (B) is true: multiply M by the claimed inverse, and the top-right block is A·(−A⁻¹BD⁻¹) + B·D⁻¹ = −BD⁻¹ + BD⁻¹ = 0. (C) is false, determinants of blocks multiply, not add. (D) has the wrong sign: the top-right block should be negative.
  4. Check. Test (D) on the 2 × 2 example M = [[2, 1], [0, 1]] with A = [2], B = [1], D = [1]. The true inverse is [[1/2, −1/2], [0, 1]]. Option (D) would give +1/2, which is wrong.

Answer: (A) and (B).

An entry of a block product (NAT)

Let X = [[1, 2, 3], [0, 1, 4], [0, 0, 2]] and Y = [[1, 0, 1], [1, 1, 0], [0, 0, 5]]. What is the entry in row 1, column 3 of the product XY?

How to think about it

  1. What is asked. One entry of XY.
  2. Which idea applies. Row 1 of X times column 3 of Y, one product at a time.
  3. Work it out. Row 1 of X is (1, 2, 3). Column 3 of Y is (1, 0, 5). The product is 1·1 + 2·0 + 3·5 = 1 + 0 + 15 = 16.
  4. Check. The code in Step 2 printed the first row of XY as [3, 2, 16]. The third entry is 16, which agrees.

Answer: 16.

Determinant with a Schur complement (NAT)

Let M = [[1, 2, 0], [2, 5, 1], [0, 1, 4]]. Partition M with A = [1] (the top-left entry), so B = (2, 0), C = (2, 0) as a column, and D = [[5, 1], [1, 4]]. Use the Schur complement to find det M.

How to think about it

  1. What is asked. The determinant of M, found through a Schur complement.
  2. Which idea applies. det M = det A · det(D − CA⁻¹B).
  3. Work it out. det A = 1, and A⁻¹ = 1. C A⁻¹ B is the outer product of the column (2, 0) and the row (2, 0): [[4, 0], [0, 0]]. So S = [[5, 1], [1, 4]] − [[4, 0], [0, 0]] = [[1, 1], [1, 4]]. det S = 1·4 − 1·1 = 3. So det M = 1 · 3 = 3.
  4. Check. Expand M directly: 1(5·4 − 1·1) − 2(2·4 − 1·0) + 0 = 19 − 16 = 3. Same answer.

Answer: 3.

Block diagonal properties (MSQ)

Let M = diag(A, B) be a block diagonal matrix with A and B square and invertible. Select all that apply.

(A) det M = det A · det B   (B) rank M = rank A + rank B   (C) M⁻¹ = diag(A⁻¹, B⁻¹)   (D) M is always symmetric

How to think about it

  1. What is asked. Which properties of a block diagonal matrix are always true.
  2. Which idea applies. Block diagonal matrices are a special case of block triangular matrices.
  3. Work it out. (A) is true, by the block triangular determinant rule. (B) is true: the rank of a block diagonal matrix is the sum of the ranks of its blocks, since no column of one block depends on the other. (C) is true: [[A, 0], [0, B]] · [[A⁻¹, 0], [0, B⁻¹]] = [[I, 0], [0, I]]. (D) is false: symmetry needs A and B to be symmetric, which is not given.
  4. Check. A = [[1, 2], [3, 4]] and B = [[1]] give M = [[1, 2, 0], [3, 4, 0], [0, 0, 1]], which is not symmetric. So (D) fails.

Answer: (A), (B) and (C).

Determinant of a block pattern (NAT)

Let A = diag(1, 2) and B = diag(2, 3). Consider the 4 × 4 matrix M = [[A, B], [B, A]]. Find det M. Give the answer as an integer.

How to think about it

  1. What is asked. The determinant of a 4 × 4 block matrix with diagonal blocks.
  2. Which idea applies. Reorder rows and columns so that the matrix splits into 2 × 2 blocks. Reordering the rows and columns in the same way does not change the determinant.
  3. Work it out. Index 1 is linked only to index 3 (through B and A), and index 2 only to index 4. Reorder the basis as (1, 3, 2, 4). Then M splits into two 2 × 2 blocks: for index 1, [[1, 2], [2, 1]]; for index 2, [[2, 3], [3, 2]]. The determinants are 1 − 4 = −3 and 4 − 9 = −5. Their product is (−3)(−5) = 15.
  4. Check. Using the Schur complement with A invertible: det M = det A · det(D − CA⁻¹B) = det A · det(A − B A⁻¹ B). Here det A = 2, A⁻¹ = diag(1, 1/2), and B A⁻¹ B = diag(2·1·2, 3·(1/2)·3) = diag(4, 9/2). So S = A − BA⁻¹B = diag(1 − 4, 2 − 9/2) = diag(−3, −5/2). Its determinant is (−3)(−5/2) = 15/2, and det A · 15/2 = 2 · 15/2 = 15. Same answer.

Answer: 15.

Inverse of a block matrix (MSQ)

Let M = [[2, 1, 1], [1, 3, 0], [0, 1, 4]], partitioned with A = [[2, 1], [1, 3]], B = [[1], [0]], C = [[0, 1]] and D = [[4]]. A is invertible. Select all that apply.

(A) det M = 21   (B) The Schur complement is S = 21/5   (C) The top-left 2 × 2 block of M⁻¹ is [[4/7, −1/7], [−4/21, 8/21]]   (D) det M = det A + det S

How to think about it

  1. What is asked. Which statements about this partitioned matrix are true.
  2. Which idea applies. The Schur complement, the determinant rule, and the block inverse formula with S.
  3. Work it out. The worked example in Step 5 gives det M = 21 and S = 21/5, so (A) and (B) are true. For (C), the top-left block of M⁻¹ is A⁻¹ + A⁻¹BS⁻¹CA⁻¹, which works out to [[4/7, −1/7], [−4/21, 8/21]]. A direct cofactor calculation of M⁻¹ gives the top-left block (1/21)[[12, −3], [−4, 8]], which is the same matrix, so (C) is true. For (D), the determinant rule is a product, not a sum, so (D) is false (5 + 21/5 is not 21).
  4. Check. Multiply M by the full inverse (1/21)[[12, −3, −3], [−4, 8, 1], [1, −2, 5]]. The first row of M times the first column gives 24 − 4 + 1 = 21, so the product is the identity, as the cofactor method guarantees.

Answer: (A), (B) and (C).

Exam-level 1: Determinant of a block matrix (NAT, 2 marks)

Let M = [[A, B], [0, D]] where A = [[2, 1], [1, 1]], D = [[3, 0], [4, 2]] and B is any 2 × 2 matrix. Find det(M).

How to think about it

  1. What is asked. The determinant of a block upper triangular matrix.
  2. Which idea applies. det [[A, B], [0, D]] = det(A) det(D) for square diagonal blocks.
  3. Work it out. det(A) = 2 − 1 = 1 and det(D) = 6. So det(M) = 6, whatever B is.

def det(M):
    if len(M) == 1:
        return M[0][0]
    return sum((-1) ** j * M[0][j] * det([r[:j] + r[j + 1:] for r in M[1:]]) for j in range(len(M)))

Exam-level 2: Schur complement (NAT, 2 marks)

Let M = [[A, B], [C, D]] with A = [[2]], B = [[1, 1]], C = [[1], [1]] and D = [[3, 1], [1, 3]]. Using det(M) = det(A) det(D − CA−1B), find det(M).

How to think about it

  1. What is asked. The determinant of a 3 × 3 matrix via the Schur complement.
  2. Which idea applies. The Schur complement of A is S = D − CA−1B.

print(a[0]*(b[1]*c[2]-b[2]*c[1]) - a[1]*(b[0]*c[2]-b[2]*c[0]) + a[2]*(b[0]*c[1]-b[1]*c[0]))

Exam-level 3: Block diagonal facts (MSQ, 2 marks)

Let M = diag(A, D), a block diagonal matrix with A being 2 × 2 and D being 3 × 3. Which are TRUE? (A) rank(M) = rank(A) + rank(D). (B) The eigenvalues of M are those of A together with those of D. (C) M−1 = diag(A−1, D−1) when both inverses exist. (D) tr(M) = tr(A)tr(D).

How to think about it

  1. What is asked. Which properties split over diagonal blocks.
  2. Which idea applies. Block diagonal matrices act on the two coordinate groups separately.
  3. Work it out. (A) True. (B) det(M − λI) = det(A − λI)det(D − λI). True. (C) Multiply blockwise to get I. True. (D) The trace adds: tr(M) = tr(A) + tr(D). False.
  4. Check. With A = I2 and D = I3, tr(M) = 5 while the product would be 6.

Answer: (A), (B) and (C).

Summary

Partition matrix
A matrix cut into blocks, each block being a smaller matrix.
Block
One rectangular piece of a partition matrix.
Conformable
Block sizes match, so that addition or multiplication is possible.
Block product
[[A, B], [C, D]] · [[E, F], [G, H]] has top-left block AE + BG.
Block diagonal
All off-diagonal blocks are zero.
Block triangular
All blocks below (or above) the diagonal blocks are zero.
Triangular determinant
det [[A, B], [0, D]] = det A · det D.
Triangular inverse
The top-right block of the inverse is −A⁻¹BD⁻¹.
Schur complement
S = D − CA⁻¹B, when A is invertible.
Determinant via Schur
det M = det A · det(S).
Singular matrix
A square matrix with determinant zero.
Rank of block diagonal
The sum of the ranks of the diagonal blocks.
Reordering
Permuting rows and columns in the same way does not change the determinant.

Remember these

  1. A partition matrix is the same matrix, viewed through blocks.
  2. Block products keep the order of the factors: AE is not EA.
  3. With a zero block below the diagonal, the determinant is the product of the diagonal block determinants.
  4. The top-right block of a block triangular inverse is −A⁻¹BD⁻¹.
  5. For general blocks with A invertible, det M = det A · det(D − CA⁻¹B).
  6. Always check a block result by expanding a small example.
