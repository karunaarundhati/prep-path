First-order differential equations (linear & nonlinear)

A differential equation is an equation that links a function to its own rate of change. First-order equations involve only the first derivative dy/dx. Many robotics models, such as a motor warming up or a sensor drifting, are first-order, so this topic is central to GATE RA. You will learn four solution methods: the integrating factor, separation of variables, exact equations, and the substitution for homogeneous equations.

The idea in plain words

Imagine a cup of hot tea cooling on a table. The hotter the tea, the faster it loses heat. The rate of change of the temperature depends on the temperature itself. Writing that rule in symbols gives a differential equation. The job is then to find the temperature as a function of time that obeys the rule.

A differential equation is an equation that contains a function and its derivatives. A first-order equation contains only the first derivative, dy/dx. Solving it means finding the function y(x), not just a number. The answer usually contains a constant C, because many functions share the same rate of change.

Everyday picture: a bucket leaking water. The rate at which the level falls depends on how full the bucket is. The solution tells you the level at every moment, given where you started.

Why it matters for GATE RA: first-order equations model the charging of a capacitor, the speed of a robot with friction, and the cooling of a motor. GATE questions usually ask you to choose the right method, solve for y, and then use an initial value such as y(0) = 0 to find C.

Key terms

Differential equation
Plain meaning: a rule that says how fast something changes. Precise definition: an equation involving a function and at least one of its derivatives.
Order
Plain meaning: the highest derivative that appears. Precise definition: the highest order of differentiation in the equation. First-order means dy/dx is the highest.
General solution
Plain meaning: the whole family of answers, with a constant C still to be fixed. Precise definition: a formula for y in terms of x and an arbitrary constant that satisfies the equation.
Particular solution
Plain meaning: one specific answer chosen by extra information. Precise definition: the general solution with C fixed, usually by an initial condition.
Initial condition
Plain meaning: where the solution starts. Precise definition: a known value y(x0) = y0 used to find C.
Linear equation
Plain meaning: y and its derivative appear only to the first power, with no products of y with itself. Precise definition: an equation of the form dy/dx + P(x) y = Q(x).
Integrating factor
Plain meaning: a multiplier that makes the left side easy to integrate. Precise definition: μ(x) = e∫P(x) dx for a linear equation in standard form.
Separable equation
Plain meaning: an equation where all the y terms can move to one side and all the x terms to the other. Precise definition: dy/dx = g(x) h(y).
Exact equation
Plain meaning: an equation that is the derivative of a hidden function. Precise definition: M(x, y) dx + N(x, y) dy = 0 with ∂M/∂y = ∂N/∂x.
Homogeneous equation
Plain meaning: an equation whose right side depends only on the ratio y/x. Precise definition: dy/dx = F(y/x).

Part 1: Linear first-order equations and the integrating factor

A linear first-order equation has the standard form:

dy/dx + P(x) y = Q(x)
  • P(x) is a known function multiplying y.
  • Q(x) is a known function on the right, sometimes called the forcing term.

The solution comes from a clever trick: multiply the whole equation by a factor that turns the left side into the derivative of a product.

The integrating factor

IF = e∫ P(x) dx

Multiplying the standard form by IF makes the left side the derivative of a product:

d/dx (IF × y) = IF × Q(x)

Integrate both sides with respect to x, then divide by IF:

y = (1/IF) × [ ∫ IF × Q(x) dx + C ]

Why does this work? The product rule says d/dx (IF × y) = IF dy/dx + y dIF/dx. Since dIF/dx = P(x) IF for the integrating factor above, the right side becomes IF (dy/dx + P y), which is IF times the left side of the standard form. The factor is chosen so that the extra term exactly matches the P y term.

A worked example, every step shown

Solve dy/dx + 2y = 4.

Step 1: Identify P and Q. P(x) = 2 and Q(x) = 4.

Step 2: Integrating factor. ∫ P dx = ∫ 2 dx = 2x. So IF = e2x.

Step 3: Multiply through. e2x dy/dx + 2e2x y = 4e2x. The left side is d/dx (e2x y). Check: d/dx (e2x y) = 2e2x y + e2x dy/dx, which matches.

Step 4: Integrate both sides. e2x y = ∫ 4e2x dx = 2e2x + C.

Step 5: Solve for y. y = 2 + C e−2x.

Step 6: Check by substitution. dy/dx = −2C e−2x. Then dy/dx + 2y = −2C e−2x + 4 + 2C e−2x = 4. The equation holds for every C.

Now an initial value problem: solve dy/dx + y = x with y(0) = 0.

Step 1. P = 1 and Q = x, so IF = ex.

Step 2. The equation becomes d/dx (ex y) = x ex.

Step 3. Integrate x ex by parts, with u = x and dv = ex dx. This gives ∫ x ex dx = x ex − ex + C.

Step 4. ex y = x ex − ex + C, so y = x − 1 + C e−x.

Step 5: Use the initial condition. y(0) = 0 − 1 + C = 0, so C = 1. The particular solution is y = x − 1 + e−x.

import math

def y(x):
    return x - 1 + math.exp(-x)

def dydx(x, h=1e-6):
    return (y(x + h) - y(x - h)) / (2 * h)

print("y(0) =", round(y(0), 4))
print("y(1) =", round(y(1), 4))
residuals = [dydx(t) + y(t) - t for t in [0.0, 0.5, 1.0, 2.0, 3.5]]
print("ODE satisfied at sample points:", all(abs(r) < 1e-5 for r in residuals))
y(0) = 0.0
y(1) = 0.3679
ODE satisfied at sample points: True

TrapPut the equation in standard form first, with dy/dx having coefficient 1. For example, x dy/dx + 2y = x needs dividing by x before you read off P(x).

Key ideaThe integrating factor turns the left side into a single derivative. After that, the rest of the work is ordinary integration.

What is the integrating factor for dy/dx − 3y = 0?

P(x) = −3, so ∫ P dx = −3x, and IF = e−3x.

Solve dy/dx + 2y = 6 with y(0) = 1.

The general solution is y = 3 + C e−2x. From y(0) = 3 + C = 1, C = −2. So y = 3 − 2e−2x.

Part 2: Separable equations

Some equations can be rearranged so that every y term sits on one side and every x term sits on the other. These are called separable. The idea is to separate the variables and integrate each side on its own.

dy/dx = g(x) h(y) becomes dy/h(y) = g(x) dx

Then integrate both sides: ∫ dy/h(y) = ∫ g(x) dx + C.

Everyday picture: a bank balance that grows in proportion to the money already in it. The more you have, the faster it grows. Separating the balance from the time is the natural first step.

A worked example, every step shown

Solve dy/dx = x y with y(0) = 2.

Step 1: Separate. Divide by y and multiply by dx: dy/y = x dx. We assume y is not zero here, and check y = 0 separately below.

Step 2: Integrate. ∫ dy/y = ∫ x dx gives ln|y| = x²/2 + C.

Step 3: Solve for y. Exponentiate: |y| = eC ex²/2. Write A = ±eC, a new constant, so y = A ex²/2.

Step 4: Use the initial condition. y(0) = A e0 = A = 2. So y = 2 ex²/2.

Step 5: Check. dy/dx = 2 × x ex²/2 = x y. ✓

import math

def y(x):
    return 2 * math.exp(x * x / 2)

h = 1e-6
x0 = 1.0
dydx = (y(x0 + h) - y(x0 - h)) / (2 * h)
print("y(1) =", round(y(x0), 4))
print("dy/dx at x = 1 =", round(dydx, 4))
print("x * y at x = 1 =", round(x0 * y(x0), 4))
print("y(0) =", round(y(0.0), 4))
y(1) = 3.2974
dy/dx at x = 1 = 3.2974
x * y at x = 1 = 3.2974
y(0) = 2.0

TrapDividing by y can lose the solution y = 0. Always check whether y = 0 satisfies the original equation. For dy/dx = xy it does, and it is the case A = 0 of the family.

Solve dy/dx = 2x(1 + y) with y(0) = 0.

Separate: dy/(1 + y) = 2x dx. Integrate: ln(1 + y) = x² + C. At x = 0, y = 0 gives ln 1 = 0 = C. So ln(1 + y) = x², and y = ex² − 1.

Why do we write ln|y| instead of ln y?

The logarithm is defined only for positive numbers. The absolute value allows y to be negative, and the constant A = ±eC absorbs the sign.

Part 3: Exact and non-exact equations

Write a first-order equation in differential form: M(x, y) dx + N(x, y) dy = 0. The equation is exact when it is the total derivative of some hidden function F(x, y), so that the solution is F(x, y) = C. That means:

∂F/∂x = M and ∂F/∂y = N

There is a simple test for this. Such an F exists exactly when the cross derivatives match:

∂M/∂y = ∂N/∂x

Everyday picture: a hill with a height function F. Walking a path, the change in height is M dx + N dy. If the equation is exact, the total change depends only on the start and end points, not on the route.

Solving an exact equation, every step shown

Solve (2xy + 3) dx + (x² + 4y) dy = 0.

Step 1: Name M and N. M = 2xy + 3 and N = x² + 4y.

Step 2: Test exactness. ∂M/∂y = 2x and ∂N/∂x = 2x. They are equal, so the equation is exact.

Step 3: Integrate M with respect to x. F = ∫ M dx = x²y + 3x + g(y). The unknown function g(y) appears because the constant of integration can depend on y.

Step 4: Match N. ∂F/∂y = x² + g′(y). This must equal N = x² + 4y. So g′(y) = 4y.

Step 5: Integrate g. g(y) = 2y².

Step 6: Write the solution. x²y + 3x + 2y² = C.

When the equation is not exact

If ∂M/∂y ≠ ∂N/∂x, the equation is not exact. It may still become exact after multiplying by a suitable factor μ. A common case is when the quantity below depends only on x:

(∂M/∂y − ∂N/∂x) / N depends only on x, then μ(x) = e∫ (∂M/∂y − ∂N/∂x)/N dx

Worked example: solve y dx + 2x dy = 0.

Step 1. M = y and N = 2x. ∂M/∂y = 1 and ∂N/∂x = 2. Not equal, so not exact.

Step 2. (∂M/∂y − ∂N/∂x)/N = (1 − 2)/(2x) = −1/(2x). This depends only on x.

Step 3. μ(x) = e∫ −1/(2x) dx = e−(1/2) ln x = x−1/2.

Step 4. Multiply the equation by μ: x−1/2 y dx + 2x1/2 dy = 0. Now M′ = x−1/2 y and N′ = 2x1/2. Check: ∂M′/∂y = x−1/2 and ∂N′/∂x = 2 × (1/2) x−1/2 = x−1/2. They are equal, so the new equation is exact.

Step 5. Integrate N′ with respect to y: F = 2x1/2 y + h(x). Then ∂F/∂x = x−1/2 y + h′(x), which must equal M′ = x−1/2 y. So h′(x) = 0, and h is a constant.

Step 6. The solution is 2y√x = C, or y√x = C. Check with the original equation: y = C x−1/2 gives dy/dx = −(1/2) C x−3/2 = −y/(2x), which matches dy/dx = −M/N = −y/(2x). ✓

import math

# F(x, y) = x^2 y + 3x + 2y^2 should satisfy F_x = 2xy + 3 and F_y = x^2 + 4y
def F(x, y):
    return x * x * y + 3 * x + 2 * y * y

def fx(x, y, h=1e-6):
    return (F(x + h, y) - F(x - h, y)) / (2 * h)

def fy(x, y, h=1e-6):
    return (F(x, y + h) - F(x, y - h)) / (2 * h)

x0, y0 = 1.5, 0.7
print("F_x matches 2xy + 3:", abs(fx(x0, y0) - (2 * x0 * y0 + 3)) < 1e-5)
print("F_y matches x^2 + 4y:", abs(fy(x0, y0) - (x0 * x0 + 4 * y0)) < 1e-5)

# non-exact example: solution of y dx + 2x dy = 0 through (1, 4) is y = 4 x^(-1/2)
def curve(x):
    return 4 / math.sqrt(x)

h = 1e-6
x1 = 2.0
slope = (curve(x1 + h) - curve(x1 - h)) / (2 * h)
print("y sqrt(x) on the curve at x = 4:", round(curve(4.0) * math.sqrt(4.0), 4))
print("dy/dx = -y/(2x) at x = 2:", abs(slope + curve(x1) / (2 * x1)) < 1e-5)
F_x matches 2xy + 3: True
F_y matches x^2 + 4y: True
y sqrt(x) on the curve at x = 4: 4.0
dy/dx = -y/(2x) at x = 2: True

TrapWhen you multiply by an integrating factor, the new M and N must both be multiplied. Multiplying only one of them destroys the equation.

GATE loves thisExact equations often appear with an initial condition. Substitute the point into F(x, y) to find C, not into the original equation.

Is (y + x) dx + (x + y) dy = 0 exact?

M = y + x, so ∂M/∂y = 1. N = x + y, so ∂N/∂x = 1. They are equal, so yes, it is exact.

For the exact equation above, what is the solution through (0, 1)?

With F = x²y + 3x + 2y², the value at (0, 1) is 0 + 0 + 2 = 2. So the solution is x²y + 3x + 2y² = 2.

Part 4: Homogeneous equations and substitution

An equation dy/dx = f(x, y) is homogeneous when the right side depends only on the ratio y/x. Example: dy/dx = (x + y)/x = 1 + y/x. Here the right side is a function of y/x alone.

The trick is to substitute v = y/x. Then y = v x, and by the product rule:

dy/dx = v + x dv/dx

Substituting turns the equation into one in v that can be separated.

A worked example, every step shown

Solve dy/dx = (x + y)/x with y(1) = 2.

Step 1: Substitute. Let y = v x, so dy/dx = v + x dv/dx. The right side is (x + vx)/x = 1 + v.

Step 2: Simplify. v + x dv/dx = 1 + v. Subtract v from both sides: x dv/dx = 1.

Step 3: Separate. dv = dx/x.

Step 4: Integrate. v = ln|x| + C.

Step 5: Go back to y. y = x (ln|x| + C).

Step 6: Initial condition. y(1) = 1 × (ln 1 + C) = C = 2. So y = x (ln x + 2) for x > 0.

Step 7: Check. dy/dx = ln x + 2 + 1 = ln x + 3. The right side (x + y)/x = 1 + (ln x + 2) = ln x + 3. ✓

import math

def y(x):
    return x * (math.log(x) + 2)

h = 1e-6
def dydx(x):
    return (y(x + h) - y(x - h)) / (2 * h)

for x0 in [1.0, 2.0, math.e]:
    rhs = (x0 + y(x0)) / x0
    print("x =", round(x0, 4), " ODE holds:", abs(dydx(x0) - rhs) < 1e-5)
print("y(e) =", round(y(math.e), 4))
x = 1.0  ODE holds: True
x = 2.0  ODE holds: True
x = 2.7183  ODE holds: True
y(e) = 8.1548

TipTo recognise a homogeneous equation, replace x by λx and y by λy. If the equation is unchanged, it is homogeneous. For example, (λx + λy)/(λx) = (x + y)/x, so it is.

TrapAfter substituting, do not forget dy/dx = v + x dv/dx. Writing dy/dx = dv/dx alone is the most common error.

What is the substitution for a homogeneous equation?

v = y/x, so y = v x and dy/dx = v + x dv/dx.

Is dy/dx = y/x + x² homogeneous?

No. The term x² cannot be written as a function of y/x alone, because it depends on x by itself.

Exponential growth with a start value

Solve dy/dx = 3y with y(0) = 2. Find y(1), correct to 4 decimal places.

How to think about it

  1. What is asked. The value of the solution at x = 1.
  2. Which idea applies. The equation is separable, and also linear with P = −3 and Q = 0.
  3. Work it out. Separate: dy/y = 3 dx, so ln|y| = 3x + C, giving y = A e3x. From y(0) = 2, A = 2. So y(1) = 2e3 ≈ 40.1711.
  4. Check. The derivative of 2e3x is 6e3x, which equals 3 × 2e3x. ✓

Answer: 40.1711.

Solve dy/dx = 2y with y(0) = 3. Find y(1), correct to 4 decimal places.

How to think about it

  2. Which idea applies. Separable, giving y = A e2x.
  3. Work it out. y(0) = A = 3, so y = 3e2x. Then y(1) = 3e2 ≈ 3 × 7.389056 = 22.167168, which is 22.1672.

Which equations are linear first-order?

Select all equations that are linear first-order equations.

(A) dy/dx + xy = sin x
(B) dy/dx + y² = 0
(C) x dy/dx = y + 1
(D) dy/dx = xy

Select all that apply.

How to think about it

  1. What is asked. Which equations have y and dy/dx only to the first power, with no y² or products of y with itself.
  2. Which idea applies. Write each as dy/dx + P(x) y = Q(x).
  3. Work it out. (A) is already in the form with P = x and Q = sin x. Linear. (B) has y², so it is not linear. (C) divided by x gives dy/dx − y/x = 1/x, with P = −1/x and Q = 1/x. Linear for x ≠ 0. (D) is dy/dx − xy = 0, with P = −x and Q = 0. Linear.
  4. Check. Only the y² term breaks linearity, and only (B) has one.

Answer: (A), (C) and (D).

A separable equation through a point

Solve dy/dx = 2x(1 + y) with y(0) = 0. Find y(1), correct to 4 decimal places.

How to think about it

  1. What is asked. y(1) for the solution through (0, 0).
  2. Which idea applies. Separation of variables.
  3. Work it out. dy/(1 + y) = 2x dx, so ln(1 + y) = x² + C. At x = 0, y = 0, so C = 0. Then y = ex² − 1. At x = 1, y = e − 1 ≈ 1.7183.
  4. Check. dy/dx = 2x ex² and 2x(1 + y) = 2x ex². ✓

Answer: 1.7183.

Finding the constant of an exact solution

The exact equation (2xy + 3) dx + (x² + 4y) dy = 0 has solution x²y + 3x + 2y² = C. Find the value of C for the solution that passes through (0, 1). Give the answer as a number.

How to think about it

  1. What is asked. The constant C for one point on the curve.
  2. Which idea applies. Substitute the point into the solution function F(x, y).
  3. Work it out. F(0, 1) = 0² × 1 + 3 × 0 + 2 × 1² = 0 + 0 + 2 = 2. So C = 2.
  4. Check. Substitute (0, 1) back: 0 + 0 + 2 = 2, which matches.

Answer: C = 2.

An exact-factor problem with a starting point

Solve y dx + 2x dy = 0 with the curve passing through (1, 4). Find y when x = 4.

How to think about it

  1. What is asked. The value of y at x = 4 on the solution through (1, 4).
  2. Which idea applies. The equation is not exact, but the integrating factor μ = x−1/2 makes it exact. The solution is y√x = C.
  3. Work it out. At (1, 4), C = 4 × √1 = 4. So y√x = 4. At x = 4, y × 2 = 4, so y = 2.
  4. Check. y = 4x−1/2 gives dy/dx = −2x−3/2. At x = 1 this is −2. And −y/(2x) at x = 1 is −4/2 = −2. ✓

Answer: y = 2.

Which statements about a linear solution are correct?

Consider dy/dx + y = x with y(0) = 0, whose solution is y = x − 1 + e−x. Select all statements that are correct.

(A) y(1) = e−1.
(B) As x grows, y gets close to x − 1.
(C) y(0) = 1.
(D) y is a polynomial in x.

Select all that apply.

How to think about it

  1. What is asked. Test four claims about the solution.
  2. Which idea applies. Substitute values into the solution, and look at its large-x behaviour.
  3. Work it out. (A): y(1) = 1 − 1 + e−1 = e−1, true. (B): e−x shrinks to 0, so y approaches x − 1, true. (C): y(0) = 0 − 1 + 1 = 0, not 1, false. (D): the term e−x is not a polynomial, so false.
  4. Check. Only A and B match the computed values and the limit.

Exam-level 1: Integrating factor (NAT, 2 marks)

Solve y′ + 2y = 4x with y(0) = 1. Find y(1), correct to 3 decimal places.

How to think about it

  1. What is asked. The solution of a linear first-order equation at x = 1.
  2. Which idea applies. Integrating factor e2x. A particular solution is linear: yp = 2x − 1.
  3. Work it out. General solution y = 2x − 1 + Ce−2x. y(0) = −1 + C = 1 gives C = 2. y(1) = 1 + 2e−2 = 1.271.
  4. Check. The code runs a fine Runge-Kutta step to confirm.
import math
f = lambda x, y: 4 * x - 2 * y
x, y, h = 0.0, 1.0, 0.001
for _ in range(1000):
    k1 = f(x, y); k2 = f(x + h/2, y + h*k1/2); k3 = f(x + h/2, y + h*k2/2); k4 = f(x + h, y + h*k3)
    y += h * (k1 + 2*k2 + 2*k3 + k4) / 6; x += h
print("RK4 = %.3f  exact = %.3f" % (y, 1 + 2 * math.exp(-2)))

RK4 = 1.271  exact = 1.271

Answer: about 1.271.

Remember these

  1. Linear first-order equations use the integrating factor e∫P dx.
  2. After multiplying by the integrating factor, the left side is d/dx (IF × y).
  3. Separable equations: move all y to one side and all x to the other, then integrate.
  4. Exact test: ∂M/∂y = ∂N/∂x. Integrate M in x, then match N to find the unknown function.
  5. Multiply both M and N by a non-exact factor, not just one of them.
  6. Homogeneous equations: substitute y = v x and remember dy/dx = v + x dv/dx.
  7. Always use the initial condition last, to find C.
