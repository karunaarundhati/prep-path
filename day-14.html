Aptitude: logical reasoning

Aptitude rounds test how quickly and accurately you can reason with rules, patterns and relationships. Most logical reasoning questions are not hard once you know the method. The trap is trying to solve them in your head. For each type below, you will see the method first, then a fully solved problem. Work each one on paper before reading the solution.

A general strategy applies to every type. First, write down exactly what the question gives you. Second, turn the words into a small diagram, table or list. Third, check your answer against every statement, because a wrong option often satisfies one clue but not all of them. If an answer requires a guess, say so and move on; aptitude tests reward speed as much as accuracy.

Number and letter series

A series is a list of terms that follow a rule, and you must find the missing term. Try these checks in order:

  • Differences. Subtract each term from the next. If the differences form a pattern (constant, growing by a fixed step, or themselves a known series), the rule is additive.
  • Ratios. Divide each term by the previous one. A constant ratio means the rule is multiplicative.
  • Interleaving. Take every second term. If the odd positions form one series and the even positions form another, solve the two series separately.
  • Known families. Squares (1, 4, 9, 16), cubes (1, 8, 27, 64), primes, triangular numbers (1, 3, 6, 10) and powers of two.

Solved problem 1. Find the next term in 2, 6, 12, 20, 30, ?

  1. Differences: 6 - 2 = 4, 12 - 6 = 6, 20 - 12 = 8, 30 - 20 = 10.
  2. The differences increase by 2 each time, so the next difference is 12.
  3. Next term: 30 + 12 = 42. Check: each term is n times (n + 1), so 6 times 7 is 42.

Answer: 42.

Solved problem 2. Find the next term in 2, 5, 4, 7, 6, 9, ?

  1. Simple differences are irregular (+3, -1, +3, -1, +3), so split the series into two interleaved series.
  2. Odd positions: 2, 4, 6, which rise by 2. Even positions: 5, 7, 9, which also rise by 2.
  3. The seventh term is at an odd position, so it continues the first series: 6 + 2 = 8.

Answer: 8.

TrapWhen a series looks irregular, do not guess the first pattern you see. Test the interleaved split before you decide. Many questions are designed to look like a single rule.

Coding-decoding

In these questions a word is written in a code, and you must decode or encode another word. The usual rules are letter shifts (each letter moves forward or backward by a fixed amount), reversals (A becomes Z, B becomes Y, and so on), and substitutions. Number each letter from A equals 1 to Z equals 26 so that shifts are plain arithmetic.

Solved problem 3. If CAT is coded as DBU, how is BIRD coded?

  1. Compare the letters: C (3) becomes D (4), A (1) becomes B (2), T (20) becomes U (21). Each letter moves forward by 1.
  2. Apply the same shift to BIRD: B becomes C, I becomes J, R becomes S, D becomes E.
  3. Result: CJSE.

Answer: CJSE.

The same idea can be checked with a few lines of code, which is a good habit for shifts:

def shift(word, n):
    """Move every letter forward by n places, wrapping from Z back to A."""
    return "".join(chr((ord(ch) - ord("A") + n) % 26 + ord("A")) for ch in word)


print(shift("CAT", 1))
print(shift("BIRD", 1))

Solved problem 4. If the alphabet is reversed so that A is Z, B is Y, C is X and so on, what is CAT coded as?

  1. Reversal rule: the code of a letter at position p is the letter at position 27 minus p.
  2. C is position 3, so its code is position 24, which is X.
  3. A is position 1, so its code is position 26, which is Z.
  4. T is position 20, so its code is position 7, which is G.

Answer: XZG.

Blood relations

Blood relation questions give a chain of statements about family members. The method is to draw a family tree as you read, with generations on separate rows and siblings on the same row. Use "=" for a married pair and a straight line for parent and child. Gender matters: if a statement gives a gender, use it; if not, do not assume one.

Solved problem 5. A is the father of B. B is the sister of C. C is the mother of D. How is D related to A?

  1. Row one: A. A is the father of B, so B is on the row below A.
  2. B is the sister of C, so C is also a child of A. C is on the same row as B.
  3. C is the mother of D, so D is one row lower, a child of C.
  4. D is A's child's child, which makes D a grandchild of A. The statements do not give D's gender, so the correct description is grandchild, not grandson or granddaughter.

Answer: D is A's grandchild.

TrapIf an option says "granddaughter" and the question never states D's gender, that option is not guaranteed. Choose the description that must be true, which is "grandchild".

Direction sense

Direction problems are about position, not about the route. The reliable method is to place the start point at the origin of a graph, with north as up (positive y) and east as right (positive x). Each move changes the x or y coordinate. A left turn turns you 90 degrees counterclockwise, so facing north, a left turn makes you face west. The final distance from the start is the straight-line distance, which is the square root of x squared plus y squared, and many questions use only the simpler north-south or east-west components.

Solved problem 6. A person walks 5 km north, turns left and walks 3 km, turns left again and walks 5 km. How far is the person from the starting point, and in which direction?

  1. Start at (0, 0), facing north. Walk 5 km north: position (0, 5).
  2. Turn left: now facing west. Walk 3 km west: position (-3, 5).
  3. Turn left: now facing south. Walk 5 km south: position (-3, 0).
  4. The final position has no north-south offset and an x value of -3, so the person is 3 km west of the start.

The same walk can be checked in code, with the heading tracked as a list of directions in counterclockwise order:

DIRS = ["N", "W", "S", "E"]               # counterclockwise: one left turn moves one step forward
VEC = {"N": (0, 1), "W": (-1, 0), "S": (0, -1), "E": (1, 0)}

x, y = 0, 0
heading = 0                              # index into DIRS; the person starts facing north
walk = [(None, 5), ("L", 3), ("L", 5)]   # (turn before the walk, distance in km)
for turn, km in walk:
    if turn == "L":
        heading = (heading + 1) % 4
    dx, dy = VEC[DIRS[heading]]
    x += dx * km
    y += dy * km

print(x, y)
print(abs(x) + abs(y))

Seating arrangement

Seating questions give a set of constraints about people sitting in a row, a circle or a table. Draw empty boxes first, one per seat, and then place the fixed clues: a person at the centre, a person at an end, a person immediately next to another person. Place the most restrictive clue first. A good question has exactly one arrangement; if you find two, reread the clues, because you have missed one.

Solved problem 7. Five people P, Q, R, S and T sit in a row facing north. R sits in the centre. P sits at one end. Q sits immediately to the right of P. S sits to the right of Q but not next to Q. T sits at the other end. Who sits at the far right?

  1. Draw five boxes numbered 1 to 5 from left to right, as you read the row from its left end.
  2. R is in the centre: box 3.
  3. P is at an end. If P were in box 5, Q would need box 6 to be immediately right of P, which does not exist. So P is in box 1.
  4. Q is immediately right of P: box 2.
  5. T is at the other end: box 5.
  6. S is the only person left, and box 4 is the only free box. Check: S is in box 4, to the right of Q in box 2, and not next to Q because box 3 is in between.

Answer: T sits at the far right, in box 5. The full order from left to right is P, Q, R, S, T.

Interviewers askSeating questions reward structure rather than speed. Say the constraint you are using before you place each person; interviewers often watch how you narrow the options.

Syllogisms

A syllogism gives two or three statements and then one or more conclusions. You must decide whether each conclusion must follow from the statements, not whether it is true in the real world. The four standard forms are: "All A are B" (every A is inside B), "No A is B" (A and B do not overlap), "Some A are B" (at least one A is also a B) and "Some A are not B" (at least one A is outside B).

Two rules cover most cases. First, "Some A are B" can be turned around: it means "Some B are A". Second, "All A are B" does not allow you to reverse it: "All B are A" is not implied. Draw a Venn diagram: a circle for each term, placing one circle inside another for "All", and leaving overlap empty or non-empty as the statements require. A conclusion follows only if every diagram that fits the statements also shows it.

Solved problem 8. Statements: All pens are books. Some books are red. Conclusions: I. Some pens are red. II. Some red things are books. Which conclusions follow?

  1. Draw the circle "books" and place the circle "pens" entirely inside it, because all pens are books.
  2. Draw the circle "red" overlapping the books circle, because some books are red. The overlap might be entirely outside the pens circle.
  3. Conclusion I says some pens are red. The overlap of red and books can lie outside the pens circle, so I does not have to be true. It does not follow.
  4. Conclusion II says some red things are books. The overlap of red and books is non-empty by the second statement, and that is exactly what II says. It follows, because the statement "Some books are red" can be turned around.

Answer: only conclusion II follows.

Why does "All pens are books" not allow the conclusion "All books are pens"?

"All pens are books" says the pens circle sits inside the books circle, leaving other books outside it. "All books are pens" would require the books circle to sit inside the pens circle. Those two pictures are different, so the reverse statement is not implied. Only "Some books are pens" can be drawn from "All pens are books", because the overlap is the whole pens circle.

How do you decide whether a syllogism conclusion follows?

Draw a Venn diagram for every statement, and try to draw a picture that satisfies the statements but breaks the conclusion. If you can, the conclusion does not follow. If no valid picture can break it, the conclusion must follow.

Computer organisation

What are the four steps of the instruction cycle?

Fetch, decode, execute and store (write back). The program counter holds the address of the next instruction, the instruction register holds the current one, and the cycle repeats for each instruction.

What is the IEEE 754 layout of a single-precision float?

One sign bit, eight exponent bits with a bias of 127, and 23 fraction bits, which is 32 bits in total. Double precision uses 1, 11 and 52 bits with a bias of 1023.

What is the difference between RISC and CISC?

RISC uses a small set of simple, fixed-length instructions, usually one per clock cycle, with a load-store design. CISC offers many complex instructions, some of which access memory directly, and instruction lengths vary. Modern processors blend the two ideas.

Name the three kinds of pipeline hazard and give an example of a data hazard.

Structural hazards occur when two stages need the same hardware. Data hazards occur when an instruction needs a result that a previous instruction has not yet produced, such as add r1, r2, r3 followed by sub r4, r1, r5. Control hazards occur when a branch changes the flow before the pipeline knows which way it goes.

Write the average memory access time formula and compute an example.

AMAT equals hit time plus miss rate times miss penalty. With a 1 ns hit time, a 5 percent miss rate and a 100 ns miss penalty, the AMAT is 1 + 0.05 times 100, which is 6 ns.

How does DMA differ from interrupt-driven I/O?

With interrupt-driven I/O, the CPU moves each unit of data itself and handles an interrupt per transfer. With DMA, a DMA controller moves a block of data between the device and memory, and the CPU is interrupted only when the block is complete.

Operating systems

What is the difference between user mode and kernel mode, and why does it matter?

Kernel mode allows any instruction and any memory access. User mode is restricted, so a faulty or malicious program cannot change the hardware or other programs' memory. A system call switches the CPU into kernel mode in a controlled way.

What does fork and exec do, and what is a zombie or an orphan process?

fork creates a copy of the calling process; the child gets 0 back and the parent gets the child's PID. exec replaces the program image of the current process. A zombie is a finished child whose parent has not yet collected its exit status. An orphan is a child whose parent has ended first, so it is adopted by an init process.

Compare FCFS, SJF, SRTF and round robin in one sentence each.

FCFS runs processes in arrival order, without preemption. SJF runs the shortest job next without preemption. SRTF is the preemptive version of SJF, so a newly arrived shorter job can interrupt the running one. Round robin gives each process a fixed time quantum in turn, which favours responsiveness.

What are the four conditions for deadlock?

Mutual exclusion (a resource can be held by one process at a time), hold and wait (a process holds one resource while waiting for another), no preemption (resources cannot be forcibly taken), and circular wait (a cycle of processes, each waiting for the next). All four must hold for a deadlock to occur.

What is the difference between a mutex and a semaphore?

A mutex is a lock with ownership: the thread that locks it must unlock it, and it protects one critical section. A semaphore is a counter with wait and signal operations, and any thread may signal it, so it can count available resources or signal between threads.

What is the difference between paging and segmentation, and what does the TLB do?

Paging divides memory into fixed-size pages, which removes external fragmentation but can waste space inside the last page. Segmentation divides memory into variable-size logical units such as code and stack. The TLB is a small, fast cache of recent page-table entries, so most address translations avoid a memory access to the page table.

What is thrashing, and what causes it?

Thrashing is a state where the system spends most of its time swapping pages in and out, and very little time doing useful work. It happens when processes do not have enough frames for their working sets, so each access causes a page fault.

Concurrency and containers

What is the difference between concurrency and parallelism?

Concurrency is about managing several tasks that make progress over the same period, which can happen on one core by switching. Parallelism is about running several tasks at the same instant on several cores. Parallelism is one way to achieve concurrency, but not the only one.

What does the Python GIL do, and what does it mean for threads?

In CPython, the Global Interpreter Lock allows only one thread at a time to execute Python bytecode. Threads still help with I/O-bound work, because a thread waiting for the network releases the lock. CPU-bound work needs processes or C extensions to run in parallel.

What is the difference between a container and a virtual machine?

A container is an isolated process that shares the host kernel, isolated with namespaces and limited with cgroups. A virtual machine has its own guest kernel and virtual hardware, isolated by a hypervisor. Containers start faster and are smaller; VMs offer a stronger boundary.

Why do Dockerfile instructions get ordered from least to most frequently changing?

Each layer is cached, and a changed layer invalidates every layer after it. Dependency installs placed before source copies therefore survive most rebuilds.

What does a Kubernetes Deployment do that a bare pod does not?

A Deployment keeps the requested number of identical pods running through a ReplicaSet, replaces failed pods, and performs rolling updates and rollbacks. A bare pod is not replaced if it fails or its node dies.

Mock interview: ten questions

Treat this as a timed mock. Give yourself about two minutes per question, answer out loud, then compare your answer with the model. The model answers are deliberately complete so you can see the expected depth; in the room, aim for the first three sentences and offer more if asked.

Walk me through what happens when the CPU executes an instruction.

The program counter holds the address of the next instruction. The control unit fetches that instruction from memory into the instruction register and increments the program counter. It then decodes the instruction to find the operation and the operands, executes it in the ALU or another functional unit, and writes the result back to a register or memory. The cycle repeats. Pipelining overlaps these stages for different instructions, which raises throughput without making any single instruction faster.

A cache has a 2 ns hit time, a 10 percent miss rate and a 80 ns miss penalty. What is the AMAT?

AMAT equals the hit time plus the miss rate times the miss penalty: 2 + 0.10 times 80, which is 2 + 8, giving 10 ns. Say that each access pays the hit time, and only the misses pay the extra penalty.

What is the difference between a process and a thread?

A process has its own address space, file descriptors and resources, and it is isolated from other processes. Threads inside one process share its address space, heap and open files, but each has its own stack and register state. Creating and switching threads is cheaper than processes, but a bug in one thread can corrupt the memory of all of them.

Explain the producer-consumer problem and a correct semaphore solution.

Producers add items to a bounded buffer and consumers remove them. The buffer must not overflow or underflow, and the buffer itself must not be modified by two threads at once. Use three semaphores: mutex (initialised to 1) protects the buffer, empty (initialised to the buffer size N) counts free slots, and full (initialised to 0) counts filled slots. A producer waits on empty, then on mutex, inserts the item, signals mutex, and signals full. A consumer waits on full, then on mutex, removes the item, signals mutex, and signals empty. The order matters: if a thread waits on mutex before the counting semaphore, it can hold the lock while blocked, and the system deadlocks.

What are the four deadlock conditions, and how would you prevent deadlock with two locks?

The conditions are mutual exclusion, hold and wait, no preemption and circular wait. To prevent deadlock with two locks, break circular wait: every thread acquires lock A before lock B, always in the same global order. Breaking any one of the four conditions is enough, but ordering the locks is the most practical choice.

Trace FIFO and LRU for the reference string 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5 with three frames. What is Belady's anomaly?

With three frames, FIFO causes 9 page faults and LRU causes 10 page faults. Belady's anomaly is the observation that FIFO can cause more faults when you add frames: the same string with four frames causes 10 faults for FIFO, up from 9. LRU is a stack algorithm and never shows this anomaly.

Explain fork and exec, and say what a zombie process is.

fork duplicates the calling process, returning 0 to the child and the child's PID to the parent. exec loads a new program into the current process, keeping its PID. A zombie is a child that has exited while its parent has not yet called wait, so its exit status is still held in the process table. The fix is for the parent to wait on its children.

What is the difference between a Docker container and a Kubernetes pod?

A container is a single isolated process, started from an image. A pod is the smallest unit Kubernetes schedules: one or more containers that share a network address and can share volumes. Most pods contain one container, but a sidecar, such as a log shipper, may share the pod with the main container.

Why does Python threading not speed up CPU-bound work, and what would you use instead?

CPython's GIL lets only one thread run Python bytecode at a time, so CPU-bound threads take turns instead of running in parallel. For CPU-bound work, use the multiprocessing module, which starts separate processes with their own interpreters, or move the heavy work into a native library that releases the GIL. Threads remain useful for I/O-bound work, such as network calls.

Why does a mutex protect a critical section better than a bare flag?

A flag checked and then set in two separate steps can be interleaved by two threads, so both see it as free and both enter. A mutex makes the test and the set one atomic operation, and it blocks other threads until the owner releases it. It also gives memory ordering guarantees that a plain variable does not.

Resume and HR: telling your story

Technical rounds test what you know; HR rounds test how you explain what you have done. Interviewers use the same few questions to see whether your answers are specific, honest and connected to the role. The method that works for almost every story is STAR.

The STAR method

  • Situation. One or two sentences of context: where you were, and what problem existed.
  • Task. Your specific responsibility. Say "I was responsible for" so the interviewer knows which part was yours.
  • Action. What you did, step by step, using "I" and naming the tools or methods. This is the longest part, and it is where interviewers look for depth.
  • Result. What changed, with a number if you have one, and what you learned.

A STAR answer takes about two minutes. Spend the most time on the action, and never invent a metric. If you do not have a number, describe the result in words, such as "the bug stopped recurring" or "the team adopted the test".

TrapDo not describe the team's work as if it were yours. Interviewers are checking your contribution. Use "I" for your actions and "we" only for shared outcomes.

Gas Station (LeetCode 134)

There are n gas stations on a circular road. Station i gives you gas[i] units of fuel, and it costs cost[i] units of fuel to drive from station i to station i + 1. You start with an empty tank at one station. Return the index of the starting station from which you can complete one full clockwise loop, or -1 if no such station exists. For example, with gas = [1, 2, 3, 4, 5] and cost = [3, 4, 5, 1, 2], the answer is 3: starting at station 3 you collect 4 and spend 1, then collect 5 and spend 2, and so on, and you never run out.

How to think about it

  1. Understand. Define the net fuel at station i as gas[i] - cost[i]. A full loop needs the total net fuel to be non-negative, and the start must be chosen so the running total never drops below zero.
  2. Brute force. Try every start, simulate the loop, and stop if the tank goes negative. Each simulation takes n steps and there are n starts, so the cost is O(n^2).
  3. Find the waste. Starting from a station that fails at a later station j wastes all the simulation between them, and the next candidate is the best place to resume.
  4. Optimise. Track two running sums. The total over the whole loop decides whether any answer exists: if it is negative, return -1. The tank since the current candidate start decides when to move the candidate. If the tank goes negative at station i, no station from the candidate start up to i can work, because each of them reaches i with even less fuel. So the new candidate is i + 1 and the tank resets. If the total is non-negative, the last candidate is the answer, and it is unique.
  5. Dry run. With the example above, the net values are -2, -2, -2, 3, 3. The tank goes negative at stations 0, 1 and 2, so the candidate moves to 1, then 2, then 3. From station 3 the tank is 3, then 6, and the total is 0, which is non-negative. The answer is 3.

Code

def can_complete_circuit(gas, cost):
    """Return the starting station for a full loop, or -1 if there is none."""
    total = 0                     # net fuel for the whole loop
    tank = 0                      # net fuel since the current candidate start
    start = 0                     # the current candidate starting station
    for i in range(len(gas)):
        diff = gas[i] - cost[i]
        total += diff
        tank += diff
        if tank < 0:
            start = i + 1         # no station from start up to i can work
            tank = 0              # begin counting again from the new candidate
    return start if total >= 0 else -1


print(can_complete_circuit([1, 2, 3, 4, 5], [3, 4, 5, 1, 2]))
print(can_complete_circuit([2, 3, 4], [3, 4, 3]))
print(can_complete_circuit([5, 8, 2, 8], [6, 5, 6, 6]))

TrapDo not return start just because the loop ended. The candidate is only valid when the total is non-negative. Without that check, the second example would wrongly return a station.

Pattern to rememberWhen a greedy choice can be proven safe by a running sum, you can discard a whole block of candidates at once instead of testing each one.

Decode String (LeetCode 394)

Given an encoded string, return its decoded form. The encoding rule is k[encoded], which means the encoded text is repeated k times. Brackets can be nested. Examples: 3[a]2[bc] becomes aaabcbc, 3[a2[c]] becomes accaccacc, and 2[abc]3[cd]ef becomes abcabccdcdcdef.

How to think about it

  1. Understand. The input is always well formed, so every opening bracket has a matching closing bracket. Numbers can have more than one digit, for example 10[x].
  2. Brute force. Find the innermost bracket with a regular expression, expand it, and repeat until no brackets remain. Each pass rescans the string, so the cost grows with the depth of nesting.
  3. Find the waste. The innermost expansion is done first, but a string with n characters is rescanned for every level of nesting, and each expansion creates a new string.
  4. Optimise. Process the string once, left to right, with a stack. When you see an opening bracket, push the text built so far and the repeat count that is about to apply, then start a fresh text. When you see a closing bracket, pop the saved text and count, and append the current text repeated count times to the saved text. Each character is handled a constant number of times, so the cost is linear in the output.

def decode_string(s):
    """Expand k[text] patterns, including nested ones, in a single pass."""
    stack = []                    # each entry: (text built before the bracket, repeat count)
    current = ""                  # text being built at the current nesting level
    number = 0                    # the repeat count being read; it can have several digits
    for ch in s:
        if ch.isdigit():
            number = number * 10 + int(ch)
        elif ch == "[":
            stack.append((current, number))
            current, number = "", 0
        elif ch == "]":
            previous, times = stack.pop()
            current = previous + current * times
        else:
            current += ch
    return current

Basic Calculator (LeetCode 224)

Given a string s that represents an arithmetic expression, evaluate it and return the result. The string contains non-negative integers, the operators + and -, parentheses, and spaces. There is no multiplication or division. Examples: "1 + 1" gives 2, " 2-1 + 2 " gives 3, and "(1+(4+5+2)-3)+(6+8)" gives 23. Expressions can also start with a minus sign or a bracket, such as -(2 + 3).

How to think about it

  1. Understand. Operator precedence is not an issue, because only addition and subtraction exist. The hard part is parentheses, and unary minus, which is a minus sign that negates a number or a bracket.
  2. Brute force. Convert the expression to postfix notation with the shunting-yard algorithm, then evaluate the postfix form with a stack. It works, and it is worth naming, but it is two passes with extra structure.
  3. Find the waste. Evaluating each parenthesised group separately, then combining it with the outer level, is exactly what a stack of saved results does. We can keep one running total per nesting level.
  4. Optimise. Keep three values: the running result at the current level, the number being read, and the sign that applies to the next number. An operator adds the pending number, with its sign, to the result and records the new sign. An opening bracket saves the current result and sign on a stack, then starts fresh at level zero with sign plus. A closing bracket finishes the current level, then combines it with the saved result and sign: the saved result plus the saved sign times this level's value. Spaces are ignored. The cost is one pass, O(n).
  5. Dry run. For 2-(5-6): read 2, then the minus sets the sign to -1 with result 2. The opening bracket saves (2, -1) and starts at 0. Inside, 5 is added, then minus sets sign -1, then 6 is read. The closing bracket adds -1 times 6, giving -1 at this level, then combines it with the saved value: 2 + (-1) times (-1), which is 3.

Code

def calculate(s):
    """Evaluate an expression with +, -, parentheses and spaces in one pass."""
    result = 0                    # the running total at the current parenthesis level
    number = 0                    # the number being read
    sign = 1                      # +1 or -1: the sign that applies to the next number
    stack = []                    # saved (result, sign) pairs from outer levels
    for ch in s:
        if ch.isdigit():
            number = number * 10 + int(ch)
        elif ch in "+-":
            result += sign * number
            number = 0
            sign = 1 if ch == "+" else -1
        elif ch == "(":
            stack.append((result, sign))
            result, sign = 0, 1
        elif ch == ")":
            result += sign * number
            number = 0
            saved_result, saved_sign = stack.pop()
            result = saved_result + saved_sign * result
        # spaces fall through and are ignored
    result += sign * number       # add the last number
    return result


print(calculate("1 + 1"))
print(calculate(" 2-1 + 2 "))
print(calculate("(1+(4+5+2)-3)+(6+8)"))
print(calculate("- (3 + (4 + 5))"))
print(calculate("2-(5-6)"))
