Matrices from zero: what a matrix really is

A vector is an arrow with a list of numbers, and a matrix is a table of numbers that also works as a machine that moves arrows. Both are the building blocks of almost every GATE linear algebra question, so we start here from zero.

The idea in plain words

Welcome. If the word "matrix" makes you nervous, you are in good company. This page assumes you know almost nothing. We build every idea from a small picture, and we do not move on until the current idea feels solid.

Here is the one-sentence version: a matrix is a rectangle of numbers, and when you multiply it by a vector, it moves that vector to a new place.

Think of a matrix as a card of instructions for a robot on a grid. You hand the robot a point, it follows the card, and it gives you back a new point. Some instructions stretch the grid, some turn it, some tilt it.

Why does this matter for GATE? Almost every data science algorithm is written as matrix operations, and in Robotics and Automation the position of a robot joint after it turns is found by multiplying by a rotation matrix. GATE DA and RA questions often give a small matrix and ask what it does to a vector. Once you can read a matrix comfortably, those questions become calm and quick.

Key terms

Read this list once, and come back to it whenever a word feels unfamiliar.

Scalar
A plain single number, such as 3 or -2. Used to scale vectors.
Vector
A list of numbers that you can think of as an arrow from the origin. Precise definition: an ordered list (x1, ..., xn) of real numbers.
Component (or entry)
One number in a vector or a matrix. The value xi sits in position i.
Matrix
A rectangle of numbers in rows and columns. An m x n matrix has m rows and n columns.
Row and column
A row runs left to right; a column runs top to bottom.
Size
Rows first, then columns. A 4 x 2 matrix has 4 rows and 2 columns.
Square matrix
A matrix with the same number of rows and columns.
Identity matrix (I)
A square matrix with 1 on the main diagonal and 0 everywhere else. The "do nothing" matrix.
Zero matrix
A matrix with every entry equal to 0.
Linear combination
A mix of vectors made by scaling each one and adding the results.
Matrix product AB
Entry (i, j) is row i of A times column j of B, multiplied entry by entry and added.
Linear transformation
A move that keeps grid lines straight and evenly spaced. A matrix is one way to write it.
Determinant (det)
A number linked to a square matrix that says how much it scales areas. For 2 x 2, det [[a, b], [c, d]] = ad - bc.

Vectors: an arrow and a list of numbers

The vector (2, 1) is a movement: 2 steps right and 1 step up. It starts at the origin and ends at the point (2, 1). We can write it as a column with the entries stacked:

[ 2 ]
[ 1 ]

Adding vectors

Add entry by entry. In the picture, you place the tail of the second arrow at the tip of the first, and the sum is the arrow from the start to the final tip.

(u1, u2) + (v1, v2) = (u1 + v1, u2 + v2)

With u = (2, 1) and v = (1, 2): the first entries give 2 + 1 = 3, the second give 1 + 2 = 3, so u + v = (3, 3).

Scaling a vector

Scaling multiplies every entry by the same number c, so c(u1, u2) = (c u1, c u2). With u = (2, 1): 2u = (4, 2), which is twice as long and points the same way. -u = (-2, -1) points the opposite way. Subtraction works the same way: u - v = (2 - 1, 1 - 2) = (1, -1).

The picture shows u and v and their sum u + v. Drag the tip of v and watch the sum move with it. Notice that u + v always lands at the corner of the shape that u and v make together.

TrapYou can only add vectors with the same number of entries. Adding (1, 2) to (3, 4, 5) is not allowed.

If u = (3, -1) and v = (1, 4), what is u + v?

Add entry by entry: 3 + 1 = 4 and -1 + 4 = 3. So u + v = (4, 3).

What is 2u when u = (3, -1)?

Multiply each entry by 2: (6, -2).

Matrices: a table of numbers with a name

Here is a 2 x 3 matrix, with two rows and three columns:

A = [ 2   1   0 ]
    [ -1  3   4 ]

The first row is (2, 1, 0). The first column is (2, -1). Each entry has an address: aij is in row i and column j. So a12 = 1 and a23 = 4. Think of it like a cinema seat: row first, then seat.

TipAlways say rows first. A matrix with 4 rows and 2 columns is 4 x 2, even though it looks tall and thin.

Adding and scaling matrices

  • Addition needs the same size. Add the entries in the same position.
  • Scaling multiplies every entry by the scalar.

With A = [[1, 2], [3, 4]] and B = [[0, 1], [1, 0]]: A + B = [[1, 3], [4, 4]] and 3A = [[3, 6], [9, 12]]. The Python block runs the same arithmetic.

A = [[1, 2], [3, 4]]
B = [[0, 1], [1, 0]]
add = [[A[i][j] + B[i][j] for j in range(2)] for i in range(2)]
times3 = [[3 * A[i][j] for j in range(2)] for i in range(2)]
print("A + B =", add)
print("3A =", times3)
A + B = [[1, 3], [4, 4]]
3A = [[3, 6], [9, 12]]

TrapA 2 x 3 matrix and a 3 x 2 matrix cannot be added, even though both have six entries. The sizes must match exactly.

The identity matrix I, shown below for size 2, is the "do nothing" matrix for products.

I = [ 1  0 ]
    [ 0  1 ]
What is the size of a matrix with 5 rows and 2 columns?

It is 5 x 2. Rows first, then columns.

In the matrix A above, what is a21?

Row 2, column 1. Row 2 is (-1, 3, 4), so a21 = -1.

Matrix times vector: a mix of columns

The most important product is a matrix times a vector. The matrix is the machine, the vector is the input, and the output is Ax. GATE often asks you to solve Ax = b, which means: which input x gives output b?

Method 1: row by row

(Ax)i = ai1x1 + ai2x2 + ... + ainxn

Take A = [[2, 1], [1, 3]] and x = (1, 2). Row 1 gives 2 x 1 + 1 x 2 = 4. Row 2 gives 1 x 1 + 3 x 2 = 7. So Ax = (4, 7).

Method 2: a weighted mix of columns

The columns of A are c1 = (2, 1) and c2 = (1, 3). The entries of x are the amounts to take of each column.

Ax = x1c1 + x2c2 = 1 (2, 1) + 2 (1, 3) = (2, 1) + (2, 6) = (4, 7)

Both methods agree. The column method is the one to remember: Ax is a mix of the columns of A, with the entries of x as the amounts.

Key ideaThe number of columns of A must equal the number of entries of x. A 3 x 2 matrix times a vector with 2 entries gives a vector with 3 entries.

A = [[2, 1], [1, 3]]
x = [1, 2]
row_method = [sum(A[i][j] * x[j] for j in range(2)) for i in range(2)]
col_method = [0, 0]
for j in range(2):
    for i in range(2):
        col_method[i] += x[j] * A[i][j]
print("row method:", row_method)
print("column method:", col_method)
row method: [4, 7]
column method: [4, 7]

TrapLine up each vector entry with its matrix entry before multiplying. Most errors come from pairs that do not match.

What is Ax for A = [[1, 0], [0, 2]] and x = (3, 4)?

Row method: (1 x 3 + 0 x 4, 0 x 3 + 2 x 4) = (3, 8). Column method: 3 (1, 0) + 4 (0, 2) = (3, 8). Same answer.

Why can a 2 x 3 matrix not multiply a vector with 2 entries?

The matrix has 3 columns, so it needs a vector with 3 entries.

Matrix times matrix: one move after another

A product AB is the single matrix that does "first B, then A". To find entry (i, j), take row i of A and column j of B, multiply matching entries, and add.

(AB)ij = ai1b1j + ai2b2j + ... + ainbnj

The sizes must fit. If A is m x n and B is n x p, then AB is m x p. The middle numbers must match.

Take A = [[1, 2], [0, 1]] and B = [[0, 1], [1, 0]]. Entry (1,1): row (1, 2) times column (0, 1) gives 0 + 2 = 2. Entry (1,2): (1, 2) times (1, 0) gives 1. Entry (2,1): (0, 1) times (0, 1) gives 1. Entry (2,2): (0, 1) times (1, 0) gives 0. So AB = [[2, 1], [1, 0]]. Reversing the order gives BA = [[0, 1], [1, 2]].

Key ideaOrder matters: AB is usually not equal to BA. In (AB)x = A(Bx), the matrix B acts on x first.

def matmul(X, Y):
    n, k, m = len(X), len(Y), len(Y[0])
    return [[sum(X[i][t] * Y[t][j] for t in range(k)) for j in range(m)] for i in range(n)]

A = [[1, 2], [0, 1]]
B = [[0, 1], [1, 0]]
print("AB =", matmul(A, B))
print("BA =", matmul(B, A))
AB = [[2, 1], [1, 0]]
BA = [[0, 1], [1, 2]]

The shear A = [[1, 2], [0, 1]] keeps horizontal lines fixed and leans the vertical ones. Drag the column arrows and watch the grid lean. The area of the square does not change, a hint that the determinant is 1.

TrapNever assume AB = BA. Also, multiplying matrices is not done entry by entry. That is a different operation, not the matrix product.

What is the size of AB if A is 3 x 2 and B is 2 x 4?

The middle numbers match (2 and 2). The outside numbers give 3 x 4.

Does AI = A hold for every square matrix A of the same size?

Yes. Multiplying by the identity leaves every entry as it was.

A 2 by 2 matrix as a machine that bends the plane

Take the two basic arrows: e1 = (1, 0), pointing right, and e2 = (0, 1), pointing up. For [[a, b], [c, d]], the first column (a, c) is where e1 lands, and the second column (b, d) is where e2 lands. Because the rule is straight-line, the whole grid is then known.

Four basic moves

  • Stretch: [[2, 0], [0, 1]] doubles widths and keeps heights.
  • Rotation by 90 degrees: [[0, -1], [1, 0]] turns the plane a quarter turn anticlockwise. e1 goes to (0, 1).
  • Shear: [[1, 1], [0, 1]] slides the top sideways and keeps the horizontal line fixed.
  • Flip: [[1, 0], [0, -1]] turns the picture upside down across the horizontal line.

Drag the column arrows of the rotation and notice that the square keeps its shape, it only turns.

The symmetric matrix [[2, 1], [1, 2]] is next. Drag each column and see how the unit square becomes a tilted parallelogram.

The determinant measures area change

det [[a, b], [c, d]] = ad - bc

Here a and d are the diagonal entries and b and c are the off-diagonal entries. For [[2, 1], [1, 2]], det = 2 x 2 - 1 x 1 = 3, so the unit square becomes a parallelogram of area 3. The stretch has det 2, the rotation det 1, the shear det 1 (area kept), and the flip det -1. The sign records a flip, but the size of the determinant is the area scale.

def det2(M):
    return M[0][0] * M[1][1] - M[0][1] * M[1][0]

print("stretch:", det2([[2, 0], [0, 1]]))
print("rotation:", det2([[0, -1], [1, 0]]))
print("shear:", det2([[1, 1], [0, 1]]))
print("flip:", det2([[1, 0], [0, -1]]))
print("symmetric:", det2([[2, 1], [1, 2]]))
stretch: 2
rotation: 1
shear: 1
flip: -1
symmetric: 3

TrapA negative determinant does not mean negative area. It means the picture is flipped, and the area is scaled by the size of the determinant.

What is the determinant of [[3, 0], [0, 3]]?

ad - bc = 9. Every area is multiplied by 9.

What does a determinant of 0 tell you?

The matrix squashes the plane onto a line or a point, so all the area disappears. Such a matrix is called singular.

Real past GATE questions

GATE CSE 2016 Set 2 (verified PYQ)

Let A1, A2, A3 and A4 be four matrices with dimensions 10 x 5, 5 x 20, 20 x 10 and 10 x 5. The product A1 A2 A3 A4 can be computed in several orders. Using basic multiplication, find the minimum number of scalar multiplications needed to compute the product. Give a single number.

How to think about it

  1. What is asked. The fewest scalar multiplications over all ways to group the product.
  2. Which idea applies. Multiplying an m x n matrix by an n x p matrix costs m x n x p scalar multiplications. The grouping changes the middle sizes, so it changes the total cost.
  3. Work it out. Group as ((A1 A2) A3) A4. The costs are 10 x 5 x 20 = 1000, then 10 x 20 x 10 = 2000, then 10 x 10 x 5 = 500, total 3500. Group as A1 ((A2 A3) A4). The costs are 5 x 20 x 10 = 1000, then 5 x 10 x 5 = 250, then 10 x 5 x 5 = 250, total 1500. The second grouping is cheaper, and the Python block below checks all five groupings.
  4. Check. The answer 1500 is the smallest of the five totals, so no other grouping can beat it.

Answer: 1500.

from functools import lru_cache
dims = [10, 5, 20, 10, 5]
@lru_cache(maxsize=None)
def best(i, j):
    if i == j:
        return 0
    return min(best(i, k) + best(k + 1, j) + dims[i] * dims[k + 1] * dims[j + 1] for k in range(i, j))
print(best(0, 3))
1500

Source (also discussed on GATE Overflow)

Exam-level practice

Exam-level 1: two moves in a row (NAT, 2 marks)

A small drone is steered by two matrices. Let A = [[1, 2, 0], [0, 1, 3]] and B = [[2, 0], [1, 1], [0, 4]]. A command first applies B to a position, and then A is applied to the result. Let C = AB, so one matrix does both moves together. Let x = (1, -1) be a position. Find the first entry of the vector Cx. Give a single number.

How to think about it

  1. What is asked. One number, the first entry of Cx.
  2. Which idea applies. First combine the two matrices into C = AB (row times column), then apply C to x (row times vector).
  3. Work it out. Row 1 of A is (1, 2, 0). Column 1 of B is (2, 1, 0), giving 1 x 2 + 2 x 1 + 0 = 4. Column 2 of B is (0, 1, 4), giving 0 + 2 + 0 = 2. Row 2 of A is (0, 1, 3). With column 1 it gives 0 + 1 + 0 = 1, and with column 2 it gives 0 + 1 + 12 = 13. So C = [[4, 2], [1, 13]]. Then the first entry of Cx is 4 x 1 + 2 x (-1) = 2.
  4. Check. The shape is right: a 2 x 3 times a 3 x 2 gives 2 x 2, and a 2 x 2 times a 2 x 1 gives 2 x 1. The Python block confirms C and the entry.

Answer: 2.

def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]
def mv(A, v):
    return [sum(A[i][k] * v[k] for k in range(len(v))) for i in range(len(A))]
A = [[1, 2, 0], [0, 1, 3]]
B = [[2, 0], [1, 1], [0, 4]]
C = mul(A, B)
print("C =", C)
print("first entry of Cx =", mv(C, [1, -1])[0])
C = [[4, 2], [1, 13]]
first entry of Cx = 2

Exam-level 2: which orders agree? (MSQ, 2 marks)

Let P = [[1, 0], [2, 1]] and Q = [[1, 3], [0, 1]]. Let v = (1, 1). Consider the statements (A) PQ = [[1, 3], [2, 7]], (B) QP = [[7, 3], [2, 1]], (C) PQ = QP, and (D) P(Qv) = (PQ)v. Select all statements that are true.

How to think about it

  1. What is asked. Which of the four statements are true.
  2. Which idea applies. Matrix products are not always commutative, but they are always associative, so applying one matrix after another to a vector gives the same answer as applying their product.
  3. Work it out. PQ: row 1 (1, 0) with columns (1, 0) and (3, 1) gives 1 and 3. Row 2 (2, 1) gives 2 and 7. So (A) is true. QP: row 1 (1, 3) with columns (1, 2) and (0, 1) gives 7 and 3. Row 2 (0, 1) gives 2 and 1. So (B) is true. Since QP is not PQ, (C) is false. For (D), Qv = (4, 1) and P(4, 1) = (4, 9). Also (PQ)v = (1 + 3, 2 + 7) = (4, 9). So (D) is true.
  4. Check. Trap (C): many students assume the order does not matter, but it does here. Only (A), (B) and (D) are true, and each of those was checked by computing both sides.

Answer: (A), (B) and (D).

def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]
def mv(A, v):
    return [sum(A[i][k] * v[k] for k in range(len(v))) for i in range(len(A))]
P = [[1, 0], [2, 1]]
Q = [[1, 3], [0, 1]]
v = [1, 1]
print("PQ =", mul(P, Q))
print("QP =", mul(Q, P))
print("P(Qv) =", mv(P, mv(Q, v)), " (PQ)v =", mv(mul(P, Q), v))
PQ = [[1, 3], [2, 7]]
QP = [[7, 3], [2, 1]]
P(Qv) = [4, 9]  (PQ)v = [4, 9]

Exam-level 3: the cost of two orders (NAT, 2 marks)

Three data matrices are multiplied in a pipeline. A is 6 x 4, B is 4 x 5 and C is 5 x 2. Using basic multiplication, one scalar multiplication counts as one unit of work. Let S1 be the work needed to compute (AB) C, and let S2 be the work needed to compute A (BC). Find S1 minus S2. Give a single number.

How to think about it

  1. What is asked. The difference between two totals of scalar multiplications.
  2. Which idea applies. An m x n times n x p product costs m x n x p scalar multiplications, and the grouping decides which products appear.
  3. Work it out. For (AB) C: AB costs 6 x 4 x 5 = 120, leaving a 6 x 5 matrix. That times C costs 6 x 5 x 2 = 60. So S1 = 180. For A (BC): BC costs 4 x 5 x 2 = 40, leaving a 4 x 2 matrix. A times that costs 6 x 4 x 2 = 48. So S2 = 88. Then S1 minus S2 = 180 - 88 = 92.
  4. Check. Both groupings give a 6 x 2 result, so the comparison is fair. The Python block recomputes both totals.

Answer: 92.

S1 = 6*4*5 + 6*5*2
S2 = 4*5*2 + 6*4*2
print("S1 =", S1, " S2 =", S2, " S1 - S2 =", S1 - S2)
S1 = 180  S2 = 88  S1 - S2 = 92

Exam-level 4: a turning arm with a boost (NAT, 2 marks)

A robot arm turns a point by 90 degrees anticlockwise using R = [[0, -1], [1, 0]]. After three turns, the arm also adds twice the point itself, which is the matrix 2I = [[2, 0], [0, 2]]. Let M = R^3 + 2I. The point is then (3, 4). Find the first entry of M times (3, 4). Give a single number.

How to think about it

  1. What is asked. The first entry of M (3, 4).
  2. Which idea applies. Powers of a matrix are repeated products, and the identity matrix I has ones on the diagonal and zeros elsewhere.
  3. Work it out. R^2 = [[0, -1], [1, 0]] times itself gives [[-1, 0], [0, -1]], which is -I. So R^3 = -I times R = -R = [[0, 1], [-1, 0]]. Then M = R^3 + 2I = [[2, 1], [-1, 2]]. Multiply by (3, 4): the first entry is 2 x 3 + 1 x 4 = 10. The second entry is -1 x 3 + 2 x 4 = 5.
  4. Check. A quarter turn applied three times equals a three quarter turn, which is a clockwise quarter turn, so R^3 = -R is right. The Python block recomputes everything.

Answer: 10.

def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]
R = [[0, -1], [1, 0]]
R3 = mul(mul(R, R), R)
M = [[R3[i][j] + (2 if i == j else 0) for j in range(2)] for i in range(2)]
print("M =", M)
print("first entry of M(3,4) =", M[0][0]*3 + M[0][1]*4)
M = [[2, 1], [-1, 2]]
first entry of M(3,4) = 10

Exam-level 5: which squares and products vanish? (MSQ, 2 marks)

Two students multiply matrices by hand to test a quick idea. Let A = [[1, 1], [1, 1]] and B = [[1, -1], [-1, 1]]. Consider the statements (A) AB is the zero matrix, (B) BA is the zero matrix, (C) A^2 = 2A, and (D) B^2 = B. Select all statements that are true.

How to think about it

  1. What is asked. Which of the four statements hold.
  2. Which idea applies. Multiply row by column. Two nonzero matrices can multiply to zero, and a matrix can be a multiple of itself when squared.
  3. Work it out. AB: each entry is row times column, for example 1 x 1 + 1 x (-1) = 0, and every entry is 0. So (A) is true. BA also has all entries 0, so (B) is true. A^2: the entries are 2 everywhere, which is 2A, so (C) is true. B^2: the entries are 1 + 1 = 2 on the diagonal and -2 off it, which is 2B and not B. So (D) is false.
  4. Check. Trap (D): B^2 = B would need a matrix to equal its own square, but B^2 = 2B. Statement (B) is true too, so a product can be zero in both orders here, which the trap in (D) does not change.

Answer: (A), (B) and (C).

def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]
A = [[1, 1], [1, 1]]
B = [[1, -1], [-1, 1]]
print("AB =", mul(A, B))
print("BA =", mul(B, A))
print("A^2 =", mul(A, A), " 2A =", [[2 * x for x in row] for row in A])
print("B^2 =", mul(B, B), " B =", B)
AB = [[0, 0], [0, 0]]
BA = [[0, 0], [0, 0]]
A^2 = [[2, 2], [2, 2]]  2A = [[2, 2], [2, 2]]
B^2 = [[2, -2], [-2, 2]]  B = [[1, -1], [-1, 1]]

Summary

Vector
A list of numbers that is also an arrow from the origin.
Scalar
A plain number used to scale a vector or a matrix.
Matrix
A rectangle of numbers in rows and columns.
Size m x n
m rows and n columns. Rows are always counted first.
Entry aij
The number in row i and column j.
Matrix addition
Only for matrices of the same size, position by position.
Scaling
Multiply every entry by the same scalar.
Ax, row method
Each entry is a row of A multiplied with x and added.
Ax, column method
Ax is a mix of the columns of A, with the entries of x as amounts.
Matrix product AB
Entry (i, j) is row i of A times column j of B.
Defined product
AB exists when the columns of A equal the rows of B in number.
Commute
Matrix products usually do not commute.
Identity matrix I
1s on the diagonal and 0s elsewhere, with AI = IA = A.
Zero matrix
All entries 0.
Linear transformation
A straight-line rule that moves vectors and keeps grid lines straight.
Determinant of 2 x 2
ad - bc, the factor by which areas are scaled.
Negative determinant
The picture is flipped, and the area is scaled by the size of the determinant.
Shear
A move that slides the top of the picture sideways and keeps one line fixed.
Rotation
A turn of the plane about the origin, which keeps areas.

Remember these

  1. Ax is a mix of the columns of A, with the entries of x as the amounts.
  2. Check the sizes before multiplying: the middle numbers must match.
  3. AB is usually not equal to BA, so always keep the order.
  4. The identity matrix leaves every matrix and vector unchanged.
  5. For a 2 x 2 matrix, the determinant is ad - bc, and its size tells you the area scale.
  6. The columns of a 2 x 2 matrix show where the two basic arrows land.
