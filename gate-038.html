Cumulative Distribution Function (CDF)

The cumulative distribution function (CDF) answers the question 'what is the chance that X is at most x?' for discrete and continuous variables alike. It is the one tool that works for every random variable, and GATE uses it constantly for interval probabilities.

The idea in plain words

So far you have met two different tools. For a discrete variable you use the probability mass function (PMF), which gives the chance of each exact value. For a continuous variable you use the probability density function (PDF), whose area gives the chance of an interval. Two different tools for two different kinds of variable can feel like a lot to remember.

The cumulative distribution function, or CDF, is a single tool that works for both. It asks one question: what is the chance that X is at most x? Write this as F(x). Once you know F, you can find almost any probability you need.

Think of a water tank being filled from the bottom. At height x, the CDF tells you how much of the total water is below that level. At the very bottom, the amount is zero. At the very top, the tank is full, so the amount is 1. As the water level rises, the amount never goes down. That picture captures every property of a CDF.

Why does this matter for GATE? The Data Science and AI (DA) paper uses CDFs in the probability and statistics section, and CDF based questions often appear as numerical answer type (NAT) problems. The Robotics and Automation (RA) paper uses them for reliability, where F(t) is the chance that a component has failed by time t. Learning to read a CDF is one of the most useful skills in this unit.

Key terms

Read these first. Each term is given in plain words and then in precise form.

CDF F(x)
Plain meaning: the chance that X is at most x. Precise definition: F(x) = P(X ≤ x), defined for every real number x.
Non-decreasing
Plain meaning: the graph never goes down. Precise definition: if a ≤ b, then F(a) ≤ F(b).
Limit
Plain meaning: the value the function settles to as x goes far off. Precise definition: F(x) approaches 0 as x goes to minus infinity, and approaches 1 as x goes to plus infinity.
Right-continuous
Plain meaning: at a jump, the CDF takes the higher value, including the jump point. Precise definition: F(x) = lim as t approaches x from above of F(t).
Staircase
Plain meaning: the graph of a discrete CDF, which jumps up at each possible value. Precise definition: a step function whose jumps equal the PMF values.
Interval probability
Plain meaning: the chance that X lies between two numbers. Precise definition: P(a < X ≤ b) = F(b) - F(a).
Survival function
Plain meaning: the chance that X is still above x. Precise definition: P(X > x) = 1 - F(x).
Median
Plain meaning: the middle value, with half the probability below it. Precise definition: a value m with F(m) = 1/2 for a continuous variable, or the smallest m with F(m) ≥ 1/2 in general.
Standard normal CDF Φ(z)
Plain meaning: the CDF of the standard normal variable. Precise definition: Φ(z) = P(Z ≤ z), where Z has mean 0 and variance 1.

Concept 1: The CDF and its properties

The definition

F(x) = P(X ≤ x)

Each symbol means:

  • x is any real number we choose. It is not necessarily a value X can take.
  • X ≤ x is the event that the random variable is at most x.
  • F(x) is the probability of that event. It is always between 0 and 1.

The CDF is defined for every x, not only for the values in the support. This is the main difference from the PMF, which is only useful at the values X can take.

The four properties

Every valid CDF has these properties. Use them to check a formula or a table.

  1. Limits. F(x) approaches 0 as x becomes very negative, and approaches 1 as x becomes very large.
  2. Non-decreasing. If a ≤ b, then F(a) ≤ F(b). The graph never goes down, because adding more values to "X ≤ x" can only add probability.
  3. Right-continuous. At a jump, the CDF takes the upper value at the jump point. For a discrete variable, F(2) includes the probability at 2.
  4. Values in [0, 1]. Every F(x) is a probability, so it lies between 0 and 1.

Worked example: checking a table

A discrete variable has CDF values F(0) = 0.2, F(1) = 0.5, F(2) = 0.9 and F(3) = 1, with F(x) = 0 for x less than 0.

  1. Limits. The value for x below 0 is 0, and the value at 3 and above is 1. Both hold.
  2. Non-decreasing. The sequence 0, 0.2, 0.5, 0.9, 1 never goes down. This holds.
  3. Values in [0, 1]. Every entry is between 0 and 1. This holds.
  4. Conclusion. The table is a valid CDF. The probabilities of the individual values are the jumps: P(X = 0) = 0.2, P(X = 1) = 0.3, P(X = 2) = 0.4 and P(X = 3) = 0.1.

Key ideaA CDF can never go down and always ends at 1. If a table or a formula breaks either rule, it cannot be a CDF.

TrapThe CDF is not a PMF or a PDF. A CDF value is a probability, so it cannot be negative and cannot exceed 1. A PDF value can exceed 1, and a PMF value is a probability of one value only.

Self-check: can F(x) = 1 - x for x in [0, 1] be a CDF?

No. It falls from 1 to 0 as x increases, so it is decreasing. A CDF must be non-decreasing.

Self-check: what is F(x) for a very large x, for any random variable?

It is 1, because X will be at most a very large number almost surely.

Concept 2: CDF from the PMF and the PDF

Discrete: add up the PMF

For a discrete variable, the CDF is the running total of the PMF:

F(x) = Σ P(X = t), summed over all t ≤ x

Each symbol means: we add up the probabilities of every value t that is at most x. The result is a staircase. Each jump is a PMF value.

Continuous: integrate the PDF

For a continuous variable, the running total becomes an integral of the PDF:

F(x) = ∫ from minus infinity to x of f(t) dt

Each symbol means: we add up the area under the density from the far left up to x. The variable t is a dummy name for the position we integrate over, and x is the upper limit.

Going the other way is also possible. For a continuous variable, the PDF is the derivative of the CDF, f(x) = F'(x). This is why the CDF is the more fundamental object.

Worked example: from a density to a CDF

Let f(t) = 2t on [0, 1], and 0 otherwise. Find F(x) for 0 ≤ x ≤ 1.

  1. For x below 0, no area lies to the left, so F(x) = 0.
  2. For 0 ≤ x ≤ 1, integrate from 0 to x: F(x) = ∫ from 0 to x of 2t dt = [t²] from 0 to x = x².
  3. For x above 1, all the area has been counted, so F(x) = 1.
  4. Check. F(0) = 0, F(1) = 1, and x² never decreases on [0, 1]. The formula is valid.

TipFor continuous problems, split the number line into pieces where the PDF has a single formula. Write F(x) separately on each piece, then check that the pieces join without a gap.

TrapWhen you integrate the PDF to get the CDF, the upper limit is x, not 1. Students often write the answer in terms of the wrong variable or forget the lower region below 0.

Self-check: a discrete PMF has P(X = 0) = 0.3 and P(X = 1) = 0.7. What is F(0)?

F(0) = P(X ≤ 0) = P(X = 0) = 0.3.

Self-check: for f(t) = 1 on [0, 1], what is F(0.4)?

F(0.4) = ∫ from 0 to 0.4 of 1 dt = 0.4.

Concept 3: Interval probabilities using the CDF

Why this is the main use

Most CDF questions in GATE ask about an interval. "What is the chance that the delay is between 2 and 5 minutes?" The CDF answers this with one subtraction. You do not need to add a PMF table or integrate a PDF again.

The rule

P(a < X ≤ b) = F(b) - F(a)

Each symbol means:

  • F(b) is the chance of being at most b.
  • F(a) is the chance of being at most a. Subtracting removes everything up to and including a.
  • What remains is the chance of being above a and at most b.

The endpoints matter for discrete variables. The left endpoint a is excluded and the right endpoint b is included. For a continuous variable, the endpoints do not matter, so P(a < X ≤ b) = P(a ≤ X ≤ b).

Worked example: a discrete table

Using the table from Concept 1, with F(0) = 0.2, F(1) = 0.5, F(2) = 0.9 and F(3) = 1, find P(0 < X ≤ 2).

  1. Write the rule. P(0 < X ≤ 2) = F(2) - F(0).
  2. Substitute. F(2) = 0.9 and F(0) = 0.2.
  3. Subtract. 0.9 - 0.2 = 0.7.
  4. Check by adding the PMF values for X = 1 and X = 2. P(X = 1) + P(X = 2) = 0.3 + 0.4 = 0.7. Both methods agree.

Worked example: a tail probability

Using the same table, find P(X > 1). The complement rule gives P(X > 1) = 1 - F(1) = 1 - 0.5 = 0.5. This is the survival function at 1.

F_table = {-1: 0.0, 0: 0.2, 1: 0.5, 2: 0.9, 3: 1.0}

print("P(0 < X <= 2) =", round(F_table[2] - F_table[0], 4))
print("P(X > 1) =", round(1 - F_table[1], 4))
P(0 < X <= 2) = 0.7
P(X > 1) = 0.5

GATE loves thisWhen a question asks for "more than" a value, use 1 minus the CDF. This is one of the fastest routes in the whole topic, and it avoids summing a long PMF.

TrapFor a discrete variable, P(X < 2) and P(X ≤ 2) are different. P(X < 2) = F(1) because the value 2 is excluded. Read the inequality carefully before you pick the CDF value.

Self-check: F(4) = 0.8 and F(2) = 0.3. What is P(2 < X ≤ 4)?

P(2 < X ≤ 4) = F(4) - F(2) = 0.8 - 0.3 = 0.5.

Self-check: if F(5) = 0.65, what is P(X > 5)?

P(X > 5) = 1 - F(5) = 1 - 0.65 = 0.35.

Concept 4: CDFs of standard distributions

Uniform

For a continuous uniform on [a, b], the CDF rises in a straight line:

F(x) = 0 for x < a, F(x) = (x - a)/(b - a) for a ≤ x ≤ b, and F(x) = 1 for x > b

Each piece has a clear meaning. Left of a, nothing has happened yet. Between a and b, the fraction of the interval covered so far is (x - a)/(b - a). Right of b, the whole interval is covered.

Exponential

For an exponential variable with rate λ, the CDF is:

F(x) = 1 - e-λx for x ≥ 0, and F(x) = 0 for x < 0

This is the complement of the tail formula from the exponential topic: F(x) = 1 - P(X > x). It rises quickly at first and then flattens towards 1.

Normal

The normal CDF has no simple closed formula. We write it as Φ(z) for the standard normal, where Z has mean 0 and variance 1. Its values are found from tables or software. The next topic covers the normal distribution in full. Here you need only the idea that the CDF is still the chance of being at most z.

The Python block below uses the error function from the standard library to compute Φ, and then evaluates an interval.

import math

def Phi(z):
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))

print(f"Phi(1) = {Phi(1):.4f}")
print(f"Phi(-1) = {Phi(-1):.4f}")
print(f"P(-1 < Z <= 1) = {Phi(1) - Phi(-1):.4f}")
Phi(1) = 0.8413
Phi(-1) = 0.1587
P(-1 < Z <= 1) = 0.6827

Worked example: an exponential interval

Let X be exponential with λ = 0.5. Find P(1 < X ≤ 3).

  1. Write the rule. P(1 < X ≤ 3) = F(3) - F(1).
  2. Compute F(3) = 1 - e-1.5 ≈ 1 - 0.2231 = 0.7769.
  3. Compute F(1) = 1 - e-0.5 ≈ 1 - 0.6065 = 0.3935.
  4. Subtract. 0.7769 - 0.3935 = 0.3834.
  5. Check. The tail P(X > 1) is e-0.5 = 0.6065, and P(X > 3) is 0.2231. Their difference is 0.6065 - 0.2231 = 0.3834, which agrees.

Key ideaEvery standard CDF is built from the same two facts: it starts at 0, it ends at 1, and it never goes down. Learn the shape, and the formula follows.

TrapThe uniform CDF is a straight line only between a and b. Outside that range it is flat at 0 or at 1. Forgetting the flat parts gives wrong values for points outside the interval.

Self-check: X is uniform on [2, 6]. What is F(4)?

F(4) = (4 - 2)/(6 - 2) = 2/4 = 0.5.

Self-check: the median of a continuous variable satisfies which equation?

F(m) = 1/2. The median is the point where half the probability lies below it.

Solved GATE-style problems

These problems are original GATE-style questions written for practice. They are not past paper questions. Work each one on paper first, then compare with the solution.

Uniform CDF value

X is uniform on the interval [0, 4]. Find F(3), where F is the CDF of X. Give the answer as a decimal.

How to think about it

  1. What is asked. The chance that X is at most 3.
  2. Which idea applies. The uniform CDF (x - a)/(b - a) with a = 0 and b = 4.
  3. Work it out. F(3) = (3 - 0)/(4 - 0) = 3/4 = 0.75.
  4. Check. 3 lies inside [0, 4], and it is three quarters of the way along, so 0.75 is right.

Answer: 0.75

Select all true statements about a discrete CDF

A discrete variable X has F(0) = 0.1, F(1) = 0.4, F(2) = 0.9 and F(3) = 1. Select all that apply.

(A) P(X = 2) = 0.5.
(B) P(X ≤ 1) = 0.4.
(C) P(1 < X ≤ 3) = 0.6.
(D) P(X = 0) = 0.4.

How to think about it

  1. What is asked. Tick each true statement about this CDF.
  2. Which idea applies. Each single-value probability is a jump, and interval probabilities are differences.
  3. Work it out. Option A: P(X = 2) = F(2) - F(1) = 0.9 - 0.4 = 0.5, so A is true. Option B: P(X ≤ 1) = F(1) = 0.4, so B is true. Option C: P(1 < X ≤ 3) = F(3) - F(1) = 1 - 0.4 = 0.6, so C is true. Option D: P(X = 0) = F(0) = 0.1, not 0.4, so D is false.
  4. Check. The jumps must add to 1: 0.1 + 0.3 + 0.5 + 0.1 = 1. This confirms the values used above.

Answer: (A), (B) and (C) are true. Option (D) is false.

Interval from a PMF table

A discrete variable X takes the values 1, 2, 3 and 4 with probabilities 0.1, 0.2, 0.3 and 0.4. Find F(3) and P(2 < X ≤ 4). Give P(2 < X ≤ 4) as a decimal.

How to think about it

  1. What is asked. The CDF at 3, and an interval probability.
  2. Which idea applies. The CDF is the running total of the PMF. The interval is F(4) - F(2).
  3. Work it out. F(3) = 0.1 + 0.2 + 0.3 = 0.6. F(2) = 0.1 + 0.2 = 0.3. F(4) = 1. So P(2 < X ≤ 4) = 1 - 0.3 = 0.7.
  4. Check. Directly, P(X = 3) + P(X = 4) = 0.3 + 0.4 = 0.7. This matches.

Answer: F(3) = 0.6 and P(2 < X ≤ 4) = 0.7

From a CDF to a density and a tail

A continuous variable has CDF F(x) = x²/4 for 0 ≤ x ≤ 2, F(x) = 0 for x < 0 and F(x) = 1 for x > 2. Find P(X > 1) as a fraction.

How to think about it

  1. What is asked. The tail probability above 1.
  2. Which idea applies. The survival function P(X > 1) = 1 - F(1).
  3. Work it out. F(1) = 1²/4 = 1/4. So P(X > 1) = 1 - 1/4 = 3/4.
  4. Check. The density is f(x) = x/2 on [0, 2], which is larger on the right, so more than half the probability should lie above 1. The answer 3/4 is more than one half, which agrees.

Answer: 3/4

Median waiting time

NAT question. A waiting time X is exponential with rate 0.1 per minute. Find the median waiting time in minutes, correct to two decimal places.

How to think about it

  1. What is asked. The value m with F(m) = 1/2.
  2. Which idea applies. The exponential CDF F(x) = 1 - e-λx, set equal to 1/2.
  3. Work it out. 1 - e-0.1m = 1/2, so e-0.1m = 1/2. Take natural logs: -0.1m = ln(1/2) = -ln 2. So m = ln 2 / 0.1 = 0.6931 / 0.1 = 6.931, which is 6.93 to two decimals.
  4. Check. The mean is 1/0.1 = 10 minutes. The median of an exponential is below its mean, and 6.93 is below 10, which agrees.

Answer: 6.93

Interval across a change in formula

A continuous variable has CDF F(x) = 0 for x < 0, F(x) = 0.5x for 0 ≤ x < 1, F(x) = 0.5 + 0.25(x - 1) for 1 ≤ x < 3, and F(x) = 1 for x ≥ 3. Find P(0.5 < X ≤ 2). Give the answer as a decimal.

How to think about it

  1. What is asked. An interval probability for a CDF with two pieces.
  2. Which idea applies. P(0.5 < X ≤ 2) = F(2) - F(0.5), with each value taken from the correct piece.
  3. Work it out. F(0.5) lies in the first piece, so F(0.5) = 0.5 × 0.5 = 0.25. F(2) lies in the second piece, so F(2) = 0.5 + 0.25 × (2 - 1) = 0.75. Then P(0.5 < X ≤ 2) = 0.75 - 0.25 = 0.5.
  4. Check. The two pieces join correctly at x = 1: the first gives 0.5 and the second gives 0.5 + 0 = 0.5. Also F(3) = 0.5 + 0.5 = 1, which matches the last piece.

Answer: 0.5

A probability with a jump

NAT question. A discrete variable X has F(1) = 0.3, F(2) = 0.8 and F(3) = 1. Find P(X ≥ 2). Give the answer as a decimal.

How to think about it

  1. What is asked. The chance that X is at least 2, which includes the value 2.
  2. Which idea applies. The complement of "X ≥ 2" is "X < 2", which is "X ≤ 1" for integer values, so P(X ≥ 2) = 1 - F(1).
  3. Work it out. P(X ≥ 2) = 1 - P(X ≤ 1) = 1 - F(1) = 1 - 0.3 = 0.7.
  4. Check. The direct sum P(X = 2) + P(X = 3) = (0.8 - 0.3) + (1 - 0.8) = 0.5 + 0.2 = 0.7. This agrees. Using 1 - F(2) = 0.2 would be wrong, because it leaves out the value 2.

Answer: 0.7

Exam-level 1: Finding a percentile from a CDF (NAT, 2 marks)

NAT question. The distance X, in kilometres, that a delivery van travels before a breakdown has the cumulative distribution function F(x) = P(X ≤ x). It is given by F(x) = 0 for x less than 0, F(x) = x²/16 for 0 ≤ x ≤ 4, and F(x) = 1 for x greater than 4. Find the value x such that P(X ≤ x) = 0.75, which is the 75th percentile of X. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. The value x with F(x) = 0.75, to two decimal places.
  2. Which idea applies. On the interval from 0 to 4 the CDF is x²/16, so solve the equation for x. Then check that the answer lies in that interval.
  3. Work it out. x²/16 = 3/4 gives x² = 12, so x = √12 = 2√3 ≈ 3.4641. This lies between 0 and 4, so the formula x²/16 applies. Check: F(3.4641) = 12/16 = 0.75.
  4. Check. F(0) = 0 and F(4) = 1, so the answer must lie between 0 and 4. The value 3.46 does, and it is above the midpoint 2, which fits because F rises faster on the right.

Answer: 3.46

from math import sqrt
def Fc(x):
    if x < 0:
        return 0.0
    if x <= 4:
        return x * x / 16
    return 1.0
x = sqrt(12)
print("F at sqrt(12) =", round(Fc(x), 6))
print("75th percentile =", round(x, 4))
print("to 2 dp:", round(x, 2))
F at sqrt(12) = 0.75
75th percentile = 3.4641
to 2 dp: 3.46

Exam-level 2: Strict inequalities for a discrete CDF (MCQ, 2 marks)

A shop records the number of items X that a customer buys. X takes the values 1, 2, 3 or 4 with probabilities 0.1, 0.2, 0.3 and 0.4. The cumulative distribution function is F(x) = P(X ≤ x). Which of the following is P(2 < X < 4), with both inequalities strict? (A) 0.3 (B) 0.5 (C) 0.7 (D) 0.6. Select one option.

How to think about it

  1. What is asked. P(2 < X < 4), where neither end is included.
  2. Which idea applies. For a discrete variable the endpoints matter. Only the whole values inside the open interval count, and P(a < X < b) = F(b-) - F(a), where F(b-) means just below b.
  3. Work it out. The only whole number strictly between 2 and 4 is 3. So P(2 < X < 4) = P(X = 3) = 0.3. The answer is option A.
  4. Check. F(2) = 0.1 + 0.2 = 0.3 and F(4) = 1. The shortcut F(4) - F(2) = 0.7 is the probability of 2 < X ≤ 4, which wrongly includes X = 4. Option (C) is that trap. Option (D), 0.6, equals F(3), a cumulative value, not a single-value probability.

Answer: (A) 0.3

from fractions import Fraction as F
pmf = {1: F(1, 10), 2: F(2, 10), 3: F(3, 10), 4: F(4, 10)}
def cdf(x):
    return sum(p for k, p in pmf.items() if k <= x)
print("F(2) =", cdf(2))
print("F(4) =", cdf(4))
print("P(strictly between 2 and 4) =", sum(p for k, p in pmf.items() if 2 < k < 4))
print("F(4) - F(2) =", cdf(4) - cdf(2))
F(2) = 3/10
F(4) = 1
P(strictly between 2 and 4) = 3/10
F(4) - F(2) = 7/10

Exam-level 3: Facts about an exponential CDF (MSQ, 2 marks)

A random variable X has the cumulative distribution function F(x) = P(X ≤ x) given by F(x) = 1 - e^(-2x) for x ≥ 0, and F(x) = 0 for x less than 0. Select all the statements that are true.

  • (A) F(0) = 0
  • (B) F is non-decreasing over all real numbers.
  • (C) P(X > 1) = e^(-2)
  • (D) F(-1) = 1

How to think about it

  1. What is asked. Which of the four statements are true. Select all that apply.
  2. Which idea applies. The CDF properties: it never decreases, it runs from 0 to 1, and P(X > x) = 1 - F(x).
  3. Work it out. F(0) = 1 - e^0 = 1 - 1 = 0, so (A) is true. As x grows, e^(-2x) shrinks, so F grows, and F is non-decreasing everywhere, so (B) is true. P(X > 1) = 1 - F(1) = e^(-2), so (C) is true. For x less than 0 the CDF is 0, so F(-1) = 0, not 1, and (D) is false.
  4. Check. A CDF must be 0 far to the left, and option (D) puts the value 1 there, which is the value on the far right. That is the reason (D) fails. The answer is A, B and C.

Answer: A, B and C

from math import exp
def Fc(x):
    return 0.0 if x < 0 else 1 - exp(-2 * x)
print("F(0) =", Fc(0))
xs = [-1, -0.5, 0, 0.5, 1, 2, 5]
vals = [Fc(x) for x in xs]
print("non-decreasing on the grid:", all(a <= b for a, b in zip(vals, vals[1:])))
print("P(X exceeds 1) =", round(1 - Fc(1), 6))
print("e^-2 =", round(exp(-2), 6))
print("F(-1) =", Fc(-1))
F(0) = 0.0
non-decreasing on the grid: True
P(X exceeds 1) = 0.135335
e^-2 = 0.135335
F(-1) = 0.0

Exam-level 4: A conditional probability from a CDF (NAT, 2 marks)

NAT question. The fraction X of a tank that is filled each day has the density f(x) = 2x for 0 ≤ x ≤ 1, and f(x) = 0 elsewhere. Using the cumulative distribution function F(x) = P(X ≤ x), find the conditional probability P(X > 0.5 given X > 0.3). Give the answer correct to two decimal places.

How to think about it

  1. What is asked. P(X > 0.5 | X > 0.3), to two decimal places.
  2. Which idea applies. F(x) = ∫ from 0 to x of 2t dt = x² on [0, 1]. Then P(X > x) = 1 - F(x), and P(A | B) = P(A and B) / P(B).
  3. Work it out. F(0.5) = 0.25, so P(X > 0.5) = 0.75. F(0.3) = 0.09, so P(X > 0.3) = 0.91. The event X > 0.5 lies inside X > 0.3, so P(X > 0.5 and X > 0.3) = 0.75. Then P(X > 0.5 | X > 0.3) = 0.75 / 0.91 = 75/91 ≈ 0.8242, which is 0.82 to two decimal places.
  4. Check. The answer is between 0 and 1. It is higher than the unconditional 0.75, which makes sense: removing the low values (X ≤ 0.3) leaves a set where large values are a bigger share.

Answer: 0.82

from fractions import Fraction as F
def Fc(x):
    return x * x
pA = 1 - Fc(F(1, 2))
pB = 1 - Fc(F(3, 10))
print("P(X exceeds 0.5) =", pA)
print("P(X exceeds 0.3) =", pB)
print("P(X exceeds 0.5 given X exceeds 0.3) =", pA / pB, "=", round(float(pA / pB), 4))
P(X exceeds 0.5) = 3/4
P(X exceeds 0.3) = 91/100
P(X exceeds 0.5 given X exceeds 0.3) = 75/91 = 0.8242

Summary

CDF
F(x) = P(X ≤ x), the chance that X is at most x, for every real x.
Limits
F(x) goes to 0 on the far left and to 1 on the far right.
Non-decreasing
A CDF never goes down as x increases.
Right-continuous
At a jump, the CDF takes the upper value at the jump point.
Discrete CDF
The running total of the PMF, a staircase with jumps equal to the PMF values.
Continuous CDF
F(x) = ∫ from -∞ to x of f(t) dt, the area under the PDF to the left of x.
Interval probability
P(a < X ≤ b) = F(b) - F(a).
Survival function
P(X > x) = 1 - F(x).
Uniform CDF
(x - a)/(b - a) between a and b, flat outside.
Exponential CDF
1 - e-λx for x ≥ 0.
Standard normal CDF
Φ(z) = P(Z ≤ z), found from tables or software.
Median
The value m with F(m) = 1/2 for a continuous variable.
Staircase jump
For a discrete variable, P(X = x) = F(x) - F(x-), the size of the jump at x.
Piecewise CDF
A CDF defined by different formulas on different intervals, which must join without gaps.

Remember these

  1. The CDF is always non-decreasing, starts at 0 and ends at 1.
  2. A discrete CDF is the running total of the PMF, and a continuous CDF is the integral of the PDF.
  3. For an interval, subtract the CDF at the lower end from the CDF at the upper end.
  4. For "more than" questions, use 1 minus the CDF.
  5. For discrete variables, check whether an endpoint is included before choosing the CDF value.
  6. For the exponential, F(x) = 1 - e-λx, and the median solves F(m) = 1/2.
  7. For piecewise CDFs, pick the piece that contains each point before you evaluate.
