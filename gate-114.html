Propositional logic

Propositional logic is the language of true and false statements joined by words like and, or and not. It is the foundation for checking reasoning in AI and for many GATE questions on truth tables.

The idea in plain words

Think about a simple rule at home: "If it rains, then I take an umbrella." You can test this rule. Look at the weather and look at your umbrella. Logic gives us a careful way to test such rules, every time, without guessing.

In logic, a proposition is a statement that is either true or false. "It is raining" is a proposition. "Please close the door" is not, because it cannot be true or false. We write propositions with letters such as p, q and r. We join them with small words, called connectives, to build bigger statements.

Why does this matter? An AI agent must check whether its conclusions follow from what it knows. A computer can check this by listing every possible case. That list is called a truth table. Many GATE Data Science and AI (DA) questions ask you to build a truth table, check a rule, or simplify a formula.

Everyday analogy: a light switch circuit. Each switch is either up (true) or down (false). The light is on or off depending on the switches. Logic is the same idea written with words.

Key terms

Proposition
Plain: a statement that is true or false. Precise: a declarative sentence with exactly one truth value.
Connective
Plain: a word that joins statements. Precise: an operator that builds a compound formula from smaller ones.
NOT (¬)
Plain: flips the truth value. Precise: ¬p is true exactly when p is false.
AND (∧)
Plain: both must be true. Precise: p ∧ q is true only when both p and q are true.
OR (∨)
Plain: at least one is true. Precise: p ∨ q is false only when both p and q are false.
Implication (→)
Plain: "if p then q". Precise: p → q is false only when p is true and q is false.
Biconditional (↔)
Plain: "p exactly when q". Precise: p ↔ q is true when p and q have the same truth value.
Truth table
A table that lists every combination of truth values and the result of a formula for each one.
Well-formed formula (WFF)
A correctly written formula, built by the grammar rules of logic, with balanced brackets.
Tautology
A formula that is true in every row of its truth table.
Contradiction
A formula that is false in every row.
Satisfiable
A formula that is true in at least one row.
Equivalence (≡)
Two formulas with the same truth value in every row.
Literal
A variable or its negation, such as p or ¬p.
CNF and DNF
CNF is an AND of clauses, and each clause is an OR of literals. DNF is an OR of terms, each an AND of literals.
Resolution
A proof rule that combines two clauses containing opposite literals.

Concept 1: Propositions and connectives

Start with two propositions. Let p mean "it is raining" and q mean "I take an umbrella". Each connective gives a new formula with its own rule for when it is true.

The truth table below uses T for true and F for false. Each row is one case. For example, the second row says p is true and q is false.

pq¬pp ∧ qp ∨ qp → qp ↔ q
TTFTTTT
TFFFTFF
FTTFTTF
FFTFFTT

Look closely at the implication column. The only row where p → q is false is the second row: p is true (it rains) but q is false (I do not take an umbrella). That is the only way to break the rule "if it rains, I take an umbrella". When p is false, the rule says nothing, so p → q is true.

TrapStudents often think p → q means q → p. It does not. The statement "if it rains, I take an umbrella" is not the same as "if I take an umbrella, it rains". Always keep the order of the arrow.

The formula p ∨ q is called inclusive OR. It is true when at least one part is true, including when both are true. Everyday language often means "one or the other but not both", which is a different connective called exclusive OR (XOR). In GATE, OR means inclusive OR unless the question says otherwise.

Question: Is p → q true when p is false and q is true?

Yes. The implication is only false when p is true and q is false. Here p is false, so the rule is not broken.

Question: What is the truth value of p ↔ q when both p and q are false?

True. A biconditional is true when both sides match, and F and F match.

Concept 2: Truth tables and equivalences

A formula with n propositions has 2n rows in its truth table. Two variables give 4 rows, and three variables give 8 rows. To fill a row, substitute the truth values and evaluate the formula step by step, from the innermost brackets outward.

Worked example: evaluate (p → q) ∨ (q ↔ r) when p = T, q = F, r = T

  1. Step 1: p → q is T → F. An implication with a true left side and a false right side is false. So p → q = F.
  2. Step 2: q ↔ r is F ↔ T. The two sides differ, so the biconditional is false. So q ↔ r = F.
  3. Step 3: F ∨ F. Both are false, so the OR is false.

The answer is F.

Equivalence and standard laws

Two formulas are equivalent, written A ≡ B, when they have the same truth value in every row. Equivalences let us rewrite a formula into a simpler or more useful shape. Here are the laws you must know:

De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q and ¬(p ∨ q) ≡ ¬p ∧ ¬q
Implication: p → q ≡ ¬p ∨ q
Contrapositive: p → q ≡ ¬q → ¬p
Distributive: p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)

Here p, q and r stand for any formulas. The symbol ¬ means NOT, ∧ means AND and ∨ means OR. Use them as rewrite rules: each side can replace the other.

Example: the negation of "it is raining and it is cold" is ¬(R ∧ C), which by De Morgan equals ¬R ∨ ¬C. In words: "it is not raining, or it is not cold".

from itertools import product

def implies(p, q):
    return (not p) or q

rows = list(product([False, True], repeat=2))
print("p -> q equals (not p) or q:", all(implies(p, q) == ((not p) or q) for p, q in rows))
print("De Morgan law holds:", all((not (p and q)) == ((not p) or (not q)) for p, q in rows))

rows3 = list(product([False, True], repeat=3))
true_rows = [(p, q, r) for p, q, r in rows3 if (p or q) and ((not p) or r)]
print("Rows where the formula is true:", len(true_rows))
print(true_rows)
p -> q equals (not p) or q: True
De Morgan law holds: True
Rows where the formula is true: 4
[(False, True, False), (False, True, True), (True, False, True), (True, True, True)]

The check on the last line uses three variables, so it has 8 rows. Four of them make the formula true.

Tautology, contradiction and satisfiable

Look at the whole column of a truth table. If every row is T, the formula is a tautology. If every row is F, it is a contradiction. If at least one row is T, it is satisfiable. For example, p ∨ ¬p is a tautology, and p ∧ ¬p is a contradiction.

Key ideaTwo formulas A and B are equivalent exactly when A ↔ B is a tautology. So you can check any claim about formulas by looking at one truth table column.

Question: Is p ∨ ¬p satisfiable?

Yes. It is true in every row, so it is true in at least one row. It is also a tautology.

Question: Use De Morgan to rewrite ¬(p ∨ q).

It becomes ¬p ∧ ¬q: "not p and not q".

Concept 3: Normal forms and resolution

A literal is a variable or its negation, such as p or ¬q. A clause is literals joined by OR, such as (¬p ∨ q ∨ r).

A formula is in conjunctive normal form (CNF) if it is an AND of clauses. A formula is in disjunctive normal form (DNF) if it is an OR of terms, where each term is an AND of literals. Computers like CNF, because each clause can be checked on its own.

Converting to CNF: a worked example

Convert p → (q ∧ ¬r) into CNF.

  1. Remove the arrow. Use p → X ≡ ¬p ∨ X. We get ¬p ∨ (q ∧ ¬r).
  2. Distribute OR over AND. The rule is A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C). Here A = ¬p, B = q and C = ¬r.
  3. Result. (¬p ∨ q) ∧ (¬p ∨ ¬r). This is CNF with two clauses.

Check with one row: p = T, q = F, r = F. The original is T → (F ∧ T) = T → F = F. The CNF is (F ∨ F) ∧ (F ∨ T) = F ∧ T = F. Both give F, so the conversion is correct on this row.

Resolution

Resolution is a proof method. Suppose you want to show that a knowledge base (KB) of clauses entails a conclusion. You add the negation of the conclusion, then try to derive the empty clause, which means a contradiction. The rule is:

from (A ∨ l) and (¬l ∨ B), derive (A ∨ B)

Here l is a literal that appears positive in one clause and negative in the other. The two clauses cancel out on l. Example: from (¬p ∨ q) and p, we get q. This is the familiar modus ponens: if p then q, and p holds, so q holds.

TipTo prove a conclusion r, add ¬r as a clause. If you reach the empty clause, which is a clause with no literals left and means a contradiction, the original KB entails r.

Question: From (p ∨ q) and (¬q), what can be derived by resolution?

Resolve on q to get p. The literal q cancels with ¬q, leaving p.

Question: Why is CNF useful for computers?

Each clause is checked on its own, and resolution works on clauses. CNF gives a simple, regular shape.

Solved GATE-style problems

These problems are original, written in the style of GATE. They are not past exam questions.

Evaluate a formula

Let p = T, q = F and r = T. Find the truth value of (p → q) ∨ (q ↔ r).

How to think about it

  1. What is asked. The truth value of one formula for one row.
  2. Which idea applies. Evaluate the innermost parts first.
  3. Work it out. p → q = T → F = F. q ↔ r = F ↔ T = F. So F ∨ F = F.
  4. Check. An OR is false only when both sides are false. Both sides are F, so F is right.

Answer: F (false).

Negating a sentence

Let R mean "it is raining" and C mean "it is cold". Which sentence is the negation of R ∧ C?

How to think about it

  1. What is asked. A sentence equal to ¬(R ∧ C).
  2. Which idea applies. De Morgan's law: ¬(p ∧ q) ≡ ¬p ∨ ¬q.
  3. Work it out. ¬(R ∧ C) ≡ ¬R ∨ ¬C, which says "it is not raining or it is not cold".
  4. Check. The original is false only when both are true. The new sentence is false only when both R and C are true, so they match.

Answer: "It is not raining, or it is not cold."

Tautologies (select all that apply)

Which of the following formulas are tautologies? Select all that apply.

(A) p ∨ ¬p
(B) (p → q) ∨ (q → p)
(C) p ∧ ¬p
(D) ((p → q) ∧ p) → q

How to think about it

  1. What is asked. Which formulas are true in every row.
  2. Which idea applies. Check every row, or reason about when a formula could be false.
  3. Work it out. (A) is true in every row. (C) is always false. For (B), the formula is false only if p → q is false and q → p is false. p → q is false only when p = T and q = F, but then q → p = F → T = T. So (B) is never false. For (D), it is false only if (p → q) ∧ p is true and q is false. That needs p = T, q = F, but then p → q = F, so the premise fails. So (D) is never false.
  4. Check. Tautologies can always be checked with a four-row table. Here it confirms that (A), (B) and (D) are true in all rows.

Answer: (A), (B) and (D).

Count the true rows

Over three propositions p, q and r, how many of the 8 rows make (p ∧ q) ∨ ¬r true? Give a whole number.

How to think about it

  1. What is asked. The number of true rows, out of 8.
  2. Which idea applies. A formula is true if its OR has at least one true side.
  3. Work it out. If r = F, then ¬r is true, so the formula is true. That gives 4 rows (p and q can be anything). If r = T, then ¬r is false, so we need p ∧ q to be true. That happens in 1 row (p = T, q = T). Total: 4 + 1 = 5.
  4. Check. The rows with r = F and the rows with r = T plus p ∧ q are different rows, so nothing is counted twice.

Answer: 5.

Convert to CNF

Convert p → (q ∧ ¬r) into conjunctive normal form, and list its clauses.

How to think about it

  1. What is asked. A CNF formula equal to the given one, with its clauses.
  2. Which idea applies. Remove the arrow, then distribute OR over AND.
  3. Work it out. p → X ≡ ¬p ∨ X, so we get ¬p ∨ (q ∧ ¬r). Distribute: (¬p ∨ q) ∧ (¬p ∨ ¬r).
  4. Check. Test p = F, q = F, r = F. Original: F → anything = T. CNF: (T ∨ F) ∧ (T ∨ T) = T ∧ T = T. They match.

Answer: (¬p ∨ q) ∧ (¬p ∨ ¬r). Two clauses: (¬p ∨ q) and (¬p ∨ ¬r).

Prove a conclusion by resolution

The knowledge base contains p → q, q → r and p. Use resolution to show that r follows.

How to think about it

  1. What is asked. A resolution proof that r is entailed.
  2. Which idea applies. Negate the goal, add it as a clause, and derive the empty clause.
  3. Work it out. Clauses: (1) ¬p ∨ q, (2) ¬q ∨ r, (3) p, and the negated goal (4) ¬r. Resolve (1) and (3) on p to get q. Resolve that q with (2) on q to get r. Resolve r with (4) on r to get the empty clause.
  4. Check. Reaching the empty clause means the KB and ¬r cannot all be true. So the KB entails r.

Answer: Yes, r follows. The proof is: q from (1) and (3), then r from q and (2), then the empty clause from r and (4).

Count satisfying rows

How many of the 8 rows over p, q and r make (p → q) ∧ (q → r) ∧ ¬p true? Give a whole number.

How to think about it

  1. What is asked. The number of true rows.
  2. Which idea applies. Every part must be true, so start from the strongest condition, ¬p.
  3. Work it out. ¬p true means p = F. Then p → q is true for both values of q. Now check q → r. If q = F, q → r is true for both r. That gives 2 rows. If q = T, we need r = T, which gives 1 row. Total: 2 + 1 = 3.
  4. Check. The three rows are (F, F, F), (F, F, T) and (F, T, T). Each one makes all three parts true.

Answer: 3.

Exam-level practice

Exam-level 1: Counting models (NAT, 2 marks)

How many of the 8 truth assignments to p, q, r make (p → q) ∧ (q → r) true?

How to think about it

  1. What is asked. The number of satisfying assignments.
  2. Which idea applies. Enumerate or reason: the formula forbids p true with q false, and q true with r false.
  3. Work it out. Allowed patterns follow p ≤ q ≤ r: FFF, FFT, FTT, TTT. Count 4.
  4. Check. The code enumerates.
from itertools import product
imp = lambda a, b: (not a) or b
print(sum(imp(p, q) and imp(q, r) for p, q, r in product([False, True], repeat=3)))

4

Answer: 4.

Exam-level 2: Tautologies (MSQ, 2 marks)

Which are tautologies? (A) (p → q) ↔ (¬q → ¬p) (B) (p → q) → (q → p) (C) ((p → q) ∧ p) → q (D) (p ∨ q) → p

How to think about it

  1. What is asked. Formulas true under every assignment.
  2. Which idea applies. Contrapositive and modus ponens are valid. The converse is not.
  3. Work it out. (A) True. (B) Fails when p = F, q = T. (C) True. (D) Fails when p = F, q = T.
  4. Check. The code checks all assignments.
from itertools import product
imp = lambda a, b: (not a) or b
fs = {"A": lambda p, q: imp(p, q) == imp(not q, not p), "B": lambda p, q: imp(imp(p, q), imp(q, p)),
      "C": lambda p, q: imp(imp(p, q) and p, q), "D": lambda p, q: imp(p or q, p)}
print([k for k, f in fs.items() if all(f(p, q) for p, q in product([False, True], repeat=2))])

['A', 'C']

Answer: (A) and (C).

Exam-level 3: Resolution (MCQ, 2 marks)

From the clauses (p ∨ q), (¬p ∨ r) and (¬q ∨ r), which clause follows by resolution? (A) r (B) ¬r (C) p ∧ q (D) ¬p

How to think about it

  1. What is asked. The resolvent chain.
  2. Which idea applies. Resolve on p, then on q.
  3. Work it out. (p ∨ q) and (¬p ∨ r) give (q ∨ r). With (¬q ∨ r) this gives (r ∨ r) = r.
  4. Check. This is proof by cases: either p or q holds, and each gives r.

Answer: (A).

Remember these

  1. p → q is false only when p is true and q is false.
  2. The rows of an n-variable table number 2n.
  3. Pushing a NOT through an AND or OR flips the operator (De Morgan).
  4. p → q ≡ ¬p ∨ q.
  5. A tautology is true in every row. Check the whole column.
  6. CNF is an AND of OR-clauses. Use distribution to get there.
  7. To prove r by resolution, add ¬r and derive the empty clause.
