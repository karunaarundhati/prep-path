Servo motors & torque-speed characteristics

A servo motor checks its own position with a sensor and corrects any error, so it can be accurate and fast. Robot joints depend on servos, and GATE asks about closed-loop control, encoders and the torque-speed envelope of a servo.

The idea in plain words

Imagine you are asked to put a cup on a table at exactly 30 cm from the edge. You do not measure the distance once and then close your eyes. You look, notice your hand is at 27 cm, move it a bit forward, look again, and keep correcting until the cup is in the right place. That habit of looking and correcting is feedback.

A servo motor works this way. A sensor measures the real shaft angle. A controller compares that angle with the wanted angle. If there is a difference, the controller drives the motor to remove it. The whole system is called a servo system.

Why it matters. A robot joint must reach a target angle even when its load changes, a person pushes on it, or the gears have some play. A plain motor cannot know any of this. A servo can, because it keeps checking. This is why robot arms, cameras on gimbals and machine tools use servos.

Where it appears in GATE. In the Robotics and Automation (RA) paper, expect questions on closed-loop and open-loop control, on the feedback sensors such as encoders and potentiometers, and on the torque-speed curve of a servo. Some questions ask you to calculate encoder resolution or a control error.

Key terms

Servo system
A motor with a sensor, a controller and a drive, working together in closed loop to hold a wanted position, speed or torque.
Feedback
Information about the real output sent back to the controller so that it can compare it with the wanted value.
Setpoint (reference)
The wanted value, such as a target angle.
Error
The difference between the setpoint and the measured value. Precisely: error = wanted - measured.
Controller
The part that decides how much drive to apply, based on the error.
Drive or amplifier
The electronics that turn the controller's command into current for the motor.
Closed loop
A control system in which the output is measured and fed back to the input.
Open loop
A control system with no feedback. The controller assumes the output is correct.
Encoder
A sensor that measures shaft angle by producing pulses or digital counts as the shaft turns.
Potentiometer
A variable resistor whose wiper position follows the shaft angle. It gives an analogue voltage that is proportional to angle.
Resolution
The smallest change in angle that the sensor can report. For a simple encoder it is 360 degrees divided by the counts per revolution.
Quadrature decoding
A way of reading an encoder's two offset signals so that each edge counts, giving four counts per pulse.
Continuous torque
The torque the motor can give for a long time without overheating.
Peak torque
The largest torque the motor and drive can give for a short time, for example during fast acceleration.
Torque-speed envelope
The region on a torque against speed graph that the motor and drive can work in safely.
Base speed
The speed at which the motor reaches its maximum voltage. Above it, the available torque usually falls.
Proportional gain (Kp)
The number that turns an error into a command. Precisely: command = Kp × error.

Closed-loop control and the error

The parts of a servo loop

Here is the loop drawn as a flow of signals. Read it from left to right, and then follow the feedback arrow back.

  wanted angle                                              real angle
  (setpoint) --> [ + ] --> [ controller ] --> [ drive ] --> [ motor + load ] --+--> output
                    ^ -                                                       |
                    |                                                         |
                    +------------------ [ encoder: measured angle ] <----------+

The circle with the plus and minus sign is a comparator. It subtracts the measured angle from the wanted angle, and the result is the error. The controller turns the error into a command. The drive turns the command into current, and the motor turns the load. The encoder measures the new angle, and the loop repeats many times each second.

Proportional control

The simplest controller is proportional. The command is the error times a gain Kp:

command = Kp × error = Kp × (wanted - measured)

A big error gives a big command, and a small error gives a small command. As the error shrinks, the drive shrinks too. This smooth slowing down is what makes a servo settle at the target, instead of overshooting wildly.

Worked example: a torque command

A joint should be at 90 degrees, but it is measured at 85 degrees. The gain is Kp = 0.2 N·m per degree.

  1. Error: 90 - 85 = 5 degrees.
  2. Command: 0.2 × 5 = 1.0 N·m.
  3. The motor now pushes to close the gap. As the joint moves, the error falls, and the command falls with it.
K_p = 0.2          # N-m per degree of error
wanted = 90.0      # degrees
measured = 85.0    # degrees

error = wanted - measured
torque_cmd = K_p * error
print("Error = %.1f degrees" % error)
print("Torque command = %.2f N-m" % torque_cmd)
Error = 5.0 degrees
Torque command = 1.00 N-m

TrapStudents sometimes say a servo "knows" the target. It does not. It only knows the error, which is the wanted value minus the measured value. If the sensor is wrong, the servo will be wrong too.

Question: the wanted angle is 30 degrees and the measured angle is 32 degrees. What is the error?

Error = 30 - 32 = -2 degrees. The negative sign tells the controller to drive the joint back the other way.

Question: what happens to the command as the joint gets closer to the target?

The error falls, so the command falls. The motor slows down as it approaches the target, which reduces overshoot.

Encoders and resolution

How an incremental encoder works

An incremental encoder has a disc with many thin slots, or a magnetic ring with many poles. As the shaft turns, a light or magnetic sensor sees each slot or pole and sends a pulse. Counting pulses gives the angle moved. The encoder has a fixed number of counts per revolution, called CPR.

Most encoders use two signals, A and B, that are shifted by a quarter cycle. Reading both signals lets the electronics see which way the shaft turns. Quadrature decoding counts every edge of A and B. Four edges per pulse means four counts per pulse.

Resolution

The resolution is the smallest angle the encoder can report. For a simple count of one edge per pulse:

resolution (degrees) = 360 / (counts per revolution)

With quadrature decoding, multiply the counts per revolution by 4 first. A higher resolution gives a more accurate servo, but it costs a better encoder and faster electronics.

Worked example: resolution and counts

An encoder has 500 counts per revolution and uses 4-times quadrature decoding. Find the resolution and the number of counts for a 90 degree move.

  1. Total counts per revolution: 500 × 4 = 2000.
  2. Resolution: 360 / 2000 = 0.18 degrees per count.
  3. Counts for 90 degrees: 90 / 0.18 = 500 counts. This is a quarter of 2000, as expected.
counts_per_rev = 500
quad = 4                                  # quadrature: four counts per pulse

res_plain = 360 / counts_per_rev
res_quad = 360 / (counts_per_rev * quad)
counts_90 = 90 / 360 * counts_per_rev * quad

print("Resolution = %.2f degrees per count" % res_plain)
print("Resolution with 4x decoding = %.2f degrees" % res_quad)
print("Counts for 90 degrees with 4x decoding = %d" % counts_90)
Resolution = 0.72 degrees per count
Resolution with 4x decoding = 0.18 degrees
Counts for 90 degrees with 4x decoding = 500

Potentiometers and absolute encoders

A potentiometer gives a voltage that follows the angle, so it knows the position as soon as power is on. Its resolution depends on the analogue-to-digital converter and it wears out with use. An absolute encoder gives a unique code for every angle, so it also knows the position after a power cut. An incremental encoder must find a home position after power-up.

Question: an encoder has 1024 counts per revolution and no quadrature. What is its resolution?

360 / 1024 = 0.3516 degrees per count, about 0.35 degrees.

Question: why does an absolute encoder not need to find home after power-up?

Each angle has its own code, so the encoder reports the exact position as soon as it is powered.

The torque-speed envelope

Why a servo has two torque limits

A servo can give a large torque for a short time, for example to accelerate a heavy arm. It cannot give that large torque for long. The motor would overheat, and the drive would overload. So the datasheet gives two torque values: peak torque for short bursts, and continuous torque for steady work.

Everyday analogy. A runner can sprint at full speed for 10 seconds, but not for an hour. A servo is like the runner. Its peak is a sprint. Its continuous torque is the pace it can keep all day.

The shape of the envelope

Plot torque on the vertical axis and speed on the horizontal axis. The peak torque is flat from zero speed up to the base speed, because the drive has enough voltage. Above the base speed, the back-EMF of the motor takes up most of the supply voltage, so the torque that can be given falls. The continuous torque is a flat line lower down, limited by heating.

torque
  ^
  |  ############                   <- peak torque region (short time)
  |  #           #
  |  #            #
  |  #             #
  |  #               #
  |  ################################ <- continuous torque (long time)
  +-------------------+-----------------> speed
                 base speed

The shape above is a simple model. Real servo datasheets draw the curve more carefully, but the key idea is the same: a flat region with the peak torque, a falling region above base speed, and a lower continuous line.

Worked example: peak torque at a given speed

Use the simple linear model. The peak torque is Tpeak = 2 N·m up to a base speed of 100 rad/s, and it falls in a straight line to zero at a maximum speed of 200 rad/s. Find the peak torque at 150 rad/s.

  1. Speed 150 is above the base speed of 100, so the falling line applies.
  2. Fraction of the way from base speed to maximum: (150 - 100) / (200 - 100) = 0.5.
  3. Peak torque: 2 × (1 - 0.5) = 1.0 N·m.
T_peak = 2.0        # peak torque in N-m (up to base speed)
T_cont = 0.5        # continuous torque in N-m
w_base = 100.0      # base speed in rad/s
w_max = 200.0       # maximum speed in rad/s

def max_torque(w):
    if w <= w_base:
        return T_peak
    return T_peak * (w_max - w) / (w_max - w_base)

for w in (50, 100, 150, 200):
    print("speed %3d rad/s: peak torque %.2f N-m" % (w, max_torque(w)))
print("continuous torque limit = %.2f N-m" % T_cont)
speed  50 rad/s: peak torque 2.00 N-m
speed 100 rad/s: peak torque 2.00 N-m
speed 150 rad/s: peak torque 1.00 N-m
speed 200 rad/s: peak torque 0.00 N-m
continuous torque limit = 0.50 N-m

Key ideaA load must sit inside the envelope. For a short move you may use the peak line. For a long duty you must stay below the continuous line.

Question: why does the peak torque fall above base speed?

At high speed the back-EMF is large, so less of the supply voltage is left to push current through the winding. Less current means less torque.

Question: the continuous torque is 0.5 N·m. Can a 1.5 N·m load run for an hour?

No. 1.5 N·m is above the continuous line, so the motor would overheat over a long run. It could only use the peak torque for a short time.

Servo, stepper and DC motor compared

Each motor type has a place. Servos are chosen for accuracy with changing loads, steppers for low-cost positioning, and plain DC motors for simple speed drives.

PropertyServoStepper (open loop)Plain DC motor
Feedback sensorYes, encoder or potentiometerNo, by defaultNot needed for basic speed control
Control typeClosed loopOpen loopOften open loop or closed loop
Position accuracyHigh, corrects errorsGood, until a step is lostPoor without a sensor
Torque at high speedFalls above base speedFalls quickly with speedFalls linearly with speed
Cost and complexityHigherLowerLower
Typical robot useJoints that must be accurate under changing loadSimple axes, printers, camerasWheels, fans, simple drives

GATE loves thisThe big difference is the feedback. A servo is closed loop and corrects its error. A stepper is open loop and trusts the pulse count. If a question asks which motor can detect and correct a position error, the answer is the servo, or a stepper with an encoder added.

Question: which motor type would you choose for a robot wrist that must hold a precise angle while a changing load pushes on it?

A servo. Its feedback sensor detects the position error caused by the load, and the controller corrects it.

Question: a plain DC motor with no sensor is used for a conveyor. What is the main limitation?

Its speed and position drift with the load, because nothing measures the real output. Speed control needs a sensor or a controller that models the motor.

Solved GATE-style problems

These are original problems in the GATE style. They are not real past paper questions.

Counts for a 45 degree move

An encoder gives 1024 counts per revolution and is read without quadrature. How many counts does a 45 degree move produce?

How to think about it

  1. What is asked. The number of counts for 45 degrees.
  2. Which idea applies. Counts = angle / 360 × counts per revolution.
  3. Work it out. 45 / 360 = 0.125. Then 0.125 × 1024 = 128 counts.
  4. Check. 45 degrees is one eighth of a turn, and 1024 / 8 = 128. Good.
counts = 45 / 360 * 1024
print("Counts = %.0f" % counts)
Counts = 128

Answer: 128 counts.

Error and command

A servo joint should be at 30 degrees but is measured at 27.5 degrees. The controller gain is Kp = 0.4 N·m per degree. Find the error and the torque command.

How to think about it

  1. What is asked. The error in degrees and the command in N·m.
  2. Which idea applies. Error = wanted - measured, and command = Kp × error.
  3. Work it out. Error = 30 - 27.5 = 2.5 degrees. Command = 0.4 × 2.5 = 1.0 N·m.
  4. Check. A positive error gives a positive command, which pushes the joint toward 30 degrees. Good.
wanted = 30.0
measured = 27.5
K_p = 0.4
error = wanted - measured
print("Error = %.1f degrees" % error)
print("Command = %.1f N-m" % (K_p * error))
Error = 2.5 degrees
Command = 1.0 N-m

Answer: error 2.5 degrees, command 1.0 N·m.

Which statements about servo systems are true?

Consider the following statements about servo systems. Select all that apply.

(A) A servo is a closed-loop system.
(B) The continuous torque of a servo is limited by heating.
(C) A stepper motor is closed loop by default.
(D) A servo corrects position using a measured error, not only a count of commands.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. The definition of closed loop, the two torque limits, and the difference between servo and stepper.
  3. Work it out. (A) True, the output is measured and fed back. (B) True, the long-term torque limit comes from heat. (C) False, a stepper is open loop unless an encoder is added. (D) True, the controller corrects the measured error.
  4. Check. Statement (C) reverses the definition of open loop, so it is false.

Answer: (A), (B) and (D). Statement (C) is false.

Torque at a higher speed

A servo has a peak torque of 2 N·m up to a base speed of 100 rad/s. Above the base speed, the peak torque falls in a straight line to zero at 200 rad/s. Using this simple model, find the peak torque at 130 rad/s, correct to two decimal places.

How to think about it

  1. What is asked. The peak torque at 130 rad/s.
  2. Which idea applies. Above base speed, T = Tpeak × (wmax - w) / (wmax - wbase).
  3. Work it out. T = 2 × (200 - 130) / (200 - 100) = 2 × 70 / 100 = 1.40 N·m.
  4. Check. At 150 rad/s the same formula gives 1.00 N·m, and at 130 rad/s the torque should be a bit higher. 1.40 is between 1.00 and 2.00. Good.
T_peak = 2.0
w_base = 100.0
w_max = 200.0
w = 130.0
T = T_peak * (w_max - w) / (w_max - w_base)
print("Peak torque = %.2f N-m" % T)
Peak torque = 1.40 N-m

Answer: 1.40 N·m.

Joint resolution through a gearbox

A robot joint is driven through a gearbox with ratio 50:1. The encoder is on the motor shaft and has 1000 counts per revolution with 4-times quadrature decoding. Find the smallest joint angle the controller can see, in degrees, to four decimal places.

How to think about it

  1. What is asked. The joint resolution in degrees.
  2. Which idea applies. First the motor resolution, then divide by the gear ratio, because one joint degree needs 50 motor degrees.
  3. Work it out. Motor counts per revolution = 1000 × 4 = 4000. Motor resolution = 360 / 4000 = 0.09 degrees. Joint resolution = 0.09 / 50 = 0.0018 degrees.
  4. Check. 4000 counts per motor turn times 50 motor turns per joint turn gives 200 000 counts per joint turn. 360 / 200 000 = 0.0018 degrees. Good.
counts_motor = 1000 * 4
motor_res = 360 / counts_motor
joint_res = motor_res / 50
print("Joint resolution = %.4f degrees" % joint_res)
Joint resolution = 0.0018 degrees

Answer: 0.0018 degrees.

Highest speed for a required torque

Use the same simple torque envelope as before: peak torque 2 N·m up to 100 rad/s, falling linearly to zero at 200 rad/s. A load needs a peak torque of 1.5 N·m. Find the highest speed, in rad/s, at which the servo can still give that torque.

How to think about it

  1. What is asked. The speed w where the envelope equals 1.5 N·m.
  2. Which idea applies. Set T = 2 × (200 - w) / 100 equal to 1.5 and solve for w.
  3. Work it out. 2 × (200 - w) / 100 = 1.5. Multiply by 100: 2 × (200 - w) = 150. Divide by 2: 200 - w = 75. So w = 125 rad/s.
  4. Check. Put 125 back in: 2 × (200 - 125) / 100 = 2 × 75 / 100 = 1.5 N·m. Good.
T_peak = 2.0
T_wanted = 1.5
w_base = 100.0
w_max = 200.0
w = w_max - (T_wanted / T_peak) * (w_max - w_base)
print("Highest speed = %.0f rad/s" % w)
print("Check torque = %.2f N-m" % (T_peak * (w_max - w) / (w_max - w_base)))
Highest speed = 125 rad/s
Check torque = 1.50 N-m

Answer: 125 rad/s.

Choose the correct statements about encoders and servo sizing

A designer chooses an encoder and a servo for a joint. Select all that apply.

(A) Peak torque is meant for short accelerations, not for long steady work.
(B) On a torque-speed graph, the continuous torque line lies below the peak torque curve.
(C) Doubling the counts per revolution halves the resolution angle.
(D) A stepper with the same frame size always gives more torque at high speed than a servo.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. The two torque limits, the shape of the envelope, and resolution = 360 / counts.
  3. Work it out. (A) True, the peak is a short-term limit. (B) True, the continuous line is lower. (C) True, resolution is inversely proportional to counts, so doubling the counts halves the angle. (D) False. A stepper's torque falls quickly as speed rises, and the claim is not true in general for a stepper and a servo of the same frame size.
  4. Check. Statement (D) makes a general claim that cannot be true for every motor, so it is rejected.

Answer: (A), (B) and (C). Statement (D) is false.

Exam-level practice

Exam-level 1: Servo bandwidth (NAT, 2 marks)

A servo motor has a mechanical time constant of 20 ms. Treating it as a first-order system, find its −3 dB bandwidth in Hz, correct to 2 decimal places.

How to think about it

  1. What is asked. fc = 1/(2πτ).
  2. Which idea applies. A first-order lag has corner frequency 1/τ rad/s.
  3. Work it out. 1/(2π · 0.02) = 7.96 Hz.
  4. Check. The code computes it.
import math
print("%.2f Hz" % (1 / (2 * math.pi * 0.02)))

7.96 Hz

Answer: about 7.96 Hz.

Exam-level 2: Linear torque-speed curve (NAT, 2 marks)

A servo motor has stall torque 2 N·m and no load speed 3000 rpm with a linear torque-speed curve. Find the maximum output power in W, correct to 1 decimal place.

How to think about it

  1. What is asked. The peak of P = Tω.
  2. Which idea applies. Power is greatest at half the stall torque and half the no load speed.
  3. Work it out. T = 1 N·m, ω = 1500 rpm = 157.08 rad/s. P = 157.1 W.
  4. Check. The code scans the curve.
import math
w0 = 3000 * 2 * math.pi / 60
print("%.1f W" % max(2 * (1 - w / w0) * w for w in [w0 * k / 10000 for k in range(10001)]))

157.1 W

Answer: about 157.1 W.

Exam-level 3: Servo facts (MSQ, 2 marks)

Which are TRUE? (A) AC servo motors often use a two phase induction design with high rotor resistance. (B) Servo motors are designed for low rotor inertia. (C) A servo needs feedback for position control. (D) Torque falls as speed rises in a DC servo.

How to think about it

  1. What is asked. Properties of servo motors.
  2. Which idea applies. High rotor resistance gives a linear, drooping torque-speed curve.
  3. Work it out. (A) True. (B) True. (C) True. (D) True.
  4. Check. These features give fast, stable response.

Answer: (A), (B), (C) and (D).

Remember these

  1. A servo corrects an error that it measures, and an open-loop motor does not.
  2. Error = wanted - measured. Command = Kp × error.
  3. Resolution = 360 / counts per revolution, and quadrature multiplies the counts by 4.
  4. Peak torque is for short bursts, and continuous torque is for long duty.
  5. Above base speed, peak torque usually falls.
