Continuous random variables & PDF

A continuous random variable can take any value in an interval, such as a height or a time. Its probability density function (PDF) tells you where the probability lies, and probabilities come from areas under the curve, not from single values.

The idea in plain words

In the last two topics, the random variable took values you could list: 0, 1, 2 and so on. Now consider the time a bus takes to reach you, or the length of a metal rod. These values are not in a list. They can be 3.1, 3.14, 3.141 and every number in between. Such a quantity is a continuous random variable.

For a continuous variable, a surprising thing happens. The chance that it equals one exact value is zero. Think of a dart thrown at a dartboard. The chance that it lands on one exact point, with no width at all, is zero. But the chance that it lands somewhere in a region is clear and positive. So for continuous variables we ask about intervals, not single values.

The tool for this is the probability density function, or PDF. The PDF is a curve. Probability is the area under the curve over an interval. A tall curve over a region means that region is likely. A flat, low curve means it is unlikely. The total area under the whole curve is exactly 1, because the variable must take some value.

Why does this matter for GATE? The Data Science and AI (DA) paper uses continuous distributions in its probability and statistics sections. The Robotics and Automation (RA) paper uses them for sensor noise, measurement errors and random times. GATE questions often give a PDF and ask for a probability, a normalising constant or a mean. Each of these needs the same tools: area, the total area of 1, and simple integrals.

Key terms

Each term first gets its plain meaning, then its precise form.

Continuous random variable
Plain meaning: a quantity that can take any value in an interval. Precise definition: a random variable whose possible values form an interval or a union of intervals of real numbers.
Probability density function (PDF) f(x)
Plain meaning: a curve that shows how the probability is spread out. Precise definition: a function f(x) with f(x) ≥ 0 everywhere and total area ∫ f(x) dx = 1, where P(a ≤ X ≤ b) = ∫ from a to b of f(x) dx.
Integral ∫
Plain meaning: the area under a curve between two points. Precise definition: ∫ from a to b of f(x) dx is the signed area between the curve y = f(x) and the x-axis, from x = a to x = b.
Density
Plain meaning: how tightly the probability is packed near a point. Precise definition: f(x) is a density, not a probability. Its value can be larger than 1, but its area over any interval is at most 1.
Continuous uniform distribution U(a, b)
Plain meaning: every value between a and b is equally likely. Precise definition: a distribution with PDF f(x) = 1/(b - a) for a ≤ x ≤ b, and 0 otherwise.
Expectation of a continuous variable
Plain meaning: the long-run average. Precise definition: E[X] = ∫ x f(x) dx, over all x.
Variance of a continuous variable
Plain meaning: the average squared distance from the mean. Precise definition: Var(X) = E[X²] - (E[X])², where E[X²] = ∫ x² f(x) dx.
Support
Plain meaning: the range where the PDF is not zero. Precise definition: the set of x values where f(x) > 0.

Concept 1: Continuous variables and the PDF

Why a single value has zero probability

Suppose a sensor reads a voltage between 0 and 1 volt, and the reading can have any number of decimal places. The chance that the reading is exactly 0.5 volts is zero, because there are infinitely many possible values in the interval, and one exact point is just one of them. Each point gets zero share of the probability. This is why we never ask for P(X = 0.5) for a continuous variable. We ask for P(0.4 ≤ X ≤ 0.6) instead.

This is also why the PDF is not a probability. The height f(x) at a point is a density, a measure of how much probability is packed nearby. The probability comes only from the area.

The two rules every PDF must follow

  1. Non-negative: f(x) ≥ 0 for every x. A negative density has no meaning.
  2. Total area 1: the integral of f over the whole real line equals 1.
f(x) ≥ 0 for all x, and ∫ f(x) dx = 1 over all x

These two rules play the same role as "each PMF value is at least 0 and the values add to 1" did in the discrete case. Replace the sum with an integral, and the logic is identical.

Probabilities as areas

P(a ≤ X ≤ b) = ∫ from a to b of f(x) dx

Each symbol means:

  • a and b are the ends of the interval.
  • ∫ from a to b means the area under the curve between a and b.
  • dx marks that we add up thin slices of width dx.

Because a single point has zero width, P(X = a) = 0, and so P(a ≤ X ≤ b) = P(a < X < b). For continuous variables the endpoints do not matter.

Worked example: a valid PDF

Let f(x) = 2x for 0 ≤ x ≤ 1, and f(x) = 0 otherwise. Check that it is a PDF and find P(X ≤ 0.5).

  1. Non-negative. For 0 ≤ x ≤ 1, the value 2x is at least 0, so the first rule holds.
  2. Total area. ∫ from 0 to 1 of 2x dx = [x²] from 0 to 1 = 1² - 0² = 1. The second rule holds.
  3. Probability. P(X ≤ 0.5) = ∫ from 0 to 0.5 of 2x dx = [x²] from 0 to 0.5 = 0.5² - 0 = 0.25.
  4. Check. The density rises from 0 at x = 0 to 2 at x = 1, so the left half holds less than half the area. A value 0.25 is consistent with that.

The Python block below checks both areas numerically. It cuts [0, 1] into 100000 thin slices and adds up the rectangles. This method is a direct picture of the integral.

def f(x):
    return 2 * x            # PDF on [0, 1]

n = 100000
h = 1 / n
mids = [(i + 0.5) * h for i in range(n)]

total = sum(f(x) * h for x in mids)
p_half = sum(f(x) * h for x in mids if x <= 0.5)
print(f"total area = {total:.4f}")
print(f"P(X <= 0.5) = {p_half:.4f}")
total area = 1.0000
P(X <= 0.5) = 0.2500

Key ideaA PDF value is not a probability. Only the area over an interval is a probability. Always compute an area, never read off a height.

TrapDo not say P(X = 0.5) = f(0.5). For continuous variables that probability is zero, even though f(0.5) is a positive number. The height is a density, and the probability needs a width.

Self-check: f(x) = 3 on an interval of length 1/3. Is the total area 1?

Yes. The area is height × width = 3 × 1/3 = 1, so this is a valid uniform density on that interval.

Self-check: why is P(X = c) = 0 for any single value c?

Because the area over a single point has zero width. The integral from c to c is zero, so no probability is assigned to one exact value.

Concept 2: Integrals as areas

Why we need integrals

To find a probability or a mean from a PDF, you need the area under a curve. For simple curves, such as straight lines and parabolas, the area can be computed exactly with an integral. You do not need to be an expert in integration. You need only the power rule and a few steps of care.

The power rule

∫ xk dx = xk+1 / (k + 1), for k ≠ -1

Each symbol means:

  • xk is a power of x, such as x, x² or x³.
  • k + 1 is the new power after integrating. We divide by it, so k + 1 must not be zero.

To evaluate a definite integral from a to b, compute the antiderivative F(x) = xk+1 / (k + 1) and then take F(b) - F(a). Write this as [F(x)] from a to b.

Worked example: a definite integral

Evaluate ∫ from 1 to 3 of 3x² dx.

  1. Integrate the power. Here k = 2, so the antiderivative of 3x² is 3 × x³ / 3 = x³.
  2. Evaluate at the top limit. 3³ = 27.
  3. Evaluate at the bottom limit. 1³ = 1.
  4. Subtract. 27 - 1 = 26.

The power rule works term by term. A sum of powers is integrated one power at a time. For example, ∫ (x + 1) dx = x²/2 + x.

TipAlways check the antiderivative by differentiating it. If you differentiate x³ you get 3x², which matches the integrand. This quick check catches most errors.

TrapForgetting to subtract the bottom limit is the most common integration error. The answer is F(b) minus F(a), never F(b) alone.

Self-check: what is ∫ from 0 to 2 of x dx?

The antiderivative is x²/2. Evaluate: 2²/2 - 0 = 4/2 = 2.

Self-check: what is ∫ from 0 to 1 of 2x dx?

The antiderivative is x². Evaluate: 1² - 0² = 1.

Concept 3: The continuous uniform distribution

The idea

The simplest continuous distribution is the uniform one. Imagine a bus that is equally likely to arrive at any moment between 8:00 and 8:10. Or a random number generator that gives any value between 2 and 5 with equal likelihood. Nothing in the interval is favoured. The PDF is flat across it.

The PDF

f(x) = 1 / (b - a), for a ≤ x ≤ b, and f(x) = 0 otherwise

Each symbol means:

  • a is the smallest possible value.
  • b is the largest possible value.
  • b - a is the width of the interval.

The height 1/(b - a) times the width (b - a) gives area 1, so the rule holds automatically. A wider interval means a lower flat line.

Probabilities for the uniform

For any interval inside [a, b], the probability is just its length divided by the total length:

P(c ≤ X ≤ d) = (d - c) / (b - a), for a ≤ c ≤ d ≤ b

This is the area of a rectangle: width (d - c) times height 1/(b - a).

Mean and variance

E[X] = (a + b) / 2 and Var(X) = (b - a)² / 12

The mean is the midpoint, which makes sense for a flat shape. The variance depends only on the width. The factor 12 is worth memorising, because it is the same as the discrete uniform variance formula with the width replacing n.

Worked example: a random number from 2 to 5

Let X be uniform on [2, 5]. Find the density, the mean, the variance and P(3 ≤ X ≤ 4).

  1. Density. f(x) = 1/(5 - 2) = 1/3 on [2, 5].
  2. Mean. (2 + 5)/2 = 3.5.
  3. Variance. (5 - 2)² / 12 = 9/12 = 3/4.
  4. Probability. P(3 ≤ X ≤ 4) = (4 - 3)/(5 - 2) = 1/3.
  5. Check. The interval [3, 4] is one third of [2, 5] in length, and the probability 1/3 agrees.
from fractions import Fraction as F

a, b = 2, 5
density = F(1, b - a)
mean = F(a + b, 2)
var = F((b - a) ** 2, 12)
p = density * (4 - 3)

print("density =", density)
print("mean =", mean)
print("variance =", var)
print("P(3 < X < 4) =", p)
density = 1/3
mean = 7/2
variance = 3/4
P(3 < X < 4) = 1/3

GATE loves thisFor a uniform variable, a probability question is often a length ratio. Find the length of the wanted interval, divide by the total length b - a, and skip the integral.

TrapThe density on the uniform is 1/(b - a), not 1/b or 1/a. A frequent error is to use the wrong length, especially when a is not zero.

Self-check: X is uniform on [0, 10]. What is P(X ≥ 7)?

P(X ≥ 7) = (10 - 7)/(10 - 0) = 3/10 = 0.3.

Self-check: X is uniform on [1, 7]. What is its variance?

Var(X) = (7 - 1)²/12 = 36/12 = 3.

Concept 4: Mean and variance by integration

The continuous version of the expectation

For discrete variables, the expectation is a sum of x times P(X = x). For continuous variables, the sum becomes an integral and the PMF becomes the PDF:

E[X] = ∫ x f(x) dx, and E[X²] = ∫ x² f(x) dx

Each symbol means:

  • x f(x) is each value weighted by its density, like the discrete case.
  • ∫ ... dx adds up the weighted values over all x in the support.

Then Var(X) = E[X²] - (E[X])², exactly as before.

Worked example: the PDF f(x) = 3x² on [0, 1]

First check that it is a PDF. The integral of 3x² from 0 to 1 is [x³] from 0 to 1 = 1. Good. Now find the mean and variance.

  1. Mean. E[X] = ∫ from 0 to 1 of x × 3x² dx = ∫ from 0 to 1 of 3x³ dx = [3x⁴/4] from 0 to 1 = 3/4.
  2. Second moment. E[X²] = ∫ from 0 to 1 of x² × 3x² dx = ∫ from 0 to 1 of 3x⁴ dx = [3x⁵/5] from 0 to 1 = 3/5.
  3. Variance. Var(X) = 3/5 - (3/4)² = 3/5 - 9/16. Common denominator 80: 48/80 - 45/80 = 3/80.
  4. Check. 3/80 is 0.0375. The variance is small because the density concentrates near 1, which keeps the values close together.

The Python block computes the mean and variance numerically, by adding up thin rectangles.

n = 100000
h = 1 / n
mids = [(i + 0.5) * h for i in range(n)]

def f(x):
    return 3 * x * x        # PDF on [0, 1]

mean = sum(x * f(x) * h for x in mids)
ex2 = sum(x * x * f(x) * h for x in mids)
var = ex2 - mean ** 2

print(f"E[X] = {mean:.4f}")
print(f"Var(X) = {var:.4f}")
E[X] = 0.7500
Var(X) = 0.0375

Key ideaContinuous expectation is the same recipe as discrete expectation: weight each value, then add. Only the addition becomes an integral.

TrapDo not multiply the PDF by x and then forget the x in the next moment. E[X²] uses x² f(x), not x f(x) squared. Write the weight out each time.

Self-check: for the uniform on [0, 1], f(x) = 1. What is E[X]?

E[X] = ∫ from 0 to 1 of x dx = [x²/2] from 0 to 1 = 1/2. This matches (0 + 1)/2.

Self-check: is a PDF with E[X] = 0.5 always symmetric about 0.5?

No. A mean of 0.5 does not force symmetry. Many different shapes can have the same mean.

Solved GATE-style problems

These problems are original GATE-style questions written for practice. They are not past paper questions. Work each one on paper first, then compare with the solution.

Bus arrival time

A bus arrives at a stop at a time X, uniform between 0 and 10 minutes after you reach the stop. Find P(X ≥ 7).

How to think about it

  1. What is asked. The chance that the bus takes at least 7 minutes.
  2. Which idea applies. Uniform probability is the length ratio (d - c)/(b - a).
  3. Work it out. The interval [7, 10] has length 3, and the full interval [0, 10] has length 10. So P(X ≥ 7) = 3/10 = 0.3.
  4. Check. The answer is between 0 and 1, and the interval 7 to 10 is less than half of 0 to 10, so 0.3 is below one half.

Answer: 0.3

Select all true statements about a density

Let f(x) = 0.5 for 0 ≤ x ≤ 2, and f(x) = 0 otherwise. Select all that apply.

(A) f is a valid PDF.
(B) P(X = 1) = 0.
(C) P(0 ≤ X ≤ 1) = 0.5.
(D) f(3) = 0.5.

How to think about it

  1. What is asked. Tick each true statement about this density.
  2. Which idea applies. PDF validity, the zero probability of a point, and areas over intervals.
  3. Work it out. Option A: the density is non-negative and its area is 0.5 × 2 = 1, so A is true. Option B: a single point has zero probability, so B is true. Option C: the area over [0, 1] is 0.5 × 1 = 0.5, so C is true. Option D: the density is 0 outside [0, 2], so f(3) = 0 and D is false.
  4. Check. Option D is false even though 0.5 is the density value on [0, 2]. Point 3 lies outside the interval, where the density is zero.

Answer: (A), (B) and (C) are true. Option (D) is false.

Finding the endpoints

X is uniform on [a, b] with a < b. Its mean is 4 and its variance is 3. Find a and b. Give the answer as two integers.

How to think about it

  1. What is asked. The endpoints a and b.
  2. Which idea applies. The uniform mean (a + b)/2 and variance (b - a)²/12, then solve the two equations.
  3. Work it out. From the mean: (a + b)/2 = 4, so a + b = 8. From the variance: (b - a)²/12 = 3, so (b - a)² = 36 and b - a = 6, since b > a. Adding the equations: 2b = 14, so b = 7. Then a = 8 - 7 = 1.
  4. Check. The mean of [1, 7] is (1 + 7)/2 = 4, and the variance is (7 - 1)²/12 = 36/12 = 3. Both match.

Answer: a = 1 and b = 7

Probability under a parabola

A random variable X has PDF f(x) = 3x² for 0 ≤ x ≤ 1, and 0 otherwise. Find P(X ≤ 0.5). Give the answer as a fraction.

How to think about it

  1. What is asked. The area under the density from 0 to 0.5.
  2. Which idea applies. P(X ≤ 0.5) = ∫ from 0 to 0.5 of 3x² dx.
  3. Work it out. The antiderivative of 3x² is x³. Evaluate: (0.5)³ - 0³ = 1/8 - 0 = 1/8.
  4. Check. The full area from 0 to 1 is 1³ = 1. The density is small near 0 and large near 1, so the left half should hold much less than half. 1/8 is small, which agrees.

Answer: 1/8

Mean of a falling line

NAT question. A random variable X has PDF f(x) = 2(1 - x) for 0 ≤ x ≤ 1, and 0 otherwise. Find E[X]. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. The mean of X, to two decimals.
  2. Which idea applies. E[X] = ∫ from 0 to 1 of x × 2(1 - x) dx.
  3. Work it out. Expand the integrand: 2x(1 - x) = 2x - 2x². The integral of 2x is x², and the integral of 2x² is 2x³/3. Evaluate from 0 to 1: (1² - 2 × 1³/3) - 0 = 1 - 2/3 = 1/3, which is 0.33 to two decimals.
  4. Check. The density is largest at 0 and falls to 0 at 1, so the mean should be below 0.5. The value 0.33 is below 0.5, which agrees.

Answer: 0.33

Finding the constant and a tail probability

A random variable X has PDF f(x) = c x² for 0 ≤ x ≤ 2, and 0 otherwise. Find the constant c and then P(X > 1). Give P(X > 1) as a fraction.

How to think about it

  1. What is asked. The constant c, then the probability that X exceeds 1.
  2. Which idea applies. The total area must be 1, which gives c. Then integrate from 1 to 2.
  3. Work it out. Total area: ∫ from 0 to 2 of c x² dx = c × [x³/3] from 0 to 2 = c × 8/3. Set this to 1, so c = 3/8. Then P(X > 1) = ∫ from 1 to 2 of (3/8) x² dx = (3/8) × [x³/3] from 1 to 2 = (1/8)(8 - 1) = 7/8.
  4. Check. The density rises towards 2, so the upper half should hold more than half the area. 7/8 is well above one half, which agrees.

Answer: c = 3/8 and P(X > 1) = 7/8

Variance of a squared density

A random variable X has PDF f(x) = 3x² for 0 ≤ x ≤ 1, and 0 otherwise. Find Var(X). Give the answer as a decimal to four places.

How to think about it

  1. What is asked. The variance of X.
  2. Which idea applies. Compute E[X] and E[X²] by integration, then Var(X) = E[X²] - (E[X])².
  3. Work it out. E[X] = ∫ from 0 to 1 of 3x³ dx = 3/4. E[X²] = ∫ from 0 to 1 of 3x⁴ dx = 3/5. Var(X) = 3/5 - (3/4)² = 3/5 - 9/16 = 48/80 - 45/80 = 3/80 = 0.0375.
  4. Check. The variance must be at most 1/4 for a variable on [0, 1], since the largest possible spread on an interval of length 1 is 1/4. The value 0.0375 is well below that, and it matches the Python check.

Answer: 0.0375

The median of a parabolic density

NAT question. A random variable X has PDF f(x) = 3x² for 0 ≤ x ≤ 1, and 0 otherwise. Find the median m, that is, the value with P(X ≤ m) = 1/2. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. The value m where the area to its left is exactly one half.
  2. Which idea applies. The CDF from 0 to m equals m³, so solve m³ = 1/2.
  3. Work it out. P(X ≤ m) = ∫ from 0 to m of 3x² dx = m³. Set m³ = 1/2, so m = (1/2)1/3 = 0.7937, which is 0.79 to two decimals.
  4. Check. Cube 0.79: 0.79³ = 0.493, which is just below 0.5, and 0.80³ = 0.512, which is just above. So m lies between 0.79 and 0.80, as required.

Answer: 0.79

Exam-level 1: Variance of a density that rises linearly (NAT, 2 marks)

NAT question. The lifetime X of a battery, in hours, has the density f(x) = kx for 0 ≤ x ≤ 2, and f(x) = 0 otherwise, where k is a constant. The density must describe a valid model, so its total area is 1. Find the variance of X. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. Var(X), to two decimal places, when k is not given.
  2. Which idea applies. A density integrates to 1, which gives k. Then E[X] = ∫ x f(x) dx, E[X²] = ∫ x² f(x) dx, and Var(X) = E[X²] - (E[X])².
  3. Work it out. ∫ from 0 to 2 of kx dx = k × 2 = 1, so k = 1/2. Then E[X] = ∫ from 0 to 2 of x (x/2) dx = (1/2) × 8/3 = 4/3. Also E[X²] = ∫ from 0 to 2 of x² (x/2) dx = (1/2) × 4 = 2. So Var(X) = 2 - (4/3)² = 2 - 16/9 = 2/9, which is about 0.22.
  4. Check. The variance is positive, and the mean 4/3 lies between 0 and 2, as it must. The variance 0.22 is small compared with the range of 2, which fits a density that is spread out but not very wide.

Answer: 0.22

from fractions import Fraction as F
def I(n):
    return F(2 ** (n + 1), n + 1)
k = 1 / I(1)
EX = k * I(2)
EX2 = k * I(3)
VX = EX2 - EX ** 2
print("k =", k)
print("E[X] =", EX)
print("E[X^2] =", EX2)
print("Var(X) =", VX, "=", round(float(VX), 2))
k = 1/2
E[X] = 4/3
E[X^2] = 2
Var(X) = 2/9 = 0.22

Exam-level 2: Conditioning on a uniform wait (MCQ, 2 marks)

The waiting time X, in minutes, at a bus stop is uniformly distributed on the interval from 2 to 10 minutes, so the density is 1/8 on that interval and 0 elsewhere. A passenger has already waited more than 3 minutes. Which of the following is the probability that the total waiting time is between 4 and 7 minutes, given this? (A) 3/8 (B) 3/7 (C) 1/2 (D) 4/7. Select one option.

How to think about it

  1. What is asked. P(4 ≤ X ≤ 7 | X > 3).
  2. Which idea applies. For a uniform on (a, b), the probability of an interval is its length divided by b - a, and conditional probability P(A | B) = P(A and B) / P(B).
  3. Work it out. P(X > 3) covers the interval from 3 to 10, which has length 7, so P(X > 3) = 7/8. The event 4 ≤ X ≤ 7 lies inside X > 3, and its length is 3, so P(4 ≤ X ≤ 7) = 3/8. Then P(4 ≤ X ≤ 7 | X > 3) = (3/8) / (7/8) = 3/7 ≈ 0.4286. The answer is option B.
  4. Check. The answer is below one half, which fits because the wait is spread over 8 minutes and the target interval is 3 minutes long. Why the other options fail: (A) forgets to condition, (C) is a guess at one half, and (D) uses the wrong interval length.

Answer: (B) 3/7

from fractions import Fraction as F
a, b = 2, 10
def P_between(lo, hi):
    lo = max(lo, a)
    hi = min(hi, b)
    return F(max(0, hi - lo), b - a)
pB = P_between(3, 10)
pAB = P_between(4, 7)
print("P(X exceeds 3) =", pB)
print("P(4 to 7) =", pAB)
print("P(4 to 7 given X exceeds 3) =", pAB / pB, "=", round(float(pAB / pB), 4))
P(X exceeds 3) = 7/8
P(4 to 7) = 3/8
P(4 to 7 given X exceeds 3) = 3/7 = 0.4286

Exam-level 3: Checking a density (MSQ, 2 marks)

A continuous random variable X has density f(x) = 3x² for 0 ≤ x ≤ 1, and f(x) = 0 otherwise. Select all the statements that are true.

  • (A) The density integrates to 1 over its support.
  • (B) P(X = 0.5) = 0.
  • (C) P(X ≤ 0.5) = 1/8.
  • (D) P(X ≤ 0.5) = 3/4.

How to think about it

  1. What is asked. Which of the four statements are true. Select all that apply.
  2. Which idea applies. The total area under a density is 1, a single point has probability 0 for a continuous variable, and probabilities are areas under the density: P(X ≤ c) = ∫ from 0 to c of f(x) dx.
  3. Work it out. ∫ from 0 to 1 of 3x² dx = x³ evaluated from 0 to 1 = 1, so (A) is true. A single point has zero area, so P(X = 0.5) = 0 and (B) is true. P(X ≤ 0.5) = ∫ from 0 to 0.5 of 3x² dx = (0.5)³ = 1/8, so (C) is true. Option (D) reads the density value f(0.5) = 3 × 0.25 = 3/4 as a probability, which is wrong.
  4. Check. A density can take values above 1, such as 3/4 here, while probabilities never do. That is the key difference, and it explains why (D) is a trap. The answer is A, B and C.

Answer: A, B and C

from fractions import Fraction as F
def G(x):
    return x ** 3
print("total area =", G(F(1)) - G(F(0)))
print("P(X = 0.5) =", G(F(1, 2)) - G(F(1, 2)))
print("P(X at most 0.5) =", G(F(1, 2)) - G(F(0)))
print("f(0.5) =", 3 * F(1, 2) ** 2)
total area = 1
P(X = 0.5) = 0
P(X at most 0.5) = 1/8
f(0.5) = 3/4

Exam-level 4: Median of a linear density (NAT, 2 marks)

NAT question. The time X, in minutes, that a customer spends at a counter has the density f(x) = c(x + 1) for 0 ≤ x ≤ 2, and f(x) = 0 otherwise, where c is a constant. Find the median waiting time, which is the value m such that P(X ≤ m) = 0.5. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. The median m, to two decimal places.
  2. Which idea applies. Find c so the total area is 1, then solve F(m) = ∫ from 0 to m of f(x) dx = 0.5 for m, which is a quadratic.
  3. Work it out. ∫ from 0 to 2 of c(x + 1) dx = c(2 + 2) = 4c = 1, so c = 1/4. Then F(m) = (1/4)(m²/2 + m) = 1/2 gives m² + 2m - 4 = 0. The positive root is m = -1 + √5 ≈ 1.2361, which is 1.24 to two decimal places.
  4. Check. The median lies in [0, 2]. The density rises with x, so more than half the probability lies above the midpoint 1, which means the median must be above 1. The value 1.24 is above 1. Also, substituting back, (1/4)(1.2361²/2 + 1.2361) = (1/4)(0.7639 + 1.2361) = 0.5.

Answer: 1.24

from math import sqrt
c = 1 / 4
def Fc(m):
    return c * (m * m / 2 + m)
lo, hi = 0.0, 2.0
for _ in range(60):
    mid = (lo + hi) / 2
    if Fc(mid) < 0.5:
        lo = mid
    else:
        hi = mid
print("c =", c)
print("F(2) =", Fc(2))
print("median =", round(lo, 4))
print("exact -1 + sqrt(5) =", round(-1 + sqrt(5), 4))
print("to 2 dp:", round(lo, 2))
c = 0.25
F(2) = 1.0
median = 1.2361
exact -1 + sqrt(5) = 1.2361
to 2 dp: 1.24

Summary

Continuous random variable
A quantity that can take any value in an interval.
PDF
A non-negative curve f(x) with total area 1. Probabilities are areas under it.
Probability as area
P(a ≤ X ≤ b) = ∫ from a to b of f(x) dx.
Point probability
P(X = c) = 0 for every single value c, because a point has zero width.
Density value
f(x) is not a probability, and it can exceed 1.
Integral
The area under a curve, computed with the antiderivative F(b) - F(a).
Power rule
∫ xk dx = xk+1/(k + 1) for k ≠ -1.
Continuous expectation
E[X] = ∫ x f(x) dx.
Second moment
E[X²] = ∫ x² f(x) dx.
Variance
Var(X) = E[X²] - (E[X])².
Uniform density
f(x) = 1/(b - a) on [a, b].
Uniform mean
E[X] = (a + b)/2.
Uniform variance
Var(X) = (b - a)²/12.
Median
The value m with P(X ≤ m) = 1/2.
Normalising constant
The factor c that makes the total area of a PDF equal to 1.

Remember these

  1. For a continuous variable, probabilities are areas under the PDF, never heights.
  2. A single point has probability zero, so the endpoints of an interval do not change the answer.
  3. A PDF must be non-negative and have total area 1.
  4. To find an unknown constant, set the total area to 1 and solve.
  5. For a uniform variable, a probability is a length ratio, (d - c)/(b - a).
  6. E[X] and E[X²] are integrals of x f(x) and x² f(x), and Var(X) = E[X²] - (E[X])².
  7. Always subtract the value at the lower limit when evaluating a definite integral.
