Computer Numerical Control (CNC)

Computer Numerical Control (CNC) is a machine tool that cuts metal or plastic by following a program of numbers and letters. A CNC machine repeats the same precise cut every time, which is why it is the workhorse of modern machining. GATE asks about its parts, its G-codes and M-codes, and its control types, and sometimes asks for a short time or speed calculation.

The idea in plain words

Imagine you must cut a square hole in a block of metal by hand. You mark the lines, hold the file, and push. Your result depends on your steady hand, your eye, and how tired you are. The second hole you cut may be a little different from the first.

Now imagine you write the instructions on a sheet of numbers: "move the cutter 10 mm right, then 10 mm down, then 10 mm left, then 10 mm up". A machine reads the sheet and does exactly that, every time, with the same speed and the same depth. This is the idea of numerical control. A CNC machine is a machine tool that is run by a computer, which reads a program of numbers and moves the tool and the work accordingly.

The program is written in a language that uses letters and numbers, such as G01 X10 Y20. The letters tell the machine what to do, and the numbers tell it where or how fast. This language is called G-code, and it is covered later on this page.

Key ideaA CNC machine follows a stored program, so the same cut is made in the same way every time, with very little dependence on the operator.

Where this appears in GATE

In the RA paper, CNC questions are mostly conceptual. You may be asked to name the parts of a CNC machine, to choose between open-loop and closed-loop control, or to read a G-code line. Some questions ask for a short calculation, such as the spindle speed, the cutting time, or the number of pulses for a stepper motor. This page covers both.

Key terms

Read these now. Each one is used again below.

Numerical control (NC)
Controlling a machine by numbers. Precise definition: the automatic control of machine tool motions from a program of coded instructions.
CNC
Computer numerical control. Precise definition: numerical control in which a built-in computer stores, reads, and executes the program.
Machine tool
The machine that removes material. Precise definition: the frame, table, spindle, and slides that hold and move the cutter or the workpiece.
Controller
The computer unit of a CNC machine. Precise definition: the unit that reads the program, works out the path of each axis, and sends commands to the drives.
Drive system
The motors and their power electronics. Precise definition: the servo or stepper motors, amplifiers, and screws that turn commands into motion.
Axis
A direction of motion. Precise definition: a straight line (X, Y, Z) or a rotation (A, B, C) along which a machine part can move.
Spindle
The rotating shaft that holds the cutting tool. Precise definition: the drive shaft that spins the tool at a set speed in revolutions per minute (rpm).
G-code
The code for motion instructions. Precise definition: the set of codes starting with the letter G that define how the tool moves, such as rapid, linear, or circular motion.
M-code
The code for machine functions. Precise definition: the set of codes starting with the letter M that switch things on or off, such as the spindle, coolant, or program end.
Feed rate (F)
The speed at which the tool moves while cutting. Precise definition: the travel speed of the tool relative to the work, in mm/min.
Spindle speed (S)
The rotation speed of the tool. Precise definition: the spindle rotation in rpm.
Cutting speed (Vc)
The speed at the edge of the tool. Precise definition: the distance the edge of the cutter travels across the work per minute, in m/min.
Open-loop control
Control without position feedback. Precise definition: a control method that sends commands to the motor and assumes the motor moved as commanded, without measuring the result.
Closed-loop control
Control with position feedback. Precise definition: a control method that measures the actual position with a sensor, usually an encoder, and corrects any error.
Encoder
A sensor that reports the angle or position. Precise definition: a device that outputs a signal proportional to the shaft or slide position.
Stepper motor
A motor that moves in fixed steps. Precise definition: a motor that turns through a set angle for each electrical pulse it receives.
Lead (of a screw)
The distance moved in one turn of a screw. Precise definition: the axial travel of a nut or slide for one full revolution of the lead screw, in mm.

What CNC is and its three main parts

Before CNC, machines were run by hand wheels and levers, or by cams and gears that were slow to change. A CNC machine replaces these with a stored program. To make a new part, you load a new program. The machine does not need to be rebuilt.

A CNC system has three main parts. Here is a text diagram.

   PROGRAM (G-code)
        |
        v
  +-------------+     commands     +----------------+     motion     +------------------+
  | CONTROLLER  | ---------------> | DRIVE SYSTEM   | -------------> | MACHINE TOOL     |
  | reads code, | <--------------- | motors, drives | <------------- | spindle, table,  |
  | plans path  |    feedback      | screws         |   position     | frame, tool      |
  +-------------+   (if closed     +----------------+   (if closed   +------------------+
                     loop)                              loop)

Read the diagram from left to right. The program enters the controller. The controller works out where each axis must go and sends commands to the drive system. The drive system turns the screws, and the machine tool moves. In closed-loop systems, a feedback signal returns from the machine to the controller so that errors can be corrected.

  • The controller is the brain. It reads each line of G-code, calculates the path, and handles timing and safety.
  • The drive system is the muscle. It contains motors, amplifiers, and ball screws that convert commands into movement.
  • The machine tool is the body. It is the frame, table, slides, spindle, and tool holder that actually cut the work.

TrapThe controller does not cut the metal. It only tells the drives where to go. A good controller on a weak machine tool still gives a poor part.

Question: Which part of a CNC system reads the program and works out the path?

The controller.

Question: What is the role of the drive system?

It contains the motors, amplifiers, and screws that turn the controller's commands into motion of the machine slides and spindle.

Axes of motion

A CNC machine moves in directions called axes. The standard names are:

  • X: left and right on the table (linear motion).
  • Y: front and back on the table (linear motion).
  • Z: up and down, the depth of the cut (linear motion).
  • A, B, C: rotations about the X, Y and Z axes. These are used for tilting or turning the work.

A simple 3-axis milling machine uses X, Y and Z. A 5-axis machine adds two rotations, so the tool can reach the work from almost any direction. More axes allow more complex shapes, such as a turbine blade, but the machine costs more and the program is harder to write.

TipCount the axes by asking, "how many independent directions can the tool or the work move?" A 3-axis machine has three linear directions and no rotations.

Question: How many axes does a basic milling machine have?

Three linear axes, X, Y and Z.

Question: What do the A, B and C axes do?

They rotate the work or the tool about the X, Y and Z axes, which allows machining of angled faces and complex shapes.

G-code and M-code basics

A CNC program is a list of lines, called blocks. Each block has words. A word is a letter followed by a number, such as X25 or F200. The two most common groups of words are G-codes and M-codes.

G-codes: how to move

  • G00: rapid positioning. The tool moves fast to a point, without cutting. Used for moves in the air.
  • G01: linear interpolation. The tool moves in a straight line at the feed rate F. Used for cutting.
  • G02: circular motion, clockwise.
  • G03: circular motion, counter-clockwise.
  • G90: absolute mode. Coordinates are measured from the programmed zero point.
  • G91: incremental mode. Each coordinate is measured from the current position.

M-codes: machine functions

  • M03: start the spindle clockwise.
  • M04: start the spindle counter-clockwise.
  • M05: stop the spindle.
  • M06: tool change.
  • M08: coolant on. M09: coolant off.
  • M30: end of program, rewind to the start.

Other letters carry values. S sets the spindle speed, F sets the feed rate, and T selects a tool. A typical block might read:

N10 G90 G00 X10 Y10 S1200 M03
N20 G01 Z-5 F100
N30 G01 X60 F240
N40 G00 Z10
N50 M05 M30

Read the program one line at a time. Line N10 sets absolute mode, moves quickly to X10 Y10, and starts the spindle at 1200 rpm. Line N20 cuts down 5 mm at 100 mm/min. Line N30 cuts along X to 60 mm at 240 mm/min. Line N40 lifts the tool. Line N50 stops the spindle and ends the program.

Key ideaG01 and G00 look alike, but G01 cuts and uses the feed rate F, while G00 moves fast in the air and ignores F.

TrapG00, G01, G02 and G03 are modal. This means a G-code stays active until another code in the same group replaces it. In the example, line N30 needed only X, because G01 was still active from line N20.

Question: Which code moves the tool in a straight cutting line at a set feed?

G01, linear interpolation with feed F.

Question: Which M-code starts the spindle turning clockwise?

M03.

Open-loop and closed-loop control

How does the machine know it has moved to the right place? There are two main answers.

Open-loop control

In open-loop control, the controller sends a number of pulses to a stepper motor. Each pulse makes the motor turn one step. The controller assumes the motor moved exactly that number of steps, and it does not check the result. This is simple and cheap. It works well when the load is light and steady.

The weakness is that a stepper motor can lose steps if the load is too heavy or the motion is too fast. The controller still counts the pulses, so it believes the table is in the right place, but it is not.

Closed-loop control

In closed-loop control, an encoder measures the actual position and sends it back to the controller. The controller compares the actual position with the commanded position. Any difference, called the position error, is used to correct the motor. The result is more accurate, and lost steps or slipping are detected. The cost is higher, because the encoder and the more complex control add expense.

error = commanded position − measured position

Here the error is in mm (or degrees), and the controller acts to drive the error to zero.

Question: Why can an open-loop stepper motor end up in the wrong place without any warning?

Because it has no position feedback. If it loses a step under load, the controller still counts the pulses it sent, so it does not know the position is wrong.

Question: What is the job of the encoder in a closed-loop system?

It measures the actual position, so the controller can compare it with the commanded position and correct the error.

Speed, feed and time calculations

Spindle speed from cutting speed

The tool must turn fast enough so that its edge cuts at the right speed. The cutting speed Vc is the speed of the edge, in m/min. For a tool of diameter D (in mm), the spindle speed in rpm is:

N = 1000 × Vc / (π × D)

Here N is the spindle speed in rpm, Vc is the cutting speed in m/min, and D is the tool diameter in mm. The factor 1000 converts metres to millimetres, because D is in mm. The number π × D is the distance around the tool in one turn, in mm.

Worked example. A 20 mm tool cuts at 60 m/min. Find the spindle speed.

  1. Distance around one turn. π × 20 = 62.83 mm.
  2. Convert the cutting speed. 60 m/min = 60 000 mm/min.
  3. Divide. N = 60 000 / 62.83 = 954.9 rpm.
  4. Check. At 954.9 rpm, one turn takes 1 / 954.9 min, which is about 0.0628 s. In that time the edge travels π × 20 = 62.83 mm. That is about 1000 mm/s, which is 60 000 mm/min. This matches.
import math
vc = 60.0
d = 20.0
n = 1000 * vc / (math.pi * d)
print("Spindle speed (rpm):", round(n, 1))
Spindle speed (rpm): 954.9

Cutting time from feed rate

The time to cut a path is the length of the path divided by the feed rate. With the feed in mm/min, the time comes out in minutes:

t = L / F

Worked example. A cut is 120 mm long at a feed of 240 mm/min. The time is 120 / 240 = 0.5 min, which is 30 s. The rapid moves in the air take extra time, so the total cycle is always longer than the cutting time alone.

Steps per millimetre for a stepper motor

For an open-loop axis, the controller needs to know how many pulses give one millimetre of table travel. The steps per mm are:

steps per mm = (steps per revolution × microsteps) / lead

Here the lead is the distance moved per screw turn, in mm. Microstepping divides each full step into smaller steps, which gives finer positioning.

Worked example. A motor makes 200 full steps per turn, with 16 microsteps per step. The screw lead is 5 mm. The steps per mm are 200 × 16 / 5 = 640. To move 25 mm, the controller sends 25 × 640 = 16 000 pulses.

steps_per_rev = 200
microsteps = 16
lead_mm = 5.0
steps_per_mm = steps_per_rev * microsteps / lead_mm
print("Steps per mm:", steps_per_mm)
print("Steps for 25 mm:", round(25 * steps_per_mm))
Steps per mm: 640.0
Steps for 25 mm: 16000

TrapFeed rate F is in mm/min, but a time in seconds needs the answer multiplied by 60. Forgetting this gives a cutting time 60 times too small or too large.

Question: A tool of diameter 10 mm cuts at 30 m/min. What is the spindle speed, to the nearest rpm?

N = 1000 × 30 / (π × 10) = 30 000 / 31.42 = 954.9, which is about 955 rpm.

Question: A cut of 90 mm at a feed of 180 mm/min takes how many seconds?

t = 90 / 180 = 0.5 min = 30 s.

Solved GATE-style problems

These are original GATE-style practice problems, not real past exam questions. Try each one before reading the method.

Which code for a cutting move?

A program must cut a straight line in the work at a feed of 150 mm/min. Which G-code should the line use?

(A) G00   (B) G01   (C) G02   (D) G90

How to think about it

  1. What is asked. The G-code for a straight cutting move at a set feed.
  2. Which idea applies. G01 is linear motion at feed F. G00 is rapid motion without cutting. G02 is a circle. G90 is absolute mode.
  3. Work it out. The move is straight, cutting, and uses a feed. That is G01.
  4. Check. G00 ignores the feed, so it is wrong for cutting.

Answer: (B) G01.

Which M-code?

Which M-code stops the spindle?

(A) M03   (B) M05   (C) M08   (D) M30

How to think about it

  1. What is asked. The M-code that stops the spindle.
  2. Which idea applies. M03 starts the spindle clockwise. M08 turns coolant on. M30 ends the program.
  3. Work it out. The code that stops the spindle is M05.
  4. Check. The list has one start code (M03), one coolant code (M08), and one end code (M30), which leaves M05.

Answer: (B) M05.

Open-loop or closed-loop? (select all that apply)

Select all the statements that are correct.

(A) An open-loop stepper system uses an encoder to check the position.   (B) A closed-loop system can detect a lost step.   (C) An open-loop system is usually cheaper than a closed-loop system.   (D) A closed-loop system never makes a position error.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. Open-loop has no feedback. Closed-loop uses feedback to correct errors, at higher cost.
  3. Work it out. (A) False, open-loop has no encoder. (B) True. (C) True. (D) False, closed-loop reduces errors but does not make them impossible, because the sensor and the drive still have limits.
  4. Check. Statement (D) uses "never", which is a strong word that is usually wrong in engineering.

Answer: (B) and (C).

Spindle speed for a larger tool

A 50 mm face mill cuts at a cutting speed of 100 m/min. Find the spindle speed in rpm, to one decimal place.

How to think about it

  1. What is asked. The spindle speed N in rpm.
  2. Which idea applies. N = 1000 × Vc / (π × D).
  3. Work it out. N = 1000 × 100 / (π × 50) = 100 000 / 157.08 = 636.6 rpm.
  4. Check. A larger tool turns slower at the same cutting speed. The 20 mm tool gave 954.9 rpm at 60 m/min. A 50 mm tool at 60 m/min would turn at 954.9 × 20 / 50 = 381.96 rpm. Raising the cutting speed to 100 m/min multiplies this by 100 / 60, which gives 636.6 rpm. This matches.
import math
vc = 100.0
d = 50.0
n = 1000 * vc / (math.pi * d)
print("Spindle speed (rpm):", round(n, 1))
Spindle speed (rpm): 636.6

Answer: 636.6 rpm.

Time for a cut

A straight cut of 75 mm is made at a feed of 150 mm/min. Find the cutting time in seconds.

How to think about it

  1. What is asked. The time in seconds.
  2. Which idea applies. t = L / F gives minutes when L is in mm and F in mm/min. Then multiply by 60.
  3. Work it out. t = 75 / 150 = 0.5 min. In seconds, 0.5 × 60 = 30 s.
  4. Check. At 150 mm/min the tool covers 2.5 mm per second, and 75 mm takes 75 / 2.5 = 30 s. This matches.

Answer: 30 s.

Stepper pulses for a move

A stepper motor makes 400 full steps per turn, and each step is split into 8 microsteps. The lead of the screw is 4 mm. How many pulses must the controller send to move the table 18 mm?

How to think about it

  1. What is asked. The number of pulses for 18 mm.
  2. Which idea applies. Steps per mm = (steps per rev × microsteps) / lead. Pulses = distance × steps per mm.
  3. Work it out. Steps per rev with microsteps = 400 × 8 = 3200. Steps per mm = 3200 / 4 = 800. Pulses = 18 × 800 = 14 400.
  4. Check. One turn of 4 mm needs 3200 pulses. 18 mm is 4.5 turns, and 4.5 × 3200 = 14 400, which matches.
steps_per_rev = 400
microsteps = 8
lead_mm = 4.0
distance_mm = 18.0
steps_per_mm = steps_per_rev * microsteps / lead_mm
print("Pulses for 18 mm:", round(distance_mm * steps_per_mm))
Pulses for 18 mm: 14400

Answer: 14 400 pulses.

Trace the program position

A program starts at the origin, X = 0 and Y = 0. The blocks are: (1) G90 G00 X10 Y10; (2) G91 G01 X5 Y-3 F200; (3) X5; (4) G90 X2. Assume the G-code groups stay active until changed. Find the final X and Y, in mm.

How to think about it

  1. What is asked. The final position.
  2. Which idea applies. G90 is absolute and G91 is incremental. Each coordinate in G91 adds to the current position. G-codes stay active until changed.
  3. Work it out. Block 1 (absolute): X = 10, Y = 10. Block 2 (incremental, G91): X = 10 + 5 = 15, Y = 10 − 3 = 7. Block 3 (still G91, so incremental): X = 15 + 5 = 20, Y stays 7. Block 4 (G90, absolute): X = 2, and Y is not written so it stays 7.
  4. Check. The final position is (2, 7). The Python trace below gives the same values.
x, y = 0.0, 0.0
x, y = 10.0, 10.0
print("after G90 X10 Y10:", x, y)
x, y = x + 5, y - 3
print("after G91 X5 Y-3:", x, y)
x = x + 5
print("after G91 X5:", x, y)
x = 2.0
print("after G90 X2:", x, y)
after G90 X10 Y10: 10.0 10.0
after G91 X5 Y-3: 15.0 7.0
after G91 X5: 20.0 7.0
after G90 X2: 2.0 7.0

Answer: X = 2 mm and Y = 7 mm.

Statements about G-code and CNC (select all that apply)

Select all the statements that are correct.

(A) G00 moves the tool at rapid speed, and is used for moves in the air.   (B) G02 is a counter-clockwise circular move.   (C) M03 starts the spindle clockwise.   (D) M30 ends the program and rewinds it to the start.

How to think about it

  1. What is asked. Which statements about codes are true.
  2. Which idea applies. G00 is rapid. G02 is clockwise, G03 is counter-clockwise. M03 is clockwise spindle start. M30 ends the program.
  3. Work it out. (A) True. (B) False, G02 is clockwise, and G03 is counter-clockwise. (C) True. (D) True.
  4. Check. Statement (B) swaps G02 and G03, which is the common trap.

Answer: (A), (C) and (D).

Exam-level practice

Exam-level 1: Feed and speed (NAT, 2 marks)

A CNC turning job at cutting speed 120 m/min on a bar of diameter 50 mm. Find the spindle speed in rpm, correct to 0 decimal places.

How to think about it

  1. What is asked. N = 1000V/(πD).
  2. Which idea applies. Units: V in m/min, D in mm.
  3. Work it out. 120000/(π · 50) = 764 rpm.
  4. Check. The code computes it.
import math
print("%.0f" % (1000 * 120 / (math.pi * 50)))

764

Answer: about 764 rpm.

Exam-level 2: Ballscrew resolution (NAT, 2 marks)

A ballscrew of pitch 5 mm is driven through a 2:1 reduction by a stepper with 200 steps/rev. Find the linear resolution in µm.

How to think about it

  1. What is asked. Table travel per step.
  2. Which idea applies. Steps per screw rev = 400.
  3. Work it out. 5/400 = 0.0125 mm = 12.5 µm.
  4. Check. A finer pitch would improve it.

Answer: 12.5 µm.

Exam-level 3: G codes (MSQ, 2 marks)

Which are TRUE? (A) G01 is linear interpolation. (B) G02 is clockwise circular interpolation. (C) G00 is rapid positioning. (D) M03 stops the spindle.

How to think about it

  1. What is asked. Standard codes.
  2. Which idea applies. M03 is spindle on clockwise; M05 stops it.
  3. Work it out. (A), (B), (C) are true. (D) False.
  4. Check. G90 and G91 set absolute and incremental modes.

Answer: (A), (B) and (C).

Remember these

  1. CNC runs a stored program, so each part is made the same way.
  2. G01 cuts at feed F. G00 moves fast in the air.
  3. G02 is clockwise and G03 is counter-clockwise.
  4. M03 starts the spindle, M05 stops it, and M30 ends the program.
  5. Open-loop control has no feedback, so lost steps go unnoticed. Closed-loop control uses an encoder to correct errors.
  6. Spindle speed N = 1000 × Vc / (π × D), with D in mm.
  7. Cutting time from t = L / F is in minutes when F is in mm/min.
