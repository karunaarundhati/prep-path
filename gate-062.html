Finite differences

A finite difference is the change in a function between neighbouring points that are equally spaced. Differences let us estimate derivatives from a table of values, and they let us build Newton's interpolation formulas, which estimate values between table entries. This page builds the difference table step by step and shows the GATE-style calculations.

The idea in plain words

Suppose a sensor records the temperature of a motor every minute. You have a list of numbers, but no formula. How fast is the temperature rising? To answer, you look at how much it changed from one minute to the next. Those changes are differences. A difference of two neighbouring values is the simplest way to measure change.

Now imagine that the change itself is recorded too. The differences of differences are the second differences. They tell you whether the rise is speeding up or slowing down. An analogy helps: if your car's odometer is read every second, the differences give the distance per second, which is the speed. The differences of those differences give how the speed changes.

A difference table lays out all these layers in neat columns. It is a quick way to see the pattern in a table of data. A striking fact follows. If the data come from a polynomial of degree n, the n-th differences are all the same, and the next layer is all zero. This lets us find the polynomial that fits the table.

Why this matters for GATE. In the Robotics and Automation paper, you may be given a table of values from a sensor or a simulation, and asked to estimate a derivative or a value between table entries. Building the difference table by hand is the core skill, and it is fast once you see the pattern.

Key terms

Read this list once now. Come back to it when a symbol is unfamiliar.

Step size h
The fixed gap between neighbouring x-values, so xi+1 = xi + h.
Equally spaced points
Points x0, x0 + h, x0 + 2h, and so on. Newton's formulas need this.
Forward difference Δ
Δyi = yi+1 - yi. It looks forward to the next point.
Backward difference ∇
∇yi = yi - yi-1. It looks back to the previous point.
Central difference δ
δyi = yi+1/2 - yi-1/2. It is centred between two points, and it is written with half-step indices.
Second difference
A difference of differences. Δ2yi = Δyi+1 - Δyi.
Difference table
A table where each column is the difference of the column before, with the first entries of each column read off along a diagonal.
Degree of a polynomial
The highest power of x in a polynomial. For example, x3 + 2x has degree 3.
Numerical differentiation
Estimating a derivative from a table of values rather than from a formula.
Interpolation
Estimating a value between table entries by fitting a curve through them.
Newton's forward formula
An interpolation formula that starts at the first point and uses forward differences.
Newton's backward formula
An interpolation formula that starts at the last point and uses backward differences.
Truncation error
The error made by stopping a formula after a few terms or by approximating a derivative with a difference.

Step 1: Forward, backward and central differences

Equally spaced points

Most table-based methods use points spaced by a fixed step h. If x0 = 0 and h = 1, the points are x = 0, 1, 2, 3, and so on. If h = 0.5, the points are 0, 0.5, 1, 1.5. The corresponding values are written y0, y1, y2, and so on, where yi = f(xi).

The three basic differences

Forward: Δyi = yi+1 - yi
Backward: ∇yi = yi - yi-1
Central: δyi = yi+1/2 - yi-1/2

Read the forward difference in words: "the next value minus the current value". The backward difference is "the current value minus the previous value". The central difference is taken across the point, using the values half a step either side. In practice, central differences are often written with two whole steps, as yi+1 - yi-1, which spans the same centred interval.

Worked example 1: differences of a short table

Take the table x = 0, 1, 2, 3 and y = 1, 3, 7, 13.

  1. Forward difference at i = 0. Δy0 = y1 - y0 = 3 - 1 = 2.
  2. Forward difference at i = 1. Δy1 = 7 - 3 = 4.
  3. Forward difference at i = 2. Δy2 = 13 - 7 = 6.
  4. Backward difference at i = 3. ∇y3 = y3 - y2 = 13 - 7 = 6. Notice that this equals Δy2. In general, ∇yi = Δyi-1, so the two kinds of difference are the same numbers shifted by one place.

Key ideaForward and backward differences are the same numbers shifted by one place. Choose whichever one fits the formula in the question, and do not mix them up.

Second differences

The second forward difference is the difference of the first differences. For the table above, the first differences are 2, 4, 6, and the second differences are Δ2y0 = 4 - 2 = 2 and Δ2y1 = 6 - 4 = 2. The constant second difference tells us the table is quadratic. The formula that fits the table exactly is y = x2 + x + 1. Check: at x = 2, 4 + 2 + 1 = 7, which matches.

TrapA difference is always the later value minus the earlier one. Students often reverse the order, which flips the sign. For Δyi, the answer is yi+1 minus yi, never the other way round.

Question: For y = 2, 5, 10, 17 at x = 0, 1, 2, 3, what is Δy1?

Δy1 = y2 - y1 = 10 - 5 = 5.

Question: Why does the backward difference at i equal the forward difference at i - 1?

Both measure the change between the same two neighbouring points. ∇yi = yi - yi-1 and Δyi-1 = yi - yi-1 are identical.

Step 2: Building a difference table

Method

A difference table has one column for each order of difference. Start with the values y in the first column. Each entry in the next column is the difference of two neighbours in the column before. Keep going until one entry is left.

  1. Write the y-values in the first column.
  2. Subtract each pair of neighbours to fill the first-difference column.
  3. Subtract each pair in the first-difference column to fill the second-difference column.
  4. Continue until the column has a single entry. Each column is one shorter than the one before.

Worked example 2: the cubes

Take y = x3 at x = 0, 1, 2, 3, 4. The values are 0, 1, 8, 27, 64. Build the table.

  1. First differences. 1 - 0 = 1, 8 - 1 = 7, 27 - 8 = 19, 64 - 27 = 37.
  2. Second differences. 7 - 1 = 6, 19 - 7 = 12, 37 - 19 = 18.
  3. Third differences. 12 - 6 = 6, 18 - 12 = 6. Both are equal.
  4. Fourth differences. 6 - 6 = 0.

The third differences are constant at 6, and the fourth differences are zero. This is the signature of a cubic polynomial. The program builds the table automatically.

def difference_table(y):
    table = [y]
    while len(table[-1]) > 1:
        last = table[-1]
        table.append([last[i + 1] - last[i] for i in range(len(last) - 1)])
    return table

xs = [0, 1, 2, 3, 4]
ys = [x ** 3 for x in xs]
for level, row in enumerate(difference_table(ys)):
    print("order", level, row)
order 0 [0, 1, 8, 27, 64]
order 1 [1, 7, 19, 37]
order 2 [6, 12, 18]
order 3 [6, 6]
order 4 [0]

Key ideaIf the n-th differences are constant and the (n + 1)-th differences are zero, the data came from a polynomial of degree n. The cubes show this: the third differences are constant at 6, and the fourth are zero.

TipWrite the table with the differences lined up between the values they come from. Each new entry sits halfway between two entries above it, so a misplaced entry is easy to spot.

Question: A table of 6 equally spaced points has its first differences listed. How many entries does the second-difference column have?

Four. Each column has one fewer entry than the column before, so 6 values give 5 first differences and 4 second differences.

Question: The third differences of a table are all equal to 12. What can you say about the table?

The values are consistent with a cubic polynomial, with a leading coefficient of 12/(3! h3) = 2/h3. The fourth differences are zero if the data came exactly from a cubic.

Step 3: Numerical differentiation from differences

The idea

A derivative is a slope, and a slope is a change divided by a step. So a difference divided by the step size gives an estimate of the derivative. Three standard formulas follow:

Forward: f'(x) ≈ (f(x + h) - f(x))/h = Δy/h
Backward: f'(x) ≈ (f(x) - f(x - h))/h = ∇y/h
Central: f'(x) ≈ (f(x + h) - f(x - h))/(2h)

Each one is an approximation. The error depends on the step size h. The forward and backward formulas have an error proportional to h, written O(h). The central formula has an error proportional to h2, written O(h2). For small h, that makes the central formula much more accurate.

For the second derivative, a common formula is f''(x) ≈ (f(x + h) - 2f(x) + f(x - h))/h2. It uses the second difference divided by h2.

Worked example 3: the derivative of x squared at x = 1

Let f(x) = x2, so f'(1) = 2. Use h = 0.1. The values needed are f(0.9) = 0.81, f(1) = 1, and f(1.1) = 1.21.

  1. Forward. (f(1.1) - f(1))/0.1 = (1.21 - 1)/0.1 = 0.21/0.1 = 2.1. The error is 0.1.
  2. Central. (f(1.1) - f(0.9))/0.2 = (1.21 - 0.81)/0.2 = 0.4/0.2 = 2.0. The error is 0.
  3. Why central is exact here. The central error depends on the third derivative, which is zero for a quadratic. So the central formula is exact for any quadratic.
def f(x):
    return x * x

x, h = 1.0, 0.1
forward = (f(x + h) - f(x)) / h
central = (f(x + h) - f(x - h)) / (2 * h)
print("forward:", round(forward, 6))
print("central:", round(central, 6))
print("true value:", 2 * x)
forward: 2.1
central: 2.0

TrapSmaller h is not always better in hand calculations. When h is tiny, f(x + h) and f(x) are almost equal, and their difference loses accuracy. Pick h of moderate size, such as 0.1 or 0.01, when working from a table.

Question: Which derivative formula is exact for any quadratic polynomial?

The central difference (f(x + h) - f(x - h))/(2h). Its error depends on f''', which is zero for quadratics.

Question: The forward difference of f(x) = x2 at x = 2 with h = 1 is what value?

(f(3) - f(2))/1 = 9 - 4 = 5. The true derivative is 4, so the error is 1, which equals h because f'' = 2.

Step 4: Newton's forward and backward interpolation

The aim

Interpolation means estimating a value between the points of a table. Newton's formulas do this by writing the answer as a sum of differences, multiplied by factors that depend on how far you are from the start. Let s be the number of steps from the starting point:

Forward: s = (x - x0)/h, and p(x) = y0 + sΔy0 + s(s - 1)/2! Δ2y0 + s(s - 1)(s - 2)/3! Δ3y0 + ...
Backward: s = (x - xn)/h, and p(x) = yn + s∇yn + s(s + 1)/2! ∇2yn + s(s + 1)(s + 2)/3! ∇3yn + ...

Here 2! means 2 factorial, which is 2, and 3! is 6. The forward formula starts at the first point, x0, and uses the top diagonal of the table. The backward formula starts at the last point, xn, and uses the bottom diagonal. Use forward for an x near the start and backward for an x near the end.

Worked example 4: forward at x = 1.5

Use the table x = 0, 1, 2, 3 and y = 1, 3, 7, 13, with h = 1. Find the value at x = 1.5.

  1. Differences from the top. y0 = 1, Δy0 = 2, Δ2y0 = 2, Δ3y0 = 0.
  2. Find s. s = (1.5 - 0)/1 = 1.5.
  3. Substitute. p = 1 + 1.5 × 2 + (1.5)(0.5)/2 × 2 + 0 = 1 + 3 + 0.75 = 4.75.
  4. Check. The table fits y = x2 + x + 1, and at x = 1.5 this gives 2.25 + 1.5 + 1 = 4.75. The formula is exact here.

Worked example 5: backward at x = 2.5

Use the same table, now starting from the last point, x3 = 3. Find the value at x = 2.5.

  1. Differences from the bottom. y3 = 13, ∇y3 = 6, ∇2y3 = 2, ∇3y3 = 0.
  2. Find s. s = (2.5 - 3)/1 = -0.5. The negative sign shows that x is before the last point.
  3. Substitute. p = 13 + (-0.5)(6) + (-0.5)(0.5)/2 × 2 + 0 = 13 - 3 - 0.25 = 9.75.
  4. Check. y = x2 + x + 1 at 2.5 gives 6.25 + 2.5 + 1 = 9.75, which matches.

Worked example 6: the cubes at x = 2.5

Take y = x3 at x = 0, 1, 2, 3, 4, with h = 1. The forward differences from the top are y0 = 0, Δy0 = 1, Δ2y0 = 6, Δ3y0 = 6. At x = 2.5, s = 2.5. Then:

p = 0 + 2.5(1) + (2.5)(1.5)/2 × 6 + (2.5)(1.5)(0.5)/6 × 6 = 2.5 + 11.25 + 1.875 = 15.625

The true value is 2.53 = 15.625. Because the data are exactly cubic, the formula gives the exact answer. The program below confirms both examples and this one.

def differences_from_first(ys):
    diffs = [ys[0]]
    row = ys[:]
    for _ in range(1, len(ys)):
        row = [row[i + 1] - row[i] for i in range(len(row) - 1)]
        diffs.append(row[0])
    return diffs

def differences_from_last(ys):
    diffs = [ys[-1]]
    row = ys[:]
    for _ in range(1, len(ys)):
        row = [row[i + 1] - row[i] for i in range(len(row) - 1)]
        diffs.append(row[-1])
    return diffs

def newton_forward(ys, s):
    total, term = 0.0, 1.0
    for k, d in enumerate(differences_from_first(ys)):
        total += term * d
        term *= (s - k) / (k + 1)
    return total

def newton_backward(ys, s):
    total, term = 0.0, 1.0
    for k, d in enumerate(differences_from_last(ys)):
        total += term * d
        term *= (s + k) / (k + 1)
    return total

ys = [1, 3, 7, 13]
print("forward at x = 1.5:", newton_forward(ys, (1.5 - 0) / 1))
print("backward at x = 2.5:", newton_backward(ys, (2.5 - 3) / 1))
print("cubes at x = 2.5:", newton_forward([0, 1, 8, 27, 64], 2.5))
forward at x = 1.5: 4.75
backward at x = 2.5: 9.75
cubes at x = 2.5: 15.625

GATE loves thisNewton's formula with k terms is exact for any polynomial of degree less than k. If the k-th differences are constant, the formula is exact. Otherwise the error is about the first neglected difference term.

TrapUsing s = (x - x0)/h in the backward formula, or the wrong starting value, gives a wrong answer with no warning. Write the starting point and s on the first line of your working.

Question: Which formula should you use to interpolate at x = 3.8 from a table that runs from x = 0 to x = 4?

Newton's backward formula, because x = 3.8 is close to the last point, x = 4. It is the formula that starts from the bottom of the table.

Question: A table has a constant third difference of 6 and zero fourth differences. Which formula is exact for interpolation?

Newton's formula with terms up to the third differences. The data are exactly cubic, so the formula gives the exact value at any point.

Solved GATE-style problems

These problems are original, written in the style of GATE questions. They are not past exam questions. Try each one on paper before you read the answer.

A second difference from a table

The values of y at x = 0, 1, 2, 3 are 2, 5, 10, 17. Find Δ2y0. (Answer type: NAT, a whole number.)

How to think about it

  1. What is asked. The second forward difference starting at the first point.
  2. Which idea applies. Build the first differences, then take their differences.
  3. Work it out. First differences: 5 - 2 = 3, 10 - 5 = 5, 17 - 10 = 7. Second differences: 5 - 3 = 2 and 7 - 5 = 2. So Δ2y0 = 2.
  4. Check. The second differences are constant, so the table is quadratic, consistent with y = x2 + 2.

Answer: 2.

Select all the statements that are true.

  2. Which idea applies. Newton's forward formula, with s = 2.5.

Forward derivative of the exponential

Let f(x) = ex. Use the forward difference with h = 0.1 to estimate f'(0). Give the answer rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The forward estimate of the slope at x = 0.
  2. Which idea applies. f'(0) ≈ (f(0.1) - f(0))/0.1.
  3. Work it out. f(0.1) = e0.1 ≈ 1.105171, and f(0) = 1. So the estimate is (1.105171 - 1)/0.1 ≈ 1.05171.
  4. Check. The true derivative is e0 = 1, so the error is about 0.052, roughly h/2 times f''(0) = 0.05.
import math

print(round((math.exp(0.1) - 1) / 0.1, 4))
1.0517

Answer: 1.0517.

Central derivative of the exponential

Let f(x) = ex. Use the central difference with h = 0.1 to estimate f'(0). Give the answer rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The central estimate of the slope at x = 0.
  2. Which idea applies. f'(0) ≈ (f(0.1) - f(-0.1))/0.2.
  3. Work it out. f(0.1) ≈ 1.105171 and f(-0.1) = e-0.1 ≈ 0.904837. The difference is 0.200334, and dividing by 0.2 gives about 1.00167.

Backward interpolation near the end of a cubic table

The values of y at x = 1, 2, 3, 4 are 1, 8, 27, 64. Use Newton's backward formula with terms up to ∇3yn (with h = 1) to estimate y at x = 3.5. Give the exact fraction. (Answer type: NAT, a fraction.)

How to think about it

  1. What is asked. An estimate at x = 3.5, near the end of the table.
  2. Which idea applies. Backward formula with the last point xn = 4 and s = (3.5 - 4)/1 = -1/2.
  3. Work it out. From the bottom: yn = 64, ∇yn = 37, ∇2yn = 18, ∇3yn = 6. Then p = 64 + (-1/2)(37) + (-1/2)(1/2)/2 × 18 + (-1/2)(1/2)(3/2)/6 × 6 = 64 - 18.5 - 2.25 - 0.375 = 42.875.

Which statements about difference tables are true?

Select all the statements that are true, for equally spaced data.

(A) If all fourth differences of a table are zero, the table fits a polynomial of degree at most 3.
(B) Newton's forward formula needs the points to be equally spaced and taken from the starting point onwards.
(C) The error of the central derivative formula is proportional to h.
(D) For y = x2 with h = 1, the forward difference at x = 1 is 3.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which general statements about difference tables are true.
  2. Which idea applies. Polynomial detection, the setup of Newton's formula, the error orders, and a direct computation.
  3. Work it out. (A) True: zero fourth differences mean the data are exactly a cubic. (B) True. (C) False: the central formula's error is proportional to h2. (D) True: y(2) - y(1) = 4 - 1 = 3.
  4. Check. Statement (C) is the usual mistake. The central formula cancels the first-order error, which is why it is more accurate.

Answer: (A), (B) and (D).

Exam-level 3: Operator identities (MSQ, 2 marks)

With Δ the forward, ∇ the backward difference and E the shift operator, which are TRUE? (A) Δ = E − 1 (B) ∇ = 1 − E−1 (C) Δ∇ = Δ − ∇ (D) E = ehD, where D is differentiation

How to think about it

  1. What is asked. Standard operator relations.
  2. Which idea applies. Ef(x) = f(x + h). Taylor's theorem gives E = ehD.
  3. Work it out. (A) True. (B) True. (C) Δ∇ = (E − 1)(1 − E−1) = E − 2 + E−1, and Δ − ∇ = E − 1 − 1 + E−1, the same. True. (D) True.
  4. Check. All four are standard identities.

Answer: (A), (B), (C) and (D).

Remember these

  1. Forward difference is the next value minus the current value. Backward is the current value minus the previous value.
  2. If the third differences are constant and the fourth are zero, the data are exactly cubic.
  3. The central derivative formula is more accurate than the forward formula, because its error is O(h2).
  4. Use Newton's forward formula near the start of a table and backward near the end.
  5. Write the starting point and s before you substitute into a Newton formula.
  6. Build the difference table carefully, one column at a time.
