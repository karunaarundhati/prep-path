Laplace Transforms

The Laplace transform turns a hard calculus problem about a changing function into an easier algebra problem about a new function. This page builds the idea from zero, gives the standard table, the rules that make it work, the inverse transform with partial fractions, and the method for solving differential equations with initial conditions.

The idea in plain words

Differentiation and integration are the two big tools of calculus. They are powerful, but they can be messy. Solving a differential equation by hand often means guessing a form, differentiating it, and matching terms. That is slow, and it is easy to make a mistake.

The Laplace transform offers a different path. Think of it as a translator. You give it a function of time, written f(t), and it gives you back a new function of a new variable s, written F(s). The translation has a special property. Derivatives in the original world become simple multiplications in the new world. A differential equation becomes an ordinary algebra equation. You solve the algebra, then translate back.

Here is an everyday analogy. Suppose you need to multiply two very large numbers. You might take logarithms, add the logarithms, then take the exponential. Addition is easier than multiplication. The Laplace transform plays the same role for differential equations. It moves the hard part into an easier space, does the work there, and brings the answer back.

The overall method has three steps:

  1. Transform every term of the differential equation, using the initial conditions.
  2. Solve the resulting algebra equation for F(s).
  3. Apply the inverse transform to get y(t).

Why this matters for GATE. The Robotics and Automation paper uses Laplace transforms in control systems, where a transfer function is a ratio of Laplace transforms. Questions often ask for a transform from the table, an inverse transform with partial fractions, or the solution of an initial value problem. These are quick marks if you know the table and the rules.

Key terms

Read this list once now. You will come back to it often.

Function of time
A rule that gives a value for each time t, such as f(t) = t2. Time starts at t = 0 and runs forward.
Laplace transform
The new function F(s) = ∫0∞ e-st f(t) dt. It is written L{f(t)} or F(s).
Integral
A way of adding up many tiny pieces. The symbol ∫ means "sum over". Here we add up e-st f(t) over all times from 0 to infinity.
Infinity (∞)
A value larger than any number. An integral "to infinity" means we keep going forever, and we ask whether the total settles to a finite number.
Exponential function
A function of the form eat, where e is about 2.71828. It grows if a is positive and decays if a is negative.
Transform variable s
A new variable that plays the role of frequency or rate. It is just a symbol we use in F(s).
Linearity
The property that the transform of a sum is the sum of transforms, and constants can be taken outside.
Inverse Laplace transform
The reverse step. Given F(s), it finds the function f(t) that produced it. Written L-1{F(s)}.
Partial fractions
A method for splitting one complicated fraction into a sum of simple fractions, so that each piece is in the table.
Initial condition
The known value of y and its derivatives at t = 0, such as y(0) = 1 and y'(0) = 0.
Shifting theorem
A rule that says multiplying f(t) by eat shifts the transform from F(s) to F(s - a).
Transfer function
In control theory, the ratio of the output transform to the input transform, with all initial conditions set to zero.
Proper fraction
A fraction where the highest power of s in the numerator is smaller than the highest power in the denominator. Partial fractions needs a proper fraction.
Unit step function
A switch that is 0 before a time and 1 after it. It is used to model something that is turned on at a given moment.

Step 1: What the Laplace transform does

The integral, explained slowly

The definition is the most important line on this page:

F(s) = ∫0∞ e-st f(t) dt

Read it in parts:

  • f(t) is the original function, for example a signal or a position over time.
  • e-st is a weighting factor. When s is positive, this factor gets smaller as t grows. It fades out the far future.
  • ∫0∞ ... dt means "add up the weighted values for all times from 0 onwards".

The result F(s) depends on s, not on t. The variable t has been added away. That is why the result is a new function of a different variable.

Worked example 1: the transform of the constant 1

Find L{1}, the transform of f(t) = 1 for all t ≥ 0.

  1. Write the definition. F(s) = ∫0∞ e-st · 1 dt.
  2. Integrate. The antiderivative of e-st is -e-st/s. So the integral is [-e-st/s] evaluated from 0 to infinity.
  3. Evaluate at infinity. For s > 0, e-st goes to 0 as t grows. So the upper limit gives 0.
  4. Evaluate at zero. At t = 0, e0 = 1, so the lower limit gives -1/s.
  5. Subtract. F(s) = 0 - (-1/s) = 1/s.

So L{1} = 1/s, valid for s > 0. The condition s > 0 is needed so the integral settles to a finite number. This is an example of the convergence check that appears in many GATE questions.

Worked example 2: an exponential

Find L{eat

  1. Write the definition. F(s) = ∫0∞ e-st eat dt.
  2. Combine the exponentials. e-st eat = e-(s-a)t. So F(s) = ∫0∞ e-(s-a)t dt.
  3. Integrate. By the same method as Example 1, the result is 1/(s - a), valid for s > a.

Example: L{e3t} = 1/(s - 3), and L{e-2t} = 1/(s + 2).

Key ideaThe transform always comes with a region of validity. For exponentials, the transform exists only when s is larger than the exponent a. In exam answers you can often ignore this, but you should know it is there.

Question: What is L{e-5t}?

Use L{eat} = 1/(s - a) with a = -5. The answer is 1/(s + 5).

Question: Why do we need s > 0 when transforming the constant 1?

Because the integral of e-st from 0 to infinity converges only when s is positive. If s is zero or negative, the weighting factor does not shrink, and the total is infinite.

Step 2: Standard transforms and the rules that build new ones

Why we use a table

You could compute every transform from the definition, but that takes time. Engineers memorise a short table of standard transforms. Then they use a few rules to handle more complicated functions. Here is the table you need for GATE.

Here n! means n factorial, the product 1 × 2 × ... × n. For example, 3! = 6. And 0! = 1 by convention.

Rule 1: linearity

The transform of a sum is the sum of the transforms. A constant multiplier can be pulled outside. In symbols, for constants a and b:

L{a f(t) + b g(t)} = a F(s) + b G(s)

Worked example: find L{3t2 + 4e-t}. Using the table, L{t2} = 2!/s3 = 2/s3, and L{e-t} = 1/(s + 1). So the answer is 3 · 2/s3 + 4 · 1/(s + 1) = 6/s3 + 4/(s + 1).

Rule 2: the shifting theorem

If you multiply f(t) by eat, the transform moves. Every s in F(s) becomes (s - a):

L{eat f(t)} = F(s - a)

Worked example: find L{e-3t cos 2t}. First, L{cos 2t} = s/(s2 + 4), so F(s) = s/(s2 + 4). Here a = -3, so replace s by (s + 3). The answer is (s + 3)/((s + 3)2 + 4).

Rule 3: transform of a derivative

This is the rule that makes differential equations easy. If F(s) is the transform of f(t), then the transform of its derivative is:

L{f'(t)} = sF(s) - f(0)

Here f(0) is the value of f at t = 0. It appears because of the way the integral is evaluated at its lower limit. For a second derivative:

L{f''(t)} = s2F(s) - s f(0) - f'(0)

Here f'(0) is the slope at t = 0. These are exactly the initial conditions we need for an IVP. This is why the Laplace transform handles initial conditions so neatly.

Worked example 3: deriving the transform of cos

We know L{sin bt} = b/(s2 + b2). Use the derivative rule to find L{cos bt}.

  1. Start with the derivative. The derivative of sin bt is b cos bt. So L{b cos bt} = L{d/dt (sin bt)}.
  2. Apply the rule. L{f'} = sF - f(0) with f = sin bt. Here f(0) = sin 0 = 0. So L{b cos bt} = s · b/(s2 + b2) - 0.
  3. Divide by b. L{cos bt} = s/(s2 + b2). This matches the table.

TrapThe derivative rule includes -f(0). Students often write L{f'} = sF(s) and forget the initial value. If f(0) is not zero, the answer will be wrong. Always write the initial value term.

Rule 4: multiplying by t and integrating

Two more rules are useful in GATE. Multiplying by t corresponds to a minus sign and a derivative in s:

L{t f(t)} = -dF/ds

Integrating in time divides by s: L{∫0t f(τ) dτ} = F(s)/s. Here τ (tau) is just a dummy variable used inside the integral.

Worked example: find L{t e-2t} using the first rule. Start with F(s) = 1/(s + 2). Its derivative is dF/ds = -1/(s + 2)2. So -dF/ds = 1/(s + 2)2. This matches the table row for t eat with a = -2.

Question: Find L{t3}. Use the table.

Use tn with n = 3. The answer is 3!/s4 = 6/s4.

Question: Find L{sin 3t}, then L{e2t sin 3t}.

From the table, L{sin 3t} = 3/(s2 + 9). Using the shifting rule with a = 2, replace s by (s - 2): L{e2t sin 3t} = 3/((s - 2)2 + 9).

Step 3: Inverse Laplace transform and partial fractions

Going back

The inverse transform reverses the translation. You have an expression in s, and you want the function of t. The simplest case is when the expression matches a row of the table exactly. For example, if F(s) = 1/(s + 4), then f(t) = e-4t.

Most expressions do not match a single row. They are sums of fractions, or fractions with several factors in the bottom. In that case you split the fraction using partial fractions.

Partial fractions, the cover-up method

Suppose the bottom of a fraction is (s - p)(s - q) with p and q different. Then:

F(s) = (numerator) / ((s - p)(s - q)) = A/(s - p) + B/(s - q)

To find A, multiply both sides by (s - p) and then set s = p. The term with B disappears, and A is left. To find B, do the same with (s - q) and set s = q. The name "cover-up" comes from covering the factor you are removing with your finger.

Worked example 4: inverse transform

Find L-1{(s + 3)/((s + 1)(s + 2))}.

  1. Check the fraction is proper. The numerator is degree 1 and the denominator is degree 2. Yes, it is proper, so partial fractions works.
  2. Set up. (s + 3)/((s + 1)(s + 2)) = A/(s + 1) + B/(s + 2).
  3. Find A. Multiply by (s + 1): A = (s + 3)/(s + 2). Set s = -1: A = (-1 + 3)/(-1 + 2) = 2/1 = 2.
  4. Find B. Multiply by (s + 2): B = (s + 3)/(s + 1). Set s = -2: B = (-2 + 3)/(-2 + 1) = 1/(-1) = -1.
  5. Invert each piece. 2/(s + 1) gives 2e-t, and -1/(s + 2) gives -e-2t. So f(t) = 2e-t - e-2t.

A short program confirms the coefficients. It uses exact fractions, so there is no rounding.

from fractions import Fraction

# F(s) = (s + 3) / ((s + 1)(s + 2)), so the cover-up values are:
A = Fraction(-1 + 3, -1 + 2)   # multiply by (s + 1), then set s = -1
B = Fraction(-2 + 3, -2 + 1)   # multiply by (s + 2), then set s = -2
print("A =", A)
print("B =", B)
A = 2
B = -1

TipBefore you start partial fractions, write the bottom of the fraction in factored form. Factoring first makes the cover-up values easy to read.

Worked example 5: a fraction with a repeated or unfactored bottom

Find L-1{(2s + 5)/(s2 + 2s + 5)}. The bottom does not factor with real numbers, so we complete the square.

  1. Complete the square. s2 + 2s + 5 = (s + 1)2 + 4. Here (s + 1)2 = s2 + 2s + 1, so we add 4 to get the 5.
  2. Rewrite the numerator. 2s + 5 = 2(s + 1) + 3. Now the numerator contains the same (s + 1) as the bottom.
  3. Split the fraction. F(s) = 2(s + 1)/((s + 1)2 + 4) + 3/((s + 1)2 + 4).
  4. Match the table with a shift. s/(s2 + 4) is cos 2t, so with s replaced by (s + 1), the first term is 2e-t cos 2t. The second term is 3/((s + 1)2 + 4) = (3/2) · 2/((s + 1)2 + 4), which is (3/2)e-t sin 2t.
  5. Answer. f(t) = 2e-t cos 2t + (3/2)e-t sin 2t.

TrapPartial fractions needs a proper fraction. If the numerator has a higher power of s than the denominator, divide first, as in ordinary arithmetic, and then split the remainder. Many GATE questions hide this step.

Question: Find L-1{1/(s(s + 3))}.

Write 1/(s(s + 3)) = A/s + B/(s + 3). Cover-up gives A = 1/3 (set s = 0 in 1/(s + 3)) and B = -1/3 (set s = -3 in 1/s). So f(t) = (1/3)(1 - e-3t).

Question: What is the first step when the bottom of a fraction has no real factors?

Complete the square to get the form (s - p)2 + b2. Then match it to the sin and cos rows of the table with a shift.

Step 4: Solving linear ODEs with initial conditions

The method, step by step

Now we put the pieces together. For a linear differential equation with constant coefficients and given initial conditions, the Laplace method works the same way every time:

  1. Transform each term. Use the derivative rules, which bring in the initial values automatically.
  2. Collect Y(s). Gather all terms with Y on one side and move the rest to the other side.
  3. Solve for Y(s). You get a fraction in s.
  4. Invert. Use partial fractions and the table to find y(t).

Worked example 6: second order with two initial conditions

Solve y'' + 3y' + 2y = 0 with y(0) = 1 and y'(0) = 0.

  1. Transform the second derivative. L{y''} = s2Y - s y(0) - y'(0) = s2Y - s - 0 = s2Y - s.
  2. Transform the first derivative. L{y'} = sY - y(0) = sY - 1.
  3. Transform the whole equation. (s2Y - s) + 3(sY - 1) + 2Y = 0.
  4. Collect Y. Y(s2 + 3s + 2) = s + 3. So Y = (s + 3)/(s2 + 3s + 2).
  5. Factor. s2 + 3s + 2 = (s + 1)(s + 2). So Y = (s + 3)/((s + 1)(s + 2)). This is the same fraction as in Worked example 4.
  6. Invert. From Worked example 4, y(t) = 2e-t - e-2t.

Now verify the answer with a program. It checks the initial conditions and the equation at a few times.

import math

def y(t):
    return 2 * math.exp(-t) - math.exp(-2 * t)

def dy(t):
    return -2 * math.exp(-t) + 2 * math.exp(-2 * t)

def d2y(t):
    return 2 * math.exp(-t) - 4 * math.exp(-2 * t)

print("y(0) =", round(y(0), 6))
print("y'(0) =", round(dy(0), 6))
for t in [0.5, 1.0, 2.0]:
    residual = d2y(t) + 3 * dy(t) + 2 * y(t)
    print("t =", t, "equation holds:", abs(residual) < 1e-9)
y(0) = 1.0
y'(0) = 0.0
t = 0.5 equation holds: True
t = 1.0 equation holds: True
t = 2.0 equation holds: True

Worked example 7: a first order equation with a constant input

Solve y' + 2y = 1 with y(0) = 0. The right-hand side is the constant 1, which is a simple input to the system.

  1. Transform. sY - y(0) + 2Y = L{1} = 1/s. With y(0) = 0: sY + 2Y = 1/s.
  2. Solve for Y. Y(s + 2) = 1/s, so Y = 1/(s(s + 2)).
  3. Partial fractions. 1/(s(s + 2)) = A/s + B/(s + 2). Cover-up: A = 1/(s + 2) at s = 0, so A = 1/2. And B = 1/s at s = -2, so B = -1/2.
  4. Invert. Y = (1/2)(1/s) - (1/2)(1/(s + 2)). So y(t) = (1/2)(1 - e-2t).
import math

def y(t):
    return 0.5 * (1 - math.exp(-2 * t))

def dy(t):
    return math.exp(-2 * t)

print("y(0) =", y(0))
for t in [0.5, 1.0, 2.0]:
    print("t =", t, "equation holds:", abs(dy(t) + 2 * y(t) - 1) < 1e-9)
y(0) = 0.0
t = 0.5 equation holds: True
t = 1.0 equation holds: True
t = 2.0 equation holds: True

Key ideaThe initial conditions enter the algebra automatically through the derivative rules. You do not solve for constants separately as you did in the classical method. This is the main advantage of the Laplace method for IVPs.

Question: Transform y' - 4y = 0 with y(0) = 3. What is Y(s)?

sY - 3 - 4Y = 0, so Y(s - 4) = 3 and Y = 3/(s - 4). The inverse is y = 3e4t.

Question: In a transfer function, what initial conditions are assumed?

All initial conditions are assumed to be zero. Then the derivative rules have no extra initial value terms, and the transfer function is simply the ratio of output to input transforms.

Solved GATE-style problems

These problems are original, written in the style of GATE questions. They are not past exam questions. Try each one on paper before you read the answer.

Transform a polynomial plus an exponential

Find L{3t2 + 4e-t} and evaluate it at s = 2. Give the exact value. (Answer type: NAT, an exact fraction.)

How to think about it

  1. What is asked. The transform of a sum, then its value at s = 2.
  2. Which idea applies. Linearity, together with the table entries for t2 and e-t.
  3. Work it out. L{t2} = 2!/s3 = 2/s3, so 3 · 2/s3 = 6/s3. And L{e-t} = 1/(s + 1), so 4 · 1/(s + 1) = 4/(s + 1). Total F(s) = 6/s3 + 4/(s + 1). At s = 2: 6/8 + 4/3. Common denominator 12 gives 9/12 + 16/12 = 25/12.
  4. Check. The program adds the two fractions exactly.
from fractions import Fraction

print(Fraction(6, 8) + Fraction(4, 3))
25/12

Answer: F(s) = 6/s3 + 4/(s + 1), and F(2) = 25/12.

Inverse transform of a sine form

Let f(t) = L-1{1/(s2 + 16)}. Find f(π/8), rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The function f(t) at one time, t = π/8.
  2. Which idea applies. The sine row of the table has b/(s2 + b2). Here b = 4, but the numerator is 1, not 4.
  3. Work it out. 1/(s2 + 16) = (1/4) · 4/(s2 + 16). The inverse of 4/(s2 + 16) is sin 4t. So f(t) = (1/4) sin 4t. At t = π/8, 4t = π/2, and sin(π/2) = 1. So f(π/8) = 1/4 = 0.25.
  4. Check. The program evaluates the expression.
import math

print(round(0.25 * math.sin(4 * math.pi / 8), 4))
0.25

Answer: f(π/8) = 0.25.

Which transform rules are correct?

Select all the statements that are true.

(A) L{cos 2t} = s/(s2 + 4).
(B) L{t e3t} = 1/(s - 3)2.
(C) L{eat f(t)} = F(s + a).
(D) L{f'(t)} = F(s) - f(0).

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which of the four rules are correct.
  2. Which idea applies. Compare each statement with the table and with the shifting and derivative rules.
  3. Work it out. (A) The table row for cos bt with b = 2 gives s/(s2 + 4). True. (B) The row for t eat with a = 3 gives 1/(s - 3)2. True. (C) The shifting theorem says the shift is F(s - a), not F(s + a). False. (D) The derivative rule is sF(s) - f(0). The factor s is missing. False.
  4. Check. Test (D) with f = 1. Then f' = 0, so the left side is L{0} = 0. The right side is F(s) - f(0) = 1/s - 1, which is not zero for all s. So (D) is false, which confirms the check.

Answer: (A) and (B).

Solve a first order IVP and evaluate it

Use the Laplace transform to solve y' + 3y = 0 with y(0) = 5. Find y(1), rounded to two decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The value of y at t = 1.
  2. Which idea applies. Transform the derivative with sY - y(0), then solve for Y.
  3. Work it out. sY - 5 + 3Y = 0, so Y(s + 3) = 5 and Y = 5/(s + 3). The inverse is y(t) = 5e-3t. At t = 1, y(1) = 5e-3, which is about 0.2489.
  4. Check. The program evaluates the same expression.
import math

print(round(5 * math.exp(-3), 2))
0.25

Answer: y(1) = 5e-3, which is 0.25 to two decimal places.

Inverse transform with a complete square

Let F(s) = (2s + 5)/(s2 + 2s + 5). Find f(t) = L-1{F(s)} and evaluate f(π/4), rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The inverse transform, then its value at t = π/4.
  2. Which idea applies. The bottom has no real factors, so complete the square and use the shifting theorem.
  3. Work it out. s2 + 2s + 5 = (s + 1)2 + 4. Also 2s + 5 = 2(s + 1) + 3. So F(s) = 2(s + 1)/((s + 1)2 + 4) + (3/2) · 2/((s + 1)2 + 4). The table gives s/(s2 + 4) for cos 2t, and 2/(s2 + 4) for sin 2t. With the shift s to (s + 1), we get f(t) = 2e-t cos 2t + (3/2)e-t sin 2t. At t = π/4, 2t = π/2, so cos = 0 and sin = 1. Then f(π/4) = (3/2)e-π/4.
  4. Check. The program evaluates (3/2)e-π/4.
import math

print(round(1.5 * math.exp(-math.pi / 4), 4))
0.6839

Answer: f(π/4) = (3/2)e-π/4, which is 0.6839 to four decimal places.

Which statements about a damped response are true?

A system satisfies y'' + 4y' + 3y = 0 with y(0) = 0 and y'(0) = 2. Select all the statements that are true.

(A) y(t) = e-t - e-3t.
(B) y(t) is negative for every t > 0.
(C) y(t) tends to 0 as t tends to infinity.
(D) y(t) has its largest value at t = (ln 3)/2.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which of the four statements are true for this solution.
  2. Which idea applies. Solve by Laplace transform, then test each statement.
  3. Work it out. L{y''} = s2Y - s · 0 - 2 = s2Y - 2, and L{y'} = sY. So (s2Y - 2) + 4sY + 3Y = 0, giving Y = 2/((s + 1)(s + 3)). Cover-up gives 2/((s + 1)(s + 3)) = 1/(s + 1) - 1/(s + 3). So y = e-t - e-3t. Statement (A) is true. (B) At t = 1 the value is e-1 - e-3, which is positive, so (B) is false. (C) Both exponentials go to 0, so (C) is true. (D) y' = -e-t + 3e-3t. Setting y' = 0 gives e-2t = 1/3, so t = (ln 3)/2. This is a maximum because y' is positive at t = 0 and negative after that point. So (D) is true.
  4. Check. The program evaluates y at t = (ln 3)/2. It should give the largest value, about 0.3849.
import math

t = math.log(3) / 2
print(round(math.exp(-t) - math.exp(-3 * t), 4))
0.3849

Answer: (A), (C) and (D).

Transform of t times a sine

Find the value of L{t sin 2t} at s = 1. Give the answer to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The transform of t sin 2t, evaluated at s = 1.
  2. Which idea applies. Multiplying by t gives -dF/ds, where F(s) = L{sin 2t}.
  3. Work it out. F(s) = 2/(s2 + 4). Its derivative is dF/ds = -4s/(s2 + 4)2. So L{t sin 2t} = -dF/ds = 4s/(s2 + 4)2. At s = 1: 4/(1 + 4)2 = 4/25 = 0.16.
  4. Check. The program integrates the definition numerically. The integral must give the same value, 0.16.
import math

def laplace(f, s, T=30.0, n=300000):
    h = T / n
    total = 0.0
    for k in range(n + 1):
        t = k * h
        w = 0.5 if k in (0, n) else 1.0
        total += w * f(t) * math.exp(-s * t)
    return total * h

print(round(laplace(lambda t: t * math.sin(2 * t), 1.0), 4))
0.16

Answer: L{t sin 2t} at s = 1 is 4/25 = 0.16.

Exam-level 1: Laplace of a product with t (NAT, 2 marks)

Find L{t e−2t sin t} evaluated at s = 0, correct to 3 decimal places.

How to think about it

  2. Which idea applies. L{sin t} = 1/(s² + 1). Shift: L{e−2tsin t} = 1/((s + 2)² + 1). Multiplying by t means taking −d/ds.

Exam-level 2: Solving an ODE by Laplace (NAT, 2 marks)

Use Laplace transforms on y″ + 3y′ + 2y = 0, y(0) = 1, y′(0) = 0. Find y(1), correct to 3 decimal places.

How to think about it

  1. What is asked. The solution at t = 1.
  2. Which idea applies. (s² + 3s + 2)Y − s − 3 = 0, so Y = (s + 3)/((s + 1)(s + 2)).
  3. Work it out. Partial fractions: Y = 2/(s + 1) − 1/(s + 2). y = 2e−t − e−2t. y(1) = 0.7358 − 0.1353 = 0.600.
  4. Check. y(0) = 1 and y′(0) = −2 + 2 = 0.

Exam-level 3: Final value theorem (MCQ, 2 marks)

F(s) = 10/(s(s + 2)(s + 5)) is the transform of f(t). What is the limit of f(t) as t → ∞? (A) 0 (B) 1 (C) 2 (D) 10

How to think about it

  1. What is asked. The steady value of f.
  2. Which idea applies. The final value theorem: lim f(t) = lims→0 sF(s), valid when the poles of sF(s) are in the left half plane.
  3. Work it out. sF(s) = 10/((s + 2)(s + 5)) → 10/10 = 1.
  4. Check. The poles −2 and −5 are stable, so the theorem applies.

Answer: (B).

Summary

Laplace transform
F(s) = ∫0∞ e-st f(t) dt. It turns functions of time into functions of s.
Inverse transform
The reverse step, written L-1, which finds f(t) from F(s).
Linearity
The transform of a sum is the sum of transforms, and constants pass through.
Shifting theorem
L{eat f(t)} = F(s - a).
Derivative rule
L{f'} = sF(s) - f(0). It brings in the initial value automatically.
Second derivative rule
L{f''} = s2F(s) - s f(0) - f'(0).
Multiplying by t
L{t f(t)} = -dF/ds.
Integral rule
L{∫ f} = F(s)/s.
Standard transform of 1
L{1} = 1/s for s > 0.
Standard transform of eat
L{eat} = 1/(s - a) for s > a.
Standard transform of sin and cos
L{sin bt} = b/(s2 + b2) and L{cos bt} = s/(s2 + b2).
Partial fractions
Splitting a proper fraction into simple terms, with coefficients found by the cover-up method.
Proper fraction
A fraction whose numerator has a lower power of s than its denominator.
Completing the square
Writing s2 + bs + c as (s + b/2)2 + remainder, to match a sine or cosine form.
Initial value problem with Laplace
Transform the equation, solve the algebra for Y(s), then invert.
Transfer function
The ratio of output transform to input transform, with zero initial conditions.

Remember these

  1. The derivative rule always includes the initial value. Never drop the -f(0) or -f'(0) terms.
  2. Use the table first. Derive a new transform only when the table cannot help.
  3. Partial fractions needs a proper fraction. Divide first if the numerator has the higher power.
  4. The cover-up method gives each coefficient in one step.
  5. Complete the square when the bottom has no real factors, then use the shifting theorem.
  6. Check your final answer against the initial conditions and the original equation.
