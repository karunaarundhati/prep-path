Cross-validation: LOO & k-fold

Cross-validation is a way to estimate how well a model will work on new data, using only the data you already have. Leave-one-out and k-fold are the two standard versions. Both are used to choose settings and avoid fooling yourself, and GATE Data Science and AI asks about how they differ.

The idea in plain words

Imagine a study group preparing for an exam. Each member writes five practice questions. Then the group takes turns: one person is the "tester" and answers nobody else's questions in advance, while the others study on the rest. Each person gets a turn as the tester, so the whole group's knowledge is checked, and nobody is ever tested on questions they wrote themselves.

Cross-validation does the same thing with data. We have a set of examples with known answers. We cannot wait for new data to test a model, so we split the data we have. Part of the data is used to train the model. The other part is used to test it. Then we swap roles and repeat, until every example has been used for testing once. The average test error is our estimate of how the model will behave on new data.

Why does GATE care? Questions often ask you to say what a method costs, which estimate has low bias or high variance, or how many model fits are needed. Every term is defined below, and every number is checked with Python.

Key terms

Training set
The examples used to fit the model. Precise: the data whose inputs and answers the learning algorithm uses.
Test or validation fold
The examples held out of training so that they can measure error. Precise: the part of the data used for scoring in one round of cross-validation.
Fold
One of the equal parts the data is divided into. Precise: a subset of the data used once as the held-out part.
k
The number of folds. Precise: a whole number of at least 2 that sets how many rounds are run.
n
The number of examples in the data. Precise: the total count of input and answer pairs.
Leave-one-out cross-validation (LOOCV)
Hold out one example at a time. Precise: the special case of k-fold where k = n.
k-fold cross-validation
Split the data into k folds and take turns holding each one out. Precise: a resampling method that trains k models and averages their held-out errors.
CV error
The average held-out error over all rounds. Precise: the cross-validation estimate of prediction error.
Model fit
One act of training a model on a training set. Precise: each round of cross-validation requires one fit.
Hyperparameter
A setting chosen before training, such as the degree of a polynomial or a penalty strength. Precise: a value not learned from the data by the fitting step itself.
Model selection
Choosing between candidate models or settings. Precise: picking the candidate with the lowest estimated error.
Optimistic estimate
An estimate that is too good to be true. Precise: an error estimate that is lower than the real error on new data.

Concept 1: Why we need cross-validation

The problem with one simple split

The simplest method is a single split: keep 20 percent of the data for testing and train on the rest. This works, but it has two weaknesses. First, the test set may be small, so the error estimate is noisy. Second, the result depends on which examples happened to land in the test set. Another split could give a very different answer.

The problem with testing on training data

The other tempting mistake is to measure error on the same data used for training. A flexible model can make the training error almost zero by memorising the examples. That number tells you nothing about new data, as we saw in the bias-variance topic. Cross-validation avoids this by making sure every error is measured on examples that were not used to fit that particular model.

Key ideaEvery error in cross-validation is measured on data the model did not train on. Averaging over all rounds makes the estimate less dependent on one lucky or unlucky split.

Why is training error a poor estimate of new-data error?

Training error is measured on the same examples the model was fitted to, so it is usually too optimistic. A flexible model can fit those examples closely while doing badly on new points.

What does cross-validation give us that one simple split does not?

Every example is used for testing exactly once, and the errors are averaged. The estimate depends less on one particular split, and all the data contributes to the final estimate.

Concept 2: Leave-one-out cross-validation (LOOCV)

What it is, step by step

LOOCV is the most extreme version. It uses n rounds, where n is the number of examples. In each round:

  1. Hold out exactly one example.
  2. Train the model on the other n − 1 examples.
  3. Predict the held-out example and measure the error.

After n rounds, every example has been held out once. The LOOCV estimate is the average of the n errors:

CVLOO = (1/n) × Σ ei
  • n is the number of examples.
  • ei is the squared error on example i, measured when example i was the one held out.
  • Σ means add up the n errors, from i = 1 to n.

A worked example with a very simple model

To keep the arithmetic clear, use a model that predicts the average of its training answers. Take six answers: 1, 3, 5, 7, 9, 11. The sum of all six is 36. In round i, the training average is the sum of the other five answers divided by 5. For example, when 1 is held out, the training answers are 3, 5, 7, 9, 11 with sum 35, so the prediction is 35/5 = 7 and the error is (1 − 7)² = 36.

Python can do the other five rounds exactly, using fractions so that no rounding creeps in.

from fractions import Fraction as F

ys = [1, 3, 5, 7, 9, 11]
n = len(ys)

errors = []
for i in range(n):
    train = ys[:i] + ys[i+1:]           # everything except point i
    pred = F(sum(train), len(train))    # the mean-only model
    errors.append((ys[i] - pred) ** 2)

loo = sum(errors) / n
print("number of fits:", n)
print("training size each time:", n - 1)
print("errors:", [str(e) for e in errors])
print("LOOCV estimate:", loo)
number of fits: 6
training size each time: 5
errors: ['36', '324/25', '36/25', '36/25', '324/25', '36']
LOOCV estimate: 84/5

The six errors are 36, 324/25, 36/25, 36/25, 324/25 and 36. Their sum is 504/5, and dividing by six gives 84/5, which is 16.8. The model needed six fits, one per example.

Bias and variance of the LOOCV estimate

Each LOOCV model is trained on n − 1 examples, which is almost all the data. So the estimate is close to the error you would get from a model trained on all n examples. That means LOOCV has low bias.

The downside is variance. The n training sets overlap almost completely, since any two of them differ by only two examples. So the n error values move together. Averaging highly correlated numbers does not reduce the spread much, so the final estimate can change a lot when the data changes. LOOCV can have high variance.

The cost is also high. You need n fits. For a large dataset or a slow model, this can take too long.

TrapStudents often say "LOOCV is the best because it uses the most data, so its variance must be low". The first half is true, the second half is not. Low bias does not mean low variance.

GATE loves thisRemember the pair: LOOCV has low bias but high variance and high computation. This pairing is a common target in multiple-choice questions.

How many models does LOOCV train on a dataset of 200 points?

200 models, one per example. Each one is trained on 199 points and tested on the one point left out.

Why does LOOCV have low bias?

Because each training set has n − 1 examples, which is nearly the full dataset. The models it builds are therefore close to the model you would fit on all the data.

Concept 3: k-fold cross-validation

What it is, step by step

k-fold cross-validation splits the n examples into k groups of roughly equal size, called folds. Then:

  1. Choose one fold as the test fold.
  2. Train the model on the other k − 1 folds together.
  3. Measure the average error on the test fold.
  4. Repeat so that each fold is the test fold once.

The k-fold CV estimate is the average of the k fold errors. For this to equal the average over all n examples, the folds should be the same size, so that each fold contributes equally. The formula is:

CVk = (1/k) × Σ (average error on fold j)
  • k is the number of folds.
  • average error on fold j is the mean squared error on the examples of fold j, measured by a model trained on the other folds.

Sizes of the training and test sets

If there are n examples and k folds, each fold has about n/k examples. Each round trains on the other n − n/k examples, and tests on n/k. Let us check this with n = 10 for several values of k. Note that LOOCV is the case k = n.

n = 10
for k in [2, 5, 10]:
    test = n // k
    train = n - test
    print("k =", k, "fits =", k, "train size =", train, "test size =", test)
print("LOOCV fits for n = 10:", n)
k = 2 fits = 2 train size = 5 test size = 5
k = 5 fits = 5 train size = 8 test size = 2
k = 10 fits = 10 train size = 9 test size = 1
LOOCV fits for n = 10: 10

Read the output. With k = 5 you fit 5 models, each trained on 8 points and tested on 2. With k = 10 you fit 10 models. When k = n, which is 10 here, the method has become LOOCV.

A worked example with three folds

Use the same six answers, 1, 3, 5, 7, 9 and 11, split into three folds of two points in order: [1, 3], [5, 7] and [9, 11]. The code below trains the mean-only model three times and then averages the six squared errors.

from fractions import Fraction as F

ys = [1, 3, 5, 7, 9, 11]
n = len(ys)
k = 3
size = n // k
fold_errors = []
for f in range(k):
    test_idx = list(range(f * size, (f + 1) * size))
    train = [ys[i] for i in range(n) if i not in test_idx]
    pred = F(sum(train), len(train))
    for i in test_idx:
        fold_errors.append((ys[i] - pred) ** 2)
    print("fold", f + 1, "test points:", [ys[i] for i in test_idx], "train mean:", pred)

kfold = sum(fold_errors) / n
print("3-fold CV estimate:", kfold)
fold 1 test points: [1, 3] train mean: 8
fold 2 test points: [5, 7] train mean: 6
fold 3 test points: [9, 11] train mean: 4
3-fold CV estimate: 25

Check the first fold by hand. The test points are 1 and 3. The training points are 5, 7, 9 and 11, with average (5 + 7 + 9 + 11)/4 = 32/4 = 8. The errors are (1 − 8)² = 49 and (3 − 8)² = 25. The other two folds give 1, 1, 25 and 49. The six errors sum to 150, and 150/6 = 25.

Key ideak-fold trains only k models, not n. It is much cheaper than LOOCV, and it is still a fair estimate because every example is tested exactly once.

With n = 50 and k = 5, how many examples does each model train on?

Each fold has 50/5 = 10 examples. Each model is trained on the other 4 folds, which is 40 examples, and tested on the 10 held out.

Is 10-fold CV the same as LOOCV when n = 10?

Yes. Each fold has one example, so each round holds out one example and trains on the other nine. That is exactly leave-one-out.

Concept 4: Choosing k and comparing the methods

Which value of k?

Choosing k is a tradeoff, the same kind you met in the bias-variance topic. A small k, such as 2, trains each model on only half the data, so each model is weaker than the full-data model. The estimate is then pessimistic, meaning it tends to overstate the error, which is high bias. A large k, such as n, uses almost all the data, which lowers bias, but the rounds overlap heavily, which raises variance and cost. Textbooks and practitioners often recommend k = 5 or k = 10 as a good middle ground, which gives reasonable bias and variance at moderate cost.

TipWhen a question asks which method has low bias, look for the method that uses the most training data per fit. When it asks which has low variance, look for the method with fewer, less overlapping rounds. These two answers often point in opposite directions.

TrapDo not say "k-fold has lower variance than LOOCV, so k-fold always gives the better estimate". The bias of a small k can outweigh the variance benefit. The table shows a balance, and 5 or 10 folds is usually the reasonable choice.

Why is 2-fold CV called pessimistic?

Because each model is trained on only half of the data. A model with less data usually makes bigger errors, so the estimate overstates the error of a model trained on all the data.

Which method is cheapest, and why?

2-fold, because it trains only two models. The cost grows with k, so LOOCV, which trains n models, is the most expensive.

Concept 5: Using cross-validation to choose a model

The main job of CV

Cross-validation is most often used for model selection. Suppose you have several candidate models, or several settings of a hyperparameter such as a polynomial degree or a penalty strength. You compute the CV error for each candidate, using the same folds for all of them, and choose the candidate with the lowest error. Then you retrain that choice on all of the data to make the final model.

As a tiny example, compare two candidates on the same three folds: "predict the average of the training answers" and "always predict zero". The code below computes the CV error of each and picks the smaller one.

from fractions import Fraction as F

ys = [1, 3, 5, 7, 9, 11]
n = len(ys)
k = 3
size = n // k

def cv(predict):
    total = F(0)
    for f in range(k):
        test = list(range(f * size, (f + 1) * size))
        train = [ys[i] for i in range(n) if i not in test]
        for i in test:
            total += (ys[i] - predict(train)) ** 2
    return total / n

def mean_model(train):
    return F(sum(train), len(train))

def zero_model(train):
    return F(0)

print("CV error, predict the mean:", cv(mean_model))
print("CV error, predict zero:", cv(zero_model))
print("choose:", "mean" if cv(mean_model) < cv(zero_model) else "zero")
CV error, predict the mean: 25
CV error, predict zero: 143/3
choose: mean

The mean-only model has CV error 25, while the always-zero model has CV error 143/3, about 47.67. The mean wins, so it is chosen. The final model is then trained on all six points, not only on the training folds.

The trap: the chosen score is a little too kind

When you try many candidates and keep the best, the winning CV error is slightly optimistic. You picked it because it looked best on those same folds, so some luck is built in. For an honest final score, either keep a separate test set that you never touched during selection, or use nested cross-validation, which runs an inner loop for selection inside an outer loop for scoring.

Key ideaCross-validation chooses the setting. It does not automatically give an unbiased final score for that same setting. Keep something untouched for the final report.

GATE loves thisExpect a question about the correct workflow: choose by CV, retrain on all the data, and report on data kept aside. Reporting the winning CV error as the final result is the common mistake.

After choosing a model by CV, should you use the fold models as the final model?

Usually not. The common approach is to retrain the chosen setting on all the available training data, so the final model uses every example.

Why must every candidate be compared on the same folds?

If the folds differ, one candidate may look better simply because it was lucky with its splits. Using the same folds makes the comparison fair.

Counting the fits

A dataset has 8 examples. Leave-one-out cross-validation is used with a model that takes the same time to fit each time. How many models are trained? (NAT)

How to think about it

  1. What is asked. The number of model fits.
  2. Which idea applies. LOOCV has one round per example, and each round trains one model.
  3. Work it out. There are 8 examples, so there are 8 rounds, so 8 models.
  4. Check. Each example is held out once, so 8 held-out examples means 8 rounds.

Answer: 8

Training size in 5-fold

A dataset has 20 examples and 5-fold cross-validation is used. How many examples does each model train on? (NAT)

How to think about it

  1. What is asked. The training size per model.
  2. Which idea applies. Each fold has n/k examples, and each model trains on the rest.
  3. Work it out. Fold size: 20/5 = 4. Training size: 20 − 4 = 16.
  4. Check. Training plus test is 16 + 4 = 20, which is the whole dataset.

Answer: 16

Comparing LOOCV and 5-fold

Select all that apply. Consider LOOCV and 5-fold cross-validation on the same dataset with n = 50 examples. (MSQ)

(A) LOOCV fits 50 models and 5-fold fits 5 models.
(B) Each LOOCV model trains on more examples than each 5-fold model.
(C) LOOCV usually has higher variance as an estimate of error than 5-fold.
(D) LOOCV always gives a lower estimate of error than 5-fold.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. The counts of fits, the training sizes, and the bias-variance behaviour from Concepts 2 and 4.
  3. Work it out. (A) is true: 50 rounds for LOOCV and 5 for 5-fold. (B) is true: LOOCV trains on 49 examples, while 5-fold trains on 40. (C) is true: the 50 LOOCV errors are highly correlated, so their average varies more. (D) is false: the two methods give different estimates, and nothing guarantees that one is always lower. The 5-fold estimate is usually more pessimistic, not less.
  4. Check. (A) and (B) follow from the sizes, and (C) follows from the overlap of training sets. (D) claims a rule that is not a theorem.

Answer: (A), (B) and (C). Statement (D) is false.

Training size with 4 folds

A dataset has 12 examples. 4-fold cross-validation is used. How many examples does each model train on? (NAT)

How to think about it

  1. What is asked. The training size.
  2. Which idea applies. Test size is n/k, and training size is n minus the test size.
  3. Work it out. Test size: 12/4 = 3. Training size: 12 − 3 = 9.
  4. Check. Four folds of 3 make 12 examples. Each round uses 3 folds to train, which is 9 examples.

Answer: 9

LOOCV by hand with three points

The data are 2, 4 and 9. The model predicts the average of its training answers. Find the LOOCV estimate, which is the average of the three squared errors. Give your answer as a decimal. (NAT)

How to think about it

  1. What is asked. The LOOCV estimate as a decimal.
  2. Which idea applies. In each round, train on the other two points, predict the held-out point, and square the gap.
  3. Work it out. Hold out 2: training average (4 + 9)/2 = 6.5, error (2 − 6.5)² = 20.25. Hold out 4: training average (2 + 9)/2 = 5.5, error (4 − 5.5)² = 2.25. Hold out 9: training average (2 + 4)/2 = 3, error (9 − 3)² = 36. Average: (20.25 + 2.25 + 36)/3 = 58.5/3 = 19.5.
  4. Check. The Python run below repeats the same steps with exact fractions.

Reporting a cross-validated score

A student tries 10 values of a penalty λ, using 10-fold cross-validation on the same folds for all of them. The best λ has the lowest CV error, and the student reports that CV error as the final performance of the model. Select all statements that are correct. (MSQ)

(A) The reported score is slightly optimistic because the best λ was chosen using those same folds.
(B) A separate test set that was never used for choosing λ would give a fairer report.
(C) The final model is usually retrained on all the data using the chosen λ.
(D) In each fold, the error is measured on the examples used to train that fold's model.

How to think about it

  1. What is asked. Which statements describe the correct use of cross-validation.
  2. Which idea applies. Selection bias from picking the best of many candidates, and the rule that the test fold must be held out.
  3. Work it out. (A) is true: picking the minimum of ten noisy scores makes that minimum look better than it really is. (B) is true: a fresh test set has never influenced the choice. (C) is true: the usual final step is a refit on all the data with the chosen λ. (D) is false: the whole point of a fold is that its examples were not used to train the model that is scored on them.
  4. Check. Statement (D) describes the trap that cross-validation exists to avoid, so it must be false.

Answer: (A), (B) and (C). Statement (D) is false.

Exam-level 1: Fold sizes (NAT, 1 mark)

A data set has 1000 points. In 5-fold cross validation, how many points are used to train each model, and how many models are trained?

How to think about it

Exam-level 2: LOOCV for the mean predictor (NAT, 2 marks)

Data: 2, 4, 6, 8. The model predicts the mean of the training points. Compute the leave-one-out CV mean squared error, correct to 3 decimal places.

How to think about it

  1. What is asked. The average squared error over the 4 held out points.
  2. Which idea applies. Holding out yi, the prediction is the mean of the other three.
  3. Work it out. Hold out 2: mean 6, error 16. Hold out 4: mean 16/3, error 16/9. Hold out 6: mean 14/3, error 16/9. Hold out 8: mean 4, error 16. Average (32 + 32/9)/4 = 8.889.
  4. Check. The code computes it.
y = [2, 4, 6, 8]
errs = [(v - (sum(y) - v) / 3) ** 2 for v in y]
print("%.3f" % (sum(errs) / 4))

8.889

Answer: about 8.889.

Exam-level 3: CV facts (MSQ, 2 marks)

Which are TRUE? (A) LOOCV on n points trains n models. (B) LOOCV has lower bias than 5-fold CV. (C) Hyperparameters should be chosen on the test set. (D) Stratified k-fold keeps class proportions in each fold.

How to think about it

  1. What is asked. Properties of cross validation.
  2. Which idea applies. LOOCV trains on n − 1 points each time, almost the whole set.
  3. Work it out. (A) True. (B) True. (C) That leaks test data. False. (D) True.
  4. Check. LOOCV's estimates are highly correlated, which gives it higher variance.
