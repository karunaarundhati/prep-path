Functions, arrays, dict, strings (recap)

This quick recap revises four Python tools that every robotics program uses: functions that take inputs and return results, lists (arrays) read by position and slices, dictionaries that map names to values, and strings that hold messages from sensors. Work through the short examples, then try the GATE-style trace problems.

The idea in plain words

A robot arm reads a joint angle, stores it in a list, looks up the calibration for each joint in a dictionary, and turns a text message from a sensor into numbers. Each step uses one of four Python tools. This page is a fast refresher on those tools, with the traps that GATE trace questions like to test.

GATE expects you to read a short program and say what it prints. You do not need to memorise every method. You do need to know how indexing starts at 0, how a slice stops one step before its end, and what changes in place and what makes a copy.

Key ideaLists and dictionaries change in place. Strings never change: every string method returns a new string.

Key terms

Function
A named block of code you can call with inputs. Precisely: defined with def, and it sends back a value with return.
Parameter and argument
A parameter is the name in the definition. An argument is the value passed in the call.
Default value
A value used when the caller leaves an argument out. Precisely: written as name=value in the definition.
List (array)
An ordered collection, indexed from 0. Precisely: a mutable sequence written with square brackets.
Index
The position of an item. Precisely: the first item has index 0, and a negative index counts from the end, with -1 for the last item.
Slice
A piece of a list or string. Precisely: a[start:stop:step] includes start and excludes stop.
Dictionary
A mapping from keys to values. Precisely: written with braces, with keys that must be immutable (such as numbers, strings or tuples).
Mutable and immutable
Mutable objects change in place (lists, dictionaries). Immutable objects never change (strings, numbers, tuples).
Alias
Two names that refer to the same object. Precisely: b = a makes b an alias of a.

Functions: inputs, defaults and return

A function is a recipe with a name. You define it once and call it many times. The inputs are the parameters, and return sends a result back to the caller. A function with no return statement gives back the special value None.

Default values let a caller skip an argument. In the call area(5) below, the height is taken from the default, 2. You can also pass arguments by name, so the order does not matter.

def area(width, height=2):
    return width * height

print(area(5))
print(area(5, 3))
print(area(height=4, width=1))
10
15
4

TrapA function prints nothing unless you call print inside it, and a return value is not printed automatically. If a question shows a call without print, the result is hidden.

What does area(3) return?

6, because the default height 2 is used: 3 x 2 = 6.

Lists: indexing, slicing and changing in place

A list holds items in order. Index 0 is the first item. A slice a[start:stop] takes items from start up to, but not including, stop. Leaving start or stop out means "from the beginning" or "to the end". A third number gives the step.

Take the list a = [10, 20, 30, 40, 50]. Then a[1:4] is [20, 30, 40] (indices 1, 2 and 3). a[-1] is 50. a[::2] takes every second item, giving [10, 30, 50].

Lists are mutable. The method append adds an item to the end of the same list. An assignment b = a does not copy the list, it creates a second name for it. A slice a[:] makes a real copy.

a = [10, 20, 30, 40, 50]
print(a[1:4])
print(a[-1])
print(a[::2])
a.append(60)
b = a
c = a[:]
b.append(70)
print(len(a), len(c))
[20, 30, 40]
50
[10, 30, 50]
7 6

TipTo count items in a slice, subtract start from stop. a[1:4] has 4 - 1 = 3 items.

What is a[2:] for a = [5, 6, 7, 8]?

[7, 8]. The slice starts at index 2 and runs to the end.

After c = a[:], does appending to a change c?

No. The slice made a new list, so c is an independent copy.

Dictionaries: keys, values and lookups

A dictionary is like a labelled drawer cabinet. The key is the label, and the value is what is inside. You look up a value by its key, not by a position. Adding a new key with d[key] = value creates the entry, and assigning to an existing key replaces its value.

Three operations cover most questions. d.get(key, default) returns the value, or the default if the key is missing, without an error. key in d tests whether a key exists and gives True or False. d.items() gives the (key, value) pairs.

sensor = {"temp": 21, "hum": 40}
sensor["press"] = 1013
print(sensor.get("temp"), sensor.get("wind", "none"))
print("hum" in sensor)
for key, value in sensor.items():
    print(key, value)
21 none
True
temp 21
hum 40
press 1013

TrapReading d[key] for a missing key raises a KeyError, which stops the program. Use get when a key may be missing.

What does d.get("x") return if "x" is not a key?

None. With no default given, get returns None rather than raising an error.

Strings: methods and slices

A string is a sequence of characters, and it is immutable. Indexing and slicing work exactly as they do for lists. The methods split, join, upper, strip, replace and find each return a new string or a number. They never change the original.

  • split(",") cuts the string at each comma and returns a list.
  • "-".join(list) glues the list items together with "-" between them.
  • strip() removes spaces at both ends.
  • find(x) returns the index of the first x, or -1 if x is not present.
msg = "X:12,Y:-3,Z:7"
parts = msg.split(",")
print(parts)
print(parts[1].split(":")[1].upper())
print(msg[0:3], msg[-1])
print("-".join(["a", "b", "c"]), "  pad ".strip())
['X:12', 'Y:-3', 'Z:7']
-3
X:1 7
a-b-c pad
What does "robot".find("t") return?

4. The letters are r(0), o(1), b(2), o(3), t(4).

Does s.upper() change s?

No. It returns a new uppercase string. To keep it, write s = s.upper().

Putting it together: parsing a sensor message

A typical robot sensor sends a message such as "X:12,Y:-3,Z:7". To use it, split on the commas, split each piece on the colon, convert the number text with int, and store the result in a dictionary keyed by the axis name. The dictionary comprehension below does all of this in one line.

msg = "X:12,Y:-3,Z:7"
vals = {p.split(":")[0]: int(p.split(":")[1]) for p in msg.split(",")}
print(vals)
print(vals["Y"] + vals["Z"])
{'X': 12, 'Y': -3, 'Z': 7}
4

GATE loves thisStrings from sensors are text. "12" is not a number until you call int on it. Adding two strings joins them, so "1" + "2" gives "12", not 3.

What is "1" + "2" in Python?

The string "12". Converting with int first would give the number 3.

Aliasing traps

When two names point at one list, a change through one name shows up through the other. This is the most common source of wrong answers in trace questions. A slice or a copy breaks the link. The nested list trap is even sneakier: [[0] * 2] * 2 makes two references to one inner list, so changing one row changes both.

TrapWrite [[0] * 2 for _ in range(2)] for a grid of independent rows. The version with * on the outside shares the rows.

After b = a and b.append(4), what is a?

a has the 4 too, because a and b are two names for the same list.

Solved GATE-style problems

These problems are original GATE-style questions written for practice. They are not past exam questions.

Slices of a list

What does this program print?

a = [3, 6, 9, 12, 15]
print(a[2:], a[-2:], a[::-1][0])

How to think about it

  1. What is asked. Three values printed on one line.
  2. Which idea applies. Slices start at the start index and stop before the stop index. A negative step walks backwards.
  3. Work it out. a[2:] starts at index 2 (value 9) and runs to the end: [9, 12, 15]. a[-2:] is the last two items: [12, 15]. a[::-1] reverses the list, so its first item is 15.
  4. Check. The reversed list starts with the last item of a, which is 15. This matches a[-1].

Answer: [9, 12, 15] [12, 15] 15

a = [3, 6, 9, 12, 15]
print(a[2:], a[-2:], a[::-1][0])
[9, 12, 15] [12, 15] 15

A function that prints and returns

What does this program print?

def f(x):
    print("inside", x)
    return x * 2

y = f(4) + 1
print(y)

How to think about it

  1. What is asked. Everything printed, in order.
  2. Which idea applies. The function prints when it runs, then returns a value that is used in the expression.
  3. Work it out. f(4) runs first and prints "inside 4". It returns 8. Then 8 + 1 = 9 is stored in y, and print(y) shows 9.
  4. Check. Only two lines appear: the one from inside the function, then the final value.

Answer: "inside 4", then 9.

Which statements are true?

Select all that apply.

  • (A) s[0] = "x" works when s is a string.
  • (B) list.append changes the list in place.
  • (C) A list can be used as a dictionary key.
  • (D) "abc".upper() returns a new string and leaves "abc" unchanged.
  • (E) a[1:1] is always an empty list.

How to think about it

  1. What is asked. Which claims are true.
  2. Which idea applies. Strings are immutable, lists are mutable, and dictionary keys must be immutable.
  3. Work it out. (A) False, strings cannot be changed by item assignment. (B) True. (C) False, a list is mutable, so it cannot be a key. (D) True. (E) True, a slice from 1 to 1 includes nothing.
  4. Check. Test (A) mentally: assigning to an index of a string raises a TypeError, so it does not work.

Answer: (B), (D) and (E).

Default arguments and dictionary lookups

What does this program print?

def greet(name, greeting="Hi"):
    return greeting + ", " + name

stock = {"arm": 3}
stock["gripper"] = stock.get("gripper", 0) + 2
print(greet("Ana"), greet("Bo", "Hello"))
print(sorted(stock.items()))

How to think about it

  1. What is asked. Two printed lines.
  2. Which idea applies. Missing arguments use defaults. get returns a default for a missing key. sorted orders the pairs.
  3. Work it out. greet("Ana") uses greeting "Hi", giving "Hi, Ana". greet("Bo", "Hello") gives "Hello, Bo". print puts a space between them. The gripper key is missing, so get returns 0, and 0 + 2 = 2 is stored. The items are ("arm", 3) and ("gripper", 2), already in sorted order.
  4. Check. Each printed line has the right number of items: two strings on the first, and a list of two pairs on the second.

Answer: "Hi, Ana Hello, Bo" on the first line, then [('arm', 3), ('gripper', 2)].

def greet(name, greeting="Hi"):
    return greeting + ", " + name

Parsing a sensor message

What does this program print?

msg = "X:12,Y:-3,Z:7"
vals = {p.split(":")[0]: int(p.split(":")[1]) for p in msg.split(",")}
print(vals)
print(vals["Y"] + vals["Z"])

How to think about it

  1. What is asked. The dictionary and the sum of two values.
  2. Which idea applies. Split on commas, split each piece on the colon, convert with int, and build the dictionary.
  3. Work it out. The pieces are "X:12", "Y:-3" and "Z:7". The keys are X, Y, Z and the values are 12, -3 and 7. Then -3 + 7 = 4.
  4. Check. The dictionary has three keys, one per piece, so nothing was lost.

Answer: {'X': 12, 'Y': -3, 'Z': 7}, then 4.

How many cells hold 9?

After this program runs, how many of the four cells of grid hold the value 9?

grid = [[0] * 2] * 2
grid[0][1] = 9
print(grid)
a = [1, 2, 3]
b = a
c = a[:]
b.append(4)
c.append(5)
print(a, c)

How to think about it

  1. What is asked. A count of cells equal to 9 in the grid.
  2. Which idea applies. [[0] * 2] * 2 gives two references to the same inner list. b = a is an alias, and a[:] is a copy.
  3. Work it out. grid[0][1] = 9 changes the shared inner list. Both rows are that list, so row 0 and row 1 both show 0, 9. That gives two cells with 9. For the second part, b.append(4) changes a, so a is [1, 2, 3, 4]. c was copied before, so c.append(5) gives [1, 2, 3, 5].
  4. Check. The printed grid shows [[0, 9], [0, 9]], with 9 in two places. The printed a and c confirm the alias and the copy.

Answer: 2 cells hold 9. The program prints [[0, 9], [0, 9]], then [1, 2, 3, 4] [1, 2, 3, 5].

grid = [[0] * 2] * 2
grid[0][1] = 9
print(grid)

b = a
c = a[:]
b.append(4)
c.append(5)
print(a, c)
[[0, 9], [0, 9]]
[1, 2, 3, 4] [1, 2, 3, 5]

Strings are immutable

What does this program print?

s = "robot arm"
t = s.replace("arm", "hand").upper()
print(s)
print(t, t.find("H"), len(t))

How to think about it

  1. What is asked. The original s, then t, its index of "H", and its length.
  2. Which idea applies. Methods return new strings. Strings never change in place.
  3. Work it out. s is unchanged: "robot arm". replace gives "robot hand", and upper gives "ROBOT HAND". The letter H is at index 6 (R0 O1 B2 O3 T4 space5 H6). The length is 10, counting the space.
  4. Check. Count the characters of "ROBOT HAND": 5 letters, 1 space, 4 letters, total 10.

Answer: "robot arm", then "ROBOT HAND 6 10".

s = "robot arm"
t = s.replace("arm", "hand").upper()
print(s)
print(t, t.find("H"), len(t))
robot arm
ROBOT HAND 6 10

Exam-level 1: String slicing (NAT, 2 marks)

s = "GATEDATA2026". What does print(s[::-3]) output?

How to think about it

  1. What is asked. Every third character from the end.
  2. Which idea applies. A negative step starts at the last index and moves left.
  3. Work it out. Indices 11, 8, 5, 2: '6', '2', 'A', 'T'. Output "62AT".
  4. Check. The code prints it.
s = "GATEDATA2026"
print(s[::-3])

62AT

Answer: 62AT.

Exam-level 2: Dictionary update (NAT, 2 marks)

d = {}; for w in "the cat and the hat and the bat".split(): d[w] = d.get(w, 0) + 1. What is d["the"] * len(d)?

How to think about it

  1. What is asked. A frequency times the number of distinct words.
  2. Which idea applies. get with a default counts occurrences.
  3. Work it out. "the" appears 3 times. Distinct words: the, cat, and, hat, bat = 5. Product 15.
  4. Check. The code runs it.
d = {}
for w in "the cat and the hat and the bat".split(): d[w] = d.get(w, 0) + 1
print(d, d["the"] * len(d))

{'the': 3, 'cat': 1, 'and': 2, 'hat': 1, 'bat': 1} 15

Answer: 15.

Exam-level 3: List aliasing (MCQ, 2 marks)

a = [[0] * 2] * 3; a[0][0] = 1; print(a). The output is (A) [[1, 0], [0, 0], [0, 0]] (B) [[1, 0], [1, 0], [1, 0]] (C) [[1, 1], [1, 1], [1, 1]] (D) Error

How to think about it

  1. What is asked. The effect of repeating a list reference.
  2. Which idea applies. * 3 copies the reference, so all rows are the same list.
  3. Work it out. Changing a[0][0] changes every row.
  4. Check. Use [[0] * 2 for _ in range(3)] to get separate rows.
a = [[0] * 2] * 3; a[0][0] = 1; print(a)

[[1, 0], [1, 0], [1, 0]]

Answer: (B).

Summary

def
Keyword that defines a function.
return
Sends a value back to the caller. Without it, the result is None.
Default argument
A value used when the caller leaves that argument out.
Index
A position in a list or string, starting at 0.
Slice
a[start:stop:step]. Includes start, excludes stop.
append
Adds an item to the end of a list, in place.
Alias
Two names for the same object. Changes show through both.
Copy
A new, independent object, such as a[:] for a list.
Dictionary
A mapping from immutable keys to values.
get
Looks up a key and returns a default instead of an error.
String method
Returns a new string. Strings never change in place.
split and join
split cuts a string into a list. join glues list items into a string.
find
Returns the index of the first match, or -1 if there is none.

Remember these

  1. Indexing starts at 0, and a slice excludes its stop index.
  2. Lists and dictionaries change in place. Strings do not.
  3. Two names for one list share changes. A slice a[:] makes a copy.
  4. Sensor text must be converted with int before it is used as a number.
