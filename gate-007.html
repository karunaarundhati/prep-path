LU Decomposition

LU decomposition writes a matrix as a product of a lower triangular matrix L and an upper triangular matrix U. It is Gaussian elimination, saved in a form you can reuse. Once A = LU is known, every system Ax = b is solved by two easy triangular steps, which is why it appears in GATE questions and in real numerical software.

The idea in plain words

Suppose you must solve the same puzzle again and again with different totals. Doing the full elimination each time is wasteful. A smarter plan is to do the hard work once, save the steps, and reuse them. LU decomposition is that saved plan. It breaks the matrix A into two simpler matrices: L, which is lower triangular (zeros above the diagonal), and U, which is upper triangular (zeros below the diagonal). Their product is A. Triangular systems are easy to solve, so once you have L and U, each new system takes only a few quick steps.

Think of a recipe written as a list of simple steps. The cook can make the dish for a new guest by following the list again. L and U are that list for a matrix.

Key terms

Lower triangular matrix (L)
A square matrix with zeros above the diagonal.
Upper triangular matrix (U)
A square matrix with zeros below the diagonal.
Doolittle form
The LU form where L has 1s on its diagonal. L holds the multipliers.
Crout form
The LU form where U has 1s on its diagonal. L holds the pivots.
LU decomposition
Writing a square matrix as A = LU.
Permutation matrix (P)
A matrix made by reordering the rows of the identity. Multiplying by P swaps rows.
Multiplier
The number used to clear an entry during elimination. Multipliers become the entries of L.
Forward and back substitution
Solving a lower triangular system from the top, and an upper triangular system from the bottom.

Triangular matrices: the easy shapes

Consider the upper triangular system 2x + y + z = 4, y + z = 2, and 2z = 2. The last equation gives z = 1. The middle gives y = 1. The top gives x = 1. Each answer uses only answers already found. This is back substitution. The matrix U = [[2, 1, 1], [0, 1, 1], [0, 0, 2]] is upper triangular.

A lower triangular system is solved the other way, from the top row down, by forward substitution. For y1 = 4, 2y1 + y2 = 10, and 4y1 + 3y2 + y3 = 24, we get y2 = 2 and y3 = 2. The matrix L = [[1, 0, 0], [2, 1, 0], [4, 3, 1]] is lower triangular.

Key ideaA triangular system is easy to solve, as long as the diagonal entries are not 0. Each row has only one new unknown.

Solve the upper triangular system 3x + 2y = 8 and 4y = 4.

y = 1, then 3x = 6, so x = 2.

What is the determinant of [[2, 5, 7], [0, 3, 1], [0, 0, 4]]?

The product of the diagonal, 2 x 3 x 4 = 24.

What A = LU means, in words and in numbers

The statement A = LU means that A equals the product of L and U. For A = [[2, 1], [6, 4]], the decomposition with 1s on L's diagonal is:

A = [ 2  1 ] = [ 1  0 ] [ 2  1 ]
    [ 6  4 ]   [ 3  1 ] [ 0  1 ]

Check each entry. Entry (1,1): 1 x 2 = 2. Entry (1,2): 1 x 1 = 1. Entry (2,1): 3 x 2 = 6. Entry (2,2): 3 x 1 + 1 x 1 = 4. All four match.

Since A x = L (U x), applying A is the same as applying U first and then L. The first picture shows L, a vertical shear with 3 in its bottom-left corner. Drag the column arrows and watch the grid lean.

The second picture shows U, a stretch combined with a horizontal shear. Drag its columns and notice that the bottom edge of the grid stays on the horizontal axis, even though it is stretched.

TrapThe order matters. A = LU means U is applied first, then L. Writing A = UL gives a different matrix.

If L = [[1, 0], [2, 1]] and U = [[3, 1], [0, 2]], what is entry (2,2) of LU?

Row 2 of L is (2, 1) and column 2 of U is (1, 2). So 2 x 1 + 1 x 2 = 4.

Why must U be upper triangular?

Because U is what remains after elimination, which clears the entries below each pivot.

Building L and U from the elimination multipliers

Run Gaussian elimination on A, ignoring the right-hand side. U is the final staircase. L has the multiplier used to clear entry (i, k) in position (i, k), with 1s on its diagonal. In short, the multipliers are the entries of L.

A worked example

Take A = [[2, 1, 1], [4, 3, 3], [8, 7, 9]].

  1. Column 1. The pivot is 2. The multiplier for row 2 is 4/2 = 2, and for row 3 is 8/2 = 4. Row 2 becomes (0, 1, 1). Row 3 becomes (0, 3, 5).
  2. Column 2. The pivot is 1. The multiplier for row 3 is 3/1 = 3. Row 3 becomes (0, 0, 2).
  3. Collect. U = [[2, 1, 1], [0, 1, 1], [0, 0, 2]] and L = [[1, 0, 0], [2, 1, 0], [4, 3, 1]].
  4. Check. Row 3 of LU is 4 (2, 1, 1) + 3 (0, 1, 1) + 1 (0, 0, 2) = (8, 7, 9), which is row 3 of A.

The Python block builds L and U this way with exact fractions, then solves a system with them.

from fractions import Fraction as F

def lu(A):
    n = len(A)
    L = [[F(0)] * n for _ in range(n)]
    U = [[F(x) for x in row] for row in A]
    for i in range(n):
        L[i][i] = F(1)
    for k in range(n):
        for i in range(k + 1, n):
            m = U[i][k] / U[k][k]
            L[i][k] = m
            U[i] = [U[i][j] - m * U[k][j] for j in range(n)]
    return L, U

def solve_lu(L, U, b):
    n = len(b)
    y = [F(0)] * n
    for i in range(n):
        y[i] = (F(b[i]) - sum(L[i][j] * y[j] for j in range(i))) / L[i][i]
    x = [F(0)] * n
    for i in range(n - 1, -1, -1):
        x[i] = (y[i] - sum(U[i][j] * x[j] for j in range(i + 1, n))) / U[i][i]
    return y, x

A = [[2, 1, 1], [4, 3, 3], [8, 7, 9]]
L, U = lu(A)
print("L =")
for row in L:
    print([str(v) for v in row])
print("U =")
for row in U:
    print([str(v) for v in row])
y, x = solve_lu(L, U, [4, 10, 24])
print("y =", [str(v) for v in y])
print("x =", [str(v) for v in x])

Key ideaThe factorisation is built once, at the cost of the elimination. Each new right-hand side then needs only two triangular solves.

TipCheck L and U by multiplying them back. If the product is not A, one multiplier or one entry of U is wrong.

For A = [[3, 1], [6, 4]], what multiplier clears the 6?

6/3 = 2, so L21 = 2. Row 2 becomes (0, 2), so U22 = 2.

Why does the multiplier go into L and not into U?

L records the row operations applied to A, and U is the result of those operations.

Solving Ax = b with L and U: two easy steps

Because A = LU, the equation Ax = b becomes L(Ux) = b. Let y = Ux. Then solve two triangular systems:

  1. Forward substitution. Solve Ly = b, from the top row down.
  2. Back substitution. Solve Ux = y, from the bottom row up.
Ax = b becomes L(Ux) = b, so first Ly = b, then Ux = y

With the same A and L, U from the previous section, and b = (4, 10, 24): forward substitution gives y = (4, 2, 2), and back substitution gives x = (1, 1, 1). Check: (2 + 1 + 1, 4 + 3 + 3, 8 + 7 + 9) = (4, 10, 24).

Key ideaBuilding L and U costs most of the work, growing like n cubed. Each triangular solve grows like n squared. So for many right-hand sides, factor once and solve many times.

TrapUse L in step one and U in step two. Solving Ux = b directly is wrong, because b is not y.

With L = [[1, 0], [3, 1]], U = [[2, 1], [0, 1]] and b = (3, 10), what is y?

y1 = 3, and 9 + y2 = 10, so y = (3, 1).

Continue: solve Ux = y with U = [[2, 1], [0, 1]] and y = (3, 1).

x2 = 1 and 2x1 + 1 = 3, so x = (1, 1). Check: [[2, 1], [6, 4]] (1, 1) = (3, 10).

When LU fails, and how row swaps repair it

Try to factor A = [[0, 1], [1, 0]]. Its top-left entry is 0, so the first pivot is zero, and no LU decomposition without row swaps exists. Yet the matrix is invertible, with determinant -1. The problem is only the order of the rows.

Use a permutation matrix P to reorder the rows first. Here P = [[0, 1], [1, 0]] gives PA = I, and I = LU with L = I and U = I. So PA = LU holds.

PA = LU, where P records the row swaps

In practice, partial pivoting chooses P during elimination, which keeps the factorisation stable. Without row swaps, LU exists when every pivot is non-zero. With row swaps, PA = LU exists for every invertible matrix. The determinant then picks up a sign for each swap.

TrapDo not assume every matrix has an LU decomposition. A zero pivot means you need P, or the matrix is singular.

Does [[1, 2], [2, 4]] have an LU decomposition without swaps?

Yes. L = [[1, 0], [2, 1]] and U = [[1, 2], [0, 0]]. The matrix is singular, so U has a zero pivot.

What is det(P) when exactly one row swap is made?

One swap changes the sign, so det(P) = -1.

Solved GATE-style problems

Problems 1 to 7 are original GATE-style problems. Problems 8 and 9 are real past questions from GATE papers, rewritten in this format and marked as verified PYQs.

LU of a 2 x 2 matrix

Find L (with 1s on its diagonal) and U so that A = LU, where A = [[3, 1], [6, 4]].

How to think about it

  1. What is asked. L and U.
  2. Which idea applies. The multiplier goes into L, and the result goes into U.
  3. Work it out. The multiplier is 6/3 = 2. Row 2 becomes (0, 4 - 2) = (0, 2). So L = [[1, 0], [2, 1]] and U = [[3, 1], [0, 2]].
  4. Check. Entry (2,2) of LU is 2 x 1 + 1 x 2 = 4, as required.

Answer: L = [[1, 0], [2, 1]] and U = [[3, 1], [0, 2]].

True statements about LU (MSQ)

Select all true statements.

(A) In the Doolittle form, L has 1s on its diagonal.
(B) U is upper triangular.
(C) Every invertible matrix has an LU decomposition without row swaps.
(D) If A = LU with L having 1s on its diagonal, then det(A) equals the product of the diagonal of U.

How to think about it

  1. What is asked. Test four facts.
  2. Which idea applies. The Doolittle form, the shape of U, and the determinant of a product.
  3. Work it out. (A) true, by definition. (B) true. (C) false: [[0, 1], [1, 0]] is invertible but has no such LU. (D) true, since det(L) = 1.
  4. Check. The counterexample in (C) is the matrix from the PA = LU section.

Answer: (A), (B) and (D).

Solve a system using LU (NAT)

Let A = [[2, 1], [4, 5]] and b = (4, 14). Use A = LU, with L having 1s on its diagonal, to solve Ax = b. Find x1. Give a single number.

How to think about it

  1. What is asked. The first entry of x.
  2. Which idea applies. Factor, then solve Ly = b and Ux = y.
  3. Work it out. The multiplier is 2, so L = [[1, 0], [2, 1]] and U = [[2, 1], [0, 3]]. Forward: y1 = 4 and 8 + y2 = 14, so y2 = 6. Back: 3x2 = 6, so x2 = 2, and 2x1 + 2 = 4, so x1 = 1.
  4. Check. A (1, 2) = (2 + 2, 4 + 10) = (4, 14).

Answer: 1.

Determinant from LU (NAT)

Let A = [[2, 1, 1], [4, 3, 3], [8, 7, 9]], whose LU decomposition is given in the guide. Find det(A). Give a single number.

How to think about it

  1. What is asked. One number.
  2. Which idea applies. det(A) = det(L) x det(U), and det(L) = 1.
  3. Work it out. The diagonal of U is 2, 1, 2, so det(A) = 4.
  4. Check. Expanding along row 1: 2 (27 - 21) - (36 - 24) + (28 - 24) = 12 - 12 + 4 = 4.

Answer: 4.

Facts about a matrix with no LU without swaps (MSQ)

Let A = [[0, 1], [1, 0]]. Select all true statements.

(A) A has an LU decomposition with no row swaps.
(B) There is a permutation matrix P with PA = LU.
(C) det(A) = -1.
(D) A is upper triangular.

How to think about it

  1. What is asked. Test four facts.
  2. Which idea applies. The first pivot is 0, so a row swap is needed.
  3. Work it out. (A) false. (B) true: P = [[0, 1], [1, 0]] gives PA = I. (C) true: 0 x 0 - 1 x 1 = -1. (D) false.
  4. Check. These match the PA = LU section.

Determinant and factors (MSQ)

A is a 3 x 3 matrix with A = LU, where L has 1s on its diagonal and the diagonal of U is (2, 5, 7). Select all true statements.

(A) det(U) = 70
(B) det(L) = 70
(C) det(A) = det(L) x det(U)
(D) If U had diagonal (2, 0, 7), then A would be invertible

How to think about it

  1. What is asked. Test four facts about determinants of the factors.
  2. Which idea applies. A triangular determinant is the product of its diagonal.
  3. Work it out. (A) true, 2 x 5 x 7 = 70. (B) false, det(L) = 1. (C) true, the product rule. (D) false, a zero on the diagonal of U makes det(A) = 0.
  4. Check. From (A) and (C), det(A) = 1 x 70 = 70.

Answer: (A) and (C).

Sum of the multipliers (NAT)

Let A = [[1, 1, -2], [1, 3, -1], [2, 1, -5]]. Run elimination, and let m21, m31 and m32 be the multipliers used to clear entries (2,1), (3,1) and (3,2). Find m21 + m31 + m32. Give a single number.

How to think about it

  1. What is asked. The sum of the multipliers.
  2. Which idea applies. The multipliers are the entries of L below its diagonal.
  3. Work it out. m21 = 1 and m31 = 2. Row 2 becomes (0, 2, 1) and row 3 becomes (0, -1, -1). Then m32 = -1/2. The sum is 1 + 2 - 1/2 = 5/2.
  4. Check. These are the L entries of the verified PYQ below, which uses this matrix.

Answer: 5/2 (that is, 2.5).

GATE CSE 2015 Set 1 (verified PYQ): an entry of L with a unit diagonal in U (NAT)

In the LU decomposition of [[2, 2], [4, 9]], the diagonal entries of U are both 1. Find l22, the lower diagonal entry of L. Give a single number.

How to think about it

  1. What is asked. l22.
  2. Which idea applies. With U having 1s on its diagonal (Crout form), L carries the pivots. Multiply L and U and match entries.
  3. Work it out. l11 = 2 and l11 u12 = 2, so u12 = 1. Also l21 = 4. Then l21 u12 + l22 = 9 gives 4 + l22 = 9, so l22 = 5.
  4. Check. L = [[2, 0], [4, 5]] and U = [[1, 1], [0, 1]] multiply to [[2, 2], [4, 9]].

Answer: 5. This is a verified PYQ from GATE CSE 2015 Set 1, rewritten into the format of this page.

GATE CSE 2022 Q35 (verified PYQ): entries of L and U and a solution (NAT)

Solve x1 + x2 - 2x3 = 4, x1 + 3x2 - x3 = 7, and 2x1 + x2 - 5x3 = 7 by LU decomposition, where L is lower triangular with 1s on its diagonal and U is upper triangular. Find L32, U33 and x1, as three numbers.

How to think about it

  1. What is asked. One entry of L, one entry of U, and one unknown.
  2. Which idea applies. Elimination records the multipliers in L and leaves U. Then solve Ly = b and Ux = y.
  3. Work it out. Multipliers m21 = 1 and m31 = 2. Row 2 becomes (0, 2, 1) and row 3 becomes (0, -1, -1). Then m32 = -1/2, and row 3 becomes (0, 0, -1/2), so U33 = -1/2. Forward: y = (4, 3, 1/2). Back: x3 = -1, x2 = 2, and x1 = 0.
  4. Check. (0, 2, -1) satisfies all three original equations. The Python block repeats the factorisation with exact fractions.

Exam-level 1: Doolittle entry (NAT, 2 marks)

A = [[2, 1, 1], [4, 3, 3], [8, 7, 9]] = LU with L unit lower triangular. Find u33.

How to think about it

  1. What is asked. The last pivot of U.
  2. Which idea applies. The product of the diagonal of U equals det(A), since det(L) = 1.
  3. Work it out. Elimination: l21 = 2, row 2 becomes (0, 1, 1). l31 = 4, row 3 becomes (0, 3, 5). l32 = 3, row 3 becomes (0, 0, 2). So u33 = 2.
  4. Check. det(A) = 2 · 1 · 2 = 4. The code confirms with the Doolittle loop.
A = [[2, 1, 1], [4, 3, 3], [8, 7, 9]]
n = 3
L = [[float(i == j) for j in range(n)] for i in range(n)]
U = [[0.0] * n for _ in range(n)]
for i in range(n):
    for j in range(i, n):
        U[i][j] = A[i][j] - sum(L[i][k] * U[k][j] for k in range(i))
    for j in range(i + 1, n):
        L[j][i] = (A[j][i] - sum(L[j][k] * U[k][i] for k in range(i))) / U[i][i]
print("L =", L)
print("U =", U)

L = [[1.0, 0.0, 0.0], [2.0, 1.0, 0.0], [4.0, 3.0, 1.0]]
U = [[2, 1, 1], [0.0, 1.0, 1.0], [0.0, 0.0, 2.0]]

Answer: u33 = 2.

Exam-level 2: When LU fails (MSQ, 2 marks)

Which statements about LU decomposition without row exchanges are TRUE? (A) It exists if all leading principal minors are nonzero. (B) [[0, 1], [1, 0]] has such an LU. (C) Partial pivoting gives PA = LU for any square A. (D) If A = LU with unit L, then det(A) is the product of diagonal entries of U.

How to think about it

  1. What is asked. Conditions for and consequences of LU.
  2. Which idea applies. Pivots are ratios of leading principal minors. A zero first pivot breaks plain elimination.
  3. Work it out. (A) True. (B) The first pivot is 0, so no LU without a swap. False. (C) True: with row swaps, every square matrix (even singular) has PA = LU. (D) det L = 1, so det A = det U. True.
  4. Check. For [[0, 1], [1, 0]], swapping rows gives I = LU with L = U = I.

Answer: (A), (C) and (D).

Exam-level 3: Cholesky factor (NAT, 2 marks)

A = [[4, 2], [2, 5]] = LLᵀ with L lower triangular and positive diagonal. Find l22.

How to think about it

  1. What is asked. The second diagonal entry of the Cholesky factor.
  2. Which idea applies. l11 = √a11, l21 = a21/l11, l22 = √(a22 − l21²).
  3. Work it out. l11 = 2, l21 = 1, l22 = √(5 − 1) = 2.
  4. Check. LLᵀ = [[4, 2], [2, 1 + 4]] = A.
import math
l11 = math.sqrt(4); l21 = 2 / l11; l22 = math.sqrt(5 - l21 ** 2)
print(l11, l21, l22)

2.0 1.0 2.0

Answer: 2.

  2. U is the staircase left after elimination.
