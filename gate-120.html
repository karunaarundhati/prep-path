Kirchhoff's Laws (KCL, KVL)

Kirchhoff's current law (KCL) and voltage law (KVL) are two conservation rules. Together they let you write one equation for every node and every loop of a circuit, and then solve for any unknown current or voltage.

The idea in plain words

Imagine a water network of pipes. Water does not appear or disappear at a junction. Whatever flows into a junction must flow out again. Also, if you walk around any closed loop of pipes and return to where you started, your height has not changed overall. Some parts go up and some go down, but the total is zero.

Electric circuits follow the same two rules. Kirchhoff's current law (KCL) says that charge does not pile up at a junction. Kirchhoff's voltage law (KVL) says that energy is conserved around a closed loop. Both laws are about conservation, and both are simple to state. The skill is in applying them carefully with the right signs.

Everyday analogy: a group of friends sharing the cost of a meal. Each person pays part, and the total paid equals the bill. KCL is like that: the currents into a node add up to the currents out.

Why it matters for GATE. In the Robotics and Automation (RA) paper, many circuit questions ask for an unknown current or voltage. You write KCL or KVL equations, then solve them. The equations are short, but the signs are easy to get wrong, so each step in this topic is shown in full.

Key terms

Node
Plain: a junction where two or more wires meet. Precise: a point in a circuit where at least two branches connect.
Branch
Plain: a single path between two nodes, usually one element. Precise: a part of the circuit containing one element, connected between two nodes.
Loop
Plain: a closed path that starts and ends at the same node, without passing through any node twice. Precise: a closed path in the circuit.
Mesh
Plain: a loop with no other loop inside it. Precise: a loop in a planar circuit that encloses no element.
Reference direction
The arrow we draw for a current, and the + and - marks we draw for a voltage. It is a choice, not the true direction.
Ground (reference node)
The node we choose as having zero voltage. All other node voltages are measured from it.
Node voltage
The voltage of a node measured from the ground node.
Mesh current
A current we assume flows around a mesh. Real branch currents are found by combining mesh currents.
Ohm's law
For a resistor, v = i R, which links the voltage across it and the current through it.

Concept 1: Nodes, branches and loops

Before writing any law, you must see the structure of the circuit. Take the simple circuit below. A 10 V source drives a current around a loop through two resistors.

        +-------- R1 = 2 ohm --------+
        |                             |
       (+)                            |
      10 V                            R2 = 3 ohm
       (-)                            |
        |                             |
        +-----------------------------+

This circuit has no branching. The source and the two resistors are joined end to end in one closed path, so the same current flows through all three. That closed path is the only loop, and it is also the only mesh.

In a larger circuit, a node is a junction where three or more wires meet. KCL is applied at those junctions. KVL is applied around each closed loop.

TipBefore solving any circuit, label the nodes with letters, draw the current arrows, and mark the + and - for each voltage. Most mistakes happen because a sign was guessed rather than drawn.

Question: How many loops does a circuit with one source and two resistors in a single line have?

One loop, the outer path. There is no branching, so there is only one closed path.

Question: What is a node?

A junction where two or more branches connect.

Concept 2: Kirchhoff's current law (KCL)

KCL says: the sum of currents entering a node equals the sum of currents leaving it. Charge does not build up at a node, so whatever comes in must go out. This is conservation of charge.

A convenient way to write this is with signed currents. Pick a direction for each current. Count the currents that enter as positive, and the currents that leave as negative. Then:

sum of all currents at a node = 0

The symbol sum of means add up all the terms. Each current carries a plus sign if it enters the node and a minus sign if it leaves. Both forms give the same equation.

Worked example: a node with two resistors

A current source pushes 5 A into a node. The node connects to ground through two resistors, R1 = 1 Ω and R2 = 4 Ω. Find the node voltage V and the two branch currents.

                    node V
   5 A  -->---------+---------+
   (into node)         |         |
                     R1 = 1      R2 = 4
                       |         |
                      ground    ground
  1. Write the branch currents using Ohm's law. The current from the node to ground through R1 is V/R1 = V/1 = V. The current through R2 is V/R2 = V/4.
  2. Write KCL at the node. The 5 A enters the node. The two resistor currents leave it. So 5 = V/1 + V/4.
  3. Solve. Combine the terms: V + V/4 = 5V/4 = 5. Multiply both sides by 4/5: V = 4 V.
  4. Find the currents. Through R1: 4 V / 1 Ω = 4 A. Through R2: 4 V / 4 Ω = 1 A.
  5. Check KCL. Currents leaving the node are 4 A + 1 A = 5 A, which equals the 5 A entering. The check passes.

Here is the same calculation in Python, with exact fractions. The check at the end tests KCL directly.

from fractions import Fraction as F

Is = 5                              # amperes injected into the node
R1, R2 = 1, 4                       # ohms, from the node to ground
G = F(1, R1) + F(1, R2)             # total conductance, 1/R1 + 1/R2
V = F(Is) / G                       # KCL: Is = V/R1 + V/R2
print("Node voltage (V):", V)
print("Current through R1 (A):", V / R1)
print("Current through R2 (A):", V / R2)
print("KCL check:", V / R1 + V / R2 == Is)
Node voltage (V): 4
Current through R1 (A): 4
Current through R2 (A): 1
KCL check: True

TrapPick a direction for each current before you write KCL, and keep it fixed. A current you assumed leaving the node may come out negative, which means it really enters. A negative answer is not an error.

Key ideaA circuit with n nodes has one KCL equation for each node, but only n - 1 of them are independent. The last one follows from the others.

Question: At a node, 3 A and 2 A enter, and 4 A leaves through one branch. Is KCL satisfied?

Entering: 3 + 2 = 5 A. Leaving: 4 A. They do not match, so either another branch carries 1 A out, or the 4 A value is wrong.

Question: Why does a circuit with n nodes need only n - 1 KCL equations?

The sum of all the KCL equations is automatically zero, because every current appears once entering and once leaving. So the last equation adds no new information.

Concept 3: Kirchhoff's voltage law (KVL)

KVL says: the sum of voltages around any closed loop is zero. If you start at a point, travel around a loop, and return to the start, the voltage rises and drops add up to zero. This is conservation of energy: a charge that goes around a loop and returns to its start has no net gain of energy.

To apply KVL, choose a direction for the loop. Each element's voltage gets a plus sign if you meet its + terminal first, and a minus sign if you meet its - terminal first. Then:

sum of voltages around a closed loop = 0

Using the passive sign convention, the voltage across a resistor is v = i R, where i is the current in the reference direction. If the loop direction matches the current, the drop is +i R.

Worked example: a single loop

Use the loop from Concept 1, with Vs = 10 V, R1 = 2 Ω and R2 = 3 Ω in series. Let the current i flow clockwise.

  1. Write the voltages around the loop, in the direction of the current. Going around: the source gives a rise of +10 V, the drop across R1 is -i R1 = -2i, and the drop across R2 is -i R2 = -3i.
  2. Apply KVL. 10 - 2i - 3i = 0.
  3. Solve. Combine the terms: 10 - 5i = 0. So 5i = 10, and i = 2 A.
  4. Find each voltage. Across R1: 2 × 2 = 4 V. Across R2: 2 × 3 = 6 V. The sum of the drops is 4 + 6 = 10 V, which equals the source rise.
  5. Check. The voltages around the loop sum to 10 - 4 - 6 = 0. KVL holds.

This is the most common GATE pattern: a source, several resistors in series, and one current to find. The rule is simple once you can see the loop.

TrapKVL uses the loop direction, and KCL uses the node direction. A rise is a drop read in reverse. If you go around a resistor in the direction of the current, you have a drop. If you go against the current, you have a rise.

TipWrite the loop equation with all the terms in one direction, and check the sign of each source by asking "do I meet the + terminal first?" It is easy to miss a sign.

Question: A loop has a 9 V source and two resistors, 1 Ω and 2 Ω, in series. What is the current?

KVL: 9 - i(1) - i(2) = 0, so 3i = 9, and i = 3 A.

Question: Around a loop, the voltages are +12 V, -4 V and -5 V. Does KVL hold?

No. The sum is 12 - 4 - 5 = 3 V, not zero. There must be a missing element or a sign error.

Concept 4: Solving circuits with node and mesh equations

Most circuits have several loops and several nodes. Writing a KCL or KVL equation for each one gives a set of linear equations. Solving them gives every unknown. There are two standard systematic methods.

Nodal analysis (uses KCL)

  1. Choose one node as ground, with voltage zero.
  2. Give each other node an unknown voltage, such as Va.
  3. Write KCL at each node that is not ground. Express each branch current with Ohm's law, as (Va - Vb) / R for a resistor between nodes a and b.
  4. Solve the resulting equations.

Mesh analysis (uses KVL)

  1. Identify the meshes. Each mesh is a loop with no loop inside it.
  2. Assign a mesh current to each mesh, all in the same direction (say clockwise).
  3. Write KVL around each mesh, using the mesh currents. A resistor shared by two meshes carries the difference of their mesh currents.
  4. Solve the resulting equations. The real branch current in a shared element is the difference of the two mesh currents.

Worked example: two meshes

Mesh 1 contains a 12 V source, a 2 Ω resistor R1 and a shared 4 Ω resistor R3. Mesh 2 contains R3 and a 6 Ω resistor R2, with no source. Let the mesh currents be i1 and i2, both clockwise.

  1. KVL for mesh 1. The source gives +12 V. R1 drops 2 i1. R3 carries i1 - i2 and drops 4(i1 - i2). So 12 - 2 i1 - 4(i1 - i2) = 0. Simplify: 6 i1 - 4 i2 = 12.
  2. KVL for mesh 2. R3 carries i2 - i1 in this loop, so it drops 4(i2 - i1). R2 drops 6 i2. So 4(i2 - i1) + 6 i2 = 0. Simplify: -4 i1 + 10 i2 = 0.
  3. Solve. From the second equation, i2 = (4/10) i1 = (2/5) i1. Substitute into the first: 6 i1 - 4 (2/5) i1 = 12. This gives (6 - 8/5) i1 = 12, which is (22/5) i1 = 12, so i1 = 60/22 = 30/11 A. Then i2 = (2/5)(30/11) = 12/11 A.
  4. Check. Put i1 = 30/11 and i2 = 12/11 back into mesh 1: 6(30/11) - 4(12/11) = 180/11 - 48/11 = 132/11 = 12. Correct.

The next Python check solves the mesh equations exactly. It writes them as a matrix equation and uses Cramer's rule, which is a formula for 2 by 2 systems.

from fractions import Fraction as F

# Mesh equations written as a * [i1, i2] = b
# Mesh 1: (2 + 4) i1 - 4 i2 = 12
# Mesh 2: -4 i1 + (4 + 6) i2 = 0
a11, a12, b1 = 6, -4, 12
a21, a22, b2 = -4, 10, 0
det = a11 * a22 - a12 * a21          # determinant of the 2 by 2 matrix
i1 = F(b1 * a22 - a12 * b2, det)     # Cramer's rule
i2 = F(a11 * b2 - a21 * b1, det)
print("i1 (A):", i1)
print("i2 (A):", i2)
print("Mesh 1 check:", 6 * i1 - 4 * i2 == 12)
print("Mesh 2 check:", -4 * i1 + 10 * i2 == 0)
i1 (A): 30/11
i2 (A): 12/11
Mesh 1 check: True
Mesh 2 check: True

GATE loves thisThe number of independent KVL equations for a planar circuit is b - n + 1, where b is the number of branches and n is the number of nodes. This equals the number of meshes, and it is often asked as a counting question.

Question: In mesh analysis, why does a shared resistor carry the difference of two mesh currents?

The two meshes flow through it in opposite directions. The real current is the difference, with the sign set by the direction of the larger mesh current.

Question: Which method uses KCL, and which uses KVL?

Nodal analysis uses KCL. Mesh analysis uses KVL.

Solved GATE-style problems

These problems are original, written in the style of GATE. They are not past exam questions.

Unknown outgoing current

At a node, currents of 3 A and 2 A flow in. Two other currents flow out of the node, one of 4 A and one of x A. Find x, in amperes.

How to think about it

  1. What is asked. The value of x.
  2. Which idea applies. KCL: entering currents equal leaving currents.
  3. Work it out. Entering: 3 + 2 = 5 A. Leaving: 4 + x. So 5 = 4 + x, and x = 1 A.
  4. Check. Entering 5 A and leaving 4 + 1 = 5 A. The totals match.

Answer: x = 1 A.

Voltage across one resistor in a loop

A 9 V source is connected in a single loop with a 1 Ω resistor and a 2 Ω resistor in series. What is the voltage across the 2 Ω resistor, in volts?

How to think about it

  1. What is asked. The voltage across the 2 Ω resistor.
  2. Which idea applies. KVL gives the current. Ohm's law gives the voltage.
  3. Work it out. KVL: 9 - 1i - 2i = 0, so 3i = 9 and i = 3 A. Voltage across 2 Ω = 3 × 2 = 6 V.
  4. Check. The drop across 1 Ω is 3 V. The drops 3 + 6 = 9 V equal the source, so KVL holds.

Answer: 6 V.

Laws and conservation (select all that apply)

Which statements about Kirchhoff's laws are true? Select all that apply.

(A) KCL follows from conservation of charge.
(B) KVL follows from conservation of energy.
(C) The sum of the currents leaving a node is always 1 A.
(D) A circuit with n nodes has n - 1 independent KCL equations.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. KCL is conservation of charge. KVL is conservation of energy.
  3. Work it out. (A) is true. (B) is true. (C) is false, the sum depends on the circuit, and it is not fixed at 1 A. (D) is true, as explained in Concept 2.
  4. Check. A statement with a fixed number such as "1 A" cannot be a law, because currents depend on the circuit.

Answer: (A), (B) and (D).

Node voltage with a current source

A 6 A current source pushes current into a node. The node connects to ground through a 2 Ω resistor and a 3 Ω resistor. Find the node voltage in volts. Give a decimal.

How to think about it

  1. What is asked. The node voltage V, in volts.
  2. Which idea applies. KCL at the node: 6 = V/2 + V/3.
  3. Work it out. V/2 + V/3 = 5V/6. So 5V/6 = 6, and V = 36/5 = 7.2 V.
  4. Check. The currents are 7.2/2 = 3.6 A and 7.2/3 = 2.4 A. Their sum is 6 A, as required.

Answer: 7.2 V.

Current in a three-resistor loop

A 10 V source drives a single loop containing resistors of 2 Ω, 3 Ω and 5 Ω in series. Find the voltage across the 5 Ω resistor, in volts.

How to think about it

  1. What is asked. The voltage across 5 Ω.
  2. Which idea applies. The total resistance is the sum, and the same current flows through all three.
  3. Work it out. Total resistance = 2 + 3 + 5 = 10 Ω. Current i = 10 / 10 = 1 A. Voltage across 5 Ω = 1 × 5 = 5 V.
  4. Check. The drops are 2 V, 3 V and 5 V, which add to 10 V, the source value.

Answer: 5 V.

Current in a two-mesh circuit

Mesh 1 contains a 10 V source, a 1 Ω resistor and a shared 1 Ω resistor. Mesh 2 contains the shared 1 Ω resistor and a 3 Ω resistor, with no source. Let i1 and i2 be the clockwise mesh currents. Find i2, in amperes.

How to think about it

  1. What is asked. The mesh current i2.
  2. Which idea applies. Mesh analysis: KVL in each mesh.
  3. Work it out. Mesh 1: 10 - i1 - (i1 - i2) = 0, so 2 i1 - i2 = 10. Mesh 2: (i2 - i1) + 3 i2 = 0, so -i1 + 4 i2 = 0. From the second equation, i1 = 4 i2. Substitute: 8 i2 - i2 = 10, so 7 i2 = 10, and i2 = 10/7 A.
  4. Check. Then i1 = 40/7 A. Mesh 1 gives 2(40/7) - 10/7 = 70/7 = 10. Mesh 2 gives -40/7 + 4(10/7) = 0. Both hold.

Answer: i2 = 10/7 A, which is about 1.43 A.

Counting independent equations

A planar circuit has 5 nodes and 7 branches. How many independent mesh (KVL) equations can be written? Give a whole number.

How to think about it

  1. What is asked. The number of independent KVL equations.
  2. Which idea applies. For a planar circuit, the number of independent loops is b - n + 1.
  3. Work it out. b = 7 and n = 5, so 7 - 5 + 1 = 3.
  4. Check. The circuit also needs n - 1 = 4 independent KCL equations. Together, 4 + 3 = 7 equations, which equals the number of branch currents. This matches the number of unknowns.

Answer: 3.

Exam-level practice

Exam-level 1: KVL in a loop (NAT, 2 marks)

A single loop has a 24 V source and resistors 2 Ω, 4 Ω and 6 Ω in series. Find the voltage across the 4 Ω resistor.

How to think about it

  1. What is asked. One voltage drop.
  2. Which idea applies. Current I = V/Rtotal, then V = IR.
  3. Work it out. I = 24/12 = 2 A. V4 = 8 V.
  4. Check. Drops 4 + 8 + 12 = 24 V, as KVL requires.

Answer: 8 V.

Exam-level 2: KCL with a dependent current (NAT, 2 marks)

At a node, a 3 A current enters, a current I leaves through 2 Ω to ground, and a current 0.5V leaves through a controlled source, where V is the node voltage. Find V.

How to think about it

  1. What is asked. The node voltage.
  2. Which idea applies. KCL: in = out, with I = V/2.
  3. Work it out. 3 = V/2 + 0.5V = V. So V = 3 V.
  4. Check. Both branches carry 1.5 A.

Answer: 3 V.

Exam-level 3: Two loop circuit (NAT, 2 marks)

A 10 V source feeds 2 Ω in series with the parallel pair 3 Ω and 6 Ω. Find the current through the 6 Ω resistor.

How to think about it

  1. What is asked. A branch current.
  2. Which idea applies. Reduce the parallel pair, find the total current, then use the current divider.
  3. Work it out. 3 ∥ 6 = 2 Ω. Total 4 Ω, I = 2.5 A. I6 = 2.5 · 3/9 = 0.833 A.
  4. Check. I3 = 1.667 A, and 0.833 + 1.667 = 2.5 A.
I = 10 / (2 + 3 * 6 / 9)
print("%.3f" % (I * 3 / 9))

0.833

Answer: about 0.833 A.

Remember these

  1. KCL is conservation of charge. KVL is conservation of energy.
  2. Draw the reference directions first, and keep them fixed.
  3. Use KCL at nodes and KVL around loops, with signs set by the reference directions.
