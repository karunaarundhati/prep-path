Mean value theorems & indeterminate forms

The mean value theorems say that a smooth curve must have a point where its slope matches its average slope. The indeterminate forms are the awkward limits that need extra care, and L'Hopital's rule handles most of them. Both topics are standard in GATE RA and DA.

The idea in plain words

Imagine a car trip that starts at 9 o'clock and ends at 11 o'clock. The car covers 120 kilometres, so its average speed is 60 kilometres per hour. Did the speedometer ever read exactly 60 at some moment? It must have. If the car was always slower, the total distance would be less. This simple intuition is the mean value theorem. A smooth curve must, at some point, have the same slope as the slope of the straight line joining its two ends.

The second big idea is the indeterminate form. When you substitute a number into a limit, you sometimes get 0/0 or infinity over infinity. These answers do not tell you the limit. They are like a question mark. Think of two runners arriving at the finish line together. The finish line does not say who was faster. L'Hopital's rule looks at their speeds just before the line.

Why does this matter for GATE? Both ideas appear in quick questions about proofs and bounds, and in numerical questions that ask for a limit. A correct method saves time in the exam, and a wrong method costs marks even when the algebra looks neat.

Key terms

Each term has a plain meaning first, then a precise definition.

Secant line
Plain meaning: a straight line that cuts through two points on a curve. Precise definition: the line through (a, f(a)) and (b, f(b)), with slope (f(b) minus f(a))/(b minus a).
Tangent line
Plain meaning: a straight line that just touches the curve at one point and has the same slope there. Precise definition: the line through (c, f(c)) with slope f'(c).
Continuous on [a, b]
Plain meaning: no breaks anywhere between a and b, including the ends. Precise definition: f is continuous at every point of the closed interval.
Differentiable on (a, b)
Plain meaning: no corners, cusps or breaks inside the open interval. Precise definition: f'(x) exists for every x strictly between a and b.
Indeterminate form
Plain meaning: a form that gives no answer on substitution. Precise definition: 0/0, inf/inf, 0 times inf, inf minus inf, 1^inf, 0^0 or inf^0.
Natural logarithm
Plain meaning: the power to which e must be raised to get the number. Precise definition: ln(x) is the inverse of e^x, so ln(e^x) = x and e^(ln x) = x.
L'Hopital's rule
Plain meaning: differentiate top and bottom for 0/0 or inf/inf. Precise definition: if lim f/g is 0/0 or inf/inf, then it equals lim f'/g' whenever the right side exists.

TipIn this topic, "e" means the number 2.71828... It is the base of the natural logarithm, and it is the answer to several standard limits.

Rolle's theorem

Picture a roller coaster that starts and ends at the same height. Somewhere along the track, the cart must reach a flat point, either a top or a bottom. Rolle's theorem says exactly this, in mathematical language.

Rolle's theorem needs three conditions. If all three hold, the conclusion follows.

  1. f is continuous on the closed interval [a, b].
  2. f is differentiable on the open interval (a, b).
  3. f(a) = f(b).
Conclusion: there is some c with a < c < b and f'(c) = 0

The conditions matter. If the curve has a corner or a break, the conclusion can fail, because there may be no smooth flat point. Always check the three conditions before you use the theorem.

Worked example. Let f(x) = x squared minus 4x plus 3 on [1, 3].

  1. Step 1, continuity and differentiability. f is a polynomial, so it is continuous and differentiable everywhere.
  2. Step 2, equal ends. f(1) = 1 minus 4 plus 3 = 0, and f(3) = 9 minus 12 plus 3 = 0. The ends are equal.
  3. Step 3, find the flat point. f'(x) = 2x minus 4. Setting f'(c) = 0 gives 2c = 4, so c = 2.
  4. Step 4, check. c = 2 lies strictly between 1 and 3, as the theorem promises.
def f(x):
    return x * x - 4 * x + 3

print("f(1) =", f(1), " f(3) =", f(3), " f'(2) =", 2 * 2 - 4)
f(1) = 0  f(3) = 0  f'(2) = 0
Quick check: does Rolle's theorem apply to f(x) = |x| on [-1, 1]?

No. f(-1) = f(1) = 1, so the ends are equal, but f is not differentiable at 0, which lies inside (-1, 1). The corner at 0 breaks the second condition.

Quick check: what is c for f(x) = x squared minus 4 on [-2, 2]?

f(-2) = f(2) = 0 and f'(x) = 2x. Setting 2c = 0 gives c = 0, which lies strictly inside (-2, 2).

Lagrange's mean value theorem

Rolle's theorem needs equal ends. Lagrange's mean value theorem removes that need. It says that the average slope over an interval equals the instantaneous slope at some point inside it. Think of the car trip again: the average speed is 60 kilometres per hour, and at some moment the speedometer showed exactly 60.

f'(c) = (f(b) minus f(a))/(b minus a), for some c with a < c < b

Each symbol means:

  • (f(b) minus f(a))/(b minus a) is the slope of the secant line joining the two ends. This is the average slope.
  • f'(c) is the slope of the tangent at some point c inside the interval.
  • a < c < b says c is strictly inside the interval, not at an end.

Geometrically, somewhere between the two points the tangent line is parallel to the secant line. The conditions are the same as Rolle's theorem, except that f(a) need not equal f(b). Rolle's theorem is the special case where the secant is horizontal.

Worked example. Let f(x) = x cubed on [0, 2].

  1. Step 1, the secant slope. (f(2) minus f(0))/(2 minus 0) = (8 minus 0)/2 = 4.
  2. Step 2, the tangent slope. f'(x) = 3x squared, so f'(c) = 3c squared.
  3. Step 3, solve. 3c squared = 4 gives c squared = 4/3, so c = sqrt(4/3), which is about 1.1547.
  4. Step 4, check. 1.1547 lies between 0 and 2, so the theorem holds.
import math

c = math.sqrt(4 / 3)
print("c =", f"{c:.4f}", "0 < c < 2:", 0 < c < 2, "check 3c^2 =", f"{3 * c * c:.4f}")
c = 1.1547 0 < c < 2: True check 3c^2 = 4.0000

TrapThe theorem promises that c exists, but it does not say how many such points there are. There may be one, or several. Also, c must be strictly inside the interval, so an answer at an end point is wrong.

Quick check: for f(x) = x squared on [0, 4], what is the value of c given by the theorem?

The secant slope is (16 minus 0)/4 = 4. Since f'(c) = 2c, we need 2c = 4, so c = 2, which lies inside (0, 4).

Quick check: why is the theorem not the same as Rolle's theorem?

Rolle's theorem needs f(a) = f(b), so the secant is horizontal. Lagrange's version allows any secant slope, and so it covers more cases.

Cauchy's mean value theorem

Cauchy's mean value theorem uses two functions instead of one. It compares how fast f and g change over the same interval. Think of two cars that start together and are timed over the same route. Their speeds may differ, but there is a moment when the ratio of their speeds equals the ratio of their average speeds.

(f(b) minus f(a))/(g(b) minus g(a)) = f'(c)/g'(c), for some c with a < c < b

Here is what each symbol means:

  • f and g are two functions, both continuous on [a, b] and differentiable on (a, b).
  • f'(c) and g'(c) are the two derivatives at the same point c.

TrapYou must have g'(c) not equal to 0 at the point c, and also g(b) not equal to g(a), before dividing. In exam questions, check these conditions first.

Cauchy's theorem is the key step in proving L'Hopital's rule. The rule says that the ratio of the functions near a point equals the ratio of their derivatives, under the right conditions. You do not need the full proof for GATE, but you should know the statement and the conditions.

Quick check: when Cauchy's theorem is used with g(x) = x, what does it reduce to?

Then g(b) minus g(a) = b minus a and g'(c) = 1. The formula becomes (f(b) minus f(a))/(b minus a) = f'(c), which is exactly Lagrange's theorem.

Using the mean value theorem for bounds

The mean value theorem is useful even when you cannot find c. You know c lies in an interval, and if you know the range of the derivative on that interval, you can trap the secant slope. This is how many inequality proofs work.

Example: a bound for ln(1 + x). Take f(t) = ln(1 + t) on the interval [0, x], where x is positive. Then f'(t) = 1/(1 + t). Lagrange's theorem gives

ln(1 + x) minus ln(1) = x times 1/(1 + c), for some c with 0 < c < x

Since 0 < c < x, we have 1 < 1 + c < 1 + x, so 1/(1 + x) < 1/(1 + c) < 1. Multiply by x and use ln(1) = 0:

x/(1 + x) < ln(1 + x) < x, for every x greater than 0

The next program tests this inequality for x = 0.5, where the bounds are 1/3 and 1/2.

import math

x = 0.5
lo, hi, val = x / (1 + x), x, math.log(1 + x)
print("lower =", f"{lo:.4f}", "ln(1.5) =", f"{val:.4f}", "upper =", f"{hi:.4f}", "bounds hold:", lo < val < hi)
lower = 0.3333 ln(1.5) = 0.4055 upper = 0.5000 bounds hold: True

Key ideaTo bound a difference of function values, apply the mean value theorem, then bound the derivative at the unknown point c using the interval that contains c.

Quick check: using the bound above, is ln(1.1) at least 0.0909?

Yes. With x = 0.1, the lower bound is x/(1 + x) = 0.1/1.1 = 0.0909..., and ln(1.1) is about 0.0953, which is larger.

Quick check: why must the derivative be bounded on the whole interval?

Because c is unknown. The only safe way to bound 1/(1 + c) is to use the smallest and largest possible values of 1/(1 + t) for t in the interval.

The seven indeterminate forms

An indeterminate form is an answer that the substitution cannot decide. The table below lists all seven forms and the first step to take for each. Most can be rewritten as 0/0 or inf/inf, and then L'Hopital's rule applies.

FormMeaningFirst step
0/0Both top and bottom go to 0Apply L'Hopital's rule directly
inf/infBoth top and bottom go to infinityApply L'Hopital's rule directly
0 times infOne factor goes to 0, the other to infinityRewrite as f/(1/g), a 0/0 or inf/inf form
inf minus infTwo large numbers are subtractedCombine into one fraction
1^infBase goes to 1, power goes to infinityTake the logarithm, then exponentiate
0^0Base and power both go to 0Take the logarithm, then exponentiate
inf^0Base goes to infinity, power goes to 0Take the logarithm, then exponentiate

Logarithm trick. For the last three forms, let y = f(x) raised to the power g(x). Then ln(y) = g(x) times ln(f(x)). Find the limit of ln(y), which usually becomes a 0 times inf form, and then the answer is e raised to that limit.

Example A, 0 times inf. Find lim (x approaches 0 from the right) of x ln(x).

  1. Step 1. Substitution gives 0 times minus infinity, which is indeterminate.
  2. Step 2. Rewrite as ln(x)/(1/x). Now the form is inf/inf, because ln(x) goes to minus infinity and 1/x goes to plus infinity.
  3. Step 3. Apply L'Hopital's rule: the derivative of ln(x) is 1/x, and the derivative of 1/x is minus 1/x squared. The new fraction is (1/x) divided by (minus 1/x squared), which equals minus x.
  4. Step 4. As x goes to 0, minus x goes to 0. The limit is 0.
import math

for x in [0.1, 0.01, 0.001]:
    print("x =", x, "x ln x =", f"{x * math.log(x):.4f}")
x = 0.1 x ln x = -0.2303
x = 0.01 x ln x = -0.0461
x = 0.001 x ln x = -0.0069

Example B, inf minus inf. Find lim (x approaches 0) of (1/x minus 1/sin(x)).

  1. Step 1. Substitution gives inf minus inf, which is indeterminate.
  2. Step 2. Combine: (sin(x) minus x)/(x sin(x)). This is 0/0.
  3. Step 3. First round: the derivative of the top is cos(x) minus 1, and the derivative of the bottom is sin(x) plus x cos(x). Substituting 0 again gives 0/0.
  4. Step 4. Second round: the derivative of cos(x) minus 1 is minus sin(x), and the derivative of sin(x) plus x cos(x) is 2 cos(x) minus x sin(x). The new fraction is minus sin(x)/(2 cos(x) minus x sin(x)), which at x = 0 is 0/2 = 0.
import math

for x in [0.1, 0.01, 0.001]:
    print("x =", x, "value =", f"{1 / x - 1 / math.sin(x):.4f}")
x = 0.1 value = -0.0167
x = 0.01 value = -0.0017
x = 0.001 value = -0.0002

The values approach 0, which confirms the answer. Notice that the 1/x terms grow large, but their difference settles down. This is typical of inf minus inf.

Example C, 1 to the power infinity. Find lim (x approaches infinity) of (1 + 1/x) to the power x.

  1. Step 1. Substitution gives 1 to the power infinity, which is indeterminate.
  2. Step 2. Let y = (1 + 1/x) to the power x. Then ln(y) = x times ln(1 + 1/x).
  3. Step 3. Let t = 1/x. As x goes to infinity, t goes to 0 from above. Then x = 1/t, so ln(y) = ln(1 + t)/t. This is 0/0.
  4. Step 4. Apply L'Hopital's rule: the derivative of ln(1 + t) is 1/(1 + t), and the derivative of t is 1. The limit is 1/(1 + 0) = 1.
  5. Step 5. So ln(y) goes to 1, and y goes to e to the power 1 = e.
import math

for x in [10, 100, 1000]:
    print("x =", x, "value =", f"{(1 + 1 / x) ** x:.4f}")
print("e =", f"{math.e:.4f}")
x = 10 value = 2.5937
x = 100 value = 2.7048
x = 1000 value = 2.7169
e = 2.7183

Example D, 0 to the power 0. Find lim (x approaches 0 from the right) of x to the power x.

  1. Step 1. Substitution gives 0 to the power 0, which is indeterminate.
  2. Step 2. Let y = x to the power x. Then ln(y) = x ln(x).
  3. Step 3. From Example A, x ln(x) goes to 0.
  4. Step 4. So y goes to e to the power 0 = 1.
for x in [0.1, 0.01, 0.001]:
    print("x =", x, "value =", f"{x ** x:.4f}")
x = 0.1 value = 0.7943
x = 0.01 value = 0.9550
x = 0.001 value = 0.9931

GATE loves thisFor 1 to the power infinity, 0 to the power 0 and infinity to the power 0, the answer is always e raised to the limit of the logarithm. Learn this one pattern, and all three forms become routine.

Quick check: is lim (x approaches 0) of x to the power 2 times 1/x a 0 times inf form?

It is 0 times infinity only if you write it that way. Here x squared times 1/x equals x, so the limit is 0 directly. Always simplify before applying a rule.

Quick check: which form does ln(y) take in Example C after the substitution t = 1/x?

It takes the form 0/0, because ln(1 + t) goes to 0 and t goes to 0. This is the form where L'Hopital's rule applies directly.

Rolle's theorem point

Let f(x) = x squared minus 6x plus 5 on [1, 5]. Find the value of c in (1, 5) that Rolle's theorem guarantees, so that f'(c) = 0.

How to think about it

  1. What is asked. A point where the tangent is flat.
  2. Which idea applies. Rolle's theorem, after checking that f(1) = f(5).
  3. Work it out. f(1) = 1 minus 6 plus 5 = 0 and f(5) = 25 minus 30 plus 5 = 0. The ends are equal. f'(x) = 2x minus 6. Setting 2c minus 6 = 0 gives c = 3.
  4. Check. 3 lies strictly between 1 and 5, as required.

Answer: 3

Lagrange point

Let f(x) = x squared on [1, 4]. Find the value of c in (1, 4) given by Lagrange's mean value theorem.

How to think about it

  1. What is asked. The point c where the tangent slope equals the secant slope.
  2. Which idea applies. Lagrange's theorem: f'(c) = (f(4) minus f(1))/(4 minus 1).
  3. Work it out. The secant slope is (16 minus 1)/3 = 5. Also f'(c) = 2c, so 2c = 5 and c = 2.5.
  4. Check. 2.5 lies between 1 and 4, so the answer is valid.

Answer: 2.5

Which functions satisfy Rolle's conditions, select all that apply

Select all that apply. Which of the following functions satisfy all the hypotheses of Rolle's theorem on the stated interval? (A) f(x) = |x| on [-1, 1]; (B) f(x) = x cubed minus x on [-1, 1]; (C) f(x) = 1/x on [-1, 1]; (D) f(x) = sin(x) on [0, pi].

How to think about it

  1. What is asked. Which functions meet all three Rolle conditions.
  2. Which idea applies. Continuity on the closed interval, differentiability inside, and equal end values.
  3. Work it out. (A) fails: |x| is not differentiable at 0. (B) passes: f(-1) = minus 1 plus 1 = 0 and f(1) = 1 minus 1 = 0, and it is smooth. (C) fails: 1/x is not defined at 0, which lies in the interval. (D) passes: sin(0) = 0 and sin(pi) = 0, and sin is smooth.
  4. Check. For (D) the flat point is pi/2, where cos(pi/2) = 0, as expected.

Standard exponential limit

Find lim (x approaches 0) of (e to the power 2x minus 1)/x. Give your answer as an integer.

How to think about it

  1. What is asked. A limit that gives 0/0.
  2. Which idea applies. L'Hopital's rule.
  3. Work it out. Derivative of the top: 2 e to the power 2x. Derivative of the bottom: 1. The new fraction is 2 e to the power 2x, and at x = 0 it is 2 times 1 = 2.
  4. Check. The slope of e to the power 2x at 0 is 2, which matches the answer.

Answer: 2

One to the power infinity

Find lim (x approaches infinity) of (1 + 3/x) to the power x. Give your answer as a decimal correct to four places.

How to think about it

  1. What is asked. A 1 to the power infinity limit.
  2. Which idea applies. The logarithm trick, with the standard limit for (1 + a/x) to the power x.
  3. Work it out. Let y be the expression. Then ln(y) = x ln(1 + 3/x). Let t = 3/x, so ln(y) = 3 ln(1 + t)/t, which tends to 3 times 1 = 3 by L'Hopital. So y goes to e cubed, which is about 20.0855.
  4. Check. The number e cubed is about 20.09, and the general pattern (1 + a/x) to the power x = e to the power a confirms it.

Zero times infinity

Find lim (x approaches 0 from the right) of sqrt(x) times ln(x). Give your answer as an integer.

How to think about it

  1. What is asked. A product of a factor going to 0 and a factor going to minus infinity.
  2. Which idea applies. Rewrite the product as a fraction, then use L'Hopital's rule.
  3. Work it out. Write the product as ln(x)/(1/sqrt(x)). This is inf/inf. The derivative of ln(x) is 1/x. The derivative of 1/sqrt(x) = x to the power minus 1/2 is minus (1/2) x to the power minus 3/2. The new fraction is (1/x) divided by (minus (1/2) x to the power minus 3/2), which equals minus 2 x to the power 1/2.

Inf minus inf, a limit with two steps

Find lim (x approaches 1) of (x/(x minus 1) minus 1/ln(x)). Give your answer as a decimal number.

How to think about it

  1. What is asked. A difference of two terms that both blow up at x = 1.
  2. Which idea applies. Combine the fractions, then apply L'Hopital's rule.
  3. Work it out. Combine into (x ln(x) minus (x minus 1))/((x minus 1) ln(x)). At x = 1 this is 0/0. The derivative of the top is ln(x) + 1 minus 1 = ln(x). The derivative of the bottom is ln(x) + (x minus 1)/x. At x = 1 both are 0, so the form is still 0/0. Apply L'Hopital again. The derivative of the top is 1/x, which equals 1 at x = 1. The derivative of the bottom is 1/x plus 1/x squared, which equals 2 at x = 1. The new ratio at x = 1 is 1/2, so the limit is 0.5.

Locating the mean value point

Let f(t) = ln(1 + t). Apply Lagrange's mean value theorem on [0, 0.5]. Find the value of c in (0, 0.5) that the theorem guarantees. Give your answer as a decimal correct to four places.

How to think about it

  1. What is asked. The mean value point for ln(1 + t) on [0, 0.5].
  2. Which idea applies. Lagrange's theorem: f'(c) = (f(0.5) minus f(0))/0.5.
  3. Work it out. f(0.5) = ln(1.5) and f(0) = 0. So f'(c) = ln(1.5)/0.5. Since f'(t) = 1/(1 + t), we get 1/(1 + c) = ln(1.5)/0.5, so 1 + c = 0.5/ln(1.5), and c = 0.5/ln(1.5) minus 1.

Exam-level 1: a 1 to the power infinity limit (NAT, 2 marks)

A simple growth model uses the factor F(x) = (1 + 3x)2/x for a small time step x. The long-run factor is the limit L = lim F(x) as x approaches 0. Find L, correct to 2 decimal places. As x approaches 0 the base tends to 1 and the exponent tends to infinity, so direct substitution gives the indeterminate form 1 to the power infinity.

How to think about it

  1. What is asked. The limit L of a 1 to the power infinity form, to 2 decimal places.
  2. Which idea applies. Take natural logarithms. This turns the limit into a product that is a 0 times infinity form. Rewrite it as a quotient, which is 0/0, and apply L'Hopital's rule.
  3. Work it out. Let ln L = lim (2/x) ln(1 + 3x) = lim 2 ln(1 + 3x)/x. This is 0/0. Differentiate the top and bottom: the top gives 2 times 3/(1 + 3x) = 6/(1 + 3x), and the bottom gives 1. So ln L = 6/(1 + 0) = 6. Therefore L = e6, which is about 403.4288, or 403.43 to 2 decimal places.
  4. Check. The Python block evaluates F at x = 0.01, 0.0001 and 0.000001. The values climb towards 403.43 as x shrinks.
import math
def F(x):
    return (1 + 3*x) ** (2 / x)
for x in [0.01, 0.0001, 0.000001]:
    print("x =", x, "F =", round(F(x), 2))
print("e^6 to 2 dp =", round(math.exp(6), 2))
x = 0.01 F = 369.36
x = 0.0001 F = 403.07
x = 1e-06 F = 403.43
e^6 to 2 dp = 403.43

Exam-level 2: which statements about the mean value point are true (MSQ, 2 marks)

Let f(x) = x3 on the closed interval [0, 2]. Recall the mean value theorem: if f is continuous on [a, b] and differentiable on (a, b), then there is a point c in (a, b) where f'(c) equals the average rate of change (f(b) - f(a))/(b - a). Rolle's theorem is the special case where f(a) = f(b). Select all that apply. (A) The mean value theorem applies to f on [0, 2]. (B) The point c = 2/sqrt(3), about 1.1547, satisfies the conclusion. (C) The point c = 1 satisfies the conclusion. (D) Rolle's theorem applies to f on [0, 2].

How to think about it

  1. What is asked. Which statements about the mean value point of x3 on [0, 2] are true.
  2. Which idea applies. Check the hypotheses, which hold for any polynomial. Then compute the average rate of change and solve f'(c) = that rate for c in (0, 2). Rolle's theorem also needs f(0) = f(2).
  3. Work it out. The average rate is (8 - 0)/(2 - 0) = 4. We need 3c2 = 4, so c2 = 4/3 and c = 2/sqrt(3), which is about 1.1547 and lies in (0, 2). So (A) and (B) are true. For (C), f'(1) = 3, not 4, so (C) is false. For (D), f(0) = 0 and f(2) = 8 are different, so the hypothesis of Rolle's theorem fails and (D) is false.
  4. Check. The Python block computes the secant slope, the point c and f'(c). The slope and f'(c) both equal 4, while f'(1) is 3.
import math
def f(x):
    return x**3
def fp(x):
    return 3*x*x
slope = (f(2) - f(0)) / (2 - 0)
c = math.sqrt(slope / 3)
print("secant slope =", slope)
print("c =", round(c, 4), "f'(c) =", round(fp(c), 4))
print("f'(1) =", fp(1))

Exam-level 3: a difference of two blowing-up terms (MCQ, 2 marks)

A researcher compares two curvature terms in a model near zero. The combined term is L = lim (1/x2 - 1/sin2 x) as x approaches 0, with x in radians. Each of the two terms grows without bound as x approaches 0, and their difference is an indeterminate form of type infinity minus infinity. What is the value of L? (A) -1/3. (B) 0. (C) 1/3. (D) 1/2.

How to think about it

  1. What is asked. The value of L, which is a difference of two terms that each go to infinity.
  2. Which idea applies. Write the difference over a common denominator, or use the Taylor series of sin x. Expanding sin2 x as x2 times a series is the quickest route.
  3. Work it out. Use sin x = x - x3/6 + .... Then sin2 x = x2 - x4/3 + .... Therefore 1/sin2 x = 1/(x2(1 - x2/3 + ...)) = (1/x2)(1 + x2/3 + ...) = 1/x2 + 1/3 + .... Subtracting, 1/x2 - 1/sin2 x = -1/3 + ..., so L = -1/3. Option (A) is correct.
  4. Check. The Python block evaluates the difference at x = 0.1, 0.01 and 0.001. The values settle at -0.3333, and double precision is accurate enough at these sizes.
import math
def D(x):
    return 1/x**2 - 1/math.sin(x)**2
for x in [0.1, 0.01, 0.001]:
    print("x =", x, "D =", round(D(x), 4))
print("-1/3 to 4 dp =", round(-1/3, 4))

x = 0.01 D = -0.3333

Exam-level 4: locating a mean value point (NAT, 2 marks)

A sensor reading follows f(x) = ln(1 + x) for x in the closed interval [0, 3], where x is the time in hours since a process started. By the mean value theorem, there is a time c in the open interval (0, 3) at which the instantaneous rate of change f'(c) equals the average rate of change over [0, 3]. Find c, correct to 3 decimal places.

How to think about it

  1. What is asked. The mean value point c, to 3 decimal places.
  2. Which idea applies. Compute the average rate (f(3) - f(0))/3. Then solve f'(c) equal to that rate, using f'(x) = 1/(1 + x) for x greater than -1.
  3. Work it out. f(3) - f(0) = ln 4 - ln 1 = ln 4, which is about 1.386294. The average rate is ln 4/3, about 0.462098. Solve 1/(1 + c) = ln 4/3. Then 1 + c = 3/ln 4, which is about 2.164043, so c is about 1.164043. This value lies in (0, 3), so it satisfies the theorem, and c = 1.164 to 3 decimal places.
  4. Check. The Python block computes the average rate, the point c, and then substitutes c back into f'. The value 1/(1 + c) equals the average rate, 0.4621.
import math
def f(x):
    return math.log(1 + x)
slope = (f(3) - f(0)) / 3
c = 1 / slope - 1
print("secant slope =", round(slope, 4))
print("c =", round(c, 3))
print("check f'(c) =", round(1 / (1 + c), 4))
secant slope = 0.4621
c = 1.164
check f'(c) = 0.4621

Answer: c = 1.164

Summary

Rolle's theorem
Plain meaning: equal ends force a flat tangent. Precise definition: if f is continuous on [a, b], differentiable on (a, b) and f(a) = f(b), then f'(c) = 0 for some c in (a, b).
Lagrange's mean value theorem
Plain meaning: the tangent matches the average slope somewhere. Precise definition: f'(c) = (f(b) minus f(a))/(b minus a) for some c in (a, b).
Cauchy's mean value theorem
Plain meaning: the two-function version. Precise definition: (f(b) minus f(a))/(g(b) minus g(a)) = f'(c)/g'(c) for some c, when g'(c) is not 0.
Secant line
Plain meaning: a line through two points of a curve. Precise definition: the line with slope (f(b) minus f(a))/(b minus a).
Indeterminate form
Plain meaning: a substitution that gives no answer. Precise definition: 0/0, inf/inf, 0 times inf, inf minus inf, 1^inf, 0^0 or inf^0.
L'Hopital's rule
Plain meaning: differentiate top and bottom. Precise definition: for 0/0 or inf/inf, lim f/g = lim f'/g' when the right side exists.
Logarithm trick
Plain meaning: take ln first, then exponentiate. Precise definition: if y = f^g, then lim y = e to the power lim ln(y).
Bound from MVT
Plain meaning: trap a difference using a derivative bound. Precise definition: a value between the smallest and largest derivative values on the interval, times the interval length.
Standard exponential limit
Plain meaning: a limit to memorise. Precise definition: lim (1 + a/x) to the power x = e to the power a, as x goes to infinity.

Remember these

  1. Rolle needs equal ends. Lagrange does not.
  2. The point c given by the mean value theorem must be strictly inside the interval.
  3. L'Hopital's rule applies only to 0/0 and inf/inf.
  4. Rewrite 0 times inf as a fraction, and combine inf minus inf into one fraction.
  5. For 1^inf, 0^0 and inf^0, take the logarithm first.
  6. lim (1 + a/x) to the power x = e to the power a.
