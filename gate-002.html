Matrix transpose, trace and adjoint (recap)

A quick recap of three matrix tools: the transpose (flip the table), the trace (add the diagonal) and the adjoint (the cofactor trick that gives the inverse). They come up often in GATE RA and DA questions, usually with a 2 x 2 or 3 x 3 matrix.

The idea in plain words

This is a recap. You already know matrix addition and multiplication. Now we add three small tools. Each one takes a matrix and gives back a matrix or a single number, and each is quick once you know the steps.

The transpose turns a table over its main diagonal, so rows become columns. The trace adds the numbers on the main diagonal. The adjoint builds, from a matrix, the ingredients for its inverse.

Key terms

Diagonal
The entries a11, a22, a33 and so on, from the top-left corner to the bottom-right corner.
Transpose (AT)
The matrix with (AT)ij = aji. Rows become columns.
Symmetric matrix
A square matrix with AT = A.
Skew-symmetric matrix
A square matrix with AT = -A. Its diagonal is all 0.
Trace, tr(A)
The sum of the diagonal entries of a square matrix.
Minor, Mij
The determinant of the matrix left after covering row i and column j.
Cofactor, Cij
The minor with a sign: Cij = (-1)i+j Mij.
Adjoint (adjugate), adj(A)
The transpose of the cofactor matrix.
Inverse, A-1
The matrix with A-1A = I. It exists exactly when det(A) is not 0.

Transpose: flip the table over its diagonal

Take A = [[1, 2, 3], [4, 5, 6]], a 2 x 3 matrix. Row 1 becomes column 1, and row 2 becomes column 2:

AT = [ 1  4 ]
     [ 2  5 ]
     [ 3  6 ]

The size flips too: A is 2 x 3, and AT is 3 x 2.

Four rules to memorise

  • Flip twice: (AT)T = A.
  • Sums: (A + B)T = AT + BT.
  • Scalars: (cA)T = cAT.
  • Products reverse order: (AB)T = BTAT.

Trap(AB)T is not ATBT. The order reverses, like putting on socks and then shoes, so undoing it takes off the shoes first.

If A is 4 x 2, what is the size of ATA?

AT is 2 x 4. The middle numbers (4 and 4) match, and the outside numbers give 2 x 2.

Is [[4, 5], [6, 7]] symmetric?

No. The entries 5 and 6 above and below the diagonal must be equal.

Symmetric and skew-symmetric matrices

A symmetric matrix looks the same after flipping, as S = [[2, 1], [1, 3]] does. Only square matrices can be symmetric. A useful fact: for any A, the product ATA is symmetric, because (ATA)T = ATA.

A skew-symmetric matrix flips to its negative, as K = [[0, 2], [-2, 0]] does. Its diagonal must be 0, because a number equal to its own negative is 0. Every square matrix splits into a symmetric part (A + AT)/2 and a skew part (A - AT)/2.

The Python block checks the product rule for transposes.

def transpose(M):
    return [list(col) for col in zip(*M)]

def matmul(X, Y):
    n, k, m = len(X), len(Y), len(Y[0])
    return [[sum(X[i][t] * Y[t][j] for t in range(k)) for j in range(m)] for i in range(n)]

A = [[1, 2, 3], [4, 5, 6]]
B = [[0, 1], [2, 1], [1, 0]]
print("A^T =", transpose(A))
lhs = transpose(matmul(A, B))
rhs = matmul(transpose(B), transpose(A))
print("(AB)^T =", lhs)
print("B^T A^T =", rhs)
print("equal:", lhs == rhs)
A^T = [[1, 4], [2, 5], [3, 6]]
(AB)^T = [[7, 16], [3, 9]]
B^T A^T = [[7, 16], [3, 9]]
equal: True
Is the zero matrix symmetric and skew-symmetric?

Yes to both. Its transpose is itself, and -0 is 0.

Why must a skew-symmetric matrix have zeros on its diagonal?

Each diagonal entry must satisfy aii = -aii, and only 0 equals its own negative.

Trace: add up the diagonal

The trace works only for square matrices. For C = [[2, 7], [-1, 5]], the diagonal is 2 and 5, so tr(C) = 7.

  • Sums and scalars: tr(A + B) = tr(A) + tr(B), and tr(cA) = c tr(A).
  • Transpose: tr(AT) = tr(A).
  • Products in a loop: tr(AB) = tr(BA), even when AB and BA differ.

Example: A = [[1, 2], [0, 1]] and B = [[3, 0], [1, 2]]. AB has diagonal 5 and 2, so tr(AB) = 7. BA has diagonal 3 and 4, so tr(BA) = 7. The two traces agree.

GATE loves thisOptions that say tr(AB) = tr(A) tr(B) are usually false. The trace is additive, not multiplicative.

What is the trace of [[1, 9, 9], [9, 2, 9], [9, 9, 3]]?

1 + 2 + 3 = 6. The 9s are off the diagonal.

Is tr(A) equal to tr(AT)?

Yes. Flipping leaves the diagonal in place.

Minors and cofactors, step by step

To find the minor Mij, cover row i and column j, and take the determinant of what is left. The cofactor is Cij = (-1)i+j Mij. The signs follow a checkerboard that starts with + at the top-left:

[ +  -  + ]
[ -  +  - ]
[ +  -  + ]

Take A = [[2, 0, 1], [1, 1, 0], [0, 1, 1]]. Here are three of its nine cofactors:

  • C11: cover row 1 and column 1. Left: [[1, 0], [1, 1]], det 1. Sign + gives 1.
  • C12: cover row 1 and column 2. Left: [[1, 0], [0, 1]], det 1. Sign - gives -1.
  • C23: cover row 2 and column 3. Left: [[2, 0], [0, 1]], det 2. Sign - gives -2.

The other six, worked the same way, are C13 = 1, C21 = 1, C22 = 2, C31 = -1, C32 = 1 and C33 = 2. Collected in a grid, the cofactor matrix is [[1, -1, 1], [1, 2, -2], [-1, 1, 2]].

TrapA minor is only a determinant. A cofactor also carries the checkerboard sign. Forgetting the sign is the most common error here.

What is the sign of the cofactor in row 2, column 2 of a 3 x 3 matrix?

i + j = 4 is even, so the sign is +.

How many minors does a 3 x 3 matrix have?

One per position, so 9. Each is a 2 x 2 determinant.

Adjoint (adjugate) and the inverse

The adjoint is the transpose of the cofactor matrix. Flipping the cofactor matrix above gives:

adj(A) = [  1   1  -1 ]
         [ -1   2   1 ]
         [  1  -2   2 ]

The key identity is A adj(A) = det(A) I. For this A, the first row times the first column of adj(A) is 2 x 1 + 0 x (-1) + 1 x 1 = 3, which is det(A). The inverse is then:

A-1 = adj(A) / det(A), when det(A) is not 0

For a 2 x 2 matrix, the adjoint is quick: swap the two diagonal entries and change the sign of the others. For [[a, b], [c, d]], adj = [[d, -b], [-c, a]]. Take A = [[2, 1], [1, 1]]. Its determinant is 1, so A-1 = [[1, -1], [-1, 2]].

The picture shows [[2, 1], [1, 1]], whose determinant is 1. Drag the columns and watch the inverse bring the square back.

The Python block computes the determinant, adjoint and inverse of the 3 x 3 example with exact fractions.

from fractions import Fraction

def minor(M, i, j):
    return [row[:j] + row[j + 1:] for k, row in enumerate(M) if k != i]

def det(M):
    if len(M) == 1:
        return M[0][0]
    if len(M) == 2:
        return M[0][0] * M[1][1] - M[0][1] * M[1][0]
    return sum((-1) ** j * M[0][j] * det(minor(M, 0, j)) for j in range(len(M)))

def cofactor(M, i, j):
    return (-1) ** (i + j) * det(minor(M, i, j))

def adjugate(M):
    n = len(M)
    return [[cofactor(M, j, i) for j in range(n)] for i in range(n)]

A = [[2, 0, 1], [1, 1, 0], [0, 1, 1]]
d = det(A)
print("det A =", d)
print("adj A:")
for row in adjugate(A):
    print(row)
print("inverse A^-1:")
for row in adjugate(A):
    print([str(Fraction(x, d)) for x in row])

[1, 1, -1]
[-1, 2, 1]
[1, -2, 2]
inverse A^-1:
['1/3', '1/3', '-1/3']
['-1/3', '2/3', '1/3']
['1/3', '-2/3', '2/3']
What is the inverse of A = [[4, 7], [2, 6]]?

det = 24 - 14 = 10. The adjoint is [[6, -7], [-2, 4]]. So A-1 = [[3/5, -7/10], [-1/5, 2/5]].

What does a zero determinant mean for the inverse?

The formula divides by det(A), so the inverse does not exist. The matrix is singular.

Solved GATE-style problems

These are original GATE-style problems. Try each one on paper first.

Flip and add

Let A = [[1, 2], [3, 4]]. Find AT and then A + AT.

How to think about it

  1. What is asked. The transpose, and the sum of A with its transpose.
  2. Which idea applies. Swap entries (1,2) and (2,1), then add position by position.
  3. Work it out. AT = [[1, 3], [2, 4]]. Then A + AT = [[2, 5], [5, 8]].
  4. Check. A + AT is always symmetric, and [[2, 5], [5, 8]] passes.

Answer: AT = [[1, 3], [2, 4]] and A + AT = [[2, 5], [5, 8]].

True statements about transposes and traces (MSQ)

Let A be 2 x 3 and B be 3 x 2. Select all true statements.

(A) (AT)T = A
(B) (AB)T = ATBT
(C) AT is 3 x 2
(D) tr(AB) = tr(BA)

How to think about it

  1. What is asked. Test four rules.
  2. Which idea applies. Double transpose, product reversal, sizes, and the trace rule.
  3. Work it out. (A) true. (B) false, since the correct rule is BTAT. (C) true. (D) true, since both traces exist.
  4. Check. The false statement is the one that forgot to reverse the order.

Answer: (A), (C) and (D).

Trace of a product (NAT)

Let A = [[1, 2], [0, 1]] and B = [[3, 0], [1, 2]]. Find tr(AB). Give a single number.

How to think about it

  1. What is asked. The trace of AB.
  2. Which idea applies. Only the diagonal of AB is needed.
  3. Work it out. Entry (1,1) = (1, 2) . (3, 1) = 5. Entry (2,2) = (0, 1) . (0, 2) = 2. Trace = 7.
  4. Check. tr(BA) = 3 + 4 = 7, as the rule tr(AB) = tr(BA) predicts.

Answer: 7.

An entry of an inverse (NAT)

Let A = [[4, 7], [2, 6]], and let A-1 = [[p, q], [r, s]]. Find p. Give a single number.

How to think about it

  1. What is asked. Entry (1,1) of the inverse.
  2. Which idea applies. For 2 x 2, the inverse is adj(A) / det(A), with a and d swapped.
  3. Work it out. det(A) = 24 - 14 = 10. The adjoint is [[6, -7], [-2, 4]]. So p = 6/10 = 3/5.
  4. Check. Row 1 of A times column 1 of the inverse: 4(3/5) + 7(-1/5) = 12/5 - 7/5 = 1.

Answer: p = 3/5 (or 0.6).

A cofactor in a 3 x 3 matrix (NAT)

Let A = [[1, 2, 3], [0, 1, 4], [5, 6, 0]]. Find the cofactor C23. Give a single number.

How to think about it

  1. What is asked. The cofactor in row 2, column 3.
  2. Which idea applies. Cover the row and column, take the determinant, then apply the sign.
  3. Work it out. Covering row 2 and column 3 leaves [[1, 2], [5, 6]], with det = 6 - 10 = -4. The sign is (-1)5 = -1. So C23 = (-1)(-4) = 4.
  4. Check. The position (2, 3) has a minus sign, and the minor is negative, so the product is positive.

Answer: 4.

Adjoint facts for a 3 x 3 matrix (MSQ)

A is a 3 x 3 matrix with det(A) = 5. Select all true statements.

(A) A adj(A) = 5I
(B) det(adj(A)) = 5
(C) adj(A) A = 5I
(D) A-1 = adj(A) / 5

How to think about it

  1. What is asked. Test four facts about the adjoint.
  2. Which idea applies. A adj(A) = adj(A) A = det(A) I. For an n x n matrix, det(adj(A)) = det(A)n-1.
  3. Work it out. (A) and (C) are true. (B) is false, because det(adj(A)) = 52 = 25. (D) is the inverse formula, true.
  4. Check. For A = [[2, 1], [1, 1]] with det 1, det(adj(A)) = 1, which fits the power rule.

Answer: (A), (C) and (D).

Exam-level practice

Exam-level 1: Determinant of an adjoint (NAT, 2 marks)

Let A be a 4 × 4 real matrix with det(A) = 3. Find det(adj(2A)).

How to think about it

  1. What is asked. The determinant of the adjoint of the scaled matrix 2A, as one number.
  2. Which idea applies. For an n × n matrix M, det(adj(M)) = det(M)n−1. Also det(kM) = kndet(M).
  3. Work it out. det(2A) = 24 · 3 = 48. Then det(adj(2A)) = 483 = 110592.
  4. Check. The Python block builds a random 4 × 4 matrix with determinant 3 and checks the result with exact fractions.
from fractions import Fraction as F
def det(M):
    n = len(M)
    if n == 1:
        return M[0][0]
    return sum((-1) ** j * M[0][j] * det([r[:j] + r[j + 1:] for r in M[1:]]) for j in range(n))
def adj(M):
    n = len(M)
    return [[(-1) ** (i + j) * det([r[:i] + r[i + 1:] for k, r in enumerate(M) if k != j]) for j in range(n)] for i in range(n)]
A = [[3, 1, 0, 2], [0, 1, 4, 1], [0, 0, 1, 5], [0, 0, 0, 1]]
print("det A =", det(A))
B = [[2 * x for x in r] for r in A]
print("det adj(2A) =", det(adj(B)))

det A = 3
det adj(2A) = 110592

Answer: 110592.

Exam-level 2: Trace facts (MSQ, 2 marks)

Let A and B be n × n real matrices. Which statements are always TRUE? (A) tr(AB − BA) = 0. (B) tr(AᵀA) is the sum of squares of all entries of A. (C) tr(ABC) = tr(BAC) for any n × n C. (D) If A is skew-symmetric then tr(A) = 0.

How to think about it

  1. What is asked. Which of four trace identities hold for all matrices.
  2. Which idea applies. The trace is linear and cyclic: tr(XY) = tr(YX). Cyclic means rotating the order, not swapping arbitrary factors.
  3. Work it out. (A) tr(AB) − tr(BA) = 0. True. (B) The (j, j) entry of AᵀA is the sum of squares of column j, so the trace sums all squares. True. (C) tr(ABC) = tr(CAB) = tr(BCA), but BAC is not a rotation of ABC. False in general. (D) Skew-symmetric means aii = −aii, so every diagonal entry is 0. True.
  4. Check. The code finds a concrete counterexample for (C).
def mul(X, Y):
    return [[sum(X[i][k] * Y[k][j] for k in range(2)) for j in range(2)] for i in range(2)]
tr = lambda X: X[0][0] + X[1][1]
A = [[1, 2], [0, 0]]; B = [[0, 0], [1, 0]]; C = [[1, 0], [0, 0]]
print("tr(ABC) =", tr(mul(mul(A, B), C)), " tr(BAC) =", tr(mul(mul(B, A), C)))

tr(ABC) = 2  tr(BAC) = 0

Answer: (A), (B) and (D).

Exam-level 3: Inverse from the adjoint (NAT, 2 marks)

Let A = [[2, 1, 0], [1, 3, 1], [0, 1, 2]]. The (1, 3) entry of A−1 is p. Find p, correct to 3 decimal places.

How to think about it

  1. What is asked. One entry of the inverse.
  2. Which idea applies. A−1 = adj(A)/det(A). The (1, 3) entry of adj(A) is the cofactor C31 (note the swap of indices).
  3. Work it out. det(A) = 2(6 − 1) − 1(2 − 0) + 0 = 8. C31 = (+1)·det[[1, 0], [3, 1]] = 1. So p = 1/8 = 0.125.
  4. Check. The code inverts A exactly.
from fractions import Fraction as F
A = [[F(x) for x in r] for r in [[2, 1, 0], [1, 3, 1], [0, 1, 2]]]
n = 3
M = [r + [F(int(i == j)) for j in range(n)] for i, r in enumerate(A)]
for c in range(n):
    p = next(r for r in range(c, n) if M[r][c] != 0)
    M[c], M[p] = M[p], M[c]
    M[c] = [x / M[c][c] for x in M[c]]
    for r in range(n):
        if r != c:
            M[r] = [a - M[r][c] * b for a, b in zip(M[r], M[c])]
print("(1,3) entry of inverse =", M[0][n + 2])

(1,3) entry of inverse = 1/8

Answer: p = 1/8 = 0.125.

Remember these

  1. The transpose flips rows into columns and reverses the order of a product.
  2. The trace is the sum of the diagonal, and tr(AB) = tr(BA).
  3. For a 2 x 2 matrix, the inverse is [[d, -b], [-c, a]] divided by ad - bc.
  4. Watch the checkerboard sign when you make cofactors.
  5. A adj(A) = det(A) I is the check you can always run.
