Two-port networks

A two-port network is a black box with one pair of terminals for input and one pair for output. Four numbers, called parameters, describe the whole box. Z, Y, h and ABCD parameters are the four standard sets, and GATE RA and DA ask you to find, convert and cascade them.

The idea in plain words

Many circuits have an input and an output. A filter, an amplifier, a cable and a transformer all take a signal in at one side and deliver it at the other side. Engineers call each side a port. A port is a pair of terminals where current enters and leaves in a controlled way. A two-port network is a box with two ports.

Think of a mailbox with one slot for letters going in and one for letters coming out. You do not need to know the postal system inside. Four numbers relate the voltages and currents at the two ports, and once you know them, you can predict the output for any input.

Why does this matter? Two-port networks let you describe a large circuit as one block. You can connect blocks one after another, and multiply their numbers to get the whole chain. This is very useful for filters and amplifiers, and GATE RA and DA test it through questions on parameters, conversion and cascading.

Key ideaA two-port network is described by four numbers, but there are four different sets of these numbers. Each set is useful for a different connection.

Key terms

Each term has a plain meaning first, then a precise definition.

Port
A pair of terminals where one current enters and leaves. Precisely: port 1 is the input and port 2 is the output.
Two-port network
A network with exactly two ports. Precisely: a linear network whose behaviour is fixed by four numbers.
Port voltages and currents
V1, I1 at port 1 and V2, I2 at port 2.
Port convention
The rule that both port currents are taken as entering the network. Precisely: the standard definition used in this page.
z-parameters
Parameters that relate port voltages to port currents. Precisely: V = Z I, with z11, z12, z21, z22.
y-parameters
Parameters that relate port currents to port voltages. Precisely: I = Y V, the inverse of the z-form.
h-parameters
The hybrid set, mixing voltage and current. Precisely: used heavily for transistor circuits.
ABCD parameters
The transmission set, which relates input quantities to output quantities. Precisely: V1 = AV2 − BI2 and I1 = CV2 − DI2.
Reciprocal network
A network that gives the same response when source and measurement ports are swapped. Precisely: z12 = z21, equivalently AD − BC = 1.
Symmetric network
A network that looks the same from both ports. Precisely: z11 = z22, equivalently A = D.
Cascade
Connecting one two-port's output to the next two-port's input. Precisely: the overall ABCD matrix is the product of the individual matrices.
Determinant
For a 2 by 2 matrix [[a, b],[c, d]], the number ad − bc.

Ports and the port convention

Drawing the box

Draw a rectangle with two pairs of terminals. Port 1 is on the left, and port 2 is on the right. The voltage across port 1 is V1, and the current into port 1 is I1. The same applies to port 2.

   I1 --->+------------+---> I2
          |            |
   V1 ----+  two-port  +---- V2
          |  network   |
          +------------+

The port convention

This is the most important rule on the page. In the standard convention, both currents are taken as entering the network. So I1 enters at the top of port 1, and I2 enters at the top of port 2. If a current in your circuit leaves port 2 toward a load, its value in this convention is negative. Many wrong answers come from forgetting this.

TrapUnder the port convention, a load on port 2 has I2 = −V2/RL, not +V2/RL. The minus sign appears because the load draws current out of the network.

Self-check

A 5 ohm load is connected across port 2, with V2 = 10 V. What is I2 under the port convention?

I2 = −V2/RL = −10/5 = −2 A. The current 2 A leaves the network through the load, so it is negative when it enters.

Why do we need a convention at all?

Without one, the sign of each current is unclear, and the same network gives different equations. A fixed convention makes every parameter set unique and comparable.

Z-parameters and Y-parameters

The z-parameter equations

The z-parameters express the port voltages in terms of the port currents:

V1 = z11 I1 + z12 I2, V2 = z21 I1 + z22 I2

Each z-parameter has a simple meaning, found by opening one port:

  • z11 = V1/I1 with I2 = 0. This is the input impedance when the output is open.
  • z21 = V2/I1 with I2 = 0. This is the forward transfer impedance.
  • z12 = V1/I2 with I1 = 0. This is the reverse transfer impedance.
  • z22 = V2/I2 with I1 = 0. This is the output impedance when the input is open.

Worked example 1: the z-parameters of a T network

A T network has a 2 ohm series arm on port 1, a 4 ohm shunt arm from the middle node to ground, and a 2 ohm series arm on port 2. Find the z-parameters.

  port 1                             port 2
  o----[ 2 ohm ]----+----[ 2 ohm ]----o
                    |
                  [ 4 ohm ]
                    |
                   gnd
  1. z11. Open port 2 (I2 = 0). Now the current I1 flows through the 2 ohm arm and the 4 ohm shunt in series. So V1 = (2 + 4) I1, giving z11 = 6 ohm.
  2. z21. Still I2 = 0, so no current flows in port 2's arm. The voltage at port 2 equals the voltage across the 4 ohm shunt, which is 4 I1. So z21 = 4 ohm.
  3. z12. Open port 1 (I1 = 0) and drive I2. The same logic on the other side gives z12 = 4 ohm.
  4. z22. With I1 = 0, the port 2 arm and the shunt are in series, so z22 = 2 + 4 = 6 ohm.

The result is z11 = z22 = 6 ohm and z12 = z21 = 4 ohm. The network is symmetric and reciprocal, which matches the look of the circuit.

The y-parameter equations

The y-parameters express the port currents in terms of the port voltages:

I1 = y11 V1 + y12 V2, I2 = y21 V1 + y22 V2

They are found by shorting one port. For example, y11 = I1/V1 with V2 = 0. The y-matrix is the inverse of the z-matrix, so Y = Z−1. A series impedance Z gives Y = (1/Z) [[1, −1], [−1, 1]], and a shunt admittance Ys gives [[Ys, 0], [0, 0]].

TrapA plain wire joining the two ports has neither z-parameters nor y-parameters, because the two port voltages cannot be set independently. A series-only path has the same problem.

Self-check

In Worked example 1, what is the z11 if the 4 ohm shunt is removed?

Without the shunt, the two arms form one series path, so I1 = −I2 always. The two currents cannot be set independently, and the z-parameters do not exist. This is the trap above.

A single series impedance Z is the whole two-port. What is y11?

y11 = 1/Z. The y-matrix of a series element is (1/Z)[[1, −1], [−1, 1]], so the top-left entry is 1/Z.

h-parameters

The hybrid form

The h-parameters mix voltages and currents on the two sides. They are chosen so that transistor circuits, which are often easier to measure with a shorted output, fit the form neatly:

V1 = h11 I1 + h12 V2, I2 = h21 I1 + h22 V2
  • h11 = V1/I1 with V2 = 0 (output shorted). It is an impedance.
  • h12 = V1/V2 with I1 = 0 (input open). It is a voltage ratio, with no unit.
  • h21 = I2/I1 with V2 = 0 (output shorted). It is a current ratio, with no unit.
  • h22 = I2/V2 with I1 = 0 (input open). It is an admittance.

Worked example 2: the h-parameters of a series resistor

The simplest two-port is a single resistor R in series between the two ports. Find the h-parameters.

  1. h11. Short port 2 (V2 = 0). Then the input voltage is across R alone, with the current I1. So h11 = R.
  2. h12. Open port 1 (I1 = 0). No current flows through R, so V1 = V2. So h12 = 1.
  3. h21. Short port 2 (V2 = 0). The current entering port 1 flows through R and then out of port 2. Under the port convention, the current entering port 2 is −I1. So h21 = −1.
  4. h22. Open port 1 (I1 = 0). No current flows, so I2 = 0 and h22 = 0.

The result is h = [[R, 1], [−1, 0]]. Notice that h12 = −h21, which is the reciprocity condition for h-parameters.

TipFor transistor questions, expect the h-parameters to be given. Your job is usually to use them, not to find them.

Self-check

What is h21 for a shunt admittance Ys connected across port 1 only?

The shunt is connected only to port 1, so no current can reach port 2. I2 = 0, and therefore h21 = 0.

Why is h11 an impedance but h22 an admittance?

h11 is V1/I1, a voltage over a current. h22 is I2/V2, a current over a voltage. The units follow from the definitions.

ABCD (transmission) parameters

The transmission form

The ABCD form relates the input quantities to the output quantities. It is the form that cascades most easily:

V1 = A V2 − B I2, I1 = C V2 − D I2

Here I2 still follows the port convention, entering the network. The four parameters are:

  • A = V1/V2 with I2 = 0. A voltage ratio, with no unit.
  • B = −V1/I2 with V2 = 0. An impedance.
  • C = I1/V2 with I2 = 0. An admittance.
  • D = −I1/I2 with V2 = 0. A current ratio, with no unit.

Standard blocks have simple ABCD matrices. A series impedance Z gives [[1, Z], [0, 1]]. A shunt admittance Y gives [[1, 0], [Y, 1]].

Worked example 3: converting ABCD to z-parameters

Take the T network of Worked example 1 and its ABCD matrix, which is A = 1 + Z1/Zs, B = Z1 + Z2 + Z1Z2/Zs, C = 1/Zs, and D = 1 + Z2/Zs. With Z1 = 2, Z2 = 2 and Zs = 4, we get A = 3/2, B = 5, C = 1/4 and D = 3/2. Convert to z-parameters using these conversion formulas:

z11 = A/C, z12 = (AD − BC)/C, z21 = 1/C, z22 = D/C

Then z11 = (3/2)/(1/4) = 6, z12 = (9/4 − 5/4)/(1/4) = 1/(1/4) = 4, z21 = 4, and z22 = 6. These match the direct result in Worked example 1.

from fractions import Fraction as F
Z1, Zs, Z2 = F(2), F(4), F(2)
A = 1 + Z1 / Zs
B = Z1 + Z2 + Z1 * Z2 / Zs
C = 1 / Zs
D = 1 + Z2 / Zs
print("A =", A)
print("B =", B)
print("C =", C)
print("D =", D)
print("z11 =", A / C)
print("z12 =", (A * D - B * C) / C)
print("z21 =", 1 / C)
print("z22 =", D / C)
A = 3/2
B = 5
C = 1/4
D = 3/2
z11 = 6
z12 = 4
z21 = 4
z22 = 6

TrapThe conversion z11 = A/C needs C to be non-zero. If C = 0, the network has no z-parameters. The same warning applies to the other conversions.

Self-check

A two-port has ABCD = [[2, 5], [1, 3]]. What is z11?

z11 = A/C = 2/1 = 2 ohm.

What is the value of AD − BC for the same matrix?

AD − BC = 2 × 3 − 5 × 1 = 6 − 5 = 1. A determinant of 1 is a sign that the network is reciprocal, as we will see below.

Reciprocity, symmetry and cascading

Reciprocity

A network is reciprocal if it contains only passive elements, such as resistors, capacitors and inductors, with no controlled sources. Then, in every parameter set, the two cross-terms are equal, or the matching condition holds:

  • z-form: z12 = z21.
  • y-form: y12 = y21.
  • h-form: h12 = −h21.
  • ABCD form: AD − BC = 1.

A network is symmetric if its ports look the same from each side. Then z11 = z22, or in ABCD form, A = D. Symmetry implies reciprocity, but not the other way round.

Key ideaTest reciprocity with the ABCD determinant first. If AD − BC = 1, the network is reciprocal. This takes one line of arithmetic.

Cascading

When two two-port networks are connected one after another, the output of the first feeds the input of the second. The overall ABCD matrix is the product of the two ABCD matrices, taken in the same order as the connection:

Mtotal = M1 × M2

Worked example 4: cascading and terminating

A series 2 ohm element (port 1 side) is followed by a shunt 4 ohm element. The matrix of the series element is [[1, 2], [0, 1]], and the matrix of the shunt is [[1, 0], [1/4, 1]]. Multiply them:

  1. Multiply. A = 1 × 1 + 2 × (1/4) = 3/2. B = 1 × 0 + 2 × 1 = 2. C = 0 × 1 + 1 × (1/4) = 1/4. D = 0 × 0 + 1 × 1 = 1.
  2. Terminate. Put a 4 ohm load across port 2 with V2 = 6 V. Under the port convention, I2 = −6/4 = −3/2 A.
  3. Find V1. V1 = A V2 − B I2 = (3/2)(6) − 2(−3/2) = 9 + 3 = 12 V.
  4. Find I1. I1 = C V2 − D I2 = (1/4)(6) − 1(−3/2) = 3/2 + 3/2 = 3 A.
  5. Check. The 2 ohm carries 3 A, dropping 6 V. Add the 6 V at port 2 to get 12 V at port 1. Correct.
from fractions import Fraction as F
def mul(M, N):
    return [[M[0][0] * N[0][0] + M[0][1] * N[1][0], M[0][0] * N[0][1] + M[0][1] * N[1][1]],
            [M[1][0] * N[0][0] + M[1][1] * N[1][0], M[1][0] * N[0][1] + M[1][1] * N[1][1]]]
series2 = [[F(1), F(2)], [F(0), F(1)]]
shunt4 = [[F(1), F(0)], [F(1, 4), F(1)]]
M = mul(series2, shunt4)
A, B, C, D = M[0][0], M[0][1], M[1][0], M[1][1]
print("A =", A, ", B =", B, ", C =", C, ", D =", D)
V2 = F(6)
I2 = -V2 / 4
V1 = A * V2 - B * I2
I1 = C * V2 - D * I2
print("V1 =", V1, "V")
print("I1 =", I1, "A")
A = 3/2 , B = 2 , C = 1/4 , D = 1
V1 = 12 V
I1 = 3 A

TrapMultiply the matrices in the order the network is connected, from port 1 side to port 2 side. Reversing the order gives a different answer in general.

Self-check

Is a network with ABCD = [[3, 4], [2, 3]] reciprocal?

AD − BC = 9 − 8 = 1, so it is reciprocal. Here A = D = 3, so it is also symmetric.

If two identical series 2 ohm elements are cascaded, what is the total B?

Each series element has B = 2 and A = D = 1, C = 0. The product [[1, 2], [0, 1]] × [[1, 2], [0, 1]] = [[1, 4], [0, 1]], so B = 4, which is the sum of the two series resistances.

Solved GATE-style problems

These are original problems in the GATE style, not past exam questions. Try each one on paper first.

z-parameters of a single series element

A two-port consists of a single 5 ohm resistor connected in series between the two ports. Find z12 in ohm.

How to think about it

  1. What is asked. The reverse transfer impedance z12.
  2. Which idea applies. z12 = V1/I2 with I1 = 0.
  3. Work it out. With I1 = 0, the current I2 flows through the 5 ohm and comes back to port 1 as a drop of 5 I2. So V1 = 5 I2, and z12 = 5 ohm.
  4. Check. The network is reciprocal, so z21 is also 5 ohm, as expected for a single series element.

Answer: 5 ohm.

y-parameter of a shunt resistor

A two-port has a single 5 ohm resistor connected from port 1 to the ground return. Find y11 in siemens.

How to think about it

  1. What is asked. y11.
  2. Which idea applies. y11 = I1/V1 with V2 = 0.
  3. Work it out. With V2 = 0, the shunt across port 1 carries V1/5, so I1/V1 = 1/5 S.
  4. Check. The admittance of a 5 ohm resistor is the reciprocal of its resistance, 0.2 S.

Answer: 1/5 S, which is 0.2 S.

from fractions import Fraction as F
print("y11 =", float(F(1, 5)), "S")
y11 = 0.2 S

Statements about the parameter sets (MSQ)

Select all that apply, for a passive network with no controlled sources.

(A) The network is reciprocal, so z12 = z21.
(B) A symmetric network has z11 = z22.
(C) For a reciprocal network, AD − BC = 1.
(D) The ABCD matrix of a cascade is the sum of the individual ABCD matrices.

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. The reciprocity and symmetry conditions, and the cascade rule.
  3. Work it out. (A) True. (B) True. (C) True. (D) False: cascades multiply, they do not add.
  4. Check. Test (D) with two series 2 ohm elements. Multiplying gives B = 4, which is a sum of the resistances. But the matrices themselves multiply, so the rule is multiplication, not addition.

Answer: (A), (B) and (C).

z11 from an ABCD matrix (NAT)

A two-port has ABCD parameters A = 2, B = 5, C = 1, D = 3. Find z11 in ohm.

How to think about it

  1. What is asked. z11.
  2. Which idea applies. The conversion z11 = A/C.
  3. Work it out. z11 = 2/1 = 2 ohm.
  4. Check. AD − BC = 6 − 5 = 1, so the network is reciprocal, which is consistent with the formulas.

Answer: 2 ohm.

from fractions import Fraction as F
print("z11 =", F(2) / F(1), "ohm")
z11 = 2 ohm

Determinant of a transmission matrix (NAT)

For the two-port in the previous problem, find the value of AD − BC.

How to think about it

  1. What is asked. The determinant AD − BC.
  2. Which idea applies. The determinant of the ABCD matrix, which is 1 for a reciprocal network.
  3. Work it out. AD − BC = 2 × 3 − 5 × 1 = 6 − 5 = 1.
  4. Check. A result of 1 agrees with the reciprocity test, so the network is reciprocal.

Answer: 1.

from fractions import Fraction as F
print("AD - BC =", F(2) * F(3) - F(5) * F(1))
AD - BC = 1

A of a cascade (NAT)

A series 2 ohm element is followed by a shunt element with admittance 1/2 S. The two are cascaded in that order, with the series element on the port 1 side. Find the overall A parameter.

How to think about it

  1. What is asked. The A parameter of the cascade.
  2. Which idea applies. Multiply the matrices in order. Series 2 ohm is [[1, 2], [0, 1]], shunt 1/2 S is [[1, 0], [1/2, 1]].
  3. Work it out. A = 1 × 1 + 2 × (1/2) = 1 + 1 = 2.
  4. Check. Both factors have determinant 1, so the product also has determinant 1.

Answer: 2.

from fractions import Fraction as F
A = F(1) * F(1) + F(2) * F(1, 2)
print("A =", A)
A = 2

Input voltage of a terminated two-port (NAT)

A two-port has ABCD parameters A = 3/2, B = 2, C = 1/4, D = 1. A 2 ohm load is connected across port 2, and the voltage at port 2 is 4 V. Find the voltage at port 1, in volt.

How to think about it

  1. What is asked. V1.
  2. Which idea applies. Port convention for the load current, then the ABCD relation.
  3. Work it out. I2 = −V2/RL = −4/2 = −2 A. Then V1 = AV2 − BI2 = (3/2)(4) − 2(−2) = 6 + 4 = 10 V.
  4. Check. I1 = CV2 − DI2 = (1/4)(4) + 2 = 3 A. The input power, 10 × 3 = 30 W, is larger than the 8 W delivered to the load, which is the expected direction for a lossy network.

Answer: 10 V.

from fractions import Fraction as F
A, B = F(3, 2), F(2)
V2, RL = F(4), F(2)
I2 = -V2 / RL
V1 = A * V2 - B * I2
print("I2 =", I2, "A")
print("V1 =", V1, "V")
I2 = -2 A
V1 = 10 V

Statements about two-port parameters (MSQ)

Select all that apply.

(A) A plain wire joining port 1 directly to port 2 has no z-parameters.
(B) For a single series resistor R, h21 = −1 under the port convention.
(C) For a series impedance Z, the y11 parameter equals Z.
(D) For a series impedance Z, the ABCD matrix is [[1, Z], [0, 1]].

How to think about it

  1. What is asked. Which statements are correct.
  2. Which idea applies. The existence trap for z-parameters, the h-parameter result, the y-form of a series element, and the standard ABCD block.
  3. Work it out. (A) True: a wire ties the port voltages together, so they cannot be set independently. (B) True, as derived in Worked example 2. (C) False: y11 = 1/Z. (D) True.
  4. Check. Statements (B) and (D) are the two standard results used most often. Statement (C) is the reciprocal trap.

Answer: (A), (B) and (D).

Exam-level practice

Exam-level 1: Z parameters (NAT, 2 marks)

A T network has series arms 2 Ω and 3 Ω and a shunt arm 5 Ω. Find z11, z12 and z22.

How to think about it

  1. What is asked. The open circuit impedance parameters.
  2. Which idea applies. For a T network: z11 = Za + Zc, z22 = Zb + Zc, z12 = Zc.
  3. Work it out. z11 = 7, z12 = 5, z22 = 8.
  4. Check. z12 = z21 since the network is reciprocal.

Answer: z11 = 7 Ω, z12 = 5 Ω, z22 = 8 Ω.

Exam-level 2: ABCD of a series element (MCQ, 1 mark)

The ABCD matrix of a single series impedance Z is (A) [[1, Z], [0, 1]] (B) [[1, 0], [1/Z, 1]] (C) [[Z, 1], [1, 0]] (D) [[0, Z], [1, 0]]

How to think about it

  1. What is asked. The transmission parameters of a series element.
  2. Which idea applies. V1 = V2 + ZI2, I1 = I2.
  3. Work it out. A = 1, B = Z, C = 0, D = 1.
  4. Check. AD − BC = 1, as for every reciprocal network.

Answer: (A).

Exam-level 3: Cascade (NAT, 2 marks)

A series 2 Ω element is followed by a shunt 4 Ω element. Find the B parameter (in Ω) and the A parameter of the cascade.

How to think about it

  1. What is asked. Entries of the product of ABCD matrices.
  2. Which idea applies. Multiply [[1, 2], [0, 1]] by [[1, 0], [1/4, 1]].
  3. Work it out. A = 1 + 2/4 = 1.5. B = 2. C = 0.25. D = 1.
  4. Check. AD − BC = 1.5 − 0.5 = 1.
M1 = [[1, 2], [0, 1]]; M2 = [[1, 0], [0.25, 1]]
print([[sum(M1[i][k] * M2[k][j] for k in range(2)) for j in range(2)] for i in range(2)])

[[1.5, 2], [0.25, 1]]

Answer: A = 1.5 and B = 2 Ω.

Summary

Two-port network
A network with an input port and an output port, fixed by four numbers.
Port convention
Both port currents are taken as entering the network.
z-parameters
V = ZI. Found by opening ports.
y-parameters
I = YV, the inverse of Z. Found by shorting ports.
h-parameters
A mixed set, convenient for transistor circuits.
ABCD parameters
V1 = AV2 − BI2, I1 = CV2 − DI2. The set used for cascades.
Series impedance block
ABCD matrix [[1, Z], [0, 1]].
Shunt admittance block
ABCD matrix [[1, 0], [Y, 1]].
Reciprocity
z12 = z21, or AD − BC = 1 for ABCD.
Symmetry
z11 = z22, or A = D.
Cascade rule
Overall ABCD matrix is the product of the individual matrices, in connection order.
z from ABCD
z11 = A/C, z12 = (AD − BC)/C, z21 = 1/C, z22 = D/C.
Load on port 2
I2 = −V2/RL under the port convention.
Existence
Some parameter sets do not exist for some networks. Check the conversion denominators.

Remember these

  1. Both port currents enter the network under the standard convention.
  2. Test reciprocity first with AD − BC = 1.
  3. Cascades multiply ABCD matrices in connection order.
  4. A load on port 2 has a negative I2.
  5. The h-form suits transistors, and its h12 = −h21 for reciprocal networks.
  6. Always check that a parameter exists before converting to it.
