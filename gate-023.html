Partial derivatives & total derivative

A partial derivative measures how a function changes when only one of its inputs moves and the others are held still. Total derivatives, the chain rule and error estimates all build on this idea. They appear in robotics kinematics and in the gradients used to train DA models.

The idea in plain words

Imagine standing on a hill, and the height depends on two things: how far east you walk and how far north you walk. If you walk only east, the ground rises or falls at some rate. That rate is one partial derivative. If you walk only north, you get a second rate. Each partial derivative keeps one input still and asks how the output reacts to the other.

Many real problems have several inputs. A robot arm's tip position depends on several joint angles. A machine learning model's loss depends on many weights. A measured volume depends on several lengths. To handle all of these, we extend the derivative to functions of several variables, one variable at a time.

Why does this matter for GATE? Multivariable calculus appears in robotics kinematics, in the gradient vector used in learning algorithms, and in error analysis, where a small error in each measurement adds up to an error in the answer. Learn the rules once, and they apply everywhere.

Key terms

Each term has a plain meaning first, then a precise definition.

Function of two variables
Plain meaning: a rule that takes two numbers and gives one number. Precise definition: f(x, y), with x and y as inputs and one real output.
Partial derivative
Plain meaning: the rate of change when only one input moves. Precise definition: f_x = the derivative of f with respect to x, treating y as a constant.
Notation f_x, f_y
Plain meaning: short names for the two partial derivatives. Precise definition: f_x = partial f over partial x, and f_y = partial f over partial y.
Second-order partial
Plain meaning: a partial derivative of a partial derivative. Precise definition: for example f_xx, f_yy, f_xy and f_yx.
Mixed partial
Plain meaning: a second derivative taken with respect to two different variables. Precise definition: f_xy or f_yx.
Gradient
Plain meaning: the list of partial derivatives, which points uphill. Precise definition: the vector (f_x, f_y).
Total differential
Plain meaning: a small change in the output, estimated from small changes in the inputs. Precise definition: df = f_x dx + f_y dy.
Chain rule
Plain meaning: how a change flows through a chain of dependencies. Precise definition: the rule for the derivative of f(x(t), y(t)) with respect to t.

TipA partial derivative looks just like an ordinary derivative. The only change is that the other variables are treated as fixed numbers.

Functions of two variables and partial derivatives

Take the function f(x, y) = x squared times y plus 3y. To find f_x, treat y as a constant number and differentiate with respect to x. To find f_y, treat x as a constant and differentiate with respect to y.

f_x = partial of f with respect to x, with y held fixed
f_y = partial of f with respect to y, with x held fixed

Worked example. Let f(x, y) = x squared y + 3y. Find f_x and f_y at the point (1, 2).

  1. Step 1, f_x. Hold y fixed. The term x squared y becomes 2x y, because the derivative of x squared is 2x and y is a constant factor. The term 3y is constant with respect to x, so its derivative is 0. So f_x = 2xy.
  2. Step 2, f_y. Hold x fixed. The term x squared y gives x squared, because y differentiates to 1. The term 3y gives 3. So f_y = x squared + 3.
  3. Step 3, evaluate at (1, 2). f_x = 2 times 1 times 2 = 4. f_y = 1 squared + 3 = 4.

The next program checks f_x numerically. It measures the change in f when x moves by a tiny amount h and y stays at 2.

def f(x, y):
    return x * x * y + 3 * y

h = 0.000001
fx = (f(1 + h, 2) - f(1, 2)) / h
print("numerical f_x at (1, 2) =", round(fx, 4))
print("formula 2xy at (1, 2) =", 2 * 1 * 2)
numerical f_x at (1, 2) = 4.0
formula 2xy at (1, 2) = 4

Key ideaA partial derivative is the slope along one direction only. The other variables are frozen, so the rules of single-variable calculus apply directly.

Quick check: for f(x, y) = x y squared, what is f_y?

Hold x fixed. The derivative of y squared is 2y, so f_y = 2xy.

Quick check: what does f_x = 0 at a point tell you?

The function is flat in the x direction at that point, while y is held fixed. It does not mean the function is flat in every direction.

Higher-order and mixed partial derivatives

You can differentiate a partial derivative again. For a function of x and y there are four second-order partials:

  • f_xx: differentiate with respect to x, then x again.
  • f_yy: differentiate with respect to y, then y again.
  • f_xy: differentiate with respect to x first, then with respect to y.
  • f_yx: differentiate with respect to y first, then with respect to x.

Take f(x, y) = x squared y cubed as the example.

  1. Step 1, first partials. f_x = 2x y cubed. f_y = 3x squared y squared.
  2. Step 2, pure second partials. f_xx = 2 y cubed, because the x is differentiated. f_yy = 6x squared y.
  3. Step 3, mixed partials. f_xy = derivative of 2x y cubed with respect to y = 6x y squared. f_yx = derivative of 3x squared y squared with respect to x = 6x y squared.

The two mixed partials are equal. This is Clairaut's theorem: if the mixed partials are continuous, then f_xy = f_yx. This saves work in exam questions, because you can choose the order that is easier.

The next program estimates f_xy at (1, 2) by a small square of differences. It compares the answer with the formula 6xy squared, which equals 24.

def g(x, y):
    return x * x * y ** 3

h = 0.001
mixed = ((g(1 + h, 2 + h) - g(1 + h, 2)) - (g(1, 2 + h) - g(1, 2))) / (h * h)
print("mixed difference for f_xy at (1,2) =", f"{mixed:.1f}")
print("exact f_xy = 6xy^2 =", 6 * 1 * 4)
mixed difference for f_xy at (1,2) = 24.0
exact f_xy = 6xy^2 = 24

TrapClairaut's theorem needs the mixed partials to be continuous. In standard textbook functions this always holds, but do not assume it for a function with a strange point, such as a piecewise definition.

Quick check: for f(x, y) = x y, what are f_xx and f_xy?

f_x = y, so f_xx = 0, because y does not contain x. The mixed partial f_xy is the derivative of f_x = y with respect to y, which is 1.

Quick check: is f_xy always equal to f_yx?

Yes, for functions whose mixed partials are continuous, which covers almost every function you will meet in GATE.

The total differential

Suppose you change x a little by dx and y a little by dy. How much does f change? If the changes are small, the answer is a sum of two contributions: the change from x alone, and the change from y alone.

df = f_x dx + f_y dy

Each symbol means:

  • df is the estimated change in f.
  • f_x dx is the change from moving x by dx, with y fixed.
  • f_y dy is the change from moving y by dy, with x fixed.

Worked example. Let f(x, y) = x squared y at (2, 3). Find the estimated change when x increases by 0.01 and y decreases by 0.02.

  1. Step 1, partials. f_x = 2xy = 12 at (2, 3). f_y = x squared = 4 at (2, 3).
  2. Step 2, contributions. f_x dx = 12 times 0.01 = 0.12. f_y dy = 4 times (minus 0.02) = minus 0.08.
  3. Step 3, add. df = 0.12 minus 0.08 = 0.04.
def k(x, y):
    return x * x * y

x0, y0, dx, dy = 2.0, 3.0, 0.01, -0.02
df = 12 * dx + 4 * dy
actual = k(x0 + dx, y0 + dy) - k(x0, y0)
print("differential df =", round(df, 4), " actual change =", round(actual, 4))
differential df = 0.04  actual change = 0.0395

Key ideaThe differential is the best linear estimate of the change. It is close to the true change when dx and dy are small, and the gap between them is of a smaller order.

Quick check: for f(x, y) = x plus y squared at (1, 2), what is df when dx = 0.1 and dy = 0?

f_x = 1, so df = 1 times 0.1 + 0 = 0.1.

Quick check: why is the differential called a linear estimate?

Because df depends linearly on dx and dy, with the partial derivatives as fixed coefficients. It is the tangent plane's answer to the change.

The multivariable chain rule

Often the inputs themselves depend on a third variable. For example, a robot's position x and y might both depend on time t. Then the output z = f(x, y) depends on t through two paths. The chain rule adds the contributions of both paths.

dz/dt = f_x times dx/dt + f_y times dy/dt

Each symbol means:

  • dz/dt is how fast the output changes with time.
  • f_x and f_y are the partial derivatives of f.
  • dx/dt and dy/dt are how fast each input changes with time.

Worked example. Let z = x y, with x = t and y = t squared. Find dz/dt at t = 2.

  1. Step 1, partials of z. z_x = y and z_y = x.
  2. Step 2, rates of the inputs. dx/dt = 1 and dy/dt = 2t.
  3. Step 3, chain rule. dz/dt = y times 1 plus x times 2t = t squared + 2t squared = 3t squared.
  4. Step 4, evaluate at t = 2. 3 times 2 squared = 12.
def z(t):
    x = t
    y = t * t
    return x * y

h = 0.000001
print("numerical dz/dt at t = 2:", round((z(2 + h) - z(2)) / h, 4))
print("chain rule answer 3t^2 at t = 2:", 3 * 2 * 2)
numerical dz/dt at t = 2: 12.0
chain rule answer 3t^2 at t = 2: 12

TrapDo not forget the second path. Students often differentiate z with respect to t as if only x depended on t, and they miss the term from y.

Quick check: if z = x plus y, x = t and y = t, what is dz/dt?

f_x = 1 and f_y = 1, dx/dt = 1 and dy/dt = 1. So dz/dt = 1 plus 1 = 2.

Quick check: why is the chain rule sum for z = x y in the example above not just f_x times dx/dt?

Because y also depends on t. Both paths change z, so both contributions must be added.

Error estimation with differentials

Measurements are never perfect. If you measure a length x with a small error dx, and a width y with a small error dy, then the calculated area x y has an error. The differential estimates that error.

Worked example. A rectangle is measured as x = 2 cm and y = 3 cm. The measurement errors are at most 0.01 cm in x and at most 0.02 cm in y. Estimate the largest possible error in the area A = xy.

  1. Step 1, partials. A_x = y = 3 and A_y = x = 2.
  2. Step 2, worst case. Each error is taken at its largest size, so the error estimate is |A_x| times 0.01 plus |A_y| times 0.02.
  3. Step 3, compute. 3 times 0.01 = 0.03, and 2 times 0.02 = 0.04. The total is 0.07 square cm.
  4. Step 4, relative error. The area is 6 square cm, so the relative error is 0.07/6, which is about 1.2 percent.

GATE loves thisFor error estimates, use the absolute values of the partial derivatives and the largest allowed errors. Then add the terms. This gives a worst-case bound, not the exact error.

Quick check: for V = x squared times y at (2, 5), what is the sensitivity to dx?

V_x = 2xy = 20, so a change of 0.1 in x changes V by about 2.

Quick check: why do we take absolute values when estimating the worst-case error?

Because an error can push the output up or down. The worst case adds the sizes of the two contributions, so we use absolute values.

Problems that combine the ideas

Real questions often mix partial derivatives, the chain rule and error estimates. Work step by step: write the function, find the partials, insert the rates or errors, and add.

Worked example. Let f(x, y) = x squared plus 3xy plus y squared. Let x = s plus t and y = s minus t. Find the partial derivative of f with respect to s at s = 1, t = 0.

  1. Step 1, partials of f. f_x = 2x + 3y and f_y = 3x + 2y.
  2. Step 2, values at the point. When s = 1 and t = 0, x = 1 and y = 1. So f_x = 2 + 3 = 5 and f_y = 3 + 2 = 5.
  3. Step 3, rates. dx/ds = 1 and dy/ds = 1.
  4. Step 4, chain rule. df/ds = 5 times 1 plus 5 times 1 = 10.
Quick check: in the example, what is df/dt at the same point if x = s plus t and y = s minus t?

dx/dt = 1 and dy/dt = minus 1. So df/dt = 5 times 1 plus 5 times (minus 1) = 0.

A first partial derivative

Let f(x, y) = 3x squared y plus y cubed. Find f_x at the point (1, 2). Give your answer as an integer.

How to think about it

  1. What is asked. The rate of change in x, at (1, 2).
  2. Which idea applies. Hold y fixed and differentiate with respect to x.
  3. Work it out. f_x = 6xy. The term y cubed does not contain x, so it disappears. At (1, 2): 6 times 1 times 2 = 12.
  4. Check. The number 12 is positive, which fits a function that rises in x at that point.

Answer: 12

Partial with respect to y

For the same function f(x, y) = 3x squared y plus y cubed, find f_y at (1, 2). Give your answer as an integer.

How to think about it

  1. What is asked. The rate of change in y, at (1, 2).
  2. Which idea applies. Hold x fixed and differentiate with respect to y.
  3. Work it out. f_y = 3x squared + 3y squared. At (1, 2): 3 times 1 + 3 times 4 = 3 + 12 = 15.
  4. Check. Both terms are positive at this point, so 15 is positive.

Answer: 15

Partials of x squared y cubed, select all that apply

Let f(x, y) = x squared y cubed. Select all that apply: (A) f_x = 2x y cubed; (B) f_y = 3x squared y squared; (C) f_xy = 6x y squared; (D) f_xx = 6x y cubed.

How to think about it

  1. What is asked. Which partial derivatives are correct.
  2. Which idea applies. Single-variable rules, with the other variable held fixed.
  3. Work it out. f_x = 2x y cubed, so (A) is correct. f_y = 3x squared y squared, so (B) is correct. f_xy is the derivative of 2x y cubed with respect to y, which is 6x y squared, so (C) is correct. f_xx is the derivative of 2x y cubed with respect to x, which is 2 y cubed, not 6x y cubed, so (D) is wrong.
  4. Check. Clairaut's theorem says f_yx also equals 6x y squared, which agrees with (C).

Answer: (A), (B) and (C)

Mixed partial at a point

Let f(x, y) = x squared y cubed. Find f_xy at the point (1, 2). Give your answer as an integer.

How to think about it

  1. What is asked. The mixed partial f_xy at (1, 2).
  2. Which idea applies. Differentiate in x first, then in y, and evaluate.
  3. Work it out. f_x = 2x y cubed. Then f_xy = 6x y squared. At (1, 2): 6 times 1 times 4 = 24.
  4. Check. f_yx gives the same expression, which confirms the answer.

Answer: 24

Estimating a change

Let f(x, y) = x squared y. At the point (2, 3), x is increased by 0.1 and y is left unchanged. Use the total differential to estimate the change in f. Give your answer as a decimal number.

How to think about it

  1. What is asked. An estimate of df when dx = 0.1 and dy = 0.
  2. Which idea applies. The total differential df = f_x dx + f_y dy.
  3. Work it out. f_x = 2xy = 12 at (2, 3). So df = 12 times 0.1 + f_y times 0 = 1.2.
  4. Check. The exact change is (2.1)^2 times 3 minus 12 = 13.23 minus 12 = 1.23, which is close to 1.2.

Answer: 1.2

Chain rule with time

Let z = x squared plus x y. Suppose x = t and y = 2t. Find dz/dt at t = 1. Give your answer as an integer.

How to think about it

  1. What is asked. The rate of change of z with time at t = 1.
  2. Which idea applies. The chain rule.
  3. Work it out. z_x = 2x + y and z_y = x. At t = 1, x = 1 and y = 2, so z_x = 4 and z_y = 1. The rates are dx/dt = 1 and dy/dt = 2. So dz/dt = 4 times 1 plus 1 times 2 = 6.
  4. Check. Substitute first: z = t squared + 2t squared = 3t squared, so dz/dt = 6t, which is 6 at t = 1.

Answer: 6

Worst-case error in a volume

A box has volume V = x squared times y. The measured values are x = 2 and y = 5, with errors at most 0.02 in x and at most 0.05 in y. Estimate the largest possible error in V. Give your answer as a decimal number.

How to think about it

  1. What is asked. A worst-case error bound for V.
  2. Which idea applies. Error propagation with absolute values of the partials.
  3. Work it out. V_x = 2xy = 20 and V_y = x squared = 4 at (2, 5). Worst-case error = 20 times 0.02 plus 4 times 0.05 = 0.4 plus 0.2 = 0.6.
  4. Check. The nominal volume is 20, so the relative error bound is 0.6/20 = 3 percent.

Answer: 0.6

Two-step chain rule

Let f(x, y) = x squared plus 3xy plus y squared, with x = s plus t and y = s minus t. Find the partial derivative of f with respect to s at s = 1, t = 0. Give your answer as an integer.

How to think about it

  1. What is asked. The rate of change of f with respect to s, while t is held at 0.
  2. Which idea applies. The chain rule for a function of x and y that depend on s.
  3. Work it out. f_x = 2x + 3y and f_y = 3x + 2y. At s = 1 and t = 0, x = 1 and y = 1, so f_x = 5 and f_y = 5. Also dx/ds = 1 and dy/ds = 1. So df/ds = 5 times 1 plus 5 times 1 = 10.
  4. Check. Substitute first: f = (s + t)^2 + 3(s + t)(s - t) + (s - t)^2 = 5s^2 - t^2. Then df/ds = 10s, which is 10 at s = 1.

Answer: 10

Exam-level 1: a mixed partial derivative with a trigonometric term (NAT, 2 marks)

A sensor's output is modelled by f(x, y) = x2y3 + sin(xy), where x and y are two control settings and the sine is taken in radians. Find the mixed partial derivative fxy at the point (x, y) = (1, 2). Here fxy means differentiate first with respect to x, and then with respect to y. Give your answer correct to 2 decimal places.

How to think about it

  1. What is asked. The mixed partial fxy at (1, 2), to 2 decimal places.
  2. Which idea applies. Differentiate with respect to x, then with respect to y. Use the chain rule for sin(xy), and the product rule where two functions of y multiply.
  3. Work it out. The derivative of sin(xy) with respect to x is y cos(xy), so fx = 2xy3 + y cos(xy). Now differentiate fx with respect to y. The first term gives 6xy2. For the second term, use the product rule on y times cos(xy): the result is cos(xy) + y(-x sin(xy)). So fxy = 6xy2 + cos(xy) - xy sin(xy). At (1, 2) this is 6(1)(4) + cos 2 - 2 sin 2 = 24 - 0.416147 - 1.818595 = 21.765258, which is 21.77 to 2 decimal places.
  4. Check. The Python block computes the value from the formula, and also from a numerical derivative of fx with respect to y. Both give 21.77.
import math
def f(x, y):
    return x*x*y**3 + math.sin(x*y)
def fx(x, y):
    return 2*x*y**3 + y*math.cos(x*y)
def fxy_formula(x, y):
    return 6*x*y*y + math.cos(x*y) - x*y*math.sin(x*y)
h = 1e-6
x0, y0 = 1.0, 2.0
fxy_numeric = (fx(x0, y0 + h) - fx(x0, y0 - h)) / (2*h)
print("formula f_xy(1,2) =", round(fxy_formula(x0, y0), 2))
print("numeric f_xy(1,2) =", round(fxy_numeric, 2))
formula f_xy(1,2) = 21.77
numeric f_xy(1,2) = 21.77

Answer: 21.77

Exam-level 2: checking a harmonic function at a point (MSQ, 2 marks)

Let w(x, y) = ln(x2 + y2) for (x, y) not equal to (0, 0). This function appears in potential-flow models. Select all that apply at the point (1, 1). (A) The partial derivative wx equals 1. (B) The second partial wxx equals 0. (C) The mixed partial wxy equals 0. (D) The sum wxx + wyy equals 0.

How to think about it

  1. What is asked. Which of the four partial derivative statements at (1, 1) are true.
  2. Which idea applies. Use the chain rule on ln(u) with u = x2 + y2, then differentiate again with the quotient rule. The sum wxx + wyy is the Laplacian, which tells whether w is harmonic.
  3. Work it out. wx = 2x/(x2 + y2). At (1, 1) this is 2/2 = 1, so (A) is true. Differentiating again, wxx = (2y2 - 2x2)/(x2 + y2)2. At (1, 1) this is 0/4 = 0, so (B) is true. Differentiating wx with respect to y gives wxy = -4xy/(x2 + y2)2. At (1, 1) this is -4/4 = -1, not 0, so (C) is false. By symmetry wyy = (2x2 - 2y2)/(x2 + y2)2, so the sum is 0 at every point where w is defined, and (D) is true.
  4. Check. The Python block uses exact fractions to evaluate each derivative at (1, 1). The printed values are 1, 0, -1 and 0, which match the four options.
from fractions import Fraction as Fr
x, y = Fr(1), Fr(1)
r2 = x*x + y*y
wx = 2*x / r2
wxx = (2*y*y - 2*x*x) / r2**2
wxy = -4*x*y / r2**2
wyy = (2*x*x - 2*y*y) / r2**2
print("w_x =", wx)
print("w_xx =", wxx)
print("w_xy =", wxy)
print("w_xx + w_yy =", wxx + wyy)
w_x = 1
w_xx = 0
w_xy = -1
w_xx + w_yy = 0

Answer: (A), (B) and (D) are true. (C) is false.

Exam-level 3: a chain rule through two intermediate variables (MCQ, 2 marks)

A tank's stored energy is z = x2y + y3, where x and y both depend on time t through x = t2 and y = t. Find dz/dt at t = 1. (A) 6. (B) 8. (C) 10. (D) 12.

How to think about it

  1. What is asked. The rate of change dz/dt at the instant t = 1.
  2. Which idea applies. The multivariable chain rule: dz/dt = zx(dx/dt) + zy(dy/dt).
  3. Work it out. zx = 2xy and zy = x2 + 3y2. At t = 1 we have x = 1 and y = 1, so zx = 2 and zy = 4. Also dx/dt = 2t = 2 and dy/dt = 1. Therefore dz/dt = 2 times 2 + 4 times 1 = 8. Option (B) is correct.
  4. Check. The Python block substitutes x = t2 and y = t into z to get z(t) = t5 + t3, then takes a numerical derivative at t = 1. It gets 8.0, which matches the chain rule result.
def z_of_t(t):
    x, y = t*t, t
    return x*x*y + y**3
h = 1e-6
t0 = 1.0
dz = (z_of_t(t0 + h) - z_of_t(t0 - h)) / (2*h)
print("dz/dt numeric at t = 1 =", round(dz, 4))
x, y = 1.0, 1.0
zx = 2*x*y
zy = x*x + 3*y*y
xp, yp = 2*t0, 1.0
print("z_x =", zx, " z_y =", zy)
print("chain rule dz/dt =", zx*xp + zy*yp)
dz/dt numeric at t = 1 = 8.0
z_x = 2.0  z_y = 4.0
chain rule dz/dt = 8.0

Answer: (B) 8

Exam-level 4: error of a linear estimate for a box volume (NAT, 2 marks)

A closed box has a square base of side x and height y, so its volume is V = x2y. The measured values are x = 2.00 and y = 3.00. Later the values are re-measured and found to change by dx = 0.01 and dy = -0.02, so the new values are x = 2.01 and y = 2.98. Using a linear (differential) estimate of the change in V, find the absolute percentage error of that estimate compared with the true change in V. Give your answer correct to 1 decimal place.

How to think about it

  1. What is asked. The percentage error of the linear estimate of the change in V, compared with the true change, to 1 decimal place.
  2. Which idea applies. The total differential dV = Vx dx + Vy dy, where Vx = 2xy and Vy = x2. Then compare it with the exact change in V.
  3. Work it out. Vx = 2(2)(3) = 12 and Vy = 22 = 4. So dV = 12(0.01) + 4(-0.02) = 0.12 - 0.08 = 0.04. The exact new volume is 2.012 times 2.98 = 4.0401 times 2.98 = 12.039498, while the old volume is 12, so the true change is 0.039498. The percentage error is |0.04 - 0.039498|/0.039498 times 100, which is about 1.27 percent, or 1.3 to 1 decimal place.
  4. Check. The Python block computes the linear estimate, the exact change and the percentage error. It gives 0.04, 0.039498 and 1.3.
x, y = 2.0, 3.0
dx, dy = 0.01, -0.02
def f(a, b):
    return a*a*b
linear = 2*x*y*dx + x*x*dy
actual = f(x + dx, y + dy) - f(x, y)
print("linear estimate =", round(linear, 4))
print("actual change =", round(actual, 6))
err = abs(linear - actual) / abs(actual) * 100
print("percentage error to 1 dp =", round(err, 1))
linear estimate = 0.04
actual change = 0.039498
percentage error to 1 dp = 1.3

Answer: 1.3 (percent)

Summary

Partial derivative f_x
Plain meaning: the rate in the x direction only. Precise definition: the derivative of f with respect to x, with y held constant.
Partial derivative f_y
Plain meaning: the rate in the y direction only. Precise definition: the derivative of f with respect to y, with x held constant.
Second-order partial
Plain meaning: a partial of a partial. Precise definition: f_xx, f_yy, f_xy or f_yx.
Mixed partial
Plain meaning: a derivative with respect to two different variables. Precise definition: f_xy or f_yx.
Clairaut's theorem
Plain meaning: the order of mixed partials does not matter. Precise definition: if f_xy and f_yx are continuous, then they are equal.
Gradient
Plain meaning: the vector of partials. Precise definition: (f_x, f_y).
Total differential
Plain meaning: the estimated change in f. Precise definition: df = f_x dx + f_y dy.
Chain rule
Plain meaning: add up the contributions along every path. Precise definition: dz/dt = f_x dx/dt + f_y dy/dt.
Worst-case error
Plain meaning: the largest likely error in an output. Precise definition: |f_x| times the x error plus |f_y| times the y error.

Remember these

  1. A partial derivative keeps the other variables fixed.
  2. Clairaut's theorem lets you swap the order of mixed partials when they are continuous.
  3. The total differential adds the two single-variable contributions.
  4. The chain rule adds one term for each path from the input to the output.
  5. For error estimates, use absolute values of the partials and the largest errors.
  6. Substitute the point after differentiating, not before.
