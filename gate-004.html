Determinant, rank and nullity

The determinant tells you whether a square matrix squashes space flat. The rank counts how many independent directions survive, and the nullity counts how many directions a matrix destroys. Together they decide how many solutions an equation has, which is why they appear in almost every GATE linear algebra question.

The idea in plain words

Picture a square matrix as a machine that moves the plane. Sometimes the machine keeps the plane in one piece, so you can always undo it. Sometimes it squashes the plane flat onto a line, and information is lost. The determinant is one number that tells you which case you are in: a non-zero value means the plane survives, and zero means it is squashed.

The rank counts the independent directions that survive. The nullity counts the directions that are destroyed. Rank and nullity always add up to the number of columns, which is the rank-nullity theorem.

GATE asks "how many solutions does this system have?", "is this matrix invertible?", and "what is the dimension of the null space?". All three are answered by these tools. In Robotics, a zero determinant of a Jacobian means the arm has lost a direction of motion.

Key terms

Determinant, det(A)
A number linked to a square matrix: how much it scales areas, with a sign for flips. For 2 x 2, ad - bc.
Minor and cofactor
Mij is the determinant after covering row i and column j. Cij = (-1)i+j Mij adds the checkerboard sign.
Singular matrix
A square matrix with det = 0. It has no inverse.
Pivot
The first non-zero entry of a row in row echelon form.
Rank, rank(A)
The number of pivots, which equals the number of independent rows and the number of independent columns.
Null space, N(A)
All vectors x with Ax = 0.
Nullity
The dimension of the null space: nullity(A) = n - rank(A) for n columns.
Linearly independent
A list of vectors where no vector is a mix of the others.

The determinant by cofactor expansion

For a 2 x 2 matrix, det = ad - bc. For larger matrices, expand along a row: multiply each entry of that row by its cofactor and add.

det(A) = a11C11 + a12C12 + a13C13

Take C = [[1, 2, 3], [0, 1, 4], [5, 6, 0]]. Row 1 is (1, 2, 3).

  1. Entry 1. Cover row 1 and column 1: [[1, 4], [6, 0]] has det 0 - 24 = -24. The sign is +, so the term is 1 x (-24) = -24.
  2. Entry 2. Cover row 1 and column 2: [[0, 4], [5, 0]] has det -20. The sign is -, so the cofactor is +20. The term is 2 x 20 = 40.
  3. Entry 3. Cover row 1 and column 3: [[0, 1], [5, 6]] has det -5. The sign is +, so the term is 3 x (-5) = -15.
  4. Add. -24 + 40 - 15 = 1. So det(C) = 1.

The Python block repeats this arithmetic.

def minor(M, i, j):
    return [row[:j] + row[j + 1:] for k, row in enumerate(M) if k != i]

def det(M):
    if len(M) == 1:
        return M[0][0]
    return sum((-1) ** j * M[0][j] * det(minor(M, 0, j)) for j in range(len(M)))

C = [[1, 2, 3], [0, 1, 4], [5, 6, 0]]
terms = [(-1) ** j * C[0][j] * det(minor(C, 0, j)) for j in range(3)]
print("expansion along row 1 terms:", terms)
print("det C =", det(C))
expansion along row 1 terms: [-24, 40, -15]
det C = 1

TipExpand along the row or column with the most zeros. Zero entries contribute nothing.

TrapThe signs alternate across the row: plus, minus, plus. Using one sign for every term is a common error.

What is det of [[2, 0, 0], [5, 3, 0], [7, 1, 4]]?

Expand along row 1: 2 x det([[3, 0], [1, 4]]) = 2 x 12 = 24. (It is triangular, so the diagonal product 2 x 3 x 4 = 24 agrees.)

What is the sign of the cofactor in row 3, column 2?

i + j = 5 is odd, so the sign is -.

Properties of the determinant

These properties let you simplify a matrix before computing, which GATE questions reward.

  • Swapping two rows changes the sign of the determinant.
  • Scaling one row by c multiplies the determinant by c.
  • Adding a multiple of one row to another leaves the determinant unchanged. Row elimination uses only this move.

A triangular matrix has determinant equal to the product of its diagonal. The most important product rule is det(AB) = det(A) det(B). Determinants multiply, and they do not add: det(A + B) is usually not det(A) + det(B). Also det(AT) = det(A), and det(A-1) = 1 / det(A).

Check with A = [[2, 1], [1, 3]] and B = [[1, 2], [0, 1]]. Here AB = [[2, 5], [1, 5]], with det(A) = 5, det(B) = 1, and det(AB) = 5. The Python block confirms this.

def matmul(X, Y):
    n, k, m = len(X), len(Y), len(Y[0])
    return [[sum(X[i][t] * Y[t][j] for t in range(k)) for j in range(m)] for i in range(n)]

def transpose(M):
    return [list(col) for col in zip(*M)]

def det2(M):
    return M[0][0] * M[1][1] - M[0][1] * M[1][0]

A = [[2, 1], [1, 3]]
B = [[1, 2], [0, 1]]
AB = matmul(A, B)
print("AB =", AB)
print("det(A) =", det2(A))
print("det(B) =", det2(B))
print("det(AB) =", det2(AB))
print("det(A) x det(B) =", det2(A) * det2(B))
print("det(A^T) =", det2(transpose(A)))

Singular or not

A square matrix is singular (no inverse) exactly when its determinant is 0. The matrix [[1, 2], [2, 4]] has det 0, since its second column is twice its first. The picture shows it collapsing the square onto a line. Drag the columns and watch.

Compare the invertible matrix [[2, 1], [1, 3]], with det 5. Its square never collapses.

Key ideaA row swap flips the sign of the determinant. This is the reason a row-swapped matrix has the negative determinant, as in the verified PYQ below.

If det(A) = 4 for a 3 x 3 matrix, what is det(2A)?

Each of the 3 rows is doubled, so det(2A) = 23 x 4 = 32.

For which k is [[1, 2], [2, k]] singular?

det = k - 4, which is 0 when k = 4.

Rank: counting pivots after row reduction

The rank counts how many genuinely new directions the rows contribute. Take D = [[1, 2, 3], [2, 4, 6], [1, 1, 1]]. Row 2 is twice row 1, so it adds nothing new.

  1. Clear column 1. Row 2 becomes row 2 - 2 x row 1 = (0, 0, 0). Row 3 becomes row 3 - row 1 = (0, -1, -2).
  2. Swap rows 2 and 3. This gives [[1, 2, 3], [0, -1, -2], [0, 0, 0]]. Rank does not depend on the row order.
  3. Count pivots. The pivots are 1 and -1. Row 3 has no pivot. So rank(D) = 2.

Key ideaRank = number of pivots in row echelon form. It equals the number of independent rows and the number of independent columns.

TrapCount pivots, not non-zero entries. A matrix can have many non-zero entries and still have a small rank.

What is the rank of the identity I3?

Three pivots, so rank 3.

What is the rank of [[2, 4], [1, 2]]?

Row 2 is half of row 1, so there is one pivot and the rank is 1.

Null space and nullity: the directions that vanish

The null space N(A) is the set of all x with Ax = 0. It always contains the zero vector and is a subspace. Its dimension, the nullity, counts the independent directions that the matrix destroys.

For D above, reduce to [[1, 2, 3], [0, -1, -2], [0, 0, 0]]. Row 2 gives x2 = -2x3. Row 1 then gives x1 = x3. The variable x3 is a free variable, so the solutions are t (1, -2, 1). The nullity is 1. Check: D (1, -2, 1) = (1 - 4 + 3, 2 - 8 + 6, 1 - 2 + 1) = (0, 0, 0).

The Python block checks the rank, the nullity, and this null vector.

from fractions import Fraction as F

def rank(M):
    A = [[F(x) for x in row] for row in M]
    rows, cols = len(A), len(A[0])
    r = 0
    for c in range(cols):
        p = None
        for i in range(r, rows):
            if A[i][c] != 0:
                p = i
                break
        if p is None:
            continue
        A[r], A[p] = A[p], A[r]
        for i in range(rows):
            if i != r and A[i][c] != 0:
                f = A[i][c] / A[r][c]
                A[i] = [A[i][k] - f * A[r][k] for k in range(cols)]
        r += 1
    return r

D = [[1, 2, 3], [2, 4, 6], [1, 1, 1]]
r = rank(D)
print("rank of D =", r)
print("nullity of D =", len(D[0]) - r)
x = [1, -2, 1]
print("D x =", [sum(D[i][j] * x[j] for j in range(3)) for i in range(3)])
rank of D = 2
nullity of D = 1
D x = [0, 0, 0]
What is the null space of I3?

Only the zero vector, since Ix = 0 forces x = 0. The nullity is 0.

Is (2, 2, 2) in the null space of D?

No. D (2, 2, 2) = (12, 24, 6), which is not zero.

The rank-nullity theorem and invertibility

rank(A) + nullity(A) = number of columns of A

Every column either adds a new output direction (rank) or depends on earlier columns (nullity). For D, rank 2 + nullity 1 = 3 columns. For a 4 x 6 matrix of rank 4, the nullity is 2, even without computing the null space.

For a square n x n matrix, these four statements are equivalent: det(A) is not 0; rank(A) = n; nullity(A) = 0; and A is invertible. You only need to check one of them.

GATE loves thisFor a square matrix, one check settles invertibility. Compute the determinant, or count the pivots, and the other statements follow.

A 5 x 3 matrix has rank 3. What is its nullity?

Nullity = 3 - 3 = 0. Ax = 0 has only the zero solution.

A 3 x 3 matrix has nullity 1. Is it invertible?

No. Its rank is 2, so its determinant is 0.

Determinant of a triangular matrix

Find the determinant of A = [[2, 5, 7], [0, 3, 1], [0, 0, 4]].

How to think about it

  1. What is asked. One number.
  2. Which idea applies. A triangular matrix has determinant equal to the product of its diagonal.
  3. Work it out. 2 x 3 x 4 = 24.
  4. Check. Expanding along column 1 gives 2 x det([[3, 1], [0, 4]]) = 2 x 12 = 24.

Answer: 24.

Properties of a determinant (MSQ)

A is a 3 x 3 matrix with det(A) = 4. Select all true statements.

(A) det(2A) = 8
(B) det(AT) = 4
(C) det(A-1) = 1/4
(D) det(A + A) = 4

How to think about it

  1. What is asked. Test four statements.
  2. Which idea applies. det(cA) = cn det(A), det(AT) = det(A), and det(A-1) = 1/det(A).
  3. Work it out. (A) det(2A) = 32, so false. (B) true. (C) true. (D) A + A = 2A has determinant 32, so false.
  4. Check. The trap in (A) and (D) is forgetting the power 3.

Answer: (B) and (C).

Nullity of a rank-2 matrix (NAT)

M = [[1, 2, 3, 4], [2, 4, 6, 8], [1, 1, 1, 1]]. Find the nullity of M. Give a single number.

How to think about it

  1. What is asked. One number.
  2. Which idea applies. Nullity = number of columns - rank.
  3. Work it out. Row 2 is twice row 1, so the rank is 2. M has 4 columns, so nullity = 4 - 2 = 2.
  4. Check. Solving Mx = 0 leaves two free variables.

Answer: 2.

The value that makes a matrix singular (NAT)

For what value of k is the matrix [[1, 2], [2, k]] singular? Give a single number.

How to think about it

  1. What is asked. The k that makes det = 0.
  2. Which idea applies. det = ad - bc.
  3. Work it out. det = k - 4, so k = 4.
  4. Check. With k = 4 the second row is twice the first.

Answer: 4.

What rank 2 tells you about a 3 x 3 matrix (MSQ)

A is a 3 x 3 matrix with rank 2. Select all true statements.

(A) det(A) = 0
(B) nullity(A) = 1
(C) the columns of A are linearly independent
(D) Ax = 0 has only the zero solution

How to think about it

  1. What is asked. Which facts follow from rank 2.
  2. Which idea applies. Rank below n means singular, and nullity = n - rank.
  3. Work it out. (A) true. (B) true, nullity 1. (C) false, only two columns are independent. (D) false, since nullity 1 gives non-zero solutions.
  4. Check. Rank plus nullity = 2 + 1 = 3.

Answer: (A) and (B).

A parameter that drops the rank (NAT)

Let A = [[1, 1, 1], [1, 2, 3], [1, 3, a]]. Find the value of a for which the rank of A is 2. Give a single number.

How to think about it

  1. What is asked. The a that makes the rank drop from 3 to 2.
  2. Which idea applies. The rank drops below 3 exactly when det(A) = 0.
  3. Work it out. Expanding along row 1: det = (2a - 9) - (a - 3) + (3 - 2) = a - 5. So a = 5.
  4. Check. With a = 5, row 2 minus row 1 is (0, 1, 2), and row 3 minus row 1 is (0, 2, 4), which is twice that. So the rows are dependent and the rank is 2.

Answer: 5.

Rank, nullity and solutions for a wide matrix (MSQ)

A is a 4 x 6 matrix with rank 4. Select all true statements.

(A) The nullity of A is 2
(B) Ax = 0 has a non-zero solution
(C) The 6 columns of A are linearly independent
(D) Ax = b has a solution for every b in R4

How to think about it

  1. What is asked. Test four statements about a wide matrix.
  2. Which idea applies. Rank-nullity: rank + nullity = 6. Rank 4 equals the number of rows.
  3. Work it out. (A) true, nullity = 2. (B) true. (C) false, six vectors in R4 cannot be independent. (D) true, since the column space is all of R4.
  4. Check. More vectors than dimensions always gives dependence.

Answer: (A), (B) and (D).

GATE CSE 2023 memory-based question (verified PYQ): row swap and determinant

Let A = [[1, 2, 3, 4], [4, 1, 2, 3], [3, 4, 1, 2], [2, 3, 4, 1]] and B = [[3, 4, 1, 2], [4, 1, 2, 3], [1, 2, 3, 4], [2, 3, 4, 1]]. Which is TRUE?

(A) det(A) = det(B)
(B) det(B) = -det(A)
(C) det(A) = 0
(D) det(AB) = det(A) + det(B)

How to think about it

  1. What is asked. The true statement.
  2. Which idea applies. Compare the rows: a row swap flips the sign, and determinants multiply.
  3. Work it out. Row 1 of B is row 3 of A, and row 3 of B is row 1 of A, with the rest unchanged. So B is A with one swap, and det(B) = -det(A). (C) is false since det(A) = -160 is not 0. (D) is false since determinants multiply.
  4. Check. The Python block computes both determinants.
def minor(M, i, j):
    return [row[:j] + row[j + 1:] for k, row in enumerate(M) if k != i]

def det(M):
    if len(M) == 1:
        return M[0][0]
    return sum((-1) ** j * M[0][j] * det(minor(M, 0, j)) for j in range(len(M)))

A = [[1, 2, 3, 4], [4, 1, 2, 3], [3, 4, 1, 2], [2, 3, 4, 1]]
B = [[3, 4, 1, 2], [4, 1, 2, 3], [1, 2, 3, 4], [2, 3, 4, 1]]
print("det(A) =", det(A))
print("det(B) =", det(B))
det(A) = -160
det(B) = 160

Answer: (B). This is a verified PYQ from GATE CSE 2023, rewritten into the format of this page.

GATE CSE 2020 Q27 (verified PYQ): which rank and determinant rules hold? (MSQ)

Let A and B be n x n real matrices. Select all true statements.

(I) rank(AB) = rank(A) x rank(B)
(II) det(AB) = det(A) x det(B)
(III) rank(A + B) is at most rank(A) + rank(B)
(IV) det(A + B) is at most det(A) + det(B)

How to think about it

  1. What is asked. Test four rules.
  2. Which idea applies. The determinant product rule is exact. Rank of a product is at most the smaller rank. Rank of a sum is at most the sum of ranks.
  3. Work it out. (I) false: A = B = I3 gives rank 3, but 3 x 3 = 9. (II) true. (III) true, since the columns of A + B are sums of columns of A and of B. (IV) false: A = B = I2 gives det(2I2) = 4, but 1 + 1 = 2.
  4. Check. Identity matrices are the quickest counterexamples.

Answer: (II) and (III). This is a verified PYQ from GATE CSE 2020, Q27, rewritten into the format of this page.

GATE CSE 2021 Set 2 Q24 (verified PYQ): rank from the null space (NAT)

P is a 4 x 5 matrix such that every solution of Px = 0 is a scalar multiple of (2, 5, 4, 3, 1). Find the rank of P. Give a single number.

How to think about it

  1. What is asked. The rank of P.
  2. Which idea applies. The null space is a line, so its dimension is 1. Rank-nullity applies.
  3. Work it out. Rank = 5 - 1 = 4.
  4. Check. Rank 4 is at most the number of rows, 4.

Exam-level practice

Exam-level 1: Rank of an outer product sum (NAT, 1 mark)

Let u = (1, 2, 3), v = (2, 4, 6) and w = (1, 0, 1). Find the rank of M = uuᵀ + vvᵀ + wwᵀ.

How to think about it

  1. What is asked. The rank of a sum of three rank-one matrices.
  2. Which idea applies. The column space of M is spanned by u, v and w (M is a Gram-type sum of positive semidefinite pieces), so rank(M) = dim span{u, v, w}.
  3. Work it out. v = 2u, so the span is span{u, w}. u and w are not parallel, so the rank is 2.
  4. Check. The code computes the rank by exact row reduction.
from fractions import Fraction as F
vs = [(1, 2, 3), (2, 4, 6), (1, 0, 1)]
M = [[F(sum(v[i] * v[j] for v in vs)) for j in range(3)] for i in range(3)]
rank, r = 0, 0
for c in range(3):
    p = next((i for i in range(r, 3) if M[i][c] != 0), None)
    if p is None:
        continue
    M[r], M[p] = M[p], M[r]
    for i in range(r + 1, 3):
        M[i] = [a - M[i][c] / M[r][c] * b for a, b in zip(M[i], M[r])]
    r += 1
print("rank =", r)

rank = 2

Answer: 2.

Exam-level 2: Nullity of a product (MSQ, 2 marks)

A is 5 × 3 with rank 3 and B is 3 × 4 with rank 2. Which are TRUE? (A) rank(AB) = 2. (B) nullity(AB) = 2. (C) nullity(B) = 1. (D) AB has a nonzero null vector.

How to think about it

  1. What is asked. Rank and nullity of B and AB.
  2. Which idea applies. A has full column rank, so Ax = 0 only for x = 0. Hence ABx = 0 exactly when Bx = 0. Rank-nullity: rank + nullity = number of columns.
  3. Work it out. Null(AB) = Null(B), so rank(AB) = rank(B) = 2. True. nullity(AB) = 4 − 2 = 2. True. nullity(B) = 4 − 2 = 2, not 1. False. A nullity of 2 means nonzero null vectors exist. True.
  4. Check. Columns of AB: 4. Rank 2 plus nullity 2 gives 4.

Answer: (A), (B) and (D).

Exam-level 3: Determinant with a parameter (NAT, 2 marks)

For A = [[1, 1, 1], [1, k, 1], [1, 1, k²]], find the sum of all real k for which rank(A) is less than 3.

How to think about it

  1. What is asked. Values of k that make det(A) = 0, then their sum.
  2. Which idea applies. Subtract row 1 from rows 2 and 3 to get an upper triangular form.
  3. Work it out. Rows become (1, 1, 1), (0, k − 1, 0), (0, 0, k² − 1). det = (k − 1)(k² − 1) = (k − 1)²(k + 1). Distinct roots are k = 1 and k = −1, so the sum is 0.
  4. Check. The code scans integer k from −5 to 5 for a zero determinant.
def det3(m):
    a, b, c = m
    return a[0]*(b[1]*c[2]-b[2]*c[1]) - a[1]*(b[0]*c[2]-b[2]*c[0]) + a[2]*(b[0]*c[1]-b[1]*c[0])
print([k for k in range(-5, 6) if det3([[1, 1, 1], [1, k, 1], [1, 1, k * k]]) == 0])

[-1, 1]

Answer: 0 (the values are k = 1 and k = −1).

Summary

Determinant
A number that measures area scaling. For 2 x 2, ad - bc.
Minor
The determinant after covering one row and one column.
Cofactor
A minor with the checkerboard sign (-1)i+j.
Cofactor expansion
Determinant by adding entry times cofactor across one row.
Row swap
Changes the sign of the determinant.
Adding a row multiple
Leaves the determinant unchanged.
Triangular determinant
The product of the diagonal entries.
Product rule
det(AB) = det(A) det(B). Determinants multiply, not add.
Singular
det = 0. The matrix has no inverse.
Pivot
The first non-zero entry of a row in staircase form.
Rank
The number of pivots.
Null space
All x with Ax = 0.
Nullity
The dimension of the null space, which is n minus the rank.
Free variable
A variable not fixed by the pivots. The number of free variables is the nullity.
Rank-nullity theorem
rank + nullity = number of columns.
Cofactor expansion along any line
The same method works along any row or column, with the same checkerboard signs.
Non-trivial null vector
A non-zero x with Ax = 0. It exists exactly when the matrix is singular.

Remember these

  1. Determinant zero means singular: the matrix squashes space flat and has no inverse.
  2. A row swap flips the sign of the determinant. Adding a multiple of one row changes nothing.
  3. det(AB) = det(A) det(B). Never write det(A + B) = det(A) + det(B).
  4. Rank equals the number of pivots. Count pivots, not non-zero entries.
  5. Rank plus nullity equals the number of columns.
  6. For a square matrix, invertible, det non-zero, rank n and nullity 0 go together.
