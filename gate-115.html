Predicate / First-order logic

Predicate logic, also called first-order logic, lets us talk about objects, their properties and relations, and statements about all or some of them. It is more expressive than propositional logic and is central to knowledge representation in AI.

The idea in plain words

Propositional logic treats "Socrates is human" as one letter, p. It cannot see inside the sentence. But many useful facts talk about objects. "All humans are mortal" is about every human, not one specific person. We need a logic that can look inside a sentence and talk about objects. That logic is first-order logic (FOL), also called predicate logic.

FOL adds three new ideas. First, objects such as Socrates or the number 3. Second, predicates, which are properties or relations, such as Human(x) meaning "x is human". Third, quantifiers, which say "for all" or "there exists". With these tools, "All humans are mortal" becomes a short formula that works for any object.

Everyday analogy: a class list. A teacher can say "everyone in the class passed" (for all students) or "someone in the class got full marks" (there exists a student). Quantifiers say how many objects must satisfy a property.

Why it matters for GATE. In the Data Science and AI (DA) paper, you may be asked to translate a sentence into FOL, negate a quantified sentence, or pick the correct inference rule. These questions test careful reading more than arithmetic.

Key terms

Object (constant)
Plain: a specific thing, such as Socrates. Precise: a constant symbol names one object in the domain.
Domain
Plain: the set of things we are talking about. Precise: the non-empty set of objects over which the variables range.
Variable
Plain: a placeholder such as x that stands for any object. Precise: a symbol that a quantifier or substitution can assign objects to.
Predicate
Plain: a property or relation. Precise: a symbol with a fixed number of arguments that gives true or false, such as Human(x) or Loves(x, y).
Function
Plain: maps objects to objects, such as father-of. Precise: a symbol that takes objects and returns an object, such as f(x).
Term
Plain: something that names an object. Precise: a constant, a variable, or a function applied to terms.
Universal quantifier (∀)
Plain: "for all". Precise: ∀x P(x) is true when P(x) is true for every object x in the domain.
Existential quantifier (∃)
Plain: "there exists" or "some". Precise: ∃x P(x) is true when P(x) is true for at least one object.
Scope
The part of a formula that a quantifier applies to.
Free and bound variable
A variable is bound when a quantifier binds it. Otherwise it is free.
Ground term
A term with no variables, such as Socrates or f(plato).

Concept 1: Predicates, variables and quantifiers

A predicate with a placeholder is not yet true or false. Human(x) is only a pattern. It becomes true or false once we plug in an object. Human(socrates) is true. Human(rock) is false.

A quantifier turns the pattern into a claim about the whole domain.

∀x Human(x) means every object x in the domain is human.
∃x Human(x) means at least one object x in the domain is human.

Read the symbols one at a time. ∀ is an upside-down A for "all". ∃ is a backwards E for "exists". After the quantifier comes the variable, then the formula the quantifier controls.

Now a worked example with the domain {socrates, plato, rock}. Let Human(socrates) = T, Human(plato) = T and Human(rock) = F.

  1. ∃x Human(x). Check each object until one works. Socrates is human, so ∃x Human(x) is true.
  2. ∀x Human(x). Check all three. Rock is not human, so the claim fails. ∀x Human(x) is false.

The same ideas can be checked in Python. The domain is a list. A "for all" test is written with all, and a "there exists" test with any.

domain = ["socrates", "plato", "rock"]
human = {"socrates", "plato"}
mortal = {"socrates", "plato"}

forall_ok = all((x not in human) or (x in mortal) for x in domain)
print("All humans are mortal:", forall_ok)

exists_bad = any((x in human) and (x not in mortal) for x in domain)
print("Some human is not mortal:", exists_bad)

print("Every element is human:", all(x in human for x in domain))

P = {"socrates", "plato"}
lhs = not all(x in P for x in domain)
rhs = any(x not in P for x in domain)
print("Not every element is in P:", lhs)
print("Negation rule holds here:", lhs == rhs)
All humans are mortal: True
Some human is not mortal: False
Every element is human: False
Not every element is in P: True
Negation rule holds here: True

TrapNotice the pattern. With "all", the sentence "all humans are mortal" uses → inside: ∀x (Human(x) → Mortal(x)). With "some", the sentence "some humans are mortal" uses ∧ inside: ∃x (Human(x) ∧ Mortal(x)). Mixing these up is the most common mistake in GATE questions.

Question: Is ∃x (Human(x) ∧ Mortal(x)) true in the domain above?

Yes. Socrates is human and mortal, so at least one object works.

Question: Is Human(x) on its own true or false?

It is neither, until x is replaced by an object or a quantifier is added. It is only a pattern.

Concept 2: Translating English into first-order logic

Translation is a skill, and it follows a few patterns. Use these predicates in the examples: Student(x) means x is a student, Passed(x) means x passed, Bird(x) means x is a bird, Fly(x) means x can fly, and Loves(x, y) means x loves y.

Pattern 1: "every" or "all"

Use ∀ with an arrow. "Every student passed" means: for every object x, if x is a student, then x passed.

∀x (Student(x) → Passed(x))

Pattern 2: "some" or "there is"

Use ∃ with AND. "Some student passed" means there is an object x that is a student and passed.

∃x (Student(x) ∧ Passed(x))

Pattern 3: "not every"

Negate the universal form. "Not every bird can fly" means it is not the case that all birds fly. Use the rule ¬∀x P(x) ≡ ∃x ¬P(x).

¬∀x (Bird(x) → Fly(x)) ≡ ∃x (Bird(x) ∧ ¬Fly(x))

Read the right side in words: there is a bird that cannot fly. Negating an implication turns it into an AND with a negated right side, because ¬(A → B) ≡ A ∧ ¬B.

Pattern 4: order of quantifiers

Two quantifiers of the same kind can be swapped safely. Mixed quantifiers cannot. Compare these two sentences with Loves(x, y) meaning x loves y:

  • ∀x ∃y Loves(x, y): everyone loves someone, possibly a different person for each x.
  • ∃y ∀x Loves(x, y): there is one special person whom everyone loves.

The first is much weaker. Always read the quantifiers from left to right.

Key ideaWhen you negate a formula, push the ¬ inward and swap each quantifier: ¬∀ becomes ∃¬, and ¬∃ becomes ∀¬. For example, ¬∃x Fly(x) ≡ ∀x ¬Fly(x): nothing flies means everything does not fly.

Question: Translate "some cats are black" with Cat(x) and Black(x).

∃x (Cat(x) ∧ Black(x)). Use AND for "some", because the object must have both properties.

Question: What is the negation of ∃x (Cat(x) ∧ Black(x))?

∀x ¬(Cat(x) ∧ Black(x)), which is the same as ∀x (Cat(x) → ¬Black(x)). "No cat is black."

Concept 3: Inference rules and expressiveness

An inference rule is a safe step that gives a new true sentence from old ones. Three rules matter most in GATE.

  • Universal Instantiation (UI). From ∀x P(x), infer P(c) for any object c, such as P(socrates). We can plug in any ground term.
  • Existential Instantiation (EI). From ∃x P(x), infer P(c) for a new constant c that is not used anywhere else. We only know that some object works, so we give it a fresh name.
  • Existential Generalization (EG). From P(c), infer ∃x P(x). If one object works, then something exists.

Modus ponens still works in FOL. From P(a) → Q(a) and P(a), infer Q(a).

Worked example

Given: ∀x (P(x) → Q(x)) and ∃x P(x). Show that ∃x Q(x) follows.

  1. From ∃x P(x), use EI with a new constant c to get P(c).
  2. From ∀x (P(x) → Q(x)), use UI with c to get P(c) → Q(c).
  3. From P(c) and P(c) → Q(c), use modus ponens to get Q(c).
  4. From Q(c), use EG to get ∃x Q(x).

TrapDo not use EI with a constant that is already in use. If the premises mention socrates, a new constant must be a different name. Also, EG can only go from a specific object to "something exists". It cannot go to "everything".

Expressiveness

Propositional logic cannot say "all humans are mortal" without listing every human as a separate letter. FOL says it in one formula, for any domain size. This is why FOL is more expressive: it can state general rules and talk about relations between objects.

The price is that FOL is harder to decide. Some FOL questions have no algorithm that always gives a yes or no answer. For GATE, you only need the basic rules above and the ability to compare the two logics.

Question: Which rule turns P(socrates) into ∃x P(x)?

Existential Generalization (EG). Any object that works gives "something exists".

Question: Can you derive ∀x Q(x) from ∃x P(x) and ∀x (P(x) → Q(x))?

No. You only know that some object satisfies P, so only that object is known to satisfy Q. The other objects are not covered.

Solved GATE-style problems

These problems are original, written in the style of GATE. They are not past exam questions.

Translate "every"

Using Student(x) and Passed(x), translate "every student passed" into FOL.

How to think about it

  1. What is asked. One FOL sentence.
  2. Which idea applies. "Every" means ∀, and the claim is an implication.
  3. Work it out. For every x, if x is a student then x passed: ∀x (Student(x) → Passed(x)).
  4. Check. An AND here would say everything is a student who passed, which is wrong.

Answer: ∀x (Student(x) → Passed(x)).

Correct translations of "some" (select all that apply)

Let Cat(x) mean x is a cat and Black(x) mean x is black. Which formulas correctly say "some cats are black"? Select all that apply.

(A) ∃x (Cat(x) ∧ Black(x))
(B) ∀x (Cat(x) → Black(x))
(C) ∃x (Cat(x) → Black(x))
(D) ¬∀x (Cat(x) → ¬Black(x))

How to think about it

  1. What is asked. Which formulas mean "some cats are black".
  2. Which idea applies. "Some" uses ∃ with AND.
  3. Work it out. (A) is correct. (B) says all cats are black, which is too strong. (C) is weak: any non-cat makes the implication true, so it does not say a black cat exists. (D) negates "no cat is black", which means some cat is black, so (D) is correct.
  4. Check. Pick an object that is not a cat. It makes (C) true, but that does not prove any cat is black.

Answer: (A) and (D).

Negate a mixed-quantifier sentence

Write the negation of ∀x ∃y Loves(x, y) with all negations moved inward.

How to think about it

  1. What is asked. A formula equal to ¬∀x ∃y Loves(x, y), with no ¬ outside a predicate.
  2. Which idea applies. ¬∀ becomes ∃¬, and ¬∃ becomes ∀¬.
  3. Work it out. ¬∀x (∃y Loves(x, y)) becomes ∃x ¬(∃y Loves(x, y)). Then ¬∃y becomes ∀y ¬. We get ∃x ∀y ¬Loves(x, y).
  4. Check. In words: there is someone who loves nobody. That is the opposite of "everyone loves someone".

Answer: ∃x ∀y ¬Loves(x, y).

Translate "not every"

Using Bird(x) and Fly(x), translate "not every bird can fly" into FOL with the negation moved inward.

How to think about it

  1. What is asked. A FOL sentence for "not every bird can fly".
  2. Which idea applies. The universal sentence is ∀x (Bird(x) → Fly(x)). We negate it.
  3. Work it out. ¬∀x (Bird(x) → Fly(x)) ≡ ∃x ¬(Bird(x) → Fly(x)) ≡ ∃x (Bird(x) ∧ ¬Fly(x)).
  4. Check. In words: there is a bird that cannot fly. This matches the English.

Answer: ∃x (Bird(x) ∧ ¬Fly(x)).

Name the inference rules

Given ∀x (P(x) → Q(x)) and P(a), derive Q(a). Name each rule you use.

How to think about it

  1. What is asked. A derivation with the rule names.
  2. Which idea applies. Universal instantiation, then modus ponens.
  3. Work it out. UI with the object a gives P(a) → Q(a). Modus ponens with P(a) gives Q(a).
  4. Check. Each step uses only the sentences before it, and the object a is already known, so no new constant is needed.

Answer: Universal Instantiation, then Modus Ponens.

Derive an existential conclusion

From ∀x (P(x) → Q(x)) and ∃x P(x), derive ∃x Q(x). Give each step and the rule used.

How to think about it

  1. What is asked. A full derivation with rules.
  2. Which idea applies. EI on the "some" fact, UI on the "all" fact, modus ponens, then EG.
  3. Work it out. (1) EI on ∃x P(x) gives P(c), with c a new constant. (2) UI on the universal sentence with c gives P(c) → Q(c). (3) Modus ponens on (1) and (2) gives Q(c). (4) EG on Q(c) gives ∃x Q(x).
  4. Check. The new constant c was used only inside the proof, and the conclusion has no c, so the derivation is valid.

Answer: P(c) by EI, P(c) → Q(c) by UI, Q(c) by modus ponens, and ∃x Q(x) by EG.

Count the elements that satisfy a formula

The domain is {1, 2, 3, 4, 5, 6}. For how many values of x is the formula ∃y (x · y = 12) true? Here y also ranges over the domain. Give a whole number.

How to think about it

  1. What is asked. How many x in the domain have some y in the domain with x times y equal to 12.
  2. Which idea applies. For each x, search for a y. The ∃ needs only one y.
  3. Work it out. x = 1 needs y = 12, not in the domain. x = 2 gives y = 6, which works. x = 3 gives y = 4, which works. x = 4 gives y = 3, which works. x = 5 needs y = 12/5, not an integer. x = 6 gives y = 2, which works. Total: 4 values.
  4. Check. The four values are 2, 3, 4 and 6. Each has a partner y in the domain: 6, 4, 3 and 2.

Answer: 4.

Exam-level practice

Exam-level 1: Negating quantifiers (MCQ, 2 marks)

The negation of ∀x ∃y (P(x, y) → Q(y)) is (A) ∃x ∀y (P(x, y) ∧ ¬Q(y)) (B) ∃x ∀y (¬P(x, y) ∨ Q(y)) (C) ∀x ∃y (P(x, y) ∧ ¬Q(y)) (D) ∃x ∃y ¬P(x, y)

How to think about it

  1. What is asked. The correct negation.
  2. Which idea applies. Swap each quantifier and negate the body. ¬(A → B) = A ∧ ¬B.
  3. Work it out. ∃x ∀y ¬(P → Q) = ∃x ∀y (P ∧ ¬Q).
  4. Check. Each step is a standard equivalence.

Answer: (A).

Exam-level 2: Evaluating on a finite domain (NAT, 2 marks)

Domain {1, 2, 3, 4, 5, 6}. Let D(x, y) mean x divides y. For how many x is ∀y (D(x, y) → x ≤ y) ∧ ∃y (x ≠ y ∧ D(x, y)) true?

How to think about it

  1. What is asked. The x values with a proper multiple in the domain.
  2. Which idea applies. The first part always holds for positive integers. The second asks for a multiple other than x inside the domain.
  3. Work it out. x = 1, 2, 3 have multiples 2, 4, 6 in range. x = 4, 5, 6 do not. Count 3.
  4. Check. The code checks.
D = range(1, 7)
print(sum(all(x <= y for y in D if y % x == 0) and any(y != x and y % x == 0 for y in D) for x in D))

3

Answer: 3.

Exam-level 3: Valid inferences (MSQ, 2 marks)

Which are valid in first-order logic? (A) ∀x P(x) ⊨ ∃x P(x), for a nonempty domain. (B) ∃x ∀y R(x, y) ⊨ ∀y ∃x R(x, y). (C) ∀y ∃x R(x, y) ⊨ ∃x ∀y R(x, y). (D) ∀x (P(x) ∧ Q(x)) ⊨ ∀x P(x) ∧ ∀x Q(x).

How to think about it

  1. What is asked. Which entailments hold.
  2. Which idea applies. ∃∀ is stronger than ∀∃.
  3. Work it out. (A) True. (B) True. (C) "Everyone has a mother" does not give one mother of all. False. (D) True.
  4. Check. (B) and (C) together show the quantifier order matters.

Answer: (A), (B) and (D).

Summary

First-order logic
Logic that talks about objects, properties and relations, with quantifiers.
Domain
The set of objects the variables range over.
Predicate
A property or relation that is true or false for objects, such as Human(x).
Function
Maps objects to objects, such as f(x).
Constant
A name for one specific object.
Variable
A placeholder for any object in the domain.
Universal quantifier (∀)
True when the formula holds for every object.
Existential quantifier (∃)
True when the formula holds for at least one object.
Scope
The part of the formula a quantifier controls.
Bound variable
A variable controlled by a quantifier.
Universal Instantiation
From ∀x P(x), infer P(c) for any object c.
Existential Instantiation
From ∃x P(x), infer P(c) for a new constant c.
Existential Generalization
From P(c), infer ∃x P(x).
Modus ponens
From A → B and A, infer B.
Expressiveness
How much a logic can state. FOL can say general rules in one formula.
Ground term
A term with no variables.

Remember these

  1. "All" goes with → inside ∀. "Some" goes with ∧ inside ∃.
  2. Negation swaps the quantifier: ¬∀ becomes ∃¬, and ¬∃ becomes ∀¬.
  3. Read mixed quantifiers from left to right. The order changes the meaning.
  4. Use a new constant for EI, and never reuse an existing name.
  5. EG goes from one known object to "something exists", never to "everything".
  6. FOL can state general rules that propositional logic cannot.
