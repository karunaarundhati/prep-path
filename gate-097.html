Multiple linear regression

Multiple linear regression predicts one number from several inputs at once. You will learn the model, how the best coefficients are found with matrices, how to measure fit with R squared and adjusted R squared, and the assumptions behind the method.

The idea in plain words

Imagine you want to guess the price of a second-hand car. One clue is its age. You could draw a straight line through many cars and read the price from the line. That is simple linear regression. But a real car price depends on many things at once: age, mileage, engine size and condition. Multiple linear regression lets you use all of these clues together in one straight-line rule.

Think of a recipe. A cake's sweetness might depend on the spoons of sugar, the spoons of honey and the amount of fruit. Each ingredient adds its own share to the final taste. Multiple regression says: take each input, multiply it by a weight that says how strongly it matters, add the results together, and you get a prediction. The job of the learning algorithm is to find the best weights from the data.

Why does this matter for GATE? Multiple linear regression is the first real model in the Machine Learning part of the Data Science and AI paper (DA). It appears in questions about writing the model, computing coefficients with the normal equations, reading R squared, spotting multicollinearity, and checking the assumptions. The Robotics and Automation paper (RA) uses the same ideas when it fits a line or a plane to measured data.

You do not need to know any advanced maths to start. You need three things: the idea of a weighted sum, a little matrix multiplication, and patience with symbols. Each of these is explained below, one small step at a time.

Key terms

Read these first. Every term is used again later on the page.

Input or feature
A measured clue that goes into the model, such as the age of a car. Precisely: an independent variable xj.
Output or target
The number we want to predict, such as the price of a car. Precisely: the dependent variable y.
Coefficient or weight
A number that says how much one input moves the output. Precisely: βj, the slope for input xj.
Intercept
The prediction when all inputs are zero. Precisely: β0, the constant term.
Error or residual
The gap between the real output and the predicted output. Precisely: for one data point, residual = y minus ŷ, where ŷ is the predicted value.
Least squares
A rule for choosing the weights: pick the weights that make the sum of squared residuals as small as possible.
Matrix X
A table with one row per data point and one column per input, with an extra column of 1s for the intercept. Precisely: an m by (n+1) matrix.
Transpose XT
The same table with rows and columns swapped. The row 1 2 3 becomes the column 1, 2, 3.
Normal equations
The set of equations XTXβ = XTy that the best weights must satisfy.
Sum of squares total SST
How much the real outputs spread around their average. Precisely: SST = Σ(yi minus ȳ) squared.
Sum of squares residual SSR
How much the predictions miss. Precisely: SSR = Σ(yi minus ŷi) squared.
R squared
The share of the spread that the model explains, between 0 and 1 on training data with an intercept. Precisely: R² = 1 minus SSR/SST.
Adjusted R squared
R squared corrected for the number of inputs, so that adding useless inputs does not look good. Precisely: 1 minus (1 minus R²)(m minus 1)/(m minus n minus 1).
Multicollinearity
Two or more inputs that carry almost the same information, which makes the weights unstable.
Variance inflation factor VIF
A score for how badly one input is explained by the others. Precisely: VIFj = 1/(1 minus Rj²), where Rj² comes from regressing xj on the other inputs.
Homoscedasticity
The spread of the errors stays about the same for every prediction. The opposite is heteroscedasticity.

The model with many inputs

Step 1: start from the simple case

In simple linear regression we have one input x and one output y. The model is a straight line: y = β0 + β1x. Here β0 is the intercept (where the line crosses the vertical axis) and β1 is the slope (how much y goes up when x goes up by one).

Step 2: add more inputs

Now suppose we have n inputs, x1, x2, up to xn. The model becomes:

y = β0 + β1x1 + β2x2 + ... + βnxn + ε

Read it symbol by symbol. y is the output we predict. x1 to xn are the inputs. β0 to βn are the coefficients the algorithm must learn. The three dots mean "the same pattern continues". The letter ε (epsilon) is the part of y that the model cannot explain, the random noise.

In practice we never see the true β values. We have data: m rows, each with its inputs and its known output. We use the data to estimate the β values. The estimates are written with hats, β̂, or simply β when the context is clear.

Step 3: a tiny example with numbers

Suppose a model is ŷ = 2 + 3x1 minus x2. Here β0 = 2, β1 = 3 and β2 = minus 1. Predict y when x1 = 4 and x2 = 1.

  1. Start with the intercept. The sum starts at 2.
  2. Add the first input term. 3 times 4 is 12. The sum is 2 + 12 = 14.
  3. Add the second input term. minus 1 times 1 is minus 1. The sum is 14 minus 1 = 13.
  4. Read the answer. The predicted output is 13.

TipThe hat on ŷ means "predicted". The letter y without a hat means "the real measured value". Keeping these apart stops many mistakes.

Step 4: the meaning of a coefficient

Each coefficient answers this question: if this one input goes up by 1 and all the other inputs stay exactly the same, how much does the prediction change? For β1 = 3, a rise of 1 in x1 adds 3 to the prediction when x2 is held fixed. The phrase "holding the other inputs fixed" is the most important idea in this topic.

TrapA coefficient is not a fixed fact about the world. It depends on which other inputs are in the model. Adding or removing an input can change every other coefficient.

Step 5: the matrix form

Writing every data point out by hand is slow. Matrices pack all the data into one compact statement. We stack the data into a table called X. Each row is one data point. The first column is always 1, so that the intercept β0 multiplies a 1. The other columns are the inputs.

X (m rows, n+1 columns)      y (m rows)     β (n+1 rows)

[ 1  x11  x12  ... x1n ]     [ y1 ]         [ β0 ]
[ 1  x21  x22  ... x2n ]     [ y2 ]         [ β1 ]
[ :   :    :        :  ]     [ :  ]         [ :  ]
[ 1  xm1  xm2  ... xmn ]     [ ym ]         [ βn ]

With this layout the whole model for all m points is written in one line: y = Xβ + ε. The product Xβ means: for each row of X, multiply its entries by the matching entries of β, and add them up. This gives one predicted value per row.

ŷ = Xβ

Let us check this on the one-row example. The row of X is [1, 4, 1] (the 1 for the intercept, then x1 = 4 and x2 = 1). The vector β is [2, 3, minus 1]. The product is 1 times 2, plus 4 times 3, plus 1 times minus 1, which is 2 + 12 minus 1 = 13. It matches Step 3.

Key ideaMatrix form does not change the model. It is only a neat way to write the same weighted sum for every data point at once. That neatness is what lets us solve for β in one go.

Worked check in Python

The next code runs the same row calculation with a small loop. Read it carefully, because the same pattern appears in the matrix formulas.

beta = [2, 3, -1]      # intercept, weight of x1, weight of x2
row = [1, 4, 1]       # the 1 for the intercept, then x1 = 4 and x2 = 1
prediction = sum(b * x for b, x in zip(beta, row))
print("predicted y =", prediction)
predicted y = 13
Question: why is the first column of X always 1?

Because the intercept β0 has no input of its own. Multiplying it by 1 keeps it unchanged, so the same matrix product handles the intercept and the slopes together.

Question: a model has 3 inputs. How many columns does X have?

Four. One column of 1s for the intercept plus one column for each of the three inputs.

Least squares in matrix form

Why we need a rule

Suppose you try several possible sets of weights. Each set gives a different prediction for every data point. We need one rule that says which set is best. The usual rule is least squares: measure the residual for each point, square it so that positive and negative misses do not cancel, add up the squares, and choose the weights that make this total smallest.

The squaring step is worth a moment. If one prediction is 2 too high and another is 2 too low, plain adding gives zero, which hides the error. Squaring gives 4 and 4, which adds to 8. So squares measure how wrong the model really is.

SSR(β) = Σ (yi minus ŷi)² = (y minus Xβ)T(y minus Xβ)

Read it symbol by symbol. The Σ (capital sigma) means "add up over all data points i". The vector y minus Xβ holds all the residuals at once. The small T means transpose, which turns a column into a row so that the product of the vector with itself gives the sum of squares.

Step 1: the idea of the minimum

A cup of water at the bottom of a bowl is at its lowest point. If you tilt the bowl slightly in any direction, the water rises. At the lowest point the slope is flat in every direction. Least squares works the same way. The best β is where the slope of SSR, in every direction of β, is flat. Setting the slope to zero gives the normal equations.

XTX β = XTy

Here XTX is a square matrix, and XTy is a column of numbers. The unknown is β. If XTX has an inverse, we can multiply both sides by it to get the solution.

β = (XTX)-1 XTy

The power -1 means "the inverse". The inverse of a matrix plays the role of dividing by a number. Just as 6 divided by 3 is the same as 6 times one third, a matrix equation with an inverse can be solved by multiplying by the inverse.

TrapThe inverse exists only when XTX is invertible, which means its determinant is not zero. If one input is an exact copy of another, or a perfect mix of others, XTX is singular and the formula breaks. This is the extreme case of multicollinearity, explained later.

We use two inputs, x1 and x2, and four data points. The table of data is:

The matrix X has four rows, each starting with 1. So X is 4 by 3 and y is 4 by 1.

X = [ 1 1 2 ]        y = [ 3 ]

Step 3: build XTX

XT has three rows, one for each column of X. The entry in row i and column j of XTX is the sum of the products of column i and column j of X. Let us compute each entry.

  • Row 1 with row 1: the column of 1s times itself gives 1 + 1 + 1 + 1 = 4.
  • The column of 1s with the x1 column: 1 + 2 + 3 + 4 = 10.
  • The column of 1s with the x2 column: 2 + 1 + 4 + 3 = 10.
  • The x1 column with itself: 1 + 4 + 9 + 16 = 30.
  • The x1 column with the x2 column: 1×2 + 2×1 + 3×4 + 4×3 = 2 + 2 + 12 + 12 = 28.
  • The x2 column with itself: 4 + 1 + 16 + 9 = 30.
X^T X = [ 4   10  10 ]
        [ 10  30  28 ]
        [ 10  28  30 ]

Step 4: build XTy

Now multiply each column of X by y and add up the products.

  • The column of 1s with y: 3 + 7 + 8 + 10 = 28.
  • The x1 column with y: 1×3 + 2×7 + 3×8 + 4×10 = 3 + 14 + 24 + 40 = 81.
  • The x2 column with y: 2×3 + 1×7 + 4×8 + 3×10 = 6 + 7 + 32 + 30 = 75.
X^T y = [ 28 ]
        [ 81 ]
        [ 75 ]

Step 5: solve the three equations

The normal equations now read as three simple equations in three unknowns β0, β1 and β2.

4 b0 + 10 b1 + 10 b2 = 28
10 b0 + 30 b1 + 28 b2 = 81
10 b0 + 28 b1 + 30 b2 = 75

Solve by elimination. First, multiply the first equation by 2.5 so that its first term is 10 b0. That gives 10 b0 + 25 b1 + 25 b2 = 70. Subtract this from the second equation: 5 b1 + 3 b2 = 11. Subtract it from the third equation: 3 b1 + 5 b2 = 5.

Now solve the two-variable pair. Multiply the first new equation by 3 and the second by 5: 15 b1 + 9 b2 = 33 and 15 b1 + 25 b2 = 25. Subtract the first from the second: 16 b2 = minus 8, so b2 = minus 1/2. Put b2 back into 5 b1 + 3 b2 = 11: 5 b1 minus 1.5 = 11, so 5 b1 = 12.5 and b1 = 2.5. Finally, put both into 4 b0 + 10 b1 + 10 b2 = 28: 4 b0 + 25 minus 5 = 28, so 4 b0 = 8 and b0 = 2.

β = (2, 5/2, minus 1/2)

So the fitted model is ŷ = 2 + 2.5 x1 minus 0.5 x2. In real life you would let a computer solve the system, but it is good to know what it is doing. The code below checks the answer with exact fractions, so that no rounding can hide a mistake.

Step 6: check the fitted values and residuals

Put each row of X into the model. For point 1, the prediction is 2 + 2.5×1 minus 0.5×2 = 2 + 2.5 minus 1 = 3.5. For point 2, it is 2 + 5 minus 0.5 = 6.5. For point 3, it is 2 + 7.5 minus 2 = 7.5. For point 4, it is 2 + 10 minus 1.5 = 10.5. The residuals are y minus ŷ: minus 0.5, plus 0.5, plus 0.5 and minus 0.5. They add to zero, which is always true for least squares with an intercept.

from fractions import Fraction as F

X = [[1, 1, 2], [1, 2, 1], [1, 3, 4], [1, 4, 3]]
y = [3, 7, 8, 10]

def transpose(M):
    return [list(col) for col in zip(*M)]

def matmul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B)))
             for j in range(len(B[0]))] for i in range(len(A))]

def solve(A, b):
    # Gauss-Jordan elimination with exact fractions
    n = len(A)
    M = [[F(v) for v in A[i]] + [F(b[i])] for i in range(n)]
    for c in range(n):
        p = next(r for r in range(c, n) if M[r][c] != 0)
        M[c], M[p] = M[p], M[c]
        M[c] = [v / M[c][c] for v in M[c]]
        for r in range(n):
            if r != c and M[r][c] != 0:
                M[r] = [a - M[r][c] * v for a, v in zip(M[r], M[c])]
    return [M[i][n] for i in range(n)]

Xt = transpose(X)
XtX = matmul(Xt, X)
Xty = [sum(Xt[i][k] * y[k] for k in range(4)) for i in range(3)]
print("X^T X =", XtX)
print("X^T y =", Xty)
beta = solve(XtX, Xty)
print("beta  =", [str(v) for v in beta])
print("sum of residuals =", sum(y[i] - sum(X[i][j] * beta[j] for j in range(3)) for i in range(4)))
X^T X = [[4, 10, 10], [10, 30, 28], [10, 28, 30]]
X^T y = [28, 81, 75]
beta  = ['2', '5/2', '-1/2']
sum of residuals = 0
Question: why do the residuals add to zero?

Because the intercept term is in the model. The normal equations include the row of 1s in X, and that row says the residuals must sum to zero. Without an intercept, this need not hold.

Question: what does the solution β = (2, 5/2, minus 1/2) tell you about x2?

Holding x1 fixed, each extra unit of x2 lowers the prediction by half a unit. The negative sign says the two directions pull in opposite ways.

R squared and adjusted R squared

The question R squared answers

Once you have a model, you need a score. How good is it? Imagine you know only the average price of all cars. Your best guess for every car is that average. That guess has some total error. Now imagine your model. Its predictions should be closer to the real prices. R squared measures how much of the original error the model removed.

Two sums do the work. The first is SST, the total spread of the real y values around their average ȳ. It is the error of the "always guess the average" rule.

SST = Σ (yi minus ȳ)²

The second is SSR, the leftover spread of the residuals, the errors of the model.

SSR = Σ (yi minus ŷi)²

R squared is then:

R² = 1 minus SSR/SST

If the model is perfect, SSR is 0 and R² is 1. If the model is no better than guessing the average, SSR equals SST and R² is 0. For a least squares model with an intercept, R² always lies between 0 and 1 on the training data.

Worked example with the four points

Use the same four points as before, with y = 3, 7, 8, 10. The mean is ȳ = (3 + 7 + 8 + 10)/4 = 28/4 = 7.

  1. Find SST. The deviations from 7 are minus 4, 0, 1 and 3. Their squares are 16, 0, 1 and 9. Add them: SST = 26.
  2. Find the fitted values. From the earlier work, ŷ = 3.5, 6.5, 7.5 and 10.5.
  3. Find the residuals. y minus ŷ gives minus 0.5, plus 0.5, plus 0.5 and minus 0.5.
  4. Find SSR. The squares are 0.25, 0.25, 0.25 and 0.25. Add them: SSR = 1.
  5. Find R squared. R² = 1 minus 1/26 = 25/26, about 0.9615. The model explains about 96 percent of the spread.

Key ideaR squared is a fraction of the original error that was removed. It is not the chance that the model is right, and it is not a measure of whether the model is correct for new data.

Why adding inputs always raises R squared

Here is a surprising fact. If you add any input to a least squares model, even a column of random noise, SSR cannot go up. The old model is still available as a special case (the new weight is set to zero), so the best fit can only get better or stay the same. Therefore R squared can only go up or stay the same when you add inputs. A model with 50 random inputs can show a high R squared just by chance.

This is why we need a corrected score. That score is adjusted R squared.

R²adj = 1 minus (1 minus R²)(m minus 1)/(m minus n minus 1)

Read the symbols. m is the number of data points. n is the number of inputs, not counting the intercept. The fraction (m minus 1)/(m minus n minus 1) is a penalty. It gets bigger when you use more inputs compared with the number of points, so the score goes down unless the new input really helps.

Worked example of adjusted R squared

Use the four-point model. Here m = 4 and n = 2. R² = 25/26.

  1. Find 1 minus R². It is 1/26.
  2. Find the penalty. (m minus 1)/(m minus n minus 1) = 3/(4 minus 2 minus 1) = 3/1 = 3.
  3. Multiply. (1/26) times 3 = 3/26.
  4. Subtract from 1. Adjusted R² = 1 minus 3/26 = 23/26, about 0.8846.

The adjusted value is lower, as expected, because only 4 points are used to fit 3 numbers. The next code block checks both values with exact fractions.

from fractions import Fraction as F

y = [3, 7, 8, 10]
yhat = [F(7, 2), F(13, 2), F(15, 2), F(21, 2)]   # 3.5, 6.5, 7.5, 10.5

ybar = F(sum(y), len(y))
sst = sum((v - ybar) ** 2 for v in y)
ssr = sum((a - b) ** 2 for a, b in zip(y, yhat))
r2 = 1 - ssr / sst

m, n = len(y), 2                      # 4 points, 2 inputs
adj = 1 - (1 - r2) * (m - 1) / (m - n - 1)

print("SST =", sst)
print("SSR =", ssr)
print("R squared =", r2)
print("adjusted R squared =", adj)
SST = 26
SSR = 1
R squared = 25/26
adjusted R squared = 23/26
Question: an analyst adds a useless input and adjusted R squared falls. What does that tell you?

The new input did not explain enough extra spread to pay for the penalty. The model is worse in the adjusted sense, even though plain R squared could not fall.

Question: can R squared be 0.99 and still be a poor model?

Yes. A high R squared on training data can come from overfitting, from too many inputs, or from a non-linear pattern the model cannot represent. Always check residual plots and new data too.

Multicollinearity

The idea in plain words

Suppose two friends always tell you the same weather news. One says "it is raining" and the other says "the streets are wet". Both clues carry the same information. If you try to credit each friend for your decision to take an umbrella, you cannot tell how much each one really mattered. Multicollinearity is the same problem for regression. Two or more inputs carry almost the same information, so the model cannot separate their effects.

What goes wrong

The coefficients become unstable. A tiny change in the data can make one coefficient jump from plus 3 to minus 4 while the predictions barely change. The model may still predict well, but each individual weight becomes hard to trust. Its standard error becomes large, and a coefficient that should matter may look insignificant.

In the extreme case, the inputs are exact copies or exact mixtures of each other. Look at the earlier matrix. If x2 = 2 times x1 for every row, then the column of x2 is just twice the column of x1. The columns of X are then not independent. The matrix XTX has determinant 0, so it has no inverse, and the formula β = (XTX)-1XTy cannot be used.

TrapExact multicollinearity makes the formula impossible. Near multicollinearity does not break the formula but makes the answer unstable. Both are problems, and the second one is more common in real data.

Measuring it with VIF

To check one input xj, pretend it is the output. Regress xj on all the other inputs and find the R squared of that regression, call it Rj². If the other inputs explain xj very well, Rj² is close to 1. The variance inflation factor turns this into a warning score.

VIFj = 1 / (1 minus Rj²)

If Rj² = 0 (the other inputs say nothing about xj), VIF is 1, the best value. If Rj² = 0.9, the VIF is 1/0.1 = 10. If Rj² is 0.99, the VIF is 100. Many textbooks use a VIF above 5 or 10 as a warning sign. These are rules of thumb, not laws of nature.

GATE loves thisExpect a question that gives Rj² and asks for the VIF. Compute 1/(1 minus Rj²) and check that a large Rj² gives a large VIF.

What to do about it

  • Drop one of the copies. If two inputs carry the same information, keep the one that is easier to measure or explain.
  • Combine them. Use an average, a total, or a ratio that represents both.
  • Collect more varied data. More variety can separate the effects.
  • Use regularisation. Ridge regression, the next topic, adds a penalty that keeps the weights stable even when the inputs are close copies.

A useful habit: before you fit any model, look at the correlations between the inputs. A pair of inputs with correlation close to 1 or minus 1 is a warning sign.

Question: a predictor has Rj² = 0.75. What is its VIF?

1/(1 minus 0.75) = 1/0.25 = 4.

Question: does multicollinearity make the model's predictions wrong?

Not necessarily. The predictions can stay good while the individual coefficients are unreliable. Trouble comes when you need to interpret each coefficient or test each one.

Assumptions of linear regression

Why assumptions matter

A method works best when its conditions hold. Think of a bridge. It is designed for a certain load and certain materials. If you drive a heavy truck over it, the bridge may still stand, but your safety estimate is wrong. Linear regression has assumptions in the same way. When they hold, least squares gives the best possible answers, and the standard tests and confidence intervals are correct. When they fail, the coefficients may still be useful, but the claims you make about them may be false.

The four main assumptions

  1. Linearity. The output is a weighted sum of the inputs plus noise. The relationship between each input and the output is a straight line when the other inputs are held fixed. If the true pattern is a curve, a straight-line model will miss it. How to check: plot the residuals against the predicted values. A curve in the plot means linearity fails.
  2. Independence of errors. The error for one data point does not tell you the error for another. This often fails with data collected over time, where today's error looks like yesterday's. How to check: plot the residuals in the order they were collected and look for runs of positive or negative values.
  3. Homoscedasticity. The spread of the errors is about the same for all predicted values. A funnel shape in the residual plot, where the spread grows as the predictions grow, is called heteroscedasticity. How to check: look at the same residual plot for a funnel.
  4. No perfect multicollinearity, and no strong near-copies. XTX must be invertible. Check the VIF values.

For formal tests and confidence intervals, one more assumption is added. The residuals are roughly normally distributed (bell-shaped) with mean zero. This is needed for the t-tests on individual coefficients in small samples. It is not needed for the least squares estimates to be unbiased.

TrapThe word "normal" means two different things here. A normal distribution is the bell curve. The normal equations are called "normal" because the residual vector is perpendicular (at right angles, "normal") to every column of X. Read the context before you assume a bell curve.

What the assumptions buy you

The Gauss-Markov theorem says that if the errors have mean zero, constant variance and are uncorrelated, and if X has full column rank, then least squares is the best linear unbiased estimator. Best means it has the smallest variance among all unbiased estimators that are linear in y. This is a strong result, but notice the words "if". In real data the conditions are never perfect, so you check them.

Key ideaUnbiased means that on average over many samples, the estimate is right. Best means it is the least spread out among the honest linear rules. Both facts depend on the assumptions above.

Question: does least squares need the errors to be normal to give unbiased coefficients?

No. Unbiasedness needs the errors to have mean zero and to be unrelated to the inputs. Normality is needed only for exact small-sample tests and intervals.

Question: which plot helps you spot a curved relationship?

A plot of residuals against fitted values. A straight-line model should leave residuals that look like random scatter around zero, with no curve.

Predicting with a two-input model

A model is ŷ = 4 + 3x1 minus 2x2. Find ŷ when x1 = 2 and x2 = 1. (NAT)

How to think about it

  1. What is asked. One predicted number for one set of inputs.
  2. Which idea applies. Plug the inputs into the weighted sum.
  3. Work it out. Start with 4. Add 3 times 2, which is 6, giving 10. Add minus 2 times 1, which is minus 2, giving 8.
  4. Check. Each term has the right sign: the weight of x2 is negative, so it pulls the answer down.

Answer: 8

Facts about R squared (MSQ)

For a least squares model with an intercept, fitted on training data, which statements are true? Select all that apply.

(A) R squared cannot decrease when a new input is added.

(B) R squared can be negative.

(C) Adjusted R squared can decrease when a useless input is added.

(D) In multiple regression, R squared always equals the square of one correlation coefficient.

How to think about it

  1. What is asked. Which of four facts are correct.
  2. Which idea applies. Adding inputs can only lower SSR, so plain R squared never falls. The penalty in adjusted R squared can make it fall.
  3. Work it out. (A) is true, as explained in the R squared section. (B) is false, because with an intercept on training data R squared lies between 0 and 1. (C) is true, because a useless input adds a penalty that may be larger than its small gain. (D) is false, because that shortcut works only for simple regression with one input.
  4. Check. The statements that survive are the ones about the rule that adding inputs never lowers plain R squared, and the penalty effect in the adjusted version.

Answer: (A) and (C)

Adjusted R squared from sums of squares (NAT)

A regression uses m = 20 data points and n = 3 inputs. The total sum of squares is SST = 50 and the residual sum of squares is SSR = 10. Find the adjusted R squared to four decimal places. (NAT)

How to think about it

  1. What is asked. Adjusted R squared, not plain R squared.
  2. Which idea applies. First R squared = 1 minus SSR/SST. Then apply the penalty with m and n.
  3. Work it out. R squared = 1 minus 10/50 = 0.8. Then 1 minus R squared is 0.2. The penalty is (m minus 1)/(m minus n minus 1) = 19/16. So 0.2 times 19/16 = 3.8/16 = 0.2375. Adjusted R squared = 1 minus 0.2375 = 0.7625.
  4. Check. The adjusted value must be below 0.8, and it is.

Answer: 0.7625

Reading a solved normal equation (MCQ)

Assume the single input is centred, so that the sum of its values is 0. There are m = 2 data points. Suppose XTX = [[2, 0], [0, 4]] and XTy = [6, 8]T. Which pair (β0, β1) is the least squares solution? Select the single correct option.

(A) (3, 2) (B) (2, 3) (C) (6, 8) (D) (1.5, 2)

How to think about it

  1. What is asked. The β vector that solves XTXβ = XTy.
  2. Which idea applies. β = (XTX)-1XTy. For a diagonal matrix, the inverse just takes reciprocals of the diagonal.
  3. Work it out. The inverse of [[2, 0], [0, 4]] is [[1/2, 0], [0, 1/4]]. Multiply by [6, 8]: the first entry is 6/2 = 3 and the second is 8/4 = 2. So β = (3, 2).
  4. Check. Put it back: 2×3 + 0×2 = 6 and 0×3 + 4×2 = 8. Both match XTy.

Answer: (A) (3, 2)

Variance inflation factor (NAT)

A regression has four inputs. Input x1 is regressed on the other three inputs, and this auxiliary regression gives R2 = 0.9. Find the variance inflation factor (VIF) of x1. (NAT)

How to think about it

  1. What is asked. The VIF for one input.
  2. Which idea applies. VIF = 1/(1 minus Rj²), where Rj² comes from the auxiliary regression.
  3. Work it out. 1 minus 0.9 = 0.1. Then 1/0.1 = 10.
  4. Check. A VIF of 10 is at the usual warning level, which fits an R squared of 0.9 from the other inputs.

Answer: 10

Diagnosing a residual plot (MSQ)

A residual plot for a fitted linear model shows a funnel shape. The residuals are close to zero for small predicted values and spread far from zero for large predicted values. Select all the statements that are true.

(A) The assumption of homoscedasticity is violated.

(B) The errors have larger variance for larger predicted values.

(C) The least squares coefficient estimates become biased.

(D) A transformation of the output, such as its logarithm, might help.

How to think about it

  1. What is asked. Which statements match the funnel pattern.
  2. Which idea applies. A funnel means the spread of the errors changes with the prediction. That is heteroscedasticity.
  3. Work it out. (A) is true: constant spread is the homoscedastic case, and the funnel breaks it. (B) is true: that is exactly what the funnel shows. (C) is false: changing spread alone does not bias least squares coefficients, but it makes their standard errors wrong. (D) is true: many analysts use a log or square-root transform to shrink large spreads.
  4. Check. Ask which statement would be wrong if the spread were fine. Statement (C) is the one to reject. The funnel damages the standard errors, not the average value of the coefficients.

Answer: (A), (B) and (D)

Did the new input help? (NAT)

Model 1 uses m = 30 points and n = 5 inputs, with R squared 0.80. Model 2 adds one more input, so n = 6, uses the same 30 points, and has R squared 0.82. Find the adjusted R squared of model 2 to three decimal places. (NAT)

How to think about it

  1. What is asked. The adjusted R squared of model 2 only.
  2. Which idea applies. Use the adjusted formula with the new n.
  3. Work it out. 1 minus R squared is 0.18. The penalty is (30 minus 1)/(30 minus 6 minus 1) = 29/23. Multiply: 0.18 times 29/23 = 5.22/23, about 0.22696. Subtract from 1: about 0.77304, which rounds to 0.773.
  4. Check. Model 1 gives about 0.758, so the new input raised the adjusted score. The check code below confirms both numbers.

Answer: 0.773

The code below checks the arithmetic of the problems above with exact fractions.

from fractions import Fraction as F

# Problem 3: adjusted R squared
sst, ssr, m, n = 50, 10, 20, 3
r2 = 1 - F(ssr, sst)
adj = 1 - (1 - r2) * F(m - 1, m - n - 1)
print("P3 R squared =", r2, " adjusted =", adj, "=", round(float(adj), 4))

# Problem 5: VIF
r2_aux = F(9, 10)
print("P5 VIF =", 1 / (1 - r2_aux))

# Problem 7: model 2 adjusted R squared
r2_m2, m, n = F(82, 100), 30, 6
adj2 = 1 - (1 - r2_m2) * F(m - 1, m - n - 1)
print("P7 model 2 adjusted =", round(float(adj2), 3))

Exam-level 1: Normal equations by hand (NAT, 2 marks)

A researcher fits a two-input linear model to data that have already been centred, so no intercept column is needed. From her data she finds the matrix XTX = [[4, 2], [2, 6]] and the vector XTy = (10, 14). Using the normal equations beta = (XTX)-1 XTy, find the fitted prediction for a new point with x1 = 1 and x2 = 2. Give the answer to one decimal place. (NAT)

How to think about it

  1. What is asked. One predicted value at a new point, so first find both coefficients.
  2. Which idea applies. The normal equations give the coefficients through the inverse of XTX. Then plug the new inputs into the fitted line.
  3. Work it out. The determinant is 4 times 6 minus 2 times 2, which is 20. The inverse is (1/20) times [[6, -2], [-2, 4]]. Multiply by (10, 14). The first coefficient is (60 minus 28)/20 = 32/20 = 8/5. The second is (minus 20 plus 56)/20 = 36/20 = 9/5. The prediction is 8/5 + 2 times 9/5 = 8/5 + 18/5 = 26/5 = 5.2.
  4. Check. Put the coefficients back into the first normal equation: 4 times 8/5 plus 2 times 9/5 = 32/5 + 18/5 = 10. This matches the first entry of XTy.

Answer: 5.2 (beta1 = 8/5 and beta2 = 9/5)

Exam-level 2: Which least squares facts hold (MSQ, 2 marks)

A data scientist fits ordinary least squares models with and without an intercept. Which of the following statements are correct? Select all that apply.

(A) If one input column is an exact multiple of another input column, XTX is singular and the coefficients are not unique.

(B) Adding one more input to a least squares model never increases the residual sum of squares on the training data.

(C) When the model has an intercept, the residuals add up to zero.

(D) Ordinary least squares is biased whenever the errors are not normally distributed.

How to think about it

  1. What is asked. Which of four statements about least squares are true.
  2. Which idea applies. Singular XTX means no unique inverse. A bigger model fits the training data at least as well. The intercept forces the residuals to sum to zero. Unbiasedness does not need normal errors.
  3. Work it out. (A) is true, because a repeated direction makes the determinant of XTX equal to 0. (B) is true, because the old fit is still available inside the bigger model. (C) is true, because the normal equation for the intercept says the sum of residuals is 0. (D) is false, because unbiasedness needs zero-mean errors and the right model form, not normality.
  4. Check. Count the true statements against the rules you know. Three are true, and the only false one depends on normality, which is needed for exact small-sample tests but not for unbiasedness.

Answer: (A), (B) and (C). Option (D) is wrong because unbiasedness does not require normal errors.

Exam-level 3: Variance inflation and the new standard error (NAT, 2 marks)

In a study of house prices, the input floor area is strongly related to the other inputs. When floor area is regressed on all the other inputs, the auxiliary R squared is 7/8. Without any collinearity, the standard error of the floor area coefficient would be 0.40 in the units of that coefficient. Find the variance inflation factor for floor area, then find the standard error that the collinearity actually produces. Give the new standard error to two decimal places. (NAT)

How to think about it

  1. What is asked. The new standard error, which needs the inflation factor first.
  2. Which idea applies. VIF equals 1 divided by (1 minus the auxiliary R squared). The standard error grows by the square root of the VIF.
  3. Work it out. 1 minus 7/8 is 1/8, so VIF = 1 divided by 1/8 = 8. The square root of 8 is about 2.828. Multiply: 0.40 times 2.828 = 1.131, which rounds to 1.13.
  4. Check. A VIF of 8 sits between the usual warning levels of 5 and 10, and the standard error still grows by almost three times. That matches the square root of 8 being about 2.8.

Answer: 1.13 (VIF = 8)

Exam-level 4: The overall F statistic (NAT, 2 marks)

A regression uses m = 25 observations and k = 4 inputs, plus an intercept. The total sum of squares is SST = 200 and the residual sum of squares is SSR = 50. The overall F statistic tests whether all the slope coefficients are zero. It is given by F = (R squared / k) divided by ((1 minus R squared) / (m minus k minus 1)). Find the value of F for this model. (NAT)

How to think about it

  1. What is asked. The F statistic only, from the given sums of squares.
  2. Which idea applies. First get R squared from SSR and SST. Then put R squared, k and the degrees of freedom into the F formula.
  3. Work it out. R squared = 1 minus 50/200 = 3/4. The numerator is (3/4)/4 = 3/16. The denominator is (1/4)/(25 minus 4 minus 1) = (1/4)/20 = 1/80. So F = (3/16) divided by (1/80) = 3 times 80/16 = 15.
  4. Check. The adjusted R squared is 1 minus (1/4) times 24/20 = 0.7, which is a sensible value close to R squared. The F value of 15 is well above the usual critical values for 4 and 20 degrees of freedom, so the inputs jointly matter.

Answer: F = 15

Summary

Here is every key term in one line each.

Multiple linear regression
A weighted sum of several inputs plus a constant and noise, used to predict one output.
Coefficient βj
How much the prediction changes for one unit of input j, with the other inputs held fixed.
Intercept β0
The prediction when every input is zero.
Design matrix X
A table with a column of 1s and one column per input, one row per data point.
Least squares
Choosing the coefficients that make the sum of squared residuals as small as possible.
Normal equations
XTXβ = XTy, the equations the best coefficients must satisfy.
Closed-form estimate
β = (XTX)-1XTy, valid when XTX is invertible.
Residual
The real output minus the predicted output for one point.
SST
Total spread of the outputs around their mean.
SSR
Spread of the residuals, what the model failed to explain.
R squared
1 minus SSR/SST, the share of spread explained on training data.
Adjusted R squared
R squared penalised for the number of inputs, which can fall when a useless input is added.
Multicollinearity
Inputs that carry nearly the same information, which makes coefficients unstable.
VIF
1/(1 minus Rj²), a warning score for multicollinearity.
Linearity
The assumption that the output is a straight-line function of the inputs.
Homoscedasticity
Errors have the same spread for every prediction.
Heteroscedasticity
Errors whose spread changes with the prediction, often seen as a funnel.
Gauss-Markov theorem
Under standard assumptions, least squares is the best linear unbiased estimator.

Remember these

  • The model is a weighted sum. Each coefficient is the effect of its input with the others held fixed.
  • Least squares minimises the sum of squared residuals, and the minimum satisfies XTXβ = XTy.
  • R squared = 1 minus SSR/SST. Plain R squared never falls when you add an input.
  • Adjusted R squared penalises extra inputs, so use it when comparing models with different numbers of inputs.
  • VIF = 1/(1 minus Rj²). A large VIF means multicollinearity.
  • Check linearity and homoscedasticity with residual plots. A funnel or a curve means trouble.
  • With an intercept, the residuals sum to zero.
