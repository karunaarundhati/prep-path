Path

Robot applications: point-to-point & continuous path control

A robot can move in two basic ways. Point-to-point (PTP) control cares only about where the robot starts and stops, while continuous path (CP) control makes the tool follow a precise line or curve. Knowing which one a job needs is a common GATE conceptual question.

The idea in plain words

Imagine two ways of getting from your desk to the door. In the first way, you only care that you start at the desk and end at the door. You can walk any route you like, as long as you arrive. In the second way, you must walk exactly along a straight painted line on the floor. You must not step off it.

The first way is like point-to-point (PTP) control. The robot is given a start point and an end point, and it moves between them by whatever route is easiest for its joints. The second way is like continuous path (CP) control. The robot is given many points along a line or curve, and it moves so that the tool stays on that path at the right speed.

Why does this matter? A pick-and-place robot that takes a box from a bin and drops it on a conveyor does not care about the route between the two. A robot that welds a seam along a car door must follow the seam exactly. The control method you choose decides how hard the controller works and how precise the path is.

Key ideaPTP cares about the points. CP cares about the path between the points.

Where this appears in GATE

In the RA paper, PTP and CP questions are usually conceptual. You may be asked which control suits a given application, which one needs more computation, or which one gives a predictable path. Some questions also ask for a short calculation, such as the time for a move or the number of segments needed to keep a path within a tolerance. This page covers both.

Key terms

Read these now. You will meet each one again below.

Point-to-point (PTP) control
Moving between a start and an end point without controlling the path between them. Precise definition: a motion mode in which only the target points are specified, and the controller moves the joints towards the target in a way it chooses.
Continuous path (CP) control
Moving the tool along a specified line or curve. Precise definition: a motion mode in which many points on the path are specified, and the controller keeps the tool on the path at a set speed.
Waypoint
A point the robot passes through or stops at. Precise definition: a stored position in the program, given as joint angles or as a position and orientation of the tool.
Trajectory
The full history of position, velocity, and time along a motion. Precise definition: a function that gives the position of the robot at every instant.
Joint space
A description of the robot by the angle of each joint. Precise definition: the space whose coordinates are the joint variables (for example θ1, θ2, θ3).
Cartesian space
A description of the tool by its x, y, and z position. Precise definition: the space of tool positions in the world frame, usually with orientation.
Joint interpolation
Moving each joint from its start to its end angle. Precise definition: a motion in joint space, where each joint moves in a smooth way from start to end, often used for PTP.
Linear interpolation
Moving the tool along a straight line in Cartesian space. Precise definition: a motion in which the tool position is a straight-line function of time.
Path deviation
How far the tool is from the ideal path. Precise definition: the distance from the actual tool position to the nearest point on the ideal path.
Chord error
The gap between a curve and a straight segment that approximates it. Precise definition: the distance from the middle of a straight chord to the arc it replaces, also called the sagitta.
Segment
One short straight piece of a path. Precise definition: a part of a path between two consecutive points used for approximation.
Servo control
A feedback loop that drives a joint to a commanded value. Precise definition: a controller that measures the joint position, compares it with the command, and adjusts the motor torque to remove the difference.
Teaching
Programming the robot by moving it by hand or with a pendant. Precise definition: recording waypoints or a path directly from the robot's own positions.
Interpolation
Filling in the points between given points. Precise definition: calculating intermediate positions along a path from known positions, usually at a fixed time step.

Point-to-point (PTP) control

In PTP control, the programmer gives a list of target points. The controller moves the robot to each point in turn, and the robot stops at each point before it moves on. What happens between the points is not specified. The robot may curve through the air, swing wide, or take the shortest joint route. The important thing is that it arrives at each target.

How PTP moves the joints

Most PTP moves are joint interpolation. Each joint starts moving at the same time and moves to its own target angle. Joints that have a long way to go take longer. The move is finished when the slowest joint arrives. The tool path in Cartesian space is therefore curved, even though the joint motion is smooth.

Here is a simple text diagram of a PTP move in a plane. Two points are shown, A and B. The tool does not follow a straight line, so the path between A and B is only what the joints happen to produce.

        B *
           \
            \      joint-driven path (curved)
             \
              \__
                 \__
                    \__
  A *                  \_

The picture shows a curve from A to B. The curve depends on the robot and the speeds of the joints. It is not a straight line, and the programmer does not control its exact shape.

Time for a PTP move

Suppose each joint moves at its own constant maximum speed. Joint i with angle change |Δθi| and speed ωi takes this long:

ti = |Δθi| / ωi

The whole PTP move takes the longest of these times, because all joints start together and the move ends when the slowest joint arrives:

tmove = max(t1, t2, t3)

Here the joint angles are in degrees and the speeds are in degrees per second. The next example uses three joints.

Worked example. Joint 1 must turn 120 degrees at 60 degrees per second. Joint 2 must turn 45 degrees at 90 degrees per second. Joint 3 must turn 30 degrees at 30 degrees per second.

  1. Joint 1 time. 120 / 60 = 2.0 s.
  2. Joint 2 time. 45 / 90 = 0.5 s.
  3. Joint 3 time. 30 / 30 = 1.0 s.
  4. Move time. The slowest joint is joint 1, so the PTP move takes 2.0 s. Joints 2 and 3 wait at their targets.
joint_moves = [120.0, 45.0, 30.0]
joint_speeds = [60.0, 90.0, 30.0]
times = [abs(d) / v for d, v in zip(joint_moves, joint_speeds)]
for i, t in enumerate(times, 1):
    print("Joint", i, "time (s):", round(t, 2))
print("Point-to-point move time (s):", round(max(times), 2))
Joint 1 time (s): 2.0
Joint 2 time (s): 0.5
Joint 3 time (s): 1.0
Point-to-point move time (s): 2.0

TrapThe move time is the maximum of the joint times, not the sum. Students often add them. The joints move at the same time, so you add nothing.

TipPTP is cheap to program and fast to compute, because the controller only needs the target joint angles. That is one reason pick-and-place robots use it.

Question: In PTP, which points must the robot reach exactly?

The programmed target points (waypoints). The path between them is not controlled.

Question: Why is the PTP path between two points usually curved in Cartesian space?

Each joint moves in joint space to its own target. The tool position is a nonlinear function of the joint angles, so a smooth joint motion gives a curved Cartesian path.

Continuous path (CP) control

In CP control, the tool must follow a specified path closely while it moves. Examples are a welding torch that follows a seam, a paint nozzle that follows a car body, or a cutting head that follows a drawn outline. The path is given as a set of points, and the controller fills in the gaps with very small steps.

The idea is called interpolation. Between two given points, the controller calculates many intermediate points, one for each small time step. Each step is a short segment of the path. The controller then moves the joints so that the tool passes through each step at the right time and speed.

Straight-line motion and speed

For a straight line in Cartesian space, the tool moves at a constant speed along the line. The distance from A to B is found with Pythagoras, and the time is distance divided by speed:

L = √(dx² + dy²) t = L / v

Here dx and dy are the differences along each axis, L is the path length in mm, v is the speed in mm/s, and t is the time in seconds.

Worked example. The tool moves from A to B where dx = 120 mm and dy = 160 mm. The required speed is 50 mm/s.

  1. Path length. L = √(120² + 160²) = √(14 400 + 25 600) = √40 000 = 200 mm.
  2. Time. t = 200 / 50 = 4.0 s.
  3. Check. In 4 seconds at 50 mm/s the tool covers 200 mm, which is the path length. The numbers agree.
import math
dx = 120.0
dy = 160.0
speed = 50.0
length = math.sqrt(dx**2 + dy**2)
time = length / speed
print("Path length (mm):", round(length, 2))
print("Time at 50 mm/s (s):", round(time, 2))
Path length (mm): 200.0
Time at 50 mm/s (s): 4.0

Key ideaIn CP, the controller must move several joints together so that the tool stays on the line. Each joint speed is scaled so that all joints arrive at the same time. This is called coordinated motion.

Why CP is harder

CP asks more of the controller. It must:

  • calculate the joint positions many times a second (inverse kinematics at each step);
  • keep several joints synchronised, so the tool does not drift off the line;
  • tune the servo loops tightly, so that the joints follow their commands closely during fast changes in direction;
  • control the speed along the path, which may need slowing at corners.

Because of these demands, CP controllers cost more and need more computing power than PTP controllers. They also need a more accurate robot, because a small joint error becomes a visible error on the path.

GATE loves thisWhen a question asks which mode needs more computation, the answer is CP. When it asks which mode gives control of the path, the answer is also CP. PTP only controls the endpoints.

Question: A robot must weld along a curved seam. Should the robot use PTP or CP?

CP. The weld must follow the seam, so the path between points must be controlled.

Question: Why do the joints need to be coordinated in CP but not in PTP?

In CP the tool must stay on a straight or curved line, so the joints must move together in a precise ratio. In PTP the path between points does not matter, so each joint can move on its own schedule.

Joint space and Cartesian space

PTP and CP can be described in two different spaces. This is a small idea with a big effect on the path.

In joint space, the robot is described by its joint angles. A 3-joint arm is a point (θ1, θ2, θ3). In Cartesian space, the robot is described by where the tool is, a point (x, y, z), and often its orientation.

The two descriptions are linked by the robot's kinematics. Going from joint angles to tool position is called forward kinematics. Going from a tool position to joint angles is called inverse kinematics. CP usually works in Cartesian space and uses inverse kinematics at each step. PTP often works in joint space, which avoids inverse kinematics for each move.

FeatureJoint interpolation (usual for PTP)Linear or circular interpolation (usual for CP)
Space used to plan the moveJoint spaceCartesian space
Shape of the tool pathCurved, not controlledStraight line or arc, controlled
Inverse kinematics at each stepNot needed in real timeNeeded at each step
Controller effortLowHigh

TrapA PTP move that is linear in joint space is not linear in Cartesian space. If a question says "straight line", check whether it means the tool path or the joint motion.

Question: Which space is used to describe the tool's x, y, and z position?

Cartesian space.

Question: What does inverse kinematics compute?

The joint angles needed to place the tool at a given position and orientation.

Choosing PTP or CP for an application

Choosing the control mode is a question about the job. Ask two questions: "does the path matter?" and "does the tool have to stay on a line?" If the answer to both is no, PTP is usually the choice. If either answer is yes, CP is needed.

ApplicationDoes the path matter?Usual mode
Pick a part from a bin and place it on a conveyorNo, only the start and end matterPTP
Spot welding of car body panelsNo, only the spot positions matterPTP
Machine tending (loading a press)No, only the load and unload points matterPTP
Arc welding along a seamYes, the torch must follow the seamCP
Painting a car bodyYes, the spray must follow the surfaceCP
Dispensing glue along a beadYes, the bead must be on the lineCP
Deburring a machined edgeYes, the tool must follow the edgeCP

TipSpot welding looks like a path, but only the spot positions matter, because the tool does not weld between the spots. That is why it is PTP.

Question: Why is PTP used for pick-and-place?

The path between the bin and the conveyor does not matter, only the two points. PTP is simpler and faster to program.

Question: Why might a company choose PTP even for a job that could be done with CP?

PTP is cheaper, needs less computing power, and is easier to program. If the path does not matter for the job, the extra cost of CP is wasted.

Path accuracy and chord error

Many CP controllers do not follow a true curve. They follow short straight segments that approximate the curve. This works well if the segments are short enough. The error that comes from replacing a curve by straight segments is called the chord error.

Picture an arc of a circle. Draw a straight line (a chord) between two points on the arc. The chord lies inside the circle, and its middle is a little away from the arc. That gap is the chord error, also called the sagitta. Here is a text picture.

        ____
      /        \          arc (true path)
     /          \
    /      .      \       chord error: gap from the middle
   ------------------     chord (straight segment)

For a circle of radius R, a segment that turns through an angle θ has a chord error of:

e = R × (1 − cos(θ / 2))

Here R is the radius in mm, θ is the angle of the segment in radians, and cos is the cosine. A smaller segment angle gives a smaller error.

Worked example. A circle has radius 100 mm. The controller uses segments that each turn through 10 degrees. Find the chord error.

  1. Convert the angle. θ = 10 degrees. The half angle is θ / 2 = 5 degrees.
  2. Find the cosine. cos(5°) = 0.99619 (about).
  3. Apply the formula. e = 100 × (1 − 0.99619) = 100 × 0.00381 = 0.38 mm.
  4. Check. The error is small compared with the radius, which is what we expect for a small angle.
import math
R = 100.0
seg_deg = 10.0
half = math.radians(seg_deg / 2)
print("Chord error at 10 deg (mm):", round(R * (1 - math.cos(half)), 2))
Chord error at 10 deg (mm): 0.38

Key ideaTo keep the chord error below a tolerance, the segment angle must be small. Smaller segments mean more points, more computing, and a slower program.

TrapUse the half angle in the formula. Many students put the full segment angle in the cosine, which gives a wrong and much larger error.

Question: A segment turns through 0 degrees. What is the chord error?

Zero. A segment that does not turn is a straight line, so it has no error. The formula gives R × (1 − cos 0) = R × 0 = 0.

Question: Why does a bigger radius give a bigger chord error for the same segment angle?

The chord error is R times a number that depends only on the angle. A bigger R multiplies that number by more, so the error grows.

Solved GATE-style problems

These are original GATE-style practice problems, not real past exam questions. Try each one before reading the method.

Which mode for arc welding?

A robot must weld along a straight seam on a steel frame. The torch must stay on the seam. Which control mode is needed?

(A) PTP   (B) CP   (C) Joint space only   (D) Neither, the robot does not need control

How to think about it

  1. What is asked. The control mode for a seam weld.
  2. Which idea applies. If the path between points matters, the mode must be CP.
  3. Work it out. The torch must stay on the seam, so the path matters. That is CP. Option (C) is a space, not a mode. Option (D) is wrong because the path must be controlled.
  4. Check. A seam weld is a classic CP job.

Answer: (B) CP.

Which mode for which job?

Two jobs are compared. Job X moves a part from a tray to a fixture, and only the two points matter. Job Y moves a sealant nozzle along a curved edge. Which statement is correct?

(A) Job X needs CP and job Y needs PTP.   (B) Job X needs PTP and job Y needs CP.   (C) Both need PTP.   (D) Both need CP.

How to think about it

  1. What is asked. Which pairing of modes is correct.
  2. Which idea applies. Only endpoints matter gives PTP. A path that must be followed gives CP.
  3. Work it out. Job X: only endpoints, so PTP. Job Y: a curved edge that must be followed, so CP.
  4. Check. Option (B) matches both jobs.

Answer: (B).

Move time for a three-joint PTP motion

A PTP move changes three joints. Joint 1 turns 120 degrees at 60 degrees per second. Joint 2 turns 45 degrees at 30 degrees per second. Joint 3 turns 30 degrees at 40 degrees per second. Find the time for the whole move in seconds, to two decimal places.

How to think about it

  1. What is asked. The total move time, in seconds.
  2. Which idea applies. Each joint time is |Δθ| / ω. The move time is the largest.
  3. Work it out. Joint 1: 120 / 60 = 2.00 s. Joint 2: 45 / 30 = 1.50 s. Joint 3: 30 / 40 = 0.75 s. The largest is 2.00 s.
  4. Check. Joint 1 is the slowest, so it sets the time. Joint 2 would finish earlier at 1.50 s and wait.

Answer: 2.00 s.

Which statements are true? (select all that apply)

Select all the statements that are correct about PTP and CP.

(A) PTP controls the path between the points.   (B) CP needs inverse kinematics many times per second.   (C) PTP is usual for spot welding.   (D) In CP, the joints must be coordinated.

How to think about it

  1. What is asked. Which statements are true.
  2. Which idea applies. PTP ignores the path. CP needs inverse kinematics at each step and joint coordination.
  3. Work it out. (A) False, PTP does not control the path. (B) True. (C) True, only the spot positions matter. (D) True, the tool must stay on a line.
  4. Check. Statement (A) reverses the definition, which is the trap.

Answer: (B), (C) and (D).

Time to draw a straight line

A tool moves in a straight line in a plane with dx = 90 mm and dy = 120 mm, at a constant speed of 30 mm/s. Find the time in seconds.

How to think about it

  1. What is asked. The time t in seconds.
  2. Which idea applies. L = √(dx² + dy²), then t = L / v.
  3. Work it out. L = √(8100 + 14400) = √22500 = 150 mm. t = 150 / 30 = 5 s.
  4. Check. 90, 120, 150 is a scaled 3-4-5 triangle (multiply by 30), so L = 150 is right.

Answer: 5 s.

Segments for a circle (numerical answer)

A circle of radius 100 mm must be drawn by straight segments. The chord error must not exceed 0.1 mm. Find the largest segment angle, in degrees to three decimal places, and the smallest whole number of segments needed to draw the full circle.

How to think about it

  1. What is asked. The largest segment angle θ and the number of segments N.
  2. Which idea applies. e = R × (1 − cos(θ/2)). Set e = 0.1 and solve for θ/2 with the inverse cosine.
  3. Work it out. 1 − cos(θ/2) = 0.1 / 100 = 0.001, so cos(θ/2) = 0.999. Then θ/2 = arccos(0.999) = 0.044721 rad, so θ = 0.089443 rad = 5.125 degrees. N = 360 / 5.125 = 70.24, which rounds up to 71.
  4. Check. 71 segments of 5.125 degrees give 71 × 5.125 = 363.9 degrees, which is more than 360. That is correct, because we rounded up. The segment angle with 70 segments would be 5.143 degrees, which is too big for the tolerance.
import math
R = 100.0
tol = 0.1
half = math.acos(1 - tol / R)
seg = math.degrees(2 * half)
print("Max segment angle (deg):", round(seg, 3))
print("Segments needed:", math.ceil(360 / seg))
Max segment angle (deg): 5.125
Segments needed: 71

Answer: θ = 5.125 degrees, and 71 segments.

What makes CP harder? (select all that apply)

A company moves from PTP to CP for a sealing job. Which of the following are true reasons why the controller must do more work? Select all that apply.

(A) The tool must stay on the path, so joints must be coordinated.   (B) Only the endpoints of each move are stored.   (C) The controller must compute joint angles many times a second.   (D) Speed along the path may need changing at corners.

How to think about it

  1. What is asked. Which reasons are correct.
  2. Which idea applies. CP needs path control, coordination, and real-time inverse kinematics.
  3. Work it out. (A) True. (B) False, CP stores many path points, not only endpoints. (C) True. (D) True.
  4. Check. Option (B) describes PTP, not CP, so it is the one to reject.

Answer: (A), (C) and (D).

Chord error for a larger radius

A circle of radius 200 mm is drawn with segments that each turn through 6 degrees. Find the chord error in mm, to two decimal places.

How to think about it

  1. What is asked. The chord error e.
  2. Which idea applies. e = R × (1 − cos(θ/2)) with θ/2 = 3 degrees.
  3. Work it out. cos(3°) = 0.998630. 1 − 0.998630 = 0.001370. e = 200 × 0.001370 = 0.274 mm, which rounds to 0.27 mm.
  4. Check. Doubling the radius to 200 mm roughly doubles the 100 mm error at the same angle, and the error at 6 degrees is smaller than at 10 degrees, which is the expected trend.
import math
R = 200.0
seg_deg = 6.0
half = math.radians(seg_deg / 2)
sagitta = R * (1 - math.cos(half))
print("Chord error (mm):", round(sagitta, 2))
Chord error (mm): 0.27

Answer: about 0.27 mm.

Exam-level practice

Exam-level 1: Trapezoidal motion time (NAT, 2 marks)

A joint must turn 90° with maximum speed 60°/s and acceleration 120°/s². Using a trapezoidal velocity profile, find the move time.

How to think about it

  1. What is asked. Total time.
  2. Which idea applies. Accelerate time ta = v/a. Distance in each ramp is v²/(2a).
  3. Work it out. ta = 0.5 s, ramp distance 15° each. Cruise 60° at 60°/s = 1 s. Total 2 s.
  4. Check. The code integrates the profile.
v, a, D = 60, 120, 90
ta = v / a; dc = D - v * v / a
print(2 * ta + dc / v, "s")

2.0 s

Answer: 2 s.

Exam-level 2: Cubic trajectory (NAT, 2 marks)

A cubic θ(t) = a0 + a1t + a2t² + a3t³ moves from 0 to 90° in 3 s with zero start and end velocity. Find the peak velocity in °/s.

How to think about it

  1. What is asked. Maximum of θ′.
  2. Which idea applies. a2 = 3Δθ/T², a3 = −2Δθ/T³. Peak at T/2.
  3. Work it out. a2 = 30, a3 = −20/3. θ′(1.5) = 2 · 30 · 1.5 + 3(−20/3)(2.25) = 90 − 45 = 45°/s.
  4. Check. Peak velocity = 1.5Δθ/T = 45.

Answer: 45°/s.

Exam-level 3: PTP versus CP (MSQ, 2 marks)

Which are TRUE? (A) Spot welding is a point to point task. (B) Spray painting needs continuous path control. (C) Arc welding is point to point. (D) In PTP control the path between points is not tightly controlled.

How to think about it

  1. What is asked. Classify tasks.
  2. Which idea applies. CP control keeps the tool on a path the whole time.
  3. Work it out. (A) True. (B) True. (C) Arc welding follows a seam: CP. False. (D) True.
  4. Check. Pick and place is another PTP task.

Answer: (A), (B) and (D).

Summary

Point-to-point (PTP)
Control that cares only about the start and end points of each move.
Continuous path (CP)
Control that makes the tool follow a specified line or curve.
Waypoint
A stored point the robot moves to or through.
Trajectory
The position of the robot as a function of time along a motion.
Joint space
A description of the robot by its joint angles.
Cartesian space
A description of the tool by its x, y, and z position.
Joint interpolation
Moving each joint from start to end angle, usually for PTP.
Linear interpolation
Moving the tool along a straight line at a set speed.
Interpolation
Calculating intermediate points between given points.
Path deviation
The distance from the actual tool position to the ideal path.
Chord error
The gap between an arc and the straight chord that replaces it, also called the sagitta.
Segment
One short straight piece of a path.
Servo control
A feedback loop that drives a joint to its commanded value.
Inverse kinematics
Calculating joint angles from a desired tool position.
Forward kinematics
Calculating the tool position from joint angles.
Coordinated motion
Moving several joints together so that the tool follows the path.

Remember these

  1. PTP controls the points. CP controls the path between the points.
  2. The PTP move time is the largest joint time, not the sum.
  3. Pick-and-place and spot welding use PTP. Seam welding, painting, and deburring use CP.
  4. CP needs more computation, tighter servo control, and joint coordination.
  5. Chord error is e = R × (1 − cos(θ/2)), and the half angle is the one to use.
  6. Smaller segments give smaller chord error, but more points.
