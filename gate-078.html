Flowcharts & pseudocode (recap)

A flowchart is a picture of an algorithm, and pseudocode is the same algorithm written as plain, structured lines. Both help you plan a solution before you write real code. This quick recap covers the standard flowchart symbols, the usual pseudocode keywords, how to turn a problem into a flowchart, and how to translate between a flowchart, pseudocode and Python.

The idea in plain words

Before you cook a new recipe, you read the steps and check that they make sense. A flowchart does the same job for a program. It draws each step as a shape and connects the shapes with arrows, so you can follow the path from start to finish. Pseudocode is the written version: short lines in plain English, with a few keywords, that describe the steps without the strict rules of a real language.

GATE questions in this area ask you to read a flowchart or pseudocode, trace it with values, and say what it prints or computes. They also sometimes ask which code matches a flowchart. The skill is careful, step-by-step tracing with a table.

Key ideaEvery flowchart can be written as pseudocode, and every pseudocode can be written as a flowchart. Only the picture and the words differ. The steps and their order stay the same.

Key terms

Flowchart
A diagram of an algorithm made of symbols joined by arrows. Precisely: a directed graph of steps, with one start and at least one end.
Flow line
An arrow that shows the order of steps. Precisely: it shows which step comes next.
Pseudocode
Structured plain-language lines describing an algorithm. Precisely: it follows the same logic as a program but is not tied to one language.
Variable
A named box that holds a value. Precisely: a name bound to a value that can change over time.
Assignment
Storing a value in a variable. Precisely: x ← x + 1 (or x = x + 1 in Python) computes the right side, then stores it in x.
Condition
A test that gives true or false. Precisely: a relational expression such as x > 5.
Loop
A part of the algorithm repeated while a condition holds. Precisely: a WHILE loop tests first, a REPEAT loop tests last.
Trace table
A table with one column per variable and one row per step. Precisely: it records each value as the algorithm runs.
Off-by-one error
A loop that runs one time too many or too few. Precisely: a mistake in the start, stop or test value.

Flowchart symbols and flow lines

Each shape has one job. Learn these five, and you can read almost every flowchart in GATE.

SymbolNameWhat it means
Rounded ends (oval or pill)TerminalStart or end of the algorithm. Every flowchart has one start.
ParallelogramInput or outputREAD a value from the user, or PRINT a value.
RectangleProcessA calculation or assignment, such as total = total + i.
DiamondDecisionA yes or no question. It has two exits, labelled Yes and No (or True and False).
ArrowFlow lineShows the order of steps. Read the chart by following the arrows.

A decision diamond is the only shape with two exits. A process box has one exit. A loop appears when a flow line returns to an earlier shape, so the chart goes around again.

TrapStudents often forget that a loop is just an arrow that goes back. If you do not trace the back arrow, you will stop too early or never stop.

Which symbol checks a condition?

The diamond (decision). It has a yes exit and a no exit.

Which symbol reads a value from the user?

The parallelogram (input or output), labelled READ or INPUT.

Pseudocode conventions

Pseudocode is easy to read because it uses a small set of keywords. You will see these in GATE questions, with small differences in style, so learn the idea rather than the exact spelling.

  • Assignment: x ← 5 means store 5 in x. Some books write x = 5 or x := 5.
  • Input and output: READ n, PRINT total.
  • Decision: IF condition THEN ... ELSE ... ENDIF.
  • WHILE loop: WHILE condition DO ... ENDWHILE. The test happens before each pass, so the body may run zero times.
  • FOR loop: FOR i ← 1 TO n DO ... ENDFOR. It runs for i = 1, 2, ..., n.
  • REPEAT loop: REPEAT ... UNTIL condition. The test happens after each pass, so the body runs at least once.

Here is a short pseudocode example that adds up the numbers from 1 to n:

READ n
total ← 0
i ← 1
WHILE i <= n DO
    total ← total + i
    i ← i + 1
ENDWHILE
PRINT total

TipWhen the pseudocode uses ←, read it as "becomes". The right side is worked out first, then the answer is stored in the left-hand name. So total ← total + i means "the new total is the old total plus i".

Does a WHILE loop always run its body at least once?

No. The condition is tested first. If it is false at the start, the body never runs. A REPEAT loop always runs at least once.

What does i ← i + 1 do?

It increases i by 1. The old value of i is used on the right, and the result is stored back in i.

From a problem to a flowchart, and then to code

To draw a flowchart for a problem, follow four steps. First, write down the inputs and the output. Second, choose the variables you need, and give each one a starting value. Third, decide what must repeat, and write the loop test. Fourth, check the result with a small example before you trust the chart.

Example: add up the numbers from 1 to n. Here is the chart as text:

        (  START  )
            |
        [ READ n ]
            |
        [ total = 0, i = 1 ]
            |
        < i <= n ? >---- no ----+
            | yes                    |
        [ total = total + i ]        |
            |                        |
        [ i = i + 1 ]                |
            |                        |
            +---- back to test       |
                                     |
        [ PRINT total ]  <----------+
            |
        (   END   )

The diamond with the condition i <= n has a yes exit that goes into the loop body, and a no exit that leaves the loop. The arrow from the end of the body goes back to the diamond. That back arrow is what makes it a loop.

Now translate the chart to Python. Each rectangle becomes one line, each diamond becomes an if or while, and each back arrow becomes the end of the loop body.

n = 5
total = 0
i = 1
while i <= n:
    total = total + i
    i = i + 1
print(total)
15

Trace table for n = 5. Each row is one check of the diamond, and the values are the values after the check and the body.

The loop body ran five times, and the sixth check exits. The printed value is 15, which is 1 + 2 + 3 + 4 + 5.

How many times does the body run if n = 0 in this chart?

Zero times. The test i <= 0 is false on the first check, so the no exit is taken immediately and total stays 0.

Why is the test written i <= n and not i < n?

To include n in the sum. With i < n the loop would stop before adding n, which is an off-by-one error.

From code back to a flowchart, and common traps

Reading code and drawing its chart is the same skill in reverse. Find each decision, each loop test, and each assignment. Then draw one symbol for each.

Take this problem: find the largest of three numbers. The code has an if, an elif and an else. In a chart, that becomes two diamonds in a row. The first diamond asks whether a is the largest, and the second asks whether b is bigger than c. If both answers are no, c is the largest.

a, b, c = 4, 9, 6
if a >= b and a >= c:
    m = a
elif b >= c:
    m = b
else:
    m = c
print("max is", m)
max is 9

A FOR loop in pseudocode maps to Python's range. Remember that range(1, 5) stops before 5, so it gives 1, 2, 3 and 4. This is a common off-by-one trap.

for i in range(1, 5):
    print(i * i)
1
4
9
16

TrapIn pseudocode, one = usually means assignment, while == (or the word equals) tests equality. In Python, x = 5 is assignment and x == 5 is a test. Writing if x = 5 in Python is a syntax error, so read every condition carefully.

What does range(0, 3) produce?

0, 1 and 2. The stop value 3 is excluded.

In the max-of-three chart, what happens if a is equal to b and both are the largest?

The first test a >= b is true, so a is chosen. The equal case is handled because the test uses >= and not >.

Solved GATE-style problems

These problems are original GATE-style questions written for practice. They are not past exam questions. Build a trace table for every loop.

Sum of squares in pseudocode

Trace this pseudocode and find the final value of s.

i ← 1
s ← 0
WHILE i <= 4 DO
    s ← s + i * i
    i ← i + 1
ENDWHILE

How to think about it

  1. What is asked. The final value of s.
  2. Which idea applies. A WHILE loop repeats while the test is true. Each pass adds i * i to s.
  3. Work it out. i = 1: s = 0 + 1 = 1. i = 2: s = 1 + 4 = 5. i = 3: s = 5 + 9 = 14. i = 4: s = 14 + 16 = 30. Then i = 5, and the test 5 <= 4 is false.
  4. Check. The sum 1 + 4 + 9 + 16 is 30, and the code below confirms it.

Answer: s = 30.

print(sum(i * i for i in range(1, 5)))
30

Flowchart symbols

Select all that apply. Which statements about standard flowchart symbols are true?

  • (A) A diamond is a decision.
  • (B) A parallelogram is a process.
  • (C) A rectangle is a process.
  • (D) An oval marks the start or end.
  • (E) An arrow shows the order of steps.

How to think about it

  1. What is asked. Which symbol meanings are correct.
  2. Which idea applies. Use the symbol table in this page.
  3. Work it out. (A) True. (B) False, a parallelogram is input or output. (C) True. (D) True. (E) True.
  4. Check. Compare each option with the table: the only wrong one is the parallelogram.

Answer: (A), (C), (D) and (E).

Odd or even, then halve

What does this program print?

x = 7
if x % 2 == 0:
    print("even")
else:
    print("odd")
print(x // 2)

How to think about it

  1. What is asked. The printed lines.
  2. Which idea applies. The diamond sends the flow down the yes or no branch. % gives the remainder and // gives the whole part of a division.
  3. Work it out. 7 % 2 is 1, which is not 0, so the else branch prints "odd". Then 7 // 2 is 3, since 2 goes into 7 three times.
  4. Check. Odd numbers leave remainder 1 when divided by 2, so "odd" is right.

Answer: "odd", then 3.

x = 7

    print("even")
else:
    print("odd")

Count the multiples of 3

Trace the program. It starts at 12 and counts down to 1, adding 1 to count each time n is a multiple of 3. What is the final value of count?

n = 12
count = 0
while n > 0:
    if n % 3 == 0:
        count = count + 1
    n = n - 1
print(count)

How to think about it

  1. What is asked. The final count.
  2. Which idea applies. The loop visits every value from 12 down to 1. The decision adds 1 only when n % 3 is 0.
  3. Work it out. The values that are multiples of 3 between 1 and 12 are 3, 6, 9 and 12. Each one adds 1, so count becomes 4.
  4. Check. There are 12 // 3 = 4 multiples of 3 up to 12, which agrees.

Answer: 4.

n = 12
count = 0
while n > 0:
    if n % 3 == 0:
        count = count + 1
    n = n - 1
print(count)
4

Sum of even numbers

What does this program print?

total = 0
for i in range(1, 11):
    if i % 2 == 0:
        total = total + i
print(total)

How to think about it

  1. What is asked. The printed total.
  2. Which idea applies. range(1, 11) gives 1 to 10. The decision adds only even values.
  3. Work it out. The even numbers from 1 to 10 are 2, 4, 6, 8 and 10. Their sum is 2 + 4 + 6 + 8 + 10 = 30.
  4. Check. range(1, 11) includes 10 but not 11, so the last value is 10, which is correct.

Answer: 30.

total = 0
for i in range(1, 11):
    if i % 2 == 0:
        total = total + i

Greatest common divisor by subtraction

The flowchart below repeats until a equals b. Trace it with a = 12 and b = 18. What are the final values of a and the number of passes through the loop?

a ← 12, b ← 18, steps ← 0
WHILE a != b DO
    IF a > b THEN
        a ← a - b
    ELSE
        b ← b - a
    ENDIF
    steps ← steps + 1
ENDWHILE
PRINT a

How to think about it

  1. What is asked. The printed value of a, and how many passes the loop makes.
  2. Which idea applies. Trace each pass with a trace table. The decision subtracts the smaller number from the bigger one.
  3. Work it out. Pass 1: a = 12, b = 18. a is not greater than b, so b becomes 18 - 12 = 6. steps = 1. Pass 2: a = 12, b = 6. a is greater, so a becomes 12 - 6 = 6. steps = 2. Now a = 6 and b = 6, so the test a != b is false and the loop stops.
  4. Check. The answer 6 is the greatest common divisor of 12 and 18, and the code below uses the standard library to confirm it.

Answer: a is 6, and the loop makes 2 passes.

a, b = 12, 18
steps = 0
while a != b:
    if a > b:
        a = a - b
    else:
        b = b - a
    steps = steps + 1
print(a, steps)
6 2
import math
print(math.gcd(12, 18))
6

Which flowchart statements are true?

Select all that apply.

  • (A) In a standard flowchart, a decision diamond has two exits, labelled yes and no.
  • (B) A WHILE loop tests its condition after the body has run.
  • (C) In Python, x == 5 tests equality, while x = 5 stores the value 5 in x.
  • (D) range(1, n) includes n.
  • (E) A process box may have two exits in a standard flowchart.

How to think about it

  1. What is asked. Which claims about flowcharts, loops and Python tests are true.
  2. Which idea applies. Diamonds decide. WHILE tests first, REPEAT tests last. range excludes its stop value. A process box has one exit.
  3. Work it out. (A) True. (B) False, that is REPEAT. (C) True, == compares and = assigns. (D) False. (E) False.
  4. Check. Trace the range claim: range(1, 4) gives 1, 2, 3, not 4.

Answer: (A) and (C).

Exam-level practice

Exam-level 1: Tracing a loop flowchart (NAT, 2 marks)

Pseudocode: s ← 0; i ← 1; while i ≤ 20: if i mod 3 = 0 then s ← s + i; i ← i + 2. Find s.

How to think about it

  1. What is asked. The sum of selected odd numbers.
  2. Which idea applies. i takes odd values 1, 3, ..., 19. Only multiples of 3 are added.
  3. Work it out. Odd multiples of 3 up to 19: 3, 9, 15. Sum 27.
  4. Check. The code runs the loop.
s, i = 0, 1
while i <= 20:
    if i % 3 == 0: s += i
    i += 2
print(s)

27

Answer: 27.

Exam-level 2: Decision count (NAT, 1 mark)

A flowchart finds the largest of n numbers by comparing each new number with the current maximum. How many decision boxes are executed for n = 25?

How to think about it

  1. What is asked. The number of comparisons.
  2. Which idea applies. Every number after the first needs one comparison.
  3. Work it out. 25 − 1 = 24.
  4. Check. No method can do better, since every non-maximum must lose at least once.

Answer: 24.

Exam-level 3: Nested loop count (NAT, 2 marks)

for i ← 1 to 10: for j ← i to 10: count ← count + 1. Starting from count = 0, find count.

How to think about it

  1. What is asked. The number of inner iterations.
  2. Which idea applies. For each i, the inner loop runs 11 − i times.
  3. Work it out. Σ (11 − i) for i = 1..10 = 10 + 9 + ... + 1 = 55.
  4. Check. That is the number of pairs i ≤ j from 1 to 10.

Answer: 55.

Summary

Flowchart
A diagram of steps joined by arrows.
Oval
Start or end of the algorithm.
Parallelogram
Input or output.
Rectangle
A process, such as an assignment or calculation.
Diamond
A decision with yes and no exits.
Flow line
An arrow showing the next step.
Pseudocode
Structured plain-language steps with keywords such as IF, WHILE and FOR.
Assignment
Store the value of an expression in a variable.
WHILE loop
Tests first. The body may run zero times.
REPEAT loop
Tests last. The body runs at least once.
Trace table
A record of variable values, one row per step.
Off-by-one error
A loop that runs one time too many or too few.
range(a, b)
Gives a, a + 1, ..., b - 1. The stop value b is excluded.

Remember these

  1. Only the diamond has two exits. A process box has one.
  2. A loop is an arrow that goes back to an earlier step.
  3. Use a trace table for every loop, and write down each value.
  4. The right side of an assignment is worked out first.
  5. range and loop tests have end values that are easy to get wrong by one.
