Python basics: syntax, data types, control flow

Python is a readable programming language, and short Python snippets that you must read and predict are a common style of question in the Data Science and AI paper. This page builds the basics from zero: values, types, operators, decisions, loops, and the habit of tracing code one line at a time.

The idea in plain words

Imagine a row of labelled boxes. Each box holds one thing, and the label on the box tells you how to find it. In Python, a variable is exactly that: a label that points to a value. When you write age = 21, you are saying "put the value 21 in a box, and call the box age". Later you can ask for age, and Python gives you 21.

A program is a list of instructions. Python reads them from the top of the file to the bottom, one line at a time. It does not skip ahead. This simple rule is the key to almost every Python question in GATE. If you can follow the lines in order and keep track of what each label holds, you can predict what the program prints.

Python programs are built from four ingredients:

  • Values and types: numbers, text, true/false values, and groups of values.
  • Operators: symbols such as +, == and and that combine values.
  • Decisions: "if this is true, do that, otherwise do something else".
  • Loops: "do this again and again until a rule says stop".

Every topic on this page is one of these ingredients. Learn them in this order, and each new piece will have a place to fit.

Why this matters for GATE. Questions in the Data Science and AI paper often show a short code snippet and ask "what is printed?" or "what is the final value of this variable?". These questions test whether you can read code carefully. They do not need any special knowledge. They reward patience and a neat table where you write down every change.

Variables and data types

Why types matter

Every value in Python has a type. The type decides what you can do with the value. You can add two numbers, but adding a number to a piece of text needs a conversion first. Python tells you the type with the built-in function type().

You do not declare types in advance. Python works out the type from the value you assign. This is called dynamic typing.

The four basic types

  • int stands for integer. Example: age = 21.
  • float stands for floating point number. Example: height = 1.75. A float is the type you get from a decimal point.
  • str stands for string. Example: name = "Asha". Quotes make it text, even when the text looks like a number. "21" is a string, not an int.
  • bool stands for Boolean. Only two values exist: True and False.

TrapPython treats True as 1 and False as 0 when you do arithmetic. So True + 1 is 2. This is legal Python, and exam questions use it on purpose.

Changing a label

Assignment does not change a value. It only moves a label. Look at this step by step:

  1. x = 5. The label x now points to the value 5.
  2. x = x + 1. Python first works out the right side: x + 1 uses the current value of x, which is 5, so the result is 6. Then it moves the label x to point to 6.
  3. Now x is 6. The old value 5 is no longer used.

The line x = x + 1 looks odd in mathematics, because no number equals itself plus one. In Python it is perfectly normal. Always read the right side first.

Key ideaIn an assignment, Python evaluates the right side completely first, then stores the result in the left side. Read count = count + 1 as "take the old count, add 1, and call the result the new count".

If x = 4 and then x = x * x, what is x?

The right side is 4 * 4, which is 16. So x is 16.

What does type("7") give?

It gives <class 'str'>. The quotes make 7 a piece of text, not a number.

Collections: list, tuple, set, dict

Why we need groups of values

Suppose you have the marks of 30 students. Making 30 separate variables would be silly. A collection stores many values in one object. Python has four main collections, and they differ in three ways: whether they keep order, whether they allow repeats, and whether you can change them.

Lists and indexes

A list is like a row of numbered seats. The first seat is number 0, not 1. This number is the index. So in nums = [10, 20, 30], nums[0] is 10, nums[1] is 20, and nums[2] is 30. The index -1 means "the last item".

The method append adds an item at the end. "Method" just means a function that belongs to an object, and you call it with a dot.

Tuples, sets and dictionaries

  • Tuple: use it for a fixed group, such as a point (x, y). Once made, you cannot change its items.
  • Set: use it when you only care whether something is present, and each item should appear once. Adding a duplicate does nothing. len(s) counts the distinct items.
  • Dictionary: use it to look things up by a name. ages["Meena"] asks for the value stored under the key "Meena".

TrapA set does not keep a fixed order, so do not predict its printed order from the way you typed it. If you need a fixed order in a question, the question will usually call sorted() first. For the same reason, we print a sorted set below.

Length and membership

len(x) gives the number of items. The word in asks a yes or no question: is this item inside? For example, 3 in [1, 2, 3] is True, and "Ravi" in ages is True because "Ravi" is a key.

What is len({1, 2, 2, 3, 3, 3})?

The set keeps each value once: 1, 2 and 3. So the answer is 3.

What is (5, 6)[1]?

Index 1 is the second item, which is 6. Indexes start at 0.

Operators

Arithmetic operators

An operator is a symbol that does something to values. The arithmetic operators do sums and products. Here is the full list, with a small number example for each.

  • + addition: 7 + 2 is 9.
  • - subtraction: 7 - 2 is 5.
  • * multiplication: 7 * 2 is 14.
  • / division: 7 / 2 is 3.5. In Python 3, / always gives a float, even when the answer is whole. So 8 / 2 is 4.0.
  • // floor division: 7 // 2 is 3. It divides and then rounds down to the nearest whole number.
  • % remainder (modulo): 7 % 2 is 1. This is what is left over after dividing.
  • ** power: 2 ** 5 is 32, because 2 times 2 times 2 times 2 times 2 is 32.

Two of these deserve extra care. The first is floor division with negative numbers. Floor means "round down, towards minus infinity". So -7 // 2 is -4, not -3. The remainder then has to make the equation work: a = b * (a // b) + (a % b). Check it: -7 = 2 * (-4) + 1, so -7 % 2 is 1.

The second is the order of operations. Python follows the usual mathematical order: powers first, then *, /, // and %, then + and -. Brackets override everything. So 2 + 3 * 4 is 14, not 20.

Comparison operators

Comparison operators ask a question and give a bool. The symbols are == (equal), != (not equal), < (less than), > (greater than), <= (less than or equal) and >= (greater than or equal).

Notice that 4 == 4.0 is True. Python compares the values, not the types, when you use ==.

Conditionals: if, elif, else

Making a decision

A program often needs to choose. Suppose a teacher gives a grade based on marks. The teacher checks the highest band first, then the next band, and so on. Python does the same thing with if, elif (short for "else if") and else.

The structure is:

if condition_1:
    block run when condition_1 is True
elif condition_2:
    block run when condition_1 is False and condition_2 is True
else:
    block run when every condition above is False

Three rules matter:

  1. Python checks the conditions from the top. The first one that is True runs its block. The rest are skipped.
  2. Only one block ever runs. Even if two conditions are true, the second one is skipped once the first has been used.
  3. The indentation tells Python which lines belong to which block. The colon : at the end of the if line starts the block.

TrapTwo separate if statements are not the same as if followed by elif. Two if lines are each checked on their own, so more than one block can run. An elif is part of the same decision as the if above it.

A runnable example

marks = 72
if marks >= 90:
    print("grade A")
elif marks >= 60:
    print("grade B")
elif marks >= 40:
    print("grade C")
else:
    print("fail")
print("done")
grade B
done

The program first checks 72 >= 90. That is False, so the first block is skipped. Then it checks 72 >= 60. That is True, so it prints "grade B". The other two checks are never looked at. The last line print("done") is not indented, so it always runs.

If x = 0, which line is printed by an if x > 0 / elif x == 0 / else chain?

The if check 0 > 0 is False. The elif check 0 == 0 is True, so its block runs. The else block is skipped.

Why does an extra line at the same indentation as the if run every time?

Lines that are not indented inside a block are not part of the decision. They run after the whole if chain, no matter which block was chosen.

Loops: for, while, break, continue

Why loops exist

Suppose you want the sum of the numbers from 1 to 100. You could write 100 additions, but a loop does the same job with two lines. A loop repeats a block of code. Each pass through the block is an iteration.

The for loop and range()

A for loop visits every item in a sequence, one at a time. The most common sequence is made with range(). The call range(a, b) produces the numbers from a up to b - 1. The end value b is never included. This surprises beginners, so say it out loud: "start included, stop excluded".

  • range(5) gives 0, 1, 2, 3, 4. It has 5 items.
  • range(1, 6) gives 1, 2, 3, 4, 5. It has 5 items.
  • range(2, 10, 3) gives 2, 5, 8. The third number is the step, here 3. The next value would be 11, which is past 10, so it stops.

The while loop

A while loop repeats as long as its condition is True. It checks the condition before each pass. If the condition is False at the start, the body never runs. A while loop must change something that eventually makes the condition False, or it runs forever.

break and continue

  • break leaves the loop straight away. Nothing after it in the loop body runs on that pass.
  • continue skips the rest of the current pass and moves to the next iteration. The loop itself keeps going.

Key ideaThink of continue as "skip this one" and break as "stop the whole loop". Many GATE traces are built on exactly this difference.

n = 0
while True:
    n = n + 1
    if n % 2 == 0:
        continue
    if n > 7:
        break
    print(n)
print("stopped at", n)
1
3
5
7
stopped at 9

Trace this code slowly, because it is a classic pattern. The variable n goes up by 1 on every pass, so it visits 1, 2, 3, and so on. The check n % 2 == 0 is True for even numbers. For an even number, continue jumps back to the top of the loop before anything is printed. For odd numbers, the program checks whether n is greater than 7. When n reaches 9, that check is True, so break ends the loop. The last line then prints the value 9.

How many numbers does range(3, 3) produce?

None. The start (3) is included and the stop (3) is excluded, so there is nothing between them. The loop body never runs.

What does a continue do inside a for loop over range(4) on the pass where i is 2?

It skips the rest of that pass only. The loop moves on to i = 3, and the remaining body lines for i = 2 are not run.

Tracing code by hand

Why tracing is a skill

In an exam there is no computer. You must predict the output on paper. The method that works every time is a trace table. You draw one column for every variable, and one row for every important step. Then you fill the table in order, copying the values that did not change.

Four rules for tracing

  1. Read top to bottom. Do not jump ahead to the end.
  2. Work out the right side first. In x = x + 2, use the old x to compute the new value.
  3. Note what each block does. If a condition is False, its block is skipped completely. If a loop ends, the variables keep the values they had at the last pass.
  4. Remember the end value of range. range(2, 5) stops at 4.

A worked trace with several variables

Here is a snippet you could meet in an exam. Read it, then follow the trace table that comes after it.

a = [1, 2]
b = a
b.append(3)
print(a)
c = 5
d = c
d = d + 1
print(c)
[1, 2, 3]
5

Look closely at the first part. The line b = a does not copy the list. It makes a second label, b, point to the same list that a already points to. So b.append(3) changes the one list, and a shows the change too. This is called aliasing, and it is a favourite trap.

The second part works differently. d = c copies the number 5 into the label d. Then d = d + 1 moves the label d to a new value 6. The label c still points to 5. So the final print shows 5.

After x = 3, y = x, y = y * 2, what is x?

3. The line y = y * 2 moves the label y to 6. The label x still points to 3, because y was a copy of the number, not of a label.

After p = [7], q = p, q.append(8), how many items does p have?

Two. q and p point to the same list, so the appended 8 is visible through p as well.

Solved GATE-style problems

These problems are original, written in the GATE style. They are not copied from any past paper. Try each one on paper before you read the think steps.

Floor division and remainder

What is printed by the following code? Give the number.

a = 17
b = 5
print(a // b + a % b)

How to think about it

  1. What is asked. One printed number, the sum of a floor division and a remainder.
  2. Which idea applies. // gives the whole part and % gives the remainder.
  3. Work it out. 17 divided by 5 is 3 with 2 left over. So 17 // 5 is 3 and 17 % 5 is 2. Then 3 + 2 = 5.
  4. Check. The equation a = b * (a // b) + a % b gives 5 * 3 + 2 = 17. It matches.

Answer: 5

Which comparisons are True? (select all that apply)

Which of the following expressions evaluate to True? Select all that apply.

(A) 3 == 3.0   (B) "a" < "b"   (C) not (2 > 1)   (D) 10 % 3 == 0

How to think about it

  1. What is asked. A multiple select question. Every option that is True must be picked.
  2. Which idea applies. Comparison operators give a bool. Strings compare alphabetically.
  3. Work it out. (A) 3 == 3.0 compares values, and 3 equals 3.0, so True. (B) "a" comes before "b" in the alphabet, so True. (C) 2 > 1 is True, and not flips it to False. (D) 10 % 3 is 1, which is not 0, so False.
  4. Check. Only two options were True, and both were simple comparisons that you can confirm in your head.

Answer: (A) and (B)

Skipping multiples of three

Give the number printed by this code.

total = 0
for i in range(10):
    if i % 3 == 0:
        continue
    total = total + i
print(total)

How to think about it

  1. What is asked. The final value of total.
  2. Which idea applies. range(10) gives 0 to 9. The continue skips the addition for multiples of 3.
  3. Work it out. The multiples of 3 in 0 to 9 are 0, 3, 6 and 9. These are skipped. The values added are 1, 2, 4, 5, 7 and 8. Adding them one at a time: 1, then 3, then 7, then 12, then 19, then 27.
  4. Check. The sum of all 0 to 9 is 45. Remove the skipped values 0 + 3 + 6 + 9 = 18. Then 45 - 18 = 27. It matches.

Answer: 27

Tripling until the limit

Give the two numbers printed by this code, in order.

n = 1
count = 0
while n < 100:
    n = n * 3
    count = count + 1
print(n, count)

How to think about it

  1. What is asked. The final value of n and the number of passes.
  2. Which idea applies. A while loop checks its condition before each pass and stops when it is False.
  3. Work it out. Make a row for each pass. Start: n = 1, count = 0. Pass 1: n = 3, count = 1, and 3 is less than 100. Pass 2: n = 9, count = 2. Pass 3: n = 27, count = 3. Pass 4: n = 81, count = 4. 81 is still less than 100, so pass 5: n = 243, count = 5. Now 243 is not less than 100, so the loop stops.
  4. Check. 3 to the power 5 is 243, and 5 is the number of multiplications. Both match.

Answer: 243 5

Aliasing or copying?

What does this code print? Give both lines exactly.

a = [1, 2, 3]
b = a
b = b + [4]
a.append(9)
print(a, b)

How to think about it

  1. What is asked. The two lists after all the lines run.
  2. Which idea applies. b = a makes two labels for one list. b + [4] builds a new list, and assigning it moves the label b away from the old list.
  3. Work it out. After b = a, both labels point to the list [1, 2, 3]. Then b = b + [4] builds a new list [1, 2, 3, 4] and points b to it. The old list is still pointed to by a. Then a.append(9) adds 9 to the old list, so a is [1, 2, 3, 9]. b is [1, 2, 3, 4].
  4. Check. Only a received the 9, because b was moved to a new list before that line ran.

Answer: [1, 2, 3, 9] [1, 2, 3, 4]

Counting with nested loops

Give the number printed by this code.

count = 0
for i in range(1, 4):
    for j in range(i):
        count = count + 1
print(count)

How to think about it

  1. What is asked. The final value of count.
  2. Which idea applies. The inner loop runs i times on each outer pass, because range(i) has i items.
  3. Work it out. When i = 1, the inner loop runs 1 time, so count becomes 1. When i = 2, it runs 2 times, so count becomes 3. When i = 3, it runs 3 times, so count becomes 6.
  4. Check. The total is 1 + 2 + 3, which is 6. This matches the running count.

Answer: 6

Break in the middle of a string

Give the two values printed by this code, separated by one space.

s = "GATE"
out = ""
for ch in s:
    if ch == "A":
        break
    out = out + ch + "-"
print(out, len(s))

How to think about it

  1. What is asked. The value of out after the loop, and the length of s.
  2. Which idea applies. A for loop over a string visits one character at a time. break ends the loop at once. len counts characters, and the break does not change s.
  3. Work it out. First character "G": it is not "A", so out becomes "" + "G" + "-", which is "G-". Second character "A": the condition is True, so break runs and the loop ends. The string s still has 4 characters. The print gives "G-" then a space then 4.
  4. Check. The printed line has the shape text, space, number, which is what print with two values does.

Answer: G- 4

Updating a dictionary

Give the three numbers printed by this code, separated by spaces.

scores = {"a": 2, "b": 5}
scores["a"] = scores["a"] + scores["b"]
scores["c"] = len(scores)
print(scores["a"], scores["c"], len(scores))

How to think about it

  1. What is asked. The value under key "a", the value under key "c", and the number of keys at the end.
  2. Which idea applies. Writing to an existing key replaces its value. Writing to a new key adds a pair. The right side is worked out before the assignment.
  3. Work it out. Line 2 sets "a" to 2 + 5, which is 7. Line 3 first works out len(scores), which is 2 because there are two keys so far. Then it adds the key "c" with value 2. Line 4 prints 7, then 2, then the length, which is now 3.
  4. Check. The trap is to count the keys after the new one is added on line 3. That would give 2 for the value of "c", but the length is computed before the assignment, so the value of "c" is 2 and the final length is 3.

Answer: 7 2 3

What is printed?

  return L

Summary

Variable
A label that points to a value, set by =.
Assignment
The right side is worked out first, then stored in the left side.
int, float, str, bool
The four basic types: whole numbers, decimals, text, and True or False.
list
Ordered, changeable, written in square brackets, indexed from 0.
tuple
Ordered and unchangeable, written in round brackets.
set
Unordered, no repeats, written in curly brackets.
dict
Key and value pairs, looked up by key.
Arithmetic operators
+, -, *, /, //, %, ** with their usual meanings.
Floor division
// rounds down, so -7 // 2 is -4.
Remainder
% is what is left after floor division. -7 % 2 is 1.
Comparison operators
==, !=, <, >, <=, >= give True or False.
Logical operators
and, or, not combine True and False values.
if, elif, else
Choose one block, checking the conditions from the top.
for loop
Visits each item of a sequence, one pass per item.
range(a, b)
The numbers from a up to b-1. The stop value is excluded.
while loop
Repeats while its condition is True, checked before each pass.
break
Leaves the loop at once.
continue
Skips the rest of this pass and moves to the next iteration.
Indentation
The spaces that show which lines belong to a block.
Trace
Follow code line by line, writing each variable's value, to predict the output.
Aliasing
Two labels pointing at the same mutable object, such as a list.

Remember these

  1. Python runs lines from top to bottom. Work out the right side of = first.
  2. / always gives a float. // rounds down, even for negative numbers.
  3. range(a, b) excludes b. It has b - a items when a is less than b.
  4. A set removes repeats. A dict is looked up by key.
  5. continue skips one pass. break stops the whole loop.
  6. b = a makes two labels for one list. Changing one changes the other.
