Euler-Cauchy equation

The Euler-Cauchy equation is a special second-order equation in which each power of x goes with the matching derivative order, as in a x² y″ + b x y′ + c y = 0. It looks harder than a constant-coefficient equation, but a simple trial solution or change of variable solves it. This topic appears in GATE RA and DA questions because the method is short once you know the trick.

The idea in plain words

Most differential equations with variable coefficients are hard. The Euler-Cauchy equation is the lucky exception. Its coefficients are arranged so that each term is scale-matched: the coefficient of y″ is a multiple of x², the coefficient of y′ is a multiple of x, and the coefficient of y is a constant.

Everyday picture: a photograph that you zoom in on. Each detail grows by the same factor, so the picture looks like itself at a different size. Power laws such as xm have this property, because (2x)m = 2m xm is just a constant times xm. That is why power functions are the natural guess.

There are two equivalent routes. The quick route tries y = xm and gets an algebraic equation for m. The conceptual route changes variables to t = ln x, which turns the equation into one with constant coefficients. Both give the same answer, and it is worth seeing both at least once.

Why it matters for GATE: heat flow in cylinders, potential problems with circular symmetry and many engineering models lead to equations of this shape. Exam questions usually give the equation, ask for the roots or the general solution, and sometimes ask for a value at a point.

Key terms

Euler-Cauchy equation
Plain meaning: a second-order equation where x², x and 1 multiply y″, y′ and y. Precise definition: a x² y″ + b x y′ + c y = 0, with constants a, b and c, and a not zero.
Equidimensional equation
Plain meaning: an equation that keeps its shape when x is rescaled. Precise definition: another name for the Euler-Cauchy form, because each term has the same total power of x.
Power function
Plain meaning: x raised to a fixed number. Precise definition: xm, where m is a constant.
Indicial equation
Plain meaning: the quadratic equation for the exponent m. Precise definition: a m(m − 1) + b m + c = 0, which simplifies to a m² + (b − a) m + c = 0.
Root m
Plain meaning: a value of the exponent that works. Precise definition: a solution of the indicial equation, giving xm as a solution of the original equation.
Natural logarithm ln x
Plain meaning: the power to which e must be raised to give x. Precise definition: the inverse of ex, defined for x > 0.
Change of variable
Plain meaning: writing the problem in a new variable that is easier to handle. Precise definition: the substitution x = et, so t = ln x.
Constant-coefficient equation in t
Plain meaning: the equation after substitution, with fixed numbers in front of y and its derivatives in t. Precise definition: a ytt + (b − a) yt + c y = 0.

Part 1: Recognising the Euler-Cauchy form

The Euler-Cauchy equation has this shape:

a x² y″ + b x y′ + c y = 0
  • a, b, c are constants, and a must not be zero.
  • x² multiplies y″, the second-order term.
  • x multiplies y′, the first-order term.
  • 1 multiplies y, the zero-order term.

The pattern is the key test. Each derivative order is matched with the same power of x: second derivative with x², first derivative with x, no derivative with x⁰. If the coefficients have this pattern, you have an Euler-Cauchy equation.

Not an Euler-Cauchy equation: x y″ + y = 0, because the y″ term has x¹ rather than x². Also y″ + x y′ = 0, because the y″ term has no x².

TrapCheck the powers before you use the method. The indicial method is not valid for an equation such as x y″ + 2y′ = 0, because the powers do not match.

Is x² y″ + 3x y′ + 5y = 0 an Euler-Cauchy equation?

Yes. The y″ term has x², the y′ term has x, and the y term has the constant coefficient 5.

Is x² y″ + y′ + y = 0 an Euler-Cauchy equation?

No. The y′ term needs a factor x, but here it has none.

Part 2: The trial solution xm and the indicial equation

Try y = xm, where m is an unknown constant. Then:

y′ = m xm−1 and y″ = m(m − 1) xm−2

Multiply each term by the matching power of x:

x² y″ = m(m − 1) xm, x y′ = m xm, y = xm

Substitute into the equation. Every term is now a multiple of xm, which can be divided out, leaving an algebraic equation:

a m(m − 1) + b m + c = 0, which simplifies to a m² + (b − a) m + c = 0

This is the indicial equation. Its roots m decide the solution. The roots of a quadratic come in the same three types as before.

Roots of the indicial equationGeneral solution
Two distinct real roots m1, m2y = C1 xm1 + C2 xm2
Repeated real root my = xm (C1 + C2 ln x)
Complex pair α ± iβy = xα (C1 cos(β ln x) + C2 sin(β ln x))

A worked example, every step shown

Solve x² y″ − 2x y′ + 2y = 0.

Step 1: Identify a, b, c. a = 1, b = −2, c = 2.

Step 2: Indicial equation. a m² + (b − a) m + c = m² + (−2 − 1) m + 2 = m² − 3m + 2 = 0.

Step 3: Factor. (m − 1)(m − 2) = 0, so m = 1 or m = 2.

Step 4: General solution. y = C1 x + C2 x².

Step 5: Check x². For y = x², y′ = 2x and y″ = 2. Then x² × 2 − 2x × 2x + 2 × x² = 2x² − 4x² + 2x² = 0. ✓

def residual(y, x, h=1e-4):
    # x^2 y'' - 2x y' + 2y for the given function y
    d1 = (y(x + h) - y(x - h)) / (2 * h)
    d2 = (y(x + h) - 2 * y(x) + y(x - h)) / (h * h)
    return x * x * d2 - 2 * x * d1 + 2 * y(x)

def sq(t):
    return t * t

def cube(t):
    return t ** 3

def ident(t):
    return t

print("x^2 solves it:", all(abs(residual(sq, x)) < 1e-3 for x in [0.5, 1.0, 2.0]))
print("x solves it:", all(abs(residual(ident, x)) < 1e-3 for x in [0.5, 1.0, 2.0]))
print("x^3 solves it:", all(abs(residual(cube, x)) < 1e-3 for x in [0.5, 1.0, 2.0]))
x^2 solves it: True
x solves it: True
x^3 solves it: False

Key ideaThe trial xm works because each term of the equation gets multiplied by the same power of x. That is exactly the scale-matching property from the introduction.

What is the indicial equation for x² y″ + 3x y′ + y = 0?

a = 1, b = 3, c = 1. So m² + (3 − 1) m + 1 = m² + 2m + 1 = 0.

Does y = x3 solve x² y″ − 2x y′ + 2y = 0?

No. Its exponent 3 is not a root of m² − 3m + 2 = 0, and the Python check above confirmed it.

Part 3: Real, repeated and complex roots

Distinct real roots

The example in Part 2 is this case. Two different powers, x and x², each solve the equation, and the general solution is any combination of them.

A repeated root

Solve x² y″ + 5x y′ + 4y = 0. Here a = 1, b = 5, c = 4. The indicial equation is m² + (5 − 1) m + 4 = m² + 4m + 4 = (m + 2)² = 0. The root m = −2 is repeated.

A repeated root gives only one power function, x−2. The second solution is x−2 ln x, just as x erx appeared for the constant-coefficient case. So:

y = x−2 (C1 + C2 ln x)

Check the second solution: for y = x−2 ln x, y′ = −2x−3 ln x + x−3, and y″ = 6x−4 ln x − 5x−4. Substituting: x² y″ + 5x y′ + 4y = (6 ln x − 5) x−2 + 5(−2 ln x + 1) x−2 + 4 ln x · x−2 = (6 ln x − 5 − 10 ln x + 5 + 4 ln x) x−2 = 0. ✓

Complex roots

Solve x² y″ + x y′ + y = 0. Here a = 1, b = 1, c = 1. The indicial equation is m² + (1 − 1) m + 1 = m² + 1 = 0, so m = ±i. With α = 0 and β = 1:

y = C1 cos(ln x) + C2 sin(ln x)

The solution oscillates as x changes, but on a logarithmic scale. Doubling x adds ln 2 to the phase, not a fixed amount of x. This is the surprising feature of Euler-Cauchy equations.

TrapThe formula uses ln x inside cos and sin, not x. Writing cos x instead of cos(ln x) is a very common mistake.

import math

def residual(y, x, h=1e-4):
    # x^2 y'' + x y' + y for the given function y
    d1 = (y(x + h) - y(x - h)) / (2 * h)
    d2 = (y(x + h) - 2 * y(x) + y(x - h)) / (h * h)
    return x * x * d2 + x * d1 + y(x)

def cos_log(x):
    return math.cos(math.log(x))

def sin_log(x):
    return math.sin(math.log(x))

print("cos(ln x) solves it:", all(abs(residual(cos_log, x)) < 1e-3 for x in [1.5, 2.0, 3.0]))
print("sin(ln x) solves it:", all(abs(residual(sin_log, x)) < 1e-3 for x in [1.5, 2.0, 3.0]))
cos(ln x) solves it: True
sin(ln x) solves it: True

Key ideaA repeated root always produces a logarithm, and complex roots always produce cos and sin of ln x.

What is the general solution of x² y″ − 6x y′ + 6y = 0?

a = 1, b = −6, c = 6. The indicial equation is m² + (−6 − 1) m + 6 = m² − 7m + 6 = (m − 1)(m − 6) = 0. So y = C1 x + C2 x6.

For x² y″ + 3x y′ + 5y = 0, what are the complex roots of the indicial equation?

m² + 2m + 5 = 0 gives m = (−2 ± √(4 − 20))/2 = −1 ± 2i. So α = −1 and β = 2.

Part 4: Converting to constant coefficients with x = et

The indicial method is quick, but the substitution explains why it works. Let x = et, so t = ln x. Then the derivative with respect to x can be written in terms of the derivative with respect to t:

x dy/dx = dy/dt

Write D for d/dt. The rule above says x d/dx = D. Applying it twice gives x² d²y/dx² = D(D − 1) y, which is D² y − D y. So the Euler-Cauchy terms become:

x y′ = D y and x² y″ = (D² − D) y

Substituting into a x² y″ + b x y′ + c y = 0 gives:

a (ytt − yt) + b yt + c y = 0, that is, a ytt + (b − a) yt + c y = 0

This is a constant-coefficient equation in t. Its characteristic equation is a r² + (b − a) r + c = 0, which is exactly the indicial equation with r in place of m. The roots carry over, and the solutions in t are emt = xm. That is why the power-function answers come out automatically.

A worked example, every step shown

Solve x² y″ − 3x y′ + 4y = 0 with y(1) = 1 and y′(1) = 0.

Step 1: Indicial equation. a = 1, b = −3, c = 4. Then m² + (−3 − 1) m + 4 = m² − 4m + 4 = (m − 2)² = 0. The root m = 2 is repeated.

Step 2: General solution. y = x² (C1 + C2 ln x).

Step 3: Derivative. Differentiate with the product rule: y′ = 2x (C1 + C2 ln x) + x² (C2/x) = 2x (C1 + C2 ln x) + C2 x.

Step 4: First condition. y(1) = 1² (C1 + C2 × 0) = C1 = 1.

Step 5: Second condition. y′(1) = 2 (C1 + 0) + C2 = 2C1 + C2 = 0. With C1 = 1, C2 = −2.

Step 6: Particular solution. y = x² (1 − 2 ln x).

Step 7: Value at x = e. y(e) = e² (1 − 2 × 1) = −e² ≈ −7.3891.

import math

def y(x):
    return x * x * (1 - 2 * math.log(x))

def residual(x, h=1e-4):
    d1 = (y(x + h) - y(x - h)) / (2 * h)
    d2 = (y(x + h) - 2 * y(x) + y(x - h)) / (h * h)
    return x * x * d2 - 3 * x * d1 + 4 * y(x)

print("ODE holds at sample points:", all(abs(residual(x)) < 1e-3 for x in [1.5, 2.0, 3.0]))
print("y(1) =", round(y(1.0), 4))
print("y(e) =", round(y(math.e), 4))
ODE holds at sample points: True
y(1) = 1.0
y(e) = -7.3891

TrapWhen you differentiate C2 ln x inside x² (C1 + C2 ln x), the product rule gives two terms. Dropping the x² × (C2/x) term is the usual slip.

GATE loves thisInitial conditions for Euler-Cauchy equations are often given at x = 1. This is convenient, because ln 1 = 0 and the constant C2 term disappears from y(1).

Using x = et, what is the equation in t for x² y″ + x y′ + y = 0?

a = 1, b = 1, c = 1. So ytt + (1 − 1) yt + y = 0, that is, ytt + y = 0.

Why is x y′ equal to dy/dt?

Because t = ln x, so dt/dx = 1/x. By the chain rule, dy/dt = (dy/dx)(dx/dt) = (dy/dx) x, which is x y′.

Solved GATE-style problems

These problems are original, written in GATE style, and are not past exam questions. Try each one before reading the answer.

The repeated root

Find the repeated root of the indicial equation for x² y″ + 3x y′ + y = 0.

How to think about it

  1. What is asked. The value of the repeated exponent m.
  2. Which idea applies. The indicial equation a m² + (b − a) m + c = 0.
  3. Work it out. a = 1, b = 3, c = 1. So m² + 2m + 1 = (m + 1)² = 0, and m = −1.
  4. Check. Substituting m = −1 into m² + 2m + 1 gives 1 − 2 + 1 = 0. ✓

Answer: m = −1.

Sum of the exponents

For x² y″ − 2x y′ + 2y = 0, find the sum of the two roots of the indicial equation.

How to think about it

  1. What is asked. The sum m1 + m2.
  2. Which idea applies. For a quadratic m² + p m + q = 0, the sum of the roots is −p.
  3. Work it out. The indicial equation is m² − 3m + 2 = 0. The sum of the roots is 3. Check by factoring: (m − 1)(m − 2) gives 1 and 2, and 1 + 2 = 3.
  4. Check. The product of the roots is 2, which matches the constant term.

Answer: 3.

Which statements are correct?

Consider x² y″ + x y′ + 4y = 0. Select all statements that are correct.

(A) The indicial roots are complex.
(B) y = cos(2 ln x) is a solution.
(C) y = x is a solution.
(D) The real part of the roots is 0.

Select all that apply.

How to think about it

  1. What is asked. Test four claims about the roots and solutions.
  2. Which idea applies. Indicial equation with a = 1, b = 1, c = 4: m² + 4 = 0.
  3. Work it out. m = ±2i, so the roots are complex with α = 0 and β = 2. A is true and D is true. The general solution is C1 cos(2 ln x) + C2 sin(2 ln x), so B is true (take C1 = 1, C2 = 0). For C, m = 1 is not a root, since 1 + 4 ≠ 0, so y = x is not a solution.
  4. Check. Since the roots are purely imaginary, there is no power-law growth or decay, only oscillation in ln x.

Answer: (A), (B) and (D).

A value at a point

Solve x² y″ + 3x y′ + y = 0 with y(1) = 2 and y′(1) = 0. Find y(e), as a number correct to 4 decimal places.

How to think about it

  1. What is asked. The value of the solution at x = e.
  2. Which idea applies. The repeated root m = −1 gives y = x−1(C1 + C2 ln x).
  3. Work it out. y(1) = C1 = 2. Differentiate: y′ = −x−2(C1 + C2 ln x) + x−2 C2. At x = 1, y′(1) = −C1 + C2 = 0, so C2 = 2. Then y(e) = e−1(2 + 2 × 1) = 4/e ≈ 1.4715.
  4. Check. The value is positive and smaller than y(1) = 2, consistent with the decaying factor x−1.

Answer: 1.4715.

Converting to a constant-coefficient equation

Using the substitution x = et, the equation x² y″ − 4x y′ + 6y = 0 becomes a constant-coefficient equation in t. Write this equation in the form ytt + p yt + q y = 0 and give the values of p and q.

How to think about it

  1. What is asked. The values of p and q in the t equation.
  2. Which idea applies. The equation in t is a ytt + (b − a) yt + c y = 0.
  3. Work it out. a = 1, b = −4, c = 6. So ytt + (−4 − 1) yt + 6y = 0, that is, ytt − 5 yt + 6y = 0. So p = −5 and q = 6.
  4. Check. The characteristic equation r² − 5r + 6 = (r − 2)(r − 3) has roots 2 and 3, which match the exponents of the original equation, so the change of variable is consistent.

Answer: ytt − 5 yt + 6y = 0, so p = −5 and q = 6.

A value from a repeated-root initial value problem

Solve x² y″ − 3x y′ + 4y = 0 with y(1) = 1 and y′(1) = 0. Find y(e), correct to 3 decimal places.

How to think about it

  1. What is asked. y(e) for the particular solution.
  2. Which idea applies. Repeated root m = 2, so y = x²(C1 + C2 ln x).
  3. Work it out. y(1) = C1 = 1. Then y′(1) = 2C1 + C2 = 0, so C2 = −2. The solution is y = x²(1 − 2 ln x). At x = e, ln e = 1, so y(e) = e²(1 − 2) = −e² ≈ −7.389.
  4. Check. The Python block in Part 4 confirms the ODE holds and gives y(e) = −7.3891.

Answer: y(e) = −e² ≈ −7.389.

A cosine solution with a value

Solve x² y″ + x y′ + y = 0 with y(1) = 1 and y′(1) = 0. Find y(eπ).

How to think about it

  1. What is asked. The value of y at x = eπ.
  2. Which idea applies. Complex roots ±i, so y = C1 cos(ln x) + C2 sin(ln x).
  3. Work it out. y(1) = C1 cos 0 = C1 = 1. Differentiate: y′ = (−C1 sin(ln x) + C2 cos(ln x))/x. At x = 1, y′(1) = C2 = 0. So y = cos(ln x). At x = eπ, ln x = π, so y = cos π = −1.
  4. Check. Cosine takes values between −1 and 1, and −1 is the value at π, which is correct.

Answer: −1.

Which statements about x² y″ + 5x y′ + 4y = 0 are correct?

Consider x² y″ + 5x y′ + 4y = 0 for x > 0. Select all statements that are correct.

(A) The general solution is x−2(C1 + C2 ln x).
(B) y = x−2 is a solution.
(C) y = x−2 ln x is a solution.
(D) y = x² is a solution.

Select all that apply.

How to think about it

  1. What is asked. Test four claims about this equation.
  2. Which idea applies. Indicial equation m² + 4m + 4 = (m + 2)² = 0, so m = −2 is repeated.
  3. Work it out. A is true, the standard repeated-root form. B is true, since C1 = 1 and C2 = 0. C is true, since C2 = 1 and C1 = 0, and it was checked by hand in Part 3. D is false, because m = 2 gives 4 + 8 + 4 = 16, not 0.
  4. Check. The root −2 is the only exponent that works, and the logarithm form is the second solution, as the hand check in Part 3 showed.

Exam-level practice

Exam-level 1: Euler-Cauchy with distinct roots (NAT, 2 marks)

Solve x²y″ − 2xy′ + 2y = 0 for x > 0 with y(1) = 0 and y′(1) = 1. Find y(2).

How to think about it

  1. What is asked. The value of the solution at x = 2.
  2. Which idea applies. Try y = xm: m(m − 1) − 2m + 2 = m² − 3m + 2 = 0, so m = 1 and 2.
  3. Work it out. y = Ax + Bx². y(1) = A + B = 0 and y′(1) = A + 2B = 1. So B = 1 and A = −1. y(2) = −2 + 4 = 2.
  4. Check. y = x² − x gives x²·2 − 2x(2x − 1) + 2(x² − x) = 0.

Answer: 2.

Exam-level 2: Repeated root case (MCQ, 2 marks)

The general solution of x²y″ + 3xy′ + y = 0, x > 0, is (A) c1x + c2x ln x (B) (c1 + c2 ln x)/x (C) c1/x + c2x (D) c1 cos(ln x) + c2 sin(ln x)

How to think about it

  1. What is asked. The form of the solution for a double root.
  2. Which idea applies. Indicial equation: m(m − 1) + 3m + 1 = m² + 2m + 1 = 0, so m = −1 twice.
  3. Work it out. Double root gives x−1(c1 + c2 ln x).
  4. Check. Substituting x = et turns the equation into y″ + 2y′ + y = 0 in t.

Answer: (B).

Exam-level 3: Complex roots (NAT, 2 marks)

For x²y″ + xy′ + 4y = 0, solutions are xacos(b ln x) and xasin(b ln x). Find a + b.

How to think about it

  1. What is asked. The real and imaginary parts of the indicial roots.
  2. Which idea applies. m(m − 1) + m + 4 = m² + 4 = 0.
  3. Work it out. m = ±2i, so a = 0 and b = 2. a + b = 2.
  4. Check. In t = ln x, the equation is y″ + 4y = 0, with frequency 2.

Answer: 2.

Summary

Euler-Cauchy equation
a x² y″ + b x y′ + c y = 0, where each power of x matches the derivative order.
Trial solution
y = xm, which turns the equation into an algebraic one.
Indicial equation
a m² + (b − a) m + c = 0, whose roots are the exponents m.
Distinct real roots
y = C1 xm1 + C2 xm2.
Repeated root
y = xm(C1 + C2 ln x).
Complex roots
y = xα(C1 cos(β ln x) + C2 sin(β ln x)).
Substitution x = et
Turns the equation into a ytt + (b − a) yt + c y = 0, with constant coefficients.
Operator identity
x y′ = dy/dt and x² y″ = (D² − D) y, where D = d/dt.
Initial conditions at x = 1
ln 1 = 0, which simplifies the constants.

Remember these

  1. Check first that the powers of x match the derivative orders.
  2. Try y = xm and collect the indicial equation a m² + (b − a) m + c = 0.
  3. A repeated root gives xm and xm ln x.
  4. Complex roots α ± iβ give xα with cos and sin of β ln x.
  5. With the product rule, do not drop the derivative of the logarithm term.
  6. Apply the initial conditions last, to find C1 and C2.
