Orthogonal matrix & idempotent matrix

Orthogonal matrices move vectors without changing their lengths, like turning a page. Idempotent matrices give the same result when applied twice, like rounding a number. Both types appear often in GATE questions that ask you to identify a matrix from its properties.

The idea in plain words

Picture a turntable with a record on it. When you turn the record, every point moves, but no point gets stretched, squashed or bent. Distances stay the same. A matrix that does this is called an orthogonal matrix. It is a rigid motion: a rotation or a flip.

Now picture a rounding button on a calculator. Press it on 2.7 and you get 3. Press it again and the number stays 3. Pressing it twice does nothing new. A matrix with this property is called idempotent. The word comes from "idem" (same) and "potent" (power). Its square is the same as itself.

Why does GATE care? Many questions give you a matrix and ask you to say what kind it is. The answer lets you skip a lot of work. If you know that a matrix is orthogonal, you know its inverse is just its transpose. If you know that it is idempotent, you know its eigenvalues must be 0 or 1. These shortcuts save time in the exam.

Key terms

Transpose
Swap the rows and columns of a matrix. Precise: (Aᵀ)ij = Aji.
Identity matrix
The matrix with 1s on the diagonal and 0s elsewhere, written I. It does nothing when multiplied. Precise: IA = AI = A.
Inverse
The matrix A⁻¹ that undoes A. Precise: A⁻¹A = AA⁻¹ = I.
Symmetric matrix
A matrix equal to its own transpose. Precise: A = Aᵀ.
Orthogonal matrix
A square matrix Q with QᵀQ = I. Its columns are orthonormal.
Orthonormal
Vectors that are unit length (length 1) and mutually perpendicular.
Idempotent matrix
A square matrix A with A² = A. Applying it twice gives the same as applying it once.
Projection matrix
A matrix that projects vectors onto a subspace. Every projection matrix is idempotent.
Eigenvalue
A number λ such that Av = λv for some non-zero vector v.
Trace
The sum of the diagonal entries of a square matrix.
Rank
The number of pivots, or the dimension of the column space.
Centering matrix
A matrix I − (1/n)11ᵀ that subtracts the average from every entry of a vector.

Step 1: Transpose, symmetry and the identity

Two tools come first. The transpose swaps rows and columns. Flip the matrix along its diagonal.

Worked example. Let A = [[1, 2], [3, 4]]. Then the first row (1, 2) becomes the first column, and the second row (3, 4) becomes the second column:

A  = [ 1  2 ]      Aᵀ = [ 1  3 ]
     [ 3  4 ]           [ 2  4 ]

If a matrix equals its transpose, it is symmetric. For example, [[2, 5], [5, 1]] is symmetric, because the entry in row 1, column 2 (5) equals the entry in row 2, column 1 (5).

The second tool is the identity matrix I. It has 1s on the diagonal. For 2 × 2, I = [[1, 0], [0, 1]]. Multiplying by I changes nothing: I(x, y) = (x, y).

Aᵀ: (Aᵀ)ij = Aji Symmetric: A = Aᵀ Identity: IA = AI = A

TrapThe transpose of a product reverses the order: (AB)ᵀ = BᵀAᵀ. Students often write AᵀBᵀ by mistake.

Question: what is the transpose of the row vector (1, 2, 3)?

The column vector with entries 1, 2, 3 (stacked from top to bottom).

Question: is [[1, 4], [2, 1]] symmetric?

No. The entry in row 1, column 2 is 4, but the entry in row 2, column 1 is 2. They must be equal for a symmetric matrix.

Step 2: Orthogonal matrices

An orthogonal matrix Q is a square matrix that satisfies:

QᵀQ = I (which also gives QQᵀ = I, so Qᵀ = Q⁻¹)

Why does this definition mean "rigid motion"? Look at what QᵀQ = I says about the columns. Entry (i, j) of QᵀQ is the dot product of column i and column j of Q. For this to equal I, two things must hold:

  • The dot product of a column with itself is 1. So every column has length 1.
  • The dot product of two different columns is 0. So the columns are perpendicular.

In other words, the columns of an orthogonal matrix are orthonormal. The same is true of the rows, because QQᵀ = I as well.

Worked example (a 3-4-5 rotation). Let

Q = (1/5) [  3  -4 ]
          [  4   3 ]
  1. Write the columns: c1 = (3/5, 4/5) and c2 = (−4/5, 3/5).
  2. Length of c1: (3/5)² + (4/5)² = 9/25 + 16/25 = 1. Length 1.
  3. Length of c2: (4/5)² + (3/5)² = 16/25 + 9/25 = 1. Length 1.
  4. Dot product: c1·c2 = (3/5)(−4/5) + (4/5)(3/5) = −12/25 + 12/25 = 0.
  5. So QᵀQ = I, and Q is orthogonal. Its inverse is Qᵀ = (1/5)[[3, 4], [−4, 3]].

The matrix is a rotation: it turns every vector by the same angle. Now test the key consequence, that lengths are preserved. Take x = (1, 2). Then Qx = (1/5)(3·1 − 4·2, 4·1 + 3·2) = (1/5)(−5, 10) = (−1, 2). The length of x is √5, and the length of Qx is √(1 + 4) = √5. Same length.

In general, ‖Qx‖² = (Qx)ᵀ(Qx) = xᵀQᵀQx = xᵀx = ‖x‖². This is why orthogonal matrices never stretch.

Look at the picture. It shows a 2 × 2 matrix bending the grid. Here the matrix is a rotation by 90 degrees, with entries 0, −1, 1, 0. Notice that the grid squares keep their size and only turn. Try the next example, a reflection, which flips the grid instead.

This second picture is a reflection in the horizontal axis, with entries 1, 0, 0, −1. The grid is flipped, not rotated, and the area is still preserved. Compare the determinant in each picture.

Key ideaFor an orthogonal matrix, det(Q) = ±1. The value +1 is a rotation and −1 is a reflection. Both keep lengths and angles.

TrapOrthogonal columns are not enough. The matrix [[2, 0], [0, 2]] has perpendicular columns, but its columns have length 2, so QᵀQ = 4I, not I. The columns must be unit length as well.

Question: is the matrix [[0, 1], [1, 0]] orthogonal?

Yes. Its columns are (0, 1) and (1, 0): both have length 1 and their dot product is 0. Its determinant is −1, so it is a reflection (in the line y = x).

Question: if Q is orthogonal, what is Q⁻¹ in terms of Q?

Q⁻¹ = Qᵀ. This is the most useful fact about orthogonal matrices: inverting costs nothing, you just transpose.

Step 3: Idempotent matrices

A square matrix A is idempotent when:

A² = A

Read it in words: applying A twice gives the same result as applying it once. The rounding button is idempotent because round(round(x)) = round(x).

Worked example. Let A = [[2, −2], [1, −1]]. Compute A²:

  1. Entry (1, 1) of A² is row 1 of A times column 1 of A: 2·2 + (−2)·1 = 4 − 2 = 2.
  2. Entry (1, 2) is row 1 times column 2: 2·(−2) + (−2)·(−1) = −4 + 2 = −2.
  3. Entry (2, 1) is row 2 times column 1: 1·2 + (−1)·1 = 2 − 1 = 1.
  4. Entry (2, 2) is row 2 times column 2: 1·(−2) + (−1)·(−1) = −2 + 1 = −1.
  5. So A² = [[2, −2], [1, −1]] = A. The matrix is idempotent.

Some idempotent matrices you already know: the zero matrix (0² = 0), the identity (I² = I), and [[1, 0], [0, 0]], which keeps the first coordinate and throws away the second.

Can an invertible matrix be idempotent? Only the identity. If A² = A and A is invertible, multiply both sides by A⁻¹ to get A = I. So every idempotent matrix other than I is singular (its determinant is 0).

GATE loves thisTo test idempotence, compute A² and compare. For a 2 × 2 matrix [[a, b], [c, d]] that is idempotent with trace 1, the determinant must be 0. Use this as a quick check when options are given.

Look at the picture for the same matrix. Notice that the grid is squashed onto a single line. Points on that line stay where they are, because they are already fixed by A. Drag your attention to the line and check that its points are unchanged.

Question: is [[1, 1], [0, 0]] idempotent?

Yes. Its square is [[1·1 + 1·0, 1·1 + 1·0], [0, 0]] = [[1, 1], [0, 0]], which equals the matrix itself.

Question: is the rotation matrix [[0, −1], [1, 0]] idempotent?

No. Its square is [[−1, 0], [0, −1]] = −I, which is not equal to the original matrix.

Step 4: Orthogonal projections and the centering matrix

Earlier we saw that projection matrices are idempotent. Here is the full picture. A matrix is an orthogonal projection exactly when it is both idempotent and symmetric:

P² = P and Pᵀ = P together mean P is an orthogonal projection

The word "orthogonal" here is about the direction of the projection. The leftover part is perpendicular to the target, which is the symmetry condition at work.

TrapIdempotent alone does not mean orthogonal projection. The matrix [[1, 1], [0, 0]] is idempotent, but it is not symmetric. It projects along a slanted direction, not a perpendicular one.

A useful example from data science is the centering matrix. Let 1 be the column of n ones, and J = 11ᵀ the n × n matrix of all ones. Then:

M = I − (1/n) J

Worked example (n = 3). Here J has all entries 1, so M = I − (1/3)J:

M = [  2/3  -1/3  -1/3 ]
    [ -1/3   2/3  -1/3 ]
    [ -1/3  -1/3   2/3 ]
  1. Apply M to x = (1, 2, 6). The average of x is (1 + 2 + 6)/3 = 3.
  2. Subtract the average from every entry: (1 − 3, 2 − 3, 6 − 3) = (−2, −1, 3).
  3. The product Mx is (−2, −1, 3). Entry 1: (2/3)(1) − (1/3)(2) − (1/3)(6) = 2/3 − 2/3 − 6/3 = −2. Correct.
  4. The entries of Mx add up to 0: −2 − 1 + 3 = 0. So the output is centred around zero.

So M is a projection onto the set of vectors whose entries sum to zero. It is symmetric, because J is symmetric, and idempotent, as the code below confirms. This is why it is called the centering matrix, and it is the first step of PCA.

The code below checks the examples of this page with exact fractions.

from fractions import Fraction as F

def matmul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]

def transpose(A):
    return [list(row) for row in zip(*A)]

Q = [[F(3, 5), F(-4, 5)], [F(4, 5), F(3, 5)]]
print("Q^T Q =", [[str(x) for x in row] for row in matmul(transpose(Q), Q)])

A = [[2, -2], [1, -1]]
print("A =", A)
print("A^2 =", matmul(A, A))

n = 3
M = [[F(1 if i == j else 0) - F(1, n) for j in range(n)] for i in range(n)]
print("M^2 == M:", matmul(M, M) == M)
print("M is symmetric:", transpose(M) == M)
print("trace(M) =", sum(M[i][i] for i in range(n)))
Q^T Q = [['1', '0'], ['0', '1']]
A = [[2, -2], [1, -1]]
A^2 = [[2, -2], [1, -1]]
M^2 == M: True
M is symmetric: True
trace(M) = 2
Question: for the centering matrix M with n = 3, what is M applied to (5, 5, 5)?

The zero vector. The entries are all equal to the average, so subtracting the average gives zeros.

Step 5: Eigenvalues, trace and rank of idempotent matrices

An eigenvalue λ of A is a number for which Av = λv has a non-zero solution v. Eigenvalues are the scaling factors along special directions. For idempotent matrices, the eigenvalues are very restricted.

Proof idea. Suppose Av = λv with v not zero. Apply A again: A²v = A(λv) = λ(Av) = λ²v. But A² = A, so A²v = Av = λv. Comparing the two results, λ²v = λv. Since v is not zero, λ² = λ. The only solutions are λ = 0 and λ = 1.

Key ideaEvery eigenvalue of an idempotent matrix is 0 or 1. The eigenvalue 1 gives the directions the matrix keeps fixed, and the eigenvalue 0 gives the directions it kills.

A second fact is very useful in GATE. For an idempotent matrix, the trace equals the rank:

trace(A) = rank(A) for every idempotent A

Why? The trace is the sum of the eigenvalues, counted with multiplicity. Each eigenvalue is 0 or 1, so the trace counts the number of 1s. The eigenvalue 1 directions are exactly the column space, so the number of them is the rank.

Worked example. Let A = [[2, −2], [1, −1]] from Step 3.

  1. The trace is 2 + (−1) = 1.
  2. The rank is 1, because the second row is half the first row (row 2 = (1, −1) and row 1 = (2, −2)).
  3. Trace = rank = 1. Consistent with the fact above.
  4. The eigenvalues are 0 and 1, which add up to the trace 1 and multiply to the determinant 0.

TrapEigenvalues 0 and 1 do not make a matrix orthogonal, and an orthogonal matrix does not need real eigenvalues at all. The rotation [[0, −1], [1, 0]] has eigenvalues ±i. For orthogonal matrices, the test is always QᵀQ = I.

Question: a 4 × 4 idempotent matrix has trace 3. What is its rank, and what are its eigenvalues?

Rank 3, because trace = rank. Eigenvalues are 1, 1, 1 and 0, since three of them must be 1 and the eigenvalues are only 0 or 1. Their sum is 3, which is the trace.

Real past GATE questions

Centering matrix properties, verified PYQ

GATE DA 2026 (MSQ, 2 marks) (verified PYQ). Let M = In − (1/n)11ᵀ, where 1 = [1, 1, ..., 1]ᵀ. Which are TRUE?

(A) M is a projection matrix   (B) Mᵀ = M   (C) M² = I   (D) trace(M) = n

How to think about it

  1. What is asked. Which properties of the centering matrix hold.
  2. Which idea applies. Let J = 11ᵀ. A key fact: J² = nJ, because each entry of J² is a sum of n ones.
  3. Work it out. (B): J is symmetric, so Mᵀ = I − (1/n)J = M. True. M² = I − (2/n)J + (1/n²)J² = I − (2/n)J + (1/n²)(nJ) = I − (1/n)J = M. So M is idempotent. (A): symmetric and idempotent means M is an orthogonal projection. True. (C): M² = M, not I. False. (D): trace(M) = trace(I) − (1/n)trace(J) = n − 1, since trace(J) = n. False.
  4. Check. Trace = rank for idempotents, so rank(M) = n − 1. This matches the projection onto the n − 1 dimensional space of vectors whose entries sum to zero.

Answer: (A) and (B).

Length-preserving matrices, verified PYQ

GATE DA 2025 (MSQ) (verified PYQ). An n × n real matrix A satisfies ‖Ax‖2 = ‖x‖2 for all x in Rn. Which must be true?

(A) A must be orthogonal   (B) A = I is the only solution   (C) The eigenvalues of A are either +1 or −1   (D) A has full rank

How to think about it

  1. What is asked. Which conclusions follow from "A preserves length".
  2. Which idea applies. Square both sides: xᵀAᵀAx = xᵀx for every x. A symmetric matrix S with xᵀSx = xᵀx for all x must equal I.
  3. Work it out. AᵀA is symmetric, and xᵀ(AᵀA)x = xᵀx for all x, so AᵀA = I. (A) is true, since this is the definition of orthogonal. (D): AᵀA = I gives A⁻¹ = Aᵀ, so A is invertible and has full rank. True. (B): a rotation such as [[0, −1], [1, 0]] also preserves length, so it is not the only solution. False. (C): that rotation has eigenvalues ±i, which are complex, so the claim fails. False.
  4. Check. The example [[0, −1], [1, 0]] rules out both (B) and (C), while the algebra supports (A) and (D).

Answer: (A) and (D).

Exam-level practice

Exam-level 1: Householder entry (NAT, 2 marks)

A Householder reflection is a matrix of the form Q = I − 2uuᵀ/(uᵀu), where u is a nonzero column vector. Let u = (1, 2, 2), so uᵀu = 9. Let Q11 be the entry in row 1 and column 1 of Q. Also check whether Q is orthogonal. Find Q11, correct to 2 decimal places.

How to think about it

  1. What is asked. The entry Q11, as a decimal to 2 places.
  2. Which idea applies. The outer product uuᵀ has entries uiuj. Then Qij = δij − 2uiuj/9, where δij is 1 when i = j and 0 otherwise.
  3. Work it out. For (1, 1): u1u1 = 1·1 = 1. So Q11 = 1 − 2·1/9 = 1 − 2/9 = 7/9 = 0.777..., which is 0.78 to 2 decimal places. For the orthogonality check, Qᵀ = Q and Q² = I − 4uuᵀ/9 + 4u(uᵀu)uᵀ/81 = I, so QᵀQ = I.
  4. Check. The Python block confirms 7/9 and that QᵀQ is the identity matrix, using exact fractions.
from fractions import Fraction as F
u = [1, 2, 2]
P = [[F(u[i] * u[j], 9) for j in range(3)] for i in range(3)]
Q = [[(1 if i == j else 0) - 2 * P[i][j] for j in range(3)] for i in range(3)]
QtQ = [[sum(Q[k][i] * Q[k][j] for k in range(3)) for j in range(3)] for i in range(3)]
print("Q11 =", Q[0][0], "=", round(float(Q[0][0]), 2))
print("QtQ is the identity:", QtQ == [[1 if i == j else 0 for j in range(3)] for i in range(3)])

Q11 = 7/9 = 0.78
QtQ is the identity: True

Answer: Q11 = 7/9, which is 0.78 to 2 decimal places. Q is orthogonal (and symmetric).

Exam-level 2: Projection and reflection properties (MSQ, 2 marks)

Let u = (1, 2, 2) and let P = uuᵀ/(uᵀu), the orthogonal projection onto the line through u. Let I be the 3 × 3 identity matrix. Which of the following statements are TRUE? Select all that apply. (A) P is idempotent. (B) P is orthogonal, meaning PᵀP = I. (C) I − P is idempotent. (D) I − 2P is orthogonal.

How to think about it

  1. What is asked. Which of the four matrix statements hold for this rank-one projection P.
  2. Which idea applies. A projection is idempotent (P² = P). A matrix Q is orthogonal when QᵀQ = I. For a symmetric matrix, Qᵀ = Q, so orthogonality means Q² = I.
  3. Work it out. (A) P² = P · P = (uuᵀ/9)(uuᵀ/9) = u(uᵀu)uᵀ/81 = uuᵀ/9 = P. True. (B) PᵀP = P² = P. P has rank 1, so P is not the identity and PᵀP ≠ I. False. (C) (I − P)² = I − 2P + P² = I − P. True. (D) (I − 2P)² = I − 4P + 4P² = I. Since I − 2P is symmetric, it is orthogonal. True.
  4. Check. The Python block checks each statement with exact fractions.
from fractions import Fraction as F
u = [1, 2, 2]
uu = sum(x * x for x in u)
I = [[F(int(i == j)) for j in range(3)] for i in range(3)]
P = [[F(u[i] * u[j], uu) for j in range(3)] for i in range(3)]
def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(3)) for j in range(3)] for i in range(3)]
def T(A):
    return [[A[j][i] for j in range(3)] for i in range(3)]
def lin(a, A, b, B):
    return [[a * A[i][j] + b * B[i][j] for j in range(3)] for i in range(3)]
IP = lin(1, I, -1, P)
IP2 = lin(1, I, -2, P)
print("(A) P^2 = P:", mul(P, P) == P)
print("(B) P^T P = I:", mul(T(P), P) == I)
print("(C) (I-P)^2 = I-P:", mul(IP, IP) == IP)
print("(D) (I-2P)^T (I-2P) = I:", mul(T(IP2), IP2) == I)

(A) P^2 = P: True
(B) P^T P = I: False
(C) (I-P)^2 = I-P: True
(D) (I-2P)^T (I-2P) = I: True

Answer: (A), (C) and (D). Statement (B) is wrong because PᵀP = P, and P ≠ I.

Exam-level 3: Trace of a sandwich product (NAT, 2 marks)

Let E = (1/2) [[1, 1], [1, 1]] and let Q = [[3/5, −4/5], [4/5, 3/5]]. Compute the trace of the product EQE, which is the sum of its diagonal entries. Use the fact that E is idempotent and symmetric, and that Q is a rotation matrix. Give the answer correct to 2 decimal places.

How to think about it

  1. What is asked. The sum of the diagonal entries of EQE, to 2 decimal places.
  2. Which idea applies. The trace has the cyclic property trace(XYZ) = trace(ZXY). Since E² = E, trace(EQE) = trace(E·E·Q) = trace(EQ).
  3. Work it out. trace(EQ) = Σ over i, k of EikQki. Every Eik equals 1/2, so trace(EQ) = (1/2)(Q11 + Q12 + Q21 + Q22) = (1/2)(3/5 − 4/5 + 4/5 + 3/5) = (1/2)(6/5) = 3/5 = 0.60.
  4. Check. The Python block computes EQE directly with exact fractions and gets the same trace.
from fractions import Fraction as F
E = [[F(1, 2), F(1, 2)], [F(1, 2), F(1, 2)]]
Q = [[F(3, 5), F(-4, 5)], [F(4, 5), F(3, 5)]]
def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(2)) for j in range(2)] for i in range(2)]
M = mul(mul(E, Q), E)
tr = M[0][0] + M[1][1]
print("E^2 = E:", mul(E, E) == E)
print("trace(EQE) =", tr, "=", round(float(tr), 2))

E^2 = E: True
trace(EQE) = 3/5 = 0.6

Answer: 3/5, which is 0.60 to 2 decimal places.

Exam-level 4: Householder reflection eigenvalues (MSQ, 2 marks)

Let x = (1/3, 2/3, 2/3) be a unit vector and let R = I − 2xxᵀ, where I is the 3 × 3 identity matrix. Let v1 = (2, −1, 0) and v2 = (2, 4, −5). Which of the following are TRUE? Select all that apply. (A) R is orthogonal. (B) det(R) = −1. (C) R has the eigenvalue +1 with multiplicity 2. (D) R² = I but R is not symmetric.

How to think about it

  1. What is asked. Which statements about R hold, and in particular its eigenvalues.
  2. Which idea applies. xᵀx = 1 gives R x = x − 2x = −x, so x is an eigenvector with eigenvalue −1. Any vector v perpendicular to x satisfies Rv = v, so eigenvalue +1.
  3. Work it out. (A) xxᵀ is symmetric and (xxᵀ)² = x(xᵀx)xᵀ = xxᵀ, so R is symmetric and R² = I, which gives RᵀR = I. True. (B) The eigenvalues are −1 (once) and +1 (twice), whose product is −1, so det(R) = −1. True. (C) v1 and v2 are perpendicular to x, so both have eigenvalue +1, and they are independent. True. (D) R is symmetric, so the claim that it is not symmetric is false.
  4. Check. The Python block confirms the determinant, the trace 1 = −1 + 1 + 1, and the eigenvector equations using exact fractions.
from fractions import Fraction as F
x = [F(1, 3), F(2, 3), F(2, 3)]
I = [[F(int(i == j)) for j in range(3)] for i in range(3)]
R = [[I[i][j] - 2 * x[i] * x[j] for j in range(3)] for i in range(3)]
def mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(3)) for j in range(3)] for i in range(3)]
def T(A):
    return [[A[j][i] for j in range(3)] for i in range(3)]
def mv(A, v):
    return [sum(A[i][k] * v[k] for k in range(3)) for i in range(3)]
def det3(M):
    return (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
            - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
            + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))
v1 = [2, -1, 0]
v2 = [2, 4, -5]
print("(A) R^T R = I:", mul(T(R), R) == I)
print("(B) det R =", det3(R))
print("(C) R v1 = v1 and R v2 = v2:", mv(R, v1) == v1 and mv(R, v2) == v2)
print("R x = -x:", mv(R, x) == [-xi for xi in x])
print("(D) R symmetric:", T(R) == R)

(A) R^T R = I: True
(B) det R = -1
(C) R v1 = v1 and R v2 = v2: True
R x = -x: True
(D) R symmetric: True

Summary

Transpose
Swap rows and columns. Written Aᵀ.
Symmetric
A matrix equal to its own transpose.
Identity
The matrix I with 1s on the diagonal. It changes nothing.
Inverse
The matrix A⁻¹ with A⁻¹A = I.
Orthogonal matrix
A square matrix with QᵀQ = I. Its columns are orthonormal.
Orthonormal
Unit length and mutually perpendicular.
Rotation
An orthogonal matrix with determinant +1.
Reflection
An orthogonal matrix with determinant −1.
Idempotent matrix
A square matrix with A² = A.
Orthogonal projection
A matrix that is both idempotent and symmetric.
Eigenvalue
A scaling factor λ with Av = λv for some non-zero v.
Eigenvalues of an idempotent
Always 0 or 1.
Trace
The sum of the diagonal entries, which equals the sum of the eigenvalues.
Trace equals rank
True for every idempotent matrix.
Centering matrix
M = I − (1/n)11ᵀ, an orthogonal projection that subtracts the mean.

Remember these

  1. For an orthogonal matrix, Q⁻¹ = Qᵀ, and the lengths of vectors are preserved.
  2. Orthogonal columns are not enough. The columns must also have length 1.
  3. Idempotent means A² = A, and it is the mark of a projection.
  4. The eigenvalues of an idempotent matrix are 0 or 1.
  5. For an idempotent matrix, trace = rank.
  6. Idempotent and symmetric together give an orthogonal projection.
