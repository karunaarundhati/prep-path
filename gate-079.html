Python operators, expressions & conditionals (recap)

An expression is a piece of code that gives a value, such as 7 // 2 or x &gt; 3. Operators join values together, and conditionals choose between actions based on those values. This quick recap revisits the arithmetic, comparison, logical and bitwise operators, the precedence rules that decide what is computed first, and the if, elif, else and match structures.

The idea in plain words

Think of a calculator with a long list of buttons. Some buttons add or divide. Some ask a yes or no question, such as "is this bigger?" Some combine two answers, such as "both are true". A program is a long sequence of these button presses, and the order in which the calculator applies them matters a lot.

GATE questions in this area give you one or two lines of Python and ask for the printed result. Most wrong answers come from forgetting the precedence rules, from mixing up integer division with normal division, or from missing that a logical operator may stop early. This page revises exactly those points.

Key ideaEvery expression has one value. To find it, apply the operators in precedence order, and remember that and and or can stop as soon as the answer is known.

Key terms

Operator
A symbol that works on one or two values. Precisely: + - * / // % ** are arithmetic, == != < > are comparisons, and and, or, not are logical.
Operand
A value that an operator works on. In 7 // 2, the operands are 7 and 2.
Expression
A combination of values and operators that gives one value.
Integer division (//)
Divide and round down to the whole number below. Precisely: floor division, so -7 // 2 is -4.
Remainder (%)
What is left after integer division. Precisely: a - (a // b) * b. In Python the result has the same sign as the divisor.
Truthiness
Whether a value counts as true or false. Precisely: 0, 0.0, "" (empty string), [] and None are false; most other values are true.
Short-circuit evaluation
Stopping as soon as the result is known. Precisely: in a and b, b is skipped when a is false, and in a or b, b is skipped when a is true.
Bitwise operator
An operator that works on the individual bits of an integer. Precisely: & (and), | (or), ^ (exclusive or), << (shift left) and >> (shift right).
Precedence
The order in which operators are applied when several appear. Precisely: higher-precedence operators bind tighter.
Conditional structure
Code that chooses a path by a test: if, elif, else, and match-case.

Arithmetic operators and integer division

The usual operators are + (add), - (subtract), * (multiply), / (divide), ** (power), // (integer division) and % (remainder). Two details are often tested. First, / always gives a decimal result in Python 3, even when the answer is whole: 6 / 2 is 3.0. Second, // and % are linked by the rule a = (a // b) * b + (a % b), which holds for every integer a and b (with b not zero).

Negative numbers are the trap. Python rounds the quotient down (towards negative infinity), so -7 // 2 is -4, not -3. The remainder then takes the sign of the divisor, so -7 % 2 is 1. Check with the rule: (-4) * 2 + 1 = -7. It works.

print(7 // 2, -7 // 2, 7 % 3, -7 % 3, 2 ** 5)
print(6 / 2)
3 -4 1 2 32
3.0

TrapMany languages, such as C, round integer division towards zero, which gives -3 for -7 / 2. Python gives -4. GATE questions about Python will use Python's rule, so read the question's language.

What is 17 // 5 and 17 % 5?

3 and 2. Five goes into 17 three times with 2 left over.

What does 10 / 4 give in Python 3?

2.5. The / operator keeps the fraction. Use // for the whole part only.

Comparisons, logical operators and truthiness

A comparison gives True or False. The operators are == (equal), != (not equal), < (less), > (greater), <= (at most) and >= (at least). Python also allows a chain such as 1 < x < 5, which means 1 < x and x < 5.

Logical operators combine truth values. not flips the value. and is true only if both parts are true. or is true if at least one part is true. The operators and and or do not always return True or False in Python. They return one of their operands. This is useful, but you must trace it carefully.

print(5 > 3 and 2 > 4 or not False)
x = 0
print(x != 0 and 10 / x > 1)
print(0 or "" or "default", 5 and 0)
print(bool(""), bool("0"), bool([]))
True
False
default 0
False True False

The second line does not crash, even though 10 / x would divide by zero. That is because x != 0 is already False, so and stops and never evaluates the division. This is short-circuit evaluation. The string "0" is true because it is not empty.

TipFor a and b, if a is false the answer is a. Otherwise the answer is b. For a or b, if a is true the answer is a. Otherwise the answer is b. This explains why 5 and 0 gives 0.

What is True or 1 / 0 in Python?

True. The left side is true, so or stops and the division is never run.

Is an empty list true or false?

False. Empty containers and empty strings are false.

Bitwise operators

An integer is stored as bits, each 0 or 1. Bitwise operators work on those bits, column by column. Write 12 as 1100 and 10 as 1010 in binary. Then:

  • & (and): a column gives 1 only if both bits are 1. 1100 & 1010 = 1000, which is 8.
  • | (or): a column gives 1 if either bit is 1. 1100 | 1010 = 1110, which is 14.
  • ^ (exclusive or): a column gives 1 if the bits differ. 1100 ^ 1010 = 0110, which is 6.
  • << (shift left): move every bit left, filling with 0. Each shift doubles the value. 1 << 4 = 16.
  • >> (shift right): move every bit right, dropping the last bit. Each shift halves the value, rounding down. 32 >> 2 = 8.
print(12 & 10, 12 | 10, 12 ^ 10, 1 << 4, 32 >> 2)
8 14 6 16 8

GATE loves thisx & 1 gives 1 exactly when x is odd, because only the last bit can be 1 for an odd number. A quick test for the last bit is worth remembering.

What is 6 | 3 in binary terms?

110 | 011 = 111, which is 7.

What does 5 >> 1 give?

2. The bits 101 shift right to 10, which is 2 (the last 1 is dropped).

Operator precedence and evaluation order

When an expression has several operators, Python applies them in a fixed order. From the tightest binding to the loosest, the main groups are: ** (power), then unary minus and ~, then * / // %, then + -, then << >>, then &, then ^, then |, then the comparisons (==, <, in, and so on), then not, then and, then or.

Two rules deserve special attention. Power is right-associative, which means 2 ** 3 ** 2 is 2 ** (3 ** 2) = 2 ** 9 = 512, not (2 ** 3) ** 2 = 64. And a chained comparison is not applied left to right in the way you might expect: 1 < 2 < 3 means "1 < 2 and 2 < 3".

print(2 + 3 * 4 ** 2 // 8)
print(1 + 2 * 3 << 2)
print(2 ** 3 ** 2)
print(1 < 2 < 3 != 4, 3 > 2 > 5)
print(not 3 == 4)
8
28
512
True False
True

Read the second line carefully. The + and * act before <<, so 1 + 2 * 3 is 7 first, and then 7 << 2 is 28. A beginner who reads the shift first would get a different answer. When in doubt, add brackets. Brackets never change the result of a correct program, they only make your reading clearer.

Trapnot binds tighter than and, but looser than ==. So not 3 == 4 means not (3 == 4), which is True. Writing (not 3) == 4 would be a different expression.

What is 10 - 4 - 3 in Python?

3. The minus signs group from the left: (10 - 4) - 3 = 3. Only ** groups from the right.

Is "a or b and c" the same as "(a or b) and c"?

No. and binds tighter than or, so it means a or (b and c).

Conditional structures: if, elif, else and the conditional expression

An if statement runs its block only when a condition is true. An elif is checked only when the earlier conditions were false, and else runs when none of them were true. Python checks the tests from top to bottom and runs the first matching block, then skips the rest. This means the order of your tests matters.

A conditional expression gives one of two values in a single line. The form is value_if_true if condition else value_if_false.

score = 72
if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"
print(grade)
print("pos" if -4 > 0 else "non-positive")
B
non-positive

TrapIf you write the test 70 <= score before 90 <= score, every score of 90 or more would be graded B, because the first test already matches. Test from the most specific or highest range first.

If score is 90, which grade does the code above give?

A. The first test score >= 90 is true, so its block runs and the rest are skipped.

Does the else block run if an earlier elif was true?

No. Only one block in an if-elif-else chain runs.

match-case: choosing one value from several

Python 3.10 introduced match, which is similar to a switch statement in C. It compares one value with several patterns. A pattern may list alternatives with |, and case _ is the default that matches anything. The first matching case runs, and the rest are skipped.

code = 2
match code:
    case 1:
        print("start")
    case 2 | 3:
        print("run")
    case _:
        print("stop")
run

In GATE questions, match is less common than if-elif. Read it the same way: the first matching case wins, and the wildcard _ comes last.

What does the code above print if code is 7?

stop. No case 1, 2 or 3 matches, so the wildcard runs.

Solved GATE-style problems

Powers and negative division

What does this program print?

print(2 ** 3 ** 2, -7 // 2, -7 % 2)

How to think about it

  1. What is asked. Three values on one line.
  2. Which idea applies. ** groups from the right. // rounds down. % takes the sign of the divisor.
  3. Work it out. 3 ** 2 = 9 first, so 2 ** 9 = 512. -7 // 2 rounds down from -3.5 to -4. For -7 % 2, use the identity: -7 = (-4) x 2 + 1, so the remainder is 1.
  4. Check. Verify the identity: (-4) x 2 + 1 = -7, which is correct.

Answer: 512 -4 1

print(2 ** 3 ** 2, -7 // 2, -7 % 2)
512 -4 1

Division and remainder

What does this program print?

print(17 // 5, 17 % 5, 17 / 5)

How to think about it

  1. What is asked. Three values: integer division, remainder and true division.
  2. Which idea applies. // gives the whole part, % gives what is left, and / keeps the decimal.
  3. Work it out. 5 fits into 17 three times, leaving 2. So 17 // 5 = 3 and 17 % 5 = 2. 17 / 5 = 3.4.
  4. Check. 3 x 5 + 2 = 17, and 3.4 x 5 = 17.

Answer: 3 2 3.4

print(17 // 5, 17 % 5, 17 / 5)
3 2 3.4

Which operator statements are true?

Select all that apply.

  • (A) In Python 3, 5 / 2 gives 2.5.
  • (B) In Python 3, 5 // 2 gives 2.5.
  • (C) not binds tighter than and.
  • (D) The chain 1 < x < 5 means (1 < x) and (x < 5).
  • (E) The ^ operator means exponentiation in Python.

How to think about it

  1. What is asked. Which claims about operators are true.
  2. Which idea applies. / is true division, // is floor division, ** is power, and ^ is bitwise exclusive or.
  3. Work it out. (A) True. (B) False, 5 // 2 is 2. (C) True, not comes before and in the precedence list. (D) True, that is the meaning of a chain. (E) False, ^ is exclusive or on bits.
  4. Check. Print 5 / 2 and 5 // 2 in your head: 2.5 and 2. Only the first is a decimal.

Answer: (A), (C) and (D).

Short-circuit results

What does this program print?

print(True or 1 / 0)
print(0 or "" or "default", 5 and 0)

How to think about it

  1. What is asked. Two lines of output.
  2. Which idea applies. or stops at the first true operand. and stops at the first false operand. Each returns the operand that decided the result.
  3. Work it out. The first line: True is already true, so 1 / 0 is never run. It prints True. The second line: 0 is false, "" is false, so "default" is the value of the or. For 5 and 0, the first operand 5 is true, so the and returns 0.
  4. Check. If the division had run, the program would stop with an error. It does not, which confirms the short circuit.

Answer: True, then default 0.

print(True or 1 / 0)
print(0 or "" or "default", 5 and 0)
True
default 0

Trace an if-elif chain

What does this program print?

x = 10
if x % 3 == 0 and x % 5 == 0:
    out = "FizzBuzz"
elif x % 3 == 0:
    out = "Fizz"
elif x % 5 == 0:
    out = "Buzz"
else:
    out = x
print(out)

How to think about it

  1. What is asked. The value of out.
  2. Which idea applies. Tests are checked from the top, and the first true test wins.
  3. Work it out. 10 % 3 is 1, so the first test is false and so is the second. 10 % 5 is 0, so the third test is true and out becomes "Buzz". The else is skipped.
  4. Check. 10 is divisible by 5 but not by 3, so "Buzz" is the right label.

Answer: Buzz

Clearing the lowest set bit

Let x = 0b1011 (binary 1011). The program below applies x = x & (x - 1) twice. After the second line, how many 1 bits does x have?

x = 0b1011
x = x & (x - 1)
print(bin(x))
x = x & (x - 1)
print(bin(x), bin(x).count("1"))

How to think about it

  1. What is asked. The number of 1 bits after two steps.
  2. Which idea applies. Subtracting 1 flips the lowest set bit to 0 and the bits below it to 1. The and then clears the lowest set bit.
  3. Work it out. 1011 - 1 = 1010. 1011 & 1010 = 1010. That is the first print. Next, 1010 - 1 = 1001, and 1010 & 1001 = 1000. That is the second print, with one 1 bit.
  4. Check. Each step removed exactly one 1 bit, from 3 to 2 to 1, which the count in the code confirms.

Answer: 1 bit. The program prints 0b1010, then 0b1000 1.

x = 0b1011
x = x & (x - 1)
print(bin(x))
x = x & (x - 1)
print(bin(x), bin(x).count("1"))
0b1010
0b1000 1

Which statements are true?

Select all that apply.

  • (A) not 3 == 4 evaluates to True.
  • (B) For any integer x, x & 1 equals 1 exactly when x is odd.
  • (C) In a match statement, case _ runs when no earlier case matches.
  • (D) In a or b, b is always evaluated, even when a is true.
  • (E) 5 >> 1 equals 2.

How to think about it

  1. What is asked. Which claims are true.
  2. Which idea applies. Precedence (not is looser than ==), the last bit test, match order, short-circuit, and right shift.
  3. Work it out. (A) True, not (3 == 4) = not False = True. (B) True, the last bit is 1 for odd numbers, including negatives in Python. (C) True. (D) False, or skips b when a is true. (E) True, 5 is 101 and shifting right gives 10, which is 2.
  4. Check. The code below checks (A), (B) and (E) with values, including the negative numbers in (B).

Answer: (A), (B), (C) and (E).

print(not 3 == 4, -3 & 1, -2 & 1, 5 >> 1)

How to think about it
