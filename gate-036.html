Exponential & Poisson distributions

The Poisson distribution counts rare events in a fixed time or space, such as calls arriving at a helpline. The exponential distribution measures the waiting time between those events. Together they model arrivals, failures and queues, which GATE uses often.

The idea in plain words

Imagine a helpline that receives calls at random. Some minutes have no calls, some have one, and some have several. On average it gets 6 calls per hour, but the exact number changes from hour to hour. The Poisson distribution describes how such counts behave when events happen at a steady average rate and are independent of each other. It answers questions like "what is the chance of exactly 3 calls in the next hour?"

Now look at the time between calls instead of the count. Some gaps are short and some are long. The exponential distribution describes these waiting times. It is the continuous partner of the Poisson counts. If calls arrive as a Poisson process, the gaps between them follow the exponential distribution. This is a neat and important connection.

Why do these matter for GATE? Many questions describe a system where failures, requests or arrivals happen at random. The Data Science and AI (DA) paper uses these models in probability and in queueing-type reasoning. The Robotics and Automation (RA) paper uses them for failure times and for random arrivals of tasks or sensor events. The formulas are short, but you must know which one to use and how to read the rate.

A small word of warning. The Poisson distribution is discrete, so we add up a PMF. The exponential distribution is continuous, so probabilities come from areas under a curve. You will see this difference again in the next topics on continuous random variables.

Key terms

Read these before the explanations. Each one is first given in plain words.

Rate λ (lambda)
Plain meaning: the average number of events per unit of time or space. Precise definition: the constant average number of events per unit interval in a Poisson process.
Rare event
Plain meaning: something that happens seldom in any short time slot, such as an accident in one minute. Precise definition: an event with a small chance in each tiny slot of time, where many slots are used.
Poisson distribution
Plain meaning: the distribution of the count of events in a fixed interval. Precise definition: the discrete distribution with P(X = x) = e-λ λx / x! for x = 0, 1, 2, ....
Factorial x!
Plain meaning: multiply all whole numbers from x down to 1. Precise definition: x! = x × (x - 1) × ... × 1, with 0! = 1.
Euler's number e
Plain meaning: a fixed constant, about 2.71828, that appears in growth and decay. Precise definition: the base of the natural logarithm, e = 2.718281..., so e-λ is the reciprocal of eλ.
Exponential distribution
Plain meaning: the distribution of a waiting time when events arrive at a constant rate. Precise definition: a continuous distribution with density f(x) = λ e-λx for x ≥ 0.
Probability density function (PDF)
Plain meaning: a curve whose area gives probabilities. Precise definition: a function f(x) that is non-negative and has total area 1, with P(a ≤ X ≤ b) equal to the area under f from a to b.
Tail probability
Plain meaning: the chance that the waiting time is longer than a given time. Precise definition: P(X > t), which for the exponential distribution equals e-λt.
Memoryless property
Plain meaning: having waited a while does not change the chance of waiting longer. Precise definition: P(X > s + t | X > s) = P(X > t) for all s, t ≥ 0.
Poisson process
Plain meaning: random events that arrive at a steady average rate, independently of each other. Precise definition: a process whose counts in disjoint intervals are independent Poisson variables with mean proportional to the interval length.

Concept 1: The Poisson distribution

Why it matters

Suppose a website gets an average of 3 visits per minute. Some minutes get 0 visits, some get 1, and some get 5 or more. You want the chance of each count. The Poisson distribution gives it, using only one number: the rate λ = 3.

Everyday picture: think of raindrops falling on a large paving slab. Each small square has a tiny chance of a drop, and there are very many squares. The total number of drops in the slab is Poisson. The key idea is "many chances, each with a tiny probability, adding up to a steady average".

The PMF

P(X = x) = e-λ λx / x!, for x = 0, 1, 2, ...

Each symbol means:

  • x is the number of events we are counting.
  • λ is the average number of events in the interval, which must be greater than 0.
  • e-λ is a damping factor. It ensures the probabilities add up to 1 across all x.
  • λx / x! grows with λ and shrinks with the factorial, so the probabilities rise to a peak and then fall.

Mean and variance

E[X] = λ and Var(X) = λ

This is a very useful fact. For the Poisson distribution, the mean and the variance are the same number. If a question gives you a count whose variance equals its mean, the Poisson model is a likely fit.

Worked example: calls per minute

A helpline receives calls at an average rate of λ = 3 per minute. Find the chance of exactly 2 calls in a minute.

  1. Write the formula. P(X = 2) = e-3 × 32 / 2!.
  2. Compute the powers. 32 = 9. Also 2! = 2 × 1 = 2.
  3. Combine. P(X = 2) = e-3 × 9 / 2 = 4.5 × e-3.
  4. Evaluate. e-3 is about 0.0498, so P(X = 2) = 4.5 × 0.0498 = 0.2241, approximately.
  5. Check. The probability 0.224 is the largest of the early values for λ = 3, which fits: the peak of a Poisson with λ = 3 is at x = 2 and x = 3.

The Python block computes the chances for 0, 2 and "at most 2" calls.

import math

lam = 3

def poisson_pmf(x, lam):
    return math.exp(-lam) * lam**x / math.factorial(x)

print(f"P(X = 0) = {poisson_pmf(0, lam):.4f}")
print(f"P(X = 2) = {poisson_pmf(2, lam):.4f}")
print(f"P(X <= 2) = {sum(poisson_pmf(x, lam) for x in range(3)):.4f}")
P(X = 0) = 0.0498
P(X = 2) = 0.2240
P(X <= 2) = 0.4232

Key ideaFor a Poisson count, the mean and the variance are both λ. This one fact lets you answer many mean and variance questions in seconds.

TrapMatch the interval. If the rate is 3 per minute and the question asks about 10 minutes, the new rate is 30, not 3. Always scale λ to the length of the interval in the question.

Self-check: calls arrive at 4 per hour. What is the rate for a 30 minute interval?

λ = 4 × 30/60 = 2 calls per 30 minutes.

Self-check: a Poisson variable has mean 7. What is its variance?

The variance is also 7, because for the Poisson distribution Var(X) = E[X] = λ.

Concept 2: Poisson as an approximation to the binomial

Why it matters

Recall the binomial distribution: n trials, each with success chance p. Sometimes n is very large and p is very small. For example, 1000 light bulbs each fail with chance 0.002. Computing C(1000, x) for large x is slow and error-prone by hand. The Poisson distribution gives a simple and accurate substitute.

The rule

When n is large and p is small, the binomial is close to the Poisson with the same mean. Set:

λ = np, then Bin(n, p) is approximately Poisson(λ)

The matching of means is the reason. Both distributions have mean np. The rule works well when n is at least about 20 and p is at most about 0.05, which is the usual textbook guideline.

Worked example: the light bulbs

  1. Take n = 1000 and p = 0.002. The mean is λ = np = 1000 × 0.002 = 2.
  2. The exact binomial chance of no failures is (1 - p)n = 0.9981000, which is about 0.1351.
  3. The Poisson approximation is e-2, which is about 0.1353.
  4. Compare. The two values differ by only 0.0002, which is a very good match.

The Python check below compares the two values directly.

import math

n, p = 1000, 0.002
lam = n * p

binom0 = (1 - p) ** n
pois0 = math.exp(-lam)
print(f"binomial P(X = 0) = {binom0:.4f}")
print(f"Poisson P(X = 0) with lambda = {lam} = {pois0:.4f}")
binomial P(X = 0) = 0.1351
Poisson P(X = 0) with lambda = 2.0 = 0.1353

TipIn a GATE question, look for words like "rare", "a very large number of trials", or "small chance per item". These signal that the Poisson approximation is intended, and that λ = np is the rate to use.

TrapThe approximation needs np to be moderate. If n is 1000 and p is 0.5, the mean is 500, and the Poisson is a poor fit. Check that p is small before you approximate.

Self-check: n = 400 and p = 0.01. What is λ for the Poisson approximation?

λ = np = 400 × 0.01 = 4.

Self-check: why do the binomial and Poisson approximation share the same mean?

Because the binomial mean is np, and the approximation is chosen to match it. A good approximation must keep the average the same.

Concept 3: The exponential distribution

Why it matters

Back to the helpline. Calls arrive at 6 per hour on average. How long do you wait for the next call? Sometimes a call comes almost at once, and sometimes you wait a long time. The waiting time is a continuous quantity, so we use a continuous distribution. For arrivals at a steady rate, that distribution is the exponential.

The density and the area

A continuous variable has a probability density function, f(x). Probabilities are areas under the curve, not single heights. The density of the exponential distribution is:

f(x) = λ e-λx, for x ≥ 0

Each symbol means:

  • x is the waiting time, which is never negative.
  • λ is the rate of arrivals, in events per unit of time. A larger λ means shorter waits.
  • e-λx decreases as x grows, so long waits are less likely than short ones.

The tail formula

The most useful quantity is the tail probability, the chance of waiting longer than t:

P(X > t) = e-λt

This formula appears in almost every exponential GATE question. It is much quicker than integrating the density.

Mean and variance

E[X] = 1/λ and Var(X) = 1/λ²

The mean waiting time is the reciprocal of the rate. If calls arrive at 6 per hour, the mean wait is 1/6 of an hour, which is 10 minutes. The variance is 1/λ², so the standard deviation equals the mean, which is a special feature of this distribution.

Worked example: the helpline

Calls arrive at λ = 6 per hour. Find the chance that the next call takes more than 20 minutes.

  1. Use the same units. 20 minutes is 1/3 of an hour, so t = 1/3.
  2. Write the tail formula. P(X > 1/3) = e-6 × 1/3.
  3. Simplify the exponent. 6 × 1/3 = 2, so P(X > 1/3) = e-2.
  4. Evaluate. e-2 is about 0.1353, so there is about a 13.5 percent chance of a wait longer than 20 minutes.
  5. Check. The mean wait is 10 minutes, and 20 minutes is twice the mean. A tail value of about 0.135 is a plausible small chance.

The Python check computes the tail probability with a function, so you can reuse it for any t.

import math

lam = 0.5                        # rate: 0.5 events per minute, mean wait 2 minutes

def surv(t):                     # P(X > t) for the exponential distribution
    return math.exp(-lam * t)

print(f"P(X > 2) = {surv(2):.4f}")
print(f"P(X > 5 given X > 3) = {surv(5) / surv(3):.4f}")
P(X > 2) = 0.3679
P(X > 5 given X > 3) = 0.3679

Key ideaThe exponential tail formula e-λt is the only formula you need for most waiting-time questions. Convert the time to the same unit as the rate first.

TrapUnits must match. A rate of 6 per hour with a time of 20 minutes gives the wrong answer if you plug in t = 20. Convert 20 minutes to 1/3 of an hour first.

Self-check: λ = 2 per hour. What is P(X > 1) for waiting time in hours?

P(X > 1) = e-2, which is about 0.1353.

Self-check: the mean waiting time is 5 minutes. What is λ per minute?

λ = 1/E[X] = 1/5 = 0.2 per minute.

Concept 4: The memoryless property

What it means

Imagine you have already waited 3 minutes for a bus. Does the chance that you wait at least 2 more minutes change because of the time already spent? For the exponential distribution, the answer is no. The distribution "forgets" the past. This is called the memoryless property.

Formally:

P(X > s + t | X > s) = P(X > t)

Each symbol means:

  • s is the time already waited.
  • t is the extra time we ask about.
  • P(X > s + t | X > s) is the chance of waiting longer than s + t, given that we have already waited longer than s.

Why it is true

Use the definition of conditional probability. The event "X > s + t" is contained inside "X > s", so their intersection is just "X > s + t". Then:

P(X > s + t | X > s) = P(X > s + t) / P(X > s) = e-λ(s+t) / e-λs = e-λt = P(X > t)

The exponent rules let us subtract λs from both parts. Only the part after s remains, so the past s has disappeared.

Worked example: the bus

Buses arrive at a rate of λ = 0.2 per minute, so the waiting time is exponential. You have already waited 3 minutes. Find the chance that you wait at least 2 more minutes.

  1. Identify s and t. s = 3 minutes already waited, t = 2 more minutes.
  2. Apply the memoryless property. P(X > 5 | X > 3) = P(X > 2).
  3. Compute the tail. P(X > 2) = e-0.2 × 2 = e-0.4, which is about 0.6703.
  4. Check by direct division. P(X > 5) = e-1 and P(X > 3) = e-0.6. Their ratio is e-1 / e-0.6 = e-0.4, which is the same value.

GATE loves thisWhen a question says "already waited" or "has survived so far" and the distribution is exponential, use the memoryless property to drop the past. It saves a lot of algebra.

TrapThe memoryless property is special to the exponential distribution among continuous distributions. Do not apply it to a normal or uniform distribution, where the past does matter.

The Poisson process link

If events form a Poisson process with rate λ, the time from one event to the next is exponential with mean 1/λ. The count of events in an interval of length t is Poisson with mean λt. So the two distributions describe the same process from two different angles: the count and the gap.

The Python block below checks the memoryless ratio numerically.

import math

lam = 0.2
def surv(t):
    return math.exp(-lam * t)

print(f"P(X > 5 | X > 3) = {surv(5) / surv(3):.4f}")
print(f"P(X > 2) = {surv(2):.4f}")
P(X > 5 | X > 3) = 0.6703
P(X > 2) = 0.6703

TipWhen you see a Poisson count question, ask whether the question is about the number of events or the time between them. Counts use the Poisson PMF. Waiting times use the exponential tail.

Self-check: is the memoryless property true for a uniform distribution on 0 to 10?

No. For a uniform distribution, the chance of waiting longer does depend on how long you have already waited, because the remaining range shrinks.

Self-check: buses come at λ = 0.2 per minute. What is the mean waiting time?

E[X] = 1/λ = 1/0.2 = 5 minutes.

Solved GATE-style problems

These problems are original GATE-style questions written for practice. They are not past paper questions. Work each one on paper first, then compare with the solution.

Waiting for a bus

The waiting time for a bus is exponential with mean 4 minutes. Find the probability that you wait more than 4 minutes. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. P(X > 4) for an exponential variable with mean 4.
  2. Which idea applies. The mean is 1/λ, so λ = 1/4. Then use the tail formula P(X > t) = e-λt.
  3. Work it out. λ = 1/4. P(X > 4) = e-(1/4) × 4 = e-1, which is about 0.3679, or 0.37 to two decimals.
  4. Check. The wait is exactly the mean, so the chance of waiting longer should be a bit under one half. 0.37 is below 0.5, which is reasonable.

Answer: 0.37

Select all true statements about a Poisson variable

Let X be Poisson with λ = 4. Select all that apply.

(A) E[X] = 4.
(B) Var(X) = 4.
(C) P(X = 0) = e-4.
(D) The standard deviation of X is 4.

How to think about it

  1. What is asked. Tick every true statement.
  2. Which idea applies. Poisson mean and variance are both λ, and the PMF at x = 0 is e-λ.
  3. Work it out. Option A: E[X] = λ = 4, so A is true. Option B: Var(X) = λ = 4, so B is true. Option C: P(X = 0) = e-4 × 40 / 0! = e-4, so C is true. Option D: the standard deviation is √4 = 2, not 4, so D is false.
  4. Check. Option D confuses the variance with the standard deviation. The variance is 4 and the standard deviation is its square root, 2.

Answer: (A), (B) and (C) are true. Option (D) is false.

Exactly three calls

Calls arrive at a helpline as a Poisson process at 6 per hour. Find the probability of exactly 3 calls in one hour. Give the answer correct to four decimal places.

How to think about it

  1. What is asked. P(X = 3) for a count in one hour.
  2. Which idea applies. The Poisson PMF with λ = 6 for one hour, x = 3.
  3. Work it out. P(X = 3) = e-6 × 63 / 3! = e-6 × 216 / 6 = 36 × e-6. Since e-6 is about 0.0024788, the answer is 36 × 0.0024788 = 0.089236, or 0.0892.
  4. Check. The mean count is 6, so 3 calls is in the lower tail but not extremely rare. A value near 0.09 is plausible.

Answer: 0.0892

Lifetime of a component

The lifetime of a component is exponential with mean 500 hours. Find the probability that it lasts more than 1000 hours. Give the answer correct to four decimal places.

How to think about it

  1. What is asked. P(X > 1000).
  2. Which idea applies. λ = 1/500 from the mean, then the tail formula.
  3. Work it out. P(X > 1000) = e-1000/500 = e-2 = 0.135335, which is 0.1353 to four decimals.
  4. Check. 1000 hours is twice the mean. The answer e-2 is about 0.135, a small chance, as expected for a long life.

Answer: 0.1353

Survival after a long run

NAT question. The lifetime of a component is exponential with mean 500 hours. It has already survived 300 hours. Find the probability that it survives at least another 200 hours. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. P(X > 500 | X > 300).
  2. Which idea applies. The memoryless property, which reduces the question to P(X > 200).
  3. Work it out. λ = 1/500. P(X > 200) = e-200/500 = e-0.4, which is about 0.6703, or 0.67 to two decimals.
  4. Check. The past 300 hours do not change the chance. The answer 0.67 is greater than the chance e-1 = 0.37 of surviving 500 hours from new, which is consistent with a short extra wait being likely.

Answer: 0.67

Poisson with a special ratio

A Poisson random variable X satisfies P(X = 1) = 2 P(X = 0). Find λ.

How to think about it

  1. What is asked. The rate λ that makes the two probabilities have ratio 2.
  2. Which idea applies. Write both PMF values and set up the equation.
  3. Work it out. P(X = 0) = e-λ and P(X = 1) = e-λ λ. So e-λ λ = 2 e-λ. Divide both sides by e-λ, which is never zero: λ = 2.
  4. Check. With λ = 2, P(X = 0) = e-2 and P(X = 1) = 2e-2. The ratio is 2, as required.

Answer: λ = 2

Poisson approximation for a rare fault

NAT question. A batch has 500 independent items. Each item is faulty with probability 0.004. Use the Poisson approximation to find the probability that the batch has no faulty item. Give the answer correct to four decimal places.

How to think about it

  1. What is asked. An approximation to P(X = 0) for a binomial with n = 500 and p = 0.004.
  2. Which idea applies. Poisson approximation with λ = np.
  3. Work it out. λ = 500 × 0.004 = 2. Then P(X = 0) ≈ e-2 = 0.135335, or 0.1353 to four decimals.
  4. Check. The exact binomial value is (0.996)500, which is about 0.1348. The approximation 0.1353 is close, which confirms that the approximation is good here.

Answer: 0.1353

At least two arrivals in a minute

NAT question. Requests arrive at a server as a Poisson process with rate 2 per minute. Find the probability that at least 2 requests arrive in one minute. Give the answer correct to three decimal places.

How to think about it

  1. What is asked. P(X ≥ 2) for a Poisson count with λ = 2.
  2. Which idea applies. Use the complement: P(X ≥ 2) = 1 - P(X = 0) - P(X = 1).
  3. Work it out. P(X = 0) = e-2. P(X = 1) = e-2 × 2 = 2e-2. So P(X ≥ 2) = 1 - e-2 - 2e-2 = 1 - 3e-2. Since e-2 is about 0.135335, we get 1 - 0.406006 = 0.593994, or 0.594 to three decimals.
  4. Check. The mean count is 2, so the chance of at least 2 should be somewhat above one half. 0.594 is above 0.5, which fits.

Answer: 0.594

Exam-level 1: Waiting after a quiet period (NAT, 2 marks)

NAT question. Calls reach a help desk at random times. The waiting time T, in hours, until the next call is exponential with rate λ = 3 per hour, so the mean waiting time is 1/3 hour. Ten minutes pass and no call arrives. Find the probability that the next call arrives more than 20 minutes after this point. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. P(T > 30 minutes | T > 10 minutes), to two decimal places.
  2. Which idea applies. The exponential survival function P(T > t) = e^(-λt), and the memoryless property, which says the wait already passed does not change the future wait.
  3. Work it out. Convert to hours: 10 minutes is 1/6 hour and 30 minutes is 1/2 hour. Then P(T > 1/2 | T > 1/6) = P(T > 1/2) / P(T > 1/6) = e^(-3 × 1/2) / e^(-3 × 1/6) = e^(-1.5) / e^(-0.5) = e^(-1) ≈ 0.3679. Rounded, the answer is 0.37.
  4. Check. The memoryless property says the answer equals P(T > 20 minutes) from the start, which is e^(-3 × 1/3) = e^(-1). Both routes agree. A wait longer than the mean of 20 minutes is less likely than not, so 0.37 is below one half.

Answer: 0.37

from math import exp
lam = 3.0
t1 = 10 / 60
t2 = 20 / 60
cond = exp(-lam * (t1 + t2)) / exp(-lam * t1)
print("P(T exceeds 30 min given T exceeds 10 min) =", round(cond, 4))
print("e^-(lam x 20/60) =", round(exp(-lam * t2), 4))
print("decimal to 2 places =", round(cond, 2))
P(T exceeds 30 min given T exceeds 10 min) = 0.3679
e^-(lam x 20/60) = 0.3679
decimal to 2 places = 0.37

Exam-level 2: Poisson stands in for a binomial (MCQ, 2 marks)

A website has 1000 visitors each day. Each visitor independently makes a purchase with probability 0.002, so the number of purchases X in a day is binomial with n = 1000 and p = 0.002. Because n is large and p is small, a Poisson model is a good approximation. Using the Poisson approximation, which of the following is approximately P(X ≥ 1)? (A) 0.14 (B) 0.86 (C) 0.50 (D) 0.98. Select one option.

How to think about it

  1. What is asked. P(X ≥ 1), using a Poisson model.
  2. Which idea applies. The complement rule P(X ≥ 1) = 1 - P(X = 0), and the Poisson approximation to the binomial with λ = np.
  3. Work it out. λ = 1000 × 0.002 = 2. Then P(X = 0) ≈ e^(-2) ≈ 0.1353, so P(X ≥ 1) ≈ 1 - 0.1353 = 0.8647, which rounds to 0.86. The answer is option B.
  4. Check. The mean is 2 purchases a day, so at least one purchase is likely, which fits an answer above one half. The exact binomial value is 0.8649, very close to 0.86. Why the other options fail: (A) is P(X = 0) without the complement, (C) is a guess near one half, and (D) is too high, since 1 - e^(-2) is not 0.98.

Answer: (B) 0.86

from math import exp
n = 1000
p = 0.002
lam = n * p
print("lambda = n p =", lam)
print("Poisson P(X at least 1) =", round(1 - exp(-lam), 4))
print("exact binomial P(X at least 1) =", round(1 - (1 - p) ** n, 4))
lambda = n p = 2.0
Poisson P(X at least 1) = 0.8647
exact binomial P(X at least 1) = 0.8649

Exam-level 3: Facts about an exponential time (MSQ, 2 marks)

A sensor reports a fault after a random time T, measured in minutes. The time is exponential with rate λ = 0.5 per minute, so its density is f(t) = 0.5 e^(-0.5t) for t ≥ 0. Select all the statements that are true.

  • (A) E[T] = 2 minutes
  • (B) Var(T) = 4
  • (C) P(T > 2) = e^(-1)
  • (D) The median of T is 0.5 minutes.

How to think about it

  1. What is asked. Which of the four statements are true. Select all that apply.
  2. Which idea applies. For an exponential with rate λ: E[T] = 1/λ, Var(T) = 1/λ², P(T > t) = e^(-λt), and the median m solves P(T ≤ m) = 0.5.
  3. Work it out. E[T] = 1/0.5 = 2, so (A) is true. Var(T) = 1/0.5² = 4, so (B) is true. P(T > 2) = e^(-0.5 × 2) = e^(-1), so (C) is true. For the median, 1 - e^(-0.5m) = 0.5 gives m = ln 2 / 0.5 = 2 ln 2 ≈ 1.386 minutes, so (D) is false.
  4. Check. The median must be below the mean for a right-skewed exponential, and 1.386 is below 2, which is consistent. Option (D) confuses the median with the rate 0.5.

Answer: A, B and C

from math import exp, log
lam = 0.5
print("E[T] =", 1 / lam)
print("Var(T) =", 1 / lam ** 2)
print("P(T exceeds 2) =", round(exp(-lam * 2), 6), "and e^-1 =", round(exp(-1), 6))
print("median =", round(log(2) / lam, 4))
E[T] = 2.0
Var(T) = 4.0
P(T exceeds 2) = 0.367879 and e^-1 = 0.367879
median = 1.3863

Exam-level 4: Poisson failures over five days (NAT, 2 marks)

NAT question. A small server fails at random times. Failures follow a Poisson process with rate 0.4 per day, so the number of failures in any period is Poisson distributed with mean 0.4 times the length of that period in days. Over a 5-day period, let X be the number of failures. Given that there are at least 2 failures in the period, find the probability that there are exactly 2. Give the answer correct to two decimal places.

How to think about it

  1. What is asked. P(X = 2 | X ≥ 2), to two decimal places.
  2. Which idea applies. The Poisson PMF e^(-λ) λ^k / k!, the complement rule for the tail, and the conditional probability rule.
  3. Work it out. The mean over 5 days is λ = 0.4 × 5 = 2. P(X = 2) = e^(-2) × 2² / 2! = 2e^(-2) ≈ 0.2707. P(X ≥ 2) = 1 - P(X = 0) - P(X = 1) = 1 - e^(-2) - 2e^(-2) = 1 - 3e^(-2) ≈ 0.5940. So the answer is 0.2707 / 0.5940 ≈ 0.4557, which is 0.46 to two decimal places.
  4. Check. The answer is between 0 and 1, and it is below one half. That fits, since the tail from 3 upward also carries weight (about 0.32 of the total).

Answer: 0.46

from math import exp, factorial
lam = 0.4 * 5
def pois(k):
    return exp(-lam) * lam ** k / factorial(k)
tail = 1 - pois(0) - pois(1)
ans = pois(2) / tail
print("lambda =", round(lam, 2))
print("P(X = 2) =", round(pois(2), 6))
print("P(X at least 2) =", round(tail, 6))
print("P(X = 2 given X at least 2) =", round(ans, 4))
print("to 2 dp:", round(ans, 2))

Summary

Rate λ
The average number of events per unit of time or space.
Poisson distribution
The distribution of event counts in a fixed interval, with P(X = x) = e-λ λx / x!.
Poisson mean and variance
Both equal λ.
Poisson approximation
For large n and small p, Bin(n, p) is close to Poisson with λ = np.
Factorial
x! = x × (x - 1) × ... × 1, with 0! = 1.
Exponential distribution
The distribution of waiting times with density λ e-λx for x ≥ 0.
Exponential tail
P(X > t) = e-λt.
Exponential mean and variance
E[X] = 1/λ and Var(X) = 1/λ².
Memoryless property
P(X > s + t | X > s) = P(X > t), so the past is forgotten.
Poisson process
Events at a steady rate, independent of each other. Counts are Poisson and gaps are exponential.
Probability density
A curve whose area gives probabilities for a continuous variable.
Complement for "at least"
P(X ≥ 2) = 1 - P(X = 0) - P(X = 1) for a Poisson count.
Unit matching
The rate and the time must use the same unit before you compute.

Remember these

  1. A Poisson count has mean λ and variance λ.
  2. Scale the rate to the interval in the question before you use the Poisson formula.
  3. For large n and small p, use Poisson with λ = np as an approximation to the binomial.
  4. The exponential tail P(X > t) = e-λt answers most waiting-time questions.
  5. The exponential mean is 1/λ, so a mean given in minutes gives λ = 1/mean.
  6. The exponential is the only continuous distribution with the memoryless property.
  7. Counts use the Poisson PMF, and waiting times use the exponential tail.
