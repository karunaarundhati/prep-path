Initial and boundary value problems

A differential equation describes how something changes. To get one specific answer from the many answers an equation allows, you must add extra facts called initial or boundary conditions. This page explains the two kinds of conditions, shows how to use them to find the constants, and gives the checks GATE Robotics and Automation questions expect.

The idea in plain words

Suppose you throw a ball up in the air. The rule of motion says the ball's speed changes all the time because gravity pulls it down. A rule that links a quantity to how fast it changes is called a differential equation. Engineers use these rules for motors, springs, heaters, robot arms and electrical circuits.

Here is the catch. The rule alone does not tell you one exact answer. It tells you a whole family of possible answers. To pick the one that matches your real situation, you need a few extra facts. These facts are called conditions. For example, you might know where the ball starts, or how fast it starts moving.

Think of a family of roads that all have the same shape but start at different places. The rule describes the shape. The condition tells you which road you are on. In this topic you will learn two main kinds of conditions:

  • Initial conditions give information at one starting point. This leads to an initial value problem (IVP).
  • Boundary conditions give information at two different points, often the two ends of a rod or a string. This leads to a boundary value problem (BVP).

The method is always the same. First find the general family of answers. Then apply the conditions to find the constants. The end result is the particular answer you need.

Why this matters for GATE. In the Robotics and Automation paper, differential equations appear in control of motors, vibration of machines, and heat flow in parts. Questions often give you a general solution with unknown constants and then ask you to use the conditions to find those constants, or to find a value of the solution at a given point. Many marks are earned by simply applying the conditions correctly.

Key terms

Read this list once now. Come back to it whenever a word feels unclear.

Derivative
The rate of change. If y is a quantity, y' (read "y prime") is how fast y changes as x changes. Formally, y' = dy/dx.
Differential equation
An equation that contains a function and one or more of its derivatives. Example: y' = 2x.
Order
The highest derivative that appears in the equation. y'' + y = 0 has order 2. y' = 2x has order 1.
Solution
A function y(x) that makes the equation true for every x in the range of interest when you put it in.
General solution
A solution that still has arbitrary constants such as C1 and C2. An equation of order n usually has a general solution with n constants.
Arbitrary constant
A letter, usually C or C1, C2, that can stand for any number until a condition fixes it.
Particular solution
A solution with the constants fixed to specific numbers by using the conditions.
Condition
An extra fact about the solution, such as the value of y at some point. It is used to find the constants.
Initial condition
A condition where all the given information is at one single point x0. Example: y(0) = 1 and y'(0) = 0.
Boundary condition
A condition where the given information is at two or more different points. Example: y(0) = 0 and y(π) = 0.
Initial value problem (IVP)
A differential equation together with initial conditions. The aim is to find the solution that starts from the given values.
Boundary value problem (BVP)
A differential equation together with boundary conditions. The aim is to find a solution that meets the conditions at the boundary points.
Existence
The question "does at least one solution exist?"
Uniqueness
The question "is there only one solution?" If there are many, the problem is not unique.
Linear equation
An equation where y and its derivatives appear only to the first power and are not multiplied together. Example: y'' + 4y = 0 is linear. y y' = 1 is not.
Homogeneous
A linear equation whose right-hand side is zero. Example: y'' + 4y = 0.
Trigonometric function
Functions such as sin x and cos x. Their derivatives repeat in a cycle: the derivative of sin x is cos x, and the derivative of cos x is -sin x.

Step 1: What a solution looks like

Starting with the simplest case

Begin with the simplest possible differential equation. Suppose you are told that the slope of a curve at any point x is 2x. Written in symbols:

y' = 2x

Here y is the unknown function, y' is its slope, and x is the position along the horizontal axis. To find y, you do the reverse of differentiation, which is called integration. Integrating 2x gives x2, but you must also add a constant, because the derivative of any constant is zero:

y = x2 + C

Here C is the arbitrary constant. Every value of C gives a parabola shifted up or down. All of these curves have the same slope rule y' = 2x, so all of them are solutions. This is the general solution.

Checking a solution

Always check your answer by putting it back into the equation. Take y = x2 + C. Its derivative is y' = 2x + 0 = 2x. That matches the equation, so the check passes for every C.

Counting the constants

The order tells you how many constants to expect. A first order equation such as y' = 2x has one constant. A second order equation such as y'' + y = 0 has two constants. Here is the second order example in full.

y'' + y = 0

This says: the second derivative of y plus y itself is zero. Functions whose second derivative is the negative of themselves are sine and cosine. The general solution is

y = C1 cos x + C2 sin x

Let us check it step by step. Write y = C1 cos x + C2 sin x.

  1. The first derivative is y' = -C1 sin x + C2 cos x.
  2. The second derivative is y'' = -C1 cos x - C2 sin x.
  3. Add y and y'': (-C1 cos x - C2 sin x) + (C1 cos x + C2 sin x) = 0.

The result is zero for every x and every choice of C1 and C2. So the general solution is correct.

Key ideaA general solution is a family. The number of constants equals the order of the equation. Conditions are needed to pick one member of the family.

Question: How many constants does the general solution of a third order equation have?

Three. Each integration step adds one constant, and a third order equation needs three integrations. The usual answer is n constants for an order n equation.

Question: Is y = 3 cos x a solution of y'' + y = 0?

Yes. Here C1 = 3 and C2 = 0. The general solution allows this choice, so y = 3 cos x is one particular solution.

Step 2: Initial value problems (IVP)

The idea

An initial value problem gives you everything at one point. The usual point is x = 0, but it can be any x0. Think of it as knowing exactly where a moving object starts and how fast it starts moving. Once you know the starting position and starting speed, the whole future path is fixed.

The general pattern for a second order IVP is:

y'' + p y' + q y = 0, with y(x0) = y0 and y'(x0) = y1

Here p and q are fixed numbers, y0 is the given value of y at the start, and y1 is the given value of the slope at the start. For a first order equation you need only one initial condition.

Worked example 1: first order

Solve y' = 2x with the initial condition y(1) = 3.

  1. Find the general solution. From Step 1, y = x2 + C.
  2. Apply the condition. The condition says y(1) = 3. Put x = 1 into the general solution: y(1) = 12 + C = 1 + C.
  3. Set equal. 1 + C = 3, so C = 2.
  4. Write the particular solution. y = x2 + 2.
  5. Check. y' = 2x, which matches. And y(1) = 1 + 2 = 3, which matches the condition.

Worked example 2: second order

Solve y'' + 4y = 0 with y(0) = 2 and y'(0) = 0.

  1. General solution. For y'' + 4y = 0, the solutions are cos 2x and sin 2x, because the second derivative of cos 2x is -4 cos 2x. So y = C1 cos 2x + C2 sin 2x.
  2. Derivative. y' = -2C1 sin 2x + 2C2 cos 2x. The factor 2 comes from the inner derivative of 2x.
  3. Use y(0) = 2. At x = 0, cos 0 = 1 and sin 0 = 0. So y(0) = C1. Therefore C1 = 2.
  4. Use y'(0) = 0. At x = 0, y'(0) = 0 + 2C2 = 2C2. Set 2C2 = 0, so C2 = 0.
  5. Particular solution. y = 2 cos 2x.

TrapStudents often forget the inner derivative. The derivative of cos 2x is -2 sin 2x, not -sin 2x. Always multiply by the derivative of the inside, which is 2 here.

A short Python check

Numbers are easy to get wrong by hand, so we check the answer with a small program. The program evaluates the solution and its derivative at a few points and tests the equation. Here the equation is y' + 2y = 0 with y(0) = 4, which has the solution y = 4e-2x.

import math

def y(x):
    return 4 * math.exp(-2 * x)

def dy(x):
    return -8 * math.exp(-2 * x)

print("y(0) =", y(0))
print("y'(0) =", dy(0))
print("y'(1) + 2*y(1) is zero:", abs(dy(1) + 2 * y(1)) < 1e-9)
y(0) = 4.0
y'(0) = -8.0
y'(1) + 2*y(1) is zero: True

TipWrite the general solution, then the derivative, then the two conditions on separate lines. Keeping each step on its own line prevents most mistakes.

Question: Solve y' = 6x with y(0) = 5. What is y(2)?

Integrate: y = 3x2 + C. Then y(0) = C = 5, so y = 3x2 + 5. At x = 2, y = 3(4) + 5 = 17.

Question: Why do we need two conditions for a second order IVP?

The general solution has two constants, C1 and C2. Each condition gives one equation, so two equations are needed to fix two unknowns.

Step 3: Boundary value problems (BVP)

The idea

A boundary value problem gives information at two different points. A common example is a string tied at both ends, or a metal rod whose ends are kept at fixed temperatures. You know the state at the two ends, but you do not know what happens in between.

This changes the algebra. In an IVP both conditions are at the same point, so you get two simple equations. In a BVP the two conditions are at different points, so the equations contain values like cos(π) and sin(π). These can give surprising results. There may be exactly one solution, many solutions, or no solution at all.

Worked example 3: a BVP with one solution

Solve y'' + 4y = 0 with y(0) = 1 and y(π/4) = 0.

  1. General solution. y = C1 cos 2x + C2 sin 2x, as before.
  2. First condition. y(0) = C1 = 1.
  3. Second condition. At x = π/4, 2x = π/2. So cos(π/2) = 0 and sin(π/2) = 1. Then y(π/4) = C1(0) + C2(1) = C2.
  4. Set equal. C2 = 0.
  5. Particular solution. y = cos 2x. Check: y(0) = 1 and y(π/4) = cos(π/2) = 0. Both conditions hold.

Worked example 4: a BVP with infinitely many solutions

Solve y'' + y = 0 with y(0) = 0 and y(π) = 0.

  1. General solution. y = C1 cos x + C2 sin x.
  2. First condition. y(0) = C1 cos 0 + C2 sin 0 = C1. So C1 = 0.
  3. Second condition. y(π) = C1 cos π + C2 sin π = C1(-1) + C2(0) = -C1. Since C1 = 0, this is 0. The condition is satisfied automatically.
  4. What is left. C2 never gets fixed. Every solution y = C2 sin x works. So there are infinitely many solutions.

Key ideaIn a BVP, the number of solutions can be one, none, or infinitely many. An IVP with reasonable coefficients usually has exactly one solution. Always check for this.

Worked example 5: a BVP with no solution

Solve y'' + y = 0 with y(0) = 0 and y(π) = 1.

  1. From the first condition, C1 = 0, as in Example 4.
  2. The second condition gives y(π) = -C1 = 0.
  3. But the problem says y(π) = 1. We need 0 = 1, which is impossible.
  4. So this BVP has no solution.

TrapA question may say "find the solution" without saying it exists. For a BVP, first check whether your conditions can be met at all. A contradiction like 0 = 1 means there is no solution.

Question: For y'' + y = 0 with y(0) = 0 and y(π/2) = 5, is there a solution?

Yes, one solution. C1 = 0 from y(0) = 0. Then y(π/2) = C2 sin(π/2) = C2 = 5. So y = 5 sin x is the unique solution.

Question: Why does y(π) involve cos π?

Because the second condition is at x = π, and the general solution is written in terms of cos x and sin x. At x = π, cos π = -1 and sin π = 0. Substituting the boundary point into the general solution is always the method.

Step 4: Existence and uniqueness, briefly

Why this question matters

Before you spend time solving a problem, it helps to know whether a solution exists and whether it is the only one. In engineering, a problem with no answer or many answers is a sign that the model is wrong or incomplete. GATE sometimes asks about these ideas in a short, conceptual way.

A standard result, called the existence and uniqueness theorem, says the following in plain words. Take a first order equation written as y' = f(x, y) with the condition y(x0) = y0. If the function f and its partial derivative with respect to y are continuous near the point (x0, y0), then a solution exists near x0, and it is the only one.

y' = f(x, y), y(x0) = y0, with f and ∂f/∂y continuous near (x0, y0)

Here ∂f/∂y means "how f changes when only y changes". It is a partial derivative, which means we treat x as fixed while we differentiate with respect to y.

A case where uniqueness fails

Consider the IVP y' = 3y2/3 with y(0) = 0. Two different functions both solve it, at least for x ≥ 0:

  • y = 0. Its derivative is 0, and 3(0)2/3 = 0. This works.
  • y = x3. Its derivative is 3x2. For x ≥ 0, y2/3 = (x3)2/3 = x2, so 3y2/3 = 3x2. This works too.

Two solutions from one starting point means uniqueness fails. The reason is that ∂f/∂y = 2y-1/3 is not continuous at y = 0. The function f is fine, but its slope with respect to y blows up there.

GATE loves thisWhen a question asks whether the IVP "has a unique solution", look at whether f and ∂f/∂y are continuous near the starting point. If ∂f/∂y is not continuous, uniqueness may fail. Many GATE options use this idea.

Question: Does y' = 2y with y(0) = 1 have a unique solution?

Yes. Here f(x, y) = 2y and ∂f/∂y = 2. Both are continuous everywhere, so the theorem applies. The unique solution is y = e2x.

Question: In a BVP, can a solution fail to be unique even when the equation is nice?

Yes. Example 4 showed that y'' + y = 0 with y(0) = 0 and y(π) = 0 has infinitely many solutions. The equation is nice, but the boundary points are special, so the usual IVP uniqueness theorem does not apply to BVPs.

Step 5: Finding constants step by step

A checklist you can use in the exam

GATE questions in this area follow a predictable pattern. Use this checklist every time:

  1. Write the general solution with constants C1, C2, and so on, one for each order.
  2. Differentiate once if you need a derivative condition. Write the derivative on its own line.
  3. Substitute each condition. Each substitution gives one equation.
  4. Solve the equations for the constants. For two constants you get a 2 by 2 system.
  5. Write the particular solution and check it against every condition.

Solving a 2 by 2 system with a program

When two conditions give two equations in C1 and C2, the system has the form a11C1 + a12C2 = b1 and a21C1 + a22C2 = b2. Cramer's rule gives the answer:

det = a11a22 - a12a21, C1 = (b1a22 - a12b2)/det, C2 = (a11b2 - b1a21)/det

The example below uses the equation y'' + 4y = 0, whose general solution is y = C1 cos 2x + C2 sin 2x. The conditions are y(0) = 2 and y'(0) = 6. Substituting gives C1 = 2 and 2C2 = 6. The program uses exact fractions so there is no rounding.

from fractions import Fraction

# Equations:  1*C1 + 0*C2 = 2   (from y(0) = 2)
#             0*C1 + 2*C2 = 6   (from y'(0) = 6)
a11, a12, b1 = Fraction(1), Fraction(0), Fraction(2)
a21, a22, b2 = Fraction(0), Fraction(2), Fraction(6)

det = a11 * a22 - a12 * a21
C1 = (b1 * a22 - a12 * b2) / det
C2 = (a11 * b2 - b1 * a21) / det
print("C1 =", C1)
print("C2 =", C2)
C1 = 2
C2 = 3

TipWrite each substitution as a separate equation before you solve anything. Two clear equations are much easier to solve than one long line.

Applying the checklist to a full problem

Solve y'' + 4y = 0 with y(0) = 2 and y'(0) = 6. Follow the checklist.

  1. General solution. y = C1 cos 2x + C2 sin 2x.
  2. Derivative. y' = -2C1 sin 2x + 2C2 cos 2x.
  3. Substitute. y(0) = C1 = 2. And y'(0) = 2C2 = 6.
  4. Solve. C1 = 2 and C2 = 3. This matches the program output above.
  5. Particular solution and check. y = 2 cos 2x + 3 sin 2x. At x = 0, y = 2 and y' = 6, as required.
Question: A student gets C1 = 2 and C2 = 0 for an IVP. The condition y'(0) was written as y'(0) = 0. Is this consistent?

Yes. With y'(0) = 2C2 = 0, we get C2 = 0. The student's values are right, and this matches Worked example 2.

Question: What is the first step of the checklist for any problem?

Write the general solution with the right number of constants. You cannot apply conditions until you have the family of solutions.

Solved GATE-style problems

These problems are original, written in the style of GATE questions. They are not past exam questions. Try each one on paper before you read the answer.

Integrate from a starting value

Solve y' = 4x3 with y(0) = 5. What is y(1)? (Answer type: NAT, a number.)

How to think about it

  1. What is asked. The value of y at x = 1.
  2. Which idea applies. This is a first order IVP. Integrate once and use the condition to find the constant.
  3. Work it out. Integrating 4x3 gives x4, so y = x4 + C. The condition y(0) = 5 gives 0 + C = 5, so C = 5. Then y(1) = 1 + 5 = 6.
  4. Check. y' = 4x3, which matches. And y(0) = 0 + 5 = 5.

Answer: y(1) = 6.

Two integrations, two conditions

Solve y'' = 6x with y(0) = 1 and y'(0) = 2. What is y(1)? (Answer type: NAT, a number.)

How to think about it

  1. What is asked. The value of y at x = 1.
  2. Which idea applies. This is a second order IVP. Integrate twice, adding one constant each time, then use the two conditions.
  3. Work it out. First integration: y' = 3x2 + C1. Use y'(0) = 2: C1 = 2, so y' = 3x2 + 2. Second integration: y = x3 + 2x + C2. Use y(0) = 1: C2 = 1, so y = x3 + 2x + 1. At x = 1, y = 1 + 2 + 1 = 4.
  4. Check. y'' = 6x, which matches. And y(0) = 1 and y'(0) = 2 both hold.

Answer: y(1) = 4.

Which statements about y'' + 9y = 0 are true?

The equation y'' + 9y = 0 has general solution y = C1 cos 3x + C2 sin 3x. Select all that apply.

(A) The BVP with y(0) = 0 and y(π) = 0 has infinitely many solutions.
(B) The IVP with y(0) = 1 and y'(0) = 0 has the solution y = cos 3x.
(C) The BVP with y(0) = 0 and y(π/3) = 1 has a solution.
(D) The IVP with y(0) = 2 and y'(0) = 3 has the solution y = 2 cos 3x + sin 3x.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which of the four statements are true.
  2. Which idea applies. Use the general solution, then test each set of conditions separately.
  3. Work it out. (A) y(0) = C1 = 0. Then y(π) = C2 sin 3π = 0 for any C2, because sin 3π = 0. So C2 is free, giving infinitely many solutions. True. (B) y(0) = C1 = 1. Also y'(0) = 3C2 = 0, so C2 = 0. The solution is cos 3x. True. (C) y(0) = C1 = 0. Then y(π/3) = C2 sin π = 0, but we need 1. Impossible. False. (D) y(0) = C1 = 2. Also y'(0) = 3C2 = 3, so C2 = 1. The solution is 2 cos 3x + sin 3x. True.
  4. Check. Statement (C) is the only one with a contradiction, which is the kind of BVP that has no solution. That matches Worked example 5.

Answer: (A), (B) and (D).

Exponential solutions with two conditions

Solve y'' - y = 0 with y(0) = 3 and y'(0) = 1. Find y(ln 2). (Answer type: NAT, a number. The answer is exact.)

How to think about it

  1. What is asked. The value of y at x = ln 2, where ln is the natural logarithm.
  2. Which idea applies. Use the exponential form for y'' - k2y = 0 with k = 1, which is y = C1ex + C2e-x.
  3. Work it out. The derivative is y' = C1ex - C2e-x. At x = 0: y(0) = C1 + C2 = 3 and y'(0) = C1 - C2 = 1. Adding the two equations gives 2C1 = 4, so C1 = 2. Then C2 = 1. So y = 2ex + e-x. At x = ln 2, eln 2 = 2 and e-ln 2 = 1/2. So y = 2(2) + 1/2 = 4.5.
  4. Check. The program below evaluates the answer numerically.
import math

C1, C2 = 2, 1
x = math.log(2)
print(round(C1 * math.exp(x) + C2 * math.exp(-x), 6))
4.5

Answer: y(ln 2) = 4.5.

Decay from a starting value

Solve y' + 2y = 0 with y(0) = 4. Find y(1), rounded to four decimal places. (Answer type: NAT, a number.)

How to think about it

  1. What is asked. The value of y at x = 1, to four decimal places.
  2. Which idea applies. This is first order linear with no right-hand side. The formula is y = Ce-kx with k = 2.
  3. Work it out. The general solution is y = Ce-2x. The condition y(0) = 4 gives C e0 = C = 4. So y = 4e-2x. At x = 1, y(1) = 4e-2. Since e-2 is about 0.135335, the value is about 0.54134.
  4. Check. The program prints the value directly.
import math

print(round(4 * math.exp(-2), 4))
0.5413

Answer: y(1) = 4e-2, which is 0.5413 to four decimal places.

Largest value of a solution

Solve y'' + 4y = 0 with y(0) = 1 and y'(0) = 2. Find the largest value that y(x) takes over all real x, rounded to four decimal places. (Answer type: NAT, a number.)

How to think about it

  1. What is asked. The maximum of y(x), not y at one point.
  2. Which idea applies. Find the particular solution first. Then combine the cosine and sine terms into one sine or cosine with an amplitude. The amplitude is the largest value.
  3. Work it out. General solution: y = C1 cos 2x + C2 sin 2x. From y(0) = 1, C1 = 1. From y'(0) = 2C2 = 2, C2 = 1. So y = cos 2x + sin 2x. For a sum a cos θ + b sin θ, the largest value is √(a2 + b2). Here that is √(1 + 1) = √2, which is about 1.4142. The program below samples the function to confirm.
  4. Check. The sampled maximum should be close to √2.
import math

best = max(math.cos(2 * x) + math.sin(2 * x) for x in [i * 0.0001 for i in range(31416)])
print(round(best, 4))
1.4142

Answer: the largest value is √2, which is 1.4142 to four decimal places.

Where uniqueness fails

Consider the IVP y' = 3y2/3 with y(0) = 0, for x ≥ 0. Select all that apply.

(A) y = 0 is a solution of the IVP.
(B) y = x3 is a solution of the IVP for x ≥ 0.
(C) The IVP has exactly one solution for x ≥ 0.
(D) The existence and uniqueness theorem does not apply, because ∂f/∂y is not continuous at y = 0.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which statements are true about this IVP.
  2. Which idea applies. Test the candidate solutions directly. Then check the hypothesis of the uniqueness theorem by computing ∂f/∂y.
  3. Work it out. (A) If y = 0, the left side is 0 and the right side is 3(0)2/3 = 0. True. (B) If y = x3, the left side is 3x2. The right side is 3(x3)2/3 = 3x2 for x ≥ 0. True. (C) Two different solutions exist, so the solution is not unique. False. (D) Here f(x, y) = 3y2/3, so ∂f/∂y = 2y-1/3. This blows up as y approaches 0, so it is not continuous at y = 0. The theorem's hypothesis fails. True.
  4. Check. Two different solutions from one starting point is the direct proof that uniqueness fails, so (C) must be false.

Answer: (A), (B) and (D).

Exam-level practice

Exam-level 1: Boundary value problem (NAT, 2 marks)

Solve y″ = 6x on 0 ≤ x ≤ 1 with y(0) = 0 and y(1) = 2. Find y(0.5).

How to think about it

  1. What is asked. The solution value at the midpoint.
  2. Which idea applies. Integrate twice: y = x³ + Ax + B.
  3. Work it out. y(0) = B = 0 and y(1) = 1 + A = 2, so A = 1. y(0.5) = 0.125 + 0.5 = 0.625.
  4. Check. y″ = 6x and both ends match.

Answer: 0.625.

Exam-level 2: Eigenvalue BVP (MCQ, 2 marks)

For y″ + λy = 0 with y(0) = 0 and y(π) = 0, nonzero solutions exist exactly when (A) λ = n, n = 1, 2, ... (B) λ = n², n = 1, 2, ... (C) λ < 0 (D) λ = 0

How to think about it

  1. What is asked. Which λ give nontrivial solutions.
  2. Which idea applies. For λ > 0, y = A cos √λ x + B sin √λ x. y(0) = 0 gives A = 0.
  3. Work it out. y(π) = B sin(√λ π) = 0 needs √λ = n, so λ = n². For λ ≤ 0 only y = 0 fits.
  4. Check. n = 1 gives y = sin x, which vanishes at 0 and π.

Answer: (B).

Exam-level 3: IVP uniqueness (MSQ, 2 marks)

Which initial value problems have a unique solution near x = 0 by the Picard theorem? (A) y′ = x² + y², y(0) = 0 (B) y′ = √|y|, y(0) = 0 (C) y′ = sin(xy), y(0) = 1 (D) y′ = y1/3, y(0) = 0

How to think about it

  1. What is asked. Which right-hand sides are Lipschitz in y near the initial point.
  2. Which idea applies. A continuous ∂f/∂y near the point is enough for uniqueness.
  3. Work it out. (A) ∂f/∂y = 2y, continuous. Unique. (B) Both y = 0 and y = x²/4 (x ≥ 0) work. Not unique. (C) ∂f/∂y = x cos(xy), continuous. Unique. (D) y = 0 and y = (2x/3)3/2 both work. Not unique.
  4. Check. (B) and (D) fail because the derivative of the right side blows up at y = 0.

Answer: (A) and (C).

Summary

Differential equation
An equation linking a function to its derivatives. It describes how something changes.
Order
The highest derivative in the equation.
General solution
A family of solutions with arbitrary constants. An order n equation usually has n constants.
Particular solution
One member of the family, with the constants fixed by conditions.
Condition
An extra fact about the solution used to find the constants.
Initial condition
A condition given at a single point.
Boundary condition
A condition given at two or more different points.
Initial value problem (IVP)
A differential equation with initial conditions. Usually it has one solution.
Boundary value problem (BVP)
A differential equation with boundary conditions. It can have one, none, or infinitely many solutions.
Existence
Whether at least one solution exists.
Uniqueness
Whether there is only one solution.
Existence and uniqueness theorem
If f and ∂f/∂y are continuous near the starting point, the first order IVP has a unique solution nearby.
Partial derivative
The rate of change of a function with respect to one variable, with the other variables held fixed.
Homogeneous linear equation
A linear equation whose right-hand side is zero.
Cramer's rule
A formula that solves a 2 by 2 linear system using determinants.
Arbitrary constant
A letter such as C that stands for any number until conditions fix it.

Remember these

  1. The number of constants in the general solution equals the order of the equation.
  2. An IVP gives all conditions at one point. A BVP gives them at two or more points.
  3. A BVP can have one solution, no solution, or infinitely many solutions. Always check.
  4. After integrating or differentiating, write each condition as a separate equation.
  5. Always check the particular solution against every condition and against the equation.
  6. If ∂f/∂y is not continuous at the starting point, uniqueness may fail.
