Higher-order linear DEs with constant coefficients

A linear differential equation with constant coefficients has the form a y'' + b y' + c y = f(x), where a, b and c are fixed numbers. These equations describe springs, RLC circuits and robot joints with damping. The method is to guess that the solution has the form e^(rx), which turns the calculus problem into an algebra problem with a quadratic (or higher-degree) equation for r.

The idea in plain words

Picture a mass hanging on a spring with a damper. The position of the mass depends on how the spring pulls, how the damper slows it, and what outside force pushes on it. Each of these effects is a term involving y, its first derivative y′, or its second derivative y″. Adding them up gives a second-order linear equation with constant coefficients.

The coefficients a, b and c do not change with x. That is what "constant coefficients" means, and it is the key simplification. Because the coefficients are fixed, a clever guess works: try y = erx. Its derivatives are just multiples of itself, so substituting the guess turns the calculus problem into a polynomial problem in r.

Everyday picture: a swing that is pushed. Left alone, it slows and settles (the homogeneous part). Pushed rhythmically by a motor, it follows the push (the particular part). The full motion is the sum of the two.

Why it matters for GATE RA: vibration, control and circuit questions reduce to these equations. Marks come from finding the roots, writing the general solution in the right form for the root type, and then using initial conditions.

Key terms

Order
Plain meaning: the highest derivative in the equation. Precise definition: n for an equation containing y(n) and no higher derivative.
Constant coefficients
Plain meaning: the numbers in front of y, y′ and y″ do not change with x. Precise definition: a, b, c, and so on, are fixed real numbers.
Homogeneous equation
Plain meaning: the equation with nothing on the right side. Precise definition: a y″ + b y′ + c y = 0.
Characteristic equation
Plain meaning: the polynomial you get by replacing each derivative with a power of r. Precise definition: a r² + b r + c = 0 for the second-order case.
Root
Plain meaning: a value of r that makes the characteristic equation zero. Precise definition: a solution r of the characteristic polynomial.
Complementary function yh
Plain meaning: the solution of the homogeneous equation. Precise definition: the general solution of a y″ + b y′ + c y = 0.
Particular integral yp
Plain meaning: one specific solution that produces the right side. Precise definition: any single function that satisfies the full non-homogeneous equation.
General solution
Plain meaning: every possible solution in one formula. Precise definition: y = yh + yp, with constants to fix.
Undetermined coefficients
Plain meaning: guess the shape of yp and find its unknown numbers. Precise definition: a method that assumes yp has the same form as the right side, with unknown coefficients.
Resonance (in this method)
Plain meaning: the guess clashes with the homogeneous solution. Precise definition: when the trial form already solves the homogeneous equation, so it must be multiplied by x (or x²).

Part 1: The characteristic equation and the homogeneous solution

Start with the homogeneous equation:

a y″ + b y′ + c y = 0

Try y = erx. Then y′ = r erx and y″ = r² erx. Substituting:

a r² erx + b r erx + c erx = 0

The factor erx is never zero, so divide it out. This leaves the characteristic equation:

a r² + b r + c = 0

Solve this quadratic for r. The type of the roots decides the form of the general solution.

RootsDiscriminant b² − 4acGeneral solution yh
Two distinct real roots r1, r2Greater than 0C1 er1 x + C2 er2 x
Repeated real root rEqual to 0(C1 + C2 x) erx
Complex pair α ± iβLess than 0eαx (C1 cos βx + C2 sin βx)

Case 1: distinct real roots

Solve y″ − 3y′ + 2y = 0. The characteristic equation is r² − 3r + 2 = 0, which factors as (r − 1)(r − 2) = 0. So r = 1 or r = 2, and y = C1 ex + C2 e2x.

Check: for y = e2x, y″ − 3y′ + 2y = 4e2x − 6e2x + 2e2x = 0. ✓

Case 2: a repeated real root

Solve y″ − 4y′ + 4y = 0. The characteristic equation is r² − 4r + 4 = (r − 2)² = 0, so r = 2 is a double root. Using only e2x is not enough, because only one function would appear. The second solution is x e2x. So y = (C1 + C2 x) e2x.

Check the second function: let y = x e2x. Then y′ = e2x + 2x e2x and y″ = 4e2x + 4x e2x. So y″ − 4y′ + 4y = (4 + 4x − 4 − 8x + 4x) e2x = 0. ✓

Case 3: complex roots

Solve y″ + 4y = 0. The characteristic equation is r² + 4 = 0, so r = ±2i. Here α = 0 and β = 2. The general solution is y = C1 cos 2x + C2 sin 2x. The sine and cosine come from e2ix = cos 2x + i sin 2x, which is Euler's formula.

Everyday picture: a spring with no damping. It oscillates forever at a fixed frequency. The β in the solution is that frequency.

Higher order

For an n-th order equation, the characteristic polynomial has degree n. Each distinct real root r gives erx. A repeated root r with multiplicity m gives erx, x erx, up to xm−1 erx. A complex pair gives the cos and sin pattern, with x multiplying them if the pair is repeated.

Example: y‴ − y″ = 0. The characteristic equation is r³ − r² = r²(r − 1) = 0. The roots are 0 (double) and 1. So y = C1 + C2 x + C3 ex.

import math

def residual(y, x, h=1e-4):
    # y'' - 3y' + 2y for the function y
    d1 = (y(x + h) - y(x - h)) / (2 * h)
    d2 = (y(x + h) - 2 * y(x) + y(x - h)) / (h * h)
    return d2 - 3 * d1 + 2 * y(x)

def y_repeated(x):
    return x * math.exp(2 * x)

# check the repeated-root solution of y'' - 4y' + 4y = 0 at a few points
def residual_rep(x, h=1e-4):
    d1 = (y_repeated(x + h) - y_repeated(x - h)) / (2 * h)
    d2 = (y_repeated(x + h) - 2 * y_repeated(x) + y_repeated(x - h)) / (h * h)
    return d2 - 4 * d1 + 4 * y_repeated(x)

print("distinct roots solution OK:", all(abs(residual(lambda t: math.exp(2 * t), x)) < 1e-3 for x in [0.0, 0.5, 1.0]))
print("repeated root solution OK:", all(abs(residual_rep(x)) < 1e-2 for x in [0.0, 0.5, 1.0]))
distinct roots solution OK: True
repeated root solution OK: True

TrapDo not write C1 e2x + C2 e2x for a repeated root. The two terms merge, so you need x e2x for the second independent solution.

Key ideaThe sign of the discriminant b² − 4ac decides the type of the roots. Compute it first, and the form of the answer follows.

What is the general solution of y″ − 5y′ + 6y = 0?

r² − 5r + 6 = (r − 2)(r − 3) = 0, so r = 2 and 3. The solution is y = C1 e2x + C2 e3x.

For y″ + 2y′ + 5y = 0, what is the discriminant?

b² − 4ac = 4 − 20 = −16, which is negative, so the roots are complex: −1 ± 2i.

Part 2: Particular solutions by undetermined coefficients

Now the full equation with a right side:

a y″ + b y′ + c y = f(x)

The general solution is y = yh + yp. We already know yh from Part 1. The task is to find one particular solution yp.

The method of undetermined coefficients works when f(x) is one of a few standard forms. Guess a yp of the same family, with unknown coefficients, substitute it in, and match the terms.

Right side f(x)Trial yp
Polynomial of degree nPolynomial of degree n, with unknown coefficients
k esxA esx
k cos βx or k sin βxA cos βx + B sin βx
Polynomial times esxPolynomial times esx, same degree

Resonance rule. If the trial form already solves the homogeneous equation, multiply the trial by x (or by x² if it is a double root). Otherwise the matching will give 0 = something.

A worked example, every step shown

Solve y″ − 3y′ + 2y = e3x.

Step 1: Homogeneous part. From Part 1, yh = C1 ex + C2 e2x.

Step 2: Trial. The right side is e3x, so try yp = A e3x. Since 3 is not a root (the roots are 1 and 2), no multiplication by x is needed.

Step 3: Derivatives. yp′ = 3A e3x and yp″ = 9A e3x.

Step 4: Substitute. 9A e3x − 9A e3x + 2A e3x = e3x. The left side is 2A e3x.

Step 5: Match. 2A = 1, so A = 1/2.

Step 6: General solution. y = C1 ex + C2 e2x + (1/2) e3x.

An example with resonance

Solve y″ + y = cos x.

Step 1: Homogeneous part. The roots are ±i, so yh = C1 cos x + C2 sin x.

Step 2: Trial and clash. The naive trial A cos x + B sin x solves the homogeneous equation, so it gives 0 on the left. We must multiply by x: try yp = x (A cos x + B sin x).

Step 3: Derivatives. Using the product rule, yp′ = (A cos x + B sin x) + x (−A sin x + B cos x). Differentiating again gives yp″ = 2(−A sin x + B cos x) − x (A cos x + B sin x).

Step 4: Substitute. yp″ + yp = 2(−A sin x + B cos x). The x terms cancel.

Step 5: Match. 2(−A sin x + B cos x) = cos x. So −2A = 0 and 2B = 1. Thus A = 0 and B = 1/2.

Step 6: Result. yp = (x/2) sin x. The general solution is y = C1 cos x + C2 sin x + (x/2) sin x.

import math

def yp(x):
    return (x / 2) * math.sin(x)

def residual(x, h=1e-4):
    d2 = (yp(x + h) - 2 * yp(x) + yp(x - h)) / (h * h)
    return d2 + yp(x) - math.cos(x)

print("particular solution OK:", all(abs(residual(x)) < 1e-5 for x in [0.0, 0.7, 1.3, 2.5]))
particular solution OK: True

TrapForgetting the resonance rule is the most common error. If the trial solves the homogeneous equation, the substitution gives zero, and you learn nothing. Check the trial against the roots before you start.

TipFor f(x) = polynomial times esx, the trial is a polynomial times esx of the same degree. Each unknown coefficient is found by matching.

For y″ − y = 4e2x, what is the trial function?

Try A e2x. Since 2 is not a root of r² − 1 = 0 (the roots are ±1), no x is needed.

For y″ + 4y = cos 2x, does the trial need an extra x?

Yes. The roots are ±2i, so cos 2x and sin 2x already solve the homogeneous equation. The trial becomes x(A cos 2x + B sin 2x).

Part 3: Initial conditions and the complete solution

The general solution has as many constants as the order of the equation. For a second-order equation there are two constants, C1 and C2. To fix them, we need two conditions, usually y(0) and y′(0). These are the initial conditions.

Procedure: write the complete solution y = yh + yp, differentiate it, substitute the two initial conditions, and solve the pair of equations for the constants.

A worked example, every step shown

Solve y″ − 3y′ + 2y = 0 with y(0) = 1 and y′(0) = 0.

Step 1: General solution. y = C1 ex + C2 e2x.

Step 2: Derivative. y′ = C1 ex + 2C2 e2x.

Step 3: First condition. y(0) = C1 + C2 = 1.

Step 4: Second condition. y′(0) = C1 + 2C2 = 0.

Step 5: Solve. Subtract the first from the second: C2 = −1. Then C1 = 1 − C2 = 2.

Step 6: Particular solution. y = 2ex − e2x.

Step 7: Check. y(0) = 2 − 1 = 1 ✓. y′(0) = 2 − 2 = 0 ✓.

A complex-root example

Solve y″ + 4y = 0 with y(0) = 1 and y′(0) = 2. The general solution is y = C1 cos 2x + C2 sin 2x. Then y(0) = C1 = 1. Its derivative is y′ = −2C1 sin 2x + 2C2 cos 2x, so y′(0) = 2C2 = 2, giving C2 = 1. The solution is y = cos 2x + sin 2x.

import math

def y(x):
    return 2 * math.exp(x) - math.exp(2 * x)

h = 1e-6
print("y(0) =", round(y(0.0), 4))
print("y'(0) close to 0:", abs((y(h) - y(-h)) / (2 * h)) < 1e-5)
print("y(1) =", round(y(1.0), 4))
y(0) = 1.0
y'(0) close to 0: True
y(1) = -1.9525

Key ideaInitial conditions fix the constants after you have the general solution. Never apply them before you know the full form of y.

TrapWhen differentiating C2 x erx, remember the product rule. The derivative gives C2 erx + C2 r x erx, and the first term is easy to forget.

For y″ − 2y′ + y = 0, the root is r = 1 (double). What is the general solution?

y = (C1 + C2 x) ex.

If y(0) = 5 and y = C1 cos 3x + C2 sin 3x, what is C1?

y(0) = C1 cos 0 + C2 sin 0 = C1, so C1 = 5.

Solved GATE-style problems

These problems are original, written in GATE style, and are not past exam questions. Try each one before reading the answer.

Larger root

Find the larger root of the characteristic equation for y″ − 5y′ + 6y = 0.

How to think about it

  1. What is asked. The larger of the two roots.
  2. Which idea applies. Write r² − 5r + 6 = 0 and solve.
  3. Work it out. Factor: (r − 2)(r − 3) = 0. The roots are 2 and 3. The larger is 3.
  4. Check. Sum of roots = 5, which equals the coefficient 5 with a sign change. Product = 6, the constant term. ✓

Answer: 3.

A repeated root with initial values

Solve y″ + 6y′ + 9y = 0 with y(0) = 2 and y′(0) = 0. Find y(1), correct to 4 decimal places.

How to think about it

  1. What is asked. The value y(1) for the particular solution.
  2. Which idea applies. The characteristic equation has a repeated root, so the general solution is (C1 + C2 x) e−3x.
  3. Work it out. y(0) = C1 = 2. Differentiate: y′ = C2 e−3x − 3(C1 + C2 x) e−3x. At x = 0, y′(0) = C2 − 6 = 0, so C2 = 6. So y = (2 + 6x) e−3x, and y(1) = 8e−3 ≈ 0.3983.
  4. Check. The value is positive and small, as expected for a decaying solution. The initial value y(0) = 2 is satisfied.

Answer: 0.3983.

Which statements about y″ + 2y′ + 5y = 0 are correct?

Consider y″ + 2y′ + 5y = 0. Select all statements that are correct.

(A) The roots of the characteristic equation are complex.
(B) The general solution is e−x(C1 cos 2x + C2 sin 2x).
(C) Every solution tends to 0 as x grows.
(D) The roots are real and distinct.

Select all that apply.

How to think about it

  1. What is asked. Which claims about the roots and the behaviour are true.
  2. Which idea applies. Characteristic equation r² + 2r + 5 = 0, with the complex-root form.
  3. Work it out. The discriminant is 4 − 20 = −16 < 0, so the roots are complex: r = (−2 ± 4i)/2 = −1 ± 2i. So A is true and D is false. With α = −1 and β = 2, the solution is e−x(C1 cos 2x + C2 sin 2x), so B is true. Since e−x goes to 0 and the cos and sin terms are bounded, every solution tends to 0, so C is true.
  4. Check. The negative real part −1 is what makes the decay happen. Positive real part would give growth.

Answer: (A), (B) and (C).

Particular solution coefficient

For the equation y″ − y = 4e2x, find the value of A in the trial particular solution yp = A e2x. Give the answer as a fraction.

How to think about it

  1. What is asked. The coefficient A.
  2. Which idea applies. Substitute the trial into the equation and match.
  3. Work it out. yp″ = 4A e2x. Then yp″ − yp = 4A e2x − A e2x = 3A e2x. Match to 4e2x: 3A = 4, so A = 4/3.
  4. Check. The roots of r² − 1 = 0 are ±1, neither equal to 2, so no x was needed. Substituting A = 4/3 gives 3 × 4/3 = 4. ✓

Answer: A = 4/3.

A numerical value from a cosine solution

Solve y″ + 4y = 0 with y(0) = 3 and y′(0) = 0. Find y(π/8), correct to 4 decimal places.

How to think about it

  1. What is asked. The value of the solution at x = π/8.
  2. Which idea applies. Complex roots ±2i give y = C1 cos 2x + C2 sin 2x.
  3. Work it out. y(0) = C1 = 3. y′ = −2C1 sin 2x + 2C2 cos 2x, so y′(0) = 2C2 = 0, giving C2 = 0. So y = 3 cos 2x. At x = π/8, 2x = π/4, so y = 3 cos(π/4) = 3 × 0.70711 ≈ 2.1213.
  4. Check. The value must lie between −3 and 3, and 2.1213 does.

Answer: 2.1213.

A repeated root with a boundary condition

Solve y″ − 2y′ + y = 0 with y(0) = 1 and y(1) = 0. Find the value of the constant C2 in the general solution written as (C1 + C2 x) ex. Give the answer as a number.

How to think about it

  1. What is asked. The constant C2, from conditions at two points.
  2. Which idea applies. The roots of r² − 2r + 1 = (r − 1)² = 0 give a repeated root r = 1. Use y(0) and y(1) instead of the derivative.
  3. Work it out. y(0) = C1 = 1. Then y(1) = (C1 + C2) e = (1 + C2) e = 0. Since e is not zero, 1 + C2 = 0, so C2 = −1.
  4. Check. The solution is y = (1 − x) ex. At x = 0 it is 1, and at x = 1 it is 0 × e = 0, as required.

Answer: C2 = −1.

Coefficient of a resonant particular solution

For the equation y″ + y = cos x, the trial particular solution is yp = x (A cos x + B sin x). Find the value of B. Give the answer as a fraction.

How to think about it

  1. What is asked. The coefficient B.
  2. Which idea applies. Substitute the trial and match the sin x and cos x terms.
  3. Work it out. Substituting gives yp″ + yp = 2(−A sin x + B cos x). Match with cos x: 2B = 1, so B = 1/2. The sin x term gives A = 0.
  4. Check. With A = 0 and B = 1/2 we get yp = (x/2) sin x, which the Python check in Part 2 confirmed.

Answer: B = 1/2.

Which statements about a triple root are correct?

Consider y‴ − 3y″ + 3y′ − y = 0. Select all statements that are correct.

(A) The general solution is (C1 + C2 x + C3 x²) ex.
(B) y = ex is a solution.
(C) y = x ex is a solution.
(D) y = e2x is a solution.

Select all that apply.

How to think about it

  1. What is asked. Test four claims about this third-order equation.
  2. Which idea applies. The characteristic polynomial is r³ − 3r² + 3r − 1 = (r − 1)³, so r = 1 is a triple root.
  3. Work it out. A triple root gives ex, x ex and x² ex, so A is true. B is true, since C1 = 1 and the others are 0. C is true, since C2 = 1. For D, the only exponent present is ex, so e2x is not a solution, and D is false.
  4. Check. Expanding (r − 1)³ gives r³ − 3r² + 3r − 1, matching the coefficients exactly.

Answer: (A), (B) and (C).

Exam-level 1: Repeated roots (NAT, 2 marks)

Solve y″ − 4y′ + 4y = 0 with y(0) = 1 and y′(0) = 0. Find y(1), correct to 3 decimal places.

How to think about it

  1. What is asked. The value at x = 1.
  2. Which idea applies. Auxiliary equation m² − 4m + 4 = 0 has a double root m = 2, so y = (A + Bx)e2x.
  3. Work it out. y(0) = A = 1. y′ = (B + 2A + 2Bx)e2x, so y′(0) = B + 2 = 0 and B = −2. y(1) = (1 − 2)e² = −7.389.
  4. Check. The code checks the differential equation at a few points with finite differences.
import math
y = lambda x: (1 - 2 * x) * math.exp(2 * x)
h = 1e-4
for x in (0.3, 1.0):
    d1 = (y(x + h) - y(x - h)) / (2 * h); d2 = (y(x + h) - 2 * y(x) + y(x - h)) / h ** 2
    print("residual at %.1f: %.4f" % (x, d2 - 4 * d1 + 4 * y(x)))
print("y(1) = %.3f" % y(1))

Exam-level 2: Particular solution with resonance (MCQ, 2 marks)

The correct form of a particular solution of y″ + 9y = sin 3x is (A) A sin 3x (B) A cos 3x + B sin 3x (C) x(A cos 3x + B sin 3x) (D) x² sin 3x

How to think about it

  1. What is asked. The trial form when the forcing matches the natural frequency.
  2. Which idea applies. The homogeneous solutions are cos 3x and sin 3x. The forcing duplicates them, so multiply the trial by x.
  3. Work it out. The trial is x(A cos 3x + B sin 3x). Substituting gives A = −1/6, B = 0.
  4. Check. The resulting yp = −(x/6) cos 3x grows with x, the mark of resonance.

For y‴ − 6y″ + 11y′ − 6y = 0, find the sum of the exponents in the general solution y = c1em₁x + c2em₂x + c3em₃x.

How to think about it

  2. Which idea applies. For m³ − 6m² + 11m − 6, the sum of roots is 6 by Vieta.
  3. Work it out. The roots are 1, 2 and 3. Sum = 6.

b² − 4ac, which decides the type of roots.
Distinct real roots
yh = C1 er1 x + C2 er2 x.
Repeated root
yh = (C1 + C2 x) erx.
Complex roots
yh = eαx(C1 cos βx + C2 sin βx).
Complementary function
The homogeneous solution yh.
Particular integral
A single yp that produces the right side f(x).

Guess yp in the same family as f(x), then match coefficients.

Values of y and y′ at a point, used to fix the constants.

Remember these

  1. Replace y by erx to get the characteristic equation.
  2. Compute the discriminant first. It tells you the form of the answer.
  3. A repeated root needs x erx as the second solution.
  4. Complex roots α ± iβ give eαx times cos and sin of βx.
  5. The general solution is the homogeneous part plus one particular part.
  6. If the trial solves the homogeneous equation, multiply it by x.
  7. Use the initial conditions last, to find the constants.
