Rank & eigenvalues recap for RA context

A quick recap of two tools that link everything else in linear algebra: rank, which tells you whether a system of equations can be solved, and eigenvalues, which tell you about stability. You will also see how a robot arm loses control at a singular position.

The idea in plain words

Suppose you are solving a puzzle with several clues. Some clues may repeat information you already have. The puzzle then has fewer real clues than it looks. The rank of a matrix counts how many real, non-repeated clues it contains.

Eigenvalues answer a different question: what happens when you repeat a process again and again? A direction whose eigenvalue is bigger than 1 in size grows with each step. A direction whose eigenvalue is smaller than 1 fades away.

Why does this matter for GATE RA? Robot arms, circuits and control systems are all described by matrices. Rank tells you whether the equations have a solution. Eigenvalues tell you whether a controlled system settles down.

Key terms

Row operation
A change that keeps the solutions and the rank: swap rows, scale a row by a non-zero number, or add a multiple of one row to another.
Echelon form
A staircase shape where each row starts further right than the one above, with zeros below each pivot.
Pivot
The first non-zero entry of a row in echelon form.
Rank
The number of pivots. Equivalently, the number of independent columns.
Augmented matrix
The matrix [A | b], with the right-hand side b added as an extra column.
Null space and nullity
The null space is all x with Ax = 0. Its dimension is the nullity.
Characteristic polynomial
det(A − λI). Its roots are the eigenvalues.
Jacobian
A matrix of partial derivatives. For a robot arm, it links joint speeds to the speed of the tool tip.

Step 1: Rank through echelon form

To find the rank, use row operations. They change the rows but keep the rank, so you can simplify freely until the pivots are visible.

Worked example. Find the rank of A = [[1, 2, 3], [2, 4, 7], [1, 0, 1]].

  1. Row 2 minus 2 times row 1 gives (0, 0, 1). Row 3 minus row 1 gives (0, −2, −2).
  2. Swap rows 2 and 3: [[1, 2, 3], [0, −2, −2], [0, 0, 1]]. This is in echelon form.
  3. The pivots are 1, −2 and 1, one in each row, so rank(A) = 3.

Key ideaRank equals the number of pivots. If some column has no pivot, the columns are dependent.

TrapDo not count non-zero rows of the original matrix. Only the pivot count of the echelon form is the rank.

Question: what is the rank of [[1, 2], [2, 4]]?

1. Row 2 minus 2 times row 1 gives (0, 0), so only one pivot remains.

Step 2: When does Ax = b have a solution?

Build the augmented matrix [A | b] and compare two ranks:

Ax = b has a solution ⇔ rank(A) = rank([A | b])

If the rank jumps when b is added, b creates a new pivot and the equations contradict each other. If the system is consistent with n unknowns:

  • Unique solution when rank(A) = n (a pivot in every column).
  • Infinitely many solutions when the system is consistent and rank(A) < n.

The practice section works through the GATE questions that use this test. The key step is always the same: row reduce, then read off the pivots.

GATE loves thisWith more equations than unknowns, solve with some of them, then test the extra ones. One failing extra equation means no solution.

Question: a system has rank(A) = 2, rank([A | b]) = 3, and 2 unknowns. How many solutions?

None. The rank jumps when b is added, so the equations are inconsistent.

Step 3: Rank and the null space

The solutions of Ax = 0 form the null space. Its dimension is linked to the rank by the rank-nullity rule:

rank(A) + nullity(A) = number of columns of A

Each column either adds a pivot (a new direction) or does not (it is a combination of earlier columns, giving a free variable). The two counts add up to the number of columns.

For a matrix with more columns than rows, rank cannot exceed the number of rows, so the nullity is at least (columns − rows). This fact is used in the practice section.

Question: a 5 × 3 matrix has rank 3. What is the dimension of its null space?

0. Rank-nullity gives 3 + nullity = 3, so nullity = 0. The only solution of Ax = 0 is x = 0.

Step 4: Eigenvalues and singularity

Eigenvalues are the roots of det(A − λI) = 0. Three statements about a square matrix always agree: A is singular (det = 0), 0 is an eigenvalue, and the rank is less than the size.

Worked example. Let A = [[2, 1], [2, 1]]. The trace is 3 and the determinant is 0. The characteristic polynomial is λ² − 3λ, so the eigenvalues are 0 and 3. Because 0 is an eigenvalue, A is singular, and its rank is 1.

Eigenvalues also decide stability of ẋ = Ax, where ẋ is the rate of change of x. The solution settles to zero when every eigenvalue has a negative real part, and it blows up if any eigenvalue has a positive real part.

Key ideaA homogeneous system Ax = 0 has a non-trivial solution exactly when A is singular.

Question: a system ẋ = Ax has eigenvalues −1 and −2. Does x settle to zero?

Yes. Both eigenvalues have negative real parts, so every term decays.

Step 5: Singularity in robot kinematics

Take a planar robot arm with two links of lengths l1 and l2, and joint angles θ1 and θ2. The Jacobian J links joint speeds to the tool-tip speed. For this arm, its determinant simplifies to:

det J = l1 l2 sin θ2

When det J = 0, the arm is in a singular configuration: θ2 = 0 (fully stretched) or θ2 = π (folded back). The rank of J drops, and the tool loses one direction of motion. No joint speed can move the tip that way.

The code below computes J at a sample pose and checks the formula.

import math

l1, l2 = 1.0, 1.0
t1, t2 = 0.3, 0.5
s1, c1 = math.sin(t1), math.cos(t1)
s12, c12 = math.sin(t1 + t2), math.cos(t1 + t2)
J = [[-l1 * s1 - l2 * s12, -l2 * s12], [l1 * c1 + l2 * c12, l2 * c12]]
det = J[0][0] * J[1][1] - J[0][1] * J[1][0]
print("det J =", round(det, 6))
print("l1*l2*sin(theta2) =", round(l1 * l2 * math.sin(t2), 6))
det J = 0.479426
l1*l2*sin(theta2) = 0.479426

TrapA singular configuration is not an unreachable position. The arm can reach the point, but it cannot move in one direction from there.

Solved GATE-style problems

Problems marked "verified PYQ" are real past GATE questions. The rest are GATE-style practice problems.

Rank of a small matrix

Find the rank of A = [[1, 2, 3], [2, 4, 6], [1, 0, 1]].

How to think about it

  1. What is asked. The number of pivots.
  2. Which idea applies. Row reduce and count pivots.
  3. Work it out. Row 2 is 2 times row 1, so it adds nothing. Row 3 minus row 1 gives (0, −2, −2), which is not zero. Two independent rows remain, so rank = 2.
  4. Check. The rank is less than 3, as expected from the repeated row.

Answer: 2.

Singular or not?

Let A = [[2, 1], [2, 1]]. Is A singular? What are its eigenvalues?

How to think about it

  1. What is asked. Singularity, and the eigenvalues.
  2. Which idea applies. A is singular when det = 0. Use λ² − trace·λ + det = 0.
  3. Work it out. det = 2 − 2 = 0, so A is singular. Trace = 3, so λ² − 3λ = 0, giving λ = 0 or 3.
  4. Check. The eigenvalue 0 confirms singularity, and 0 + 3 = 3 is the trace.

Answer: yes, A is singular. Its eigenvalues are 0 and 3.

Unique solution for which α? (verified PYQ)

GATE CSE 2008 · Q3 (verified PYQ). The following system has a unique solution. What are the possible values of α?

x1 + x2 + 2x3 = 1, x1 + 2x2 + 3x3 = 2, x1 + 4x2 + αx3 = 4.

How to think about it

  1. What is asked. The values of α that give three pivots.
  2. Which idea applies. A unique solution needs rank 3, so det(A) ≠ 0.
  3. Work it out. Row 2 minus row 1 gives [0, 1, 1]. Row 3 minus row 1 gives [0, 3, α − 2]. Row 3 minus 3 times the new row 2 gives [0, 0, α − 5]. So α ≠ 5.
  4. Check. At α = 5 the last row is zero, the rank drops to 2, and there are infinitely many solutions.

Answer: any real α except 5.

Condition for a non-trivial solution (verified PYQ)

GATE CSE 2015 Set 3 · Q42 (verified PYQ). If the following system has a non-trivial solution, which condition holds?

px + qy + rz = 0, qx + ry + pz = 0, rx + py + qz = 0.

(A) p − q + r = 0 or p = q = −r   (B) p + q − r = 0 or p = −q = r   (C) p + q + r = 0 or p = q = r   (D) p − q + r = 0 or p = −q = −r

How to think about it

  1. What is asked. The condition that makes the homogeneous system singular.
  2. Which idea applies. A square homogeneous system has a non-trivial solution exactly when its determinant is zero.
  3. Work it out. The determinant is 3pqr − (p³ + q³ + r³) = −(p + q + r)(p² + q² + r² − pq − qr − rp). The second factor is zero only when p = q = r.
  4. Check. With p = q = r = 1, every equation becomes x + y + z = 0, which has non-trivial solutions. With p = 1, q = 1, r = 0, option (A) holds, but the determinant is −2, so (A) is not sufficient.

Answer: (C).

Rank from the null space (NAT, verified PYQ)

GATE CSE 2021 Set 2 · Q24 (verified PYQ). P is a 4 × 5 matrix such that every solution of Px = 0 is a scalar multiple of [2, 5, 4, 3, 1]ᵀ. What is the rank of P?

How to think about it

  1. What is asked. rank(P).
  2. Which idea applies. Rank-nullity.
  3. Work it out. The null space is a line, so nullity = 1. P has 5 columns, so rank = 5 − 1 = 4.
  4. Check. A 4 × 5 matrix has at most 4 pivots, and 4 is that maximum.

Answer: 4.

Guaranteed solutions of Ax = 0 (NAT, verified PYQ)

GATE CSE 2024 (verified PYQ, rewritten as a number question). Let A be an n × m matrix with m > n. What is the minimum number of linearly independent solutions that Ax = 0 is guaranteed to have?

How to think about it

  1. What is asked. The guaranteed nullity over all such matrices.
  2. Which idea applies. nullity = m − rank(A), and rank(A) ≤ n.
  3. Work it out. Since rank(A) ≤ n, nullity ≥ m − n. A matrix of rank n reaches exactly m − n, so the guaranteed minimum is m − n.
  4. Check. A = 0 has nullity m, which is larger, so it does not lower the bound.

Answer: m − n.

Singular configurations of a two-link arm (MSQ)

A planar two-link arm with l1 = l2 = 1 has Jacobian determinant det J = sin θ2. For θ2 in [0, π], select all the singular values.

(A) θ2 = 0   (B) θ2 = π/2   (C) θ2 = π   (D) θ2 = π/4

How to think about it

  1. What is asked. The values of θ2 where det J = 0.
  2. Which idea applies. A singular configuration is one where the Jacobian determinant is zero.
  3. Work it out. sin θ2 = 0 at θ2 = 0 and θ2 = π. At π/2, sin = 1, and at π/4, sin = √2/2, so those are not singular.
  4. Check. θ2 = 0 is fully stretched and θ2 = π is folded back. In both, the links line up, which removes a direction of motion.

Answer: (A) and (C).

Exam-level practice

Exam-level 1: Rank of a diagonalizable matrix (NAT, 1 mark)

A 5 × 5 diagonalizable matrix has characteristic polynomial λ²(λ − 1)(λ − 3)². Find rank(A).

How to think about it

  1. What is asked. The rank from the eigenvalue list.
  2. Which idea applies. For a diagonalizable matrix, the rank equals the number of nonzero eigenvalues counted with multiplicity.
  3. Work it out. Eigenvalues: 0, 0, 1, 3, 3. Nonzero count = 3. Rank = 3.
  4. Check. Diagonalizable means the zero eigenvalue has a 2 dimensional eigenspace, which is the null space, so nullity 2 and rank 5 − 2 = 3.

Answer: 3.

Exam-level 2: Rank and eigenvalue facts (MSQ, 2 marks)

Let A be a real n × n matrix. Which are TRUE? (A) rank(A) is at least the number of nonzero eigenvalues counted with algebraic multiplicity. (B) If A is singular, 0 is an eigenvalue of A. (C) [[0, 1], [0, 0]] has rank 1 but no nonzero eigenvalue. (D) rank(A) always equals the number of nonzero eigenvalues counted with multiplicity.

How to think about it

  1. What is asked. How rank and eigenvalues relate in general.
  2. Which idea applies. Eigenvectors for nonzero eigenvalues lie in the column space of A. A nilpotent matrix shows the rank can be larger than that count.
  3. Work it out. (A) The generalized eigenspaces for nonzero eigenvalues sit inside the column space, so the bound holds. True. (B) det(A − 0I) = det(A) = 0. True. (C) Its only eigenvalue is 0, yet one column is nonzero. True. (D) The matrix in (C) has rank 1 and zero nonzero eigenvalues. False. Equality holds for diagonalizable matrices.
  4. Check. (C) is the counterexample to (D), so (C) and (D) cannot both be true.

Answer: (A), (B) and (C).

Exam-level 3: Rank of a Gram matrix (NAT, 2 marks)

X is a 100 × 6 data matrix of rank 4. Find the number of zero eigenvalues of XᵀX.

How to think about it

  1. What is asked. How many eigenvalues of the 6 × 6 Gram matrix are zero.
  2. Which idea applies. rank(XᵀX) = rank(X), and XᵀX is symmetric so it is diagonalizable.
  3. Work it out. rank(XᵀX) = 4, so 6 − 4 = 2 eigenvalues are zero.
  4. Check. XᵀXv = 0 means ‖Xv‖² = 0, so Null(XᵀX) = Null(X) with dimension 2.

Answer: 2.

Summary

Row operation
A change that keeps the solutions and the rank.
Echelon form
A staircase form that shows the pivots clearly.
Pivot
The first non-zero entry of a row in echelon form.
Rank
The number of pivots.
Augmented matrix
[A | b], used to test whether Ax = b is consistent.
Consistent
The system has at least one solution.
Unique solution
Consistent and rank equal to the number of unknowns.
Null space
All solutions of Ax = 0.
Nullity
The dimension of the null space.
Rank-nullity
rank + nullity = number of columns.
Characteristic polynomial
det(A − λI), whose roots are the eigenvalues.
Singular
Determinant zero, equivalently 0 is an eigenvalue.
Stability
A system ẋ = Ax settles when all eigenvalues have negative real parts.
Jacobian
The matrix linking joint speeds to tool-tip speed.
Singular configuration
A robot pose where the Jacobian loses rank.

Remember these

  1. Rank is the number of pivots, found by row operations.
  2. Ax = b has a solution exactly when adding b does not raise the rank.
  3. Unique solution needs rank equal to the number of unknowns.
  4. Rank plus nullity equals the number of columns.
  5. A square matrix is singular exactly when its determinant is zero, which happens exactly when 0 is an eigenvalue.
  6. In robotics, a singular configuration is where the Jacobian determinant is zero.
