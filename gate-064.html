Explicit single & multi-step methods for ODEs

Many differential equations cannot be solved with a formula, but we can still move the solution forward one small step at a time. This page explains the explicit methods that do this: Euler's method, the improved Euler (Heun) method, the fourth-order Runge-Kutta method and the basic multi-step idea, with the errors and traps that GATE questions test.

The idea in plain words

A differential equation tells you the slope of a solution at every point. If you know where you start, the slope tells you which way to go. Imagine using a compass while walking. At each moment the compass points along the direction of travel. If you walk in a straight line for a short distance, then check the compass again, you follow the path step by step.

That is the whole idea behind numerical methods for ODEs. We know the starting value y0 at x0. We compute the slope there, take a small step h in that direction, and land at a new point. Then we repeat. The result is a list of values that approximates the true curve.

Methods differ in how they choose the slope for each step. A crude choice (the slope at the start only) is simple but inaccurate. A cleverer choice (several slopes averaged) is more work per step but much more accurate. This topic follows that path from the simplest method to the most popular one used in engineering software.

Why this matters for GATE. In the Robotics and Automation paper, you may be asked to take one or two steps of Euler's method or RK4 by hand, to state the order of a method, or to spot a stability problem. Each of these is a short calculation once the formulas are clear.

Key terms

Read this list once now. Return to it when a word is unfamiliar.

Ordinary differential equation (ODE)
An equation linking a function y(x) to its derivative, such as y' = y.
Initial value problem
An ODE together with a starting value, such as y' = y with y(0) = 1.
Step size h
The distance between neighbouring x-values in the calculation, xn+1 = xn + h.
Explicit method
A method where yn+1 is computed directly from values already known, with no equation to solve.
Single-step method
A method that uses only the latest value to compute the next one.
Multi-step method
A method that uses several past values to compute the next one.
Slope
The value of f(x, y) = y', the rate of change at a point.
Local truncation error
The error made in one step, assuming the starting value was exact.
Global error
The total error after many steps, which is the accumulation of the local errors.
Order of a method
The power p such that the global error is proportional to hp. Euler has order 1, Heun order 2, RK4 order 4.
Predictor and corrector
A rough estimate of the next value (the predictor), then an improved value using a better slope (the corrector).
Runge-Kutta method
A family of single-step methods that average several slopes within one step.
Stability
Whether small errors die out or grow as the steps go on. A method with a step that is too large can become unstable.
Starting values
The first few values that a multi-step method needs before it can start, usually found with a single-step method.

Step 1: Euler's method and its errors

The rule

Suppose we know yn at xn. The ODE says the slope there is f(xn, yn). Euler's method follows that slope for one step of width h:

yn+1 = yn + h · f(xn, yn), with xn+1 = xn + h

Read each symbol: yn is the current value, f(xn, yn) is the slope there, and h is the step size. The product h · f is the change in y over one step. This is simply "rise equals slope times run". It is the tangent line followed for a short distance.

Worked example 1: y' = y by Euler

Solve y' = y with y(0) = 1, using h = 0.5, from x = 0 to x = 1. The exact solution is ex, so y(1) = e, about 2.71828.

  1. Step 1, from x = 0 to 0.5. The slope at (0, 1) is f = y = 1. So y1 = 1 + 0.5 × 1 = 1.5.
  2. Step 2, from x = 0.5 to 1. The slope at (0.5, 1.5) is f = 1.5. So y2 = 1.5 + 0.5 × 1.5 = 2.25.
  3. Compare. The estimate 2.25 is below the exact value 2.71828. The error is about 0.468, which is large. A bigger step gives a bigger error.

How the error depends on h

The local truncation error of Euler's method is proportional to h2. Over the whole interval there are about 1/h steps, and the local errors add up to roughly h times a constant. So the global error is proportional to h. Halving the step halves the global error. The program below shows this for y' = y on [0, 1].

import math

def euler_final(h):
    x, y = 0.0, 1.0
    n = round(1 / h)
    for _ in range(n):
        y = y + h * y
        x += h
    return y

exact = math.e
for h in [0.1, 0.05]:
    err = exact - euler_final(h)
    print("h =", h, "error =", round(err, 4))
h = 0.1 error = 0.1245
h = 0.05 error = 0.065

Key ideaEuler is first order: halving h halves the global error. Getting ten times more accuracy by Euler needs about ten times more steps, which is slow. Higher-order methods are the answer.

TrapEuler uses the slope at the start of the step only. If that slope is zero, the step does not move, even if the curve is steep further along. Question writers use this to catch students who assume the slope is constant over the step.

Question: Euler's method with h = 0.2 is applied to y' = 2x with y(0) = 0. What is y1?

The slope at (0, 0) is f = 2 × 0 = 0. So y1 = 0 + 0.2 × 0 = 0. The exact value at x = 0.2 is 0.04, so Euler misses the curve in the first step.

Question: What is the order of Euler's method, and what does that mean for the global error?

The order is 1. The global error is proportional to h, so halving h halves the error.

Step 2: The improved Euler (Heun) method

The idea: check the road ahead

Euler uses only the slope at the start of the step. If the curve bends, that slope is misleading by the end of the step. Heun's method improves on this with a two-part plan. First, it takes a rough Euler step to find a predicted end value. Second, it computes the slope at that predicted end, and averages it with the starting slope.

Predictor: y* = yn + h f(xn, yn)
Corrector: yn+1 = yn + (h/2)[f(xn, yn) + f(xn+1, y*)]

The predictor is the Euler step, and the corrector is the averaged step. Averaging two slopes, one at each end of the step, is a good idea because the true average slope over a step is usually between them. This is like a driver who checks the road ahead before deciding how far to turn.

Worked example 2: one Heun step for y' = y

Start at (0, 1) with h = 0.5, and solve y' = y. The exact value at x = 0.5 is e0.5, about 1.64872.

  1. Predictor. The slope at the start is f(0, 1) = 1. So y* = 1 + 0.5 × 1 = 1.5.
  2. Slope at the predicted end. f(0.5, 1.5) = 1.5, because f depends on y only.
  3. Average the slopes. (1 + 1.5)/2 = 1.25.
  4. Corrector. y1 = 1 + 0.5 × 1.25 = 1.625.
  5. Compare. Euler gave 1.5, with error about 0.149. Heun gives 1.625, with error about 0.024. One extra slope evaluation cut the error by a factor of six.
from fractions import Fraction

def f(x, y):
    return y

x, y, h = Fraction(0), Fraction(1), Fraction(1, 2)
euler = y + h * f(x, y)
heun = y + h / 2 * (f(x, y) + f(x + h, euler))
print("Euler:", euler, float(euler))
print("Heun:", heun, float(heun))
Euler: 3/2 1.5
Heun: 13/8 1.625

Order and cost

Heun's method is second order. Its local error is proportional to h3, and its global error to h2. Halving h therefore divides the global error by four. Each step needs two slope evaluations instead of one. Another second-order method is the midpoint method, which evaluates the slope halfway through the step.

TrapThe corrector uses the slope at the predicted point y*, not at the final yn+1. The final value is not known until the corrector has been computed.

Question: In Heun's method, at which point is the second slope evaluated?

At (xn+1, y*), where xn+1 = xn + h and y* is the Euler predictor.

Question: If the global error of a second-order method is 0.04 at h = 0.2, roughly what is it at h = 0.1?

About 0.01. Halving h divides a second-order global error by four, so 0.04/4 = 0.01.

Step 3: Runge-Kutta, fourth order

Four slopes, one weighted average

The fourth-order Runge-Kutta method, usually written RK4, takes four slopes within one step and combines them with weights. It is the most widely used method in this family. The four slopes are:

k1 = f(xn, yn)
k2 = f(xn + h/2, yn + (h/2)k1)
k3 = f(xn + h/2, yn + (h/2)k2)
k4 = f(xn + h, yn + hk3)
yn+1 = yn + (h/6)(k1 + 2k2 + 2k3 + k4)

Here k1 is the slope at the start, k2 and k3 are slopes at the midpoint, each using a better guess for y, and k4 is the slope at the end. The weights 1, 2, 2, 1 divided by 6 form a weighted average of the four slopes. The midpoint slopes count twice, because they are the most representative of the whole step.

Worked example 3: one RK4 step for y' = y

Start at (0, 1) with h = 0.5.

  1. k1. f(0, 1) = 1.
  2. k2. y + (h/2)k1 = 1 + 0.25 = 1.25, so k2 = 1.25.
  3. k3. y + (h/2)k2 = 1 + 0.25 × 1.25 = 1.3125, so k3 = 1.3125.
  4. k4. y + hk3 = 1 + 0.5 × 1.3125 = 1.65625, so k4 = 1.65625.
  5. Combine. y1 = 1 + (0.5/6)(1 + 2 × 1.25 + 2 × 1.3125 + 1.65625) = 1 + (1/12)(7.78125) = 1.6484375.
  6. Compare. The exact value is 1.6487213, so the error is about 0.0003. Compare this with the Heun error of 0.024 from Worked example 2.
from fractions import Fraction

def f(x, y):
    return y

def rk4_step(x, y, h):
    k1 = f(x, y)
    k2 = f(x + h / 2, y + h / 2 * k1)
    k3 = f(x + h / 2, y + h / 2 * k2)
    k4 = f(x + h, y + h * k3)
    return y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)

y1 = rk4_step(Fraction(0), Fraction(1), Fraction(1, 2))
print(y1, float(y1))
211/128 1.6484375

RK4 uses four times as many slope evaluations as Euler per step, but it usually needs far fewer steps for the same accuracy.

GATE loves thisRK4 is exact for polynomial solutions up to degree 4. The weights 1, 2, 2, 1 are chosen to make this true, which is why its order is 4.

TrapThe weights are 1, 2, 2, 1 and the divisor is 6, not 4. Students often divide by 4, which gives a wrong step. Check that the weights add to 6 before you divide.

Question: How many slopes does RK4 evaluate in one step?

Four: k1, k2, k3 and k4. Each one needs one evaluation of f.

Question: For RK4 with h = 0.5 on y' = y, what does the weighted average of the slopes equal?

(1 + 2(1.25) + 2(1.3125) + 1.65625)/6 = 7.78125/6 = 1.296875. Multiplied by h = 0.5, this gives 0.6484375, which is added to y = 1 to give 1.6484375.

Step 4: Multi-step methods and stability

Reusing past slopes

A multi-step method stores slopes from earlier steps and reuses them. The two-step Adams-Bashforth method is the simplest example:

yn+1 = yn + (h/2)(3fn - fn-1)

Here fn = f(xn, yn) and fn-1 = f(xn-1, yn-1). The method uses the slope from the latest step with weight 3, and the one before with weight -1. Because the slopes are reused, each step needs only one new evaluation of f, which is cheaper than RK4.

The catch is the start. To begin, you need two values, y0 and y1. The standard approach is to compute y1 with a single-step method such as RK4, and then switch to the multi-step rule.

Worked example 4: one Adams-Bashforth step

For y' = y, take y0 = 1 and y1 = 211/128 from the RK4 step above, with h = 0.5. Find y2.

  1. Slopes. For y' = y, f = y. So f1 = 211/128 and f0 = 1.
  2. Apply the rule. y2 = 211/128 + (0.5/2)(3 × 211/128 - 1) = 211/128 + (1/4)(505/128).
  3. Simplify. y2 = 211/128 + 505/512 = 844/512 + 505/512 = 1349/512, which is about 2.634766.
  4. Compare. The exact value at x = 1 is e, about 2.718282. The error is about 0.084 after two steps, which is reasonable for h = 0.5.
from fractions import Fraction

y0 = Fraction(1)
y1 = Fraction(211, 128)
h = Fraction(1, 2)
f0 = y0
f1 = y1
y2 = y1 + h / 2 * (3 * f1 - f0)
print(y2, float(y2))
1349/512 2.634765625

Stability: when a large step blows up

Accuracy is not the only concern. Consider y' = -10y, whose exact solution y = e-10x decays quickly to zero. For a method, the question is whether its numerical values also decay. For Euler's method, each step multiplies y by the factor 1 + hλ, where λ = -10 in this equation.

  • With h = 0.5, the factor is 1 + 0.5 × (-10) = -4. Each step multiplies y by -4, so the values grow and alternate in sign. The method is unstable.
  • With h = 0.1, the factor is 1 + 0.1 × (-10) = 0. The values drop to zero at the next step, which is stable.

The program below shows the blow-up for h = 0.5.

print(1 + 0.5 * -10, 1 + 0.1 * -10)

y = 1.0
values = [y]
for _ in range(3):
    y = y * (1 + 0.5 * -10)
    values.append(y)
print(values)
-4.0 0.0
[1.0, -4.0, 16.0, -64.0]

TrapAccuracy for small h does not guarantee a good answer for large h. Always check the stability condition for the equation and the method before choosing a step size. For Euler on y' = λy, the factor 1 + hλ must lie between -1 and 1.

Question: How many starting values does the two-step Adams-Bashforth method need?

Two: y0 and y1. The first step needs f0 and f1, so a single-step method such as RK4 usually provides y1.

Question: For Euler's method on y' = -10y, for which h is the factor 1 + hλ between -1 and 1?

1 - 10h must lie between -1 and 1. So 0 < h < 0.2. Steps of 0.2 or more make the Euler values grow or oscillate.

Solved GATE-style problems

These problems are original, written in the style of GATE questions. They are not past exam questions. Try each one on paper before you read the answer.

One Euler step

Solve y' = 2y with y(0) = 1 by one step of Euler's method with h = 0.1. Find y(0.1). (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The value after one step of size 0.1.
  2. Which idea applies. y1 = y0 + h f(x0, y0).
  3. Work it out. f(0, 1) = 2 × 1 = 2. So y1 = 1 + 0.1 × 2 = 1.2.
  4. Check. The exact value e0.2 is about 1.2214, so the Euler answer is a little low, as expected for a convex solution.

Answer: 1.2.

Properties of the methods

Select all the statements that are true.

(A) Euler's method is explicit.
(B) The global error of Euler's method is proportional to h.
(C) The classical RK4 method evaluates f four times per step.
(D) Heun's method is a multi-step method.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which facts about the methods are correct.
  2. Which idea applies. Explicit methods, the order of each method, and the number of slopes per step.
  3. Work it out. (A) True, the next value is computed directly. (B) True, Euler has order 1. (C) True, k1 to k4. (D) False, Heun uses only the latest value, so it is single-step.
  4. Check. Statement (D) confuses Heun, a single-step method, with the Adams-Bashforth method.

Answer: (A), (B) and (C).

One Heun step

Solve y' = y with y(0) = 1 by one step of Heun's method with h = 0.5. Find y(0.5). (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. One Heun step from (0, 1).
  2. Which idea applies. Predictor y* = y + h f, then corrector y + (h/2)(f0 + f(x1, y*)).
  3. Work it out. Predictor y* = 1 + 0.5 × 1 = 1.5. Then f(0.5, 1.5) = 1.5. The corrector gives 1 + 0.25 × (1 + 1.5) = 1.625.
  4. Check. The exact value e0.5 is about 1.6487. The Heun value 1.625 is closer than Euler's 1.5.

y_star = y + 0.5 * y
y1 = y + 0.5 * (y + y_star) / 2

Two Euler steps for a non-autonomous equation

Solve y' = x + y with y(0) = 1 by Euler's method with h = 0.5. Find y after two steps, that is y(1) approximately. Give the exact fraction. (Answer type: NAT, a fraction.)

How to think about it

  1. What is asked. The Euler value at x = 1 after two steps.
  2. Which idea applies. Each step uses f(x, y) = x + y at the current point.
  3. Work it out. Step 1 at (0, 1): f = 1, so y = 1 + 0.5 × 1 = 1.5. Step 2 at (0.5, 1.5): f = 2, so y = 1.5 + 0.5 × 2 = 2.5.
  4. Check. The exact solution is 2ex - x - 1, which gives 2e - 2, about 3.44 at x = 1. Euler is clearly low with this big step, which is a sign that h = 0.5 is coarse.
from fractions import Fraction

x, y, h = Fraction(0), Fraction(1), Fraction(1, 2)
for _ in range(2):
    y = y + h * (x + y)
    x = x + h
print(y)
5/2

Answer: 5/2.

One RK4 step on a decaying equation

Solve y' = -2y with y(0) = 1 by one RK4 step with h = 0.1. Find y(0.1), rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. One RK4 step on y' = -2y.
  2. Which idea applies. The four slopes k1 to k4, then the weighted average.
  3. Work it out. For a linear equation y' = λy, one RK4 step multiplies y by 1 + z + z2/2 + z3/6 + z4/24, where z = hλ = -0.2. This gives 1 - 0.2 + 0.02 - 0.00133 + 0.0000667, about 0.81873.
  4. Check. The exact value e-0.2 is about 0.81873. The program runs the four slopes directly.
def f(x, y):
    return -2 * y

def rk4_step(x, y, h):
    k1 = f(x, y)
    k2 = f(x + h / 2, y + h / 2 * k1)
    k3 = f(x + h / 2, y + h / 2 * k2)
    k4 = f(x + h, y + h * k3)
    return y + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)

print(round(rk4_step(0.0, 1.0, 0.1), 4))
0.8187

Answer: 0.8187.

Two-step Adams-Bashforth on a decay

Solve y' = -y with starting values y(0) = 1 and y(0.5) = 0.5. Use the two-step Adams-Bashforth method with h = 0.5 to find y(1). Give the exact fraction. (Answer type: NAT, a fraction.)

How to think about it

  1. What is asked. One Adams-Bashforth step from the two given values.
  2. Which idea applies. yn+1 = yn + (h/2)(3fn - fn-1), with f = -y.

Stability of explicit Euler

Explicit Euler is applied to y' = -10y with step h = 0.5, or with step h = 0.1. Select all that apply.

(A) With h = 0.5, one Euler step gives y1 = -4y0.
(B) With h = 0.5, the Euler values decay to zero.
(C) With h = 0.1, one Euler step gives y1 = 0 when y0 = 1.
(D) Because the exact solution decays, the step h = 0.5 gives an accurate answer.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which statements about the two step sizes are true.
  2. Which idea applies. The Euler factor 1 + hλ, with λ = -10.
  3. Work it out. With h = 0.5, the factor is 1 + 0.5 × (-10) = -4, so y1 = -4y0. (A) is true. The factor -4 has size greater than 1, so the values grow and alternate, which makes (B) false. With h = 0.1 the factor is 0, so y1 = 0. (C) is true. (D) is false, because the step is too large for the decay.
  4. Check. The program prints the two factors.
print(1 + 0.5 * -10, 1 + 0.1 * -10)
-4.0 0.0

Answer: (A) and (C).

Exam-level 3: Stability of explicit Euler (NAT, 2 marks)

For y′ = −50y, find the largest step size h for which explicit Euler does not grow, that is |1 + λh| ≤ 1.

How to think about it

  1. What is asked. The stability limit.
  2. Which idea applies. Euler gives yn+1 = (1 + λh)yn, with λ = −50.

Remember these

  1. Euler uses the slope at the start of the step. It is first order, so the global error halves when h halves.
  2. Heun averages the slopes at the two ends of the step, using an Euler predictor. It is second order.
  3. RK4 uses four slopes with weights 1, 2, 2, 1 and divides by 6. It is fourth order.
  4. Multi-step methods reuse past slopes, but they need starting values.
  5. For y' = λy, explicit Euler is stable only when |1 + hλ| is at most 1.
  6. Check the weights and the divisor before you calculate a step.
