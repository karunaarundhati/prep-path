Solving linear & non-linear algebraic equations numerically

Many equations cannot be solved neatly with a formula, so engineers find answers by repeating a simple step until the answer is good enough. This page covers three root-finding methods (bisection, Newton-Raphson and regula falsi), how fast each one converges, and two iterative methods (Jacobi and Gauss-Seidel) for systems of linear equations.

The idea in plain words

Some equations are easy. The equation 2x + 6 = 0 gives x = -3 in one step. But many equations in engineering have no neat formula, such as cos x = x. We can search for the answer instead. Start with a guess, check how wrong it is, improve it, and repeat. Each pass is called an iteration.

Think of a game of "higher or lower". Someone picks a whole number from 1 to 100. You guess 50, and they say "higher". You guess 75, and they say "lower". Each answer cuts the range of possibilities in half. The bisection method plays exactly this game.

Root-finding methods differ in two ways: how safe they are, and how fast the guess improves. This topic compares them so you can choose wisely.

Why this matters for GATE. The Robotics and Automation paper uses numerical methods for equations that arise in kinematics and control. Questions often ask for two or three iterations by hand, a convergence rate, or the method that is guaranteed to work. Each is a short calculation once you know the formulas.

Key terms

Read this list once now. Return to it when a word is unfamiliar.

Root
A value x where f(x) = 0. The root of x - 3 is 3.
Iteration
One pass of a repeated rule. The result of one pass becomes the input to the next.
Continuous function
A function whose graph has no sudden jumps or gaps. You can draw it without lifting your pen.
Bracket
An interval [a, b] where f(a) and f(b) have opposite signs, so the graph must cross zero between them.
Derivative f'(x)
The slope of the graph at x. The derivative of x2 is 2x.
Tangent line
The straight line that touches the graph at a point and has the same slope there.
Secant line
A straight line through two points on the graph.
Error
The difference between the current iterate and the true root, written en = xn - r.
Tolerance
A small number, such as 10-6, that tells the method when to stop.
Linear convergence
The error shrinks by a fixed fraction each step.
Quadratic convergence
The error at the next step is about a constant times the square of the current error. Correct digits roughly double each step.
Linear system
Several equations with several unknowns, where each unknown appears only to the first power, such as 4x + y = 9.
Diagonally dominant
In each row of the system, the diagonal coefficient is larger in size than the sum of the other coefficients in that row.

Step 1: The bisection method

The idea

Bisection uses one fact from calculus, the intermediate value theorem. If f is continuous and f(a) and f(b) have opposite signs, the graph must cross zero somewhere between a and b. You do not need to know where. Bisection checks the midpoint m = (a + b)/2. If f(m) has the same sign as f(b), the root lies between a and m. Otherwise it lies between m and b. The new bracket is always half as wide.

Procedure

  1. Choose a bracket [a, b] where f(a) and f(b) have opposite signs.
  2. Compute the midpoint m = (a + b)/2.
  3. If f(a) and f(m) have opposite signs, set b = m. Otherwise set a = m.
  4. Repeat until the bracket is narrower than the tolerance.

Worked example 1: the square root of 2 by hand

Find the root of f(x) = x2 - 2 in [1, 2]. The true answer is √2, about 1.41421.

  1. Check the bracket. f(1) = -1 is negative and f(2) = 2 is positive. So a root lies in [1, 2].
  2. Iteration 1. m = 1.5, and f(1.5) = 2.25 - 2 = 0.25 is positive. The sign matches f(2), so the new bracket is [1, 1.5].
  3. Iteration 2. m = 1.25, and f(1.25) = 1.5625 - 2 = -0.4375 is negative. The sign matches f(1), so the new bracket is [1.25, 1.5].
  4. Iteration 3. m = 1.375, and f(1.375) = 1.890625 - 2 = -0.109375 is negative. The new bracket is [1.375, 1.5].
  5. Iteration 4. m = 1.4375, and f(1.4375) = 2.06640625 - 2 = 0.06640625 is positive. The new bracket is [1.375, 1.4375].
  6. Result. The bracket has width 0.0625 and contains √2. The midpoint 1.40625 is within 0.0625 of the true root.

How many steps do we need?

After n steps the bracket has width (b - a)/2n. To make it at most a tolerance ε, you need:

n ≥ log2((b - a)/ε)

Here log2 is the logarithm to base 2. For the square-root example, b - a = 1 and ε = 10-6, so n ≥ log2(106), which is about 19.93. Rounding up gives 20 steps. The program counts them.

import math

def f(x):
    return x * x - 2

a, b = 1.0, 2.0
steps = 0
while b - a > 1e-6:
    m = (a + b) / 2
    if f(a) * f(m) < 0:
        b = m
    else:
        a = m
    steps += 1

print("steps:", steps)
print("formula gives:", math.ceil(math.log2(1 / 1e-6)))
print("midpoint within 1e-6 of sqrt(2):", abs((a + b) / 2 - math.sqrt(2)) < 1e-6)
steps: 20
formula gives: 20
midpoint within 1e-6 of sqrt(2): True

TrapBisection needs a sign change. A double root, such as f(x) = (x - 1)2, does not change sign at x = 1, so bisection cannot bracket it.

Question: The starting width is 4. How wide is the bracket after 5 steps?

The width halves each step, so it is 4/25 = 4/32 = 0.125.

Question: Why does bisection need f(a) and f(b) to have opposite signs?

Because of the intermediate value theorem. For a continuous function, opposite signs at the ends guarantee a root between them.

Step 2: The Newton-Raphson method

The idea: follow the tangent

Picture a hill and a sea level. You stand at a point, look at the slope under your feet, and follow it down to where it reaches sea level. Newton's method does the same with a graph. At the current guess xn, draw the tangent line. Where this straight line crosses the x-axis is the next guess xn+1.

xn+1 = xn - f(xn)/f'(xn)

Here f(xn) is the function value at the guess and f'(xn) is the slope there. The tangent line is y = f(xn) + f'(xn)(x - xn). Setting y = 0 and solving for x gives the formula.

Worked example 2: the square root of 2 by Newton

Use f(x) = x2 - 2, so f'(x) = 2x. Start at x0 = 1.5.

  1. Step 1. f(1.5) = 0.25 and f'(1.5) = 3. So x1 = 1.5 - 0.25/3 = 17/12, about 1.41667.
  2. Step 2. f(17/12) = 289/144 - 2 = 1/144 and f'(17/12) = 17/6. So x2 = 17/12 - (1/144)/(17/6) = 577/408, about 1.414216.
  3. Compare. The true value is √2 = 1.4142136. The error falls from about 0.0025 to about 0.0000021 in one step.
from fractions import Fraction

def f(x):
    return x * x - 2

def df(x):
    return 2 * x

x = Fraction(3, 2)
for k in range(1, 3):
    x = x - f(x) / df(x)
    print("x", k, "=", x, "=", round(float(x), 6))
x 1 = 17/12 = 1.416667
x 2 = 577/408 = 1.414216

Why Newton is so fast

The error falls from 0.0025 to 0.0000021. The new error is roughly the square of the old one, times a constant. This is quadratic convergence:

en+1 ≈ C · en2, where C = f''(r)/(2f'(r)) and r is the root

If the error is 0.01, the next is about 0.0001, and then about 10-8. The number of correct digits doubles each step. Bisection, by contrast, gains about one binary digit per step.

When Newton fails

Newton needs f' to be non-zero near the iterates and a start reasonably close to the root. Take f(x) = x3 - 2x + 2 and start at x0 = 0. Then x1 = 0 - 2/(-2) = 1. At x = 1, f(1) = 1 and f'(1) = 1, so x2 = 1 - 1/1 = 0. The guesses bounce between 0 and 1 forever.

TrapNewton can cycle or diverge from a poor start. Bisection never does this. When a question asks which method is guaranteed to converge, the answer is bisection (or regula falsi), not Newton.

Question: Apply one Newton step to f(x) = x2 - 4 from x0 = 3. What is x1?

f(3) = 5 and f'(3) = 6. So x1 = 3 - 5/6 = 13/6, about 2.1667.

Question: Write the Newton iteration formula.

xn+1 = xn - f(xn)/f'(xn). Write it down before you calculate.

Step 3: The regula falsi (false position) method

The idea: join the two ends

Regula falsi keeps the safety of bisection but makes a smarter guess. Instead of the midpoint, it draws the secant line joining (a, f(a)) and (b, f(b)). The guess is where this line crosses the x-axis:

x = (a·f(b) - b·f(a)) / (f(b) - f(a))

The new point replaces whichever end has the same sign as f(x), so the sign change is kept. If the graph is nearly straight in the bracket, the guess is very close to the root.

Worked example 3: the square root of 2 again

Use f(x) = x2 - 2 on [1, 2], where f(1) = -1 and f(2) = 2.

  1. Step 1. x = (1 × 2 - 2 × (-1))/(2 - (-1)) = 4/3, about 1.3333. Then f(4/3) = 16/9 - 2 = -2/9, which is negative. Its sign matches f(1), so the new bracket is [4/3, 2].
  2. Step 2. With a = 4/3, f(a) = -2/9, b = 2 and f(b) = 2, we get x = (8/3 + 4/9)/(20/9) = 28/20 = 7/5 = 1.4.
  3. Compare. f(7/5) = -1/25 = -0.04, so the guess 1.4 is already close to √2.
from fractions import Fraction

def f(x):
    return x * x - 2

a, b = Fraction(1), Fraction(2)
for k in range(1, 3):
    x = (a * f(b) - b * f(a)) / (f(b) - f(a))
    print("step", k, "x =", x, "f(x) =", f(x), "=", float(f(x)))
    if f(a) * f(x) < 0:
        b = x
    else:
        a = x
step 1 x = 4/3 f(x) = -2/9 = -0.2222222222222222
step 2 x = 7/5 f(x) = -1/25 = -0.04

TrapRegula falsi can be slow. On a curved graph, one end of the bracket may stay fixed for many steps while the other moves in. Check the iterates rather than assuming they improve fast.

Question: Which line does regula falsi use to pick the next guess?

The secant through the two endpoints of the current bracket. The next guess is where it crosses the x-axis.

Question: What is the first regula falsi guess for f(x) = x2 - 2 on [1, 2]?

x = 4/3, about 1.3333.

Step 4: Convergence rates compared

How to measure speed

We compare methods by how the error changes from one step to the next:

  • Bisection halves the error bound each step. This is linear convergence with ratio 1/2.
  • Regula falsi usually converges linearly, often faster than bisection, but one end can stay fixed, so its rate can be poor.
  • Newton squares the error each step. This is quadratic convergence, the fastest of the three once the guess is close.
MethodConvergenceNeedsAlways safe?
BisectionLinear, error halves each stepA sign changeYes
Regula falsiUsually linear, can be slowA sign changeYes
Newton-RaphsonQuadratic near the rootf' and a good startNo

For the square root of 2 to within 10-8, bisection on [1, 2] needs 26 steps, while Newton from 1.5 needs only 3. The extra cost of Newton is computing f', and its risk is a poor start.

Question: Bisection needs about 26 steps to reach 10-8. Roughly how many for 10-16?

About 53. Each factor of 108 needs about 26.6 more halvings, since log2(108) is about 26.6. So 26 + 27 = 53 steps.

Question: Which method gives a safe first estimate, and which one polishes it quickly?

Bisection gives the safe first estimate, because a sign change guarantees it. Newton then polishes the estimate quickly, because it converges quadratically near the root.

Step 5: Jacobi and Gauss-Seidel for linear systems

The problem

Engineering problems often give several equations at once, such as 4x + y = 9 and x + 3y = 7. For very large systems, iterative methods are cheaper than elimination. Each one repeats a simple update until the values settle.

Jacobi method

Rearrange each equation to solve for one unknown: x = (9 - y)/4 and y = (7 - x)/3. Start from x = 0 and y = 0. Each step uses only the old values:

xk+1 = (9 - yk)/4, yk+1 = (7 - xk)/3

Gauss-Seidel method

Gauss-Seidel uses each new value as soon as it exists:

xk+1 = (9 - yk)/4, yk+1 = (7 - xk+1)/3

Notice that yk+1 uses the newest x. This extra information usually makes the method faster.

Worked example 4: two steps by hand

The exact answer is x = 20/11, about 1.8182, and y = 19/11, about 1.7273.

  1. Jacobi, step 1. x1 = 9/4 = 2.25 and y1 = 7/3 = 2.3333.
  2. Jacobi, step 2. x2 = (9 - 2.3333)/4 = 1.6667 and y2 = (7 - 2.25)/3 = 1.5833.
  3. Gauss-Seidel, step 1. x1 = 2.25, then y1 = (7 - 2.25)/3 = 1.5833.
  4. Gauss-Seidel, step 2. x2 = (9 - 1.5833)/4 = 1.8542, then y2 = (7 - 1.8542)/3 = 1.7153.
  5. Compare. After two steps Gauss-Seidel is at (1.8542, 1.7153), much closer to the exact answer than Jacobi's (1.6667, 1.5833).

When does it converge?

Both methods converge when the system is diagonally dominant. In each equation, the diagonal coefficient must be larger in size than the sum of the other coefficients. Here 4 > 1 and 3 > 1, so both methods converge.

TrapIn Gauss-Seidel, use the newest values. If you use old values, you have Jacobi again and lose the speed-up.

Question: Is 2x + 5y = 1 with 3x + y = 4 ready for Jacobi as written?

No. In the first row 2 is smaller than 5, and in the second row 1 is smaller than 3. Rearrange so that each diagonal entry is the largest in its row, and check dominance again.

Question: In Gauss-Seidel, which values compute yk+1?

The newest value xk+1, computed in the same step, together with the update formula for y.

These problems are original, written in the style of GATE questions. They are not past exam questions. Try each one on paper before you read the answer.

First bisection midpoint

Let f(x) = x3 - 2 on the bracket [1, 2]. What is the midpoint used in the first step of bisection? (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The first midpoint.
  2. Which idea applies. m = (a + b)/2.
  3. Work it out. m = (1 + 2)/2 = 1.5.
  4. Check. f(1) = -1 and f(2) = 6 have opposite signs, so the bracket is valid, and 1.5 lies inside it.

Answer: 1.5.

Properties of bisection

Select all the statements about the bisection method that are true.

(A) It needs f(a) and f(b) to have opposite signs at the start.
(B) Each step halves the width of the bracket.
(C) It always converges faster than Newton-Raphson.
(D) It needs f to be continuous on the bracket.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which statements describe bisection correctly.
  2. Which idea applies. The sign-change requirement, the halving rule, and the speed comparison.
  3. Work it out. (A) True. (B) True. (C) False, because Newton is usually much faster near the root. (D) True, since the intermediate value theorem needs continuity.
  4. Check. Worked example 2 showed Newton finishing in 3 steps where bisection needed 26.

Answer: (A), (B) and (D).

Two Newton steps for a square root

Use Newton-Raphson on f(x) = x2 - 3 starting at x0 = 2. Find x2, rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The second iterate.
  2. Which idea applies. xn+1 = xn - (xn2 - 3)/(2xn).
  3. Work it out. Step 1: f(2) = 1 and f'(2) = 4, so x1 = 2 - 1/4 = 7/4. Step 2: f(7/4) = 1/16 and f'(7/4) = 7/2, so x2 = 7/4 - (1/16)/(7/2) = 97/56, about 1.7321.
  4. Check. The program repeats the two steps with exact fractions.
from fractions import Fraction

x = Fraction(2)
for k in range(2):
    x = x - (x * x - 3) / (2 * x)
print(x, round(float(x), 4))
97/56 1.7321

Answer: x2 = 97/56, which is 1.7321 to four decimal places.

First regula falsi guess

Use regula falsi on f(x) = x2 - 2 with the bracket [1, 2]. Find the first guess x1, rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The first regula falsi guess.
  2. Which idea applies. x = (a f(b) - b f(a))/(f(b) - f(a)).
  3. Work it out. f(1) = -1 and f(2) = 2, so x = (2 + 2)/(2 + 1) = 4/3, about 1.3333.
  4. Check. f(4/3) = -2/9 has the same sign as f(1), so the bracket becomes [4/3, 2] and the sign change is kept.

Answer: x1 = 4/3, which is 1.3333 to four decimal places.

Which statements about the system are true?

Consider the system 3x + y = 5 and x + 2y = 5, solved iteratively from x = 0, y = 0. Select all that apply.

(A) The coefficient matrix is diagonally dominant.
(B) Both Jacobi and Gauss-Seidel converge to the solution.
(C) Gauss-Seidel uses the newest x when it computes y, so its iterates can differ from Jacobi's in the same step.
(D) Gauss-Seidel always needs more iterations than Jacobi.

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which statements are true.
  2. Which idea applies. Diagonal dominance, its convergence guarantee, and the difference between the two update rules.
  3. Work it out. (A) 3 > 1 and 2 > 1. True. (B) Dominance guarantees convergence. True. (C) Jacobi gives y1 = 5/2 = 2.5, but Gauss-Seidel gives y1 = (5 - 5/3)/2 = 5/3 after x1 = 5/3. True. (D) Gauss-Seidel is usually faster, so this is false.
  4. Check. The step-1 values in (C) differ between the two methods, as claimed.

Newton's method on cosine

Use Newton-Raphson on f(x) = cos x - x with starting value x0 = 1. Find x2, rounded to four decimal places. (Answer type: NAT, a decimal.)

How to think about it

  1. What is asked. The second iterate.
  2. Which idea applies. f'(x) = -sin x - 1 and the Newton formula.
  3. Work it out. At x0 = 1: cos 1 is about 0.5403 and sin 1 is about 0.8415. So f(1) is about -0.4597 and f'(1) is about -1.8415, giving x1 = about 0.7504. At 0.7504: cos is about 0.7314 and sin is about 0.6818, so f is about -0.0189 and f' is about -1.6819. Then x2 = 0.7504 - (-0.0189)/(-1.6819), about 0.7391.
  4. Check. The true root is about 0.73909. The program computes two steps at full precision.
import math

def f(x):
    return math.cos(x) - x

def df(x):
    return -math.sin(x) - 1

x = 1.0
for k in range(2):
    x = x - f(x) / df(x)
print(round(x, 4))
0.7391

Answer: x2 is about 0.7391 to four decimal places.

Where a Newton method can go wrong

Let f(x) = x3 - 2x + 2. Select all that apply.

(A) Newton-Raphson from x0 = 0 gives x1 = 1.
(B) Newton-Raphson from x0 = 0 gives x2 = 0.
(C) Newton-Raphson from x0 = 0 converges to a root of f.
(D) Bisection can be started on the bracket [-3, 0].

Answer type: MSQ, select all that apply.

How to think about it

  1. What is asked. Which statements are true.
  2. Which idea applies. Compute the Newton steps, then check the signs at the ends of the proposed bracket.
  3. Work it out. At x = 0, f = 2 and f' = -2, so x1 = 1. At x = 1, f = 1 and f' = 1, so x2 = 0. So (A) and (B) are true, and the iterates cycle, so (C) is false. For (D), f(-3) = -19 and f(0) = 2 have opposite signs, so (D) is true.
  4. Check. The program prints the two end values of the bracket.
def f(x):
    return x**3 - 2*x + 2

print(f(-3), f(0))
-19 2

Answer: (A), (B) and (D).

Exam-level 1: Newton-Raphson iteration (NAT, 2 marks)

Apply Newton-Raphson to f(x) = x³ − 2x − 5 starting at x0 = 2. Find x2, correct to 4 decimal places.

How to think about it

  1. What is asked. The second Newton iterate.
  2. Which idea applies. xn+1 = xn − f(xn)/f′(xn), with f′ = 3x² − 2.
  3. Work it out. x1 = 2 − (−1)/10 = 2.1. f(2.1) = 0.061, f′(2.1) = 11.23. x2 = 2.1 − 0.00543 = 2.0946.
  4. Check. The code prints both iterates.
f = lambda x: x ** 3 - 2 * x - 5
d = lambda x: 3 * x ** 2 - 2
x = 2.0
for i in range(2):
    x = x - f(x) / d(x)
    print("x%d = %.4f" % (i + 1, x))

x1 = 2.1000
x2 = 2.0946

Answer: 2.0946.

Exam-level 3: Convergence order (MSQ, 2 marks)

Which are TRUE? (A) Newton-Raphson converges quadratically to a simple root. (B) Bisection converges linearly. (C) The secant method has order about 1.618. (D) Newton-Raphson always converges for any starting point.

How to think about it

  1. What is asked. Facts about root-finding methods.
  2. Which idea applies. Each method's error obeys en+1 ≈ Cenp for its order p.
  3. Work it out. (A) True. (B) The error bound halves each step. True. (C) The golden ratio. True. (D) It can diverge or cycle, for example from a point where f′ is near 0. False.

Summary

Root
A value x where f(x) = 0.
Iteration
A repeated step in which each result becomes the next input.
Intermediate value theorem
For a continuous f, a sign change on [a, b] guarantees a root inside.
Bracket
An interval whose endpoints give function values with opposite signs.
Bisection
Halve the bracket each step, keeping the half with the sign change. Linear and always safe.
Newton-Raphson
Follow the tangent line to the next guess. Quadratic near the root, but can cycle from a poor start.
Regula falsi
Use the secant through the bracket ends to find the next guess. Always safe, but can be slow.
Linear convergence
The error shrinks by a fixed fraction each step.
Quadratic convergence
The error at the next step is about a constant times the square of the current error.
Tolerance
The accuracy target that tells an iterative method when to stop.
Linear system
Several equations in several unknowns, each appearing to the first power.
Jacobi method
Solve each unknown from the old values of the others, then repeat.
Gauss-Seidel method
Like Jacobi, but use each new value immediately in the same step.
Diagonally dominant
Each diagonal entry is larger in size than the sum of the other entries in its row.
Secant line
A straight line through two points on a graph.

Remember these

  1. Bisection needs a sign change, and it is guaranteed to converge.
  2. The number of bisection steps for tolerance ε is at least log2((b - a)/ε).
  3. The Newton formula is xn+1 = xn - f(xn)/f'(xn).
  4. Newton is fast near the root, but it can cycle from a poor start.
  5. Regula falsi uses the straight line through the bracket ends.
  6. Check diagonal dominance before Jacobi or Gauss-Seidel, and use the newest values in Gauss-Seidel.
